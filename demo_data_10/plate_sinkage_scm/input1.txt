Write a PyChrono (version 10.0) Python script that runs a plate-sinkage (bevameter-style) virtual experiment on deformable soil, headless (no visualization window, no rendering).

Setup:
- Use PyChrono's SCM (Soil Contact Model) deformable terrain from the vehicle module, with these Bekker-Wong soil parameters: Bekker Kphi = 2.0e6, Bekker Kc = 0.0, exponent n = 1.0, Mohr cohesion = 0.0, Mohr friction = 30 deg, Janosi shear = 0.01, elastic stiffness K = 2.0e7, damping R = 1.0e4.
- Terrain: a flat square SCM patch 1.0 m x 1.0 m with mesh resolution (delta) 0.02 m, lying in the X-Y plane with height along +Z (gravity acts along -Z at 9.81 m/s^2).
- Press a rigid flat plate onto the soil: a box 0.2 m x 0.2 m (footprint) x 0.05 m (thick), placed with its bottom face resting on the soil surface (z = 0), carrying a total downward load of F = 500 N (i.e. give the plate a mass so its weight is 500 N). Let it settle and sink to equilibrium.
- Integrate at a fixed step of 2e-3 s for 1.5 s of simulated time.
- Note: in PyChrono 10.0 a collision system must be set on the system BEFORE the SCM terrain is created; and the SCM terrain is advanced each step (synchronize then advance) alongside the dynamics step.

Required outputs (so the experiment can be graded):
- Write a file named out.csv with a header row "t,sinkage" and one row per timestep, where sinkage is the plate's downward drop below its initial position (meters, positive as it sinks).
- At the very end, print exactly one JSON line to stdout: {"sinkage": <final plate sinkage in meters>, "load_N": <the applied load in newtons>}.

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
