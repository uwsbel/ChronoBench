Write a PyChrono (version 10.0) Python script that runs a single-tire terramechanics virtual experiment on CRM deformable terrain (Chrono's SPH-based continuum granular model), headless (no visualization window, no rendering), using the vehicle module's tire test rig.

Setup (use pychrono.vehicle):
- Load the wheel and tire from the shipped Polaris JSON specs: ReadWheelJSON(GetVehicleDataFile("Polaris/Polaris_Wheel.json")) and ReadTireJSON(GetVehicleDataFile("Polaris/Polaris_RigidMeshTire.json")).
- A ChSystemNSC with the Bullet collision system type and the BARZILAIBORWEIN solver; set the tire step size to 2e-4 s.
- A ChTireTestRig on that system with: gravitational acceleration 9.8, normal load 2500 N, tire step size 2e-4 s, tire visualization NONE.
- CRM terrain via rig.SetTerrainCRM(size, params) with a TerrainPatchSize of length 4.0 m, width 0.8 m, depth 0.2 m, and TerrainParamsCRM with sph_params.initial_spacing = 0.02, mat_props.density = 1700, mat_props.Young_modulus = 2e6, mat_props.cohesion_coeff = 1e2.
- Rig motion: constant carriage speed 0.2 m/s (SetLongSpeedFunction with a ChFunctionConst), constant wheel speed 10 RPM (SetAngSpeedFunction; convert RPM to rad/s with CH_RPM_TO_RAD_S), time delay 1.0 s, then Initialize(ChTireTestRig.Mode_TEST, 0.05).
- Simulation loop: advance the rig at a fixed 2e-4 s step until t = 5.0 s of simulated time (read t from the system clock). The rig sequences itself: it drops the tire onto the soil first and activates the motors and measurements around t = 3 s; do not fight that sequencing.

Required outputs (the script must produce these so the experiment can be graded):
- Write a file named out.csv with a header row "t,z,dbp,slip" and one row every 10 steps (every 2e-3 s), where z is the spindle body's height rig.GetSpindle().GetPos().z (m), dbp is the drawbar pull rig.GetDBP(), and slip is rig.GetLongitudinalSlip().
- At the very end, print exactly one JSON line to stdout:
  {"z_settled": <mean z over the last 1.0 s>, "dbp_tail": <mean dbp over the last 1.0 s>, "slip_tail": <mean slip over the last 1.0 s>, "load": 2500.0}

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
