Write a PyChrono (version 10.0) Python script that measures resting contact forces using a custom contact reporter, headless (no visualization window, no rendering).

Setup:
- Create a fixed horizontal ground plane (or a large fixed box acting as the floor).
- Drop N = 4 rigid spheres, each of radius 0.1 m and mass about 1.0 kg, from a small height so they fall a short distance onto the floor under gravity 9.81 m/s^2 (-Y). Space them out in X so they each settle independently.
- Simulate for about 1.5 s at a time step of 1e-3 s so all spheres come to rest on the floor.
- Note: in PyChrono 10.0 you must explicitly select a collision system for contacts to be generated (contacts will not form otherwise).

Measurement (this is the point of the task):
- After the spheres have settled, obtain the contact data by implementing your OWN contact reporter: subclass PyChrono's Python-side contact-reporting callback class, override its per-contact reporting method, and have the system report all current contacts to your reporter. Keep your reporter object alive on the Python side while it is used.
- Accumulate (a) the number of contacts reported and (b) the sum of the normal reaction force magnitudes over all contacts.

Required output:
- Print exactly one JSON line to stdout:
  {"n_contacts": <integer number of contacts reported>, "normal_force": <sum of contact normal reaction forces, in newtons>}

The summed normal force at static equilibrium should be about N*m*g (the total weight of the resting spheres). The script must run to completion on its own and exit (headless, no display). Output only the Python script.
