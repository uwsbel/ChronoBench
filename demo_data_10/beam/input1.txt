Write a PyChrono (version 10.0) Python script that computes the static tip deflection of a cantilever beam using the finite-element (FEA) module, headless (no visualization window, no rendering).

Setup:
- Model a slender cantilever beam with Euler-Bernoulli beam elements:
  - length 1.0 m, discretized into about 10 elements along its axis;
  - square cross-section 0.05 m x 0.05 m;
  - Young's modulus 2.0e10 Pa, Poisson ratio 0.3, density 7800 kg/m^3.
- Fully clamp one end (constrain all 6 degrees of freedom of the end node to a fixed body).
- Apply a static transverse point load of 150 N at the free tip, directed downward (-Y).
- Solve the LINEAR STATIC equilibrium (a direct/sparse solver is appropriate). Do not run a time-stepping dynamic loop; this is a static solve. Turn off automatic gravity on the mesh so the only load is the applied tip force.

Required output (so the experiment can be graded):
- At the very end, print exactly one JSON line to stdout:
  {"tip_deflection": <magnitude of the free tip's vertical deflection, in meters>, "analytic": <the Euler-Bernoulli prediction F*L^3/(3*E*I), with I = b^4/12 for the square section>}

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
