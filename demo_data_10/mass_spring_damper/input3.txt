  F(t) = F0 * sin(omega * t),  with  F0 = 1.0 N  and  omega = 10.0 rad/s.
Note that omega = 10 rad/s equals the oscillator's undamped natural frequency sqrt(k/m), so this drives the system at resonance. Keep everything else the same (headless, 1e-4 s step, 5.0 s).

After the initial transient dies out, the mass settles into a steady-state oscillation. Report its amplitude.

Required outputs (needed for grading):
- Write out.csv with header row "t,disp" (disp = displacement from equilibrium, meters), one row per timestep.
- Print exactly one JSON line at the end: {"ss_amp": <steady-state oscillation amplitude of disp in meters, i.e. the peak |disp| after the transient has decayed (say for t >= 3 s)>}.

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
