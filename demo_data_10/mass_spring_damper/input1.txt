Write a PyChrono (version 10.0) Python script that runs a one-dimensional damped spring-mass oscillator virtual experiment, headless (no visualization window, no rendering).

Setup:
- A single rigid mass of 1.0 kg connected to a fixed ground by a linear translational spring-damper (a single force element that provides both stiffness and viscous damping): stiffness k = 100 N/m, damping coefficient c = 2 N*s/m, spring rest length 1.0 m.
- No gravity (set gravitational acceleration to zero) so the only forces are the spring and damper.
- Displace the mass 0.1 m from its static equilibrium position along the spring axis and release it from rest.
- Integrate with a fixed time step of 1e-4 s for 5.0 s of simulated time.

Required outputs (the script must produce these so the experiment can be graded):
- Write a file named out.csv with a header row "t,disp" and one row per timestep, where disp is the mass's displacement from equilibrium along the spring axis (meters).
- At the very end, print exactly one JSON line to stdout:
  {"period_d": <damped oscillation period in seconds>, "zeta_est": <damping ratio estimated from the log-decrement of successive displacement peaks>}

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
