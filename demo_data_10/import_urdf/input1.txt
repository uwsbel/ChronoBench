Write a PyChrono (version 10.0) Python script that imports a robot description from a URDF file and actuates it, headless (no visualization window, no rendering).

A file named pendulum.urdf is available in the current working directory. Its full content is:

<?xml version="1.0"?>
<robot name="chronobench_pendulum">
  <link name="base_link">
    <inertial>
      <origin xyz="0 0 0" rpy="0 0 0"/>
      <mass value="1.0"/>
      <inertia ixx="0.01" iyy="0.01" izz="0.01" ixy="0" ixz="0" iyz="0"/>
    </inertial>
  </link>
  <link name="arm">
    <inertial>
      <origin xyz="0 -0.5 0" rpy="0 0 0"/>
      <mass value="2.0"/>
      <inertia ixx="0.1666667" iyy="0.0010" izz="0.1666667" ixy="0" ixz="0" iyz="0"/>
    </inertial>
    <visual>
      <origin xyz="0 -0.5 0" rpy="1.5707963 0 0"/>
      <geometry>
        <cylinder radius="0.02" length="1.0"/>
      </geometry>
    </visual>
  </link>
  <joint name="swing" type="revolute">
    <parent link="base_link"/>
    <child link="arm"/>
    <origin xyz="0 0 0" rpy="0 0 0"/>
    <axis xyz="0 0 1"/>
    <limit lower="-3.2" upper="3.2" effort="100.0" velocity="20.0"/>
  </joint>
</robot>

Setup:
- Create a system with gravity 9.81 m/s^2 along -Y.
- Load pendulum.urdf with PyChrono's URDF parser (pychrono.parsers, ChParserURDF), populate the system, and FIX the root link in place.
- Set the joints to POSITION actuation and drive the joint named "swing" with a sinusoidal motor function theta(t) = A*sin(2*pi*f*t), amplitude A = 0.5 rad, frequency f = 1.0 Hz.
- Integrate with a fixed time step of 1e-3 s for 3.0 s of simulated time.

Required outputs (the script must produce these so the experiment can be graded):
- Write a file named out.csv with a header row "t,theta" and one row per timestep, where theta is the arm's rotation angle about the global +Z axis in radians (the actuated joint angle).
- At the very end, print exactly one JSON line to stdout:
  {"amplitude": <max |theta| over the run, rad>, "A": <the amplitude you commanded>, "f": <the frequency you commanded>}

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
