Write a PyChrono (version 10.0) Python script that runs a full HMMWV wheeled-vehicle virtual experiment on rigid flat terrain, headless (no visualization window, no rendering).

Setup (use the pychrono.vehicle module):
- Create a full HMMWV (HMMWV_Full): SMC contact method, initial position (-6, 0, 0.6) with identity orientation, SHAFTS engine model, AUTOMATIC_SHAFTS transmission, AWD driveline, RIGID tire model. Initialize it, set all visualization types to NONE, and set the system's collision system type to Bullet.
- Terrain: a RigidTerrain with one flat patch (SMC contact material, friction 0.9) whose top surface is at z = 0, about 40 m x 8 m.
- Driver: straight-line drive, throttle ramped as throttle(t) = min(0.7, 3.5 * max(0, t - 0.2)), zero steering, zero braking (the plain vehicle ChDriver with SetThrottle/SetSteering/SetBraking is enough).
- Simulation loop at a fixed step of 2e-3 s for 4.0 s of simulated time, with the standard vehicle co-simulation pattern each step: driver.Synchronize(t), terrain.Synchronize(t), vehicle.Synchronize(t, driver_inputs, terrain), then Advance(step) on driver, terrain, and vehicle.

Required outputs (the script must produce these so the experiment can be graded):
- Write a file named out.csv with a header row "t,dist,speed,rut" and one row per step, where dist is the distance traveled along +X since the start (m), speed is the vehicle speed (m/s), and rut is the negative of the terrain height sampled at the rear-left wheel's current (x, y) location (identically 0 on rigid terrain; include the column anyway).
- At the very end, print exactly one JSON line to stdout:
  {"dist": <total distance traveled, m>, "final_speed": <speed at the end, m/s>, "rut_max": <max of the rut column, m>, "terrain": "rigid"}

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
