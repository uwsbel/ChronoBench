Write a PyChrono (version 10.0) Python script that runs a bouncing-ball restitution virtual experiment using the NSC (non-smooth, complementarity-based) contact formulation, headless (no visualization window, no rendering).

Setup:
- Use an NSC system (ChSystemNSC) and set the collision system type explicitly (Bullet).
- Gravity 9.81 m/s^2 along -Y.
- A fixed rigid floor box (e.g. 2 m x 0.2 m x 2 m) whose TOP face is at y = 0, with collision enabled.
- A rigid sphere of radius 0.1 m and density 1000 kg/m^3, with collision enabled, released from REST with its BOTTOM exactly 1.0 m above the floor top (so the sphere center starts at y = 1.1 m).
- One shared NSC contact material on both bodies: coefficient of restitution 0.7, friction 0.3.
- Integrate with a fixed time step of 2.0e-4 s for 1.5 s of simulated time. Use exactly this step: NSC impact resolution is time-step sensitive, and the graded physics assumes it.
- Ideal impact physics: the ball hits at t = 0.45 s and its first-bounce apex (ball-bottom height) is e^2 * h0 = 0.49 m.

Required outputs (the script must produce these so the experiment can be graded):
- Write a file named out.csv with a header row "t,y_bot" and one row per timestep, where y_bot is the HEIGHT OF THE BALL'S BOTTOM (center y minus radius) in meters.
- At the very end, print exactly one JSON line to stdout:
  {"apex1": <max of y_bot over t >= 0.5 s, i.e. the first-bounce apex, in meters>, "restitution": <the restitution you used>, "method": "NSC"}

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
