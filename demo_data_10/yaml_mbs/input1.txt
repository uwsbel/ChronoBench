Write a PyChrono (version 10.0) Python script that builds and runs a slider-crank mechanism DECLARED ENTIRELY IN CHRONO'S MBS-YAML SCHEMA, headless (no visualization window, no rendering).

Your script must author the YAML files itself (write them to the current working directory as inline strings), then load and run them through PyChrono's YAML parser (pychrono.parsers, ChParserMbsYAML):
- A MODEL yaml declaring, under a top-level "model:" key: bodies (name/location/mass/com/inertia; a fixed ground), joints, constraints, and motors.
- A SOLVER yaml (contact method, integrator type and time step, solver type).
- A SIMULATION yaml with "type: MBS" that references the model and solver files (bare filenames; they are resolved relative to the simulation file's directory) and sets "simulation: end_time" with "enforce_realtime: false".
- Construct the parser from the SIMULATION yaml (pass an absolute path), then CreateSystem() and Populate(sys), and run your own stepping loop.

The mechanism to declare:
- Fixed ground.
- A crank body whose pivot is at the origin, driven by a declared ROTATION motor (spindle REVOLUTE, body1 ground, body2 crank, axis [0, 1, 0], actuation_type SPEED, CONSTANT actuation function with value pi = 3.141592653589793 rad/s).
- A slider body on a PRISMATIC joint to ground along the +X axis, located at x = r + l.
- A connecting rod of length l realized as a DISTANCE constraint between the crank pin and the slider. IMPORTANT schema convention: the constraint attachment points (point1, point2) are given in GLOBAL coordinates of the initial assembly, so point1 = [r, 0, 0] (the crank pin) and point2 = [r + l, 0, 0] (the slider).
- Parameters: crank radius r = 0.25 m, rod length l = 1.0 m.
- Step the system at 1e-3 s for 4.0 s of simulated time.
- Physics check: for an inline slider-crank the slider stroke (peak-to-peak travel) equals 2*r = 0.5 m, independent of l and omega.

Required outputs (the script must produce these so the experiment can be graded):
- Write a file named out.csv with a header row "t,slider_x" and one row per timestep, where slider_x is the slider body's x coordinate (meters).
- At the very end, print exactly one JSON line to stdout:
  {"stroke": <peak-to-peak slider travel over the run, m>, "r": <the crank radius you declared, m>}

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
