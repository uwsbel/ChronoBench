Write a PyChrono (version 10.0) Python script that runs a two-gear train virtual experiment, headless (no visualization window, no rendering).

Setup:
- A fixed base (truss) body.
- Gear A, pitch radius 0.2 m, driven about the global Z axis by a rotational-speed motor at a constant +4 rad/s (signed by the right-hand rule about +Z).
- Gear B, pitch radius 0.4 m, mounted on its own fixed axis parallel to gear A's axis (revolute joint to the base), meshing EXTERNALLY with gear A.
- Model the mesh with PyChrono's gear constraint (the transmission-ratio link, ChLinkLockGear); do NOT model tooth geometry or rely on collision detection.
- Ideal external-mesh physics must hold: the pitch-line velocities match, so gear B counter-rotates at omega_B = -(rA/rB) * omega_A.
- Integrate with a fixed time step of 1e-3 s for 3.0 s of simulated time.

Required outputs (the script must produce these so the experiment can be graded):
- Write a file named out.csv with a header row "t,w1,w2" and one row per timestep, where w1 and w2 are the angular velocities (rad/s) of gear A and gear B about the global Z axis (signed, right-hand rule).
- At the very end, print exactly one JSON line to stdout:
  {"w1_mean": <mean of w1 over t >= 2.0 s>, "w2_mean": <mean of w2 over t >= 2.0 s>, "ratio": <rA/rB>}

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
