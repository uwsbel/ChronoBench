Write a PyChrono (version 10.0) Python script that runs a slider-crank mechanism virtual experiment, headless (no visualization window, no rendering).

Setup:
- Build a planar slider-crank as a closed kinematic loop, mounted relative to a fixed base body:
  - a crank of radius 0.4 m, driven about the global Z axis by a rotational-speed motor at a constant pi rad/s;
  - a connecting rod of length 1.5 m joining the crank pin to the piston (revolute joints at both ends of the rod);
  - a piston constrained to translate along a single straight line by a prismatic joint.
- Integrate with a fixed time step of 1e-3 s for 3.0 s of simulated time.

Required outputs (the script must produce these so the experiment can be graded):
- Write a file named out.csv with a header row "t,piston_x" and one row per timestep, where piston_x is the piston's position along its slide axis (meters).
- At the very end, print exactly one JSON line to stdout:
  {"stroke": <peak-to-peak travel of the piston over the run, in meters>, "crank_rad": <the crank radius you used, in meters>}

For an inline slider-crank the piston stroke equals twice the crank radius. The script must run to completion on its own and exit (headless, no display). Output only the Python script.
