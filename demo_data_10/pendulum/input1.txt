Write a PyChrono (version 10.0) Python script that runs a simple pendulum virtual experiment, headless (no visualization window, no rendering).

Setup:
- A single rigid pendulum: a compact bob of mass 1.0 kg whose center is 1.0 m from the pivot. Treat the bob as a point mass (give it negligible own rotational inertia).
- The pivot is at the origin. Use a revolute joint so the bob swings in a vertical plane about the global Z axis.
- Gravity is 9.81 m/s^2 acting in the -Y direction.
- Release the pendulum from rest at a small angle of 5 degrees from the downward vertical.
- Integrate with a fixed time step of 1e-3 s for 5.0 s of simulated time.

Required outputs (the script must produce these so the experiment can be graded):
- Write a file named out.csv with a header row "t,theta" and one row per timestep, where theta is the pendulum's angle in radians measured from the downward vertical (0 at the hanging equilibrium).
- At the very end, print exactly one JSON line to stdout of the form:
  {"period_est": <estimated oscillation period in seconds>, "theta_max": <maximum absolute angle in radians over the run>}

The script must run to completion on its own and exit (no blocking calls, no display). Output only the Python script.
