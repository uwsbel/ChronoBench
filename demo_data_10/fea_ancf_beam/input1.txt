Write a PyChrono (version 10.0) Python script that computes the static deflection of a cantilever using ANCF cable finite elements, headless (no visualization window, no rendering).

Setup:
- Model a slender cantilever with the ANCF gradient-deficient CABLE element (ChElementCableANCF, e.g. via the ChBuilderCableANCF helper):
  - length 1.0 m along the +X axis, discretized into about 20 elements;
  - CIRCULAR cross-section of diameter 0.02 m (set on a ChBeamSectionCable);
  - Young's modulus 2.0e10 Pa, density 7800 kg/m^3, no Rayleigh damping.
- Clamp the root: the first node's position AND slope must both be fixed (a cantilever clamp, not a hinge).
- Apply a static transverse point load of 2.0 N at the free tip, directed downward (-Y).
- Solve the NONLINEAR STATIC equilibrium (a direct/sparse solver such as Pardiso is appropriate). Do not run a time-stepping dynamic loop. Turn off automatic gravity on the mesh so the only load is the applied tip force.
- Physics check: in this small-deflection regime the ANCF cable statics must match Euler-Bernoulli, delta = F*L^3/(3*E*I) with I = pi*d^4/64 for the circular section.

Required outputs (so the experiment can be graded):
- Write a file named out.csv with a header row "x,y" and one row per node, giving each node's axial coordinate x (meters) and its transverse deflection y (meters) in the solved deflected shape. (The tip is the node at x = 1.0 m.)
- At the very end, print exactly one JSON line to stdout:
  {"tip_deflection": <magnitude of the free tip's vertical deflection, m>, "analytic": <F*L^3/(3*E*I), I = pi*d^4/64>}

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
