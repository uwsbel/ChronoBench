Write a PyChrono (version 10.0) Python script that runs a fluid-solid interaction (FSI) virtual experiment, headless (no visualization window, no rendering): a rigid sphere dropped into a tank of water, simulated with Chrono's SPH-based FSI module (pychrono.fsi).

Setup:
- Multibody side: a ChSystemNSC with the Bullet collision system type.
- FSI problem: a ChFsiProblemCartesian with initial spacing 0.025 m on that system; gravity (0, 0, -9.8); CFD step size 1e-4 s and MBD step size 1e-4 s.
- Fluid (SetCfdSPH with a FluidProperties): density 1000 kg/m^3, viscosity 1.
- SPH parameters (SetSPHParameters with an SPHParameters): RK2 integration scheme, 4 BCE layers, initial spacing 0.025, d0 multiplier 1, max velocity 4.0, XSPH shifting with eps 0.5, artificial viscosity 0.03, TAIT equation of state, ARTIFICIAL_UNILATERAL viscosity method, ADAMI boundary method, proximity search every step, delta-SPH on with coefficient 0.1, variable time step enabled.
- The sphere: radius R = 0.12 m, density 500 kg/m^3 (half the water density). Build it as a ChBody with mass = density * sphere volume and inertia = mass * the sphere's gyration tensor, initial center at (0, 0, 1.05 * 0.5 + 0.12), i.e. released just above the water. Give it collision/BCE geometry via a ChBodyGeometry carrying one SphereShape of radius R and a default contact material, and couple it to the fluid with AddRigidBody(body, geometry, True, True).
- The tank: register a DepthPressurePropertiesCallback for a fluid depth of 0.5 m, then Construct the fluid box of size (0.8, 0.8, 0.5) at origin (0, 0, 0) with all box sides EXCEPT the top (BoxSide_ALL & ~BoxSide_Z_POS), so the still-water surface sits at z = 0.5. Initialize the FSI problem.
- Time integration: advance the coupled problem with DoStepDynamics at a meta step of 5e-4 s until t = 3.0 s.
- Physics to expect: a density-500 sphere floats half-submerged; after the splash it settles with its center close to the still-water surface.

Required outputs (the script must produce these so the experiment can be graded):
- Write a file named out.csv with a header row "t,z,zrel" and one row per meta step, where z is the sphere center height (m) and zrel = z - 0.5 is the center height relative to the still-water surface (m).
- At the very end, print exactly one JSON line to stdout:
  {"z_settled_rel_surface": <mean of zrel over the last 1.0 s>, "density": 500.0, "behavior": "floats"}

The script must run to completion on its own and exit (headless, no display). Output only the Python script.
