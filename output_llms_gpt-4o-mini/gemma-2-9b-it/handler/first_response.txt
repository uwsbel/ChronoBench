```python
import pychrono as chrono
import rospy
from chrono_ros_msgs.msg import IntegerStamped

# Initialize ROS node
rospy.init_node('chrono_ros_sim')

# Initialize Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravitational acceleration

# Define physical material properties
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.5)
material.SetRestitution(0.2)

# Add fixed floor
floor = chrono.ChBodyEasyBox(10, 10, 0.1, material)
floor.SetPos(chrono.ChVectorD(0, -0.5, 0))
floor.SetBodyFixed(True)
system.Add(floor)

# Add movable box
box = chrono.ChBodyEasyBox(1, 1, 1, material)
box.SetPos(chrono.ChVectorD(0, 1, 0))
system.Add(box)

# Create custom ROS handler
class IntegerHandler(chrono.ChRosHandler):
    def __init__(self, topic_name):
        super().__init__()
        self.topic_name = topic_name
        self.pub = rospy.Publisher(self.topic_name, IntegerStamped, queue_size=10)

    def update(self, time):
        # Publish integer message to ROS topic
        msg = IntegerStamped()
        msg.header.stamp = rospy.Time.now()
        msg.data = int(time)
        self.pub.publish(msg)

# Configure ROS manager
ros_manager = chrono.ChRosManager()
ros_manager.SetClockHandler(chrono.ChRosClockHandler())
ros_manager.SetBodyHandler(chrono.ChRosBodyHandler())
ros_manager.SetTransformHandler(chrono.ChRosTransformHandler())
ros_manager.AddHandler(IntegerHandler('integer_topic'))

# Run simulation loop
while not rospy.is_shutdown():
    system.DoStepDynamics(0.01)  # Advance system by 0.01 seconds
    ros_manager.Update(system)  # Update ROS communication

```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries.
   - Initializes ROS node with `rospy.init_node()`.
   - Creates a Chrono system with `chrono.ChSystemNSC()`.
   - Sets gravitational acceleration using `Set_G_acc()`.

2. **Physical Systems:**
   - Defines a material with friction and restitution properties.
   - Adds a fixed floor using `chrono.ChBodyEasyBox()` and sets its position and fixed state.
   - Adds a movable box using `chrono.ChBodyEasyBox()` and sets its initial position.

3. **ROS Handler:**
   - Creates a custom `IntegerHandler` class that inherits from `chrono.ChRosHandler`.
   - Overrides the `update()` method to publish an integer message containing the current simulation time to the specified ROS topic.

4. **ROS Manager Configuration:**
   - Creates a `chrono.ChRosManager` object.
   - Configures handlers for clock, body, and transform updates.
   - Registers the custom `IntegerHandler` using `AddHandler()`.

5. **Simulation Loop:**
   - Enters a loop that continues until ROS shutdown.
   - Advances the Chrono system by one timestep using `DoStepDynamics()`.
   - Updates ROS communication using `ros_manager.Update()`.

**Note:**

- Replace `'integer_topic'` with the desired ROS topic name.
- Adjust the simulation timestep (`0.01`) as needed.
- This script assumes you have the necessary ROS packages installed, including `chrono_ros_msgs`.
