```python
import pychrono as chrono
import pychrono.irrlicht as vis

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# 2. Add physical systems and objects
#  - Floor (truss)
floor = chrono.ChBodyEasyBox(10, 10, 0.1)
floor.SetPos(chrono.ChVectorD(0, 0, -0.1))
floor.SetBodyFixed(True)
system.Add(floor)

#  - Crankshaft
crankshaft = chrono.ChBodyEasyCylinder(0.1, 0.5, 10)
crankshaft.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(crankshaft)

#  - Connecting Rod
connecting_rod = chrono.ChBodyEasyCylinder(0.05, 0.5, 1)
connecting_rod.SetPos(chrono.ChVectorD(0.5, 0, 0))
system.Add(connecting_rod)

#  - Piston
piston = chrono.ChBodyEasyBox(0.2, 0.2, 0.1)
piston.SetPos(chrono.ChVectorD(1, 0, 0))
system.Add(piston)

#  - Joints
crankshaft_joint = chrono.ChLinkLockPrismatic()
crankshaft_joint.Initialize(crankshaft, connecting_rod, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(1, 0, 0))
connecting_rod_joint = chrono.ChLinkLockRevolute()
connecting_rod_joint.Initialize(connecting_rod, piston, chrono.ChVectorD(0.25, 0, 0), chrono.ChVectorD(0, 0, 1))
system.Add(crankshaft_joint)
system.Add(connecting_rod_joint)

#  - Motor
motor = chrono.ChMotorRotation()
motor.SetMode(chrono.ChMotorMode.MODE_TORQUE_CONTROL)
motor.SetTorque(10)
motor.Initialize(crankshaft, chrono.ChVectorD(0, 0, 1))
system.Add(motor)

# 3. Set default parameters
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))
system.Set_TimeStep(0.01)

# 3. Visualization setup
vis.Add(system)
vis.SetCamera(chrono.ChVectorD(3, 3, 3), chrono.ChVectorD(0, 0, 0))
vis.SetAmbientLight(chrono.ChColor(0.2, 0.2, 0.2))
vis.SetDirectionalLight(chrono.ChColor(0.8, 0.8, 0.8), chrono.ChVectorD(1, 1, -1))

# Additional visual elements (example)
# piston.SetTexture(chrono.ChTexture("path/to/piston_texture.png"))
# crankshaft.SetLogo("path/to/crankshaft_logo.png")

# Run the simulation
vis.Start()
while vis.GetTimer() < 10:
    system.DoStepDynamics()
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - `chrono.SetChronoDataPath()`: Sets the path to your Chrono data files (replace "path/to/chrono/data").
   - `system = chrono.ChSystemNSC()`: Creates a new Chrono simulation system.

2. **Adding Objects:**
   - **Floor:** A simple box shape representing the ground. It's fixed in place.
   - **Crankshaft:** A cylinder representing the rotating shaft.
   - **Connecting Rod:** Another cylinder connecting the crankshaft to the piston.
   - **Piston:** A box shape representing the moving component.
   - **Joints:**
     - `crankshaft_joint`: A prismatic joint allowing the connecting rod to slide along the crankshaft.
     - `connecting_rod_joint`: A revolute joint allowing the piston to rotate around the connecting rod.

3. **Motor:**
   - A `ChMotorRotation` is added to the crankshaft to provide a constant torque, causing it to rotate.

4. **Parameters:**
   - `system.Set_G_acc()`: Sets the gravitational acceleration.
   - `system.Set_TimeStep()`: Defines the simulation time step (smaller values mean more accurate but slower simulations).

5. **Visualization:**
   - `vis.Add(system)`: Adds the Chrono system to the Irrlicht visualization.
   - `vis.SetCamera()`: Sets the initial camera position and target.
   - `vis.SetAmbientLight()`: Sets the overall ambient lighting.
   - `vis.SetDirectionalLight()`: Adds a directional light source.
   - **Optional:** You can add textures and logos to the objects using `SetTexture()` and `SetLogo()`.

6. **Simulation Loop:**
   - `vis.Start()`: Starts the Irrlicht visualization.
   - The `while` loop runs the simulation:
     - `system.DoStepDynamics()`: Performs one simulation time step.
     - `vis.Render()`: Renders the visualization.



Remember to:

- Replace `"path/to/chrono/data"` with the actual path to your Chrono data files.
- Adjust the simulation parameters (time step, motor torque, etc.) to your needs.
- Customize the visualization settings (camera, lighting, textures) as desired.
