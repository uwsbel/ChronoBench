```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht

# Initialize Chrono
chrono.SetChronoDataPath("path/to/your/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Create Irrlicht visualization
app = irrlicht.ChIrrApp(system)
app.SetWindowSize(800, 600)
app.AddCamera(chrono.ChVectorD(0, 1, 2))  # Initial camera position
app.AddLight(chrono.ChVectorD(1, 1, 1))
app.AssetBindAll()

# Particle Emitter
class ParticleEmitter(chrono.ChBody):
    def __init__(self, system, particle_count, emission_rate):
        super().__init__()
        self.particle_count = particle_count
        self.emission_rate = emission_rate
        self.system = system
        self.particle_list = []

    def EmitParticle(self):
        # Generate random particle properties
        shape = chrono.ChBoxShape(chrono.ChVectorD(0.1, 0.1, 0.1))  # Example shape
        mass = 0.1
        pos = chrono.ChVectorD(chrono.Random(), chrono.Random(), chrono.Random())
        vel = chrono.ChVectorD(chrono.Random(), chrono.Random(), chrono.Random())
        orient = chrono.Q_from_Euler123(chrono.Random(), chrono.Random(), chrono.Random())

        # Create particle body
        particle = chrono.ChBodyEasy(mass, shape)
        particle.SetPos(pos)
        particle.SetRot(orient)
        particle.SetBodyFixed(False)
        particle.SetLinearVelocity(vel)
        self.system.Add(particle)
        self.particle_list.append(particle)

    def Update(self):
        if len(self.particle_list) < self.particle_count:
            self.EmitParticle()

# Create and configure particle emitter
emitter = ParticleEmitter(system, 100, 1)  # Emit 100 particles at a rate of 1 per frame

# Apply custom gravitational forces
def apply_gravitational_force(particle, target_particle):
    distance = particle.GetPos() - target_particle.GetPos()
    force_magnitude = -100 * (1 / distance.Length())  # Example force
    force_direction = distance.Normalize()
    particle.AddForce(force_direction * force_magnitude)

# Simulation loop
while not app.GetDevice().isWindowClosed():
    app.BeginScene()
    system.DoStepDynamics(chrono.ChTime(0.01))

    # Apply gravitational forces between particles
    for i in range(len(emitter.particle_list)):
        for j in range(i + 1, len(emitter.particle_list)):
            apply_gravitational_force(emitter.particle_list[i], emitter.particle_list[j])

    app.DrawAll()
    app.EndScene()

app.GetDevice().run()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries (pychrono and irrlicht).
   - Initializes the Chrono environment and sets the data path.
   - Creates an Irrlicht visualization app, sets window size, adds a camera, and a light source.

2. **Particle Emitter:**
   - Defines a custom `ParticleEmitter` class that inherits from `chrono.ChBody`.
   - `__init__`: Initializes particle count, emission rate, system, and an empty particle list.
   - `EmitParticle`: Generates random particle properties (shape, mass, position, velocity, orientation) and creates a `chrono.ChBody` instance.
     - The shape, mass, and other properties can be customized.
   - `Update`: Emits a new particle if the particle count is below the target.

3. **Custom Gravitational Forces:**
   - Defines a `apply_gravitational_force` function that calculates the gravitational force between two particles based on their distance.
   - You can modify the force calculation to adjust the strength and behavior of the attraction.

4. **Simulation Loop:**
   - Enters a loop that runs until the window is closed.
   - `app.BeginScene()`: Starts the rendering frame.
   - `system.DoStepDynamics(chrono.ChTime(0.01))`: Advances the simulation by 0.01 seconds.
   - Iterates through the particle list and applies gravitational forces between each pair of particles using `apply_gravitational_force`.
   - `app.DrawAll()`: Renders the simulation scene.
   - `app.EndScene()`: Ends the rendering frame.

5. **Cleanup:**
   - `app.GetDevice().run()`: Starts the Irrlicht event loop.



**Remember:**

- Replace `"path/to/your/chrono/data"` with the actual path to your Chrono data directory.
- Customize the particle properties (shape, mass, velocity, etc.) and the gravitational force calculation to achieve the desired simulation behavior.
- You can add more complex interactions, such as collisions, to the simulation.
