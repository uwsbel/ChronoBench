```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht

# Initialize Chrono environment
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Create the IGA beam
beam_material = chrono.ChMaterialSurfaceNSC()
beam_material.SetFriction(0.5, 0.5)  # Adjust friction as needed
beam_material.SetDamping(0.1)  # Adjust damping as needed

beam = chrono.ChBeamIGA(
    num_nodes=10,  # Adjust number of nodes for beam refinement
    cross_section_type=chrono.ChBeamIGA.CrossSectionType.RECTANGLE,
    cross_section_params=[0.1, 0.01],  # Adjust dimensions
    material=beam_material,
)

# Attach the flywheel to the beam
flywheel_radius = 0.05  # Adjust flywheel radius
flywheel_mass = 1.0  # Adjust flywheel mass
flywheel = chrono.ChBodyEasyCylinder(flywheel_radius, flywheel_mass)
flywheel.SetPos(chrono.ChVectorD(0, 0, 0.05))  # Adjust position

beam.AddBody(flywheel)

# Create the rotational motor
motor = chrono.ChMotorRotation(
    beam, flywheel,
    axis=[0, 1, 0],  # Motor axis aligned with beam
    mode=chrono.ChMotorRotation.Mode.ROT_SPEED,
    speed=10.0,  # Adjust motor speed
)

# Add the beam and motor to the system
system.Add(beam)
system.Add(motor)

# Visual setup
vis = irrlicht.ChIrrApp(system, "Jeffcott Rotor Simulation")
vis.AddTypicalLights()
vis.AddCamera(
    pos=chrono.ChVectorD(1, 1, 1),
    lookat=chrono.ChVectorD(0, 0, 0),
)

# Enable FEM visualization
beam.EnableFEMVisualization(vis.GetRenderSystem())

# Run the simulation
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))  # Set gravity
vis.Start()

while vis.GetDevice().run():
    system.DoStepDynamics(0.01)
    vis.Render()

vis.GetDevice().drop()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules (`pychrono` and `pychrono.irrlicht`).
   - Initializes the Chrono environment using `chrono.ChSystemNSC()`.
   - Sets the path to Chrono data files using `chrono.SetChronoDataPath()`.

2. **IGA Beam Creation:**
   - Creates an IGA beam object using `chrono.ChBeamIGA()`.
   - Specifies the number of nodes (`num_nodes`) for beam refinement.
   - Sets the cross-section type and dimensions (`cross_section_type`, `cross_section_params`).
   - Defines the material properties of the beam using `chrono.ChMaterialSurfaceNSC()`.

3. **Flywheel Attachment:**
   - Creates a flywheel object using `chrono.ChBodyEasyCylinder()`.
   - Sets the flywheel's radius and mass.
   - Positions the flywheel at the center of the beam using `beam.SetPos()`.

4. **Rotational Motor:**
   - Creates a rotational motor object using `chrono.ChMotorRotation()`.
   - Specifies the motor axis, mode (rotational speed), and speed.
   - Attaches the motor to the beam and flywheel.

5. **System Setup:**
   - Adds the beam, flywheel, and motor to the Chrono system using `system.Add()`.
   - Sets the gravitational acceleration using `system.Set_G_acc()`.

6. **Visual Setup:**
   - Creates an Irrlicht visualization window using `chrono.ChIrrApp()`.
   - Adds typical lights and a camera to the scene.
   - Enables FEM visualization for the beam using `beam.EnableFEMVisualization()`.

7. **Simulation Loop:**
   - Runs the simulation in a loop using `vis.GetDevice().run()`.
   - Updates the system dynamics using `system.DoStepDynamics()`.
   - Renders the scene using `vis.Render()`.



**Important Notes:**

- Replace `"path/to/chrono/data"` with the actual path to your Chrono data files.
- Adjust parameters like `num_nodes`, `cross_section_params`, `flywheel_radius`, `flywheel_mass`, `motor_speed`, and friction coefficients to fine-tune the simulation.
- The simulation will visualize the beam's deformation and the rotation of the flywheel.
