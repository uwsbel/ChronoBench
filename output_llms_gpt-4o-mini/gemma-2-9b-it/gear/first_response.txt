```python
import pychrono as chrono
import pychrono.irrlicht as vis

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("./")  # Set path to Chrono data files
system = chrono.ChSystemNSC()
vis.ChVisualSystemIrrlicht.Create(
    "Epicyclic Gears Simulation",
    width=800,
    height=600,
    vSync=True,
    backgroundColor=[0.8, 0.8, 0.8],
)
vis.AddCamera(
    pos=[5, 5, 5],
    target=[0, 0, 0],
    up=[0, 0, 1],
)

# 2. Add physical systems and objects
# Fixed Truss
truss = chrono.ChBodyEasyBox(1.0, 0.5, 0.2, 100)
truss.SetPos(chrono.ChVectorD(0, 0, 0))
system.AddBody(truss)

# Rotating Bar
bar = chrono.ChBodyEasyCylinder(0.1, 0.5, 10)
bar.SetPos(chrono.ChVectorD(0, 0, 0.2))
bar.SetRot(chrono.Q_from_Euler(chrono.rad2deg(90), 0, 0))
bar.SetBodyFixed(False)
system.AddBody(bar)

# Gears
gear1 = chrono.ChBodyEasyCylinder(0.1, 0.1, 10)
gear1.SetPos(chrono.ChVectorD(0.2, 0, 0.3))
gear1.SetRot(chrono.Q_from_Euler(chrono.rad2deg(90), 0, 0))
system.AddBody(gear1)

gear2 = chrono.ChBodyEasyCylinder(0.1, 0.1, 10)
gear2.SetPos(chrono.ChVectorD(0.4, 0, 0.3))
gear2.SetRot(chrono.Q_from_Euler(chrono.rad2deg(90), 0, 0))
system.AddBody(gear2)

# Gear Motor
motor = chrono.ChMotorRotation(
    gear1,
    chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.Q_from_Euler(0, 0, 0)),
    chrono.ChVectorD(0, 0, 1),
    chrono.ChVectorD(0, 0, 1),
    100,  # constant rotation speed
)
system.AddMotor(motor)

# 3. Set necessary default parameters

# Define materials and apply to objects
mat_metal = chrono.ChMaterialSurfaceNSC()
mat_metal.SetFriction(0.5)
mat_metal.SetRestitution(0.2)
truss.SetMaterial(mat_metal)
bar.SetMaterial(mat_metal)
gear1.SetMaterial(mat_metal)
gear2.SetMaterial(mat_metal)

# Define lighting
vis.GetActiveCamera().SetLight(vis.GetActiveCamera().GetLight(0))
vis.GetActiveCamera().GetLight(0).SetDiffuseColor(chrono.ChColor(1, 1, 1))

# Simulation setup
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))
system.Set_Speed_limit(1000)
system.Set_Time_step(0.01)

# Run simulation
vis.Start()
while vis.GetActiveCamera().IsRunning():
    system.DoStepDynamics()
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules (`pychrono` and `pychrono.irrlicht`).
   - Sets the Chrono data path.
   - Creates a Chrono system (`chrono.ChSystemNSC()`) and an Irrlicht visualization system (`vis.ChVisualSystemIrrlicht`).
   - Adds a camera to the visualization system for viewing the simulation.

2. **Object Creation:**
   - **Fixed Truss:** A box-shaped body (`chrono.ChBodyEasyBox`) representing the fixed truss is created and positioned at the origin.
   - **Rotating Bar:** A cylinder-shaped body (`chrono.ChBodyEasyCylinder`) representing the rotating bar is created and positioned above the truss. It's set to rotate around its Z-axis.
   - **Gears:** Two cylinder-shaped bodies (`chrono.ChBodyEasyCylinder`) represent the epicyclic gears and are positioned relative to the rotating bar.

3. **Gear Motor:**
   - A rotation motor (`chrono.ChMotorRotation`) is attached to one of the gears to enforce a constant rotation speed.

4. **Material and Lighting:**
   - A basic metal material (`chrono.ChMaterialSurfaceNSC`) is defined and applied to all objects.
   - Basic lighting is set up for the visualization system.

5. **Simulation Setup:**
   - Gravity is set (`system.Set_G_acc()`).
   - A speed limit is set (`system.Set_Speed_limit()`).
   - The time step for the simulation is defined (`system.Set_Time_step()`).

6. **Simulation Loop:**
   - The `vis.Start()` function starts the Irrlicht visualization loop.
   - Inside the loop:
     - `system.DoStepDynamics()` performs a single step of the simulation.
     - `vis.Render()` renders the current state of the simulation.



Remember to adjust parameters like gear sizes, motor speed, and material properties to achieve the desired epicyclic gear behavior.
