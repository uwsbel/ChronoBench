```python
import pychrono as chrono
import pychrono.irrlicht as vis
import numpy as np

# Initialize Chrono environment
chrono.SetChronoDataPath("..")  # Set the path to Chrono data files
system = chrono.ChSystemNSC()

# Create ground body
ground = chrono.ChBodyEasyBox(10, 10, 1, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(ground)

# Create pendulum body
pendulum_mass = 1.0
pendulum_length = 1.0
pendulum_body = chrono.ChBodyEasySphere(pendulum_mass, 0.1)
pendulum_body.SetPos(chrono.ChVectorD(0, pendulum_length, 0))
pendulum_body.SetBodyFixed(False)  # Allow rotation
system.Add(pendulum_body)

# Create revolute joint
joint = chrono.ChLinkLockRevolute(ground, pendulum_body,
                                  chrono.ChVectorD(0, 0, 0),
                                  chrono.ChVectorD(0, 0, 1))
system.Add(joint)

# Visualization setup
vis.Init(chrono.ChVectorD(800, 600), "PyChrono Pendulum")
vis.Add(ground)
vis.Add(pendulum_body)

# Simulation parameters
dt = 0.01
steps = 1000

# Logging variables
pendulum_positions = []
pendulum_velocities = []

# Simulation loop
for i in range(steps):
    system.DoStepDynamics(dt)

    # Log pendulum position and velocity
    pendulum_positions.append(pendulum_body.GetPos().y)
    pendulum_velocities.append(pendulum_body.GetRot().GetV())

    # Update visualization
    vis.Render()

# Cleanup
vis.Close()

# Print or plot the logged data
print("Pendulum Positions:", pendulum_positions)
print("Pendulum Velocities:", pendulum_velocities)

# You can further process and plot the data as needed.
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries: `pychrono` for physics simulation and `pychrono.irrlicht` for visualization.
   - Initializes the Chrono environment and creates a new system.

2. **Ground Body:**
   - Creates a rectangular ground body using `ChBodyEasyBox` with specified dimensions and mass.
   - Sets its position at the origin (0, 0, 0) and adds it to the system.

3. **Pendulum Body:**
   - Creates a spherical pendulum body using `ChBodyEasySphere` with given mass and radius.
   - Sets its initial position at a distance `pendulum_length` above the ground and allows it to rotate.
   - Adds it to the system.

4. **Revolute Joint:**
   - Creates a revolute joint using `ChLinkLockRevolute` connecting the ground and pendulum bodies.
   - Specifies the joint's axis of rotation (pointing upwards) and adds it to the system.

5. **Visualization:**
   - Initializes Irrlicht visualization using `vis.Init`.
   - Adds the ground and pendulum bodies to the visualization scene.

6. **Simulation Parameters:**
   - Sets the time step (`dt`) for the simulation and the number of simulation steps (`steps`).

7. **Logging Variables:**
   - Creates lists to store the pendulum's position and velocity data during the simulation.

8. **Simulation Loop:**
   - Iterates for the specified number of steps.
   - Calls `system.DoStepDynamics(dt)` to advance the simulation by one time step.
   - Logs the pendulum's position (y-coordinate) and velocity (angular velocity) at each step.
   - Updates the visualization using `vis.Render()`.

9. **Cleanup:**
   - Closes the Irrlicht visualization window using `vis.Close()`.

10. **Data Output:**
    - Prints the logged pendulum positions and velocities to the console.
