```python
import pychrono as chrono
import pychrono.irrlicht as irr
import pychrono.irrlicht.irrlicht_utils as irr_utils

# Initialize PyChrono
chrono.init()

# Create the Irrlicht environment
irr_env = irr.IrrlichtEnvironment("MyWindow")

# Create the RigidTerrain
terrain_dimensions = (10, 10)  # Define terrain dimensions
terrain = chrono.RigidTerrain(
    chrono.Vector3(0, 0, 0),  # Initial position
    chrono.Vector3(terrain_dimensions[0], terrain_dimensions[1], 0),  # Dimensions
    chrono.Vector3(0, 0, 0),  # Initial orientation
    chrono.Vector3(0, 0, 0),  # Initial velocity
    chrono.Vector3(0, 0, 0),  # Initial angular velocity
    chrono.Vector3(0, 0, 0),  # Initial momentum
    chrono.Vector3(0, 0, 0),  # Initial inertia tensor
    chrono.Vector3(0, 0, 0),  # Initial mass
)
terrain.set_material("grass", irr_utils.IrrlichtMaterial(irr_env))  # Set custom texture
terrain.set_collision_type(chrono.CollisionType.STATIC)

# Create the ARTcar vehicle
car = chrono.ARTcar(
    chrono.Vector3(0, 0, 0),  # Initial position
    chrono.Vector3(0, 0, 0),  # Initial orientation
    chrono.Vector3(0, 0, 0),  # Initial velocity
    chrono.Vector3(0, 0, 0),  # Initial angular velocity
    chrono.Vector3(0, 0, 0),  # Initial momentum
    chrono.Vector3(0, 0, 0),  # Initial inertia tensor
    chrono.Vector3(0, 0, 0),  # Initial mass
)
car.set_contact_method(chrono.ContactMethod.CONTACT_METHOD_PLANE)  # Set contact method
car.set_visualization_type(chrono.VisualizationType.VISUALIZATION_TYPE_MESH)  # Set visualization type

# Initialize the simulation loop
chrono.simulation_loop(
    50,  # Frames per second
    chrono.TimeStep(0.01),  # Time step
    chrono.SimulationMode.REAL_TIME,  # Simulation mode
)

# Add the vehicle to the scene
irr_env.add_object(car)
irr_env.add_object(terrain)

# Run the simulation
irr_env.run()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries (pychrono, irrlicht).
   - Initializes PyChrono using `chrono.init()`.
   - Creates an Irrlicht environment using `irr.IrrlichtEnvironment("MyWindow")`.

2. **Terrain:**
   - Creates a `RigidTerrain` object with dimensions, position, and orientation.
   - Sets a custom texture using `irr_utils.IrrlichtMaterial`.
   - Sets the collision type to `STATIC`.

3. **Vehicle:**
   - Creates an `ARTcar` object with initial position, orientation, velocity, and angular velocity.
   - Sets the contact method to `CONTACT_METHOD_PLANE`.
   - Sets the visualization type to `VISUALIZATION_TYPE_MESH`.

4. **Simulation Loop:**
   - Sets the simulation loop to run at 50 frames per second.
   - Uses a `TimeStep` of 0.01 for time integration.
   - Sets the simulation mode to `REAL_TIME` for real-time updates.

5. **Adding Objects:**
   - Adds the vehicle and terrain to the Irrlicht environment using `irr_env.add_object()`.

6. **Running the Simulation:**
   - Starts the Irrlicht environment using `irr_env.run()`.

**Note:**

- You need to install the necessary libraries (pychrono, irrlicht, and pychrono.irrlicht).
- The `irr_utils` module provides functions for Irrlicht materials and other visualizations.
- You can customize the vehicle's parameters, terrain properties, and simulation settings to suit your needs.
