```python
import pychrono as chrono
import pychrono.ros as ros
import rospy
import time

# Initialize PyChrono
chrono.init()

# Create Chrono system
system = chrono.System()
world = chrono.World()
world.addSystem(system)

# Define gravitational acceleration
g = chrono.Vector3D(0, -9.81, 0)

# Define material properties
material_density = 1000.0
material_elasticity = 1.0

# Add floor
floor = chrono.RigidBody(chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 0), 
                         chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 0), 
                         chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 0), material_density, material_elasticity)
world.addBody(floor)

# Add box
box = chrono.RigidBody(chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 0), 
                         chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 0), 
                         chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 0), material_density, material_elasticity)
world.addBody(box)

# Set initial positions and velocities
box.setPosition(chrono.Vector3D(1, 0, 0))
box.setVelocity(chrono.Vector3D(0, 1, 0))

# Define ROS handler
class BoxROSHandler(ros.ROSHandler):
    def __init__(self, topic):
        super().__init__()
        self.topic = topic
        self.timer = None

    def handle_update(self, dt):
        # Publish ROS message here
        message = "Box position: " + str(box.getPosition())
        self.publish_message(message)

# Configure ROS manager
ros_manager = ros.ROSManager(world)
ros_manager.clock = ros.Clock()
ros_manager.body = ros.Body()
ros_manager.transform = ros.Transform()

# Register ROS handler
ros_manager.register_handler(BoxROSHandler("box_position_topic"))

# Run simulation loop
while True:
    # Advance simulation
    world.step(dt)

    # Update ROS communication
    ros_manager.update()

    # Sleep for a short duration
    time.sleep(0.01)
```


**Explanation:**

1. **Initialization:**
   - Imports necessary libraries: `pychrono`, `pychrono.ros`, `rospy`, and `time`.
   - Initializes PyChrono with `chrono.init()`.

2. **Chrono System and World:**
   - Creates a `chrono.System` object for the simulation.
   - Creates a `chrono.World` object to hold the system and its bodies.

3. **Gravitational Acceleration:**
   - Defines the gravitational acceleration vector `g`.

4. **Material Properties:**
   - Sets the density and elasticity of the material.

5. **Floor:**
   - Creates a `chrono.RigidBody` representing the floor.
   - Sets its initial position, velocity, and material properties.
   - Adds the floor to the world.

6. **Box:**
   - Creates a `chrono.RigidBody` representing the movable box.
   - Sets its initial position, velocity, and material properties.
   - Adds the box to the world.

7. **Initial Positions and Velocities:**
   - Sets the initial position and velocity of the box.

8. **ROS Handler:**
   - Defines a custom ROS handler class `BoxROSHandler` that handles publishing messages to the specified ROS topic.
   - The `handle_update` method is called at each timestep to publish the current box position.

9. **ROS Manager:**
   - Creates a `ros.ROSManager` object to handle ROS communication.
   - Configures the clock, body, and transform handlers.
   - Registers the `BoxROSHandler` with the ROS manager.

10. **Simulation Loop:**
   - Enters an infinite loop to run the simulation.
   - Advances the simulation using `world.step(dt)`, where `dt` is the timestep size.
   - Updates ROS communication using `ros_manager.update()`.
   - Sleeps for a short duration (`time.sleep(0.01)`) to control the simulation speed.

**To run this script:**

1. Make sure you have PyChrono and ROS installed.
2. Save the code as a Python file (e.g., `simulation.py`).
3. Run the script from your terminal using `python simulation.py`.

This script provides a basic framework for integrating PyChrono with ROS. You can customize the simulation by adding more bodies, changing the material properties, and modifying the ROS handler logic.
