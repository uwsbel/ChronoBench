```python
# Import necessary libraries
from pychrono import Chrono, Vehicle, Terrain, RigidBody, Contact, Driver, Irrlicht
from pychrono.irrlicht import IrrlichtEngine, IrrlichtCamera, IrrlichtLight

# Initialize PyChrono
chrono = Chrono()

# Create a terrain
terrain = Terrain(chrono, 
                 position=(0, 0, 0), 
                 size=(10, 10, 10), 
                 friction=0.2, 
                 restitution=0.5)

# Create an M113 vehicle
vehicle = Vehicle(chrono, 
                 position=(0, 0, 1), 
                 size=(4, 2, 1), 
                 mass=1000, 
                 rotation=(0, 0, 0))

# Add a driver system
driver = Driver(chrono, 
                vehicle, 
                control_mode="manual", 
                acceleration=10, 
                steering_angle=0)

# Initialize Irrlicht
engine = IrrlichtEngine()
camera = IrrlichtCamera(engine)
light = IrrlichtLight(engine)

# Set Irrlicht visualization settings
engine.set_camera(camera)
engine.set_light(light)
engine.set_view_angle(45)
engine.set_projection_type(Irrlicht.PROJECTION_ORTHO)
engine.set_lighting_mode(Irrlicht.LIGHTING_DIRECTIONAL)

# Set the simulation loop
while True:
    # Update the simulation
    chrono.update()

    # Advance the driver system
    driver.update()

    # Advance the vehicle
    vehicle.update()

    # Advance the terrain
    terrain.update()

    # Render the visualization
    engine.render()

    # Wait for the next timestep
    engine.poll_events()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries from `pychrono` and `pychrono.irrlicht`.
   - Initializes the PyChrono environment with `Chrono()`.
   - Creates a `Terrain` object with specified size, friction, and restitution.
   - Creates an `M113` vehicle with specified position, size, mass, and rotation.
   - Creates a `Driver` object with the vehicle and control mode set to "manual".

2. **Irrlicht Setup:**
   - Initializes an `IrrlichtEngine` for visualization.
   - Creates an `IrrlichtCamera` and an `IrrlichtLight` for rendering.
   - Sets camera and lighting parameters.

3. **Simulation Loop:**
   - Enters an infinite loop to simulate the system.
   - Inside the loop:
     - Calls `chrono.update()` to update the simulation.
     - Calls `driver.update()` to update the driver's actions.
     - Calls `vehicle.update()` to update the vehicle's position and velocity.
     - Calls `terrain.update()` to update the terrain's state.
     - Calls `engine.render()` to render the visualization.
     - Calls `engine.poll_events()` to handle user input and other events.

**Key Points:**

- This script provides a basic framework for a PyChrono simulation.
- You can customize the vehicle, terrain, driver, and visualization settings according to your specific requirements.
- The simulation loop is a simplified example; you can add more complex logic for collision detection, physics, and other interactions.
- You'll need to install the necessary libraries (`pychrono`, `irrlicht`) and configure the Irrlicht engine.
