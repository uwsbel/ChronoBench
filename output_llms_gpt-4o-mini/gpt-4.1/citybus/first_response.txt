Certainly! Below is a **PyChrono** simulation script that sets up a CityBus vehicle on a rigid terrain, uses Irrlicht for visualization, applies mixed visualization types, and implements an interactive driver. The simulation runs at 50 FPS, updating vehicle dynamics and rendering in real time.

**Requirements:**  
- `pychrono` and `pychrono_vehicle` must be installed.
- Place a suitable texture image (e.g., `"../data/vehicle/terrain/textures/tile4.jpg"`) in the specified path or update the path as needed.

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr
import math

# 1. Initialize PyChrono
chrono.SetChronoDataPath(chrono.GetChronoDataPath())
veh.SetDataPath(veh.GetDataPath())

# 2. Create the physical system
system = chrono.ChSystemNSC()

# 3. Create the vehicle (CityBus)
initLoc = chrono.ChVectorD(0, 0, 1.0)  # x, y, z
initYaw = chrono.ChQuaternionD(1, 0, 0, 0)  # No rotation
tire_type = veh.TireModelType.TMEASY

citybus = veh.CityBus(system)
citybus.SetContactMethod(chrono.ChContactMethod_NSC)
citybus.SetChassisVisualizationType(veh.VisualizationType.MESH)
citybus.SetSuspensionVisualizationType(veh.VisualizationType.PRIMITIVES)
citybus.SetSteeringVisualizationType(veh.VisualizationType.PRIMITIVES)
citybus.SetWheelVisualizationType(veh.VisualizationType.MESH)
citybus.SetTireType(tire_type)
citybus.SetTireVisualizationType(veh.VisualizationType.PRIMITIVES)
citybus.Initialize(chrono.ChCoordsysD(initLoc, initYaw))

# 4. Create the terrain
terrain = veh.RigidTerrain(system)
patch = terrain.AddPatch(
    chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.QUNIT),
    200.0, 100.0  # size_x, size_y
)
patch.SetContactFrictionCoefficient(0.9)
patch.SetRestitutionCoefficient(0.01)
patch.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
patch.SetTexture(veh.GetDataFile("terrain/textures/tile4.jpg"), 200, 100)
terrain.Initialize()

# 5. Create the Irrlicht application
app = veh.ChWheeledVehicleIrrApp(citybus, "PyChrono CityBus Demo", irr.dimension2du(1024, 768))
app.SetSkyBox()
app.AddTypicalLights()
app.AddLightWithShadow(chrono.ChVectorD(60, 100, 120), chrono.ChVectorD(0, 0, 0), 160, 1, 40, 512)
app.SetChaseCamera(chrono.ChVectorD(0.0, 0.0, 1.75), 6.0, 0.5)  # (track point, distance, height)
app.SetTimestep(0.02)  # 50 FPS

# 6. Create the interactive driver
driver = veh.ChIrrGuiDriver(app)
driver.SetSteeringDelta(0.04)
driver.SetThrottleDelta(0.02)
driver.SetBrakingDelta(0.1)
driver.Initialize()

# 7. Simulation loop
step_size = 0.02  # 50 FPS
render_steps = 1

while app.GetDevice().run():
    time = system.GetChTime()

    # Collect driver inputs
    driver_inputs = driver.GetInputs()

    # Update modules
    driver.Synchronize(time)
    terrain.Synchronize(time)
    citybus.Synchronize(time, driver_inputs, terrain)
    app.Synchronize("CityBus Demo", driver_inputs)

    # Advance simulation
    driver.Advance(step_size)
    terrain.Advance(step_size)
    citybus.Advance(step_size)

    # Render scene
    if app.GetDevice().run():
        app.BeginScene()
        app.DrawAll()
        app.EndScene()

    # Step system
    system.DoStepDynamics(step_size)

    # Optional: break after some time
    # if time > 60:
    #     break
```

---

**Key Features:**
- **CityBus vehicle** with mesh and primitive visualization for different parts.
- **RigidTerrain** with a custom texture.
- **Irrlicht visualization** with a chase camera.
- **Interactive driver** for steering, throttle, and braking.
- **Real-time simulation** at 50 FPS.

**Controls:**  
- Arrow keys or `WASD` for steering/throttle/brake (see Irrlicht driver documentation for details).

**Note:**  
- Adjust the texture path if needed.
- You can set a simulation time limit by uncommenting the break condition.
