```python
import pychrono as chrono
import pychrono.vehicle as vehicle
import pychrono.irrlicht as irrlicht

# 1. Initialize the PyChrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# 2. Create the ARTcar vehicle
artcar = vehicle.ARTcar(system)
artcar.Initialize(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0.5), chrono.QUNIT))
artcar.SetChassisVisualizationType(vehicle.VisualizationType_MESH)
artcar.SetWheelVisualizationType(vehicle.VisualizationType_MESH)

# 3. Create the RigidTerrain
terrain = vehicle.RigidTerrain(system)
terrain.SetPlane(chrono.ChPlane(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1)))
terrain.SetSize(chrono.ChVectorD(100, 100, 10))
terrain.SetTexture(chrono.GetChronoDataFile("terrain/textures/grass.jpg"))

# 4. Set up Irrlicht visualization
app = vehicle.ChVehicleIrrApp(artcar, terrain, 'ARTcar Simulation')
app.SetWindowSize(1024, 768)
app.SetWindowTitle('ARTcar Simulation')
app.SetChaseCamera(chrono.ChVectorD(0, -5, 2), 6.0, 0.5)
app.AssetBindAll()
app.AssetUpdateAll()

# 5. Create interactive driver system
driver = vehicle.ChIrrGuiDriver(app)
driver.SetSteeringDelta(0.05)
driver.SetThrottleDelta(0.05)
driver.SetBrakingDelta(0.05)

# 6. Simulation loop parameters
step_size = 0.02  # 50 FPS
simulation_time = 0

# Main simulation loop
while app.GetDevice().run():
    # Update driver inputs
    driver_inputs = driver.GetInputs()
    
    # Update vehicle dynamics
    artcar.Synchronize(simulation_time, driver_inputs, terrain)
    system.DoStepDynamics(step_size)
    simulation_time += step_size

    # Update visualization
    app.BeginScene()
    app.DrawAll()
    app.EndScene()
```

### Explanation:

1. **System Initialization**:
   - Creates a Chrono system with non-smooth contact (NSC) solver.
   - Sets gravitational acceleration to -9.81 m/s² in the Z-direction.

2. **Vehicle Setup**:
   - Instantiates an ARTcar vehicle at position (0, 0, 0.5) with no initial rotation.
   - Uses mesh-based visualization for both chassis and wheels.

3. **Terrain Creation**:
   - Creates a flat rigid terrain with dimensions 100x100x10 units.
   - Applies a grass texture from Chrono's data directory.

4. **Visualization**:
   - Uses `ChVehicleIrrApp` for vehicle-specific visualization.
   - Sets up a chase camera for following the vehicle.
   - Binds and updates all visualization assets.

5. **Driver System**:
   - Creates an Irrlicht-based GUI driver with customizable input sensitivity.
   - Allows control over steering, throttle, and braking through keyboard inputs.

6. **Simulation Loop**:
   - Runs at 50 FPS with a fixed time step of 0.02 seconds.
   - Updates vehicle dynamics using the driver's inputs.
   - Synchronizes visualization with physics updates.

### Notes:
- The simulation uses Chrono's built-in data files for textures.
- The vehicle will respond to user input from the Irrlicht window.
- The simulation runs indefinitely until the user closes the window.
- The ARTcar model includes its own tire models and contact mechanics.
