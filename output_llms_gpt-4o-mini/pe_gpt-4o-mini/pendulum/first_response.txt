Here's a complete simulation script for a simple pendulum using the PyChrono library with Irrlicht for visualization. This script initializes the PyChrono environment, sets up the required physical systems and objects, and logs the pendulum's position and velocity periodically.

```python
import os
import math
import numpy as np
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr

# Initialize the PyChrono environment
chrono.SetChronoDataPath('/path/to/data')  # Set to your Chrono data path
sys = chrono.ChSystemNSC()

# Create ground body
ground = chrono.ChBody()
ground.SetMass(0)  # Ground has infinite mass
ground.SetCollide(False)  # No collision for ground
ground.SetFixed(True)  # Ground is fixed in space
sys.Add(ground)

# Create the pendulum body
pendulum_length = 2.0  # Length of the pendulum
pendulum_mass = 1.0  # Mass of the pendulum
pendulum = chrono.ChBodyEasyBox(0.1, 0.1, pendulum_length, pendulum_mass, True, True)
pendulum.SetPos(chrono.ChVector3d(0, -pendulum_length / 2, 0))  # Set initial position
pendulum.SetInertiaXX(chrono.ChVector3d(0.01, 0.01, 0.1))  # Set inertia
sys.Add(pendulum)

# Create a revolute joint to connect the pendulum to the ground
rev_joint = chrono.ChLinkLockRevolute()
rev_joint.Initialize(ground, pendulum, chrono.ChCoordsysD(chrono.ChVector3d(0, 0, 0), chrono.ChQuaternionD(1, 0, 0, 0)))
sys.Add(rev_joint)

# Set up the visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Simple Pendulum Simulation')
vis.Initialize()
vis.AddCamera(chrono.ChVector3d(0, 2, 5))
vis.AddTypicalLights()
vis.AddSkyBox()

# Simulation loop
time_step = 0.01  # Time step for simulation
while vis.Run():
    # Perform a simulation step
    sys.DoStepDynamics(time_step)

    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Log pendulum position and velocity
    pendulum_pos = pendulum.GetPos()
    pendulum_vel = pendulum.GetPos_dt()
    print(f"Pendulum Position: {pendulum_pos}, Velocity: {pendulum_vel}")

# Cleanup and exit
vis.Drop();
```

### Explanation of the Code:
1. **Initialization**: The code starts by importing the necessary libraries and initializing the PyChrono environment. It sets the path to the Chrono data directory.

2. **Ground Body**: A ground body is created and fixed in space, meaning it will not move during the simulation.

3. **Pendulum Body**: A pendulum body is created using a box shape to represent the pendulum. It is assigned a mass and inertia properties and positioned appropriately.

4. **Revolute Joint**: A revolute joint is established between the ground and the pendulum, allowing the pendulum to swing.

5. **Visualization System**: The visualization system is set up using the Irrlicht engine, with a window size and title defined. A camera is positioned to view the pendulum.

6. **Simulation Loop**: The main loop runs the simulation, updating the system dynamics and rendering the scene. It also logs the pendulum's position and velocity at each time step.

7. **Cleanup**: After exiting the loop, the visualization system is dropped to free resources.

Make sure to adjust the `chrono.SetChronoDataPath('/path/to/data')` line to point to the correct data path for your Chrono installation.
