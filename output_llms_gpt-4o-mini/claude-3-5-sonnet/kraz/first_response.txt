Here's a PyChrono script that implements the simulation as per your instructions:

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr
import math

# Initialize the ChronoEngine and vehicle components
chrono.SetChronoDataPath("path/to/chrono/data/")
veh.SetDataPath("path/to/vehicle/data/")

# Create the simulation system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the terrain
terrain = veh.RigidTerrain(system)
patch_mat = chrono.ChMaterialSurfaceNSC()
patch_mat.SetFriction(0.9)
patch_mat.SetRestitution(0.01)
terrain_patch = terrain.AddPatch(patch_mat, 
                                 chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.QUNIT),
                                 100, 100)
terrain.Initialize()

# Create the vehicle
vehicle = veh.Kraz(system, veh.ChContactMethod_NSC)
vehicle.Initialize(chrono.ChCoordsysD(chrono.ChVectorD(0, 0.5, 0), chrono.QUNIT))
vehicle.SetChassisVisualizationType(veh.VisualizationType_MESH)
vehicle.SetSuspensionVisualizationType(veh.VisualizationType_PRIMITIVES)
vehicle.SetSteeringVisualizationType(veh.VisualizationType_PRIMITIVES)
vehicle.SetWheelVisualizationType(veh.VisualizationType_MESH)

# Create and initialize the powertrain
powertrain = veh.SimplePowertrain()
vehicle.InitializePowertrain(powertrain)

# Create the driver system
driver = veh.ChIrrGuiDriver(vehicle.GetVehicle())
driver.Initialize()

# Create the vehicle Irrlicht interface
vis = veh.ChWheeledVehicleIrrApp(vehicle.GetVehicle())

vis.SetHUDLocation(500, 20)
vis.SetSkyBox()
vis.AddTypicalLogo()
vis.AddTypicalLights(irr.vector3df(30, 100, 30), irr.vector3df(30, 100, 50), 250, 130)
vis.AddTypicalLights(irr.vector3df(-30, 100, 30), irr.vector3df(-30, 100, 50), 250, 130)
vis.AddTypicalCamera(irr.vector3df(0, 3, -6), irr.vector3df(0, 0, 0))

vis.AttachVehicle(vehicle.GetVehicle())

# Simulation parameters
step_size = 1e-3
render_step_size = 1.0 / 50
sim_time = 0

# Simulation loop
while vis.GetDevice().run():
    # Synchronize vehicle, terrain, and other systems
    time = vehicle.GetSystem().GetChTime()
    driver.Synchronize(time)
    vehicle.Synchronize(time, driver.GetInputs(), terrain)
    terrain.Synchronize(time)
    vis.Synchronize(driver.GetInputs(), time)

    # Advance simulation for one timestep
    vehicle.Advance(step_size)
    terrain.Advance(step_size)
    vis.Advance(step_size)

    # Increment simulation time
    sim_time += step_size

    # Render scene
    if sim_time >= render_step_size:
        vis.BeginScene()
        vis.Render()
        vis.EndScene()
        sim_time = 0

    # Allow real-time execution
    vis.Sync(step_size)

# Clean up
vis.GetDevice().drop()
```

This script does the following:

1. Initializes the PyChrono environment and core components.
2. Sets up a rigid terrain with specified friction and restitution.
3. Creates a Kraz vehicle with initial conditions and visualization settings.
4. Initializes a driver system for vehicle control.
5. Sets up real-time visualization using Irrlicht with camera settings and lighting.
6. Implements a simulation loop that:
   - Synchronizes the vehicle, terrain, driver, and visual system.
   - Advances the simulation by one timestep.
   - Renders the scene at specified intervals.
   - Maintains real-time execution.

Note that you'll need to replace "path/to/chrono/data/" and "path/to/vehicle/data/" with the actual paths to your Chrono data directories.

This script provides a basic framework for the simulation. You may need to adjust parameters, add more detailed vehicle configurations, or include additional features depending on your specific requirements.
