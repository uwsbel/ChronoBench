Certainly! Below is a PyChrono script that fulfills the requirements specified for simulating a CityBus vehicle on a rigid terrain with visualization using Irrlicht. This script initializes the environment, sets up the vehicle with specified parameters, and includes an interactive driver system for controlling the vehicle.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import pychrono.vehicle.wheeled_vehicle as veh_wheeled

# --------------------------
# Initialize the simulation
# --------------------------
chrono.SetChronoDataPath('path/to/chrono/data')

# Create a Chrono::Engine physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle('CityBus Simulation')
vis.Initialize()
vis.AddTypicalSky()
vis.AddTypicalLogo(chrono.GetChronoDataFile('logo_pychrono_rgb.png'))
vis.AddLightWithShadow(chrono.ChCoordsysD(chrono.ChVectorD(2, 4, 5), chrono.Q_UNIT),  # position
                       chrono.ChVectorD(1, 1, 1),  # direction
                       5, 5, 20, 40, 50,  # near, far, angle, resolution_x, resolution_y
                       chrono.ChColor(1, 1, 1))  # color

# --------------------------
# Create the rigid terrain
# --------------------------
terrain = veh_wheeled.ChTerrain()
terrain.SetContactMaterial(0.8, 0.8, 0.01)
terrain.Initialize(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(100, 100, 0), 1, 1)
terrain.GetGroundSurface().LoadTexture(chrono.GetChronoDataFile('textures/concrete.jpg'))

# Add the terrain to the system
system.Add(terrain)

# --------------------------
# Create the CityBus vehicle
# --------------------------
citybus = veh_wheeled.ChVehicleCityBus()
citybus.InitSystem(system, veh_wheeled.ChVehicleCityBus.VEHICLE_2AXLES)
citybus.SetChassisBodyVisualizationType(veh_wheeled.ChVehicleCityBus.VISUALIZATION_MESH)
citybus.SetChassisBodyMeshFilename(chrono.GetChronoDataFile('vehicle/citybus/chassis_geom.obj'))
citybus.SetChassisBodyTextureFilename(chrono.GetChronoDataFile('vehicle/citybus/chassis_texture.png'))
citybus.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0.5), chrono.Q_from_AngAxis(chrono.ChVectorD(0, 0, 1), chrono.CHR_PI_2)))

# Add the vehicle to the system
system.Add(citybus)

# --------------------------
# Create the driver system
# --------------------------
driver = veh_wheeled.ChDriver()
driver.Initialize(citybus)
driver.SetSteeringController(veh_wheeled.ChGenericDriverController())
driver.SetThrottleController(veh_wheeled.ChGenericDriverController())
driver.SetBrakingController(veh_wheeled.ChGenericDriverController())

# --------------------------
# Set up the camera
# --------------------------
camera = vis.AddCamera(chrono.ChVectorD(10, -10, 5), chrono.ChVectorD(0, 0, 0))
camera.SetNearClip(0.1)
camera.SetFarClip(1000)
camera.SetYfov(chrono.CHR_PI / 4)

# --------------------------
# Simulation loop
# --------------------------
def simulation_step():
    while vis.Run():
        time = system.GetChronoDataTime()
        driver.UpdateDriver(time)

        system.DoStepDynamics(1.0 / 50)
        vis.Render()

simulation_step()
```

### Explanation:

1. **Initialization**: The script initializes the Chrono::Engine and Irrlicht visualization systems. It sets up the simulation environment, including gravity and window settings.

2. **Terrain Creation**: A rigid terrain is created with a specified contact material and texture. The terrain is added to the simulation system.

3. **Vehicle Creation**: The CityBus vehicle is initialized with the specified parameters, including its position, orientation, and mesh files for visualization. The vehicle is then added to the simulation system.

4. **Driver System**: An interactive driver system is set up to control the vehicle's steering, throttle, and braking.

5. **Camera Setup**: The camera is positioned to follow the vehicle from a specified viewpoint.

6. **Simulation Loop**: The simulation loop runs at 50 frames per second, updating the vehicle dynamics and rendering the scene in real-time using Irrlicht.

Make sure to replace `'path/to/chrono/data'` with the actual path to your Chrono data directory and ensure that the necessary mesh and texture files are available in the specified locations.
