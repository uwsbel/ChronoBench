Below is a comprehensive PyChrono simulation script that sets up an epicyclic gear system with a fixed truss, a rotating bar, and two gears, one of which is driven by a gear motor to maintain a constant rotation speed. The script also initializes the visualization using Irrlicht with appropriate materials and lighting.

```python
import pychrono.core as chrono

# Initialize the Chrono system
system = chrono.ChSystemNSC()

# Set gravity (if needed, here set to zero for pure rotational system)
system.Set_G_acc(chrono.ChVectorD(0, 0, 0))

# Create a fixed truss (base frame)
truss = chrono.ChBodyEasyBox(0.2, 0.02, 0.2, 1000, True, True)
truss.SetBodyFixed(True)
system.Add(truss)

# Create a rotating bar (epicyclic arm)
arm = chrono.ChBodyEasyBox(0.4, 0.02, 0.02, 1000, True, True)
arm.SetPos(chrono.ChVectorD(0, 0.1, 0))
system.Add(arm)

# Create gears
# Gear 1 (fixed gear attached to the truss)
gear1_radius = 0.05
gear1 = chrono.ChBodyEasyCylinder(gear1_radius, 0.02, 1000, True, True)
gear1.SetPos(chrono.ChVectorD(0.1, 0.02, 0))
system.Add(gear1)

# Gear 2 (gear mounted on the rotating arm)
gear2_radius = 0.05
gear2 = chrono.ChBodyEasyCylinder(gear2_radius, 0.02, 1000, True, True)
gear2.SetPos(chrono.ChVectorD(0.2, 0.1, 0))
system.Add(gear2)

# Connect gear1 to the truss with a revolute joint (fixed)
joint_gear1_truss = chrono.ChLinkRevolute()
joint_gear1_truss.Initialize(gear1, truss, chrono.ChCoordsysD(gear1.GetPos(), chrono.Q_from_AngZ(0)))
system.Add(joint_gear1_truss)

# Connect gear2 to the arm with a revolute joint
joint_gear2_arm = chrono.ChLinkRevolute()
joint_gear2_arm.Initialize(gear2, arm, chrono.ChCoordsysD(gear2.GetPos(), chrono.Q_from_AngZ(0)))
system.Add(joint_gear2_arm)

# Add gear constraints to enforce gear ratio (meshing)
gear_constraint = chrono.ChLinkGear()
gear_constraint.Initialize(gear1, gear2, chrono.ChVectorD(0, 0, 1))
gear_constraint.SetGearRatio(gear1_radius / gear2_radius)
system.Add(gear_constraint)

# Add a motor to gear1 to enforce constant rotation speed
motor = chrono.ChLinkMotorRotation()
motor.Initialize(gear1, truss, chrono.ChFrameD(gear1.GetPos(), chrono.Q_from_AngZ(0)))
system.Add(motor)

# Set the motor to rotate gear1 at a constant angular velocity
desired_omega = 10.0  # rad/sec
motor.SetSpeed(desired_omega)

# Visualization setup
application = chrono.ChIrrApp(system, 'Epicyclic Gear System', chrono.dimension(800, 600))
application.AddTypicalLights()
application.SetContactsDrawMode(chrono.ChIrrTools.COLORS)
application.SetShowInfos(True)

# Add bodies to visualization
application.AssetBindAll()
application.AssetUpdateAll()

# Simulation loop
time_step = 1e-3
application.SetTimestep(time_step)

while application.GetDevice().run():
    system.DoStepDynamics(time_step)
    application.BeginScene()
    application.DrawAll()
    application.EndScene()

```

### Explanation:
- **System Initialization:** Sets up the physical system with no gravity for pure rotational motion.
- **Fixed Truss:** Acts as the base, fixed in space.
- **Rotating Bar (Arm):** Represents the epicyclic arm that can rotate.
- **Gears:** Two cylinders representing gears, positioned appropriately.
- **Joints:** Revolute joints connect gears to the truss and arm.
- **Gear Constraint:** Enforces the gear ratio, ensuring proper meshing.
- **Motor:** Drives gear1 at a constant angular velocity.
- **Visualization:** Uses Irrlicht to visualize the setup with lighting and materials.
- **Simulation Loop:** Advances the simulation and renders continuously.

Feel free to adjust parameters such as gear sizes, rotation speeds, or positions to better suit your specific epicyclic gear system design.
