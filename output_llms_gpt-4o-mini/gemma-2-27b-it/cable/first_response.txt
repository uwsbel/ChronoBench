```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment and core components.
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create the Irrlicht visualization system
viz = chronoirr.ChIrrApp(my_system, 'ANCF Beam Simulation', chronoirr.dimension2d(800, 600))
viz.AddTypicalSky()
viz.AddTypicalLights()
viz.SetCameraPosition(chrono.ChVectorD(5, 5, 5))
viz.SetCameraLookAt(chrono.ChVectorD(0, 0, 0))

# 2. Add the required physical systems and objects.
# Define beam parameters
beam_length = 5
num_elements = 10
element_length = beam_length / num_elements

# Create the ANCF cable elements
beam_body = chrono.ChBody()
beam_body.SetBodyFixed(True)  # Fix one end to the ground

# Create nodes and elements
nodes = []
for i in range(num_elements + 1):
    node = chrono.ChNodeANCF()
    node.SetPos(chrono.ChVectorD(i * element_length, 0, 0))
    nodes.append(node)
    beam_body.AddNode(node)

# Create ANCF elements
for i in range(num_elements):
    element = chrono.ChElementCableANCF()
    element.SetNodes(nodes[i], nodes[i + 1])
    beam_body.AddElement(element)

# Add the beam body to the system
my_system.Add(beam_body)

# 3. Set necessary default parameters.

# Visualization settings
viz.AssetBindAll()
viz.AddChBody(beam_body)

# Simulation loop
while viz.Run():
    my_system.DoStepDynamics(0.01)
    viz.BeginScene()
    viz.Render()
    viz.EndScene()
```

**Explanation:**

1. **Initialization:**
   - We create a `ChSystemNSC` object to manage the simulation.
   - Gravity is set using `Set_G_acc`.
   - The Irrlicht visualization system (`chronoirr.ChIrrApp`) is initialized with the simulation system, window title, and resolution.

2. **Beam Creation:**
   - We define beam parameters like length and the number of elements.
   - An empty `ChBody` is created to hold the beam's nodes and elements.
   - Nodes are created using `ChNodeANCF` and positioned along the beam's length.
   - `ChElementCableANCF` objects are created to connect consecutive nodes, forming the ANCF cable elements.
   - The nodes and elements are added to the `ChBody`.
   - Finally, the beam body is added to the simulation system.

3. **Visualization and Simulation Loop:**
   - We bind assets for visualization and add the beam body to the Irrlicht scene.
   - The simulation loop runs until the Irrlicht window is closed.
   - Inside the loop:
     - The simulation is advanced one time step using `DoStepDynamics`.
     - The Irrlicht scene is rendered, visualizing the beam's deformation and nodal positions.

**Key Points:**

- **ANCF Elements:** This script uses `ChElementCableANCF` to represent the beam as a series of ANCF cable elements. These elements are suitable for modeling flexible structures with large deformations.
- **Visualization:** The Irrlicht engine is used for real-time visualization of the beam's movement.
- **Simulation Parameters:** You can adjust parameters like `beam_length`, `num_elements`, gravity, and time step to experiment with different scenarios.
