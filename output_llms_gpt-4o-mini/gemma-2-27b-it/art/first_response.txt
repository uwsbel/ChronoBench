```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files

# Create the physical system
system = chrono.ChSystemNSC()

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("ARTcar Simulation")
vis.Initialize()

# 2. Add physical systems and objects

# Create the terrain
terrain = chrono.ChRigidTerrain(system)
terrain.SetSize(chrono.ChVectorD(100, 100, 1))  # Set terrain dimensions
terrain.SetTexture(chrono.GetChronoDataPath() + "terrain/textures/grass.png")  # Set custom texture

# Create the ARTcar vehicle
vehicle = chronovehicle.ChVehicle(system)
vehicle.SetChassisBody(chrono.ChBodyEasyBox(2.5, 1.2, 0.8, 1000))  # Set chassis dimensions and mass
vehicle.SetChassisFixed(False)  # Allow chassis to move
vehicle.SetInitPosition(chrono.ChVectorD(0, 0, 1))  # Set initial position
vehicle.SetInitRotation(chrono.Q_from_AngAxis(chrono.CH_C_PI / 4, chrono.ChVectorD(0, 0, 1)))  # Set initial orientation

# Add wheels to the vehicle
wheel_radius = 0.3
wheel_width = 0.1
for i in range(4):
    wheel = chronovehicle.ChWheel(vehicle.GetSystem())
    wheel.SetRadius(wheel_radius)
    wheel.SetWidth(wheel_width)
    vehicle.AddWheel(wheel)

# Set contact method for the wheels
vehicle.SetContactMethod(chronovehicle.ChContactMethod.NSC)

# Set visualization type for the vehicle
vehicle.SetChassisVisualizationType(chronovehicle.VisualizationType.PRIMITIVES)
vehicle.SetWheelVisualizationType(chronovehicle.VisualizationType.MESH)

# 3. Set default parameters

# Set steering, throttle, and braking controls
driver = chronovehicle.ChIrrAppDriver(vis, vehicle)

# 4. Simulation loop
while vis.Run():
    # Update vehicle dynamics
    system.DoStepDynamics(0.01)

    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Control vehicle using driver input
    driver.Update()

    # Limit frame rate to 50 FPS
    chrono.ChTime.Sleep(1.0 / 50.0)

# End of simulation
vis.Deinitialize()
```

**Explanation:**

1. **Initialization:**
    - Imports necessary modules.
    - Sets the Chrono data path.
    - Creates the physical system (`system`) and the Irrlicht visualization system (`vis`).
    - Initializes the Irrlicht window.

2. **Adding Objects:**
    - Creates a `RigidTerrain` with specified dimensions and a custom texture.
    - Creates an `ARTcar` vehicle using the `ChVehicle` class.
    - Sets the chassis properties (dimensions, mass, initial position and orientation).
    - Adds four wheels to the vehicle with specified radius and width.
    - Sets the contact method for the wheels to `NSC` (Non-Smooth Contact).
    - Sets the visualization type for the chassis and wheels.

3. **Default Parameters:**
    - Creates an `IrrAppDriver` to handle interactive controls for steering, throttle, and braking.

4. **Simulation Loop:**
    - Runs the simulation loop until the Irrlicht window is closed.
    - Updates the vehicle dynamics using `system.DoStepDynamics()`.
    - Renders the scene using Irrlicht.
    - Updates the vehicle controls based on driver input.
    - Limits the frame rate to 50 FPS using `chrono.ChTime.Sleep()`.

5. **Cleanup:**
    - Deinitializes the Irrlicht visualization system.

**Notes:**

- This script provides a basic framework for simulating an ARTcar on a rigid terrain.
- You may need to adjust parameters like vehicle properties, terrain dimensions, and control settings based on your specific requirements.
- The `chronovehicle` module provides various advanced features for vehicle modeling and simulation, which you can explore further.
