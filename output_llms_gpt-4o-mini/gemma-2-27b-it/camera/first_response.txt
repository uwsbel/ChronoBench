```python
import pychrono as chrono
import pychrono.postprocess as postprocess
import pychrono.irrlicht as chronoirr
import numpy as np

# 1. Initialize the PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)

# 2. Add the triangular mesh as a fixed body
mesh_file = "your_mesh.obj"  # Replace with the path to your .obj file
mesh = chrono.ChTriangleMeshConnected()
mesh.LoadWavefrontMesh(mesh_file)

body = chrono.ChBody()
body.SetBodyFixed(True)
body.SetCollide(True)
body.SetMesh(mesh)

my_system.Add(body)

# 3. Add camera sensor and sensor manager
camera = chrono.ChCameraSensor()
camera.SetCameraPosition(chrono.ChVectorD(2, 2, 2))
camera.SetCameraTarget(chrono.ChVectorD(0, 0, 0))

sensor_manager = chrono.ChSensorManager()
sensor_manager.AddSensor(camera)

# Add noise filter and visualization to the camera
noise_filter = chrono.ChNoiseFilter()
noise_filter.SetNoiseLevel(0.01)  # Adjust noise level as needed
camera.AddFilter(noise_filter)

# Visualization setup
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Mesh Visualization with Camera')
vis.Initialize()
vis.AddCamera(camera)

# Simulation loop
while vis.Run():
    # Update camera position in an orbit
    angle = my_system.GetChTime() * 0.5  # Adjust speed as needed
    radius = 3
    camera.SetCameraPosition(chrono.ChVectorD(radius * np.cos(angle), 2, radius * np.sin(angle)))
    camera.SetCameraTarget(chrono.ChVectorD(0, 0, 0))

    # Simulate one time step
    my_system.DoStepDynamics(0.01)

    # Print camera buffer data
    buffer = camera.GetImageBuffer()
    print(buffer)

    vis.Render()
```

**Explanation:**

1. **Initialization:**
   - We create a `ChSystemNSC` object for the simulation.
   - Gravity is set, and the solver type is chosen.

2. **Mesh Loading:**
   - The triangular mesh is loaded from the specified `.obj` file using `ChTriangleMeshConnected` and `LoadWavefrontMesh`.
   - A `ChBody` is created, fixed in place, and assigned the mesh.

3. **Camera Sensor:**
   - A `ChCameraSensor` is created with initial position and target.
   - A `ChSensorManager` is used to manage the sensor.
   - A `ChNoiseFilter` is added to the camera to simulate noise in the image.

4. **Visualization:**
   - `ChVisualSystemIrrlicht` is used for rendering.
   - The camera is added to the visualization system.

5. **Simulation Loop:**
   - The camera's position is updated in an orbit around the mesh.
   - The simulation is advanced one time step using `DoStepDynamics`.
   - The camera's image buffer data is printed.
   - The scene is rendered using `vis.Render()`.

**Remember:**


- Replace `"your_mesh.obj"` with the actual path to your mesh file.
- Adjust parameters like noise level, camera position, orbit speed, and simulation time step as needed for your specific simulation.
