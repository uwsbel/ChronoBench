```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("data/")

# Create the simulation system
system = chrono.ChSystemNSC()

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Epicyclic Gears Simulation")
vis.Initialize()
vis.AddCamera(chrono.ChVectorD(2, 2, 2))
vis.AddLight(chrono.ChVectorD(1, 1, 1))

# 2. Add physical systems and objects
# Create a fixed truss
truss = chrono.ChBody()
truss.SetBodyFixed(True)
truss.SetPos(chrono.ChVectorD(0, 0, 0))
system.AddBody(truss)

# Create a rotating bar
bar = chrono.ChBody()
bar.SetMass(1)
bar.SetInertiaXX(chrono.ChVectorD(0.1, 0.1, 0.1))
bar.SetPos(chrono.ChVectorD(0, 0, 1))
system.AddBody(bar)

# Create a revolute joint to connect the bar to the truss
joint_bar_truss = chrono.ChLinkRevolute()
joint_bar_truss.Initialize(truss, bar, chrono.ChVectorD(0, 0, 1))
system.AddLink(joint_bar_truss)

# Create two gears
gear1 = chrono.ChBodyEasyCylinder(0.5, 0.1, 1000, True, True)
gear1.SetPos(chrono.ChVectorD(1, 0, 1))
system.AddBody(gear1)

gear2 = chrono.ChBodyEasyCylinder(0.25, 0.1, 1000, True, True)
gear2.SetPos(chrono.ChVectorD(1.5, 0, 1))
system.AddBody(gear2)

# Create revolute joints to connect gears to the bar
joint_gear1_bar = chrono.ChLinkRevolute()
joint_gear1_bar.Initialize(bar, gear1, chrono.ChVectorD(1, 0, 1))
system.AddLink(joint_gear1_bar)

joint_gear2_bar = chrono.ChLinkRevolute()
joint_gear2_bar.Initialize(bar, gear2, chrono.ChVectorD(1.5, 0, 1))
system.AddLink(joint_gear2_bar)

# Create a gear motor to enforce a constant rotation speed on gear1
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(gear1, chrono.ChVectorD(0, 0, 1))
motor.SetSpeedFunction(chrono.ChFunction_Const(10))  # Set speed to 10 rad/s
system.AddLink(motor)

# 3. Set default parameters

# Set gravity
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Set simulation parameters
system.SetTimestep(0.01)

# 4. Run the simulation
while vis.Run():
    system.DoStepDynamics(0.01)
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a `ChSystemNSC` object to manage the simulation.
   - Initializes the Irrlicht visualization system (`chronoirr`) and sets up the camera and lighting.

2. **Object Creation:**
   - Creates a fixed truss (`truss`) as a reference point.
   - Creates a rotating bar (`bar`) connected to the truss by a revolute joint.
   - Creates two gears (`gear1` and `gear2`) with specified radii and masses.
   - Connects the gears to the bar using revolute joints.
   - Adds a `ChLinkMotorRotationSpeed` to `gear1` to enforce a constant rotation speed.

3. **Parameter Setting:**
   - Sets the gravitational acceleration.
   - Sets the simulation timestep.

4. **Simulation Loop:**
   - Enters a loop that runs until the Irrlicht window is closed.
   - Performs a simulation step using `DoStepDynamics`.
   - Renders the scene using Irrlicht.

**Key Points:**

- **Epicyclic Gears:** The setup demonstrates the principle of epicyclic gears, where one gear rotates around another while also rotating on its own axis.
- **Irrlicht Visualization:** The Irrlicht system provides a real-time 3D visualization of the simulation.
- **Motor Control:** The `ChLinkMotorRotationSpeed` ensures that `gear1` rotates at a constant speed.

Remember to install the necessary PyChrono and Irrlicht dependencies before running this script.
