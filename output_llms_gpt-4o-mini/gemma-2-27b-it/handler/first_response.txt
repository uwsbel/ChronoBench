```python
import pychrono as chrono
import pychrono.ros as chroro
import rospy

# Initialize Chrono and ROS
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create ROS manager
ros_manager = chroro.ChROSManager(my_system)

# Configure ROS clock, body, and transform handlers
ros_manager.SetClockHandler(chroro.ChROSSystemClockHandler())
ros_manager.SetBodyHandler(chroro.ChROSBodyHandler())
ros_manager.SetTransformHandler(chroro.ChROSTransformHandler())

# Create custom ROS handler for publishing integer messages
class CustomROSHandler(chroro.ChROSHandler):
    def __init__(self, topic_name):
        super().__init__()
        self.topic_name = topic_name
        self.publisher = rospy.Publisher(self.topic_name, rospy.rostime.Duration, queue_size=10)

    def OnUpdate(self, time, dt):
        message = rospy.rostime.Duration(secs=time)
        self.publisher.publish(message)

# Register custom ROS handler
custom_handler = CustomROSHandler("/custom_topic")
ros_manager.AddHandler(custom_handler)

# Create physical objects
floor_material = chrono.ChMaterialSurfaceNSC()
floor_material.SetFriction(0.5)
floor_material.SetRestitution(0.2)

floor = chrono.ChBodyEasyBox(10, 0.1, 10, 1000, True, True, floor_material)
floor.SetPos(chrono.ChVectorD(0, -0.5, 0))
floor.SetBodyFixed(True)
my_system.Add(floor)

box_material = chrono.ChMaterialSurfaceNSC()
box_material.SetFriction(0.8)
box_material.SetRestitution(0.3)

box = chrono.ChBodyEasyBox(1, 1, 1, 10, True, True, box_material)
box.SetPos(chrono.ChVectorD(0, 2, 0))
my_system.Add(box)

# Simulation loop
rospy.init_node('chrono_ros_simulation', anonymous=True)
ros_manager.Start()

while True:
    my_system.DoStepDynamics(0.01)
    ros_manager.Update()
    rospy.rostime.wallsleep(0.01)
```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules.
   - Sets Chrono data path and initializes the Chrono system.
   - Creates a ROS manager to handle communication.
2. **ROS Configuration:**
   - Configures ROS clock, body, and transform handlers for synchronization.
   - Creates a custom ROS handler (`CustomROSHandler`) to publish integer messages to a specified topic.
   - Registers the custom handler with the ROS manager.
3. **Physical Objects:**
   - Defines material properties for the floor and box.
   - Creates a fixed floor and a movable box using `ChBodyEasyBox`.
   - Sets initial positions and adds them to the Chrono system.
4. **Simulation Loop:**
   - Initializes the ROS node.
   - Starts the ROS manager.
   - Enters a loop that:
     - Advances the Chrono system by one timestep (`DoStepDynamics`).
     - Updates ROS communication (`ros_manager.Update`).
     - Sleeps for a short duration to maintain real-time execution (`rospy.rostime.wallsleep`).

**Key Points:**

- This script demonstrates a basic integration of PyChrono with ROS.
- The custom ROS handler allows you to publish custom data from the simulation to ROS.
- The simulation loop ensures real-time execution by synchronizing with the ROS clock.

**Remember:**

- You need to have PyChrono, pychrono.ros, and rospy installed.
- Adjust the topic name, message type, and other parameters as needed for your specific application.
