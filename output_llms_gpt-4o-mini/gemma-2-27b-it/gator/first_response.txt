```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Create the simulation system
#

my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# ---------------------------------------------------------------------
#
# Create the Irrlicht visualization system
#

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Gator Vehicle Simulation')
vis.Initialize()
vis.AddTypicalSky()
vis.AddCamera(chrono.ChVectorD(0, 2, -5))
vis.GetCamera().SetLookAt(chrono.ChVectorD(0, 0, 0))

# ---------------------------------------------------------------------
#
# Create the ground
#

ground = chrono.ChBodyEasyBox(
    20, 20, 1, 1000, True, True, chrono.ChMaterialSurface.NSC
)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
ground.SetBodyFixed(True)
my_system.Add(ground)

# Create a textured terrain
texture = chronoirr.ChTexture()
texture.SetTextureFilename("path/to/your/terrain_texture.jpg")
ground.AddAsset(texture)

# ---------------------------------------------------------------------
#
# Create the Gator vehicle
#

vehicle = chronovehicle.ChVehicle("Gator")
vehicle.SetSystem(my_system)

# Set vehicle position and orientation
vehicle.SetChassisPosition(chrono.ChVectorD(0, 1, 0))
vehicle.SetChassisRotation(chrono.Q_from_AngAxis(0, chrono.ChVectorD(0, 1, 0)))

# Use TMEASY tire model
tire_model = chronovehicle.ChTMeasyTire()
vehicle.SetTireModel(tire_model)

# Load vehicle chassis and suspension from file
vehicle.SetChassis(chronovehicle.ChRigidBody())
vehicle.GetChassis().SetMass(1000)
vehicle.GetChassis().SetInertiaXX(chrono.ChVectorD(100, 100, 100))
vehicle.LoadChassisFile("path/to/your/gator_chassis.obj")

# Load wheels and suspension components from file
vehicle.AddWheel(chronovehicle.ChWheelInfo("wheel_FL",
                                        chrono.ChVectorD(1.5, 0.5, 1),
                                        chrono.ChVectorD(0, -1, 0),
                                        chrono.ChVectorD(0, 0, 1),
                                        "path/to/your/gator_wheel.obj"))

# ... Add other wheels similarly

# Set contact method
vehicle.SetContactMethod(chrono.ChContactMethod.NSC)

# ---------------------------------------------------------------------
#
# Interactive driver system
#

driver = chronovehicle.ChDriver()
driver.SetVehicle(vehicle)

# Set up keyboard controls for steering, throttle, and braking

# ---------------------------------------------------------------------
#
# Simulation loop
#

while vis.Run():
    # Get input from driver system
    driver.Synchronize(vis.GetTimeStep())

    # Update vehicle dynamics
    my_system.DoStepDynamics(vis.GetTimeStep())

    # Render the scene
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules.
   - Creates a `ChSystemNSC` object for the simulation.
   - Sets gravitational acceleration.
2. **Visualization:**
   - Creates an `Irrlicht` visualization system and attaches it to the simulation.
   - Sets window size and title.
   - Initializes the visualization and adds a sky and camera.
3. **Ground:**
   - Creates a `ChBodyEasyBox` for the ground.
   - Sets its position, size, and material properties.
   - Adds a texture to the ground using `ChTexture`.
4. **Gator Vehicle:**
   - Creates a `ChVehicle` object named "Gator".
   - Sets the vehicle's system and initial position/orientation.
   - Uses the `TMEASY` tire model.
   - Loads chassis and suspension components from `.obj` files.
   - Adds wheels with specified positions, directions, and filenames.
   - Sets the contact method to `NSC`.
5. **Driver System:**
   - Creates a `ChDriver` object to control the vehicle.
   - Sets the vehicle for the driver.
   - Implements keyboard controls for steering, throttle, and braking (not shown in detail here).
6. **Simulation Loop:**
   - Runs the Irrlicht visualization loop.
   - Synchronizes the driver system with the simulation time step.
   - Updates vehicle dynamics using `DoStepDynamics`.
   - Renders the scene using `vis.Render()`.

**Important Notes:**

- Replace `"path/to/your/..."` with the actual paths to your vehicle model files (`.obj`) and texture file.
- Implement the keyboard control logic for the driver system according to your desired input mapping.
- Adjust simulation parameters like time step and rendering frequency as needed.
