```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and add the rigid bodies
#
# ---------------------------------------------------------------------

system = chrono.ChSystemNSC()

# Set the default gravity
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body
ground = chrono.ChBodyEasyBox(10, 1, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
system.Add(ground)

# Create the mass body
mass = chrono.ChBodyEasySphere(1, 10, True, True)
mass.SetPos(chrono.ChVectorD(0, 2, 0))
system.Add(mass)

# Create the spring-damper connection
spring = chrono.ChLinkTSDA()
spring.Initialize(ground, mass, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 0))
system.Add(spring)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#
# ---------------------------------------------------------------------

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Mass-Spring-Damper System')
vis.Initialize()
vis.AddLight(chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1))
vis.AddCamera(chrono.ChVectorD(0, 5, -5))
vis.SetCameraPosition(chrono.ChVectorD(0, 5, -5))

# Create visual shapes for the mass and spring
mass_shape = chronoirr.ChVisualShapeSphere(0.5, mass)
mass_shape.SetTexture(chronoirr.ChTexture())
vis.AddVisualShape(mass_shape)

spring_shape = chronoirr.ChVisualShapeLine(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 2, 0), 0.05)
spring_shape.SetColor(chrono.ChColor(0, 0, 1))
vis.AddVisualShape(spring_shape)

# ---------------------------------------------------------------------
#
#  Run the simulation
#
# ---------------------------------------------------------------------

while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    system.DoStepDynamics(0.01)

```

**Explanation:**

1. **Initialization:**
   - Imports `pychrono` and `pychrono.irrlicht`.
   - Creates a `ChSystemNSC` object for the simulation.
   - Sets default gravity.

2. **Physical Objects:**
   - Creates a ground body using `ChBodyEasyBox`.
   - Creates a mass body using `ChBodyEasySphere`.
   - Connects the mass to the ground using `ChLinkTSDA` (mass-spring-damper connection).

3. **Visualization:**
   - Creates an Irrlicht visualization system (`ChVisualSystemIrrlicht`).
   - Attaches the simulation system to the visualizer.
   - Sets window size, title, and adds light and camera.
   - Creates visual shapes for the mass (sphere) and spring (line) and adds them to the visualizer.

4. **Simulation Loop:**
   - Runs the simulation loop until the Irrlicht window is closed.
   - In each iteration:
     - Renders the scene using `vis.Render()`.
     - Performs a simulation step using `system.DoStepDynamics(0.01)`.

**Key Points:**



* The script uses default linear spring-damper parameters for the `ChLinkTSDA` connection. You can customize these parameters if needed.
* The Irrlicht visualization provides a 3D view of the simulation, allowing you to observe the mass oscillating due to the spring-damper system.
* The script sets up basic lighting and camera settings for better visualization.
