```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and set up the simulation parameters
#
# ---------------------------------------------------------------------

my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))
my_system.SetTimestepperType(chrono.ChTimestepper.Type_EULER_IMPLICIT_LINEARIZED)
my_system.SetSolverType(chrono.ChSolver.Type_PSOR)

# ---------------------------------------------------------------------
#
#  Create the ground body
#
# ---------------------------------------------------------------------

ground = chrono.ChBodyEasyBox(10, 1, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
ground.SetBodyFixed(True)
my_system.Add(ground)

# ---------------------------------------------------------------------
#
#  Create the beam mesh
#
# ---------------------------------------------------------------------

# Define the beam properties
beam_length = 2
beam_width = 0.1
beam_height = 0.1
beam_density = 1000
beam_E = 2e7  # Young's modulus
beam_nu = 0.3  # Poisson's ratio

# Create the nodes
nodes = [
    chrono.ChNodeFEAxyz(chrono.ChVectorD(-beam_length / 2, 0, 0)),
    chrono.ChNodeFEAxyz(chrono.ChVectorD(beam_length / 2, 0, 0)),
]

# Create the beam element
beam = chrono.ChElementBeamEuler(nodes[0], nodes[1], beam_width, beam_height, beam_density, beam_E, beam_nu)

# Add the nodes and element to the system
my_system.Add(nodes[0])
my_system.Add(nodes[1])
my_system.Add(beam)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#
# ---------------------------------------------------------------------

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Beam FEA Simulation")
vis.Initialize()
vis.AddCamera(chrono.ChCamera(chrono.ChVectorD(0, 2, 5)))
vis.AddLight(chrono.ChLight(chrono.ChVectorD(2, 5, 2)))

# ---------------------------------------------------------------------
#
#  Run the simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    my_system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:** The code starts by importing necessary PyChrono modules and initializing the `chrono.ChSystemNSC` object, which represents the physical system.

2. **Ground Body:** A fixed ground body is created using `chrono.ChBodyEasyBox` to provide a surface for the beam to rest on.

3. **Beam Mesh:**

   - **Properties:** The code defines the beam's length, width, height, density, Young's modulus, and Poisson's ratio.
   - **Nodes:** Two `chrono.ChNodeFEAxyz` objects are created to represent the beam's endpoints.
   - **Element:** A `chrono.ChElementBeamEuler` object is created, connecting the nodes and using the defined beam properties.
   - **Adding to System:** The nodes and beam element are added to the `my_system` object.

4. **Visualization:**

   - **Irrlicht Setup:** The code uses `chronoirr.ChVisualSystemIrrlicht` to create a visualization system based on the Irrlicht engine.
   - **Camera and Light:** A camera and a light source are added for better visualization.

5. **Simulation Loop:**

   - **Time Stepping:** The `my_system.DoStepDynamics(0.01)` function advances the simulation by 0.01 seconds in each iteration.
   - **Rendering:** `vis.Render()` updates the visualization based on the current state of the simulation.
