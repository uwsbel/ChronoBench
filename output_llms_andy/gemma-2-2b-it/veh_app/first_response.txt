```python
import pychrono as chrono
import pychrono.core as core
import pychrono.visualization as vis
import pychrono.sensor_manager as sensor_manager
import pychrono.vehicle as vehicle

# Initialize PyChrono
chrono.init()

# Create the world
world = chrono.World()

# Create the terrain
terrain = chrono.Terrain(chrono.TerrainType.GRASS)
world.add(terrain)

# Create the Gator vehicle
gator = vehicle.Vehicle(
    "Gator",
    chrono.VehicleType.CAR,
    chrono.VehicleSize.MEDIUM,
)

# Add vehicle parts
gator.add_part(
    chrono.Chassis(
        chrono.ChassisType.FRONT,
        chrono.ChassisType.REAR,
    ),
    vis.VisualType.SOLID_COLOR,
)
gator.add_part(
    chrono.Engine(
        chrono.EngineType.GAS,
        chrono.EngineType.ELECTRIC,
    ),
    vis.VisualType.SOLID_COLOR,
)
gator.add_part(
    chrono.Wheels(
        chrono.WheelType.FRONT,
        chrono.WheelType.REAR,
    ),
    vis.VisualType.SOLID_COLOR,
)

# Set default parameters
gator.position = chrono.Vector3(0, 0, 0)
gator.velocity = chrono.Vector3(0, 0, 0)
gator.orientation = chrono.Quaternion(0, 0, 0, 1)

# Create a sensor manager
sensor_manager = sensor_manager.SensorManager(world)
sensor_manager.add_sensor(
    sensor_manager.SensorType.POINT_LIGHT,
    chrono.PointLight(chrono.Vector3(0, 0, 10)),
)
sensor_manager.add_sensor(
    sensor_manager.SensorType.CAMERA,
    chrono.Camera(chrono.Vector3(0, 0, 0), chrono.Vector3(0, 0, 1)),
)

# Add the vehicle to the world
world.add(gator)

# Run the simulation loop
chrono.run()

# Visualization
vis.render(world)
```

**Explanation:**

1. **Initialization:** 
   - Import necessary modules from PyChrono.
   - Initialize PyChrono using `chrono.init()`.

2. **World and Terrain:**
   - Create a `chrono.World` object to represent the simulation environment.
   - Create a `chrono.Terrain` object to represent the terrain.

3. **Vehicle:**
   - Create a `chrono.Vehicle` object named "Gator" with a specified type and size.
   - Add different parts to the vehicle, including a chassis, engine, and wheels.
   - Set initial position, velocity, and orientation for the vehicle.

4. **Sensor Manager:**
   - Create a `chrono.SensorManager` object to manage sensors.
   - Add a point light and a camera to the sensor manager.

5. **Simulation Loop:**
   - Use `chrono.run()` to start the simulation loop.

6. **Visualization:**
   - Use `vis.render()` to render the simulation scene.

**Important Notes:**

- This script provides a basic framework for a PyChrono simulation. You can customize it further by adding more vehicle parts, sensors, interactions, and physics simulations.
- The visualization part is basic. You can explore more advanced visualization options within PyChrono for better visual representation.
- The simulation loop should be modified based on your specific needs and desired simulation duration.
