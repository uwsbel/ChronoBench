```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import pychrono.physics as physics
import pychrono.vehicle as vehicle
import pychrono.terrain as terrain

# Initialize PyChrono and Irrlicht
chrono.init()
irr = irrlicht.IrrlichtDevice()

# Create a RigidTerrain
terrain_width = 10.0
terrain_height = 5.0
terrain = terrain.RigidTerrain(
    width=terrain_width, height=terrain_height, texture="terrain.jpg"
)

# Create a vehicle
vehicle_name = "Gator"
vehicle = vehicle.Vehicle(vehicle_name, irr)
vehicle.set_position(chrono.Vector3(0, 0, 0))

# Set vehicle parameters
vehicle.set_orientation(chrono.Vector3(0, 0, 0))
vehicle.set_contact_method(chrono.ContactMethod.CONTACT)
vehicle.set_tire_model(vehicle.TMEASY)

# Define vehicle components
vehicle.add_component(vehicle.Wheel(
    name="front_left", position=chrono.Vector3(0, 0, 0),
    orientation=chrono.Vector3(0, 0, 0),
    contact_method=chrono.ContactMethod.CONTACT
))
vehicle.add_component(vehicle.Wheel(
    name="front_right", position=chrono.Vector3(0, 0, 0),
    orientation=chrono.Vector3(0, 0, 0),
    contact_method=chrono.ContactMethod.CONTACT
))
vehicle.add_component(vehicle.Wheel(
    name="rear_left", position=chrono.Vector3(0, 0, 0),
    orientation=chrono.Vector3(0, 0, 0),
    contact_method=chrono.ContactMethod.CONTACT
))
vehicle.add_component(vehicle.Wheel(
    name="rear_right", position=chrono.Vector3(0, 0, 0),
    orientation=chrono.Vector3(0, 0, 0),
    contact_method=chrono.ContactMethod.CONTACT
))

# Add the vehicle to the Irrlicht scene
irr.add_entity(vehicle)
irr.add_entity(terrain)

# Set up the simulation loop
chrono.set_simulation_loop_frequency(50)

# Start the simulation
chrono.run()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries.
   - Initializes PyChrono and Irrlicht.
2. **Terrain Creation:**
   - Creates a `RigidTerrain` object with specified dimensions and texture.
3. **Vehicle Creation:**
   - Creates a `Vehicle` object with a name, position, orientation, and contact method.
   - Sets the vehicle's tire model to `TMEASY`.
4. **Component Setup:**
   - Adds wheels to the vehicle, specifying their positions, orientations, and contact methods.
5. **Adding to Scene:**
   - Adds the vehicle and terrain to the Irrlicht scene.
6. **Simulation Loop:**
   - Sets the simulation loop frequency to 50 frames per second.
   - Starts the simulation using `chrono.run()`.

**Key Components:**

- **PyChrono:** Provides the core simulation engine and physics functionalities.
- **Irrlicht:** A 3D rendering library for visualization.
- **RigidTerrain:** A terrain object for the simulation environment.
- **Vehicle:** A class for representing the vehicle with its components.
- **Wheel:** A component representing a wheel.
- **TMEASY:** A tire model for handling tire contact and dynamics.

**Note:**

- This script provides a basic framework. You can customize it by adding more components, interactions, and visual elements.
- You will need to have the required libraries installed (`pychrono`, `pychrono.irrlicht`, `pychrono.physics`, `pychrono.vehicle`, `pychrono.terrain`). 
- You can replace the default texture with your own image.
- You can adjust the simulation parameters like contact method, tire model, and other vehicle properties.
