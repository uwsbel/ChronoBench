```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht

# Create PyChrono environment
app = chrono.Application()

# Create Irrlicht engine
irr = irrlicht.IrrlichtEngine()

# Initialize Irrlicht scene
scene = irr.createScene()

# Define vehicle parameters
vehicle = chrono.Vehicle()
vehicle.addComponent(chrono.MeshComponent(
    "vehicle_body",
    chrono.Mesh("vehicle_body.obj", "vehicle_body.png", 
                chrono.Mesh.MeshType.OBJ, 
                chrono.Mesh.MeshType.PNG),
    chrono.Material("vehicle_body_mat"),
    chrono.Transform(chrono.Vector3(0, 0, 0), chrono.Quaternion(0, 0, 0, 1))
))

# Define terrain parameters
terrain = chrono.Terrain()
terrain.addMesh("Highway_col.obj", "Highway_vis.obj")

# Define driver system
driver = chrono.Driver()

# Set simulation parameters
app.setSimulationParameters(
    chrono.SimulationParameters(
        fps=50,
        dt=0.01,
        gravity=chrono.Vector3(0, -9.81, 0),
        contactMethod=chrono.ContactMethod.PENALTY
    )
)

# Add vehicle and terrain to the scene
scene.add(vehicle)
scene.add(terrain)

# Initialize driver system
driver.init(vehicle)

# Start simulation loop
app.run()
```

**Explanation:**

1. **PyChrono Initialization:** 
   - The code imports necessary libraries (pychrono and pychrono.irrlicht).
   - An `Application` object is created to manage the simulation.
   - An `IrrlichtEngine` is created to render the scene.

2. **Vehicle and Terrain Setup:**
   - A `Vehicle` object is created to represent the HMMWV.
   - A `MeshComponent` is added to the vehicle, using a custom mesh file ("vehicle_body.obj" and "vehicle_body.png").
   - A `Terrain` object is created, using two mesh files ("Highway_col.obj" and "Highway_vis.obj") for collision and visualization.

3. **Driver System:**
   - A `Driver` object is created to control the vehicle's movement.

4. **Simulation Parameters:**
   - The `setSimulationParameters` method configures the simulation with a desired frame rate (50 FPS), time step (0.01 seconds), gravity, and contact method.

5. **Adding Objects to the Scene:**
   - The vehicle and terrain are added to the Irrlicht scene.

6. **Driver System Initialization:**
   - The driver system is initialized to control the vehicle.

7. **Running the Simulation:**
   - The `app.run()` method starts the simulation loop, rendering the scene in real time.


**Note:**

- You will need to replace the placeholder mesh file names ("vehicle_body.obj", "vehicle_body.png", "Highway_col.obj", "Highway_vis.obj") with the actual file paths to your custom meshes.
- You will need to install the necessary dependencies (pychrono, pychrono.irrlicht, Irrlicht engine) before running the script.
