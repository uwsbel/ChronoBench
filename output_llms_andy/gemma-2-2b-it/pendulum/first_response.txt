```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import numpy as np

# Initialize PyChrono
chrono.init()

# Create the Irrlicht engine
engine = irrlicht.IrrlichtEngine()

# Create the world
world = chrono.World()

# Create the ground body
ground = chrono.Body(chrono.BodyType.Ground)
ground.setMass(100)
ground.setPosition(0, 0, 0)
world.addBody(ground)

# Create the pendulum
pendulum = chrono.Body(chrono.BodyType.RigidBody)
pendulum.setMass(1)
pendulum.setInertia(chrono.Inertia(1, 0, 0))  # Example inertia
pendulum.setPosition(0, 1, 0)  # Example position
pendulum.setVelocity(0, 0, 0)  # Example velocity
pendulum.setAngularVelocity(0, 0, 0)  # Example angular velocity

# Create the revolute joint
joint = chrono.RevoluteJoint(pendulum, ground)
world.addBody(pendulum)
world.addBody(ground)
world.addJoint(joint)

# Set visualization parameters
engine.setCameraPosition(0, 0, 10)
engine.setCameraTarget(0, 0, 0)
engine.setCameraZoom(10)

# Simulation parameters
dt = 0.01  # Time step
duration = 10  # Simulation duration

# Main loop
while engine.isRunning():
    # Update the simulation
    world.update(dt)

    # Log the pendulum's position and velocity
    print("Position:", pendulum.getPosition())
    print("Velocity:", pendulum.getVelocity())

    # Render the simulation
    engine.render()

# Clean up
engine.shutdown()
```

**Explanation:**

1. **Initialization:** The script initializes PyChrono and creates an Irrlicht engine.
2. **World and Bodies:** It creates a world and adds a ground body and a pendulum body to it.
3. **Joint:** It creates a revolute joint between the pendulum and the ground.
4. **Visualization:** It sets the camera position and zoom for visualization.
5. **Simulation Parameters:** It sets the time step and duration for the simulation.
6. **Main Loop:** The script runs the simulation in a loop, updating the world and logging the pendulum's position and velocity.
7. **Rendering:** The Irrlicht engine renders the simulation.
8. **Cleanup:** The script shuts down the Irrlicht engine.


**Note:** 

* This is a basic example, and you can adjust the parameters and add more complex physics and visualization features.
* You'll need to have the PyChrono and Irrlicht libraries installed. 
* You can adjust the pendulum's mass, inertia, and initial position and velocity.
* The visualization will show the pendulum swinging back and forth.
