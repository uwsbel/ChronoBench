Here is a self–contained Python script that sets–up and runs a simple Jeffcott-rotor model in Project Chrono.  
The flexible shaft is created with an IGA (isogeometric) beam, a rigid fly-wheel is bolted to the mid-span node, and a speed-controlled motor spins the shaft about its axis at the left support.  The right support is a free revolute bearing.  Basic finite–element colour plots together with an Irrlicht 3-D window let you watch the motion while the solver runs.

```python
# Jeffcott rotor – IGA beam example
# ---------------------------------------------------------------
# requirements:
#   Project Chrono 8.0 or newer with the Python bindings
#   Irrlicht support enabled when Chrono was built
# ---------------------------------------------------------------

import pychrono                 as chrono
import pychrono.fea             as fea
import pychrono.irrlicht        as chronoirr
import math

# -----------------------------------------------------------------
# 1. Initialise Chrono
# -----------------------------------------------------------------
chrono.SetChronoDataPath( chrono.GetChronoDataPath() )        # for textures etc.
system = chrono.ChSystemNSC()                                  # non- smooth contacts
system.Set_G_acc( chrono.ChVectorD(0,0,0) )                    # Jeffcott rotor – ignore gravity

# -----------------------------------------------------------------
# 2. Material and IGA shaft
# -----------------------------------------------------------------
E_modulus    = 2.1e11      # Pa
poisson      = 0.3
density      = 7800        # kg/m³
diameter     = 0.02        # 20 mm shaft
length       = 0.6         # 600 mm span
num_elems    = 16          # IGA elements along the shaft

section      = fea.ChBeamSectionAdvanced()
section.SetDensity( density )
section.SetYoungModulus( E_modulus )
section.SetPoissonRatio( poisson )
section.SetAsCircularSection( diameter )

mesh   = fea.ChMesh()

builder = fea.ChBuilderBeamIGA()

# build the beam along the global X axis
builder.BuildBeam( mesh,
                   section,
                   num_elems,
                   chrono.ChVectorD( 0, 0, 0 ),
                   chrono.ChVectorD( length, 0, 0 ),
                   chrono.ChVectorD( 0, 1, 0 ) )         # Y up for section reference

# convenient access ------------------------------------------------
first_node   = builder.GetLastBeamNodes().front()             # node at x = 0
mid_node     = builder.GetLastBeamNodes()[ num_elems // 2 ]   # mid span node
last_node    = builder.GetLastBeamNodes().back()              # node at x = L

system.Add( mesh )

# -----------------------------------------------------------------
# 3. Supports (ground) and speed motor
# -----------------------------------------------------------------
ground   = chrono.ChBody()              # static reference
ground.SetBodyFixed( True )
system.Add( ground )

# revolute bearing on right end (free to spin)
rev_right = chrono.ChLinkLockRevolute()
rev_right.Initialize( last_node, ground,
                      chrono.ChCoordsysD( last_node.GetPos(),
                                          chrono.Q_from_AngAxis( 0, chrono.ChVectorD(0,1,0)) ) )
system.Add( rev_right )

# speed-controlled motor on left end
motor_fun = chrono.ChFunctionConstant( 2*math.pi*30 )     # 30 Hz  (≈188 rad/s)
motor     = chrono.ChLinkMotorRotationSpeed()
motor.Initialize( first_node, ground,
                  chrono.ChFrameD( first_node.GetPos(),
                                   chrono.Q_from_AngAxis( 0, chrono.ChVectorD(0,1,0)) ) )
motor.SetSpeedFunction( motor_fun )
system.Add( motor )

# fully constrain the left-end translations (so it only spins)
fix_left = chrono.ChLinkMateGeneric( True, True, True,    # x,y,z translations
                                     False, False, False )# allow rotations
fix_left.Initialize( first_node, ground, first_node.Frame() )
system.Add( fix_left )

# -----------------------------------------------------------------
# 4. Fly-wheel at mid span
# -----------------------------------------------------------------
disc_radius  = 0.08          # 80 mm
disc_thick   = 0.02          # 20 mm
flywheel     = chrono.ChBodyEasyCylinder( disc_radius, disc_thick, density )
flywheel.SetPos( mid_node.GetPos() )
flywheel.SetRot( mid_node.GetRot() )
system.Add( flywheel )

# rigidly attach the fly-wheel to the node
rigid_link   = chrono.ChLinkMateFix()
rigid_link.Initialize( mid_node, flywheel )
system.Add( rigid_link )

# -----------------------------------------------------------------
# 5. FEA visualisation helpers
# -----------------------------------------------------------------
# colour plot of nodal speed magnitude
mesh_vis = fea.ChVisualizationFEAmesh( mesh )
mesh_vis.SetFEMglyphType( fea.ChVisualizationFEAmesh.GLYPH_NODE_DOT_POS )
mesh_vis.SetFEMdataType ( fea.ChVisualizationFEAmesh.PLOT_NODE_SPEED_NORM )
mesh_vis.SetColorscaleMinMax( 0, 20 )
mesh_vis.SetSmoothFaces( True )
mesh.AddAsset( mesh_vis )

# -----------------------------------------------------------------
# 6. Irrlicht application
# -----------------------------------------------------------------
app = chronoirr.ChIrrApp( system, "Jeffcott rotor – IGA shaft", chronoirr.dimension2du(1280,720) )
app.AddTypicalSky()
app.AddTypicalCamera( chronoirr.vector3df( 0.2, 0.3, 1.1 ) )
app.AddTypicalLights()

app.AssetBindAll()
app.AssetUpdateAll()

# solver / integrator
system.SetStep( 1e-4 )
system.SetSolverType( chrono.ChSolver.Type_BARZILAIBORWEIN )
system.SetTimestepperType( chrono.ChTimestepper.Type_EULER_IMPLICIT_LINEARIZED )

# -----------------------------------------------------------------
# 7. Simulation loop
# -----------------------------------------------------------------
while app.GetDevice().run():
    app.BeginScene()
    app.DrawAll()
    app.DoStep()
    app.EndScene()
```

How the script is organised  
1. Physics system, gravity and material are set at the top.  
2. An IGA beam (ChBuilderBeamIGA) spans the X–axis; three convenient node pointers (`first_node`, `mid_node`, `last_node`) are extracted for later constraints.  
3. Ground is a fixed body.  A speed motor spins the shaft about X at the left node, while a revolute bearing lets the right node rotate freely but keeps it in place.  A separate mate‐constraint locks the translational DOFs of the left node so it behaves like an ideal bearing that only transmits torque.  
4. A rigid body representing the Jeffcott disc (fly-wheel) is created and rigidly “bolted” to the mid-span node through `ChLinkMateFix`.  
5. Basic FEA colour-mapping shows nodal speed (you can switch to displacement, strain … by changing `SetFEMdataType`).  
6. The Irrlicht window is initialised, assets bound, and the main loop advances the solver while drawing the scene.

Run the script and you should see the flexible shaft whip while the disc introduces the classical Jeffcott critical-speed behaviour.  All important parameters (beam length, material, motor speed, disc size, solver settings) are gathered near the top so you can easily tweak the scenario.
