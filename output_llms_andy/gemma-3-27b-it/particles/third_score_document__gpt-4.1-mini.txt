### 2. Correctness (30 points)

- **API usage:**  
  - `ChContactMaterialNSC` is created and passed to `ChBodyEasySphere`. This is not standard per the API docs: `ChBodyEasySphere` expects a material pointer for SMC contact (soft contact) or no material for NSC. The API docs show `ChBodyEasySphere(radius, density, visualize, collision, material)`, but the material is expected to be a `ChMaterialSurface` pointer, which is usually created via `ChMaterialSurfaceNSC()` or `ChMaterialSurfaceSMC()`. The code uses `ChContactMaterialNSC()`, which is not the same as `ChMaterialSurfaceNSC()`. This is a subtle but important error: `ChContactMaterialNSC` is a contact material used for contact container, not for body surface material. The correct material class to pass to `ChBodyEasySphere` is `ChMaterialSurfaceNSC()`.  
  - **Deduction: 15 points** for incorrect material usage that could affect collision behavior.  

- **Use of `SetUseGyroTorque(False)`:** This disables gyroscopic torque on bodies, which is acceptable but not explained. No deduction.

- **Solver:** PSOR solver is set with max iterations 40, which is reasonable. ✔️
