### 2. Correctness (30 points)

- **Incorrect use of PyChrono API:**

  - `mcrank = chrono.ChBodyEasyCylinder(chrono.ChAxis_Y, crank_rad, crank_thick, 1000)`  
    According to the API, `ChBodyEasyCylinder` expects parameters: `(radius, height, density, visualize=True, collision=True, material=None)`  
    The first argument should be radius (float), not an axis vector. The axis is not a parameter for `ChBodyEasyCylinder`.  
    This is a **significant API misuse** and will cause an error or unexpected behavior.  
    **Deduct 15 points**

- **Joint Initialization:**

  - `my_motor.Initialize(mcrank, mfloor, chrono.ChFramed(crank_center))`  
    The API expects `chrono.ChCoordsysD` (or `ChCoordsys`) for the frame, not `ChFramed`. `ChFramed` is not a documented class in the API.  
    Similarly, for all joints, `chrono.ChFramed` is used instead of `chrono.ChCoordsysD` or `chrono.ChCoordsys`. This is an incorrect class usage and will cause errors.  
    **Deduct 15 points**

- **Motor function setting:**

  - `my_motor.SetMotorFunction(my_angularspeed)`  
    The API method is `SetSpeedFunction(func)`, not `SetMotorFunction`.  
    This is an incorrect method call.  
    **Deduct 15 points**

- **Getting angle and angular velocity:**

  - `angle = mcrank.GetAngle(chrono.ChAxis_Y)`  
    - `GetAngle` expects an axis vector, but `chrono.ChAxis_Y` is not defined in the API doc. The correct way is to pass a `ChVector` or use `chrono.VECT_Y` or `chrono.ChVectorD(0,1,0)`.  
    - Similarly, `GetWvel` expects no arguments or a vector? The API doc does not mention `GetWvel(axis)`; it usually returns the angular velocity vector.  
    This is a minor API misuse or misunderstanding.  
    **Deduct 5 points**

- **Logo loading:**

  - `vis.AddLogo(chrono.GetChonoDataFile('logo_pychrono_alpha.png'))`  
    Typo in `GetChonoDataFile` (should be `GetChronoDataFile`). This will cause an error.  
    **Deduct 15 points**
