### 2. Correctness (30 points)

- **API Usage:**

  - `ChBodyEasyCylinder` is called with `chrono.ChAxis_Y` as the first argument. The documentation shows `ChBodyEasyCylinder(radius, height, density, visualize, collision, material)`. The first argument should be radius, not an axis. This is a **significant API misuse**.

    The correct call should be:

    ```python
    chrono.ChBodyEasyCylinder(radius, height, density, visualize, collision, material)
    ```

    The axis orientation should be set by rotating the body, not by passing an axis as the first argument.

    This mistake occurs multiple times:

    ```python
    mbody_gearA = chrono.ChBodyEasyCylinder(chrono.ChAxis_Y, radA, 0.5, 1000, True, False, mat)
    ```

    Here, `chrono.ChAxis_Y` is passed as radius, which is incorrect.

    This will cause the cylinder to be created with wrong dimensions or fail.

    Deduct **15 points** for this critical API misuse.

- **Joint Initialization:**

  - Revolute joints are initialized with `chrono.ChFrameD` which is an alias for `ChCoordsysD` (or similar). This is acceptable.

  - Motor speed function is set correctly with `ChFunctionConst(3)`.

  - Gear ratios and frames are set properly.

- **Quaternion usage:**
