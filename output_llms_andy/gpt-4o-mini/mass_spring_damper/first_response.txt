Here is a Python script that demonstrates a single mass-spring-damper system using `ChLinkTSDA` in PyChrono. The script initializes the PyChrono environment, sets up the mass, spring, and damper, and includes visualization using Irrlicht.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr

# Initialize the Chrono environment
chrono.SetChronoDataPath('path/to/chrono/data/')  # Set the path to Chrono data if needed
system = chrono.ChSystemNSC()

# Create the ground body
ground = chrono.ChBodyEasyBox(5, 0.1, 5, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
system.Add(ground)

# Create a mass body
mass = chrono.ChBodyEasySphere(0.1, 1000, True, True)
mass.SetPos(chrono.ChVectorD(0, 1, 0))
mass.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
system.Add(mass)

# Create a spring-damper link
spring_damper = chrono.ChLinkTSDA()
spring_damper.Initialize(ground, mass, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
spring_damper.SetSpringK(1500)  # Spring constant
spring_damper.SetDampingR(10)    # Damping coefficient
system.Add(spring_damper)

# Set up visualization
app = chronoirr.ChIrrApp(system, 'Mass-Spring-Damper System', chronoirr.dimension2du(800, 600))
app.AddTypicalLights()
app.SetCamera(chrono.ChVectorD(0, 2, -5), chrono.ChVectorD(0, 0, 0))
app.AddTypicalSky(chrono.ChColor(0.5, 0.5, 0.5), 0.5)
app.AddLogo(chrono.ChVectorD(0.5, 0.5, 0), 0.1)

# Run the simulation
app.AssetBindAll()
app.AssetUpdateAll()
app.SetTimestep(0.01)

while app.GetDevice().run():
    app.BeginScene()
    app.DrawAll()
    app.EndScene()
    system.DoStepDynamics(app.GetTimestep())
```

### Explanation of the Code:
1. **Environment Initialization**: The script initializes the Chrono environment and sets the data path if needed.
2. **Ground and Mass Creation**: A ground body and a mass body are created. The mass is represented as a sphere.
3. **Spring-Damper Link**: A `ChLinkTSDA` is created to connect the mass to the ground, with specified spring constant and damping coefficient.
4. **Visualization Setup**: Irrlicht visualization is set up with lights and a camera angle to view the simulation effectively.
5. **Simulation Loop**: The main loop runs the simulation and updates the visualization.

Make sure to adjust the `SetChronoDataPath` to point to your Chrono data directory if necessary.
