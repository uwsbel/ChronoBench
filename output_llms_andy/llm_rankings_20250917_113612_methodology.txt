LLM RANKING METHODOLOGY
==================================================

This ranking system uses z-score based consensus scoring:

1. Data Collection:
   - Judge scores from output_llms/*/score files
   - Similarity metrics from evaluation_results.csv

2. Scale Normalization:
   - Detect if scores are in 0-10 or 0-100 scale
   - Convert all to 0-100 scale
   - Cap any scores > 100 (error correction)

3. Z-Score Calculation:
   - Calculate z-scores for each metric
   - Z-score = (value - mean) / std_dev

4. Consensus Score:
   - Judge metrics weight: 70%
   - Similarity metrics weight: 30%
   - Final score: min-max scaled to 0-100

5. Special Handling:
   - gemma-3-27b-it: No scale multiplication (already 0-100)
   - phi-3-medium: Cap scores at 100 (fix double-multiplication)
