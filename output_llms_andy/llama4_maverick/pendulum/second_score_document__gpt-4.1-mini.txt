    According to the documentation, the method is `Set_G_acc` in the code, but the official API uses `Set_G_acceleration`.  
    This is a minor naming inconsistency. However, PyChrono Python API historically has used `Set_G_acc` as a shortcut.  
    This is acceptable but could cause confusion.  
    **Minor inaccuracy: -5 points**

- **Body properties:**
