```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#

mysystem = chrono.ChSystemNSC()
mysystem.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht application
myapplication = chronoirr.ChIrrApp(mysystem, 'ARTcar Simulation', chronoirr.dimension2du(800, 600))
myapplication.AddTypicalSky()
myapplication.AddTypicalLights()
myapplication.SetCameraLocation(chrono.ChVectorD(0, 2, -5))
myapplication.SetCameraLookAt(chrono.ChVectorD(0, 0, 0))

# ---------------------------------------------------------------------
#
# Create the vehicle and terrain
#

# Vehicle parameters
vehicle_location = chrono.ChVectorD(0, 0.5, 0)
vehicle_orientation = chrono.Q_from_AngAxis(0, chrono.ChVectorD(0, 1, 0))

# Load the ARTcar vehicle model
vehicle = chrono.ChVehicle(mysystem, "ARTcar", vehicle_location, vehicle_orientation)

# Set contact method (e.g., ChContactMethodNSC)
vehicle.SetContactMethod(chrono.ChContactMethodNSC())
vehicle.SetChassisVisualizationType(chrono.ChVehicle.VisualizationType_MESH)

# Rigid terrain
terrain_size = chrono.ChVectorD(100, 100, 1)
terrain = chrono.ChRigidTerrain(mysystem, terrain_size, 50, 50)

# Add a custom texture to the terrain
terrain.SetTexture(chronoirr.GetChronoDataPath() + 'terrain/grass.png')
terrain.Initialize()

# ---------------------------------------------------------------------
#
#  Set up interactive driver system
#

driver = chronoirr.ChIrrDriver(myapplication, vehicle)

# ---------------------------------------------------------------------
#
# Simulation loop
#

myapplication.SetTimestep(0.01)
myapplication.SetTryRealtime(True)

while myapplication.GetDevice().run():
    myapplication.BeginScene()
    myapplication.DrawAll()
    
    # Update vehicle dynamics and driver input
    driver.Update(myapplication.GetDevice().GetElapsedSeconds())
    mysystem.DoStepDynamics(myapplication.GetTimestep())
    
    myapplication.EndScene()



```

**Explanation:**

1. **Initialization:** The code starts by importing necessary PyChrono modules and creating the simulation system (`mysystem`), setting gravity.

2. **Visualization:** It initializes an Irrlicht application (`myapplication`) for visualization, adds a sky and lights, and sets the initial camera position and view.

3. **Vehicle and Terrain:**
   - It defines the initial location and orientation of the ARTcar vehicle.
   - It loads the ARTcar model (you'll need to have the model file available).
   - It sets the contact method for the vehicle (e.g., `ChContactMethodNSC`) and specifies how the chassis should be visualized (here, using a mesh).
   - It creates a `ChRigidTerrain` object with defined dimensions and adds a custom texture.

4. **Interactive Driver:**
   - An `ChIrrDriver` object is created to handle user input (steering, throttle, braking) through the Irrlicht interface.

5. **Simulation Loop:**
   - The loop runs until the Irrlicht application is closed.
   - Inside the loop:
     - The scene is drawn using Irrlicht.
     - The `ChIrrDriver` updates the vehicle controls based on user input.
     - The `mysystem.DoStepDynamics()` function advances the simulation by one timestep.



**Remember:**

- You'll need to have the PyChrono library installed and configured.
- Replace `"ARTcar"` with the actual filename of your ARTcar model.
- Adjust parameters like vehicle location, terrain size, and texture path as needed.
