```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add physical systems and objects

# a. Fixed ground
ground = chrono.ChBodyEasyBox(100, 1, 100, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# b. Curiosity rover
rover = chrono.ChWheeledVehicle()
rover.SetSystem(system)

# Add chassis
chassis = chrono.ChBodyEasyBox(2, 1, 3, 100, True, True)
chassis.SetPos(chrono.ChVectorD(0, 1, 0))
rover.AddChassis(chassis)

# Add wheels
wheel_radius = 0.5
wheel_width = 0.2
wheel_pos = [
    chrono.ChVectorD(1, 0, 1),
    chrono.ChVectorD(1, 0, -1),
    chrono.ChVectorD(-1, 0, 1),
    chrono.ChVectorD(-1, 0, -1),
]
for pos in wheel_pos:
    wheel = chrono.ChWheel(chrono.ChVectorD(0, -wheel_radius, 0), wheel_radius, wheel_width)
    wheel.SetFriction(0.8)
    wheel.SetSteering(True)
    rover.AddWheel(wheel, pos)

# 3. Set default parameters

# Motor control driver
motor_driver = chrono.ChMotorControlDriver()
motor_driver.SetSteeringAngle(0)
motor_driver.SetThrottle(0)
rover.SetMotorControlDriver(motor_driver)

# 4. Visualization with Irrlicht

# Create the Irrlicht application
vis = chronoirr.ChIrrApp(system, "Curiosity Rover Simulation")
vis.SetWindowSize(1200, 800)
vis.SetCameraPosition(chrono.ChVectorD(5, 5, 5))
vis.SetCameraLookAt(chrono.ChVectorD(0, 1, 0))

# Customize camera settings
vis.AddCameraLight(chrono.ChVectorD(2, 5, 2))
vis.SetShadow(True)

# Add textures and logos (optional)
# ...

# Simulation loop
while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()
    vis.DoStep()
    vis.EndScene()
```

**Explanation:**

1. **Initialization:**

- Imports necessary PyChrono and Irrlicht modules.
- Sets the data path for Chrono.
- Creates the `ChSystemNSC` (non-smooth contact) for the simulation.
- Sets the gravitational acceleration.

2. **Adding Objects:**
- **Ground:** Creates a fixed box representing the terrain with collision properties.
- **Rover:**
    - Creates a `ChWheeledVehicle` object.
    - Adds a chassis (box shape) to the rover.
    - Adds four wheels with specified radius, width, and positions. Each wheel has friction and steering capabilities.

3. **Default Parameters:**
- **Motor Control:** Creates a `ChMotorControlDriver` to control the rover's steering and throttle.

4. **Visualization:**
- Creates an Irrlicht application (`ChIrrApp`) linked to the physics system.
- Sets window size, initial camera position, and look-at point.
- Enables shadows and adds a camera light for better visualization.
- You can further customize the visualization by adding textures, logos, and other visual elements.

5. **Simulation Loop:**
- The `while` loop runs the simulation until the Irrlicht window is closed.
- Inside the loop:
    - `vis.BeginScene()` and `vis.EndScene()` handle Irrlicht rendering.
    - `vis.Render()` renders the scene.
    - `vis.DoStep()` advances the physics simulation by one timestep.

**To run this script:**

- Make sure you have PyChrono and Irrlicht installed.
- Save the code as a Python file (e.g., `curiosity_sim.py`).
- Run the script from the command line: `python curiosity_sim.py`.

This will launch a window showing the Curiosity rover navigating on the rigid terrain. You can control the rover's movement using the `motor_driver` object.
