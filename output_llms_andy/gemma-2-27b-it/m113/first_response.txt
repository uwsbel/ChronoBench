```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add terrain
terrain = chrono.ChBodyEasyBox(100, 1, 100, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, -0.5, 0))
terrain.SetBodyFixed(True)
my_system.Add(terrain)
terrain.GetMaterialSurface().SetFriction(0.8)
terrain.GetMaterialSurface().SetRestitution(0.2)

# 3. Add M113 vehicle
vehicle = chronovehicle.ChVehicle(my_system)
vehicle.SetChassis(chronovehicle.ChChassis(
    chrono.ChBodyEasyBox(3.5, 1, 6, 1000, True, True)
))
vehicle.SetChassisFixed(False)
vehicle.SetChassisPos(chrono.ChVectorD(0, 1, 0))
vehicle.Initialize()

# 4. Add driver system
driver = chronovehicle.ChDriver(vehicle)
driver.SetSteeringAngle(0)
driver.SetThrottle(0)

# 5. Set up Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('M113 Simulation')
vis.Initialize()
vis.AddCamera(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0))
vis.AddLight(chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1))

# 6. Simulation loop
while vis.Run():
    # Apply driver input
    driver.Synchronize(my_system.GetChTime())
    vehicle.Synchronize(my_system.GetChTime())

    # Advance simulation
    my_system.DoStepDynamics(0.01)

    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
```

**Explanation:**

* **Initialization:** Sets up the Chrono system, gravity, and a basic terrain with friction and restitution.
* **Vehicle:** Creates an M113 vehicle using ChronoVehicle's predefined chassis and initializes it.
* **Driver:** Implements a basic driver system to control the vehicle's steering and throttle.
* **Visualization:** Initializes Irrlicht for real-time visualization, sets up a camera, and adds lighting.
* **Simulation Loop:** Synchronizes driver input, advances the simulation, and updates the visualization at each timestep.

**Notes:**

* This script provides a basic framework. You can extend it by adding more complex terrain, vehicle models, sensors, and control systems.
* Adjust the simulation parameters (timestep, friction, etc.) for desired behavior.
* Explore ChronoVehicle's documentation for more advanced vehicle modeling and control options.
