```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#
# ---------------------------------------------------------------------

my_system = chrono.ChSystemNSC()

# Set gravitational acceleration
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('HMMWV Simulation')
vis.Initialize()
vis.AddTypicalSky()
vis.AddTypicalLights()

# Create the HMMWV vehicle
vehicle = chronovehicle.ChVehicle("HMMWV")
vehicle.SetSystem(my_system)

# Add terrain
terrain = chrono.ChTerrainModel()
terrain.SetTexture("textures/terrain.png")
terrain.SetSize(200, 200)
terrain.Initialize()
my_system.Add(terrain)

# Add vehicle to terrain
vehicle.SetChassisBody(terrain.GetBody())

# Create and attach IMU and GPS sensors
imu = chronovehicle.ChSensorIMU(vehicle.GetChassisBody())
gps = chronovehicle.ChSensorGPS(vehicle.GetChassisBody())

# ---------------------------------------------------------------------
#
#  Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    # Get driver inputs (replace with actual driver model)
    steering = 0.0  # Example steering input
    throttle = 0.5  # Example throttle input

    # Apply driver inputs to vehicle
    vehicle.ApplySteering(steering)
    vehicle.ApplyThrottle(throttle)

    # Update sensor data
    imu.Update()
    gps.Update()

    # Output vehicle mass
    print("Vehicle mass:", vehicle.GetMass())

    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Advance the simulation
    my_system.DoStepDynamics(0.01)

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono modules.
   - Creates a `ChSystemNSC` object to manage the simulation.
   - Sets gravitational acceleration.
   - Initializes the Irrlicht visualization system (`chronoirr`).
   - Creates a `ChVehicle` object representing the HMMWV.

2. **Terrain and Vehicle Setup:**
   - Creates a `ChTerrainModel` object for the terrain.
   - Sets the terrain texture and size.
   - Adds the terrain to the simulation system.
   - Attaches the vehicle's chassis to the terrain body.

3. **Sensors:**
   - Creates `ChSensorIMU` and `ChSensorGPS` objects and attaches them to the vehicle's chassis.

4. **Simulation Loop:**
   - Enters a loop that runs until the Irrlicht window is closed.
   - **Driver Inputs:** Placeholder for actual driver model. Replace with code to read driver inputs (steering, throttle, etc.).
   - **Vehicle Control:** Applies steering and throttle inputs to the vehicle.

   - **Output:** Prints the vehicle's mass.
   - **Rendering:** Renders the scene using Irrlicht.
   - **Simulation Advance:** Advances the simulation by one time step using `DoStepDynamics`.
