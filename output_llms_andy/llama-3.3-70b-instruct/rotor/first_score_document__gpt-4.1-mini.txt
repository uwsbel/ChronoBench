### 2. Correctness (30 points)

- **Flywheel creation:**  
  The line:  
  ```python
  flywheel = chrono.ChBodyEasyBox(sys, 0.1, 0.1, 0.1, 7800)
  ```  
  is incorrect. According to the API, `ChBodyEasyBox` constructor is:  
  ```python
  ChBodyEasyBox(lengthX, lengthY, lengthZ, density, visualize=True, collision=True, material=None)
  ```  
  The first argument should be lengthX (float), but `sys` (the system object) is passed instead. This will cause a runtime error or unexpected behavior.  
  Deduct **15 points** for incorrect API usage that will break simulation.

- **Motor initialization:**  
  The motor is created as `ChLinkMotorRotation()`, but `Initialize` is called with only two arguments:  
  ```python
  motor.Initialize(iga_beam, flywheel)
  ```  
  According to the documentation, `Initialize` requires three arguments: `body1`, `body2`, and a `frame` (`ChCoordsysD`) specifying the joint coordinate system. Omitting the frame will cause incorrect joint placement or failure.  
  Deduct **15 points** for incorrect joint initialization.

- **Motor function:**  
  The motor function is set with `SetMotorFunction(chrono.ChFunction_Const(10))`. The correct method name is `SetSpeedFunction()` for `ChLinkMotorRotation` (see API).  
  Deduct **15 points** for incorrect method name usage.

- **Visualization:**  
  Missing `vis.AttachSystem(sys)` means the visualization system is not linked to the physical system, so no bodies will be rendered.  
  Deduct **15 points** for incorrect visualization setup.

- **Repeated `AddTypicalLights()`:**  
  Calling `AddTypicalLights()` twice is unnecessary but not harmful. Deduct **5 points** minor inaccuracy.
