```python
# Import necessary modules
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh

# Initialize the PyChrono environment and core components
sys = chrono.ChSystemNSC()

# Create the Irrlicht visualization window
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AddSkyBox()
vis.AddTypicalLights()

# Create the vehicle
hmmwv = veh.HMMWV()
hmmwv.SetChassisFixed(False)
hmmwv.SetChassisPosition(chrono.ChVectorD(0, 1, 0))
hmmwv.SetChassisOrientation(chrono.Q_from_AngX(chrono.CH_C_PI_2))
hmmwv.AddRigidTireWheels()
hmmwv.Visualize(chrono.ChVisualMode.MESH)

# Add the vehicle to the system
sys.Add(hmmwv)

# Create the SCM terrain
terrain = veh.SCMDeformableTerrain()
terrain.SetSoilParameters(0.1, 0.5, 0.3, 0.2, 0.1)
terrain.SetMovingPatch(True, hmmwv.GetChassisBody(), 5, 5, 10)
terrain.Visualize(chrono.ChVisualMode.SINKAGE_FALSE_COLOR)

# Add the terrain to the system
sys.Add(terrain)

# Create the interactive driver system
driver = veh.InteractiveDriver()
driver.SetVehicle(hmmwv)
driver.SetSteeringGain(1.0)
driver.SetThrottleGain(1.0)
driver.SetBrakingGain(1.0)

# Add the driver to the system
sys.Add(driver)

# Set up the simulation
step_size = 0.001
vis.SetWindowSize(1024, 768)
vis.SetCamera(chrono.ChVectorD(0, 10, -20), chrono.ChVectorD(0, 0, 0), 35)

# Run the simulation
while vis.Run():
    sys.DoStepDynamics(step_size)
    vis.BeginScene()
    vis.DrawAll()
    vis.EndScene()
    chrono.ChUtilities().Sleep(1 / 50.0)
```

This code initializes a PyChrono simulation of a full HMMWV on SCM deformable terrain using Irrlicht for visualization. The vehicle is initialized with specific parameters, including location, orientation, and a rigid tire model, and mesh visualization is applied to all vehicle components. The SCM terrain is configured with custom soil parameters, and a moving patch feature is enabled to dynamically follow the vehicle chassis. The terrain visualizes sinkage with false color plotting. An interactive driver system is set up to control steering, throttle, and braking, and the simulation runs in real time, updating vehicle dynamics and rendering the scene at 50 frames per second.
