### DOC

- `SetContactMaterialProperties()` is not documented.
- `AddPatch()` requires size parameters (length and width).

- MODEL CODE uses `Q_from_AngX(-0.5 * CH_C_PI)` rotation, which is likely incorrect (terrain patch is usually flat on XY plane with Z up).
- MODEL CODE uses `veh.GetDataFile("terrain/textures/grass.jpg")` which is fine if `veh.SetDataPath()` is set (but it is missing).
- REFERENCE uses `ChContactMaterialNSC` explicitly and passes it to `AddPatch()`.
