```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr

def main():
    # 1. Initialize PyChrono environment
    chrono.SetChronoDataPath("C:/path/to/chrono/data/")  # Update this path
    system = chrono.ChSystemNSC()
    system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
    system.SetSolverMaxIterations(150)
    system.SetMaxPenetrationRecoverySpeed(2.5)

    # 2. Create rigid terrain
    terrain = veh.RigidTerrain(system)
    patch_mat = chrono.ChMaterialSurfaceNSC()
    patch_mat.SetFriction(0.8)
    patch_mat.SetRestitution(0.01)
    patch = terrain.AddPatch(patch_mat, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1), 100, 50)
    patch.SetTexture(veh.GetDataFile("terrain/textures/grass.jpg"), 100, 50)
    terrain.Initialize()

    # 3. Create M113 vehicle
    vehicle = veh.M113()
    vehicle.SetContactMethod(chrono.ChContactMethod_NSC)
    vehicle.SetChassisCollisionType(veh.CollisionType_NONE)
    vehicle.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 1.5, 2), chrono.Q_ROTATE_Y_TO_Z))
    vehicle.Initialize()

    # Set visualization modes
    vehicle.SetChassisVisualizationType(veh.VisualizationType_PRIMITIVES)
    vehicle.SetSprocketVisualizationType(veh.VisualizationType_MESH)
    vehicle.SetIdlerVisualizationType(veh.VisualizationType_MESH)
    vehicle.SetRoadWheelAssemblyVisualizationType(veh.VisualizationType_PRIMITIVES)
    vehicle.SetRoadWheelVisualizationType(veh.VisualizationType_MESH)
    vehicle.SetTrackShoeVisualizationType(veh.VisualizationType_MESH)

    # 4. Initialize driver system
    driver = veh.ChInteractiveDriverIRR(vehicle)
    driver.SetSteeringDelta(0.02)
    driver.SetThrottleDelta(0.02)
    driver.SetBrakingDelta(0.06)
    driver.Initialize()

    # 5. Create Irrlicht visualization
    vis = irr.ChVisualSystemIrrlicht()
    vis.AttachSystem(system)
    vis.SetWindowSize(1280, 720)
    vis.SetWindowTitle("M113 Simulation")
    vis.Initialize()
    
    # Configure camera and lighting
    vis.AddCamera(chrono.ChVectorD(5, 3, 2), chrono.ChVectorD(0, 0, 0))
    vis.AddTypicalLights()
    vis.AddSkyBox()
    vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
    
    # Add vehicle-specific visualization assets
    vehicle.AddVisualizationAssets(irr.vis)

    # 6. Simulation loop
    step_size = 0.005
    realtime_timer = chrono.ChRealtimeStepTimer()
    
    while vis.Run():
        time = system.GetChTime()
        
        # Update visualization
        vis.BeginScene()
        vis.Render()
        vis.EndScene()
        
        # Process driver inputs
        driver_inputs = driver.GetInputs()
        driver.Synchronize(time)
        
        # Advance vehicle and terrain states
        vehicle.Synchronize(time, driver_inputs, terrain)
        terrain.Synchronize(time)
        
        # Advance simulation
        system.DoStepDynamics(step_size)
        
        # Maintain real-time execution
        realtime_timer.Spin(step_size)

if __name__ == "__main__":
    main()
```

Key features implemented:
1. **Physical Systems Setup**:
   - NSC (Non-Smooth Contacts) system with optimized solver settings
   - Rigid terrain with configurable friction (0.8) and restitution (0.01)
   - M113 vehicle with collision disabled for chassis

2. **Visualization**:
   - Irrlicht real-time visualization
   - Camera positioned at (5,3,2) looking at origin
   - Skybox, logo, and directional lighting
   - Different visualization types for vehicle components

3. **Driver System**:
   - Interactive keyboard control (arrow keys)
   - Adjustable steering/throttle/braking sensitivity
   - Synchronized with simulation time

4. **Simulation Loop**:
   - Fixed timestep (5ms) for physics stability
   - Real-time synchronization using ChRealtimeStepTimer
   - Proper synchronization order: Driver → Vehicle → Terrain → Physics

**Important Notes**:
1. Update the Chrono data path in `SetChronoDataPath()` to match your installation
2. Requires PyChrono compiled with Vehicle and Irrlicht modules
3. Control the vehicle using:
   - Arrow Up/Down: Throttle/Braking
   - Arrow Left/Right: Steering
   - 'Z': Reverse gear
   - 'X': Toggle manual/automatic transmission

The simulation maintains real-time execution while accurately modeling vehicle-terrain interactions with the specified physical parameters.
