
To create the PyChrono simulation with a Viper rover as described, here's the complete solution:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.viper as viper

def main():
    # Initialize Chrono system with gravity
    system = chrono.ChSystemNSC()
    system.SetGravity(chrono.ChVectorD(0, -9.81, 0))
    
    # Create ground body
    ground = chrono.ChBody()
    ground.SetBodyFixed(True)
    ground_box = chrono.ChBoxShape()
    ground_box.GetBoxGeometry().Size = chrono.ChVectorD(20, 0.1, 20)
    ground_box.GetBoxGeometry().Pos = chrono.ChVectorD(0, -0.2, 0)
    ground.AddAsset(ground_box)
    ground_texture = chrono.ChTexture()
    ground_texture.SetTextureFilename(chrono.GetChronoDataFile("textures/concrete.jpg"))
    ground.AddAsset(ground_texture)
    system.Add(ground)
    
    # Initialize Viper rover
    rover = viper.Viper(system)
    rover.Initialize(chrono.ChCoordsysD(chrono.ChVectorD(0, -0.2, 0), chrono.QUNIT))
    
    # Create Viper driver with steering control
    driver = viper.ViperDCMotorControl()
    rover.SetDriver(driver)
    
    # Set up Irrlicht visualization
    vis = chronoirr.ChIrrApp(system, "Viper Rover Simulation", chronoirr.dimension2du(800,600))
    vis.AddTypicalLights()
    vis.AddSkyBox()
    vis.AddCamera(chrono.ChVectorD(3, 1.5, 3), chrono.ChVectorD(0, 0, 0))
    vis.AssetBindAll()
    vis.AssetUpdateAll()
    
    # Simulation parameters
    time_step = 0.001
    end_time = 10.0
    steering_start = 0.0
    steering_end = 0.4
    steering_change_time = 5.0
    
    # Simulation loop
    time = 0.0
    while time < end_time:
        # Gradually change steering from 0 to 0.4 radians over 5 seconds
        if time < steering_change_time:
            steering = steering_start + (steering_end - steering_start) * (time / steering_change_time)
        else:
            steering = steering_end
            
        # Update driver inputs
        driver.SetSteering(steering)
        driver.SetSpeed(0.3)  # Constant forward speed
        
        # Advance simulation
        vis.BeginScene()
        vis.Render()
        rover.Update()
        system.DoStepDynamics(time_step)
        vis.EndScene()
        
        time += time_step

if __name__ == "__main__":
    main()
```

Key components of this solution:

1. **System Initialization**:
   - Creates physical system with Earth gravity (-Y direction)
   - Adds a textured rigid ground plane

2. **Viper Rover Setup**:
   - Initializes Viper rover at ground level
   - Configures DC motor driver for control

3. **Visualization**:
   - Sets up Irrlicht 3D environment
   - Configures camera position and lighting
   - Adds skybox for visual context

4. **Dynamic Steering Control**:
   - Linearly ramps steering angle from 0 to 0.4 radians over 5 seconds
   - Maintains constant forward speed (0.3 m/s)
   - Uses small timesteps (1ms) for stable physics

5. **Simulation Loop**:
   - Updates rover controls each timestep
   - Advances physics simulation
   - Renders each frame in real-time

The rover will start moving straight, then gradually turn while maintaining forward motion. The visualization provides third-person view of the rover navigating the terrain.
