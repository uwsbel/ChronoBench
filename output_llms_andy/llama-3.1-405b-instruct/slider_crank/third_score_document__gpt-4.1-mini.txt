  ```python
  ChBodyEasyCylinder(radius, height, density, visualize=True, collision=True, material=None)
  ```  

  The motor is initialized with `chrono.ChFramed(crank_center)`. The API expects `chrono.ChCoordsysD` (or `ChCoordsys`) for frames, not `ChFramed`. This is a **significant API misuse**. The same applies to the joints initialized with `chrono.ChFramed(...)`. The correct class is `chrono.ChCoordsysD` or `chrono.ChCoordsys`. Using `ChFramed` is incorrect and will cause errors.
