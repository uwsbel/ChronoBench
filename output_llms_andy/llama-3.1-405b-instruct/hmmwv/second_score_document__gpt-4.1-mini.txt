### 2. Correctness (30 points)

  The vehicle is initialized correctly with contact method, chassis collision type, fixed chassis flag, initial position, tire type, and tire step size.  
  The visualization types for chassis, suspension, steering, wheels, and tires are set after initialization, which is acceptable.

- **Visualization:**  
  The visualization system is set up correctly. However, `AddLightDirectional()` is called, but the API documentation suggests `AddTypicalLights()` is the standard method for lighting. This may cause suboptimal lighting.  
  **Deduct 2 points** for minor visualization issue.

- **Path Visualization:**  
  The path is visualized by adding `ChSphereShape()` objects. However, `ChSphereShape` is a visual shape, not a body. The code calls `ball.SetPos(path_points[i])` which is not a documented method for `ChSphereShape`. Visual shapes do not have a position; they are attached to bodies or added to the visualization system with a position parameter.  
  This is a **significant API misuse** and will likely cause the spheres not to appear or be positioned incorrectly.  
  **Deduct 15 points** for incorrect use of visual shapes.

- **PID Control:**  
  The PID control calculation is incorrect:  
  - The derivative and integral terms are computed as `steering_error / step_size` and `steering_error / step_size**2`, which is not a correct derivative or integral calculation.  
  - The error is a scalar distance, but steering typically requires an angular error or lateral offset, not just distance.  
  - The control output is directly set as steering input without any saturation or limits.  
  This is a **logical error** in control implementation.  
  **Deduct 10 points** for logical errors in control.

- **Advancing Simulation:**  
  The code calls `vehicle.Advance(step_size)`, `terrain.Advance(step_size)`, and `vis.Advance(step_size)`, which is correct.  
  The line `time += step_size` is unnecessary because `time` is fetched from the system each loop iteration and not used elsewhere.  
  **Deduct 3 points** for minor inefficiency/unnecessary code.

- **Real-time Step Timer:**  
  The timer is created anew each loop iteration: `chrono.ChRealtimeStepTimer().Spin(step_size)`. This is inefficient; the timer should be created once outside the loop and reused.  
  **Deduct 5 points** for inefficient use of timer.
