  **Issue:**  
  The `GetTractor()` method is not a standard method in the PyChrono vehicle API for `veh.Kraz()` or `veh.HMMWV()`. Using `GetTractor()` will raise an AttributeError unless the vehicle class has been subclassed or modified to include this method. This is a significant correctness issue that will break the visualization attachment and mass printing lines.  
  **Deduct 15 points for incorrect API usage.**
