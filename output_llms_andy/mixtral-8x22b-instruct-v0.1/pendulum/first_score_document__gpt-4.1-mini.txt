  The second argument to `ChBodyEasySphere` is density, but the code passes `pendulum_mass` (1), which is not a density but a mass. The density should be mass divided by volume, or a realistic density value. This will cause incorrect mass and inertia calculation internally.  
  Deduct **15 points** for incorrect API usage affecting simulation behavior.

- **Manual setting of inertia tensor after using `ChBodyEasySphere`:**  
  `ChBodyEasySphere` automatically computes mass and inertia from radius and density. Manually setting inertia is redundant and may cause inconsistency if not consistent with mass and radius. This is a logical error.  
  Deduct **10 points** for logical error.

- **Joint initialization frame:**  
  The joint is initialized at `(0,0,0)`, which is the pivot point. This is acceptable for a pendulum fixed at origin. No deduction.

  `SetWvel_loc` is used correctly to set local angular velocity. No deduction.
