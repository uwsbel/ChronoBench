- **Driver inputs:**  
  The driver inputs are created using `veh.ChInput` with correct parameters.

- **Sensor offset pose:**  
  The offset pose for sensors is created with `chrono.ChFramed` and `chrono.QuatFromAngleAxis`. However, the documentation and typical usage show `chrono.ChFrame` or `chrono.ChCoordsysd` as the pose type. `ChFramed` is not a standard PyChrono class for poses. This is likely an error or typo.
