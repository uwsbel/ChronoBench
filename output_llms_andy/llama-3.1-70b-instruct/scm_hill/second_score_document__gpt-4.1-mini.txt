### 2. Correctness (30 points)

- **Obstacle Creation:**  
  The line:  
  ```python
  obstacle = chrono.ChBodyEasyBox(vehicle.GetSystem(), 1, 1, 1, 1000, True, True)
  ```  
  is incorrect. According to the API, `ChBodyEasyBox` constructor signature is:  
  ```python
  ChBodyEasyBox(lengthX, lengthY, lengthZ, density, visualize, collision, material=None)
  ```  
  The first argument should be the box length, not the system. Passing `vehicle.GetSystem()` as the first argument is a misuse and will cause an error or unexpected behavior.  
  **Deduct 15 points** for incorrect API usage that affects simulation behavior.

- **Obstacles Not Added to System:**  
  The obstacles are created but never added to the system via `vehicle.GetSystem().Add(obstacle)`. This means they won't participate in the simulation.  
  This is a logical error.  
  **Deduct 10 points** for logical error.

  The collision system type is set after vehicle initialization:  
  ```python
  vehicle.GetSystem().SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)
  ```  
