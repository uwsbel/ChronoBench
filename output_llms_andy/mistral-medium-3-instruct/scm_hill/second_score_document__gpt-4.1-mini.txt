### 2. Correctness (30 points)

- **Incorrect API usage:**  
  - The line:  
    ```python
    lidar.SetFilterType(sens.ChLidarFilterType::ChLidarFilterType_BC)
    ```  
    uses C++-style scope resolution `::` instead of Python attribute access `.`. This will cause a syntax error. It should be:  
    ```python
    lidar.SetFilterType(sens.ChLidarFilterType.ChLidarFilterType_BC)
    ```  
    **Deduct 15 points** for this significant API misuse that would break the script.

- **Logical errors:**  
  - The boxes added as obstacles have collision and visual models created manually, but the collision model is not enabled explicitly via `EnableCollision(True)`. Although `AddBox()` usually enables collision, best practice is to call `EnableCollision(True)` explicitly. This is a minor issue, but since the boxes are fixed and added to the system, it should still work.
