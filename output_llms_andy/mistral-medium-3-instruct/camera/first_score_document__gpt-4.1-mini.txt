### 2. Correctness (30 points)

  **No deduction.**

  - The camera sensor constructor uses C++ style scope resolution operator `::` for enums:  
    ```python
    chrono.ChCameraSensor::LENS_PERSPECTIVE
    ```
    This is invalid Python syntax. The correct usage is:  
    ```python
    chrono.ChCameraSensor.LENS_PERSPECTIVE
    ```
    Similarly for `NoiseModel_GAUSSIAN`, `BlurFilter_GAUSSIAN`, and `FILTER_BILINEAR`.  
    This is a **significant API misuse** that will cause runtime errors.  
    **Deduct 15 points.**

  - `camera.SetCameraTransform()` is called with a `ChFrameD` constructed from position and a quaternion generated by `chrono.Q_from_AngAxis(angle, chrono.ChVectorD(0, 0, 1))`. The function `Q_from_AngAxis` is not part of the documented API. The documented way is `chrono.Q_from_AngAxis(angle, chrono.ChVector3d(0, 0, 1))` or `chrono.Q_from_AngAxis(angle, chrono.ChVectorD(0, 0, 1))`. Assuming `Q_from_AngAxis` exists, this is acceptable.  
  **No deduction.**
