Neither `chrono.ChBody.Truss()` nor `chrono.ChBody.Rigid()` exist in the PyChrono API. The correct approach is to instantiate `chrono.ChBody()` or use helper classes like `ChBodyEasyBox`, `ChBodyEasySphere`, etc., then add them to the system via `sys.Add(body)`. Also, `AddBody` is not a method of the system.

Speed is set via `SetSpeedFunction()`, typically with a `ChFunction_Const` or other function objects. `SetAngle` and `SetAngVel` are not valid methods.

  The script calls `my_ChronoEngine.SetGroundBody(floor)`. The PyChrono API does not have a `SetGroundBody` method on the system. Instead, the ground is simply a fixed body added to the system.
