```python
import pychrono as chrono
import numpy as np

# Initialize PyChrono environment
chrono.setChronoDataPath("path/to/chrono_data")  # Replace with the actual path
chrono.setChronoLogLevel(chrono.LOG_LEVEL_WARNING)

# Create the Chrono system
sys = chrono.ChSystemNSC()
sys.Set_Gravity(chrono.ChVectorD(0, -9.81, 0))

# Add the ground body
ground = chrono.ChBodyEasyBox(100, 1, 100, 1000, 1000, 1000)
ground.SetPos(chrono.ChVectorD(0, -5, 0))
sys.Add(ground)

# Initialize the Viper rover and its driver
rover = chrono.ChBody()
rover.SetPos(chrono.ChVectorD(0, 0, 0))
sys.Add(rover)

# Add the rover's wheels and steering mechanism (omitted for simplicity)

# Create a real-time visualization using Irrlicht
vis = chrono.ChVisualSystemIrrlicht()
vis.Attachsys(sys)
vis.SetWindowTitle("Viper Rover Simulation")
vis.Initialize()
vis.AddCamera(chrono.ChCamera(), chrono.ChVectorD(0, 5, -10), chrono.ChVectorD(0, 0, 0))
vis.AddLight(chrono.ChLightDirectional(), chrono.ChVectorD(1, 1, 1), chrono.ChVectorD(0, 0, -1))

# Simulation loop
t = 0
steering_angle = 0
dt = 0.01
total_time = 5

while t < total_time:
    # Update the rover's steering
    steering_angle += 0.1
    if steering_angle > 1:
        steering_angle = 1

    # Update the Chrono system
    sys.DoStepDt(dt)

    # Render the scene
    vis.Render()
    vis.WaitForFrameEnd()

    t += dt
```

This script initializes a PyChrono simulation with a Viper rover on a rigid terrain, sets up the Chrono system with gravity and ground body, initializes the Viper rover and its driver, creates a real-time visualization using Irrlicht with camera settings and lighting, and implements a simulation loop where the rover's steering gradually changes over a specified time period, updating and rendering the rover at each timestep.
