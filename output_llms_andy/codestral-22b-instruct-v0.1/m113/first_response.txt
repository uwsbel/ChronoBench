```python
# Import necessary PyChrono modules
import pychrono as chrono
import pychrono.irrlicht as irr
import pychrono.vehicle as veh

# Initialize PyChrono system
chrono.SetChronoDataPath('path_to_your_data_folder/')
my_system = chrono.ChSystemNSC()

# Create the vehicle
m113 = veh.M113()
m113.Initialize(my_system)
m113.SetChassisPos(chrono.ChVectorD(0, 0, 1))

# Create the terrain
terrain = veh.RigidTerrain(m113.GetSystem())
patch = terrain.AddPatch(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.Q_from_AngAxis(0, chrono.ChVectorD(1, 0, 0))))
patch.SetFriction(0.9)
patch.SetRestitution(0.01)

# Initialize the driver system
driver = veh.ChDriver(m113.GetVehicle())
driver.Initialize()

# Create the visualization system
application = irr.ChIrrApp(m113.GetSystem(), 'M113 Vehicle Simulation', irr.dimension2du(1024, 768))
application.AddTypicalLogo()
application.AddTypicalSky()
application.AddTypicalLights()
application.AddTypicalCamera(chrono.ChVectorD(0, -10, 5))
application.AssetBindAll()
application.AssetUpdateAll()

# Simulation loop
while application.GetDevice().run():
    application.BeginScene()
    application.DrawAll()
    application.DoStep()
    application.EndScene()
    my_system.DoStepDynamics(0.01)
    driver.Synchronize(my_system.GetChTime())
```

This script initializes a PyChrono simulation with an M113 vehicle on a rigid terrain. The vehicle is positioned at (0, 0, 1) and the terrain has a friction coefficient of 0.9 and a restitution coefficient of 0.01. A driver system is initialized for vehicle control. The simulation uses Irrlicht for real-time visualization with a camera positioned at (0, -10, 5). The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep.
