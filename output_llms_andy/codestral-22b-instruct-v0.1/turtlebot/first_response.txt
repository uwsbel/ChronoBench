I have created a PyChrono simulation script based on the provided instructions. Here's the Python code:

```python
import pychrono as chrono
import pychrono.irrlicht as irr

# Initialize the Chrono system
chrono.SetChronoDataPath("path/to/chrono/data/")
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# Create the ground body
ground = chrono.ChBodyEasyBox(10, 10, 1, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, 0, -0.5))
system.Add(ground)

# Create the Turtlebot robot
turtlebot = chrono.ChBodyEasyBox(0.5, 0.5, 0.2, 10, True, True)
turtlebot.SetPos(chrono.ChVectorD(0, 0, 0.2))
turtlebot.SetRot(chrono.ChQuaternionD(1, 0, 0, 0))
system.Add(turtlebot)

# Create the real-time visualization using Irrlicht
app = irr.ChIrrApp(system, 'Turtlebot Simulation', irr.dimension2du(800, 600))
app.AddTypicalLogo()
app.AddTypicalSky()
app.AddTypicalCamera(irr.vector3df(0, 3, -3))
app.AddTypicalLights()

# Create the simulation loop
while app.GetDevice().run():
    app.BeginScene()
    app.DrawAll()
    app.DoStep()
    app.EndScene()

    # Control the Turtlebot's motors
    time = system.GetChTime()
    if time < 2:
        # Left turn
        turtlebot.SetWvel(chrono.ChVectorD(0, 0, 2))
    elif time < 4:
        # Right turn
        turtlebot.SetWvel(chrono.ChVectorD(0, 0, -2))
    else:
        # Stop
        turtlebot.SetWvel(chrono.ChVectorD(0, 0, 0))

    # Update and render the robot
    system.DoStepDynamics(0.01)
```

In this script, we first initialize the Chrono system and set the gravity. Then, we create a ground body and a Turtlebot body, both with specified dimensions and positions. We add these bodies to the system.

Next, we create a real-time visualization using Irrlicht, which includes setting up the camera and lighting.

Finally, we enter the simulation loop. Inside the loop, we control the Turtlebot's motors based on the simulation time. For the first 2 seconds, the Turtlebot turns left, then for the next 2 seconds, it turns right, and after that, it stops. At each timestep, we update and render the robot using the `DoStepDynamics` function.
