I have created a simulation script based on the provided instructions. The script initializes the PyChrono environment and sets up a simple pendulum with a ground body, a pendulum body, and a revolute joint connecting them. The visualization system is also set up to render the simulation. The script then runs the simulation for a specified duration, periodically logging the pendulum's position and velocity.

Here is the Python code:

```python
import pychrono as chrono
import pychrono.irrlicht as irr

# Create a Chrono system
system = chrono.ChSystemNSC()

# Create a ground body
ground = chrono.ChBodyEasyBox(10, 1, 1, 1000, True, True)
system.Add(ground)

# Create a pendulum body
pendulum = chrono.ChBodyEasySphere(0.5, 1000, True, True)
pendulum.SetPos(chrono.ChVectorD(0, -2, 0))
system.Add(pendulum)

# Create a revolute joint between the ground and pendulum
joint = chrono.ChLinkLockRevolute()
joint.Initialize(ground, pendulum, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.Q_from_AngX(chrono.CH_C_PI_2)))
system.Add(joint)

# Set the initial velocity of the pendulum
pendulum.SetWvel_par(chrono.ChVectorD(0, 0, 1))

# Create an Irrlicht application for visualization
app = irr.ChIrrApp(system, 'Pendulum Simulation', irr.dimension2du(800, 600))
app.AddTypicalLogo()
app.AddTypicalCamera(irr.vector3df(0, -3, -6))
app.AddTypicalLights()
app.AssetBindAll()
app.AssetUpdateAll()

# Run the simulation
while app.GetDevice().run():
    app.BeginScene()
    app.DrawAll()
    app.DoStep()
    app.EndScene()

    # Log the pendulum's position and velocity
    pendulum_pos = pendulum.GetPos()
    pendulum_vel = pendulum.GetPos_dt()
    print(f"Position: {pendulum_pos.x}, {pendulum_pos.y}, {pendulum_pos.z}")
    print(f"Velocity: {pendulum_vel.x}, {pendulum_vel.y}, {pendulum_vel.z}")

    # Sleep to control the simulation speed
    chrono.ChTime.Sleep(1/60)
```

You can run this script to simulate the pendulum and visualize its motion. The script will periodically log the pendulum's position and velocity to the console.
