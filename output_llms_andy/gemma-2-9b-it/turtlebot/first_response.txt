```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize Chrono
chrono.SetChronoData(chrono.CHRONO_DATA_USE_MULTITHREADING)
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create ground body
ground = chrono.ChBodyEasyBox(10, 10, 0.1)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.AddBody(ground)

# Initialize Turtlebot
turtlebot = chrono.ChBodyEasyCylinder(0.3, 0.3, 0.1)
turtlebot.SetPos(chrono.ChVectorD(0, 0, 0.1))
turtlebot.SetRot(chrono.Q_from_Euler(chrono.CH_C_DEGREE, 0, 0))  # Initial orientation
system.AddBody(turtlebot)

# Create visualization
vis.Initialize()
vis.Add(turtlebot)
vis.SetCamera(
    chrono.ChVectorD(2, 2, 2), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0)
)
vis.SetAmbientLight(chrono.ChColor(0.3, 0.3, 0.3))
vis.SetDirectionalLight(chrono.ChColor(0.8, 0.8, 0.8))

# Simulation loop
dt = 0.01
while True:
    # Control Turtlebot motors
    if chrono.GetChTime() > 1:
        turtlebot.SetWvel(chrono.ChVectorD(0.5, 0, 0))  # Rotate right
    elif chrono.GetChTime() > 2:
        turtlebot.SetWvel(chrono.ChVectorD(-0.5, 0, 0))  # Rotate left

    # Update simulation
    system.DoStepDynamics(dt)

    # Render visualization
    vis.Render()

    # Wait for a short time
    chrono.Sleep(dt)

```

**Explanation:**

1. **Initialization:**
   - Import necessary modules: `pychrono` for physics simulation and `pychrono.irrlicht` for visualization.
   - Initialize Chrono with multithreading enabled.
   - Create a Chrono system and set gravity.

2. **Ground and Turtlebot:**
   - Create a rigid ground body using `ChBodyEasyBox`.
   - Create a cylindrical Turtlebot body using `ChBodyEasyCylinder`.
   - Set initial position and orientation for the Turtlebot.
   - Add both the ground and Turtlebot to the Chrono system.

3. **Visualization:**
   - Initialize Irrlicht visualization.
   - Add the Turtlebot to the visualization scene.
   - Set camera position, target, and up direction.
   - Configure ambient and directional lighting.

4. **Simulation Loop:**
   - Set the time step `dt`.
   - Enter a loop that continues indefinitely.
   - **Control Motors:**
     - Implement logic to control the Turtlebot's motors based on time.
     - Here, it rotates right for 1 second and then left for 1 second.
   - **Update Simulation:**
     - Call `system.DoStepDynamics(dt)` to update the physics simulation for each time step.
   - **Render Visualization:**
     - Call `vis.Render()` to render the current state of the simulation.
   - **Wait:**
     - Use `chrono.Sleep(dt)` to pause for the duration of the time step.
