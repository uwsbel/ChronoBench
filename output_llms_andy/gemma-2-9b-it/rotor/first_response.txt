```python
from Chrono import *
from Chrono.irrlicht import *

# Initialize Chrono
ChSystemNSC = ChSystemNSC()

# Create the beam using IGA
beam_data = ChBeamIGA(
    ChVectorD(0, 0, 0),  # Initial position
    ChVectorD(1, 0, 0),  # Initial length
    ChVectorD(0, 0, 0),  # Initial cross-section
    ChVectorD(0, 0, 0),  # Initial cross-section
    ChVectorD(0, 0, 0),  # Initial cross-section
    ChVectorD(0, 0, 0),  # Initial cross-section
    10,  # Number of control points
    10,  # Number of elements
)

# Attach the flywheel to the center of the beam
flywheel = ChBodyEasyCylinder(0.1, 0.1, 10)  # Radius, height, mass
flywheel.SetPos(beam_data.GetPos() + beam_data.GetHalfExtents())
beam_data.AddBody(flywheel)

# Create the motor at one end of the beam
motor = ChMotorRotation(beam_data, ChCoordsys<>(beam_data.GetPos(), Q_from_Euler(0, 0, 0)),
                         ChVectorD(0, 0, 1), 10)  # Axis of rotation, torque

# Add the beam and motor to the system
ChSystemNSC.Add(beam_data)
ChSystemNSC.Add(motor)

# Set up visualization
vis = IrrlichtVisualizer(ChSystemNSC)
vis.SetCameraPos(ChVectorD(2, 2, 2))
vis.SetCameraLookAt(ChVectorD(0, 0, 0))
vis.SetCameraTarget(ChVectorD(0, 0, 0))
vis.AddBody(beam_data)
vis.AddBody(flywheel)
vis.SetFemVisualization(beam_data, True)

# Run the simulation
vis.Start()
while vis.IsRunning():
    ChSystemNSC.DoStepDynamics(0.01)
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules from `Chrono`.
   - Creates a `ChSystemNSC` object, which represents the simulation environment.

2. **Beam Creation:**
   - Uses `ChBeamIGA` to create an IGA beam.
   - Sets initial position, length, and cross-section parameters.
   - Specifies the number of control points and elements for the IGA representation.

3. **Flywheel Attachment:**
   - Creates a `ChBodyEasyCylinder` object to represent the flywheel.
   - Positions the flywheel at the center of the beam.
   - Attaches the flywheel to the beam using `beam_data.AddBody(flywheel)`.

4. **Motor Setup:**
   - Creates a `ChMotorRotation` object to represent the driving motor.
   - Specifies the motor's attachment point (one end of the beam), axis of rotation, and torque.

5. **System Integration:**
   - Adds the beam and motor to the simulation system using `ChSystemNSC.Add()`.

6. **Visualization:**
   - Creates an `IrrlichtVisualizer` object to display the simulation.
   - Sets camera position and orientation for viewing.
   - Adds the beam and flywheel to the visualization.
   - Enables FEM visualization for the beam using `vis.SetFemVisualization(beam_data, True)`.

7. **Simulation Loop:**
   - Starts the visualization loop using `vis.Start()`.
   - In the loop:
     - Advances the simulation by one time step using `ChSystemNSC.DoStepDynamics(0.01)`.
     - Renders the visualization using `vis.Render()`.
