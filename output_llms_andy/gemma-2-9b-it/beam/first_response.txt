```python
from pychrono import ChSystem, ChBody, ChMaterialSurface, ChLinkLock, ChVectorD, ChQuaternionD, ChFunction
from pychrono.irrlicht import IrrlichtVisualizer
import numpy as np

# Initialize PyChrono system
system = ChSystem()

# Define material properties
beam_mat = ChMaterialSurface()
beam_mat.SetYoungModulus(1e9)  # Young's modulus
beam_mat.SetYieldStress(5e8)  # Yield stress
beam_mat.SetDensity(7850)  # Density

# Create nodes
node1 = ChBody(beam_mat)
node1.SetPos(ChVectorD(0, 0, 0))
node1.SetBodyFixed(True)  # Fix node1
system.Add(node1)

node2 = ChBody(beam_mat)
node2.SetPos(ChVectorD(1, 0, 0))
system.Add(node2)

# Create beam element
beam = ChBeam(beam_mat)
beam.SetNodes(node1, node2)
beam.SetCrossSection(ChVectorD(0.1, 0.1))  # Cross-section dimensions
beam.SetLength(1)  # Beam length

system.Add(beam)

# Add visualization
vis = IrrlichtVisualizer(system)
vis.SetCameraPos(ChVectorD(2, 1, 1))
vis.SetCameraTarget(ChVectorD(0, 0, 0))

# Simulation loop
while True:
    system.DoStepDynamics(0.01)
    vis.Render()



```

1. **Initialization:**
   - Imports necessary PyChrono modules.
   - Creates a `ChSystem` object to represent the simulation environment.

2. **Material Definition:**
   - Defines a `ChMaterialSurface` object with properties like Young's modulus, yield stress, and density for the beam elements.

3. **Node Creation:**
   - Creates two `ChBody` objects representing nodes in the beam structure.
   - Sets the initial positions of the nodes.
   - Fixes node1 to the ground using `SetBodyFixed(True)`.
   - Adds both nodes to the system.

4. **Beam Element Creation:**
   - Creates a `ChBeam` object representing the beam element.
   - Assigns the material to the beam.
   - Specifies the nodes connected to the beam.
   - Sets the cross-sectional dimensions and length of the beam.
   - Adds the beam to the system.

5. **Visualization:**
   - Initializes an `IrrlichtVisualizer` object to render the simulation in real-time.
   - Sets the camera position and target for viewing.

6. **Simulation Loop:**
   - Enters a loop that continuously updates the simulation.
   - Calls `system.DoStepDynamics(0.01)` to advance the simulation by a small time step (0.01 seconds).
   - Renders the current state of the simulation using `vis.Render()`.
