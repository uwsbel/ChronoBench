```python
import pychrono as chrono
import chrono.irrlicht as irrlicht
import random

# Initialize Chrono environment
app = chrono.ChSystemNSC()
vis = irrlicht.ChIrrApp(app, 'Gravitational Particle Simulation')

# Create particle emitter
emitter = chrono.ChParticleEmitter()
emitter.SetParticleType(chrono.ChParticle.Type.PARTICLE_SPHERE)
emitter.SetParticleRadius(0.05)
emitter.SetParticleMass(0.1)
emitter.SetParticleLifetime(10)
emitter.SetEmissionRate(100)
emitter.SetEmissionRadius(1)

# Set initial particle properties
emitter.SetParticleVelocity(chrono.ChVectorD(random.uniform(-1, 1), random.uniform(-1, 1), random.uniform(-1, 1)))
emitter.SetParticleOrientation(chrono.Q_from_Euler(random.uniform(0, 2*3.14159), random.uniform(0, 2*3.14159), random.uniform(0, 2*3.14159)))

# Add emitter to the world
app.Add(emitter)

# Set up Irrlicht visualization
vis.AddCamera(chrono.ChVectorD(5, 5, 5))
vis.AddLight(chrono.ChVectorD(10, 10, 10))
vis.SetCamera(vis.GetActiveCamera())
vis.SetTimestep(1/240)

# Define custom gravitational force
def apply_gravitational_force(particle, other_particle):
    distance = chrono.ChVectorD.distance(particle.GetPos(), other_particle.GetPos())
    force = chrono.ChVectorD(0, 0, 0)
    if distance > 0:
        force = chrono.ChVectorD(0, 0, -1) * (particle.GetMass() * other_particle.GetMass()) / (distance**2)
    return force

# Simulation loop
while vis.Run():
    app.DoStepDynamics(1/240)

    # Apply custom gravitational forces
    for particle in app.GetParticleList():
        for other_particle in app.GetParticleList():
            if particle != other_particle:
                force = apply_gravitational_force(particle, other_particle)
                particle.AddForce(force)

    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries: `pychrono`, `chrono.irrlicht`, and `random`.
   - Initializes the Chrono environment (`app`) and Irrlicht visualization (`vis`).

2. **Particle Emitter:**
   - Creates a `ChParticleEmitter` object.
   - Sets particle properties: type (sphere), radius, mass, lifetime, emission rate, and radius.
   - Generates random initial velocities and orientations for particles.

3. **Adding Emitter and Visualization:**
   - Adds the emitter to the Chrono world (`app.Add(emitter)`).
   - Sets up Irrlicht visualization: adds a camera, light, and defines the timestep.

4. **Custom Gravitational Force:**
   - Defines a function `apply_gravitational_force` that calculates the gravitational force between two particles based on their mass and distance.

5. **Simulation Loop:**
   - Runs the simulation until the user closes the window (`vis.Run()`).
   - Performs a timestep (`app.DoStepDynamics(1/240)`).
   - Applies the custom gravitational force to each particle, considering all other particles in the world.
   - Renders the visualization (`vis.Render()`).



**Note:** This script provides a basic framework. You can customize it further by:

- Changing particle properties (shape, size, mass, color).
- Modifying the gravitational force function (e.g., adding damping or different force laws).

- Implementing user controls to manipulate the simulation.
