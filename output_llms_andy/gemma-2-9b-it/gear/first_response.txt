```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize Chrono
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files
system = chrono.ChSystemNSC()

# Create the fixed truss
truss = chrono.ChBodyEasyBox(1.0, 0.5, 0.2, 1000.0)
truss.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(truss)

# Create the rotating bar
bar = chrono.ChBodyEasyCylinder(0.1, 0.5, 1000.0)
bar.SetPos(chrono.ChVectorD(0, 0, 0.3))
bar.SetBodyFixed(False)
system.Add(bar)

# Create the gears
gear1 = chrono.ChBodyEasyCylinder(0.1, 0.1, 1000.0)
gear1.SetPos(chrono.ChVectorD(0.2, 0, 0.5))
gear1.SetBodyFixed(False)
system.Add(gear1)

gear2 = chrono.ChBodyEasyCylinder(0.1, 0.1, 1000.0)
gear2.SetPos(chrono.ChVectorD(0.4, 0, 0.5))
gear2.SetBodyFixed(False)
system.Add(gear2)

# Add gear mesh
gear1_mesh = chrono.ChMeshSphere(0.1)
gear1.AddAsset(gear1_mesh)
gear2_mesh = chrono.ChMeshSphere(0.1)
gear2.AddAsset(gear2_mesh)

# Connect the gears with a joint
gear_joint = chrono.ChLinkLockUniversal(gear1, gear2)
gear_joint.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(gear_joint)

# Add gear motor to enforce constant rotation speed
motor = chrono.ChMotorRotation(chrono.ChCoordsysD(chrono.ChVectorD(0.2, 0, 0.5), chrono.Q_from_Euler123(0, 0, 0)), gear1, chrono.ChVectorD(0, 0, 1), 100)
system.Add(motor)

# Set simulation parameters
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))
system.Set_Step_Size(0.01)
system.Set_Max_Substeps(10)

# Create Irrlicht visualization
vis.InitVisualization()
vis.Add(truss)
vis.Add(bar)
vis.Add(gear1)
vis.Add(gear2)
vis.SetCamera(chrono.ChVectorD(1, 1, 1), chrono.ChVectorD(0, 0, 0))

# Run the simulation
for i in range(1000):
    system.DoStepDynamics()
    vis.Render()

vis.CloseVisualization()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules (`pychrono` and `pychrono.irrlicht`).
   - Initializes the Chrono environment with `chrono.SetChronoDataPath` and creates a new Chrono system (`chrono.ChSystemNSC`).

2. **Physical Systems:**
   - **Fixed Truss:** A box-shaped body (`chrono.ChBodyEasyBox`) is created to represent the fixed truss. It's positioned at the origin and marked as fixed (`SetBodyFixed(True)`).
   - **Rotating Bar:** A cylinder-shaped body (`chrono.ChBodyEasyCylinder`) is created for the rotating bar. It's positioned above the truss and not fixed, allowing it to rotate.
   - **Gears:** Two identical cylinder-shaped bodies (`chrono.ChBodyEasyCylinder`) are created to represent the gears. They're positioned along the bar.
   - **Gear Mesh:** Sphere meshes (`chrono.ChMeshSphere`) are added to the gears for visualization.
   - **Gear Joint:** A universal joint (`chrono.ChLinkLockUniversal`) connects the two gears, allowing them to rotate relative to each other.

3. **Gear Motor:**
   - A rotation motor (`chrono.ChMotorRotation`) is attached to one of the gears (`gear1`) to enforce a constant rotation speed. The motor's axis is aligned with the gear's axis.

4. **Simulation Parameters:**
   - Gravity is set (`system.Set_G_acc`).
   - Simulation time step and maximum substeps are defined (`system.Set_Step_Size` and `system.Set_Max_Substeps`).

5. **Visualization:**
   - Irrlicht visualization is initialized (`vis.InitVisualization`).
   - All physical bodies are added to the visualization system (`vis.Add`).
   - The camera position is set for a good view of the setup.

6. **Simulation Loop:**
   - A loop runs for 1000 steps, updating the simulation dynamics (`system.DoStepDynamics()`) and rendering the visualization (`vis.Render()`).

7. **Closing Visualization:**
   - After the simulation, the Irrlicht visualization is closed (`vis.CloseVisualization()`).
