Sure! Below is a Python script using PyChrono to create the specified simulation:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize the PyChrono environment
chrono.SetChronoDataPath('path/to/chrono/data')  # Set the path to Chrono data

# Create a Chrono::Engine physical system
system = chrono.ChSystemNSC()

# Create the ground (rigid terrain)
ground = chrono.ChBodyEasyBox(10, 0.1, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
ground.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
ground.GetMaterialSurface().SetFriction(0.8)
ground.GetMaterialSurface().SetRestitution(0.2)
system.Add(ground)

# Create the M113 vehicle
vehicle = chrono.vehicle.M113()
vehicle.SetChassisBody(system)
vehicle.SetInitPosition(chrono.ChVectorD(0, 0.5, 0), chrono.ChQuaternionD(1, 0, 0, 0))
vehicle.SetInitState(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 0))

# Initialize the driver system for vehicle control
driver = chrono.vehicle.Driver()
driver.Initialize(vehicle.GetDriveline(), vehicle.GetSteering())

# Create the Irrlicht visualization system
visualization = chronoirr.ChVisualSystemIrrlicht()
visualization.AttachSystem(system)
visualization.SetWindowSize(800, 600)
visualization.SetWindowTitle('M113 Vehicle Simulation')
visualization.Initialize()
visualization.AddTypicalSky()
visualization.AddTypicalLights()
visualization.AddLogo()
visualization.SetCamera(chrono.ChVectorD(5, 5, -5), chrono.ChVectorD(0, 0, 0))

# Set up the simulation loop
step_size = 0.01
max_time = 100  # Simulate for 100 seconds

# Simulation loop
current_time = 0
while current_time < max_time:
    visualization.BeginScene()
    visualization.Render()

    # Synchronize and advance the vehicle, terrain, driver, and visual system
    system.DoStepDynamics(step_size)
    driver.Synchronize(step_size)
    visualization.EndScene()
    current_time += step_size

# Close the visualization
visualization.Close()
```

### Explanation:
1. **Initialization**:
   - The script starts by setting the Chrono data path and creating a `ChSystemNSC` object, which is the core physical system.
2. **Ground (Rigid Terrain)**:
   - A rigid terrain is created using `ChBodyEasyBox` with specified dimensions, mass, and material properties (friction and restitution).
3. **M113 Vehicle**:
   - The M113 vehicle is instantiated and added to the system with initial position and orientation.
4. **Driver System**:
   - A driver system is initialized to control the vehicle.
5. **Visualization**:
   - The Irrlicht visualization system is set up with a camera and lighting.
6. **Simulation Loop**:
   - The simulation runs for a specified duration, advancing the physical system and updating the visualization in real-time.
