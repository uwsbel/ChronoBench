Below is a Python script that demonstrates how to create a PyChrono simulation using beam finite elements. The script initializes the PyChrono environment, sets up the physical system with beam elements, and adds visualization using the Irrlicht engine.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.fem as fem

# Initialize the simulation system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create the Irrlicht visualization system
visualization = chronoirr.ChVisualSystemIrrlicht()
visualization.AttachSystem(system)
visualization.SetWindowSize(1280, 720)
visualization.SetWindowTitle('PyChrono Beam FEM Simulation')
visualization.SetTryFullscreen(False)
visualization.Initialize()
visualization.AddLogo()
visualization.AddSkyBox()
visualization.AddCamera(chrono.ChVectorD(1, 1, 1), chrono.ChVectorD(0, 0, 0))

# Create a mesh of beam finite elements
beam_mesh = fem.ChMesh()
beam_mesh.SetAutomaticGravity(True)

# Create material properties for the beam
beam_material = chrono.ChMaterialShellBeam()
beam_material.SetYoungModulus(210e9)  # Young's modulus (Pa)
beam_material.SetPoissonRatio(0.3)    # Poisson's ratio
beam_material.SetDensity(7800)        # Density (kg/m^3)

# Create beam elements and nodes
num_elements = 10
length = 1.0
beam_elements = []

for i in range(num_elements):
    beam_element = fem.ChElementBeam()
    beam_element.SetMaterial(beam_material)
    beam_element.SetLength(length / num_elements)
    beam_element.SetCrossArea(0.01)  # Cross-sectional area (m^2)
    beam_element.SetJ(0.0001)        # Moment of inertia (m^4)
    beam_element.SetE(210e9)         # Young's modulus (Pa)
    beam_element.SetG(80e9)          # Shear modulus (Pa)
    beam_element.SetRho(7800)        # Density (kg/m^3)

    node1 = fem.ChNodeFEAxy()
    node1.SetPos(chrono.ChVectorD(i * length / num_elements, 0, 0))
    beam_mesh.AddNode(node1)

    node2 = fem.ChNodeFEAxy()
    node2.SetPos(chrono.ChVectorD((i + 1) * length / num_elements, 0, 0))
    beam_mesh.AddNode(node2)

    beam_element.AddNode(node1)
    beam_element.AddNode(node2)
    beam_mesh.AddElement(beam_element)
    beam_elements.append(beam_element)

# Add the mesh to the system
system.Add(beam_mesh)

# Set up the simulation parameters
system.SetTimestepperType(chrono.ChTimestepper.HYBRID)
system.SetSolverType(chrono.ChSolver.MINRES)

# Run the simulation loop
while visualization.Run():
    system.DoStepDynamics(0.01)

# Clean up
visualization.Close()
```

This script initializes a PyChrono simulation with a mesh of beam finite elements. It sets up the material properties for the beams and creates nodes and beam elements. The simulation is visualized in real-time using the Irrlicht engine. The simulation loop runs with a time step of 0.01 seconds.
