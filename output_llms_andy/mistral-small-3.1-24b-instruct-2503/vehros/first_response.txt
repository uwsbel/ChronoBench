Here is a PyChrono simulation script that meets the specified requirements:

```python
import pychrono.core as chrono
import pychrono.vehicle as veh
import pychrono.ros as ros_interface
import rospy
from std_msgs.msg import String

# Initialize the Chrono::Engine
chrono.SetChronoDataPath('path/to/chrono/data')

# Create a Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the HMMWV vehicle
vehicle = veh.HMMWV()
vehicle.Init()
vehicle.SetChassisBodyFixed(False)
vehicle.SetInitPosition(chrono.ChVectorD(0, 0, 0.5))
vehicle.SetInitOrientation(chrono.ChQuaternionD(1, 0, 0, 0))
vehicle.SetTireForceHandler(veh.ChTireHandlerList(veh.ChTireHandlerList.Type.TMEASY))
vehicle.SetDriver(veh.ChDriverVehicleBase())
vehicle.SetEngineModel(veh.ChEngineSimpleMap)
vehicle.SetTransmissionModel(veh.ChSimpleTransmission)

# Create the terrain
terrain = veh.ChTerrain()
terrain.Initialize(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(100, 100, 0))
terrain.SetContactMaterial(chrono.ChMaterialSurfaceNSC())
terrain.GetContactMaterial().SetFriction(0.9)
terrain.GetContactMaterial().SetRestitution(0.2)
terrain.AddVisualizationMesh(chrono.ChTriangleMeshConnected())
terrain.GetTriangleMesh().LoadWavefrontMesh('path/to/terrain.obj')
terrain.GetTriangleMesh().Transform(chrono.ChVectorD(0, 0, 0), chrono.ChMatrix33D(1))

# Add the vehicle and terrain to the system
system.Add(vehicle)
system.Add(terrain)

# Initialize ROS
rospy.init_node('chrono_vehicle_simulation', anonymous=True)

# Create ROS manager
ros_manager = ros_interface.ChRosManager()
ros_manager.Initialize(system)

# Register ROS handlers
ros_manager.RegisterClockHandler()
ros_manager.RegisterDriverInputHandler()
ros_manager.RegisterVehicleStateHandler(vehicle)

# Simulation parameters
step_size = 0.01
end_time = 10.0

# Simulation loop
current_time = 0.0
while current_time < end_time:
    # Advance the simulation
    system.DoStepDynamics(step_size)

    # Update ROS manager
    ros_manager.Synchronize(step_size)
    ros_manager.Publish()

    # Increment time
    current_time += step_size

# Clean up
ros_manager.Finalize()
```

### Explanation:
1. **Initialization**:
   - The Chrono environment is initialized with the correct data path.
   - A Chrono system is created and gravity is set.

2. **Vehicle Setup**:
   - An HMMWV vehicle is created and initialized.
   - The vehicle's chassis is set to be non-fixed.
   - The vehicle's initial position and orientation are set.
   - The tire force handler is set to TMEASY.
   - A simple engine and transmission model are assigned.

3. **Terrain Setup**:
   - A terrain is created and initialized.
   - Contact material properties (friction and restitution) are set.
   - A visualization mesh for the terrain is loaded from an OBJ file.

4. **ROS Integration**:
   - ROS is initialized.
   - A ROS manager is created and initialized with the Chrono system.
   - Handlers for clock synchronization, driver inputs, and vehicle state are registered.

5. **Simulation Loop**:
   - The simulation runs for a specified duration, advancing the system at each timestep.
   - The ROS manager is synchronized and data is published at each timestep.

### Notes:
- Ensure that the paths to the Chrono data and terrain OBJ file are correctly specified.
- This script assumes that the necessary ROS packages and dependencies are installed and configured.
