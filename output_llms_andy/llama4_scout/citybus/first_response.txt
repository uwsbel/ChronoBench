### PyChrono Simulation Script: CityBus on Rigid Terrain

```python
import chrono as ch
import chrono.irrlicht as irr
import math

# Initialize PyChrono environment
ch.CHORKERN.SetChVerbose(True)

# Create the Chrono systems
system = ch.ChSystem()

# Create the Irrlicht application
app = irr.ChIrrApp(system, 'CityBus Simulation', irr.DIM_2D)

# Create the CityBus vehicle
citybus = ch.ChVehicle()

# Define vehicle parameters
vehicle_mass = 12000  # kg
vehicle_COM = ch.ChVector(0, 0, 0.5)  # Center of Mass

# Create vehicle chassis
chassis_body = ch.ChBody()
chassis_body.SetMass(vehicle_mass)
chassis_body.SetPos(vehicle_COM)
chassis_body.SetRot(ch.ChQuaternion(1, 0, 0, 0))
system.AddBody(chassis_body)

# Create and add wheels
wheel_radius = 0.5
for i in range(4):
    wheel = ch.ChBody()
    wheel.SetMass(100)
    wheel.SetPos(ch.ChVector(0, 0, wheel_radius))
    system.AddBody(wheel)

# Create and add tire models
tire_model = ch.ChTire()
tire_model.SetTireMass(20)
tire_model.SetTireRadius(wheel_radius)
system.AddTire(tire_model)

# Create and add suspension
suspension = ch.ChLinkTSDA()
suspension.SetSpringConstant(10000)
suspension.SetDampingCoefficient(500)
system.AddLink(suspension)

# Create rigid terrain
terrain = ch.ChRigidTerrain(system)
terrain.SetTerrainFile('terrain.obj')
terrain.SetTextureFile('terrain_texture.jpg')
terrain.AddVisualizationAssets(terrain)

# Create interactive driver system
driver = ch.ChDriver()
driver.SetSteering(0.5)
driver.SetThrottle(0.2)
driver.SetBraking(0.1)
system.AddDriver(driver)

# Set visualization
chassis_body.AddVisualizationAsset(ch.ChVisualShapeBox(5, 2, 1))
for i in range(4):
    wheel.AddVisualizationAsset(ch.ChVisualShapeSphere(wheel_radius))

# Set camera
camera = app.GetCamera()
camera.SetPosition(ch.ChVector(0, -10, 5))
camera.SetTarget(ch.ChVector(0, 0, 0))

# Simulation loop
app.SetTimestep(0.02)
app.SetFrameRate(50)

while app.Run():
    system.Update()
    app.Render()
    app.Screenshot('citybus_simulation.png')
```

### Explanation

The provided Python script simulates a CityBus vehicle on a rigid terrain using PyChrono and Irrlicht for visualization. The script initializes the PyChrono environment, creates the necessary physical systems and objects, sets default parameters, and implements an interactive driver system.

The script starts by importing the necessary modules and initializing the PyChrono environment. It then creates a Chrono system and an Irrlicht application.

The CityBus vehicle is created and its parameters, such as mass and center of mass, are defined. The vehicle chassis, wheels, tire models, and suspension are created and added to the system.

A rigid terrain is created with a custom texture, and an interactive driver system is implemented to control the vehicle's steering, throttle, and braking.

The script sets the visualization for the vehicle parts using a combination of mesh and primitive visualization types. The camera is set to follow the vehicle from a specified position.

The simulation loop runs at 50 frames per second, updating the vehicle dynamics and rendering the scene in real-time. The simulation can be controlled using the Irrlicht application's run loop.

### Usage

1. Save the script as `citybus_simulation.py`.
2. Install the required dependencies, including PyChrono and Irrlicht.
3. Run the script using `python citybus_simulation.py`.
4. Use the Irrlicht application's controls to interact with the simulation.

Note: Make sure to replace the `terrain.obj` and `terrain_texture.jpg` files with your own terrain and texture files.
