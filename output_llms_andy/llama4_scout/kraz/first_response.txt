### PyChrono Simulation Script

```python
import chrono as ch
import chrono.irrlicht as irr

# 1. Initialize the PyChrono environment and core components
ch.CH_INIT()

# 2. Create the simulation system
system = ch.ChSystem()

# 3. Create a rigid terrain
terrain = ch.ChTerrain()
terrain.SetGridSize(100, 100)
terrain.SetGridSpacing(1, 1)
terrain.SetFriction(0.8)
terrain.SetRestitution(0.3)
terrain.Initialize()

# Add terrain to the system
system.Add(terrain.GetGroundBody())

# 4. Create a Kraz vehicle
vehicle = ch.ChVehicle()

# Assuming a Kraz vehicle model is available and loaded correctly
# For demonstration, we'll use a simple body
body = ch.ChBody()
body.SetPos(ch.ChVector3d(0, 0, 1))
body.SetMass(1000)
system.Add(body)

# 5. Initialize a driver system for vehicle control
driver = ch.ChDriver()
driver.Initialize(vehicle)

# 6. Create a real-time visualization using Irrlicht
vis = irr.ChIrrApp(system, 'Kraz Vehicle Simulation', irr.dimension2D(800, 600))
vis.SetCameraVertical(irr.ChVector3d(0, -1, 0.5))
vis.SetCameraTarget(irr.ChVector3d(0, 0, 0.5))
vis.EnableShadows()
vis.EnableSun(irr.ChSun())

# 7. Simulation loop
while vis.Run():
    vis.PrepareTimestep()
    system.DoStepDynamics(0.02)
    vis.EndTimestep()
```

### Explanation

This script initializes a basic PyChrono simulation featuring a Kraz vehicle (simplified as a single body for demonstration) on a rigid terrain with specified friction and restitution. It sets up a driver system for vehicle control and creates a real-time visualization using Irrlicht. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep.

### Notes

- Ensure you have a Kraz vehicle model loaded and correctly integrated into the simulation.
- Adjust parameters (e.g., friction, restitution, mass) according to your specific requirements.
- This script assumes a basic understanding of PyChrono and its components.
