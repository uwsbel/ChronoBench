### 2. Correctness (30 points)

- **API Usage:**  
  - The vehicle is created and configured correctly with contact method, collision type, tire model, visualization types, and system collision type.  
  - Terrain is initialized with soil parameters and height map correctly.  
  - Obstacles are created with proper size, density, collision, and visualization flags.  
  - Visualization system is properly initialized and attached.  
  - Sensor manager and Lidar sensor are created with correct parameters and added properly.  
  - Driver is set up with reasonable deltas and initialized.  
  - Simulation loop calls synchronization and advance methods in correct order.  
  - Real-time timer is used correctly.

- **Potential Issues:**  
  - The line `vehicle.GetSystem().SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)` is called **after** vehicle initialization. According to best practices, collision system type should be set **before** system initialization to take effect properly. Changing collision system type after initialization may have no effect or cause inconsistencies. This is a significant correctness issue.  
  - The `lidar.SetVisualizationFilters()` call uses constants `chrono.ChLidarSensor.RESOLUTION`, `RANGE`, and `RETURN_TYPE`. These constants are typically bit flags and should be combined with bitwise OR (`|`) rather than passed as separate arguments. Passing them as separate arguments may not work as intended. This is a correctness issue.  
  - The obstacles are placed at random positions in x and y between -10 and 10, but z is fixed at 0.5. Given the terrain height and vehicle initial height, this might cause obstacles to be partially embedded or floating. Not a critical error but could cause unexpected behavior.  
  - The `chrono.SetChronoDataPath(chrono.GetChronoDataPath())` call is redundant but not incorrect.

**Deductions:**  
- Collision system type set after initialization: -15 points (significant).  
- Incorrect usage of `SetVisualizationFilters` (should combine flags): -10 points.  
- Minor logical issue with obstacle placement height: -5 points.
