### PyChrono Simulation Script: M113 Vehicle on Rigid Terrain

```python
import chrono as ch
import chrono.irrlicht as irr

# 1. Initialize the PyChrono environment and core components
ch.ChEngine.Initialize()

# 2. Create the M113 vehicle
vehicle = ch.ChM113()

# Set initial conditions for the vehicle
vehicle.SetChassisPos(ch.ChVector3d(0, 0, 1.5))

# 3. Create a rigid terrain
terrain = ch.ChTerrain()
terrain.SetGridSize(200, 200)
terrain.SetPos(ch.ChVector3d(0, 0, 0))
terrain.SetFriction(0.8)
terrain.SetRestitution(0.3)

# 4. Initialize a driver system for vehicle control
driver = ch.ChDriver(vehicle)
driver.SetSteeringType(ch.ChSteeringType_SHAFT_ANGLE)
driver.SetThrottleType(ch.ChThrottleType_TORQUE_INPUT)

# 5. Create a real-time visualization using Irrlicht
vis = irr.ChIrrApp(vehicle, 'M113 Vehicle Simulation', irr.dimension2D(800, 600), False)

# Set up camera and lighting
vis.SetCameraVertical(ch.ChVector3d(0, -1, 0.5))
vis.SetCameraTarget(vehicle.GetPos())
vis.EnableSun()

# 6. Simulation loop
while vis.Run():
    # Synchronize and advance the vehicle and terrain
    vehicle.Advance(0.02)
    terrain.Advance(0.02)
    
    # Synchronize and advance the driver
    driver.Advance(0.02)
    
    # Render the visual system
    vis.Synchronize('', 0)
    vis.Render(0.02)

# Clean up
ch.ChEngine.Terminate()
```

### Explanation

This script initializes a PyChrono simulation featuring an M113 vehicle on a rigid terrain with specified initial conditions and visualization settings. 

1.  **Environment Initialization**: The PyChrono environment and core components are initialized.
2.  **Vehicle Creation**: An M113 vehicle is created and positioned.
3.  **Terrain Setup**: A rigid terrain with defined friction and restitution is created.
4.  **Driver System**: A driver system for vehicle control is initialized.
5.  **Visualization**: A real-time visualization using Irrlicht is set up with camera settings and lighting.
6.  **Simulation Loop**: The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.

### Usage

To run this script, ensure you have PyChrono installed. Save this code in a `.py` file and execute it using Python. The simulation will display in a window, showing the M113 vehicle on the terrain. You can control the vehicle using the driver system. The simulation will run in real-time, updating at each timestep.
