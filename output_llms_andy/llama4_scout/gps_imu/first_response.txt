### PyChrono Simulation Script

Below is a Python script that sets up a PyChrono simulation as per your instructions. This script initializes the PyChrono environment, sets up an HMMWV vehicle, adds terrain, driver inputs, visual interface, IMU, and GPS sensors, and runs a simulation loop.

```python
import chrono as ch
import chrono.irrlicht as irr
import math

# Initialize PyChrono environment
ch.utils.ChUtils.print_versions()
ch.set_default_G_acc(9.81)

# Create the HMMWV vehicle
veh = ch.WheeledVehicle(ch.ChCoordsysD(0, 0, 1), "HMMWV")
veh.Initialize(ch.ChCoordsysD(0, 0, 1))

# Create the terrain
terrain = ch.terrain.GroundPlane()
terrain.SetVisualShape(ch.ChVisualShapeBox(100, 100, 0.1, ch.ChColor(0.5, 0.5, 0.5)))

# Create the driver inputs
driver = ch.vehicle.ChDriver(veh)
driver.SetThrottleInputMode(ch.vehicle.DRIVER_THROTTLE_RAMP)
driver.SetSteeringInputMode(ch.vehicle.DRIVER_STEERING_RAMP)

# Create the visual system
vis = irr.ChVisualSystemIrrlicht()
vis.AttachVehicle(veh)
vis.SetCameraLocation(ch.ChVectorD(0, -10, 2))

# Add IMU and GPS sensors
imu = ch.vehicle.ChIMU(veh.GetChassis())
gps = ch.vehicle.ChGPS(veh.GetChassis())

# Simulation loop
while vis.Run() and not vis.ExitRequested():
    # Advance the vehicle, terrain, and driver
    veh.Update(0.01)
    driver.Update(0.01)
    terrain.Update(0.01)

    # Update sensor data
    imu.Update(0.01)
    gps.Update(0.01)

    # Output vehicle mass
    print("Vehicle Mass: ", veh.GetMass())

    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Advance time
    ch.ChGlobals.IncrementSimulationTime(0.01)

# Clean up
del veh
del terrain
del driver
del vis
del imu
del gps
```

### Explanation

The provided Python script initializes a PyChrono simulation featuring an HMMWV vehicle. The simulation includes a full system setup with terrain, driver inputs, and a visual interface using Irrlicht. IMU and GPS sensors are attached to the vehicle's chassis, and their data is processed and updated at each simulation step. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system modules while outputting the vehicle mass and rendering scenes.

### Usage

1. Ensure you have PyChrono installed and configured properly.
2. Save the script to a file (e.g., `hmmwv_simulation.py`).
3. Run the script using Python (e.g., `python hmmwv_simulation.py`).
4. The simulation will start, and you can observe the HMMWV vehicle on the terrain with IMU and GPS sensors providing data.
5. Press the 'Esc' key to exit the simulation.

### Notes

* This script assumes that the HMMWV vehicle model and required data are available in the PyChrono installation.
* You may need to adjust the simulation parameters (e.g., time step, simulation duration) based on your specific requirements.
* The visual interface and sensor data output can be customized as needed.
