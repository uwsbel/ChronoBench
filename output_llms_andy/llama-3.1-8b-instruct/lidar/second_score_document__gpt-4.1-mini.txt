  The code uses `chrono.ChFramed` to define sensor offset poses. According to the PyChrono API, the class is `ChFrame` or `ChCoordsys` (or `ChCoordsysD` in C++). `ChFramed` is not a standard PyChrono class or constructor.  
  ```python
  chrono.ChFrameD(chrono.ChVector3d(...), chrono.ChQuaternionD(...))
  ```  
  or  
  ```python
  chrono.ChCoordsysD(chrono.ChVector3d(...), chrono.ChQuaternionD(...))
  ```  
  This is a critical error that will prevent the code from running correctly.
