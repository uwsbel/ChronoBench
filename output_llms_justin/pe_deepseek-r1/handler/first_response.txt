Here's a PyChrono simulation integrated with ROS that meets your requirements. The script creates a physical simulation with a floor and movable box, and publishes integer messages via a custom ROS handler:

```python
import pychrono as chrono
import pychrono.ros as chros
import rospy
from std_msgs.msg import Int32

# Custom ROS handler for publishing integer messages
class CustomIntPublisher(chros.ChROSHandler):
    def __init__(self, topic_name):
        super().__init__()
        self.topic_name = topic_name
        self.publisher = None
        self.counter = 0

    def Initialize(self):
        if not rospy.get_node_uri():
            rospy.init_node('pychrono_node', anonymous=True)
        self.publisher = rospy.Publisher(self.topic_name, Int32, queue_size=10)
        return True

    def Publish(self, time):
        msg = Int32()
        msg.data = self.counter
        self.publisher.publish(msg)
        self.counter += 1
        return True

def main():
    # Initialize Chrono system
    system = chrono.ChSystemNSC()
    system.SetGravitationalAcceleration(chrono.ChVector3d(0, 0, -9.81))

    # Create contact material with specified properties
    material = chrono.ChContactMaterialNSC()
    material.SetFriction(0.4)
    material.SetRestitution(0.1)

    # Create fixed floor
    floor = chrono.ChBodyEasyBox(20, 20, 1, 1000, True, True, material)
    floor.SetPos(chrono.ChVector3d(0, 0, -1))
    floor.SetFixed(True)
    system.Add(floor)

    # Create movable box
    box = chrono.ChBodyEasyBox(1, 1, 1, 1000, True, True, material)
    box.SetPos(chrono.ChVector3d(0, 0, 2))
    system.Add(box)

    # Initialize ROS manager
    ros_manager = chros.ChROSPyManager()
    ros_manager.RegisterHandler(chros.ChROSClockHandler())
    ros_manager.RegisterHandler(chros.ChROSBodyHandler(ros_manager, box, "box"))
    ros_manager.RegisterHandler(chros.ChROSTFHandler(ros_manager, 100))
    
    # Add custom integer publisher
    int_publisher = CustomIntPublisher("pychrono_counter")
    ros_manager.RegisterHandler(int_publisher)

    # Initialize ROS
    if not ros_manager.Initialize():
        print("ROS initialization failed!")
        return

    # Simulation loop
    time_step = 0.01
    realtime_step = True
    frame_interval = 0.01  # ROS update interval (10ms)

    while ros_manager.NodeOK():
        # Advance simulation
        system.DoStepDynamics(time_step)
        
        # Update ROS communication
        ros_manager.Update(system.GetChTime(), realtime_step)
        
        # Maintain real-time execution
        if realtime_step:
            ros_manager.SpinSome(frame_interval)

if __name__ == "__main__":
    main()
```

### Key Components Explained:

1. **ROS Integration**:
   - `ChROSPyManager` handles ROS communication
   - Custom `ChROSHandler` publishes integer messages
   - Built-in handlers for clock, body state, and transforms

2. **Physical Setup**:
   - NSC system with Earth gravity
   - Fixed floor (20x20x1 box at z=-1)
   - Movable box (1x1x1 box at z=2)
   - Contact material with friction/restitution properties

3. **ROS Features**:
   - Publishes integer counter on `pychrono_counter` topic
   - Tracks box position via `ChROSBodyHandler`
   - Maintains simulation-realtime synchronization
   - Provides TF transforms for visualization

4. **Execution Flow**:
   1. Initialize Chrono system and bodies
   2. Configure ROS manager and handlers
   3. Simulation loop with fixed timestep
   4. ROS updates synchronized with physics
   5. Real-time execution management

### Usage Instructions:
1. Run with ROS environment sourced:
```bash
source /opt/ros/<distro>/setup.bash
python3 chrono_ros_demo.py
```

2. Monitor published data:
```bash
rostopic echo /pychrono_counter
rostopic echo /chrono/box/pose
```

3. Visualize in RViz:
   - Add TF display to see box position
   - Add Marker display for floor/box visualization

This implementation maintains real-time synchronization between the physics simulation and ROS communication while providing the required messaging functionality. The counter increments with each physics step, demonstrating the custom ROS handler integration.
