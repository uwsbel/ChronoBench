### 2. Correctness (30 points)

- **Use of `ChContactMaterialNSC` in `ChBodyEasySphere`:**  
  The constructor of `ChBodyEasySphere` expects a material pointer for contact material. The code passes `sphere_mat` which is a `ChContactMaterialNSC()` instance. However, according to PyChrono API, `ChBodyEasySphere` expects a `ChMaterialSurface` or derived pointer, not a `ChContactMaterialNSC` directly. Usually, one creates a `ChMaterialSurfaceNSC` or similar and passes that. This is a significant API misuse that can lead to incorrect contact behavior.  
  **-15 points**

- **Collision System Access:**  
  The code calls `coll = sys.GetCollisionSystem()`. According to the API, `GetCollisionSystem()` returns the collision system interface, but binding items to it is unusual and not documented. Usually, collision is handled internally by the system and bodies. The use of `self.coll.BindItem(body)` in the callback is suspicious and likely incorrect or unnecessary.  
  **-10 points** (logical error / incorrect API usage)
