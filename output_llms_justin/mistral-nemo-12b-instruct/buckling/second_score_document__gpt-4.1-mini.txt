This is a significant API misuse and could cause runtime errors or unexpected behavior.
- **Visual Shapes:** `chrono.ChVisualShapeBox` is constructed with three floats, but the API documentation shows it expects a `chrono.ChVector3d` for size. The code uses `chrono.ChVisualShapeBox(0.03, 0.25, 0.12)`, which is likely incorrect; it should be `chrono.ChVisualShapeBox(chrono.ChVector3d(0.03, 0.25, 0.12))`. This is a significant API misuse.
