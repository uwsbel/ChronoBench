### 2. Correctness (30 points)

- **Gravity setting:**

  - This could cause unexpected behavior or be ignored.  
  - Deduct **15 points** for incorrect API usage that affects simulation behavior.

- **Use of `CH_PI`:**  
  - Defined as `3.1456` instead of the more accurate `3.141592653589793`. While this is a minor numerical inaccuracy, it can affect precision in geometry calculations.  
  - Deduct **5 points** for minor inaccuracy.

- **Joint initialization:**  
  - `myjoint.Initialize(node_mid, mbodyflywheel)` is called without a frame argument. According to the API, `Initialize` requires two bodies and a frame (`chrono.ChCoordsysD`). Omitting the frame is a logical error and will likely cause an exception or incorrect joint setup.  
  - Deduct **10 points** for logical error in joint initialization.

- **Bearing joint:**  
  - `chrono.ChLinkMateGeneric(False, True, True, False, True, True)` is initialized with `builder.GetLastBeamNodes().back()` and `truss`. The first argument should be a `ChBody` or `ChPhysicsItem`, but `builder.GetLastBeamNodes().back()` returns a node, not a body.  
  - This is a misuse of the API and will cause errors.  
  - Deduct **15 points** for incorrect API usage.

- **Motor joint:**  
  - `rotmotor1.SetMotorFunction(f_ramp)` is called, but the correct method name per API is `SetSpeedFunction()`.  
  - Deduct **15 points** for incorrect API usage.

- **Use of `chrono.VECT_Y` and `chrono.VECT_Z`:**  
  - These constants are not standard in PyChrono Python API; the correct usage is `chrono.ChVectorD(0,1,0)` or `chrono.VECT_Y` might be defined in C++ but not necessarily in Python.  
  - However, this is minor and may work if defined elsewhere, so no deduction.

- **Use of `m.floor(builder.GetLastBeamNodes().size() / 2.0)`:**  
  - `builder.GetLastBeamNodes()` returns a Python list, which uses `len()` not `.size()`.  
  - This will cause an AttributeError.  
  - Deduct **15 points** for incorrect Python API usage.

- **`sys.DoStaticLinear()` call:**  
  - This is a static solver call, but the system is set up for dynamic simulation with motors and visualization loop.  
  - Calling static solver here is inconsistent and unnecessary.  
  - Deduct **5 points** for unnecessary or inconsistent API call.
