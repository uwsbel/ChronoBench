```python
import pychrono as chrono
import pychrono.robot as viper
import pychrono.irrlicht as chronoirr

# Set the Chrono data path
chrono.SetChronoDataPath(chrono.GetChronoDataPath())

# Create the Chrono system with gravity
system = chrono.ChSystemSMC()
system.SetGravitationalAcceleration(chrono.ChVector3d(0, -9.81, 0))

# Create the ground body
ground = chrono.ChBody()
ground.SetPos(chrono.ChVector3d(0, -1, 0))
ground.SetFixed(True)
ground.GetCollisionModel().ClearModel()
ground.GetCollisionModel().AddBox(20, 1, 20)  # Dimensions: length, height, width
ground.SetCollide(True)

# Add visualization for the ground
ground_shape = chrono.ChVisualShapeBox(20, 1, 20)
ground_shape.SetColor(chrono.ChColor(0, 1, 0))  # Green color
ground.AddVisualShape(ground_shape)
system.Add(ground)

# Initialize the Viper rover
rover = viper.Viper(system)
rover.Initialize(chrono.ChCoordsysD(chrono.ChVector3d(0, 0.5, 0), chrono.QUNIT))  # Start above ground

# Create and set the driver
driver = viper.ViperDriver()
rover.SetDriver(driver)

# Set throttle to a constant value (e.g., 0.5 for half throttle)
driver.SetThrottle(0.5)

# Setup Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('Viper Rover on Rigid Terrain')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(0, 2, -3))  # Camera position
vis.AddTypicalLights()

# Simulation loop parameters
time_step = 0.01
end_time = 10.0
steering_amplitude = 0.5  # Maximum steering angle (radians)

# Simulation loop
while vis.Run():
    current_time = system.GetChTime()
    
    # Gradually increase steering over time (linear from 0 to max)
    if current_time < end_time:
        steering = steering_amplitude * (current_time / end_time)
        driver.SetSteering(steering)
    
    # Update rover and visualization
    rover.Update()
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    
    # Advance simulation
    system.DoStepDynamics(time_step)
```

### Explanation:

1. **System Initialization**:
   - A `ChSystemSMC` is created for smooth contact handling.
   - Gravity is explicitly set to standard Earth gravity.

2. **Ground Setup**:
   - A large box represents the rigid terrain.
   - Collision and visualization shapes are added for interaction and rendering.

3. **Viper Rover**:
   - The rover is initialized at a safe height (0.5m) to avoid initial penetration.
   - A `ViperDriver` controls the rover, with constant throttle and time-dependent steering.

4. **Visualization**:
   - Irrlicht is configured with a camera, lighting, and a green-colored terrain.

5. **Simulation Loop**:
   - Steering angle increases linearly from 0 to 0.5 radians over 10 seconds.
   - The loop updates the rover's state, renders the scene, and steps the simulation.

This script creates a realistic simulation of the Viper rover navigating a rigid terrain with dynamic steering control, visualized in real-time using Irrlicht.
