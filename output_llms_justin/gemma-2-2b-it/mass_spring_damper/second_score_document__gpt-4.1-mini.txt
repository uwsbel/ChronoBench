### 2. Correctness (30 points)

- **Force Functor Implementation:**  
  The `computeForce` method is supposed to compute the spring force based on the relative position vector and velocity (for damping). The current implementation:

  ```python
  force = self.spring_coef * (relative_pos - chrono.ChVector3d(0, 0, 0))
  force *= self.damping_coef
  return force
  ```

  Issues:  
  - The force is computed as spring_coef * relative_pos (which is a vector), but the spring force should be proportional to the displacement from rest length along the spring axis, not just the relative position vector.  
  - Damping force should depend on relative velocity, but the functor does not receive velocity information.  
  - Multiplying the spring force by damping coefficient directly is incorrect.  
  - The API expects the force functor to compute the force based on the current spring length relative to rest length and relative velocity, but this is not done.

  This incorrect force calculation will significantly affect simulation behavior.
