```python
# Import necessary libraries
from pychrono import *
from pychrono.irrlicht import IrrlichtDevice
from pychrono.irrlicht.irrlicht import irrlicht_engine
from pychrono.irrlicht.irrlicht import irrlicht_camera
from pychrono.irrlicht.irrlicht import irrlicht_gui
from pychrono.irrlicht.irrlicht import irrlicht_scene
from pychrono.irrlicht.irrlicht import irrlicht_video_output

# Initialize PyChrono
chrono.init()

# Create Irrlicht device
device = IrrlichtDevice("IrrlichtDemo")
engine = irrlicht_engine(device)

# Create Irrlicht scene
scene = irrlicht_scene(engine)
camera = irrlicht_camera(engine, (100, 100), (0, 0, 0))
gui = irrlicht_gui(engine)

# Define vehicle parameters
vehicle_mass = 2000.0
vehicle_length = 4.0
vehicle_width = 2.0
vehicle_height = 1.5
vehicle_center_of_mass = (vehicle_length / 2, vehicle_width / 2, vehicle_height / 2)

# Define tire parameters
tire_radius = 0.5
tire_mass = 10.0

# Create vehicle object
vehicle = Vehicle(vehicle_mass, vehicle_length, vehicle_width, vehicle_height, vehicle_center_of_mass)

# Create tire objects
tire_left = Tire(tire_radius, tire_mass, vehicle.position, vehicle.orientation)
tire_right = Tire(tire_radius, tire_mass, vehicle.position, vehicle.orientation)

# Create a SCM terrain object
terrain = SCMTerrain(soil_parameters)

# Initialize SCM terrain with a moving patch feature
terrain.enable_moving_patch(vehicle.position, vehicle.orientation)

# Set up a sinkage visualization
terrain.enable_sinkage_visualization(color_scheme=(0, 0, 255))

# Configure the driver system
driver_system = DriverSystem(vehicle)

# Set up the simulation loop
while engine.running():
    # Update vehicle dynamics
    driver_system.update(engine.get_time())

    # Update vehicle position and orientation
    vehicle.update(driver_system.position, driver_system.orientation)

    # Update tire position and orientation
    tire_left.update(vehicle.position, vehicle.orientation)
    tire_right.update(vehicle.position, vehicle.orientation)

    # Update SCM terrain
    terrain.update(vehicle.position, vehicle.orientation)

    # Render the scene
    engine.render()

    # Update the display
    engine.update()
```

**Explanation:**

1. **Initialization:** The script begins by importing necessary libraries and initializing PyChrono.
2. **Irrlicht Setup:** It creates an Irrlicht device and engine, sets up a scene, and initializes a camera and GUI.
3. **Vehicle Definition:**  Defines the vehicle parameters like mass, length, width, height, and center of mass. 
4. **Tire Model:** Creates tire objects with their respective parameters.
5. **Terrain Creation:** Creates a SCM terrain object with soil parameters.
6. **Terrain Customization:** Enables a moving patch feature for the terrain, allowing it to dynamically adapt to the vehicle's movement.
7. **Sinkage Visualization:** Enables sinkage visualization to display the deformation of the terrain under the vehicle.
8. **Driver System:** Initializes a driver system for controlling the vehicle's steering, throttle, and braking.
9. **Simulation Loop:** The main simulation loop iterates through time, updating vehicle dynamics, rendering the scene, and handling user input.

**Note:** 

* This is a basic framework and needs to be further developed with specific soil properties, driver controls, and visualization elements.
* You will need to install PyChrono, Irrlicht, and other necessary libraries.
* You can modify the vehicle parameters, terrain properties, and driver system behavior to achieve the desired simulation.
