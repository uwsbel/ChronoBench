```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht

# Initialize PyChrono
chrono.init()

# Create Irrlicht environment
engine = irrlicht.IrrlichtEngine()
engine.createWindow("HMMWV Simulation", 800, 600)
engine.run()

# Create a RigidTerrain
terrain = chrono.RigidTerrain()
terrain.setDimensions(10, 10, 0.1)
terrain.setTexture("terrain.jpg")
terrain.setFriction(0.5)

# Create a HMMWV
vehicle = chrono.Vehicle()
vehicle.setName("HMMWV")
vehicle.setMass(1500)
vehicle.setCenterOfMass(chrono.Vector3(0, 0, 0))

# Set TMEASY tire model
vehicle.setTireModel(chrono.TireModel.TMEASY)

# Define vehicle parameters
vehicle.setWheelRadius(0.2)
vehicle.setWheelBase(2.5)
vehicle.setWheelCount(4)
vehicle.setContactMethod(chrono.ContactMethod.CONTACT)

# Set initial position and orientation
vehicle.setPosition(chrono.Vector3(0, 0, 0))
vehicle.setOrientation(chrono.Quaternion(0, 0, 0, 1))

# Initialize driver system
driver = chrono.Driver()
driver.setThrottle(0.5)
driver.setBrake(0.2)
driver.setSteering(0.1)

# Add the vehicle and terrain to the simulation
engine.addTerrain(terrain)
engine.addVehicle(vehicle)

# Set the simulation loop
engine.setUpdateRate(50)

# Start the simulation
engine.run()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries (pychrono, pychrono.irrlicht).
   - Initializes PyChrono with `chrono.init()`.
   - Creates an Irrlicht engine and window for visualization.

2. **Terrain:**
   - Creates a `RigidTerrain` object with dimensions and texture.
   - Sets friction for the terrain.

3. **Vehicle:**
   - Creates a `Vehicle` object with the name "HMMWV".
   - Sets mass, center of mass, and tire model.
   - Defines wheel radius, base, count, and contact method.
   - Sets initial position and orientation.

4. **Driver System:**
   - Creates a `Driver` object to control steering, throttle, and braking.

5. **Simulation Loop:**
   - Sets the simulation update rate to 50 frames per second.
   - Runs the simulation using `engine.run()`.

**Notes:**

- This script provides a basic framework. You can add more complexity by:
  - Implementing detailed tire behavior using `TMEASY` parameters.
  - Adding more realistic physics and forces.
  - Implementing a more sophisticated driver system with advanced control.
- Ensure you have the necessary Irrlicht libraries installed.
