```python
from pychrono import *
from pychrono.irrlicht import IrrlichtEngine
import pychrono.irrlicht as irr
from pychrono.irrlicht import IrrlichtScene, IrrlichtEngine

# Initialize PyChrono
app = PyChronoApp()

# Define simulation parameters
dt = 0.01  # timestep
gravity = 9.81
friction = 0.5
restitution = 0.8

# Create the environment
terrain = Terrain(
    size=100,
    position=Vec3(0, 0, 0),
    friction=friction,
    restitution=restitution,
)

# Create the vehicle
vehicle = M113(
    position=Vec3(0, 0, 0),
    mass=1000,
    friction=friction,
    restitution=restitution,
)

# Create the driver system
driver = Driver(
    vehicle=vehicle,
    acceleration_factor=1.0,
    max_speed=50.0,
)

# Create Irrlicht engine and scene
engine = IrrlichtEngine()
scene = IrrlichtScene(engine)

# Set camera settings
camera = IrrlichtCamera(scene)
camera.position = Vec3(0, 0, 10)
camera.lookAt = Vec3(0, 0, 0)
camera.fov = 60.0

# Set lighting
light = IrrlichtLight(scene)
light.position = Vec3(0, 10, 0)
light.color = Vec3(1, 1, 1)

# Add visual elements to the scene
scene.add(terrain)
scene.add(vehicle)
scene.add(driver)
scene.add(light)
scene.add(camera)

# Simulation loop
while True:
    # Update simulation
    driver.update(dt)
    vehicle.update(dt)
    terrain.update(dt)
    
    # Synchronize and advance all systems
    app.update()
    
    # Render scene
    engine.render(scene)

```

**Explanation:**

1. **Initialization:** The script initializes PyChrono, sets simulation parameters, and creates the environment, vehicle, driver, and Irrlicht engine.

2. **Terrain and Vehicle:**  A `Terrain` object is created with a defined size and properties. The `M113` object is initialized with its initial position, mass, and other relevant parameters.

3. **Driver System:** A `Driver` object is created to control the vehicle's movement. It has an `acceleration_factor` and `max_speed` for controlling the vehicle's behavior.

4. **Irrlicht Integration:** An `IrrlichtEngine` and `IrrlichtScene` are created. The camera is set up with a specific position and FOV. A light source is added to the scene for visual representation.

5. **Simulation Loop:** The simulation loop runs continuously. Inside the loop:
    - The driver system updates the vehicle's position and velocity based on the driver's input.
    - The vehicle's position and velocity are updated based on the physics engine.
    - The terrain is updated with its properties.
    - The scene is rendered using the Irrlicht engine.
