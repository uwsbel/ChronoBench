```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import pychrono.physics as physics
import pychrono.math as math

# Initialize PyChrono
chrono.init()

# Create the Irrlicht engine
engine = irrlicht.IrrlichtEngine()

# Create the world
world = chrono.World()

# Create the ground body
ground = chrono.Body(chrono.BodyType.STATIC, chrono.Vector3(0, 0, 0))
ground.setMass(1000)
ground.setInertia(chrono.Vector3(0, 0, 0))
world.addBody(ground)

# Create the pendulum
pendulum = chrono.Body(chrono.BodyType.DYNAMIC, chrono.Vector3(0, 5, 0))
pendulum.setMass(1)
pendulum.setInertia(chrono.Vector3(0, 0.1, 0))
pendulum.setFixedRotation(True)

# Create the revolute joint
joint = chrono.RevoluteJoint(pendulum, ground)
world.addBody(pendulum)
world.addBody(ground)
world.addJoint(joint)

# Set the pendulum's initial position and velocity
pendulum.setPosition(chrono.Vector3(0, 5, 0))
pendulum.setVelocity(chrono.Vector3(0, 0, 0))

# Set the visualization parameters
engine.addScene(world)
engine.run()

# Periodically log the pendulum's position and velocity
while True:
    # Get the pendulum's position and velocity
    position = pendulum.getPosition()
    velocity = pendulum.getVelocity()

    # Log the values
    print(f"Position: {position}")
    print(f"Velocity: {velocity}")

    # Update the simulation
    engine.update()
```

**Explanation:**

1. **Initialization:** The script starts by importing necessary libraries and initializing PyChrono.
2. **World and Bodies:** It creates a world and adds a ground body with a fixed position and mass. It also creates a pendulum body with a mass, inertia, and fixed rotation.
3. **Joint:** A revolute joint is created to connect the pendulum and the ground.
4. **Initial Conditions:** The pendulum is given an initial position and velocity.
5. **Visualization:** The Irrlicht engine is used to render the simulation.
6. **Logging:** The script loops through the simulation, getting the pendulum's position and velocity, and printing them to the console.
7. **Update:** The Irrlicht engine is updated to simulate the pendulum's motion.


**Notes:**

* The script assumes that you have the PyChrono and Irrlicht libraries installed. 
* You can adjust the pendulum's mass, inertia, and initial position and velocity to modify the pendulum's behavior.
* The script uses a fixed rotation for the pendulum. You can change this to a free rotation if you want.
