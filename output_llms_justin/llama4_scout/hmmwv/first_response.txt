### PyChrono Simulation of HMMWV on Flat Rigid Terrain

Below is a Python script that sets up a PyChrono simulation as per your instructions. This script initializes the PyChrono environment, creates a full HMMWV vehicle model, sets up a flat rigid terrain, and configures an interactive driver system for user input.

```python
import chrono as ch
import chrono.irrlicht as irr
import chrono.vehicle as veh

# 1. Initialize the PyChrono environment and core components.
ch.ChEngine.Initialize()

# 2. Create the Irrlicht application
app = irr.ChIrrApp()

# 3. Set up the HMMWV vehicle
vehicle = veh.ChHMMWV()

# Set location and orientation
vehicle.SetChassisBodyPos(ch.ChVector3d(0, 0, 1))

# Use TMEASY tire model
vehicle.SetTireModel(veh.ChTireModel_TMEASY)

# Use primitive visualization for vehicle components
vehicle.SetVisualization(veh.ChVehicleVisualizer_Vehicle)

# 4. Create the terrain
terrain = veh.ChRigidTerrain(vehicle.GetSystem())
terrain.SetTerrainHeight(0)
terrain.SetTerrainSize(100, 100)
terrain.SetTextureFile("chrono_vehicle/tire_test/texture.jpg")

# 5. Create and set up the interactive driver system
driver = veh.ChInteractiveDriverIRR(vehicle, app)
driver.SetSteeringDelta(0.1)
driver.SetThrottleDelta(0.01)
driver.SetBrakingDelta(0.01)

# 6. Set simulation parameters
vehicle.GetSystem().SetTimestep(0.02)
vehicle.GetSystem().SetCollisionSystemType(ch.ChCollisionSystem.Type_BULLET)

# 7. Initialize the simulation
app.SetSimulationRate(1)
app.SetFrameRate(50)

while app.Run():
    vehicle.Update(vehicle.GetSystem().GetTimestep())
    app.Render()
    vehicle.GetSystem().DoStepDynamics(vehicle.GetSystem().GetTimestep())

# Clean up
ch.ChEngine.Terminate()
```

### Notes:
- Ensure you have the necessary Chrono and Irrlicht libraries installed and properly configured in your Python environment.
- The script assumes that the required data files (e.g., vehicle and terrain textures, TMEASY tire parameters) are located in the standard Chrono data directories.
- You may need to adjust file paths and simulation parameters based on your specific setup and requirements.

### Running the Simulation:
- Save this script to a `.py` file (e.g., `hmmwv_simulation.py`).
- Run the script using your Python interpreter.

This script provides a basic simulation setup. You can further customize it by modifying vehicle and terrain parameters, adding more complex scenarios, or integrating different Chrono modules for advanced simulations.
