### 2. Correctness (30 points)

- **Use of `ChContactMaterialNSC` in `ChBodyEasySphere`:** According to the API, `ChBodyEasySphere` expects a material pointer for contact material. The code creates `sphere_mat` as `ChContactMaterialNSC()` and passes it. However, `ChBodyEasySphere` expects a `ChMaterialSurface` or similar, not a `ChContactMaterialNSC` object directly. This is a subtle but important API misuse. The correct approach is to create a `ChMaterialSurfaceNSC` and set friction there, then pass that to the body. This could cause the material properties not to be applied correctly. (-15 points)
