### PyChrono Simulation Script: Mass-Spring-Damper System

```python
import chrono as ch
import chrono.irrlicht as irr

# Initialize PyChrono environment
ch.CH_INIT()

# Create the Chrono systems
sys = ch.ChSystemNSC()

# Create the ground body
ground = ch.ChBody()
ground.SetPos(ch.ChVector3d(0, 0, 0))
sys.Add(ground)

# Create a mass body
mass = ch.ChBody()
mass.SetMass(1.0)
mass.SetInertiaXX(ch.ChVector3d(1, 1, 1))
mass.SetPos(ch.ChVector3d(1, 1, 0))
sys.Add(mass)

# Create a Link_TSD_A (spring-damper) connection
link = ch.ChLinkTSDA()
link.SetName('damper')
link.Initialize(ground, mass, 
                ch.ChFrame3d(ch.ChVector3d(0, 0, 0), ch.ChQuaterniond(1, 0, 0, 0)), 
                ch.ChFrame3d(ch.ChVector3d(0, 0, 0), ch.ChQuaterniond(1, 0, 0, 0)))
link.RegisterVisualization(True)
link.SetSpringConstant(1000.0)  # Default spring constant
link.SetDampingCoefficient(10.0)  # Default damping coefficient
sys.Add(link)

# Create visual shapes for the mass and spring
mass_shape = ch.ChSphereShape(0.1)
mass.AddVisualShape(mass_shape)

spring_shape = ch.ChLineShape()
spring_shape.SetNumSegments(10)
spring_shape.SetSegmentPositions(link.GetPointsInBodyA(), link.GetPointsInBodyB())
link.AddVisualShape(spring_shape)

# Irrlicht application
app = irr.ChIrrApp(sys, 'Mass-Spring-Damper System', 800, 600)

# Set up camera
app.SetCameraPos(ch.ChVector3d(0, -5, 0))
app.SetCameraTarget(ch.ChVector3d(0, 0, 0))

# Enable default Irrlicht lighting
app.EnableDefaultLights()

# Simulation loop
while app.Run():
    sys.Update()
```

### Explanation

The provided Python script demonstrates a simple mass-spring-damper system using PyChrono. The simulation consists of:

*   Initialization of the PyChrono environment and creation of a Chrono system.
*   Definition of a ground body and a mass body with specific properties.
*   Connection of the mass body to the ground using a `ChLinkTSDA` (spring-damper) element.
*   Visualization of the mass as a sphere and the spring as a line using Irrlicht.

The script utilizes default linear spring-damper parameters for the `ChLinkTSDA` connection and sets up an Irrlicht application for visualization with appropriate lighting and camera settings.

### Usage

To run this script, ensure you have PyChrono installed. You can install it via pip:

```bash
pip install pychrono
```

After installation, save the script to a file (e.g., `mass_spring_damper.py`) and execute it using Python:

```bash
python mass_spring_damper.py
```

This will launch the Irrlicht visualization of the mass-spring-damper system.
