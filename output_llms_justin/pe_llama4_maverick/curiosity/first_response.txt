Here's a Python script that creates a PyChrono simulation based on your instructions:

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as chronoirr

def main():
    # Initialize the Chrono system
    chrono.SetChronoDataPath('/path/to/chrono/data')

    # Create a Curiosity rover simulation
    rover = veh.CuriosityRover()
    rover.SetContactMethod(chrono.ChContactMethod_NSC)
    rover.SetChassisCollisionType(veh.CollisionType_NONE)
    rover.SetInitPosition(chrono.ChCoordsysd(chrono.ChVector3d(0, 0.2, 0), chrono.QUNIT))
    rover.Initialize()

    # Create the terrain
    terrain = veh.RigidTerrain(rover.GetSystem())
    patch_mat = chrono.ChContactMaterialNSC()
    patch = terrain.AddPatch(patch_mat, chrono.ChCoordsysd(chrono.ChVector3d(0, 0, 0), chrono.QUNIT), 20, 20)
    terrain.Initialize()

    # Create the visualization system
    vis = chronoirr.ChVisualSystemIrrlicht()
    vis.AttachSystem(rover.GetSystem())
    vis.SetWindowSize(1024, 768)
    vis.SetWindowTitle('Curiosity Rover Simulation')
    vis.Initialize()
    vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
    vis.AddSkyBox()
    vis.AddCamera(chrono.ChVector3d(3, 3, -3))
    vis.AddTypicalLights()
    vis.EnableShadows()

    # Simulation loop
    while vis.Run():
        time = rover.GetSystem().GetChTime()
        driver_data = veh.DriverInputs()
        # Add your driver inputs here (e.g., steering, throttle, braking)
        driver_data.m_steering = 0.0
        driver_data.m_throttle = 0.5
        driver_data.m_braking = 0.0
        rover.GetDriver().SetInputs(driver_data)

        vis.BeginScene()
        vis.Render()
        vis.EndScene()
        rover.GetSystem().DoStepDynamics(0.01)

if __name__ == "__main__":
    main()
```

**Explanation:**

1.  The script initializes the PyChrono environment by setting the path to the Chrono data directory.
2.  It creates a Curiosity rover simulation using the `veh.CuriosityRover` class, specifying the contact method, chassis collision type, initial position, and initializing the rover.
3.  A rigid terrain is created using `veh.RigidTerrain`, and a patch is added to represent the ground with collision properties.
4.  The Irrlicht visualization system is set up to render the simulation. It is attached to the rover's system, and various visualization settings are configured, including the window size, title, camera position, lighting, and shadows.
5.  The simulation loop runs until the visualization window is closed. Inside the loop, the script advances the simulation by a time step, updates the driver inputs (steering, throttle, braking), and renders the scene.

**Customization:**

*   You can modify the driver inputs (steering, throttle, braking) to control the rover's movement.
*   Adjust the camera settings, lighting, and other visualization parameters to suit your needs.
*   You can also add more complex terrain features or modify the rover's properties to simulate different scenarios.

**Note:** Make sure to replace '/path/to/chrono/data' with the actual path to your Chrono data directory.
