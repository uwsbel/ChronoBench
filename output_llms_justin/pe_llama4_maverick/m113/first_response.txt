### M113 Vehicle Simulation with PyChrono

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as chronoirr

def main():
    # Initialize the Chrono environment
    chrono.SetChronoDataPath('/path/to/chrono/data')

    # Create the vehicle system
    vehicle = veh.M113()
    vehicle.SetContactMethod(chrono.ChContactMethod_SMC)
    vehicle.SetChassisCollisionType(veh.CollisionType_NONE)
    vehicle.SetInitPosition(chrono.ChCoordsysd(chrono.ChVector3d(0, 0, 1.0), chrono.QuatFromAngleX(chrono.CH_C_PI / 4)))
    vehicle.Initialize()

    # Create the terrain
    terrain = veh.RigidTerrain(vehicle.GetSystem())
    patch_mat = chrono.ChMaterialSurfaceSMC()
    patch_mat.SetFriction(0.9)
    patch_mat.SetRestitution(0.1)
    patch = terrain.AddPatch(patch_mat, chrono.ChCoordsysd(chrono.ChVector3d(0, 0, 0), chrono.QUNIT), 100, 100)
    terrain.Initialize()

    # Create the driver system
    driver = veh.ChDriver(vehicle.GetVehicle())
    driver.Initialize()

    # Create the Irrlicht visualization system
    vis = chronoirr.ChVisualSystemIrrlicht()
    vis.AttachSystem(vehicle.GetSystem())
    vis.SetWindowSize(800, 600)
    vis.SetWindowTitle('M113 Vehicle Simulation')
    vis.Initialize()
    vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
    vis.AddSkyBox()
    vis.AddCamera(chrono.ChVector3d(10, 10, -5))
    vis.AddTypicalLights()

    # Simulation loop
    realtime_timer = chrono.ChRealtimeStepTimer()
    while vis.Run():
        time = vehicle.GetSystem().GetChTime()
        driver_inputs = driver.GetInputs()
        vehicle.Advance(time)
        terrain.Advance(time)
        driver.Advance(time)
        vis.BeginScene()
        vis.Render()
        vis.EndScene()
        realtime_timer.Spin(0.016)

if __name__ == "__main__":
    main()
```

### Key Components:

1.  **PyChrono Environment Initialization**: The script begins by importing necessary modules and initializing the PyChrono environment with the `chrono.SetChronoDataPath` function.
2.  **M113 Vehicle Setup**: The `veh.M113` class is used to create an instance of the M113 vehicle. The contact method, chassis collision type, and initial position are set accordingly.
3.  **Rigid Terrain Creation**: A rigid terrain is created using `veh.RigidTerrain`, and a patch is added with specified friction and restitution properties.
4.  **Driver System Initialization**: A driver system is created using `veh.ChDriver` to control the vehicle.
5.  **Irrlicht Visualization**: The Irrlicht visualization system is set up with `chronoirr.ChVisualSystemIrrlicht`, and the camera, lighting, and other visualization settings are configured.
6.  **Simulation Loop**: The simulation loop runs in real-time, advancing the vehicle, terrain, and driver systems at each timestep. The `ChRealtimeStepTimer` ensures that the simulation stays synchronized with real-time.

### Running the Simulation:

To run the simulation, simply execute the script. The Irrlicht visualization window will display the M113 vehicle on the rigid terrain, and the simulation will progress in real-time. The camera can be controlled using the Irrlicht interface.
