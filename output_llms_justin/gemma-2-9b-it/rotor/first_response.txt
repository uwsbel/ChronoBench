```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize Chrono
chrono.SetChronoDataPath("..")  # Set the path to your Chrono data files

# Create the simulation world
world = chrono.World()

# --- Create the IGA Beam ---
beam_params = chrono.ChBodyEasyBox(0.1, 0.05, 0.01, 1000)  # Dimensions and mass
beam_params.SetPos(chrono.ChVectorD(0, 0, 0))  # Initial position

# Create the IGA beam
beam = chrono.ChBeamIga(beam_params, 
                       chrono.ChVectorD(0, 0, 0),  # Start point
                       chrono.ChVectorD(1, 0, 0),  # End point
                       10,  # Number of elements
                       10,  # Number of nodes
                       chrono.ChVectorD(0, 0, 0),  # Initial velocity
                       chrono.ChVectorD(0, 0, 0))  # Initial angular velocity

world.Add(beam)

# --- Attach the Flywheel ---
flywheel_params = chrono.ChBodyEasySphere(0.05, 1000)  # Radius and mass
flywheel_params.SetPos(chrono.ChVectorD(0.5, 0, 0))  # Position at beam center

flywheel = chrono.ChBodyEasy(flywheel_params)
beam.AddChild(flywheel)

# --- Add the Rotational Motor ---
motor_params = chrono.ChBodyEasyCylinder(0.02, 0.1, 1000)  # Radius, height, mass
motor_params.SetPos(chrono.ChVectorD(0, 0, 0))  # Position at beam start

motor = chrono.ChBodyEasy(motor_params)
motor.SetPos(chrono.ChVectorD(0, 0, 0))  # Position at beam start
beam.AddChild(motor)

# --- Connect the Motor to the Beam ---
motor_joint = chrono.ChLinkLockPrismatic(motor, beam,
                                        chrono.ChVectorD(0, 0, 0),
                                        chrono.ChVectorD(1, 0, 0))
motor_joint.SetPos(chrono.ChVectorD(0, 0, 0))
world.Add(motor_joint)

# --- Set Simulation Parameters ---
world.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))  # Gravity
world.Set_Speed(1000)  # Simulation speed

# --- Visualization ---
vis = chronoirr.ChIrrApp(world, 'Jeffcott Rotor Simulation', chronoirr.vector3df(800, 600, 0))

# Add FEM visualization
beam.AddVisualization(vis.GetSceneNode())

# Run the simulation
vis.SetFullscreen(True)
vis.AssetBindAll()
vis.Start()
chrono.ChSystem.Run(10)
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries: `pychrono` for physics and `pychrono.irrlicht` for visualization.
   - Sets the path to Chrono data files.
   - Creates a `chrono.World` object to represent the simulation environment.

2. **IGA Beam Creation:**
   - Defines `beam_params` with dimensions, mass, and initial position.
   - Creates an `chrono.ChBeamIga` object, specifying the beam parameters, start and end points, number of elements and nodes, and initial velocity and angular velocity.
   - Adds the beam to the world.

3. **Flywheel Attachment:**
   - Defines `flywheel_params` with radius and mass.
   - Creates a `chrono.ChBodyEasySphere` object for the flywheel and positions it at the center of the beam.
   - Adds the flywheel as a child of the beam.

4. **Rotational Motor:**
   - Defines `motor_params` with radius, height, and mass.
   - Creates a `chrono.ChBodyEasyCylinder` object for the motor and positions it at the start of the beam.
   - Adds the motor as a child of the beam.

5. **Motor-Beam Connection:**
   - Creates a `chrono.ChLinkLockPrismatic` joint to connect the motor to the beam, allowing rotational motion.
   - Sets the joint's position and adds it to the world.

6. **Simulation Parameters:**
   - Sets the gravitational acceleration and simulation speed.

7. **Visualization:**
   - Creates an `chrono.ChIrrApp` object to use Irrlicht for visualization.
   - Adds FEM visualization of the beam to the scene.
   - Sets fullscreen mode and starts the visualization.

8. **Simulation Run:**
   - Runs the simulation for a specified duration (10 seconds in this case).
