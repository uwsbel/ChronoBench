```python
import pychrono as chrono
import rospy
from std_msgs.msg import Int32

# Initialize PyChrono
chrono.SetChronoThread(chrono.CHRONO_THREAD_ROS)

# Create a Chrono system
system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# Define physical material properties
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.5)
material.SetRestitution(0.2)

# Add a fixed floor
floor = chrono.ChBodyEasyBox(10, 10, 0.1, material)
floor.SetPos(chrono.ChVectorD(0, 0, -0.5))
floor.SetBodyFixed(True)
system.AddBody(floor)

# Add a movable box
box = chrono.ChBodyEasyBox(1, 1, 1, material)
box.SetPos(chrono.ChVectorD(0, 0, 0.5))
system.AddBody(box)

# Custom ROS handler
class MyRosHandler(chrono.ChRosHandler):
    def __init__(self, topic_name):
        super().__init__()
        self.topic_name = topic_name
        self.pub = rospy.Publisher(self.topic_name, Int32, queue_size=10)

    def OnUpdate(self, time):
        # Publish an integer message to the specified topic
        msg = Int32()
        msg.data = int(time)
        self.pub.publish(msg)

# Configure ROS manager
ros_manager = chrono.ChRosManager()
ros_manager.SetClockHandler(chrono.ChRosClockHandler())
ros_manager.SetBodyHandler(chrono.ChRosBodyHandler())
ros_manager.SetTransformHandler(chrono.ChRosTransformHandler())
ros_manager.AddHandler(MyRosHandler("my_topic"))

# Run the simulation loop
rospy.init_node("chrono_ros_node")
ros_manager.Start()

while not rospy.is_shutdown():
    system.DoStepDynamics(0.01)
    ros_manager.DoStep()

ros_manager.Stop()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries: `pychrono` for Chrono integration and `rospy` for ROS communication.
   - Initializes the PyChrono environment using `chrono.SetChronoThread(chrono.CHRONO_THREAD_ROS)`.
   - Creates a Chrono system using `chrono.ChSystemNSC()`.
   - Sets gravitational acceleration using `system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))`.

2. **Physical Systems and Objects:**
   - Defines a material with friction and restitution properties using `chrono.ChMaterialSurfaceNSC()`.
   - Adds a fixed floor using `chrono.ChBodyEasyBox()` and sets its position and fixed status.
   - Adds a movable box using `chrono.ChBodyEasyBox()` and sets its initial position.

3. **ROS Handler:**
   - Creates a custom ROS handler class `MyRosHandler` that inherits from `chrono.ChRosHandler`.
   - In the `OnUpdate()` method, publishes an integer message containing the current simulation time to a specified topic.

4. **ROS Manager Configuration:**
   - Creates a ROS manager instance using `chrono.ChRosManager()`.
   - Configures handlers for clock, body, and transform synchronization.
   - Registers the custom `MyRosHandler` with the ROS manager.

5. **Simulation Loop:**
   - Initializes the ROS node using `rospy.init_node("chrono_ros_node")`.
   - Starts the ROS manager using `ros_manager.Start()`.
   - Enters a loop that advances the simulation using `system.DoStepDynamics(0.01)` and updates ROS communication with `ros_manager.DoStep()`.
   - Stops the ROS manager using `ros_manager.Stop()` when the loop terminates.
