Here is a PyChrono simulation script that models the dynamic behavior of a Jeffcott rotor using an Isogeometric Analysis (IGA) beam:

```python
import math
import numpy as np
import pychrono as chrono
import pychrono.fea as fea
import pychrono irrlicht as chronoirr

# Set up the simulation system
sys = chrono.ChSystemSMC()

# Create the visualization window
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('Jeffcott Rotor Simulation')
vis.Initialize()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(0, 5, 10))
vis.AddTypicalLights()

# Simulation parameters
beam_length = 2.0
num_elements = 10
beam_width = 0.1
beam_height = 0.1
young_modulus = 2.0e11
shear_modulus = 8.0e10
density = 8000.0
damping = 0.001
flywheel_mass = 100.0
flywheel_inertia = 0.1

# Create the beam
beam = fea.ChBeam()
beam.SetYoungModulus(young_modulus)
beam.SetShearModulus(shear_modulus)
beam.SetDensity(density)
beam.SetDamping(damping)

# Create nodes
nodes = []
for i in range(num_elements + 1):
    x = i * (beam_length / num_elements)
    node = fea.ChNodeFEAxyzrot()
    node.SetPos(chrono.ChVector3d(x, 0, 0))
    sys.Add(node)
    nodes.append(node)

# Create beam elements
for i in range(num_elements):
    element = fea.ChElementBeam()
    element.SetNodes(nodes[i], nodes[i+1])
    element.SetSection(fea.ChBeamSectionEuler())
    element.GetSection().SetAsRectangularSection(beam_width, beam_height)
    sys.Add(element)

# Add flywheel at the center
center_node = nodes[num_elements // 2]
flywheel = chrono.ChBody()
flywheel.SetMass(flywheel_mass)
flywheel.SetInertiaXX(chrono.ChVector3d(flywheel_inertia, flywheel_inertia, flywheel_inertia))
flywheel.SetPos(center_node.GetPos())
sys.Add(flywheel)

# Create a visual shape for the flywheel
flywheel_shape = chrono.ChVisualShapeCylinder(0.2, 0.4)
flywheel_shape.SetColor(chrono.ChColor(0.5, 0.5, 0.5))
flywheel.AddVisualShape(flywheel_shape)

# Add rotational motor at one end
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(nodes[0], sys.GetGround(), chrono.ChCoordsysd(chrono.ChVector3d(0, 0, 0), chrono.QUNIT))
sys.Add(motor)

# Set motor speed (constant speed for demonstration)
motor.SetSpeedFunction(chrono.ChFunction_Const(5.0))  # 5 rad/s

# Add FEM visualization
beam_mesh = fea.ChFEMMesh()
beam_mesh.AddNodes(nodes)
beam_mesh.AddElements(elements)
sys.Add(beam_mesh)

# Run the simulation
while vis.Run():
    sys.DoStepDynamics(0.001)
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
```

This script creates a Jeffcott rotor simulation with the following features:

1. A beam modeled using finite element analysis (FEA) with Euler-Bernoulli beam elements
2. A flywheel attached at the center of the beam
3. A rotational motor driving one end of the beam
4. Irrlicht visualization window showing the dynamic behavior
5. FEM visualization of the beam's deformation

Key components:

- `ChSystemSMC`: System using smooth contact mechanics for accurate dynamic simulations
- `ChVisualSystemIrrlicht`: Visualization system with camera and lighting setup
- `ChNodeFEAxyzrot`: Nodes representing the beam's degrees of freedom
- `ChElementBeam`: Beam elements with rectangular cross-section
- `ChLinkMotorRotationSpeed`: Motor driving the beam's rotation
- `ChFEMMesh`: FEM visualization of the beam's deformation

The simulation can be modified by adjusting parameters such as:
- `beam_length`: Length of the rotor beam
- `num_elements`: Number of beam elements (discretization)
- `young_modulus` and `shear_modulus`: Material properties
- `flywheel_mass` and `flywheel_inertia`: Flywheel properties
- `motor speed`: Rotation speed of the motor

The visualization shows the beam's deformation and the flywheel's rotation in real-time, allowing for analysis of the rotor's dynamic behavior.
