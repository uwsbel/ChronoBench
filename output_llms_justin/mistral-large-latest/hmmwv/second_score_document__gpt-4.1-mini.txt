### 2. Correctness (30 points)

- **API usage:**  
  - `veh.HMMWV_Full()` is used correctly with contact method and collision type set before initialization.  
  - Tire model and visualization types are set properly.  
  - Terrain patch material is created with `ChContactMaterialNSC()` and friction/restitution set correctly.  
  - Visualization system uses `ChWheeledVehicleVisualSystemIrrlicht()` and attaches vehicle correctly.  
  - PID controller usage is appropriate for steering control.  
  - The calculation of error using cross product and vehicle direction is logically sound for lateral error.  
  - The time integration is done by advancing terrain, vehicle, and visualization separately, which is standard in vehicle simulations.  
  - The realtime timer is used correctly to maintain real-time pacing.  
  - The `angle` update for circular path is mathematically incorrect:  
    ```python
    angle += step_size / (2 * math.pi * radius)
    ```  
    This increments angle by a very small fraction, but the denominator is circumference (2πr), so the units are inconsistent. The angle should be incremented by angular velocity * step_size or step_size / radius for arc length to angle conversion. This is a **logical error** affecting target movement speed.  
    **Deduct 10 points for logical error in angle update.**

- **Vehicle mass print:**  
  The call `vehicle.GetVehicle().GetMass()` is correct.

- **Visualization synchronization:**  
  `vis.Synchronize(time, driver_inputs)` is called, but `Synchronize` for visualization systems typically takes the system or vehicle state, not driver inputs. According to the API, `vis.Synchronize()` usually takes time and the vehicle or system, not driver inputs. This is a minor API misuse but unlikely to cause failure.  
  **Deduct 5 points for minor API misuse in visualization synchronization.**

- **Collision system type:**  
  The collision system is set to Bullet after vehicle initialization. It is better to set collision system type before vehicle initialization to ensure proper setup. This could cause subtle issues.  
  **Deduct 10 points for incorrect collision system setup timing.**

**Correctness score: 30 - 10 - 5 - 10 = 5**
