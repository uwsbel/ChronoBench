According to the documentation, `AddVisualShape` expects a shape and optionally a frame (`ChFrame` or `ChCoordsys`). `ChFramed` is not a documented class in the provided API. The correct class is `chrono.ChFrame` or `chrono.ChCoordsys`.

  - This is an **incorrect API usage** that could cause an error.
