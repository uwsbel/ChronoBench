```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#
# ---------------------------------------------------------------------

system = chrono.ChSystemNSC()

# Set the gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachTo(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Crank-Slider Mechanism")
vis.Initialize()

# Create a floor
floor = chrono.ChBodyEasyBox(2, 0.1, 2, 1000, True, True)
floor.SetPos(chrono.ChVectorD(0, -0.5, 0))
system.Add(floor)

# Create the crankshaft
crankshaft = chrono.ChBodyEasyCylinder(0.1, 0.3, 1000, True, True)
crankshaft.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(crankshaft)

# Create the connecting rod
connecting_rod = chrono.ChBodyEasyBox(0.2, 0.05, 0.8, 1000, True, True)
connecting_rod.SetPos(chrono.ChVectorD(0.3, 0, 0))
system.Add(connecting_rod)

# Create the piston
piston = chrono.ChBodyEasyBox(0.1, 0.1, 0.1, 1000, True, True)
piston.SetPos(chrono.ChVectorD(0.3 + 0.8, 0, 0))
system.Add(piston)

# Create revolute joints
rev_joint_crank = chrono.ChLinkRevolute()
rev_joint_crank.Initialize(floor, crankshaft, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1))
system.Add(rev_joint_crank)

rev_joint_rod = chrono.ChLinkRevolute()
rev_joint_rod.Initialize(crankshaft, connecting_rod, chrono.ChVectorD(0.3, 0, 0), chrono.ChVectorD(0, 0, 1))
system.Add(rev_joint_rod)

rev_joint_piston = chrono.ChLinkRevolute()
rev_joint_piston.Initialize(connecting_rod, piston, chrono.ChVectorD(0.3 + 0.8, 0, 0), chrono.ChVectorD(0, 0, 1))
system.Add(rev_joint_piston)

# Create a motor to drive the crankshaft
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(floor, crankshaft, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1))
motor.SetSpeedFunction(chrono.ChFunction_Const(chrono.CH_C_PI))  # Rotate at pi radians per second
system.Add(motor)

# ---------------------------------------------------------------------
#
#  Set visualization parameters
#
# ---------------------------------------------------------------------

# Set camera position
vis.GetCamera().SetLocation(chrono.ChVectorD(2, 2, 2))
vis.GetCamera().SetLookAt(chrono.ChVectorD(0, 0, 0))

# Add lighting
vis.AddLight(chrono.ChLightDirectional(chrono.ChVectorD(0, -1, 0)))

# Customize materials and textures (optional)
# ...

# ---------------------------------------------------------------------
#
#  Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - The script starts by importing the necessary Chrono libraries.
   - A Chrono system (`system`) is created to manage the simulation.
   - Gravitational acceleration is set.
   - An Irrlicht visualization system (`vis`) is initialized and attached to the Chrono system.

2. **Object Creation:**
   - A floor, crankshaft, connecting rod, and piston are created using Chrono's `ChBodyEasy` functions.
   - These objects are added to the simulation system.

3. **Joint Definition:**
   - Revolute joints (`ChLinkRevolute`) are used to connect the components:
     - `rev_joint_crank`: Connects the crankshaft to the floor.
     - `rev_joint_rod`: Connects the crankshaft to the connecting rod.
     - `rev_joint_piston`: Connects the connecting rod to the piston.

4. **Motor Setup:**
   - A motor (`ChLinkMotorRotationSpeed`) is added to drive the crankshaft.
   - The `SetSpeedFunction` is used to set a constant angular speed of pi radians per second.

5. **Visualization:**
   - Camera position and lighting are set using the Irrlicht system.
   - You can further customize materials, textures, and logos here.

6. **Simulation Loop:**
   - The `while vis.Run():` loop runs the simulation until the Irrlicht window is closed.
   - Inside the loop:
     - `system.DoStepDynamics(0.01)` performs a simulation step with a time step of 0.01 seconds.
     - `vis.Render()` updates the visualization.
