```python
import pychrono as chrono
import pychrono.fea as fea
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and set up the solver
#

my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Set solver and timestepper
solver = chrono.ChSolverMINRES()
my_system.SetSolver(solver)
timestepper = chrono.ChTimestepperEulerImplicit(my_system)
timestepper.SetStepSize(0.001)

# ---------------------------------------------------------------------
#
# Create the beam using FEA
#

beam_material = fea.ChMaterialShellANCF(100e9, 0.3, 1000)  # E, nu, rho

beam_section = fea.ChSectionShellParametric(0.05, 0.05)

beam = fea.ChBeamIGA(my_system)
beam.SetNumElements(10)
beam.SetMaterial(beam_material)
beam.SetSection(beam_section)
beam.SetNodesGeometry(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(1, 0, 0))

# ---------------------------------------------------------------------
#
# Add constraints and motor
#

# Fix one end of the beam
fixed_constraint = chrono.ChFixedJoint()
fixed_constraint.Initialize(beam.GetNode(0), my_system)

# Apply a motor to the other end of the beam
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(beam.GetNode(1), chrono.ChVectorD(0, 0, 1))
motor.SetSpeedFunction(chrono.ChFunction_Const(0.1))  # Rotate at 0.1 rad/s

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Beam Buckling Simulation")
vis.Initialize()
vis.AddTypicalLights()
vis.AddCamera(chrono.ChVectorD(2, 2, 2))

# ---------------------------------------------------------------------
#
# Simulation loop
#

while vis.Run():
    my_system.DoStepDynamics(timestepper.GetStepSize())
    vis.Render()

```

**Explanation:**

1. **Initialization:** The code initializes the PyChrono system, sets the gravitational acceleration, and configures the solver and timestepper for accurate dynamics simulation.

2. **Beam Creation:**
   - A beam material with Young's modulus, Poisson's ratio, and density is defined.
   - A rectangular cross-section is specified for the beam.
   - An `fea.ChBeamIGA` object is created, representing the beam using the Isogeometric Analysis (IGA) method. The number of elements, material, and section are set.
   - The beam's geometry is defined by specifying the coordinates of its two ends.

3. **Constraints and Motor:**
   - A fixed constraint is applied to the first node of the beam, preventing any movement.
   - A rotational motor is attached to the second node, applying a constant angular velocity to rotate the beam end.

4. **Visualization:**
   - The Irrlicht visualization system is initialized and attached to the simulation system.
   - A window is created with a title and size.
   - Typical lights and a camera are added for visualization.

5. **Simulation Loop:**
   - The simulation runs in a loop, performing the following steps in each iteration:
     - Advances the simulation by one timestep using the solver and timestepper.
     - Renders the scene using the Irrlicht visualizer.
