```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#

# Create the physical system
my_system = chrono.ChSystemNSC()

# Set gravitational acceleration
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the terrain
terrain = chrono.ChBodyEasyBox(
    200, 10, 200, 1000, True, True, chrono.ChMaterialSurface.NSC
)
terrain.SetPos(chrono.ChVectorD(0, -5, 0))
terrain.SetBodyFixed(True)
my_system.Add(terrain)

# Create the UAZBUS vehicle
vehicle = chrono.ChVehicleModel()
vehicle.SetSystem(my_system)
vehicle.SetChassis(chrono.ChChassis(chrono.ChVectorD(0, 0, 0)))

# Add wheels
wheel_radius = 0.3
wheel_width = 0.15
for i in range(4):
    wheel = chrono.ChWheel(chrono.ChVectorD(0, -0.5, 0.8 * (i % 2 * 2 - 1)),
                           chrono.ChVectorD(0, -1, 0),
                           wheel_radius, wheel_width, 20, 1000)
    wheel.SetMaterial(chrono.ChMaterialSurface.NSC)
    vehicle.AddWheel(wheel)

# Set initial conditions
vehicle.SetChassisPosition(chrono.ChVectorD(0, 1, 0))
vehicle.SetChassisVelocity(chrono.ChVectorD(1, 0, 0))

# Create the driver system
driver = chrono.ChDriver()
driver.SetVehicle(vehicle)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#

# Create the Irrlicht application
vis = chronoirr.ChIrrApp(my_system, "UAZBUS Simulation", chronoirr.dimension2du(1280, 720))

# Set camera position and lighting
vis.AddTypicalLights()
vis.SetCameraPosition(chrono.ChVectorD(5, 5, 5))
vis.SetCameraLookAt(chrono.ChVectorD(0, 1, 0))

# ---------------------------------------------------------------------
#
#  Simulation loop
#

while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()

    # Advance the simulation
    my_system.DoStepDynamics(0.01)

    # Synchronize driver system
    driver.Synchronize(0.01)

    vis.EndScene()


```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules from PyChrono and Irrlicht.
   - Creates a `chrono.ChSystemNSC` object for the physics simulation.
   - Sets gravitational acceleration.

2. **Terrain:**
   - Creates a simple box-shaped terrain using `chrono.ChBodyEasyBox`.
   - Positions the terrain and sets it as fixed.

3. **Vehicle:**
   - Creates a `chrono.ChVehicleModel` for the UAZBUS.
   - Defines the chassis and adds four wheels with specified dimensions.
   - Sets initial position and velocity for the vehicle.

4. **Driver:**
   - Creates a `chrono.ChDriver` object for controlling the vehicle.

5. **Visualization:**
   - Creates an Irrlicht visualization application using `chronoirr.ChIrrApp`.
   - Sets up camera position and lighting.

6. **Simulation Loop:**
   - Enters a loop that continues until the Irrlicht window is closed.
   - Renders the scene using Irrlicht.
   - Advances the physics simulation using `my_system.DoStepDynamics(0.01)`.
   - Synchronizes the driver system with the simulation.
