Here's a complete PyChrono simulation script based on your instructions to set up a Kraz vehicle, a rigid terrain, and a real-time visualization using Irrlicht.

```python
import os
import math
import numpy as np
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh

# Initialize the Chrono environment
chrono.SetChronoDataPath('/path/to/data')  # Set this to your Chrono data path
my_system = chrono.ChSystemNSC()  # Non-Smooth Contact system

# Set up the terrain
terrain = veh.RigidTerrain(my_system)
patch_mat = chrono.ChMaterialSurfaceNSC()  # Use NSC material
patch_mat.SetFriction(0.8)  # Set friction
patch_mat.SetRestitution(0.1)  # Set restitution

# Define terrain dimensions
terrainLength = 100.0
terrainWidth = 100.0
patch = terrain.AddPatch(patch_mat, chrono.ChCoordsysd(chrono.ChVector3d(0, 0, 0), chrono.QUNIT), terrainLength, terrainWidth)
terrain.Initialize()

# Initialize the Kraz vehicle
kraz_vehicle = veh.Kraz(my_system, veh.KrazVehicle.SuspensionType::DOUBLE_WISHBONE)
kraz_vehicle.SetContactMethod(chrono.ChContactMethod.NSC)  # Set contact method
kraz_vehicle.SetChassisCollisionType(veh.ChassisCollisionType::NONE)  # No collision for chassis
kraz_vehicle.SetInitPosition(chrono.ChCoordsysd(chrono.ChVector3d(0, 0.5, 0), chrono.QUNIT))  # Initial position
kraz_vehicle.Initialize()

# Initialize the driver system
driver = veh.DriverKraz(kraz_vehicle)
driver.SetThrottle(0.5)  # Set initial throttle
driver.SetSteering(0.0)  # Set initial steering
driver.SetBraking(0.0)  # Set initial braking

# Set up visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('Kraz Vehicle Simulation')
vis.Initialize()
vis.AddCamera(chrono.ChVector3d(0, 2, 6))  # Set camera position
vis.AddTypicalLights()  # Add typical lights
vis.AddSkyBox()  # Optional: Add a skybox
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))  # Optional: Add logo

# Simulation loop
time_step = 0.01  # Time step for the simulation
while vis.Run():
    my_system.DoStepDynamics(time_step)  # Advance the simulation
    vis.BeginScene()  # Start rendering
    vis.Render()  # Render the scene
    vis.EndScene()  # End rendering

# Cleanup if necessary (not required for this simple script)
```

### Explanation of Key Sections:
1. **Chrono Environment Initialization**: The script sets the data path for the Chrono library and initializes the physical system using Non-Smooth Contact (NSC).
  
2. **Terrain Setup**: A rigid terrain is created with specified friction and restitution properties.

3. **Vehicle Initialization**: The Kraz vehicle is instantiated, its contact method is set, and it is initialized at a specific position.

4. **Driver System Setup**: A driver system is initialized for controlling the vehicle's throttle, steering, and braking.

5. **Visualization**: The visualization system is set up using Irrlicht, including camera settings and lighting.

6. **Simulation Loop**: The main loop executes the simulation step and renders the visualization in real-time, maintaining synchronization.

Make sure to adjust the `chrono.SetChronoDataPath('/path/to/data')` to point to your local Chrono data directory where the necessary assets are stored. This script provides a foundation for simulating a Kraz vehicle on a rigid terrain with real-time visualization.
