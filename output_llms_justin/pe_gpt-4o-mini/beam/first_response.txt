Here's a PyChrono simulation script that demonstrates the use of beam finite elements, including the creation of a physical system with a mesh composed of beams and nodes, along with visualization using the Irrlicht engine. The script initializes the simulation environment, sets up the physical objects, and runs the simulation loop for real-time rendering.

```python
import os
import math
import numpy as np
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.fea as fea

# Initialize the PyChrono environment
chrono.SetChronoDataPath('/path/to/data')  # Set the path to Chrono's data directory

# Create the physical system
sys = chrono.ChSystemSMC()

# Create a mesh for the beam finite elements
mesh = fea.ChMesh()

# Define beam section properties
beam_width = 0.1  # Width of the beam
beam_height = 0.1  # Height of the beam
beam_length = 5.0  # Length of the beam
young_modulus = 0.01e9  # Young's modulus
shear_modulus = 0.01e9 * 0.3  # Shear modulus

# Create the beam section
beam_section = fea.ChBeamSectionEulerAdvanced()
beam_section.SetAsRectangularSection(beam_width, beam_height)
beam_section.SetYoungModulus(young_modulus)
beam_section.SetShearModulus(shear_modulus)
beam_section.SetRayleighDamping(0.000)

# Create nodes for the beam
node1 = fea.ChNodeFEAxyzrot(chrono.ChFrameD(chrono.ChVectorD(0, 0, 0)))
node2 = fea.ChNodeFEAxyzrot(chrono.ChFrameD(chrono.ChVectorD(beam_length, 0, 0)))

# Add nodes to the mesh
mesh.AddNode(node1)
mesh.AddNode(node2)

# Create a beam element and add it to the mesh
beam_element = fea.ChElementBeamEuler()
beam_element.SetNodes(node1, node2)
beam_element.SetSection(beam_section)
mesh.AddElement(beam_element)

# Add the mesh to the system
sys.Add(mesh)

# Set up visualization using the Irrlicht engine
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('Beam Finite Element Simulation')
vis.Initialize()
vis.AddTypicalLights()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(2.5, 2, 5))
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))

# Start the simulation loop
time_step = 0.01  # Time step for the simulation
while vis.Run():
    vis.BeginScene()
    vis.Render()
    sys.DoStepDynamics(time_step)
    vis.EndScene()

# Clean up and exit
vis.Close()
```

### Explanation of the Script:

1. **Environment Initialization**: Sets the data path for Chrono's resources.
2. **Physical System Creation**: Initializes the simulation system using `ChSystemSMC()` for smooth contact mechanics.
3. **Mesh and Beam Setup**:
   - Defines beam properties such as width, height, and material properties (Young's modulus and shear modulus).
   - Creates nodes and a beam element, linking them together and adding them to the mesh.
4. **Visualization Setup**: Uses the Irrlicht engine to create a visual representation of the simulation, including lights, camera position, and a logo.
5. **Simulation Loop**: Runs the simulation, updating the physical system and rendering the scene in real-time.

Make sure to replace `'/path/to/data'` with the actual path to your Chrono data directory. This script can be executed in a Python environment where PyChrono is installed.
