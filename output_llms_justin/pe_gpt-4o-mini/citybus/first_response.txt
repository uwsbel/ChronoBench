Here's a complete PyChrono simulation script based on your instructions to simulate a CityBus vehicle on a rigid terrain, using Irrlicht for visualization. The script initializes the necessary components, adds a rigid terrain with a custom texture, sets up the CityBus vehicle with specified parameters, and implements an interactive driver system for vehicle control. The simulation loop runs at 50 frames per second.

```python
import os
import math
import numpy as np
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh

# Set the path to Chrono data
chrono.SetChronoDataPath('/path/to/chrono/data/')

# Initialize the system
sys = chrono.ChSystemNSC()

# Create the visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('CityBus Simulation')
vis.Initialize()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(0, 3, 10))
vis.AddTypicalLights()

# Create a RigidTerrain
terrain = veh.RigidTerrain(sys)
terrain_mat = chrono.ChMaterialSurfaceNSC()
terrain_mat.SetFriction(0.8)
terrain.SetContactMaterial(terrain_mat)

# Add a patch to the terrain with a custom texture
terrain_texture = chrono.GetChronoDataFile('textures/terrain_texture.png')
patch = terrain.AddPatch(terrain_mat, chrono.ChCoordsysd(chrono.ChVector3d(0, 0, 0), chrono.QUNIT), 100, 100)
patch.SetTexture(terrain_texture)
terrain.Initialize()

# Initialize the CityBus vehicle
city_bus = veh.CityBus()
city_bus.SetContactMethod(chrono.ChContactMethod.NSC)
city_bus.SetChassisCollisionType(veh.ChassisCollisionType.FLAT_PLANE)
city_bus.SetInitPosition(chrono.ChCoordsysd(chrono.ChVector3d(0, 0.5, 0), chrono.QUNIT))
city_bus.Initialize()

# Setup the interactive driver system for controlling the vehicle
driver = veh.DriverInputs()
driver.SetThrottle(0.0)
driver.SetSteering(0.0)
driver.SetBraking(0.0)

# Main simulation loop
time_step = 1 / 50.0  # 50 frames per second
while vis.Run():
    # Update driver inputs (for demonstration, can be modified for interactive control)
    driver.SetThrottle(0.5)  # Example throttle input
    driver.SetSteering(0.1)   # Example steering input
    driver.SetBraking(0.0)    # No braking

    # Update vehicle dynamics
    city_bus.Synchronize(driver, terrain)
    sys.DoStepDynamics(time_step)

    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

# Clean up
vis.Close()
```

### Key Components of the Script:
1. **Library Imports**: The necessary libraries from PyChrono are imported, including the core, visualization, and vehicle modules.
2. **System Initialization**: The simulation system is initialized with a non-smooth contact (NSC) method.
3. **Visualization Setup**: The Irrlicht visualization system is set up with window size, title, camera position, and lighting.
4. **Rigid Terrain**: A rigid terrain is created with a specified texture, providing a realistic ground for the CityBus to drive on.
5. **CityBus Initialization**: The CityBus vehicle is initialized with its starting position and orientation.
6. **Driver Inputs**: A simple driver input system is established, allowing for throttle, steering, and braking control.
7. **Simulation Loop**: The loop runs at 50 frames per second, updating the vehicle dynamics and rendering the scene in real-time.

Make sure to replace `'/path/to/chrono/data/'` with the actual path to your Chrono data directory and ensure that the texture file exists at the specified location. Adjust the driver input logic as needed to implement actual interactive controls (e.g., using keyboard input).
