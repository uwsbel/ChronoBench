Here's a complete PyChrono script that demonstrates a single mass-spring-damper system using `ChLinkTSDA` to connect a mass to the ground. This script initializes the PyChrono environment, sets up the physical system, and includes Irrlicht visualization with appropriate lighting and camera settings.

```python
import os
import math
import numpy as np
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize the Chrono system
chrono.SetChronoDataPath('/path/to/data')  # Set the correct path for your Chrono data
my_system = chrono.ChSystemNSC()

# Create the mass body
mass = chrono.ChBodyEasyBox(0.2, 0.2, 0.2, 1000, True, True)
mass.SetPos(chrono.ChVector3d(0, 1, 0))  # Initial position above the ground
mass.SetMass(1.0)  # Mass of the block
my_system.Add(mass)

# Create the spring-damper connection
spring_damper = chrono.ChLinkTSDA()
spring_damper.Initialize(mass, my_system.Get_ground(), chrono.ChVector2d(0, 0), chrono.ChVector2d(0, 1))
spring_damper.SetSpringK(1000)  # Spring constant
spring_damper.SetDampingR(10)    # Damping coefficient
my_system.Add(spring_damper)

# Set up the visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('Mass-Spring-Damper System Simulation')
vis.Initialize()
vis.AddTypicalLights()
vis.AddCamera(chrono.ChVector3d(0, 3, 6))
vis.AddSkyBox()

# Add visual shapes for the mass (box) and spring (visual representation)
mass_shape = chrono.ChVisualShapeBox(chrono.ChVector3d(0.2, 0.2, 0.2))
mass_shape.SetColor(chrono.ChColor(0, 0, 1))  # Blue color for the mass
mass.AddVisualShape(mass_shape)

# Simulation loop
time_step = 0.01
while vis.Run():
    # Perform the simulation step
    my_system.DoStepDynamics(time_step)

    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

# Clean up and exit
vis.Close()
```

### Explanation of the Script:
1. **Initialization**: The script starts by setting the Chrono data path and initializing the `ChSystemNSC` object.

2. **Mass Body Creation**: A mass is created as a box with specified dimensions and mass properties. The initial position is set above the ground.

3. **Spring-Damper Connection**: A `ChLinkTSDA` is created to connect the mass to the ground, simulating a spring-damper system. The spring constant and damping coefficient are defined.

4. **Visualization Setup**: The visualization system is initialized using Irrlicht. The window size, title, camera position, and lighting are set.

5. **Visual Shapes**: A visual representation of the mass is added to the simulation.

6. **Simulation Loop**: The script enters a loop where it advances the simulation by the specified time step, renders the scene, and checks for the visualization run status.

Make sure to update the `chrono.SetChronoDataPath('/path/to/data')` line with the correct path to your Chrono data directory. This script should run and display a mass-spring-damper system in a graphical window using Irrlicht.
