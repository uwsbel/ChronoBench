The correct class is `chrono.ChFrame` or `chrono.ChCoordsys`. This is a significant API misuse.

Again, `ChFramed` is not a documented class; the correct class is `chrono.ChFrame` or `chrono.ChCoordsys`. Also, `chrono.VNULL` is not documented; the correct zero vector is `chrono.ChVectorD(0,0,0)` or `chrono.ChVector3d(0,0,0)`.
