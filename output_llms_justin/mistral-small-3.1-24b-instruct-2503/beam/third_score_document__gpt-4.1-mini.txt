  The `fea.ChBuilderBeamEuler.BuildBeam()` is used twice to add beams to the mesh, starting from the last beam nodes. The code then fixes the last node of the first built beam and applies a force to the first node.  
  The use of `last_beam_nodes.back()` and `last_beam_nodes.front()` is consistent with C++ STL style, but in Python, `back()` and `front()` are not standard list methods. This is a **significant correctness issue** because Python lists do not have `back()` or `front()` methods. The correct way would be `last_beam_nodes[-1]` and `last_beam_nodes[0]`. This will cause an AttributeError at runtime.
