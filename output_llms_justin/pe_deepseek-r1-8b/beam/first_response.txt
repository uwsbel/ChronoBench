Here is a comprehensive example demonstrating the use of beam finite elements in PyChrono:

```python
# Initialize the PyChrono system with Signorini-Moreau Contact mechanics
sys = chrono.ChSystemSMC()

# Create a finite element mesh
mesh = fea.ChMesh()

# Define a rectangular beam section
beam_section = fea.ChBeamSectionEulerAdvanced()
beam_section.SetAsRectangularSection(0.2, 0.3)  # LengthX, LengthY
beam_section.SetYoungModulus(0.01e9)          # Young's modulus
beam_section.SetShearModulus(0.01e9 * 0.3)  # Shear modulus
beam_section.SetRayleighDamping(0.000)       # Damping coefficient

# Create nodes with specific positions and rotations
node1 = fea.ChNodeFEAxyzrot(chrono.ChFramed(chrono.ChVector3d(0, 0, 0)))  # Node 1 at origin
node2 = fea.ChNodeFEAxyzrot(chrono.ChFramed(chrono.ChVector3d(4, 0, 0)))  # Node 2 at (4,0,0)

# Add nodes to the mesh
mesh.AddNode(node1)
mesh.AddNode(node2)

# Create a beam element connecting node1 and node2
beam_element = fea.ChElementBeamEuler()
beam_element.SetNodes(node1, node2)
beam_element.SetSection(beam_section)
mesh.AddElement(beam_element)

# Add the mesh to the system
sys.Add(mesh)

# Set visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('Beam FEA Simulation')
vis.Initialize()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(0, 3, 6))
vis.AddTypicalLights()

# Run the simulation
time_step = 0.01
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    sys.DoStepDynamics(time_step)

# Cleanup resources when done
vis.DeattachSystem(sys)
vis.Destroy()
```

### Explanation

1. **System Initialization**: The simulation starts with the creation of a `ChSystemSMC` object, which handles smooth contact interactions.

2. **Mesh Creation**: A finite element mesh is created using `ChMesh`, which will contain the beam structure. Nodes are defined with their positions and initial rotations.

3. **Beam Section Properties**: A beam section is defined with specific material properties such as Young's modulus, shear modulus, and damping.

4. **Node and Element Addition**: Nodes are added to the mesh, and a beam element is created to connect them, forming the structure.

5. **Visualization Setup**: The Irrlicht engine is initialized, attached to the simulation system, and configured with a suitable camera position and lighting.

6. **Simulation Loop**: The simulation runs in a loop, updating the positions and rendering the scene until the visualization window is closed.

This example demonstrates the use of beam finite elements in PyChrono, showcasing how to create, visualize, and simulate a simple beam structure.
