# PyChrono Gator Vehicle Simulation with Irrlicht Visualization

Below is a complete PyChrono simulation script for a Gator vehicle on flat rigid terrain with interactive controls:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import pychrono.vehicle.gator as gator
import math

# =============================================================================
# Simulation parameters
# =============================================================================

# Simulation step size
step_size = 0.02  # 50 FPS

# Time interval for simulation output
tend = 100

# =============================================================================
# Create the simulation system and add items
# =============================================================================

# Create the Chrono::Engine physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# Create the vehicle system
vehicle = gator.Gator()
vehicle.SetContactMethod(chrono.ChContactMethod_NSC)
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(chrono.ChCoorD<>(chrono.ChVectorD<>(0, 0, 0.5), chrono.Q_from_AngAxis(-math.pi/2, chrono.ChVectorD(0, 0, 1))))
vehicle.SetDriverType(veh.ChDriver::Type::INTERACTIVE)
vehicle.Initialize(system, veh.CoordinateSystem(chrono.CSYSNORM))

# Set tire type
vehicle.SetTireType(gator.TireModelType::TMEASY)

# =============================================================================
# Create the terrain
# =============================================================================

# Terrain dimensions
terrainLength = 100.0  # size in X direction
terrainWidth = 100.0   # size in Y direction

# Create the flat rigid terrain
terrain = veh.RigidTerrain(system)
patch = terrain.AddPatch(chrono.ChVectorD(0, 0, 0),
                          chrono.ChVectorD(terrainLength, terrainWidth, 0),
                          0)
patch.SetTexture(veh.GetDataFile("terrain/textures/tile4.jpg"), 200, 200)
patch.SetColor(chrono.ChColor(0.8, 0.8, 0.5))
terrain.Initialize()

# =============================================================================
# Visualization
# =============================================================================

# Create the vehicle Irrlicht interface
vis = chronoirr.ChVehicleIrrApp(system, vehicle, "Gator Vehicle Demo")
vis.SetSkyBox()
vis.AddTypicalLights(chrono.irrlicht._vector3df<>(30, -30, 100), chrono.irrlicht._vector3df<>(30, 40, 100))
vis.AddTypicalLights(chrono.irrlicht._vector3df<>(30, -30, -100), chrono.irrlicht._vector3df<>(30, 40, -100))
vis.AssetBindAll()
vis.AssetUpdateAll()

# Create the Irrlicht application for the terrain
terrain_vis = chronoirr.ChIrrAppInterface(system)
terrain_vis.AddLogo()
terrain_vis.AddSkyBox()
terrain_vis.AddTypicalLights()
terrain_vis.AssetBindAll()
terrain_vis.AssetUpdateAll()
terrain_vis.AddCamera(chrono.irrlicht._vector3df<>(0, 0, 6))
terrain_vis.SetTimestep(step_size)

# =============================================================================
# Interactive driver system
# =============================================================================

# Get the interactive driver
driver = chrono.CastToChInteractiveDriverIRR(vehicle.GetDriver())
driver.SetSteeringDelta(0.02)
driver.SetThrottleDelta(0.01)
driver.SetBrakingDelta(0.01)

# =============================================================================
# Simulation loop
# =============================================================================

# Number of simulation steps between two 3D view render frames
render_steps = math.ceil(1.0 / (step_size * 50))  # 50 FPS

# Initialize simulation frame counter
step_number = 0

while vis.Run():
    time = system.GetChTime()

    # Render scene
    if (step_number % render_steps == 0):
        vis.BeginScene()
        vis.Render()
        vis.EndScene()

    # Driver inputs
    driver.Synchronize(time)
    vehicle.Synchronize(time, driver.GetSteering(), driver.GetThrottle(), driver.GetBraking())

    # Advance simulation for one timestep for all modules
    vehicle.Advance(step_size)
    terrain.Advance(step_size)
    vis.Advance(step_size)

    # Increment frame number
    step_number += 1

    # Exit simulation loop
    if time >= tend:
        break
```

## Key Features of the Simulation:

1. **Initialization**:
   - Creates a Chrono::Engine physical system with NSC (Non-Smooth Contact) method
   - Sets up gravity and other default parameters

2. **Vehicle Setup**:
   - Initializes a Gator vehicle with TMEASY tire model
   - Sets initial position and orientation (slightly above ground)
   - Configures for interactive driver control

3. **Terrain**:
   - Creates a flat rigid terrain with specified dimensions (100x100 meters)
   - Applies a custom texture to the terrain surface

4. **Visualization**:
   - Uses Irrlicht for real-time visualization
   - Sets up lighting and camera views
   - Enables mesh visualization for all vehicle components

5. **Interactive Controls**:
   - Implements steering, throttle, and braking controls
   - Configures control sensitivity (delta values)

6. **Simulation Loop**:
   - Runs at 50 FPS (20ms step size)
   - Updates vehicle dynamics and visualization in real-time
   - Handles user input for vehicle control

## Requirements:
- PyChrono with vehicle module
- Irrlicht visualization support
- Gator vehicle definition files

The simulation will run for 100 seconds (adjustable via `tend` parameter) and can be controlled interactively using keyboard inputs (typically arrow keys for steering and W/S for throttle/braking).
