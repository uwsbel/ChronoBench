  **Major error: -15 points.**

  The code uses `particle.SetPos_DT(vel)` to set initial velocity. According to PyChrono API, `SetPos_dt()` (lowercase dt) is the correct method to set velocity. The code uses `SetPos_DT()` (capital DT), which is not a valid method and will cause an AttributeError or no effect.
