    The code passes a `ChVectorD` as the last argument, which is incorrect. Position should be set via `SetPos()`.  
    *Deduct 15 points* for incorrect body creation.

  if simulation_time > turn_time:
      left_motor_speed = -1
      right_motor_speed = 1
