  The mesh is scaled using `mmesh.Transform(chrono.ChVector3d(0, 0, 0), chrono.ChMatrix33d(2))`.  
  According to PyChrono API, `ChMatrix33d` expects a 3x3 rotation matrix, not a scalar scale factor. Using `chrono.ChMatrix33d(2)` is incorrect because `ChMatrix33d` constructor does not accept a scalar to scale uniformly.  
  The correct way to scale a mesh is to use `mmesh.Transform(scale_vector)` or to apply a scaling transform properly.  
  **Deduct 15 points** for incorrect mesh scaling API usage.
