The code uses `chrono.ChBodyEasyCylinder(chrono.ChAxis_Y, crank_rad, crank_thick, 1000)`, which is incorrect and will cause an error or unintended behavior.

The API expects `chrono.ChCoordsysD` or `chrono.ChCoordsys` for the frame parameter. `ChFramed` is not a documented class or function in PyChrono.
