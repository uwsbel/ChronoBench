To create a PyChrono simulation featuring an HMMWV vehicle with a full system setup, follow these steps:

1. **Initialize the PyChrono Environment and Core Components**:
   - Create a `ChSystem` instance.
   - Add a solver with specified settings (tolerance, maximum iterations).
   - Set up an integrator (HHT) with a defined time step.

2. **Add the HMMWV Vehicle**:
   - Import the vehicle module.
   - Create a vehicle configuration using HMMWV parameters.
   - Define the vehicle's position and orientation.
   - Optionally, add a trailer to the vehicle.

3. **Create Terrain**:
   - Use `CreateChampPaddedPlane` to generate the ground plane.
   - Set dimensions and texture for better visual appeal.

4. **Set Up Driver Inputs**:
   - Create a driver object and attach it to the vehicle.
   - Define default inputs for steering and throttle.

5. **Initialize Visual Interface with Irrlicht**:
   - Set up the Irrlicht application, passing the system.
   - Position the camera and add a light source for optimal viewing.

6. **Attach IMU and GPS Sensors**:
   - Create `ChIMU` and `ChGPS` sensors.
   - Attach these sensors to the vehicle's chassis.

7. **Simulation Loop**:
   - Continuously update the vehicle, driver, and sensors.
   - Advance the system and render using Irrlicht.
   - Output vehicle mass and sensor data at each step.

Here's the code implementing the above steps:

```python
importchrono
importchrono.vehicle as vehicle
importchrono.sensor as sensor
importchrono irrlicht

# Initialize system
system = chrono.ChSystem()
system.SetSolver(chrono.ChSolverMINRES())
system.GetSolver().SetTolerance(1e-6)
system.GetSolver().SetMaxIterations(100)
system.SetIntegrator(chrono.ChIntegratorHHT(0.001))

# Create terrain
terrain = vehicle.CreateChampPaddedPlane(system)
terrain.SetPos(chrono.ChVectorD(0, 0, 0))
terrain.Set_texture("terrain_texture.jpg")

# Create vehicle
vehicle_config = vehicle.HMMWV()
vehicle_config.vehicle.SetPos(chrono.ChVectorD(0, 0, 1))
vehicle_config.vehicle.SetRot(chrono.ChQuaternionD(1, 0, 0, 0))
vehicle_config.vehicle.Create()
vehicle_config.vehicle.Set Trailer()

# Set up driver
driver = vehicle.ChDriver()
driver.SetSteering(0.5)
driver.SetThrottle(0.8)
vehicle_config.vehicle.SetDriver(driver)

# Initialize Irrlicht
app = chrono.IrrlichtApp(system)
app.SetCameraPos(chrono.ChVectorD(5, 5, 5))
app.AddLight(chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1))

# Add sensors
imu = sensor.ChIMU()
imu.SetPos(chrono.ChVectorD(0, 0, 0))
vehicle_config.vehicle.GetChassis().AddSensor(imu)

gps = sensor.ChGPS()
gps.SetPos(chrono.ChVectorD(0, 0, 0))
vehicle_config.vehicle.GetChassis().AddSensor(gps)

# Simulation loop
while app.Run():
    vehicle_config.vehicle.Update()
    driver.Update()
    imu.Update()
    gps.Update()
    system.DoStepDynamics()
    app.Render()
    print("Vehicle mass:", vehicle_config.vehicle.GetMass())
```

This script sets up a comprehensive simulation with the specified components, ensuring all systems are integrated and synchronized.
