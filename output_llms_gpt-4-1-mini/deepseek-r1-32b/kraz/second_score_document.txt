### 2. Correctness (30 points)

- **Vehicle Initialization and System Setup:**  
  Using `vehicle.GetSystem()` is correct for vehicle simulations. Setting collision system type to BULLET is appropriate.  
  **No deduction.**

- **Quaternion Initialization:**  
  `initRot = chrono.ChQuaterniond(0, 0, 1, 0)` is intended to represent a 180-degree rotation around Y-axis. However, quaternion `(x, y, z, w)` in Chrono is `(x, y, z, w)` with `w` as scalar part. The quaternion `(0,0,1,0)` corresponds to a 180-degree rotation around Z-axis, not Y-axis.  
  The correct quaternion for 180 degrees about Y is `(0,1,0,0)`.  
  This is a **significant error** because the vehicle orientation will be incorrect.  
  **Deduct 15 points for incorrect quaternion initialization.**

- **Vehicle Visualization Type Setting:**  
  The calls to `SetChassisVisualizationType(vis_type, vis_type)` and similar for steering, suspension, wheels, tires use two arguments, but the API generally expects one argument for visualization type. This may be a misuse or redundant. The API documentation shows single argument usage for these methods.  
  This is a **minor API misuse** but unlikely to cause failure.  
  **Deduct 5 points.**

- **Attaching Vehicle to Visualization:**  
  The call `vis.AttachVehicle(vehicle.GetTractor())` is suspicious. The vehicle object is `veh.Kraz()`, which inherits from `ChWheeledVehicle`. The method `GetTractor()` is not a standard method for `veh.Kraz()` or `ChWheeledVehicle`. The correct method to attach the vehicle is `vis.AttachVehicle(vehicle)`.  
  This is a **significant error** that will cause runtime failure or no visualization of the vehicle.  
  **Deduct 15 points.**

- **Driver Inputs Update in Maneuver:**  
  The code updates `driver_inputs.m_steering` directly, but `driver_inputs` is typically a returned object from `driver.GetInputs()` and may not be intended to be modified directly. The proper way to control the driver inputs programmatically is to use driver methods or override input functions.

  **Deduct 10 points.**
