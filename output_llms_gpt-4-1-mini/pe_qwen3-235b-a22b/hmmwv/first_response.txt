```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as chronoirr

# Initialize the Chrono system with SMC contact method
sys = chrono.ChSystemSMC()

# Set up the flat rigid terrain
terrain = veh.RigidTerrain(sys)
patch_mat = chrono.ChMaterialSurfaceSMC()
patch = terrain.AddPatch(patch_mat, chrono.ChCoordsysd(), 200, 100)  # Dimensions: 200m x 100m
patch.SetTexture(chrono.GetChronoDataFile("terrain/textures/grass.png"))  # Load grass texture
terrain.Initialize()

# Create the HMMWV vehicle with TMEASY tire model
hmmwv = veh.HMMWV_Full(sys)  # Full HMMWV model
hmmwv.SetContactMethod(chrono.ChContactMethod_SMC)  # Match system contact method
hmmwv.SetChassisVisualizationType(veh.VisualizationType_MESH)  # Use mesh for chassis
hmmwv.SetSuspensionVisualizationType(veh.VisualizationType_PRIMITIVES)  # Primitives for suspension
hmmwv.SetWheelVisualizationType(veh.VisualizationType_MESH)  # Mesh for wheels
hmmwv.SetTireType(veh.TireModelType_TMEASY)  # TMEASY tire model
hmmwv.SetInitPosition(chrono.ChCoordsysd(chrono.ChVector3d(0, 0, 1.0), chrono.ChQuaterniond(1, 0, 0, 0)))  # Initial position and orientation
hmmwv.Initialize()

# Set up Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('HMMWV Simulation')
vis.AttachSystem(sys)
vis.AddLogo(chrono.GetChronoDataFile("logo_pychrono_alpha.png"))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(0, 3, 6))  # Camera position
vis.AddTypicalLights()
vis.Initialize()

# Configure interactive driver system
driver = veh.ChIrrGuiDriver(vis)  # Irrlicht GUI driver
driver.AttachVehicle(hmmwv.GetVehicle())  # Link to the HMMWV vehicle
driver.Initialize()  # Initialize driver inputs

# Simulation loop running at 50 FPS
while vis.Run():
    time = sys.GetChTime()
    
    # Synchronize driver inputs and vehicle components
    driver.Synchronize(time)
    hmmwv.Synchronize(time, driver.GetInputs(), terrain)
    
    # Advance the simulation by one time step (0.02 seconds)
    sys.DoStepDynamics(1.0 / 50)
    
    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
```

---

### **Explanation of Key Components**

1. **System Initialization**:
   - `chrono.ChSystemSMC()` is used for smooth contact mechanics, suitable for vehicle-terrain interactions.

2. **Terrain Setup**:
   - A `RigidTerrain` with a `ChMaterialSurfaceSMC` ensures realistic contact with the vehicle.
   - The terrain texture is loaded using `GetChronoDataFile()` for path resolution.

3. **Vehicle Configuration**:
   - The `HMMWV_Full` model includes all subsystems (chassis, suspension, tires).
   - `SetTireType(veh.TireModelType_TMEASY)` applies the TMEASY tire model for accurate road interaction.
   - Visualization types are set to mix meshes and primitives for performance and detail.

4. **Driver System**:
   - `ChIrrGuiDriver` captures keyboard inputs (steering, throttle, braking) via Irrlicht.
   - The driver is linked to the vehicle using `AttachVehicle()`.

5. **Visualization**:
   - The Irrlicht engine renders the scene with a skybox, camera, and lighting.
   - The camera is positioned to follow the vehicle from a trailing perspective.

6. **Simulation Loop**:
   - Runs at 50 FPS with `DoStepDynamics(0.02)` to maintain real-time performance.
   - Synchronizes driver inputs and vehicle dynamics in each iteration.

---

This script provides a complete simulation of the HMMWV on flat terrain with interactive controls and realistic tire-terrain interaction using PyChrono's vehicle module.
