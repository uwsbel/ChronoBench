### 2. Correctness (30 points)

- **Visualization system attachment**:  
  - The code uses `sys.SetVisualSystem(vis)`, but the API specifies `vis.AttachSystem(sys)`.  
  - This is a **significant API misuse** that could prevent visualization from working properly.  
  - **Deduct 15 points**.

- **Material assignment**:  
  - `body.SetMaterialSurface(material)` is not a valid method for assigning contact materials in PyChrono.  
  - Materials should be assigned to collision models or contact materials should be created and assigned properly.  
  - This could lead to the material properties not being applied correctly.  
  - **Deduct 10 points**.

- **Collision enabling**:  
  - Bodies never call `EnableCollision(True)`.  
  - Without this, collision detection is disabled, which is a **logical error** affecting simulation behavior.  
  - **Deduct 10 points**.

- **Force application**:  
  - Using `SetF()` replaces the force vector instead of accumulating forces.  
  - This is a **minor correctness issue** but could cause problems if other forces are present.  
  - **Deduct 5 points**.

- **Collision model building**:  
  - The collision model is built, but no collision system type is set for the system (e.g., Bullet).  
  - By default, `ChSystemNSC` uses the default collision system, but explicitly setting it is better practice.  
  - **No deduction**, but could be improved.
