```python
import pychrono as chrono
import pychrono.fea as fea
import pychrono.irrlicht as chronoirr

# 1. Initialize PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Create the beam using FEA
beam_material = fea.ChMaterialShellANCF(rho=7850, E=200e9, nu=0.3)
beam_section = fea.ChSectionShellParametric(
    type=fea.ChSectionShellParametric.PAR_RECTANGLE,
    width=0.1,
    thickness=0.01,
)
beam_geometry = fea.ChGeometryShell()
beam_geometry.AddSegmentCircularArc(
    radius=1.0, start_angle=0, end_angle=180 * chrono.CH_C_PI / 180, num_segments=10
)
beam = fea.ChBeamElementShell(beam_geometry, beam_material, beam_section)
beam.SetFixed(True)

# 3. Add the beam to the system
my_system.Add(beam)

# 4. Define custom motor function for applying a load
def apply_load(time):
    return 1000 * time

# 5. Create a force element and apply the custom load
force_element = chrono.ChForce()
force_element.SetMode(chrono.ChForce.FORCE)
force_element.SetDir(chrono.ChVectorD(0, 1, 0))
force_element.SetVpoint(chrono.ChVectorD(0, 1, 0))
force_element.SetMforce(apply_load)
beam.AddForce(force_element)

# 6. Set up visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Beam Buckling Simulation")
vis.Initialize()

# 7. Set up solver and timestepper
my_system.SetSolverType(chrono.ChSolver.Type_MINRES)
my_system.SetSolverMaxIterations(100)
my_system.SetTimestepperType(chrono.ChTimestepper.Type_EULER_IMPLICIT_LINEARIZED)
my_system.SetTimestep(0.001)

# 8. Simulation loop
while vis.Run():
    my_system.DoStepDynamics(0.001)
    vis.Render()

```

**Explanation:**

1. **Initialization:** We import necessary modules, create a Chrono system, and set the gravitational acceleration.

2. **Beam Creation:** We define the beam's material properties, cross-section, geometry, and create a `ChBeamElementShell` object. We fix one end of the beam.

3. **Adding to System:** The beam is added to the Chrono system.

4. **Custom Load Function:** A function `apply_load` is defined to calculate the force applied to the beam based on time.

5. **Force Application:** A `ChForce` element is created, its mode is set to FORCE, direction is specified, and the custom `apply_load` function is used to define the force magnitude.

6. **Visualization:** We initialize the Irrlicht visualization system, attach it to the Chrono system, and set up the window.

7. **Solver and Timestepper:** We choose a suitable solver (MINRES) and timestepper (Euler Implicit Linearized) for accurate dynamics simulation.

8. **Simulation Loop:** The main loop runs until the visualization window is closed. In each iteration, we perform a dynamics step and render the scene.

**Notes:**

* This script provides a basic framework. You can modify parameters like beam dimensions, material properties, load function, and solver settings to explore different buckling scenarios.
* For more complex simulations, you can add more elements, constraints, and contact interactions.
* You can also use other visualization tools provided by PyChrono.
