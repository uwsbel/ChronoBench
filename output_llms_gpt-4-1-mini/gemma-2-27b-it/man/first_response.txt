```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Create the simulation system and set the parameters
#
# ---------------------------------------------------------------------

# Create the system
system = chrono.ChSystemNSC()

# Set the simulation parameters
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Gravity
system.SetTimestep(0.01)

# ---------------------------------------------------------------------
#
# Create the terrain
#
# ---------------------------------------------------------------------

# Create a rigid terrain
terrain = chrono.ChBodyEasyBox(
    200, 200, 1, 1000, True, True, chrono.ChMaterialSurfaceNSC()
)
terrain.SetPos(chrono.ChVectorD(0, -1, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)

# ---------------------------------------------------------------------
#
# Create the MAN 10t truck
#
# ---------------------------------------------------------------------

# Load the vehicle model
vehicle = chronovehicle.ChVehicle("MAN_10t", system)

# Set vehicle visualization
vehicle.SetChassisVisualizationType(chronovehicle.ChVisualizationType_PRIMITIVES)
vehicle.SetSuspensionVisualizationType(chronovehicle.ChVisualizationType_PRIMITIVES)
vehicle.SetWheelVisualizationType(chronovehicle.ChVisualizationType_MESH)

# Configure the tire model
tire_model = chronovehicle.TMeasyTire()
vehicle.SetTireModel(tire_model)

# ---------------------------------------------------------------------
#
# Add driver controls
#
# ---------------------------------------------------------------------

# Create a driver system
driver = chronovehicle.ChDriver(vehicle)

# Set driver inputs
driver.SetSteeringInput(0)
driver.SetThrottleInput(0)
driver.SetBrakingInput(0)

# ---------------------------------------------------------------------
#
# Set up the Irrlicht visualization
#
# ---------------------------------------------------------------------

# Create the Irrlicht application
vis = chronoirr.ChIrrApp(system, "MAN 10t Truck Simulation", chronoirr.dimension2du(1280, 720))

# Set the camera
camera = vis.GetCamera()
camera.SetFollowMode(chrono.ChFollowMode.CAMERA_FOLLOW_POS_ROT)
camera.SetTarget(vehicle.GetChassis().GetPos())

# Add directional lighting
light = vis.GetSceneManager().addLightSceneNode(0, chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1))

# Add a skybox
vis.AddSkyBox("skybox")

# Set terrain textures and logos (customize as needed)
terrain.GetVisualModel().GetMaterial(0).SetTexture(chrono.ChTexture("terrain_texture.png"))
terrain.GetVisualModel().GetMaterial(0).SetBumpMap(chrono.ChTexture("terrain_bumpmap.png"))

# ---------------------------------------------------------------------
#
# Simulation loop
#
# ---------------------------------------------------------------------

while vis.GetDevice().run():
    vis.BeginScene()
    vis.DrawAll()
    vis.EndScene()

    system.DoStepDynamics(vis.GetTimeStep())

    # Update driver inputs (example)
    driver.SetSteeringInput(vis.GetDevice().GetKeyboard()->GetKeyCode(chrono.KEY_LEFT) - vis.GetDevice().GetKeyboard()->GetKeyCode(chrono.KEY_RIGHT))
    driver.SetThrottleInput(vis.GetDevice().GetKeyboard()->GetKeyCode(chrono.KEY_UP))
    driver.SetBrakingInput(vis.GetDevice().GetKeyboard()->GetKeyCode(chrono.KEY_DOWN))

```

**Explanation:**

1. **Initialization:**

   - Imports necessary PyChrono modules.
   - Creates a `ChSystemNSC` object to manage the simulation.
   - Sets gravity and timestep.

2. **Terrain:**

   - Creates a rigid terrain using `ChBodyEasyBox`.
   - Sets its position and makes it fixed.

3. **Vehicle:**

   - Loads a MAN 10t truck model using `chronovehicle.ChVehicle`.
   - Configures visualization settings for the chassis, suspension, and wheels.
   - Sets the tire model to `TMeasyTire`.

4. **Driver Controls:**

   - Creates a `ChDriver` object to control the vehicle.
   - Sets initial driver inputs to zero.

5. **Irrlicht Visualization:**

   - Creates an Irrlicht application using `chronoirr.ChIrrApp`.
   - Sets up a chase camera that follows the vehicle.
   - Adds directional lighting and a skybox.
   - Applies textures and bump maps to the terrain (customize these paths).

6. **Simulation Loop:**

   - Runs the Irrlicht event loop.
   - Renders the scene using `vis.DrawAll()`.
   - Performs a simulation step using `system.DoStepDynamics()`.
   - Updates driver inputs based on keyboard controls (example).

**Notes:**



* You'll need to have the MAN 10t truck model file available.
* Customize the terrain textures, logos, and other visual settings as desired.
* The driver control logic is basic; you can implement more sophisticated control algorithms.
