```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.postprocess as postprocess

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#

# Create a physical system
system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body
ground = chrono.ChBodyEasyBox(1, 1, 0.2, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
system.Add(ground)

# Create the pendulum bob
bob = chrono.ChBodyEasySphere(0.2, 1000, True, True)
bob.SetPos(chrono.ChVectorD(0, 1, 0))
system.Add(bob)

# Create a revolute joint between the ground and the bob
joint = chrono.ChLinkRevolute()
joint.Initialize(ground, bob, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
system.Add(joint)

# ---------------------------------------------------------------------
#
#  Set up Irrlicht visualization
#

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Simple Pendulum')
vis.Initialize()
vis.AddTypicalLights()
vis.AddCamera(chrono.ChVectorD(2, 2, 2))

# ---------------------------------------------------------------------
#
#  Simulation loop
#

# Set simulation parameters
timestep = 0.01
end_time = 10

# Create a postprocess writer to log data
output_dir = "pendulum_data"
postprocess.ChPostProcess.SetOutDir(output_dir)
writer = postprocess.ChPostProcess(system)
writer.AddLogCallback(lambda: (bob.GetPos(), bob.GetLinVel()))

# Simulation loop
while vis.Run():
    # Advance the simulation
    system.DoStepDynamics(timestep)

    # Write data to the log file
    writer.Write()

# Clean up
vis.Deinitialize()
```

**Explanation:**

1. **Initialization:** The script initializes the PyChrono environment by creating a `ChSystemNSC` object (a non-smooth contact system) and setting the gravitational acceleration.

2. **Physical Systems:**
   - **Ground:** A box-shaped ground body is created using `ChBodyEasyBox` and added to the system.
   - **Pendulum Bob:** A spherical pendulum bob is created using `ChBodyEasySphere` and added to the system.

3. **Joint:** A revolute joint (`ChLinkRevolute`) is created to connect the ground and the bob, allowing the bob to swing freely.

4. **Visualization:**
   - **Irrlicht:** The `chronoirr` module is used to set up Irrlicht visualization, attaching it to the simulation system and creating a window.
   - **Camera:** A camera is added to provide a view of the simulation.

5. **Simulation Loop:**
   - **Timestep:** The simulation runs with a fixed timestep of 0.01 seconds.
   - **Data Logging:** A `ChPostProcess` object is used to log the pendulum's position and velocity periodically.
   - **Visualization:** The `vis.Run()` function handles Irrlicht's event loop, rendering the simulation and updating the visualization.

6. **Cleanup:** After the simulation loop ends, the Irrlicht visualization system is deinitialized.
