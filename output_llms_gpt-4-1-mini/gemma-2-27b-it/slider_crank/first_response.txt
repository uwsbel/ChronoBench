```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add the required physical systems and objects

# a. Floor (truss)
floor_material = chrono.ChMaterialSurfaceNSC()
floor_material.SetFriction(0.8)
floor_material.SetRestitution(0.2)
floor = chrono.ChBodyEasyBox(2, 0.1, 2, 1000, True, True, floor_material)
floor.SetPos(chrono.ChVectorD(0, -1, 0))
floor.SetBodyFixed(True)
my_system.Add(floor)

# b. Crankshaft
crankshaft_radius = 0.2
crankshaft = chrono.ChBodyEasyCylinder(crankshaft_radius, 0.5, 1000, True, True)
crankshaft.SetPos(chrono.ChVectorD(0, 0, 0))
my_system.Add(crankshaft)

# c. Connecting Rod
connecting_rod_length = 1
connecting_rod = chrono.ChBodyEasyBox(0.1, connecting_rod_length / 2, 0.1, 1000, True, True)
connecting_rod.SetPos(chrono.ChVectorD(crankshaft_radius, 0, 0))
my_system.Add(connecting_rod)

# d. Piston
piston_radius = 0.15
piston = chrono.ChBodyEasySphere(piston_radius, 1000, True, True)
piston.SetPos(chrono.ChVectorD(crankshaft_radius + connecting_rod_length, 0, 0))
my_system.Add(piston)

# 3. Set necessary default parameters

# a. Joints
# Crankshaft-Connecting Rod: Revolute joint
revolute_joint = chrono.ChLinkRevolute()
revolute_joint.Initialize(crankshaft, connecting_rod, chrono.ChVectorD(crankshaft_radius, 0, 0))
my_system.Add(revolute_joint)

# Connecting Rod-Piston: Spherical joint
spherical_joint = chrono.ChLinkSphere()
spherical_joint.Initialize(connecting_rod, piston, chrono.ChVectorD(0, connecting_rod_length / 2, 0))
my_system.Add(spherical_joint)

# b. Motor
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(crankshaft, chrono.ChFrameD(chrono.ChVectorD(0, 0, 0), chrono.Q_from_AngAxis(chrono.CH_C_PI_2, chrono.ChVectorD(0, 0, 1))))
motor.SetTargetSpeed(10) # Angular speed in rad/s
my_system.Add(motor)

# 4. Visualization

# a. Irrlicht Visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Crank-Slider Mechanism")

# b. Camera Settings
vis.GetCamera().SetLocation(chrono.ChVectorD(2, 2, 2))
vis.GetCamera().SetLookAt(chrono.ChVectorD(0, 0, 0))

# c. Lighting and Textures (Optional)
# ...

# d. Run the simulation
while vis.Run():
    my_system.DoStepDynamics(0.01)
    vis.Render()
```

**Explanation:**

1. **Initialization:**

* We create a `ChSystemNSC` object for the physics simulation.
* Gravity is set to -9.81 m/s².

2. **Objects:**

* **Floor:** A simple box is used as the ground, with friction and restitution properties.
* **Crankshaft:** A cylinder representing the rotating crankshaft.
* **Connecting Rod:** A box connecting the crankshaft to the piston.
* **Piston:** A sphere representing the moving piston.

3. **Parameters:**

* **Joints:**
    * A `ChLinkRevolute` joint connects the crankshaft and connecting rod, allowing rotation.
    * A `ChLinkSphere` joint connects the connecting rod and piston, allowing free movement.
* **Motor:** A `ChLinkMotorRotationSpeed` is added to the crankshaft to drive it at a constant angular speed.

4. **Visualization:**

* **Irrlicht:** We use Irrlicht for visualization, attaching it to the physics system.
* **Camera:** The camera is positioned and oriented to view the mechanism.

**Customization:**

* **Lighting and Textures:** You can add more realistic lighting and textures to enhance the visualization.

* **Logos:** You can add logos or other visual elements using Irrlicht's features.

* **Simulation Parameters:** Adjust parameters like crankshaft speed, object masses, and joint properties to explore different scenarios.
