```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add SCM terrain with custom soil parameters and moving patch
terrain = chrono.ChTerrainSCM(my_system)
terrain.SetSize(200, 200)  # Set terrain dimensions
terrain.SetLevel(0)  # Set base level

# Customize soil parameters
soil_params = chrono.ChSoilParamsNSC()
soil_params.Set_ cohesion(1000)
soil_params.Set_friction(0.5)
soil_params.Set_density(1500)
terrain.SetSoilParams(soil_params)

# Enable moving patch feature
terrain.SetMovingPatch(True)
terrain.SetPatchSize(5, 5)  # Set patch size

# Visualize sinkage with false color plotting
terrain.SetVisualizationType(chrono.ChTerrainSCM.VisualizationType_FALSE_COLOR)

# 3. Create HMMWV vehicle with rigid tire model and mesh visualization
vehicle = chronovehicle.ChVehicle("HMMWV")
vehicle.SetSystem(my_system)

# Load vehicle chassis and apply mesh visualization
chassis = chronovehicle.ChBodyEasyBox(
    "chassis", 4.0, 2.0, 1.5, 2000
)  # Example chassis dimensions and mass
chassis.SetPos(chrono.ChVectorD(0, 1.0, 0))  # Initial position
vehicle.AddChassis(chassis)
chassis.AddAsset(chrono.ChAssetLevel(chrono.ChBoxShape(chrono.ChVectorD(2, 1, 0.75))))

# Add wheels with rigid tire model and mesh visualization
wheel_radius = 0.5
wheel_width = 0.2
for i in range(4):
    wheel = chronovehicle.ChWheel(
        "wheel_" + str(i),
        chrono.ChVectorD(0, -wheel_radius, 0),
        chrono.ChVectorD(0, 0, 1),
        wheel_radius,
        wheel_width,
        200,
        chrono.ChMaterialSurfaceNSC.DEFAULT,
    )
    wheel.SetVisualizationType(chrono.ChWheel.VisualizationType_MESH)
    vehicle.AddWheel(wheel)

# 4. Set up interactive driver system
driver = chronovehicle.ChDriverSystem(vehicle)
driver.SetSteering(0)  # Initial steering angle
driver.SetThrottle(0)  # Initial throttle
driver.SetBraking(0)  # Initial braking

# 5. Initialize Irrlicht visualization
vis = chronoirr.ChIrrApp(my_system, "HMMWV Simulation", chronoirr.dimension2du(1280, 720))
vis.AddTypicalSky()
vis.AddTypicalLights()
vis.SetCameraPosition(chrono.ChVectorD(10, 5, 0))
vis.SetCameraLookAt(chrono.ChVectorD(0, 1.5, 0))

# 6. Run simulation in real time at 50 FPS
while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()
    my_system.DoStepDynamics(1.0 / 50.0)  # Simulate 1/50th of a second
    vis.EndScene()

    # Handle user input for driver system
    driver.Synchronize(vis.GetDevice().GetElapsedSeconds())
```

**Explanation:**

1. **Initialization:** Sets up the Chrono environment, gravity, and creates a ChSystemNSC object for the simulation.
2. **Terrain:** Creates an SCM terrain with specified dimensions, soil parameters, and a moving patch feature that follows the vehicle. Visualization is set to false color for sinkage representation.
3. **Vehicle:** Creates a HMMWV vehicle with a simplified chassis and four wheels using rigid tire models. Mesh visualization is applied to all components for visual realism.
4. **Driver:** Implements an interactive driver system allowing user control over steering, throttle, and braking.
5. **Visualization:** Initializes Irrlicht for rendering, sets up camera position and lighting, and adds a sky.
6. **Simulation Loop:** Runs the simulation in real time at 50 frames per second, updating vehicle dynamics and rendering the scene. User input is processed to control the driver system.

**Notes:**

* This script provides a basic framework and requires further customization for a complete HMMWV simulation.
* You'll need to obtain appropriate 3D meshes for the vehicle components and terrain.
* The soil parameters and vehicle properties can be adjusted to achieve desired behavior.
* Consider adding collision detection and response for more realistic interaction between the vehicle and terrain.
