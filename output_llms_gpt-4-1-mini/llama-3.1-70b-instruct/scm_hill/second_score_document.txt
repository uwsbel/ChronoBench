  **No deduction.**

- **Obstacles:**  
  Created with `ChBodyEasyBox` with mass density 1000, collision enabled by default, and material set to `ChMaterialSurfaceNSC()`. However, the constructor call is `chrono.ChBodyEasyBox(vehicle.GetSystem(), 1, 1, 1, 1000)` which is incorrect:  
  The documented signature is:  
  ```python
  ChBodyEasyBox(lengthX, lengthY, lengthZ, density, visualize=True, collision=True, material=None)
  ```  

  The first argument should be lengthX, not the system. Passing `vehicle.GetSystem()` as the first argument is incorrect and will cause an error.  
  **Deduct 15 points for incorrect API usage in obstacle creation.**
