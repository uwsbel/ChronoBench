### 2. Correctness (30 points)

- **Incorrect use of `chrono.ChBodyEasyBox`:**

  The constructor signature from the documentation is:

  ```python
  chrono.ChBodyEasyBox(lengthX, lengthY, lengthZ, density, visualize, collision, material)
  ```

  The script calls:

  ```python
  floor_body = chrono.ChBodyEasyBox(sys, 10, 10, 1, 1000, True, floor_mat)
  ```

  and

  ```python
  box_body = chrono.ChBodyEasyBox(sys, 1, 1, 1, 1000, False, box_mat)
  ```

  The first argument should be the box dimensions, not the system. The system is not an argument to `ChBodyEasyBox`. The correct call should be:

  ```python
  floor_body = chrono.ChBodyEasyBox(10, 10, 1, 1000, True, True, floor_mat)
  ```

  The script passes `sys` as the first argument, which is incorrect and will cause an error.

- **Fixed object parameter:**

  The `ChBodyEasyBox` constructor does not take a "fixed" boolean parameter. To fix a body, one must call `body.SetFixed(True)` after creation.

  The script passes `True` or `False` as the fifth argument, presumably to indicate fixed or not, but the signature expects `visualize` and `collision` booleans.

- **Material type:**

  The script uses `chrono.ChMaterialSurfaceNSC()` for materials, but the documentation suggests using `chrono.ChContactMaterialNSC()` for NSC contact materials. `ChMaterialSurfaceNSC` is not a standard class in the API documentation; this is likely an error.

- **ROS handler class name typo:**

  The custom ROS handler class is named `CustomROSHAndler` (capital "H" in "HAndler"), which is inconsistent and likely a typo. Also, the base class is `chrono.ChROSHAndler`, which is not a documented class. The correct class is likely `chrono.ChROSHandler` or similar. This will cause runtime errors.

- **ROS manager class name typo:**

  The script uses `chrono.ChROSMAndler(sys)`, which is not documented. The correct class is likely `chrono.ChROSManager` or `chrono.ChROSHandlerManager`. This is a critical error.

- **ROS handler additions:**

  The script adds handlers `chrono.ChROSClockHandler()`, `chrono.ChROSBodyHandler()`, and `chrono.ChROSTransformHandler()`. These classes are not documented in the provided API. This could be a custom extension or outdated API usage.

- **Gravity setting:**

  The method `sys.Set_G_acc()` is used, but the documented method is `sys.Set_G_acc(chrono.ChVectorD(...))` or `sys.Set_G_acc(chrono.ChVector3d(...))`. The code uses `ChVectorD`, which is not documented; the correct class is `ChVector3d`.

- **Simulation loop:**

  The loop uses `sys.DoStepDynamics(time_step)` and `ros_manager.Advance(sys.GetChTime())`, which is acceptable.

- Incorrect use of `ChBodyEasyBox` constructor (passing system as first argument, wrong parameters): **-15 points**
