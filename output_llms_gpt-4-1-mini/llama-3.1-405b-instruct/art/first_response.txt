Here is a PyChrono simulation script based on the provided instructions:

```python
# Import necessary modules
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# Initialize the PyChrono environment
chrono.SetChronoDataPath("/path/to/chrono/data")

# Create a ChronoEngine physical system
my_system = chrono.ChSystemNSC()

# Create the Irrlicht visualization system
application = chronoirr.ChIrrApp(my_system, "ARTcar Simulation", chronoirr.dimension2du(800, 600))

# Set up the Irrlicht visualization system
application.AddTypicalSky()
application.AddTypicalCamera(chronoirr.vector3df(0, 5, -10))
application.AddTypicalLights()

# Create the RigidTerrain
terrain = chrono.ChBodyEasyBox(my_system,  # Parent system
                                100, 100, 2,  # Dimensions (x, y, z)
                                1000,  # Density
                                True,  # Visualization
                                True,  # Collision
                                chrono.ChMaterialSurfaceNSC())  # Material
terrain.SetPos(chrono.ChVectorD(0, -2, 0))  # Position
terrain.SetBodyFixed(True)  # Fix the terrain in place

# Add a custom texture to the terrain
terrain_texture = chronoirr.ChIrrNodeAsset()
terrain_texture.SetTexture(chronoirr.GetChronoDataFile("textures/concrete.jpg"))
terrain.AddAsset(terrain_texture)

# Create the ARTcar vehicle
vehicle = chrono.ChARTcarI(my_system,  # Parent system
                           chrono.ChVectorD(0, 1, 0),  # Location
                           chrono.ChQuaternionD(1, 0, 0, 0),  # Orientation
                           chrono.ChMaterialSurfaceNSC(),  # Material
                           1.5,  # Contact method (1.5 = NSC)
                           chrono.ChVisualizationMode.ASCENE,  # Visualization type
                           chrono.ChARTcarI.ControlType.ALL)  # Control type

# Initialize the interactive driver system
driver = chrono.ChIrrNodeDriverIrr(application.GetDevice(), vehicle)

# Set up the simulation loop
while application.GetDevice().run():
    # Update the vehicle dynamics
    my_system.DoStepDynamics(0.02)  # Time step (50 FPS)

    # Update the visualization
    application.BeginScene()
    application.DrawAll()
    application.EndScene()
```

This script creates a PyChrono simulation of an ARTcar vehicle on a rigid terrain using Irrlicht for visualization. It initializes the vehicle with specific parameters such as location, orientation, contact method, and visualization type. It also sets up a RigidTerrain with defined dimensions, adds a custom texture, and incorporates an interactive driver system to control the vehicle's steering, throttle, and braking. The simulation loop updates the vehicle dynamics and visualization in real time, displaying the simulation at 50 frames per second.

Note that you should replace `"/path/to/chrono/data"` with the actual path to the Chrono data directory on your system. Also, make sure to install the necessary dependencies, including PyChrono and Irrlicht, before running the script.
