### 2. Correctness (30 points)

  According to the API documentation, the constructors are:

  ```python
  ChBodyEasyBox(lengthX, lengthY, lengthZ, density, visualize, collision, material)
  ChBodyEasySphere(radius, density, visualize, collision, material)
  ```

  The **last argument must be a material object**, not a position vector.

  In the code, the last argument is given as `chrono.ChVectorD(...)` (position), which is incorrect.

- **Setting position:**

  The position should be set via `body.SetPos(chrono.ChVectorD(...))` after creation, not passed as the last argument to the constructor.

- **Missing adding bodies to system:** As noted above.

- **`ChLinkTSDA.Initialize()` usage:**

  The signature is:

  ```python
  Initialize(body1, body2, use_body_coords, posA, posB)
  ```


  This is correct usage.
