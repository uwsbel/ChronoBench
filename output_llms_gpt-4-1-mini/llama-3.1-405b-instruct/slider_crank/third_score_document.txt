### 2. Correctness (30 points)

- **API Usage:**  
  - `ChBodyEasyCylinder` constructor is called with `chrono.ChAxis_Y` as first argument, which is incorrect. According to PyChrono API, `ChBodyEasyCylinder` expects `(radius, height, density, visualize=True, collision=True, material=None)`. The axis is not an argument. The code uses `chrono.ChBodyEasyCylinder(chrono.ChAxis_Y, crank_rad, crank_thick, 1000)`, which is invalid and will cause an error or unexpected behavior.  
  - Similarly for the piston: `ChBodyEasyCylinder(chrono.ChAxis_Y, 0.2, 0.3, 1000)` is incorrect.  
  This is a **significant API misuse** and would cause failure or wrong body creation. Deduct 15 points.
- **Joint Initialization:**  
  - Motor joint initialized with `chrono.ChFramed(crank_center)`. The API expects a `ChCoordsysD` or `ChCoordsys` (frame) for the joint initialization. `ChFramed` is not a standard PyChrono class or alias. This is likely a mistake or a user-defined alias missing in the snippet. This will cause an error.  
  - Similarly, the ball socket joints and planar joint are initialized with `chrono.ChFramed(...)` which is not a documented PyChrono class. The API expects `chrono.ChCoordsysD` or `chrono.ChCoordsys`.  
  This is a **logical error in joint initialization**. Deduct 10 points.
- **Motor Speed Function:**  
  - Uses `chrono.ChFunctionConst(chrono.CH_PI)`. The API documentation shows `ChFunction_Const` (underscore), but the code uses `ChFunctionConst` (no underscore). This is a minor naming inconsistency but may cause an error depending on the PyChrono version.  
  Deduct 5 points for minor inaccuracy.
- **Stopping Condition:**  
  - The simulation stops after 20 seconds, but the comment says "stop simulation after 2 seconds". Minor inconsistency in comment vs code. Minor issue. Deduct 3 points.
- **Use of `vis.GetDevice().closeDevice()`:**  
  - This is a correct way to close the Irrlicht device, so no deduction.
- **Body Rotations:**  
  - The code uses `chrono.Q_ROTATE_Y_TO_Z` and `chrono.Q_ROTATE_Y_TO_X` for rotations. These are standard quaternion constants in PyChrono. Correct usage. No deduction.
- **Accessing motor angle:**  
  - `my_motor.GetMotorAngle()` is used. According to API, `ChLinkMotorRotationSpeed` does not have `GetMotorAngle()`. It has `GetMotorRot()` or `GetMotorRot_dt()`. This is a **logical error**. Deduct 10 points.
