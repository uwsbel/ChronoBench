### 2. Correctness (30 points)

  - The code uses `rover.SetFrame_COG_to_REF(chrono.ChFrameMovingD(...))` with a quaternion constructed as `(1, 0, 0, steering_angle)`.
  - Quaternions are `(w, x, y, z)` and must be normalized. Setting `z` to `steering_angle` directly is incorrect.
  - Also, `SetFrame_COG_to_REF` is not a standard method for updating orientation dynamically in PyChrono.
  - The correct approach would be to set the rotation via `SetRot(chrono.ChQuaternionD(...))` or use a joint to steer wheels.
  - This is a **major logical error** affecting simulation behavior. **-15 points**
