# PyChrono Simulation of a Jeffcott Rotor with IGA Beam

Below is a complete PyChrono simulation script that models a Jeffcott rotor using an Isogeometric Analysis (IGA) beam with a central flywheel and rotational motor:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.fea as fea
import numpy as np

# 1. Initialize the PyChrono environment
chrono.SetChronoDataPath("PATH_TO_CHRONO_DATA")  # Update this path

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Create the IGA beam for the Jeffcott rotor
# Parameters for the IGA beam
beam_length = 1.0  # meters
beam_radius = 0.05  # meters
beam_Young_modulus = 2.1e11  # steel Young's modulus in Pa
beam_density = 7850  # steel density in kg/m^3
beam_poisson_ratio = 0.3

# Create the IGA beam mesh
beam_mesh = fea.ChMesh()

# Create beam nodes (3 nodes for simple Jeffcott rotor)
node0 = fea.ChNodeFEAxyzrot(chrono.ChVectorD(0, 0, 0))
node1 = fea.ChNodeFEAxyzrot(chrono.ChVectorD(beam_length/2, 0, 0))
node2 = fea.ChNodeFEAxyzrot(chrono.ChVectorD(beam_length, 0, 0))
beam_mesh.AddNode(node0)
beam_mesh.AddNode(node1)
beam_mesh.AddNode(node2)

# Create beam element
beam_element = fea.ChElementBeamIGA()
beam_element.SetNodes(node0, node1, node2)

# Set beam properties
beam_section = fea.ChBeamSectionAdvanced()
beam_section.SetDiameter(beam_radius)
beam_section.SetYoungModulus(beam_Young_modulus)
beam_section.SetDensity(beam_density)
beam_section.SetPoissonRatio(beam_poisson_ratio)
beam_element.SetSection(beam_section)

beam_mesh.AddElement(beam_element)

# Add the beam mesh to the system
system.Add(beam_mesh)

# 3. Create the flywheel at the center
flywheel_radius = 0.2  # meters
flywheel_mass = 10.0   # kg
flywheel_inertia = chrono.ChVectorD(0.5*flywheel_mass*flywheel_radius**2,  # Ixx
                                    0.5*flywheel_mass*flywheel_radius**2,  # Iyy
                                    flywheel_mass*flywheel_radius**2)      # Izz

# Create the flywheel body
flywheel = chrono.ChBodyEasyCylinder(beam_radius*2, flywheel_radius, flywheel_density)
flywheel.SetPos(chrono.ChVectorD(beam_length/2, 0, 0))
flywheel.SetMass(flywheel_mass)
flywheel.SetInertiaXX(flywheel_inertia)

# Connect flywheel to the beam
link_flywheel = chrono.ChLinkLockLock()
link_flywheel.Initialize(flywheel, node1)
system.Add(link_flywheel)

# 4. Create the rotational motor at one end
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(node0, node2)  # Connect to first and last nodes
motor.SetMotorFunction(chrono.ChFunction_Const(10.0))  # 10 rad/s constant speed
system.Add(motor)

# 5. Visualization setup
# Create Irrlicht application
vis = chronoirr.ChIrrApp(system, "Jeffcott Rotor Simulation", chronoirr.dimension2du(1024, 768))
vis.AddTypicalLogo()
vis.AddTypicalSky()
vis.AddTypicalLights()
vis.AddTypicalCamera(chrono.ChVectorD(beam_length*1.5, 0, 0))
vis.SetTimestep(0.01)

# Add FEM visualization
beam_vis = fea.ChVisualizationFEAmesh(beam_mesh)
beam_vis.SetFEMdataType(fea.ChVisualizationFEAmesh.E_PLOT_NODE_SPEED_NORM)
beam_vis.SetColorscaleMinMax(0.0, 5.0)
beam_vis.SetSmoothFaces(True)
beam_vis.SetWireframe(False)
beam_mesh.AddAsset(beam_vis)

# Add visualization for the flywheel
flywheel_vis = chrono.ChColorAsset(0.5, 0.5, 0.8)
flywheel.AddAsset(flywheel_vis)

# 6. Simulation loop
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.DoStep()
    vis.EndScene()

    # Print some simulation data
    time = system.GetChTime()
    if time > 0.1 and (int(time*10) % 10 == 0):  # Print every 0.1 seconds
        print(f"Time: {time:.2f}s")
        print(f"Flywheel position: {flywheel.GetPos()}")
        print(f"Motor speed: {motor.GetMotorFunction().Get_y(time)} rad/s")
```

## Key Components Explained:

1. **IGA Beam Setup**:
   - Created with 3 nodes (start, center, end) for simplicity
   - Steel material properties applied
   - Beam element connects all three nodes

2. **Flywheel**:
   - Positioned at the center node of the beam
   - Connected with a lock constraint to maintain rigid connection
   - Has significant mass to create the Jeffcott rotor effect

3. **Rotational Motor**:
   - Connects the first and last nodes of the beam
   - Constant speed function applied (10 rad/s)
   - Drives the rotation of the entire system

4. **Visualization**:
   - Irrlicht window for real-time visualization
   - FEM visualization for the beam showing deformation/speed
   - Standard visualization for the flywheel

5. **Simulation Parameters**:
   - Gravity enabled
   - Timestep set to 0.01s
   - Data output every 0.1s

To run this simulation, you'll need to:
1. Install PyChrono (with all required dependencies)
2. Update the `PATH_TO_CHRONO_DATA` variable to point to your Chrono data directory
3. Adjust parameters like beam length, flywheel mass, and motor speed as needed for your specific simulation requirements

The simulation will show the dynamic behavior of the Jeffcott rotor, including potential whirling effects due to the unbalanced mass distribution.
