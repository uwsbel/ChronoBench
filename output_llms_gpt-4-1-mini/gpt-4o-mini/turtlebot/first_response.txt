Below is a Python script that sets up a PyChrono simulation with a Turtlebot robot on a rigid terrain, following the instructions provided. This script initializes the PyChrono environment, creates the necessary physical systems, and implements a simulation loop with real-time visualization using Irrlicht.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr

# Initialize the Chrono system
chrono.ChSystemNSC()

# Set gravity
chrono.ChSystemNSC.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create ground body (rigid terrain)
ground = chrono.ChBody()
ground.SetBodyFixed(True)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
chrono.ChSystemNSC.Add(ground)

# Create Turtlebot robot
turtlebot = chrono.ChBody()
turtlebot.SetMass(1.0)  # Mass of the Turtlebot
turtlebot.SetInertiaXX(chrono.ChVectorD(0.1, 0.1, 0.1))  # Inertia
turtlebot.SetPos(chrono.ChVectorD(0, 0.1, 0))  # Initial position
turtlebot.SetRot(chrono.ChQuaternionD(1, 0, 0, 0))  # Initial orientation
turtlebot.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
chrono.ChSystemNSC.Add(turtlebot)

# Create visualization with Irrlicht
application = chronoirr.ChIrrApp(chrono.ChSystemNSC, "Turtlebot Simulation", chronoirr.dimension2d(800, 600))
application.AddTypicalSky()
application.AddTypicalLights()
application.AddTypicalCamera(chrono.ChVectorD(0, 2, -5), chrono.ChVectorD(0, 0, 0))

# Set up the simulation loop
time_step = 0.01  # Time step for the simulation
simulation_time = 10.0  # Total simulation time
current_time = 0.0

# Main simulation loop
while current_time < simulation_time:
    # Update the simulation
    chrono.ChSystemNSC.DoStepDynamics(time_step)

    # Control Turtlebot motors for left and right turns
    if 2.0 < current_time < 4.0:  # Turn left
        turtlebot.SetPos(turtlebot.GetPos() + chrono.ChVectorD(-0.1, 0, 0))
    elif 6.0 < current_time < 8.0:  # Turn right
        turtlebot.SetPos(turtlebot.GetPos() + chrono.ChVectorD(0.1, 0, 0))

    # Render the scene
    application.DrawAll()
    application.DoStep()

    # Increment time
    current_time += time_step

# Clean up and exit
application.AssetBindAll()
application.AssetUpdateAll()
application.GetDevice().drop()  # Close the Irrlicht device
```

### Explanation of the Code:
1. **Initialization**: The script initializes the Chrono system and sets gravity.
2. **Ground Body**: A rigid ground body is created and added to the simulation.
3. **Turtlebot**: A Turtlebot is created with specified mass, inertia, position, and orientation.
4. **Irrlicht Visualization**: The script sets up a visualization window using Irrlicht, adding a sky, lights, and a camera.
5. **Simulation Loop**: The loop runs for a specified duration, updating the Turtlebot's position based on time intervals to simulate left and right turns. The scene is rendered at each timestep.

### Note:
Make sure you have the PyChrono library installed and properly configured in your Python environment to run this script. Adjust the Turtlebot's control logic as needed to fit your specific simulation requirements.
