### 2. Correctness (30 points)

- **System and Gravity:** Correct usage.

- **Ground Body:** `ground = chrono.ChBody()` is valid, but the API documentation suggests using `sys.Add(body)` rather than `sys.AddBody(body)`. The code uses `sys.Add(ground)` which is correct.  
  **No deduction.**

- **Pendulum Bodies:** For pendulums, `sys.AddBody(pend_1)` and `sys.AddBody(pend_2)` are used. According to the API, the method is `sys.Add(body)`, not `AddBody()`. This is a minor API misuse that could cause an error or unexpected behavior.  
  **Deduct 15 points for incorrect API usage here.**

- **Inertia Tensor:** `SetInertiaXX` is used with `chrono.ChVector3d(0.2, 1, 1)`. This is acceptable, though the inertia values seem arbitrary but not incorrect.

- **Visual Shapes:** `chrono.ChVisualShapeCylinder` is used correctly.

- **Joint Initialization:**  
  - The revolute joints are initialized with `chrono.ChFramed(chrono.ChVector3d(0, 0, 1), chrono.ChQuaterniond(1, 0, 0, 0))`.  
  - The API documentation specifies `Initialize(body1, body2, chrono.ChCoordsysD(position, rotation))`.  
  - `ChFramed` is a valid alias for `ChCoordsysD`, so this is acceptable.  
  - However, the joint frame position is set at `(0,0,1)` for both joints, which may not correspond to the actual joint location between pendulums. For a double pendulum, the second joint should be at the end of the first pendulum (e.g., at `(2,0,1)` or relative to pend_1). Using `(0,0,1)` for both joints likely places the second joint incorrectly, causing unrealistic behavior.  
  **Deduct 10 points for logical error in joint initialization.**

- **Initial Positions:** Pendulum 1 at `(1,0,1)`, pendulum 2 at `(2,0,1)` — pendulum 2 is placed 1 unit further along X, which is consistent with the pendulum length of 2 units (height of cylinder). However, since the pendulum is horizontal and rotated by `CH_PI_2` around Y, the center of mass is at the middle of the cylinder, so the joint should be at the end of the first pendulum (which is at `(2,0,1)`), but the joint frame is at `(0,0,1)` in absolute coordinates. This mismatch can cause incorrect joint behavior.  
  **No further deduction here beyond the joint initialization deduction.**
