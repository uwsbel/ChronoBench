### 2. Correctness (30 points)

- **Body Creation:**  
  The call `chrono.ChBodyEasyCylinder(chrono.ChAxis_Y, crank_rad, crank_thick, 1000)` is incorrect.  
  According to the API, `ChBodyEasyCylinder` expects parameters: radius, height, density, visualize, collision, material (optional).  
  The first argument should be a float radius, not an axis enum.  
  The code uses `chrono.ChBodyEasyCylinder(chrono.ChAxis_Y, crank_rad, crank_thick, 1000)` which is wrong.  
  This will cause an error or unexpected behavior.  
  The same applies for the piston creation: `chrono.ChBodyEasyCylinder(chrono.ChAxis_Y, 0.2, 0.3, 1000)` is incorrect.  
  **Deduct 15 points for incorrect API usage that affects simulation behavior.**

- **Motor Initialization:**  
  The motor is initialized with `chrono.ChFramed(crank_center)`.  
  The API expects a `ChCoordsys` or `ChCoordsysD` (depending on version) or `chrono.ChCoordsysD` for the frame.  
  `chrono.ChFramed` is not a documented class or constructor in the API.  
  The correct usage is `chrono.ChCoordsysD(crank_center)` or `chrono.ChCoordsys(crank_center)`.  
  This is a significant error and will cause failure or incorrect motor placement.  
  **Deduct 15 points.**

- **Joint Initialization:**  
  The spherical joints and planar joint are initialized with `chrono.ChFramed(...)` which is not a documented class.  
  The API uses `chrono.ChCoordsysD(position, rotation)` or `chrono.ChCoordsys(position, rotation)`.  
  This is a logical error and will cause runtime errors or incorrect joint frames.  
  **Deduct 10 points.**

- **Motor speed function:**  
  The motor speed function is created with `chrono.ChFunctionConst(chrono.CH_PI)`.  
  The API uses `ChFunction_Const` (underscore), not `ChFunctionConst`.  
  This is a minor API naming error but could cause failure.  
  **Deduct 5 points.**

- **Stopping condition:**  
  The simulation stops after 20 seconds by calling `vis.GetDevice().closeDevice()`.  
  This is a correct way to stop the Irrlicht device.  
  **No deduction.**

- **Use of `GetPosDt()` for speed:**  
  `mpiston.GetPosDt().x` is used to get piston speed along x.  
  This is correct.  
  **No deduction.**
