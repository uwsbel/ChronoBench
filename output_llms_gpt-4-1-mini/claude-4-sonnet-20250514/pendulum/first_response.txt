Here's a complete PyChrono simulation script for a simple pendulum with Irrlicht visualization:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# Initialize the PyChrono environment
chrono.SetChronoDataPath('/path/to/chrono/data/')  # Update this path as needed

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create the ground body (fixed)
ground = chrono.ChBodyEasyBox(2, 0.1, 0.5, 1000, True, False)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.SetBodyFixed(True)
ground.SetName("Ground")
system.Add(ground)

# Create the pendulum bob
pendulum_mass = 1.0  # kg
pendulum_radius = 0.1  # m
pendulum_length = 1.0  # m

# Create a sphere for the pendulum bob
pendulum = chrono.ChBodyEasySphere(pendulum_radius, pendulum_mass, True, True)
pendulum.SetPos(chrono.ChVectorD(pendulum_length, 0, 0))  # Initial position
pendulum.SetName("Pendulum")

# Set initial angular velocity (optional - for more interesting motion)
initial_angle = math.pi / 6  # 30 degrees
pendulum.SetPos(chrono.ChVectorD(pendulum_length * math.sin(initial_angle), 
                                -pendulum_length * math.cos(initial_angle), 0))

# Set material properties for the pendulum
pendulum_material = chrono.ChMaterialSurfaceNSC()
pendulum_material.SetFriction(0.3)
pendulum.GetCollisionModel().SetDefaultSuggestedEnvelope(0.01)
pendulum.GetCollisionModel().SetDefaultSuggestedMargin(0.01)

system.Add(pendulum)

# Create a revolute joint to connect ground and pendulum
# The joint will be at the origin (pivot point)
revolute_joint = chrono.ChLinkRevolute()
revolute_joint.Initialize(ground, pendulum, 
                         chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), 
                                          chrono.ChQuaternionD(1, 0, 0, 0)))
system.Add(revolute_joint)

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle("Simple Pendulum Simulation")
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile("logo_pychrono_alpha.png"))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(3, 1, 3), chrono.ChVectorD(0, 0, 0))
vis.AddTypicalLights()

# Add visual elements
# Add a line to visualize the pendulum rod
rod_shape = chrono.ChLineShape()
rod_shape.SetLineGeometry(chrono.ChLineSegment(chrono.ChVectorD(0, 0, 0), 
                                              chrono.ChVectorD(pendulum_length, 0, 0)))
rod_shape.SetColor(chrono.ChColor(0.6, 0.3, 0.0))
rod_shape.SetThickness(0.02)

# Create a visual asset for the rod
rod_visual = chrono.ChVisualShapeLine(rod_shape)
ground.AddVisualShape(rod_visual)

# Simulation parameters
time_step = 0.01
simulation_time = 0
log_interval = 0.1  # Log every 0.1 seconds
next_log_time = 0

print("Starting pendulum simulation...")
print("Time\t\tPosition (x, y, z)\t\tVelocity (x, y, z)\t\tAngle")
print("-" * 80)

# Main simulation loop
while vis.Run():
    vis.BeginScene()
    vis.Render()
    
    # Advance the simulation
    system.DoStepDynamics(time_step)
    simulation_time = system.GetChTime()
    
    # Log pendulum data periodically
    if simulation_time >= next_log_time:
        pos = pendulum.GetPos()
        vel = pendulum.GetPos_dt()
        
        # Calculate angle from vertical
        angle = math.atan2(pos.x, -pos.y)
        
        print(f"{simulation_time:.2f}\t\t"
              f"({pos.x:.3f}, {pos.y:.3f}, {pos.z:.3f})\t\t"
              f"({vel.x:.3f}, {vel.y:.3f}, {vel.z:.3f})\t\t"
              f"{math.degrees(angle):.1f}°")
        
        next_log_time += log_interval
    
    # Update the rod visualization to follow the pendulum
    rod_shape.SetLineGeometry(chrono.ChLineSegment(chrono.ChVectorD(0, 0, 0), 
                                                  pendulum.GetPos()))
    
    vis.EndScene()
    
    # Stop simulation after 10 seconds (optional)
    if simulation_time > 10:
        break

print("Simulation completed.")
```

This script creates a complete pendulum simulation with the following features:

## Key Components:

1. **Physical System Setup**:
   - Initializes PyChrono with NSC (Non-Smooth Contact) system
   - Sets gravity to standard Earth gravity (-9.81 m/s²)

2. **Bodies**:
   - **Ground**: Fixed rectangular body serving as the base
   - **Pendulum**: Spherical bob with specified mass and radius

3. **Joint**:
   - **Revolute Joint**: Connects ground and pendulum, allowing rotation around the pivot point

4. **Visualization**:
   - Irrlicht rendering system with camera, lighting, and skybox
   - Visual rod connecting pivot to pendulum bob
   - Real-time 3D visualization

5. **Data Logging**:
   - Periodic logging of position, velocity, and angle
   - Formatted output showing simulation progress

## Parameters (easily adjustable):
- `pendulum_mass`: Mass of the pendulum bob (1.0 kg)
- `pendulum_radius`: Radius of the spherical bob (0.1 m)
- `pendulum_length`: Length of the pendulum (1.0 m)
- `initial_angle`: Starting angle from vertical (π/6 radians = 30°)
- `time_step`: Simulation timestep (0.01 seconds)

## Usage Notes:
1. Update the `chrono.SetChronoDataPath()` to point to your PyChrono data directory
2. The simulation runs for 10 seconds by default but can be modified
3. The pendulum starts at a 30-degree angle for interesting motion
4. Console output shows real-time position, velocity, and angle data

The simulation demonstrates classical pendulum physics with energy conservation and periodic motion, perfect for educational or research purposes.
