Here's a complete PyChrono script that demonstrates a single mass-spring-damper system using `ChLinkTSDA`:

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import math

# Initialize the PyChrono environment
chrono.SetChronoDataPath('PYCHRONO_DATA_DIR')

# Create the physical system
system = chrono.ChSystemNSC()

# Set gravity
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body (fixed)
ground = chrono.ChBody()
ground.SetBodyFixed(True)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(ground)

# Add visual shape for ground (a box to represent the fixed point)
ground_shape = chrono.ChBoxShape()
ground_shape.GetBoxGeometry().Size = chrono.ChVectorD(0.2, 0.2, 0.2)
ground.AddVisualShape(ground_shape, chrono.ChFrameD())

# Create the mass body
mass = 2.0  # kg
mass_body = chrono.ChBody()
mass_body.SetMass(mass)
mass_body.SetPos(chrono.ChVectorD(0, -2, 0))  # Start 2 meters below ground
mass_body.SetBodyFixed(False)

# Set inertia for the mass body
inertia = chrono.ChVectorD(0.1, 0.1, 0.1)
mass_body.SetInertiaXX(inertia)

# Add visual shape for the mass (a sphere)
mass_shape = chrono.ChSphereShape()
mass_shape.GetSphereGeometry().rad = 0.3
mass_body.AddVisualShape(mass_shape, chrono.ChFrameD())

# Set color for the mass (blue)
mass_body.GetVisualShape(0).SetColor(chrono.ChColor(0.2, 0.2, 0.8))

system.Add(mass_body)

# Create the spring-damper connection using ChLinkTSDA
spring_damper = chrono.ChLinkTSDA()

# Connect the mass to the ground
spring_damper.Initialize(ground, mass_body, True, 
                        chrono.ChVectorD(0, 0, 0),     # Ground attachment point
                        chrono.ChVectorD(0, 0, 0))     # Mass attachment point (relative to mass body)

# Set spring-damper parameters
rest_length = 1.5  # meters (equilibrium position)
spring_constant = 100.0  # N/m
damping_constant = 5.0   # N*s/m

spring_damper.SetRestLength(rest_length)
spring_damper.SetSpringCoefficient(spring_constant)
spring_damper.SetDampingCoefficient(damping_constant)

# Add the spring-damper to the system
system.Add(spring_damper)

# Create visualization for the spring
spring_shape = chrono.ChSpringShape()
spring_shape.GetSpringGeometry().radius = 0.1
spring_shape.GetSpringGeometry().turns = 8
spring_shape.GetSpringGeometry().length = rest_length
spring_damper.AddVisualShape(spring_shape)

# Set color for the spring (red)
spring_damper.GetVisualShape(0).SetColor(chrono.ChColor(0.8, 0.2, 0.2))

# Give the mass an initial velocity to start oscillation
mass_body.SetPos_dt(chrono.ChVectorD(0, 0.5, 0))  # Initial velocity upward

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('Mass-Spring-Damper System')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(4, 2, 4))
vis.AddTypicalLights()

# Set up the simulation parameters
step_size = 0.01  # seconds
simulation_time = 20.0  # seconds

# Run the simulation
time = 0
while vis.Run() and time < simulation_time:
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    
    # Advance the simulation
    system.DoStepDynamics(step_size)
    time += step_size
    
    # Optional: Print some information every second
    if int(time * 10) % 10 == 0:
        pos_y = mass_body.GetPos().y
        vel_y = mass_body.GetPos_dt().y
        spring_force = spring_damper.Get_SpringReact()
        print(f"Time: {time:.1f}s, Position: {pos_y:.3f}m, Velocity: {vel_y:.3f}m/s")
```

This script creates a comprehensive mass-spring-damper simulation with the following features:

## Key Components:

1. **Physical System Setup**:
   - Creates a fixed ground body as the anchor point
   - Creates a movable mass body (2 kg sphere)
   - Connects them with a `ChLinkTSDA` spring-damper element

2. **Spring-Damper Parameters**:
   - Rest length: 1.5 meters
   - Spring constant: 100 N/m
   - Damping constant: 5 N·s/m
   - These provide realistic oscillatory motion with gradual decay

3. **Visual Elements**:
   - Ground: Small gray box representing the fixed anchor
   - Mass: Blue sphere (0.3m radius)
   - Spring: Red coil spring visualization that shows compression/extension

4. **Irrlicht Visualization**:
   - Proper camera positioning for good view of the system
   - Lighting setup for clear visibility
   - Sky box for better visual context

5. **Simulation Settings**:
   - 0.01 second time step for smooth motion
   - 20 second total simulation time
   - Initial upward velocity to start oscillation
   - Real-time feedback showing position, velocity, and spring force

The simulation will show the mass oscillating up and down, with the spring visually compressing and extending, while the damping gradually reduces the amplitude of oscillations over time.
