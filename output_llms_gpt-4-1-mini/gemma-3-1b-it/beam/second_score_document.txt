  The code uses `msection.SetSectionRotation(45 * chrono.CH_RAD_TO_DEG)`.  
  `CH_RAD_TO_DEG` converts radians to degrees (≈57.2958). The argument `45` is presumably degrees already, so multiplying by `CH_RAD_TO_DEG` results in ~2578 degrees, which is incorrect. The correct usage would be either:  
  - `45 * chrono.CH_DEG_TO_RAD` (to convert degrees to radians), or  
  - just `45` if the API expects degrees, or  
  - use radians directly (e.g., `chrono.CH_C_DEG_TO_RAD * 45`).
