  Using `veh.Kraz()` and `veh.Sedan()` without explicit system creation is acceptable, but the code calls `truck.SetTireModelType()` **after** `Initialize()`. According to vehicle API best practices, tire model type should be set **before** `Initialize()` because `Initialize()` creates tires based on the tire model type. Setting tire model after initialization will have no effect or cause inconsistencies.  
  **Deduction:** -15 points (significant API misuse affecting simulation behavior).

- **Chassis Visualization:**  
  The call `truck.SetChassisVisualizationType(vis_type, vis_type)` passes two arguments, but the API expects one argument for chassis visualization type. Similar calls for steering, suspension, wheel, and tire visualization pass two arguments, which is inconsistent with the API that usually expects one argument per visualization type. This may cause errors or unexpected behavior.  
  **Deduction:** -10 points (incorrect API usage).
