### 2. Correctness (30 points)

- **Quaternion for Terrain Patch Orientation:**  
  The provided code uses `chrono.QuatFromAngleZ(-1.57 * 2)` to represent a -90 degree rotation about Z, which is incorrect.  
  - π/2 ≈ 1.5708, so -1.57 * 2 ≈ -3.14 radians, which is -180 degrees, not -90 degrees.  
  - The reference uses a proper quaternion:  
    ```python
    quat = chrono.ChQuaterniond()
    quat.SetFromAngleAxis(-math.pi/2, chrono.ChVector3d(0, 0, 1))
    ```  
  This is the correct way to represent a -90 degree rotation about Z.  
  This mistake could cause the terrain patch to be incorrectly oriented, affecting collision and visualization.
