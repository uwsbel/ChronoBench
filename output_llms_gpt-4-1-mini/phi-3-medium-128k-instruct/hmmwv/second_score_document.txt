### 2. Correctness (30 points)

- **API Usage:**  
  - `chrono.SetChronoDataPath(chrono.GetChronoDataPath())` is redundant but harmless.  
  - `veh.SetDataPath(chrono.GetChronoDataPath() + 'vehicle/')` is correct.  
  - Vehicle initialization and parameter setting follow documented API usage.

  - Visualization setup uses `veh.ChWheeledVehicleVisualSystemIrrlicht()`, which is the correct visualization class for vehicles.  
  - The simulation loop correctly calls `Synchronize()` and `Advance()` on all modules.  
  - Real-time timer usage is appropriate.  
  - The sentinel and target points are updated and visualized correctly.  
  - The path follower driver is used properly with PID gains and throttle.  

- **Potential Issues:**  
  - The vehicle system collision type is set to BULLET after vehicle initialization. According to best practices, collision system type should be set before initialization to ensure proper setup. Here, `vehicle.GetSystem().SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)` is called **after** `vehicle.Initialize()`. This can lead to unexpected behavior or ignored collision system settings.  
  - The `path_follower.SetThrottle(constant_throttle)` is called before `Initialize()`, which is acceptable, but the steering input is not explicitly set or updated; the path follower may handle this internally, but it is not clear.  
  - The `vis.AddLightDirectional()` is used instead of `vis.AddTypicalLights()`. The latter is recommended for better lighting setup. This is a minor visualization correctness issue.  
  - The sentinel and target points are updated every step and spheres are added every loop iteration without clearing previous spheres, which may cause accumulation of spheres and degrade performance or clutter visualization. Usually, visual elements that change every frame should be updated or cleared, or added once per frame. This is a minor logical issue.  

**Major correctness issue: setting collision system type after initialization:** -15 points  
**Minor visualization lighting issue:** -2 points  
**Minor visualization accumulation issue (adding spheres every frame without clearing):** -3 points
