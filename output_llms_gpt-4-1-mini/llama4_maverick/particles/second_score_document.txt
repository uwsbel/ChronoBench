### 2. Correctness (30 points)

- **Use of `ChContactMaterialNSC` in `ChBodyEasySphere`**:  
  The constructor for `ChBodyEasySphere` expects a material pointer for contact material. The code creates `sphere_mat` as `ChContactMaterialNSC()` and passes it as the last argument.  
  However, according to the PyChrono API, `ChBodyEasySphere` expects a `ChMaterialSurface` pointer, not a `ChContactMaterialNSC` object directly. Usually, one creates a `ChMaterialSurfaceNSC` or `ChMaterialSurfaceSMC` and passes that.  
  The code uses `ChContactMaterialNSC()` which is a contact material, not a surface material. This is an API misuse and could cause incorrect behavior or errors.  
  **Deduct 15 points** for incorrect API usage here.

- **Collision System Access and Binding**:  
  The code calls `coll = sys.GetCollisionSystem()`, then passes `coll` to the callback for binding items. However, `GetCollisionSystem()` returns a `ChCollisionSystem` pointer, which is not typically used for binding visual items. Usually, the visual system binds items, and collision system manages collision shapes internally.  
  This is not a critical error but an unusual usage. No direct API method `BindItem` is documented for collision system.  
  **Deduct 5 points** for minor API misuse or unclear usage.

- **Use of `SetUseGyroTorque(False)`**:  
  This disables gyroscopic torque on the body, which is acceptable but should be justified. No error here.

### 4. Efficiency (10 points)

- **Force Calculation Using `combinations`**:  
  Calculating gravitational forces between all pairs of bodies using `combinations(sys.GetBodies(), 2)` is O(n²) and can be very expensive for large numbers of bodies (e.g., thousands of particles).  
  This is a known inefficiency in naive N-body simulations.  
  **Deduct 5 points** for inefficient force calculation.

- **Repeated Calls to `sys.GetBodies()`**:  
  The code calls `sys.GetBodies()` multiple times inside the loop (once for combinations, once for kinetic energy). It would be more efficient to store the list once.
