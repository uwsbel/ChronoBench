```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize PyChrono
chrono.SetChronoDataPath("./")  # Set the path to your Chrono data files
system = chrono.ChSystemNSC()

# Create the ground
ground = chrono.ChBodyEasyBox(10, 10, 1, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(ground)

# Create the mass
mass = chrono.ChBodyEasySphere(1, 10)
mass.SetPos(chrono.ChVectorD(0, 0, 1))
system.Add(mass)

# Create the spring-damper connection
link = chrono.ChLinkTSDA(mass, ground)
link.SetSpringParam(100, 10)  # Spring stiffness and damping coefficient
system.Add(link)

# Irrlicht visualization
vis_app = vis.ChIrrApp(system, 'Single Mass-Spring-Damper')
vis_app.AddCamera(
    chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0)
)
vis_app.AddLight(chrono.ChVectorD(5, 5, 5))

# Set visual shapes
mass.GetVisualShape().SetMaterial(chrono.ChColorAsset(1, 0, 0))  # Red color
link.GetVisualShape().SetMaterial(chrono.ChColorAsset(0, 1, 0))  # Green color

# Run the simulation
vis_app.SetTimestep(0.01)
vis_app.Start()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules (`pychrono` and `pychrono.irrlicht`).
   - Initializes the PyChrono system (`chrono.ChSystemNSC()`).
   - Sets the path to Chrono data files (`chrono.SetChronoDataPath()`).

2. **Physical Systems:**
   - Creates a ground plane using `chrono.ChBodyEasyBox()`.
   - Creates a mass sphere using `chrono.ChBodyEasySphere()`.
   - Connects the mass to the ground using `chrono.ChLinkTSDA()`, which represents a spring-damper system.
   - Sets default spring and damping parameters for the connection.

3. **Visualization:**
   - Initializes Irrlicht visualization using `chrono.ChIrrApp()`.
   - Adds a camera with a specific position, target, and up vector.
   - Adds a light source.
   - Sets visual shapes for the mass and spring using materials and colors.

4. **Simulation:**
   - Sets the simulation timestep (`vis_app.SetTimestep()`).
   - Starts the simulation loop (`vis_app.Start()`).

**Key Points:**

- `ChLinkTSDA` is used to create the spring-damper connection.
- Default spring and damping parameters are used, but you can customize them.
- Irrlicht visualization provides a visual representation of the simulation.
- Camera and lighting settings can be adjusted for better viewing.
