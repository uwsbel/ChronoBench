```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create ground body
ground = chrono.ChBodyEasyBox(10, 10, 0.1, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(ground)

# Initialize Turtlebot
turtlebot = chrono.ChBodyEasySphere(0.2, 10)
turtlebot.SetPos(chrono.ChVectorD(0, 0, 0.1))
turtlebot.SetRot(chrono.Q_from_Euler(chrono.ChVectorD(0, 0, 0)))  # Initial orientation
system.Add(turtlebot)

# Add motors
left_motor = chrono.ChMotorRotation(
    chrono.ChCoordsysD(0, 0, 0.1, chrono.Q_from_Euler(chrono.ChVectorD(0, 0, 0))),
    chrono.ChVectorD(0, 0, 1),
    turtlebot,
    chrono.ChLinkMotorRotation(
        chrono.ChVectorD(0, 0, 1),
        chrono.ChVectorD(0, 0, 0),
        chrono.ChVectorD(0, 0, 0)
    )
)
right_motor = chrono.ChMotorRotation(
    chrono.ChCoordsysD(0, 0, -0.1, chrono.Q_from_Euler(chrono.ChVectorD(0, 0, 0))),
    chrono.ChVectorD(0, 0, -1),
    turtlebot,
    chrono.ChLinkMotorRotation(
        chrono.ChVectorD(0, 0, -1),
        chrono.ChVectorD(0, 0, 0),
        chrono.ChVectorD(0, 0, 0)
    )
)
system.Add(left_motor)
system.Add(right_motor)

# Irrlicht visualization
vis = chronoirr.ChIrrApp(system, 'Turtlebot Simulation', chronoirr.dimension2du(800, 600))
vis.AddCamera(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0))
vis.AddLight(chrono.ChVectorD(5, 5, 5))

# Simulation loop
while vis.Run():
    # Control motors
    left_motor.SetMotorSpeed(1.0)  # Set left motor speed
    right_motor.SetMotorSpeed(-1.0)  # Set right motor speed
    # ... (Add logic for controlling motor speeds at specific times)

    # Update simulation
    system.DoStepDynamics(0.01)

    # Render visualization
    vis.Render()

# Cleanup
vis.GetDevice().drop()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries (pychrono and chronoirr).
   - Creates a Chrono system (`system`) with gravity set to -9.81 m/s^2.
   - Creates a ground body (`ground`) as a box with specified dimensions and mass.
   - Initializes the Turtlebot (`turtlebot`) as a sphere with a position and orientation.

2. **Adding Motors:**
   - Creates two motor objects (`left_motor` and `right_motor`) for controlling the Turtlebot's movement.
   - Each motor is attached to a corresponding link on the Turtlebot.
   - Motor speeds are set using `SetMotorSpeed()`.

3. **Visualization:**
   - Creates an Irrlicht visualization object (`vis`) to display the simulation.
   - Adds a camera with a specific position and orientation.
   - Adds a light source for illumination.

4. **Simulation Loop:**
   - Runs a loop using `vis.Run()`, which handles rendering and user interaction.
   - Inside the loop:
     - Controls the motors using `SetMotorSpeed()`. You can add logic here to control motor speeds at specific times.
     - Updates the simulation using `system.DoStepDynamics()`, advancing the simulation by 0.01 seconds each step.
     - Renders the visualization using `vis.Render()`.

5. **Cleanup:**
   - Releases resources by dropping the Irrlicht device (`vis.GetDevice().drop()`).
