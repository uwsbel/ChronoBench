### 2. Correctness (30 points)

- **Use of `chrono.ChPhysicsItem` and `Update` method:**  
  The `GravitationalForce` class overrides `Update(self, time, update_assets=True)`. According to PyChrono API, the method to override for custom physics items is `Update()` or `Update(time, update_assets)`. This is acceptable. However, the method does not call `super().Update(time, update_assets)`, which is recommended to ensure base class updates.  
  This is a minor correctness issue.  
  **Deduct 5 points.**

- **Force Application:**  
  Forces are applied via `body_i.AddForce(force)` and `body_j.AddForce(-force)`. This is correct for mutual gravitational attraction.  
  **No deduction.**

- **Body Initialization:**  
  - The inertia tensor for spheres is set as `0.4 * mass * radius^2` for each axis. The correct moment of inertia for a solid sphere is `(2/5) * mass * radius^2 = 0.4 * mass * radius^2`. This is correct.  
  - For boxes, inertia is computed as `mass * (sum of squares of other two dimensions) / 3`. This matches the formula for a cuboid's inertia tensor diagonal elements.  
  **No deduction.**

- **Visual Shape Creation:**  
  The script uses `chrono.ChSphereShape(radius)` and `chrono.ChBoxShape(size*2)`. According to the API, the classes are `ChVisualShapeSphere` and `ChVisualShapeBox`. The script uses `ChSphereShape` and `ChBoxShape`, which are **not** valid PyChrono classes. This is a **significant API misuse** that will cause runtime errors or no visualization.  
  **Deduct 15 points.**

- **Setting Initial Velocity:**  
  The script uses `body.SetPos_dt(vel)`. According to the API, `SetPos_dt()` sets linear velocity. This is correct.  
  **No deduction.**

- **Adding Bodies to System:**  
  The script uses `self.system.Add(body)`. The correct method is `Add(body)` on the system, so this is correct.  
  **No deduction.**

- **Disabling Default Gravity:**  
  The script calls `system.Set_G_acc(chrono.ChVectorD(0, 0, 0))` to disable default gravity. This is correct.  
  **No deduction.**

- **Collision System:**  
  The system sets collision system type to BULLET but bodies have collisions disabled (`SetCollide(False)`). This is not an error but may be unnecessary to set collision system if no collisions occur. Minor inefficiency.  
  **Deduct 3 points** for unnecessary collision system setup.
