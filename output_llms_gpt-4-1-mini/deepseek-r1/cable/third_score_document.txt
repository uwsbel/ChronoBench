- **End Box Creation:**  
  Boxes are created with mass and inertia set. However, the box visualization is created with `chrono.ChVisualShapeBox(0.05, 0.05, 0.05)`. According to the API, `ChVisualShapeBox` expects a `ChVector` size, not three separate floats. This is a **minor API misuse**. The correct call should be:  
  ```python
  chrono.ChVisualShapeBox(chrono.ChVectorD(0.05, 0.05, 0.05))
  ```  
  or  
  ```python
  chrono.ChVisualShapeBox(chrono.ChVector3d(0.05, 0.05, 0.05))
  ```  
  The current code passes three floats directly, which is incorrect and will cause an error or unexpected behavior.  
  **Deduct 15 points for incorrect API usage that could cause failure.**

  **No deduction (minor).**
