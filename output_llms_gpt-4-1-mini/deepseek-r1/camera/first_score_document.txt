### 2. Correctness (30 points)

- **System Gravity:**  
  Gravity is set to zero vector `(0,0,0)`. This is acceptable if the simulation is intended to be gravity-free (e.g., orbital camera).  
  **No deduction.**

- **Orbiting Body Mass:**  
  The orbiting body is set with zero mass to make it kinematic.  
  According to PyChrono best practices, to make a body kinematic, one should use `SetBodyFixed(True)` or set the body as kinematic explicitly. Setting mass to zero is not the recommended way and may cause issues in dynamics.  
  **Deduct 10 points** for incorrect method to make a body kinematic.

- **Mesh Loading:**  
  The mesh is loaded using `ChObjFileShape` and added as an asset to the body. This is correct.  
  However, collision is not enabled on the mesh body (`EnableCollision` is not called). If collision is desired, this is missing. Since the mesh is fixed and no collision is mentioned, this is acceptable.  
  **No deduction.**

- **Camera Frame Initialization:**  
  The camera is initialized with a frame at `(0,0,0)` and rotation from `chrono.Q_from_AngAxis(0, chrono.ChVectorD(0,1,0))`.  
  The angle is zero, so this is effectively the identity quaternion. This is acceptable.  
  **No deduction.**

- **Noise Model:**  
  Noise is added with mean 0.0 and std 0.1, which is reasonable.  
  **No deduction.**

- **Camera Filters:**  
  Visualization filter is added correctly.  
  **No deduction.**

- **Simulation Loop:**
