  - The `vehicle.SetChassisVisualizationType(vis_type, vis_type)` uses two arguments, but the API typically expects one argument for chassis visualization type. However, in the vehicle module, some methods accept two arguments for different parts (e.g., chassis and chassis collision). This is acceptable if the API supports it.
