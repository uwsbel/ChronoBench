### 2. Correctness (30 points)

- **PID Controller Implementation**:  
  The PID derivative term is incorrectly computed:  
  ```python
  pid_derivative = (pid_error - pid_derivative) / step_size
  ```  
  Here, `pid_derivative` is used as previous error, but it actually holds the previous derivative value. This is a logical error. The derivative term should be computed as the difference between current and previous error divided by step size.  
  This will cause incorrect throttle input calculation.  
  **Deduct 10 points** for logical error in PID derivative calculation.

- **Throttle Input Application**:  
  The computed `throttle_input` is never applied to the driver or vehicle. The driver inputs are fetched but not modified. This means the PID controller has no effect on the simulation.  
  **Deduct 15 points** for incorrect use of API / missing linkage of control input.

  **No deduction.**
