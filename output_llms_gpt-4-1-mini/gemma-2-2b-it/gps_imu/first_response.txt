```python
import pychrono as chrono
import pychrono.irrlicht as irr
import pychrono.sensor as sensor

# Initialize PyChrono
chrono.init()

# Create Irrlicht engine
engine = irr.IrrlichtEngine()

# Create the world
world = chrono.World()

# Create a HMMWV vehicle
vehicle = chrono.Vehicle(world, "HMMWV", "HMMWV_Model.obj")

# Set vehicle parameters
vehicle.mass = 2500  # kg
vehicle.length = 4.5  # m
vehicle.width = 2.0  # m

# Define terrain
terrain = chrono.Terrain(world, "terrain.png")
terrain.set_height(0.5)  # m

# Define driver
driver = chrono.Driver(vehicle)

# Define IMU and GPS sensors
imu = sensor.IMU(vehicle)
gps = sensor.GPS(vehicle)

# Set initial sensor data
imu.set_angle(0)
gps.set_position((0, 0, 0))

# Set default forces and interactions
vehicle.set_force(chrono.Force(vehicle.mass * 9.81, chrono.Vector(0, 0, 1)))  # Gravity
vehicle.set_friction(0.8)

# Define simulation loop
while True:
    # Update sensor data
    imu.update()
    gps.update()

    # Update vehicle position and velocity
    vehicle.update()

    # Update terrain and other objects
    terrain.update()

    # Render the scene
    engine.render()

    # Output vehicle mass
    print("Vehicle mass:", vehicle.mass)

# Clean up PyChrono
chrono.shutdown()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Initialize PyChrono using `chrono.init()`.
   - Create an Irrlicht engine using `irr.IrrlichtEngine()`.

2. **World and Vehicle:**
   - Create a PyChrono `World` object.
   - Create a `Vehicle` object using the `HMMWV` model.
   - Set vehicle mass, length, and width.

3. **Terrain and Sensors:**
   - Create a `Terrain` object with a specified image.
   - Define `IMU` and `GPS` sensors attached to the vehicle.

4. **Sensor Data:**
   - Initialize sensor data with initial values.

5. **Simulation Loop:**
   - Run a continuous loop.
   - Inside the loop:
     - Update sensor data using `imu.update()` and `gps.update()`.
     - Update vehicle position and velocity using `vehicle.update()`.
     - Update terrain and other objects.
     - Render the scene using `engine.render()`.
     - Output vehicle mass.

6. **Cleanup:**
   - Shut down PyChrono using `chrono.shutdown()`.

**Notes:**

- Replace `"HMMWV_Model.obj"` with the path to your HMMWV model file.
- Replace `"terrain.png"` with the path to your terrain image.
- Adjust parameters like gravity, friction, and initial sensor values as needed.
- This is a basic template; you'll need to add more complex interactions, driver input, and visual elements to create a full simulation.
- Refer to the PyChrono and Irrlicht documentation for more details and advanced features.
