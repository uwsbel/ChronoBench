- **Body Creation**:  
  The script creates bodies using `chrono.Body(chrono.BodyType.GROUND)` and `chrono.Body(chrono.BodyType.RIGID_BODY)`. Also, inertia is set incorrectly (see correctness).  
  **Deduct 15 points**

- **Joint Creation**:  
  The script uses `chrono.RevoluteJoint(pendulum, ground)`, but the API specifies `chrono.ChLinkLockRevolute()` and then `Initialize(body1, body2, frame)`. The joint is not properly initialized with a frame.
