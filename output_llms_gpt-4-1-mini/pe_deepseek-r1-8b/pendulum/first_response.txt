To create a simple pendulum simulation using PyChrono with Irrlicht visualization, follow these steps:

### Step-by-Step Explanation

1. **Import Necessary Libraries**
   - Import standard libraries and PyChrono modules for physics, robot, and visualization.

2. **Initialize the PyChrono System**
   - Create a Non-Smooth Contact (NSC) system for handling collisions and rigid body interactions.

3. **Set Up Visualization**
   - Create an Irrlicht-based visualization system, attach it to the PyChrono system, and configure the window settings.

4. **Create the Ground Body**
   - Define a static ground body positioned at the origin and fix it in space.

5. **Create the Pendulum Body**
   - Define a pendulum body as a sphere with specified mass, position, and density.

6. **Set Up the Revolute Joint**
   - Connect the pendulum to the ground using a revolute joint, setting the pivot point at the origin.

7. **Set Up Gravity and Visualization**
   - Define the gravity acceleration and set up the visualization with a camera and ground shape.

8. **Simulation Loop**
   - Use a loop to update the simulation step-by-step, render the scene, and log the pendulum's position and velocity.

### Code Implementation

```python
import os
import math
import numpy as np
from pychrono import chrono, irrrlicht as chronoirr
from pychrono.robot import *
from pychrono.vehicle import *
from pychrono.irrlicht import ChVisualShapePlane, ChColor

# Initialize the PyChrono system
sys = chrono.ChSystemNSC()

# Set the data path for assets
chrono.SetChronoDataPath(os.path.join(os.path.dirname(__file__), "data"))

# Initialize the visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle("Pendulum Simulation")
vis.Initialize()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(0, 5, 10))

# Create the ground body
ground_body = chrono.ChBody()
ground_body.SetPos(chrono.ChVector3d(0, 0, 0))
ground_body.SetMass(0)
ground_body.SetFixed(True)
sys.Add(ground_body)

# Create the pendulum body
pendulum_body = chrono.ChBodyEasySphere(0.1, 1000, True, True, chrono.ChContactMaterialNSC())
pendulum_body.SetPos(chrono.ChVector3d(0, -1, 0))
sys.Add(pendulum_body)

# Create the revolute joint
joint = chrono.ChLinkLockRevolute()
joint.Initialize(ground_body, pendulum_body, chrono.ChCoordsysD(chrono.ChVector3d(0, 0, 0), chrono.QuatFromAngleX(math.pi / 2)))

# Set gravity
sys.SetGravity(chrono.ChVector3d(0, -9.81, 0))

# Add visual shapes
pendulum_shape = chrono.ChVisualShapeSphere(0.1)
pendulum_body.AddVisualShape(pendulum_shape)
ground_shape = chrono.ChVisualShapePlane(chrono.ChPlaneXY)
ground_body.AddVisualShape(ground_shape)

# Set up logging
log_interval = 50
last_log_time = 0
position_log = []
velocity_log = []

def OnReportPosition(body, time):
    global last_log_time, position_log, velocity_log
    if time - last_log_time >= log_interval:
        pos = body.GetPos()
        vel = body.GetVelocity()
        position_log.append(f"Time: {time:.3f}, Position: ({pos.x:.3f}, {pos.y:.3f}, {pos.z:.3f})")
        velocity_log.append(f"Time: {time:.3f}, Velocity: ({vel.x:.3f}, {vel.y:.3f}, {vel.z:.3f})")
        last_log_time = time

# Register the callback
sys.GetContactContainer().RegisterAddContactCallback(OnReportPosition)

# Start the simulation
time_step = 0.001
while True:
    sys.DoStepDynamics(time_step)
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    if vis.Run():
        continue
    break

# Exit the simulation
vis.Destroy()
```

### Explanation

- **System Initialization**: The simulation starts by initializing the PyChrono system with Non-Smooth Contact (NSC) mechanics.
- **Visualization Setup**: The Irrlicht engine is initialized, attached to the system, and configured to display the simulation in a window.
- **Ground and Pendulum Bodies**: The ground is a static body fixed at the origin, while the pendulum is a sphere positioned below the pivot point.
- **Joint Setup**: A revolute joint connects the pendulum to the ground, allowing it to swing freely under gravity.
- **Gravity and Logging**: Gravity is applied to the pendulum, and a callback is registered to log the pendulum's position and velocity at regular intervals.
- **Simulation Loop**: The loop updates the simulation, renders the scene, and continues until the visualization window is closed. The loop ensures the pendulum swings and logs data for analysis.

This setup provides a basic framework for simulating a simple pendulum, allowing for further customization by adjusting parameters such as mass, length, gravity, and logging frequency.
