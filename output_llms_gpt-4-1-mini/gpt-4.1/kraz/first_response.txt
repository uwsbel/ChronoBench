Below is a **PyChrono** simulation script that sets up a Kraz vehicle on a rigid terrain, configures friction and restitution, initializes a driver, and uses Irrlicht for real-time visualization with camera and lighting. The simulation loop synchronizes and advances all systems, maintaining real-time execution.

**Requirements:**  
- PyChrono (with vehicle and Irrlicht modules)
- Python 3.x

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr
import time

# 1. Initialize PyChrono and core components
chrono.SetChronoDataPath(chrono.GetChronoDataPath())
veh.SetDataPath(veh.GetDataPath())

# 2. Create the physical system
system = chrono.ChSystemNSC()

# 3. Create the Kraz vehicle
initLoc = chrono.ChVectorD(0, 0, 1.0)  # Initial position (x, y, z)
initYaw = chrono.ChQuaternionD(1, 0, 0, 0)  # No initial rotation
vehicle = veh.Kraz()
vehicle.SetContactMethod(chrono.ChContactMethod_NSC)
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(chrono.ChCoordsysD(initLoc, initYaw))
vehicle.SetInitFwdVel(0.0)
vehicle.Initialize()

# 4. Create the rigid terrain
terrain = veh.RigidTerrain(system)
patch = terrain.AddPatch(
    chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.QUNIT),
    length=200.0, width=100.0
)
patch.SetContactFrictionCoefficient(0.9)
patch.SetContactRestitutionCoefficient(0.01)
patch.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
patch.SetTexture(veh.GetDataFile("terrain/textures/grass.jpg"), 200, 100)
patch.SetColor(chrono.ChColor(0.8, 0.8, 0.5))
terrain.Initialize()

# 5. Create the driver system (simple interactive driver)
driver = veh.ChDriverInputs()
driver_system = veh.ChIrrGuiDriver(vehicle.GetChassis())
driver_system.SetSteeringDelta(0.04)
driver_system.SetThrottleDelta(0.02)
driver_system.SetBrakingDelta(0.1)
driver_system.Initialize()

# 6. Create the Irrlicht visualization system
vis = veh.ChWheeledVehicleIrrApp(vehicle, 'Kraz Vehicle Demo', irr.dimension2du(1024,768))
vis.SetSkyBox()
vis.AddTypicalLights(chrono.ChVectorD(30, 100, 40), chrono.ChVectorD(-30, 100, 40), 250, 130)
vis.AddTypicalLogo()
vis.AddLightWithShadow(chrono.ChVectorD(60, 100, 120), chrono.ChVectorD(0,0,0), 350, 1, 10, 40, 512)
vis.SetChaseCamera(chrono.ChVectorD(0.0, 0.0, 1.75), 6.0, 0.5)
vis.SetTimestep(0.01)
vis.AssetBindAll()
vis.AssetUpdateAll()
vis.Initialize()

# 7. Simulation loop parameters
step_size = 0.01
end_time = 10.0
realtime_timer = chrono.ChRealtimeStepTimer()
time_sim = 0.0

# 8. Simulation loop
while vis.Run() and time_sim < end_time:
    # Collect driver inputs
    driver_inputs = driver_system.GetInputs()
    # Synchronize all modules
    driver_system.Synchronize(time_sim)
    terrain.Synchronize(time_sim)
    vehicle.Synchronize(time_sim, driver_inputs, terrain)
    vis.Synchronize("Kraz Vehicle Demo", driver_inputs)
    # Advance simulation for one timestep
    driver_system.Advance(step_size)
    terrain.Advance(step_size)
    vehicle.Advance(step_size)
    vis.Advance(step_size)
    # Render scene
    vis.BeginScene()
    vis.DrawAll()
    vis.EndScene()
    # Maintain real-time execution
    time_sim += step_size
    realtime_timer.Spin(step_size)

# Cleanup
vis.GetDevice().closeDevice()
```

---

**Key Points:**
- **Kraz vehicle** is initialized at (0,0,1) with no initial velocity.
- **Rigid terrain** patch is 200x100 units, with friction 0.9 and restitution 0.01.
- **Driver** uses Irrlicht GUI for interactive control.
- **Visualization** uses Irrlicht with skybox, lights, chase camera, and real-time rendering.
- **Simulation loop** synchronizes and advances all systems, maintaining real-time pace.

**Tip:**  
You can adjust `end_time` for longer/shorter simulations, and tweak camera/lighting as needed.  
Make sure you have the PyChrono vehicle and Irrlicht modules installed.
