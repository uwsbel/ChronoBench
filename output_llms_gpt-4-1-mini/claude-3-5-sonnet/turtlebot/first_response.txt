Here's a PyChrono script that implements the simulation as described in your instructions:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.robot as chrob
import math

# Initialize the Chrono system
chrono.SetChronoDataPath("C:/Program Files/Chrono/data/")
system = chrono.ChSystemNSC()

# Set gravity
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground
ground = chrono.ChBodyEasyBox(20, 0.2, 20, 1000, True)
ground.SetBodyFixed(True)
ground.SetPos(chrono.ChVectorD(0, -0.1, 0))
system.Add(ground)

# Create the Turtlebot
robot = chrob.TurtleBot()
robot.Initialize(chrono.ChFrameD(chrono.ChVectorD(0, 0.2, 0), 
                 chrono.Q_from_AngAxis(math.pi/2, chrono.ChVectorD(0,1,0))))
system.Add(robot)

# Create the visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle("Turtlebot Simulation")
vis.Initialize()
vis.AddCamera(chrono.ChVectorD(0, 4, -6))
vis.AddTypicalLights()

# Simulation parameters
time_step = 0.01
duration = 10.0

# Simulation loop
time = 0
while vis.Run() and time < duration:
    # Control the Turtlebot
    left_speed = 0
    right_speed = 0
    
    if 2 < time < 4:
        # Turn left
        left_speed = -1
        right_speed = 1
    elif 6 < time < 8:
        # Turn right
        left_speed = 1
        right_speed = -1
    else:
        # Move forward
        left_speed = 1
        right_speed = 1
    
    robot.SetMotorSpeed(chrob.TurtleBot.LEFT, left_speed)
    robot.SetMotorSpeed(chrob.TurtleBot.RIGHT, right_speed)
    
    # Step the simulation
    system.DoStepDynamics(time_step)
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    time += time_step

# Clean up
vis.GetDevice().closeDevice()
```

This script does the following:

1. Initializes the PyChrono environment and core components.
2. Sets up the physical system with gravity.
3. Creates a ground plane using a fixed ChBodyEasyBox.
4. Initializes a Turtlebot robot at a specific position and orientation.
5. Sets up the Irrlicht visualization system with camera and lighting.
6. Implements a simulation loop that:
   - Controls the Turtlebot's motors to turn left, right, or move forward at specific times.
   - Updates the physical simulation.
   - Renders the scene.

The simulation runs for 10 seconds, with the Turtlebot performing the following actions:
- Move forward from 0-2 seconds
- Turn left from 2-4 seconds
- Move forward from 4-6 seconds
- Turn right from 6-8 seconds
- Move forward from 8-10 seconds

Note: Make sure you have PyChrono and its dependencies properly installed, and adjust the Chrono data path if necessary. Also, ensure that the TurtleBot model is available in your Chrono installation.
