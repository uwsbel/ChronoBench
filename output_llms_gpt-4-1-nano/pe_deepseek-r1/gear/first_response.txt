Here's a complete PyChrono simulation demonstrating an epicyclic gear system with visualization:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# 1. Create the simulation system
system = chrono.ChSystemSMC()
system.SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)

# Set global collision margins
chrono.ChCollisionModel.SetDefaultSuggestedEnvelope(0.002)
chrono.ChCollisionModel.SetDefaultSuggestedMargin(0.001)

# 2. Create contact material for gears
gear_material = chrono.ChContactMaterialSMC()
gear_material.SetFriction(0.1)       # Low friction for smooth meshing
gear_material.SetRestitution(0.0)     # No bounce
gear_material.SetCompliance(1e-9)     # Minimal compliance

# 3. Create bodies
# -----------------
# Fixed truss (ground)
ground = chrono.ChBody()
ground.SetFixed(True)
system.Add(ground)

# Rotating bar (crank)
crank = chrono.ChBodyEasyBox(1.5, 0.1, 0.1, 1000, True, True)
crank.SetPos(chrono.ChVector3d(0, 0, 0))
crank.SetMass(5)
crank.SetInertiaXX(chrono.ChVector3d(0.1, 0.5, 0.5))
system.Add(crank)

# Sun gear (fixed to ground)
sun_gear = chrono.ChBodyEasyCylinder(0.5, 0.2, 8000, True, True)
sun_gear.SetPos(chrono.ChVector3d(0, 0, 0))
sun_gear.SetFixed(True)
system.Add(sun_gear)

# Planetary gear (attached to crank)
planet_gear = chrono.ChBodyEasyCylinder(0.3, 0.2, 6000, True, True)
planet_gear.SetPos(chrono.ChVector3d(1.0, 0, 0))
system.Add(planet_gear)

# 4. Create joints and motors
# ----------------------------
# Revolute joint between crank and ground
crank_joint = chrono.ChLinkLockRevolute()
crank_joint.Initialize(ground, crank, 
                       chrono.ChCoordsysD(chrono.ChVector3d(0, 0, 0), 
                                         chrono.QuatFromAngleY(math.pi/2)))
system.Add(crank_joint)

# Motor to drive the crank
crank_motor = chrono.ChLinkMotorRotationSpeed()
crank_motor.Initialize(ground, crank, 
                      chrono.ChFramed(chrono.ChVector3d(0, 0, 0), 
                                     chrono.QuatFromAngleY(math.pi/2)))
motor_func = chrono.ChFunction_Const(0.5)  # Constant speed (0.5 rad/s)
crank_motor.SetSpeedFunction(motor_func)
system.Add(crank_motor)

# Revolute joint between crank and planetary gear
planet_joint = chrono.ChLinkLockRevolute()
planet_joint.Initialize(crank, planet_gear, 
                       chrono.ChCoordsysD(chrono.ChVector3d(1.0, 0, 0), 
                                         chrono.QuatFromAngleY(math.pi/2)))
system.Add(planet_joint)

# 5. Set up visualization
# -----------------------
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle('Epicyclic Gear System')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddCamera(chrono.ChVector3d(2, 1, 3))
vis.AddTypicalLights()
vis.AddSkyBox()

# Colorize components
crank.GetVisualShape(0).SetColor(chrono.ChColor(0.6, 0.6, 0.6))
sun_gear.GetVisualShape(0).SetColor(chrono.ChColor(0.8, 0.2, 0.2))
planet_gear.GetVisualShape(0).SetColor(chrono.ChColor(0.2, 0.2, 0.8))

# 6. Simulation loop
# ------------------
time_step = 0.005
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    system.DoStepDynamics(time_step)

print("Simulation completed")
```

### Key Components Explained:

1. **System Setup**:
   - Uses SMC contact method for accurate gear interaction
   - Sets collision detection parameters for precise gear meshing

2. **Gear System**:
   - **Sun Gear**: Fixed central gear (radius=0.5m)
   - **Planetary Gear**: Rotates around sun gear (radius=0.3m)
   - **Crank**: Rotating arm connecting planetary gear to center
   - Gear ratio: 0.5/0.3 ≈ 1.67:1

3. **Motion Control**:
   - Constant rotation speed motor (0.5 rad/s) drives the crank
   - Planetary gear exhibits compound motion:
     - Revolution around sun gear (driven by crank)
     - Rotation around its own axis (driven by gear meshing)

4. **Visualization**:
   - Color-coded components for clear identification
   - Camera positioned for optimal viewing angle
   - Real-time physics rendering at 200 FPS (1/0.005)

### Simulation Behavior:
- The crank rotates at a constant speed (≈28.6 deg/s)
- The planetary gear orbits the sun gear while simultaneously rotating
- Gear interaction is physically simulated through:
  - Collision detection between gear surfaces
  - Friction forces at contact points
  - Constraint-based motion from joints

### Customization Options:
1. Change gear sizes by modifying cylinder radii
2. Adjust motor speed via `ChFunction_Const` parameter
3. Modify material properties (friction, compliance)
4. Add more planetary gears by duplicating and positioning
5. Enable data logging for torque/velocity analysis

This simulation demonstrates fundamental principles of gear transmission systems with physically accurate interactions. The planetary gear will exhibit rotation proportional to the size ratio between the sun and planetary gears, with the rotation direction depending on their relative positioning.
