Here's a complete PyChrono simulation script for a crank-slider mechanism with detailed explanations:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# 1. System Initialization
system = chrono.ChSystemNSC()
system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
system.SetSolverMaxIterations(100)
chrono.ChCollisionModel.SetDefaultSuggestedEnvelope(0.001)
chrono.ChCollisionModel.SetDefaultSuggestedMargin(0.001)

# 2. Create Materials
material = chrono.ChContactMaterialNSC()
material.SetFriction(0.2)
material.SetDampingF(0.01)

# 3. Create Ground Body (Fixed Truss)
ground = chrono.ChBody()
ground.SetPos(chrono.ChVector3d(0, 0, 0))
ground.SetFixed(True)
system.Add(ground)

# Visualize ground as gray platform
ground_shape = chrono.ChVisualShapeBox(2, 0.1, 2)
ground_shape.SetColor(chrono.ChColor(0.3, 0.3, 0.3))
ground.AddVisualShape(ground_shape)

# 4. Create Crank Mechanism Components
# -------------------------------------
# Parameters
crank_length = 0.3
rod_length = 0.7
crank_width = 0.05
piston_size = chrono.ChVector3d(0.1, 0.1, 0.1)

# 4.1 Crankshaft
crank = chrono.ChBody()
crank.SetPos(chrono.ChVector3d(0, 0.5, 0))
crank.SetMass(5)
crank.SetInertiaXX(chrono.ChVector3d(0.1, 0.1, 0.1))
system.Add(crank)

# Visualize as red cylinder
crank_shape = chrono.ChVisualShapeCylinder(crank_width, crank_length)
crank_shape.SetColor(chrono.ChColor(0.8, 0.0, 0.0))
crank.AddVisualShape(crank_shape, chrono.ChFramed(chrono.ChVector3d(0, 0, 0), 
                 chrono.QuatFromAngleY(chrono.CH_PI_2))

# 4.2 Connecting Rod
rod = chrono.ChBody()
rod.SetPos(chrono.ChVector3d(crank_length/2 + rod_length/2, 0.5, 0))
rod.SetMass(3)
rod.SetInertiaXX(chrono.ChVector3d(0.05, 0.5, 0.05))
system.Add(rod)

# Visualize as green box
rod_shape = chrono.ChVisualShapeBox(rod_length, crank_width, crank_width)
rod_shape.SetColor(chrono.ChColor(0.0, 0.8, 0.0))
rod.AddVisualShape(rod_shape)

# 4.3 Piston
piston = chrono.ChBody()
piston.SetPos(chrono.ChVector3d(crank_length + rod_length, 0.5, 0))
piston.SetMass(2)
piston.SetInertiaXX(chrono.ChVector3d(0.01, 0.01, 0.01))
system.Add(piston)

# Visualize as blue box
piston_shape = chrono.ChVisualShapeBox(piston_size.x, piston_size.y, piston_size.z)
piston_shape.SetColor(chrono.ChColor(0.0, 0.0, 0.8))
piston.AddVisualShape(piston_shape)

# 5. Create Joints and Constraints
# ---------------------------------
# 5.1 Ground-Crank Revolute Joint (at origin)
crank_joint = chrono.ChLinkLockRevolute()
crank_joint.Initialize(ground, crank, 
                      chrono.ChFramed(chrono.ChVector3d(0, 0.5, 0), 
                                  chrono.QuatFromAngleZ(0)))
system.Add(crank_joint)

# 5.2 Crank-Rod Revolute Joint
rod_joint1 = chrono.ChLinkLockRevolute()
rod_joint1.Initialize(crank, rod, 
                     chrono.ChFramed(chrono.ChVector3d(crank_length, 0.5, 0), 
                                 chrono.QuatFromAngleZ(0)))
system.Add(rod_joint1)

# 5.3 Rod-Piston Revolute Joint
rod_joint2 = chrono.ChLinkLockRevolute()
rod_joint2.Initialize(rod, piston, 
                     chrono.ChFramed(chrono.ChVector3d(crank_length + rod_length, 0.5, 0), 
                                 chrono.QuatFromAngleZ(0)))
system.Add(rod_joint2)

# 5.4 Piston-Ground Prismatic Joint (constrain to X-axis)
piston_joint = chrono.ChLinkLockPrismatic()
piston_joint.Initialize(ground, piston, 
                       chrono.ChFramed(chrono.ChVector3d(0, 0.5, 0), 
                                   chrono.QuatFromAngleY(chrono.CH_PI_2)))
system.Add(piston_joint)

# 5.5 Motor to drive crankshaft
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(ground, crank, 
                chrono.ChFramed(chrono.ChVector3d(0, 0.5, 0), 
                            chrono.QuatFromAngleZ(0)))
motor.SetSpeedFunction(chrono.ChFunction_Const(chrono.CH_PI))  # 180°/s = π rad/s
system.Add(motor)

# 6. Visualization Setup
# -----------------------
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle("PyChrono Crank-Slider Mechanism")
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile("logo_pychrono_alpha.png"))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(1.5, 0.5, 1.5))
vis.AddTypicalLights()

# 7. Simulation Loop
# -------------------
time_step = 0.005
simulation_time = 0
max_simulation_time = 10

while vis.Run() and simulation_time < max_simulation_time:
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    system.DoStepDynamics(time_step)
    simulation_time += time_step

print("Simulation completed successfully!")
```

### Key Components Explained:

1. **System Setup**:
   - Uses NSC (Non-Smooth Contact) solver with optimized parameters
   - Configures collision detection settings
   - Creates contact material with friction and damping

2. **Mechanism Components**:
   - **Ground**: Fixed platform as reference body
   - **Crankshaft**: Rotating component driven by motor
   - **Connecting Rod**: Transmits motion from crank to piston
   - **Piston**: Constrained to linear motion along X-axis

3. **Joints and Constraints**:
   - Revolute joints for rotational connections
   - Prismatic joint for piston linear guidance
   - Rotation motor driving crankshaft at constant speed (π rad/s)

4. **Visualization Features**:
   - Color-coded components (red crank, green rod, blue piston)
   - Custom camera position for optimal viewing
   - Skybox and logo for enhanced visual context
   - Real-time rendering at 200 FPS (with 5ms time step)

5. **Physical Parameters**:
   - Realistic mass and inertia properties
   - Proper joint positioning and alignment
   - Mechanism dimensions scaled for clear visualization

### Customization Options:
1. To change motor speed:
   ```python
   motor.SetSpeedFunction(chrono.ChFunction_Const(2 * chrono.CH_PI))  # 360°/s
   ```

2. To add textures:
   ```python
   piston_shape.SetTexture(chrono.GetChronoDataFile("textures/bluewhite.png"))
   ```

3. To enable collision detection:
   ```python
   piston.EnableCollision(True)
   piston.GetCollisionModel().AddShape(chrono.ChCollisionShapeBox(piston_size.x, piston_size.y, piston_size.z))
   ```

4. To change camera angle during simulation:
   ```python
   if simulation_time > 5:
       vis.GetActiveCamera().setPosition(chronoirr.vector3df(0, 1, 2))
   ```

This simulation demonstrates fundamental mechanical principles while showcasing PyChrono's capabilities for multibody dynamics, constraint management, and real-time visualization.
