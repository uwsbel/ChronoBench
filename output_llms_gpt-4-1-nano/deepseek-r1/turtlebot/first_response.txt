Here's a complete PyChrono simulation script that meets your requirements. The script creates a Turtlebot robot on rigid terrain, sets up real-time visualization with Irrlicht, and implements motor control for turning:

```python
import pychrono as chrono
import pychrono.robot as robot
import pychrono.irrlicht as chronoirr
import math

# =============================================================================
# Main simulation
# =============================================================================

# 1. Initialize Chrono system and set gravity
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Create rigid ground body
ground_mat = chrono.ChMaterialSurfaceNSC()
ground = chrono.ChBodyEasyBox(20, 0.1, 20, 1000, True, True, ground_mat)
ground.SetPos(chrono.ChVectorD(0, -0.05, 0))
ground.SetBodyFixed(True)
ground.GetVisualShape(0).SetTexture(chrono.GetChronoDataFile("textures/concrete.jpg"))
system.Add(ground)

# 3. Create Turtlebot robot at specified position/orientation
init_pos = chrono.ChVectorD(0, 0.1, 0)
init_rot = chrono.Q_from_AngZ(math.pi / 4)  # 45 degree initial rotation
turtlebot = robot.TurtleBot()
turtlebot.SetInitPosition(chrono.ChCoordsysD(init_pos, init_rot))
turtlebot.Initialize(system)

# 4. Set up Irrlicht visualization
application = chronoirr.ChIrrApp(system, "TurtleBot Simulation", chronoirr.dimension2du(1280, 720))
application.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
application.AddSkyBox()
application.AddTypicalLights()

# Configure camera
camera_pos = chrono.ChVectorD(3, 2, 3)
camera_target = init_pos
application.AddTypicalCamera(chronoirr.vector3df(camera_pos.x, camera_pos.y, camera_pos.z),
                             chronoirr.vector3df(camera_target.x, camera_target.y, camera_target.z))

application.AssetBindAll()
application.AssetUpdateAll()

# 5. Simulation loop with motor control
application.SetTimestep(0.01)
time = 0

while application.GetDevice().run():
    time = system.GetChTime()
    
    # Turtlebot motor control logic
    if time < 2.0:
        # Forward motion (both wheels same speed)
        turtlebot.SetMotorSpeeds(1.0, 1.0)
    elif time < 4.0:
        # Left turn (right wheel faster)
        turtlebot.SetMotorSpeeds(0.5, 1.5)
    elif time < 6.0:
        # Right turn (left wheel faster)
        turtlebot.SetMotorSpeeds(1.5, 0.5)
    else:
        # Stop after 6 seconds
        turtlebot.SetMotorSpeeds(0, 0)
    
    # Advance simulation and render
    application.BeginScene(True, True, chronoirr.SColor(255, 140, 161, 192))
    application.DrawAll()
    application.DoStep()
    application.EndScene()

# =============================================================================
# End of simulation
# =============================================================================
```

Key features of this simulation:

1. **Environment Setup**:
   - Physics system with gravity (-9.81 m/s² in Y direction)
   - Textured rigid ground (20x20 meter concrete surface)

2. **Turtlebot Initialization**:
   - Starts at position (0, 0.1, 0) with 45° initial rotation
   - Uses PyChrono's built-in Turtlebot model

3. **Visualization**:
   - Irrlicht real-time 3D rendering
   - Camera positioned at (3,2,3) focusing on robot
   - Skybox and directional lighting
   - 1280x720 resolution window

4. **Control Logic**:
   - 0-2s: Forward motion (both wheels at 1.0 rad/s)
   - 2-4s: Left turn (wheels: 0.5/1.5 rad/s)
   - 4-6s: Right turn (wheels: 1.5/0.5 rad/s)
   - After 6s: Stops

**Requirements**:
- PyChrono version 7.0.0 or later
- Chrono data files (for textures and models)
- Irrlicht library

**Note**: The Turtlebot model is part of PyChrono's robot module. If you encounter issues loading assets, ensure your `CHRONO_DATA_DIR` environment variable points to the correct data directory containing robot models and textures.

The simulation will run in real-time for approximately 6 seconds, demonstrating basic robot maneuvering on a flat surface with visual feedback.
