Below is a Python script that sets up a PyChrono simulation with a Viper rover on a rigid terrain, following the instructions provided. This script initializes the PyChrono environment, adds the necessary physical systems and objects, and implements a simulation loop with real-time visualization using Irrlicht.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr

# Initialize the Chrono system
chrono.ChSystemNSC()

# Set gravity
chrono.ChSystemNSC.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body (rigid terrain)
ground = chrono.ChBody()
ground.SetBodyFixed(True)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.GetMaterialSurface().SetFriction(0.5)
chrono.ChSystemNSC.Add(ground)

# Create the Viper rover
viper_rover = chrono.ChBody()
viper_rover.SetMass(1000)  # Mass of the rover
viper_rover.SetInertiaXX(chrono.ChVectorD(10, 10, 10))  # Inertia
viper_rover.SetPos(chrono.ChVectorD(0, 0.5, 0))  # Initial position
viper_rover.GetMaterialSurface().SetFriction(0.5)
chrono.ChSystemNSC.Add(viper_rover)

# Initialize the driver for the rover
driver = chrono.ChDriver()
driver.SetChassis(viper_rover)

# Set up Irrlicht visualization
application = chronoirr.ChIrrApp(chrono.ChSystemNSC, "Viper Rover Simulation", chronoirr.dimension2d(800, 600))
application.AddTypicalSky()
application.AddTypicalLights()
application.AddTypicalCamera(chrono.ChVectorD(0, 2, -5), chrono.ChVectorD(0, 0, 0))

# Create a simulation loop
time_step = 0.01  # Time step for the simulation
total_time = 10.0  # Total simulation time
current_time = 0.0

# Initialize steering parameters
initial_steering = 0.0
final_steering = 30.0  # Final steering angle in degrees
steering_duration = 5.0  # Duration to reach final steering
steering_rate = (final_steering - initial_steering) / steering_duration

# Main simulation loop
while current_time < total_time:
    # Update steering angle
    if current_time < steering_duration:
        current_steering = initial_steering + steering_rate * current_time
    else:
        current_steering = final_steering

    # Update the rover's steering (this is a placeholder for actual steering logic)
    driver.SetSteering(current_steering)

    # Perform the simulation step
    chrono.ChSystemNSC.DoStepDynamics(time_step)

    # Render the scene
    application.DrawAll()
    application.DoStep()

    # Increment time
    current_time += time_step

# Clean up and exit
application.AssetBindAll()
application.AssetUpdateAll()
application.GetDevice().drop()
```

### Explanation of the Script:
1. **Initialization**: The script starts by initializing the PyChrono system and setting the gravity.
2. **Ground Body**: A rigid ground body is created and added to the simulation.
3. **Viper Rover**: A Viper rover is created with specified mass and inertia, and it is positioned above the ground.
4. **Driver Initialization**: A driver is initialized for the rover to control its steering.
5. **Irrlicht Visualization**: The script sets up an Irrlicht application for real-time visualization, including a sky, lights, and a camera.
6. **Simulation Loop**: The loop updates the rover's steering over a specified duration, performs the simulation step, and renders the scene at each timestep.
7. **Cleanup**: Finally, the script cleans up the assets and exits the application.

Make sure you have the necessary PyChrono and Irrlicht libraries installed and configured in your Python environment to run this script successfully.
