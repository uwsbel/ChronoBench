```python
import pychrono as chrono
import pychrono.irrlicht as irr
import pychrono.vehicle as vehicle

# Initialize PyChrono environment
chrono.init()

# Create Irrlicht engine
engine = irr.IrrlichtEngine()
engine.createWindow("CityBus Simulation", 800, 600)
engine.setWindowCaption("CityBus Simulation")

# Create a RigidTerrain with custom texture
terrain = chrono.RigidTerrain(engine, "city_terrain.png")
terrain.setFriction(0.5)
terrain.setFriction(0.2)

# Create a CityBus vehicle
bus = vehicle.Vehicle("city_bus.fbx")
bus.setMass(1000)
bus.setEnginePower(200)
bus.setTireModel(chrono.TireModel.Radial)

# Set initial position and orientation
bus.setPosition(chrono.Vec3(0, 0, 0))
bus.setOrientation(chrono.Vec3(0, 0, 1))

# Set initial tire model
bus.setTireModel(chrono.TireModel.Radial)

# Set camera position and target
camera_position = chrono.Vec3(0, 10, 5)
camera_target = chrono.Vec3(0, 0, 0)

# Set up camera for real-time visualization
camera = engine.createCamera()
camera.setPosition(camera_position)
camera.setTarget(camera_target)
camera.setFov(45)

# Create a driver system
driver = chrono.Driver()
driver.setSteeringSensitivity(0.5)
driver.setThrottleSensitivity(1.0)
driver.setBrakeSensitivity(0.5)

# Initialize simulation loop
engine.setSimulationTimeStep(0.01)
engine.setFrameRate(50)

# Main simulation loop
while engine.isRunning():
    # Update vehicle dynamics
    bus.update(engine.getDeltaTime())
    
    # Update driver system
    driver.update(engine.getDeltaTime())
    
    # Render the scene
    engine.render()

# Clean up
engine.shutdown()
```


**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Initialize PyChrono and Irrlicht.
   - Create Irrlicht engine and window.

2. **Creating the Scene:**
   - Create a `RigidTerrain` with a custom texture (replace `city_terrain.png` with your texture file).
   - Create a `Vehicle` with parameters like mass, engine power, and tire model.
   - Set initial position and orientation for the vehicle.
   - Set initial tire model.

3. **Camera Setup:**
   - Create a camera and position it to follow the vehicle.

4. **Driver System:**
   - Create a `Driver` object to control steering, throttle, and braking.
   - Set sensitivity parameters for each control.

5. **Simulation Loop:**
   - Set the simulation time step and frame rate.
   - Inside the loop:
     - Update the vehicle's dynamics using `bus.update()`.
     - Update the driver system using `driver.update()`.
     - Render the scene using `engine.render()`.

6. **Cleanup:**
   - Shutdown the Irrlicht engine.
