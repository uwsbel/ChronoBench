```python
import pychrono as chrono
import pychrono.physics as physics
import pychrono.visualization as visualization
import pychrono.solver as solver
import pychrono.timestepper as timestepper

# Initialize PyChrono environment
chrono.init()

# Create the simulation world
world = chrono.World()

# Define the beam element material
beam_material = physics.Material(
    name="Beam Material",
    elasticity=200e9,  # Elastic modulus in Pa
    density=7850,  # Density in kg/m3
    poisson=0.3,  # Poisson's ratio
)

# Define the beam element
beam_element = physics.BeamElement(
    name="Beam Element",
    length=1.0,  # Length of the beam in meters
    cross_section="Rectangle",  # Cross-section shape
    material=beam_material,
)

# Define the motor and its properties
motor = physics.Motor(
    name="Motor",
    torque=1000,  # Torque in Nm
    speed=100,  # Speed in rpm
)

# Define the support points and constraints
support_point_1 = physics.Point(
    name="Support Point 1",
    position=(0.0, 0.0, 0.0),  # Position in meters
)
support_point_2 = physics.Point(
    name="Support Point 2",
    position=(1.0, 0.0, 0.0),  # Position in meters
)

# Define the constraints
constraint = physics.Constraint(
    name="Constraint",
    type="Fixed",  # Type of constraint
    points=[support_point_1, support_point_2],  # Points of the constraint
)

# Create the beam element and connect it to the motor
beam_element.setMotor(motor)
beam_element.setConstraint(constraint)

# Add the beam element to the world
world.add(beam_element)

# Create the visualization scene
scene = visualization.Scene()
scene.add(world)

# Set up the solver and timestepper
solver = solver.Solver(world)
timestepper = timestepper.Timestepper(solver)

# Run the simulation
chrono.run(solver, timestepper)

# Visualize the simulation
scene.render()

# Cleanup
chrono.cleanup()
```

**Explanation:**

1. **Initialization:** The script initializes PyChrono and creates a world object.
2. **Physical Components:**
   - **Beam Element:** A beam element is created with a specified length, cross-section, and material properties.
   - **Motor:** A motor is created with a specified torque and speed.
   - **Support Points:** Two support points are defined to constrain the beam.
   - **Constraint:** A constraint is created to connect the support points and the beam element.
3. **Connection and Placement:** The beam element is connected to the motor and constrained to the support points.
4. **Visualization:** A visualization scene is created and the world is added to it.
5. **Solver and Timestepper:** A solver and timestepper are set up to perform the simulation.
6. **Simulation Run:** The simulation is run using the solver and timestepper.
7. **Visualization Rendering:** The visualization scene is rendered to display the simulation.
8. **Cleanup:** The PyChrono environment is cleaned up.
