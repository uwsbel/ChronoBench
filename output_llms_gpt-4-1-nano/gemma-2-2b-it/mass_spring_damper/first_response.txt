```python
import pychrono as chrono
import pychrono.irr as irr

# Initialize PyChrono
chrono.init()

# Create a new Chrono scene
scene = chrono.Scene()

# Create a ground object
ground = chrono.Geom.createGround(chrono.Vector3(0, 0, 0), 10, 10, 10)

# Create a mass object
mass = chrono.Geom.createSphere(chrono.Vector3(0, 0, 0), 0.5)

# Create a link object
link = chrono.LinkTSDA(mass, ground)

# Set link parameters
link.setLinearStiffness(1000)
link.setLinearDamping(0.1)
link.setAngularStiffness(1000)
link.setAngularDamping(0.1)

# Add the objects to the scene
scene.add(ground)
scene.add(mass)
scene.add(link)

# Set Irrlicht visualization parameters
irr.init()
irr.setCameraPosition(chrono.Vector3(0, 5, 10))
irr.setCameraTarget(chrono.Vector3(0, 0, 0))
irr.setCameraRotation(chrono.Vector3(0, 0, 0))
irr.setCameraPerspective(60, 1000, 100)
irr.setLightPosition(chrono.Vector3(0, 1, 0))
irr.setLightColor(chrono.Vector3(1, 1, 1))

# Render the scene
chrono.run()
```

**Explanation:**

1. **Initialization:** 
   - Imports necessary libraries: `pychrono` and `pychrono.irr`.
   - Initializes PyChrono with `chrono.init()`.

2. **Scene Creation:** 
   - Creates a new Chrono scene object `scene`.

3. **Object Creation:**
   - Creates a ground object `ground` using `chrono.Geom.createGround()`.
   - Creates a mass object `mass` using `chrono.Geom.createSphere()`.
   - Creates a link object `link` using `chrono.LinkTSDA()`.

4. **Link Parameters:**
   - Sets the linear stiffness and damping for the link using `link.setLinearStiffness()` and `link.setLinearDamping()`.
   - Sets the angular stiffness and damping for the link using `link.setAngularStiffness()` and `link.setAngularDamping()`.

5. **Adding Objects to Scene:**
   - Adds the `ground`, `mass`, and `link` to the `scene`.

6. **Irrlicht Visualization:**
   - Initializes Irrlicht with `irr.init()`.
   - Sets camera position, target, rotation, and perspective.
   - Sets light position and color.

7. **Rendering:**
   - Runs the simulation with `chrono.run()`.


**Note:** 

- This script uses default parameters for the link. You can modify these parameters to change the stiffness, damping, and other properties.
- The Irrlicht visualization is basic. You can customize it further to create more complex scenes. 
- This script is a starting point. You can extend it to include more complex dynamics, such as forces and interactions, and add visual feedback for the simulation.
