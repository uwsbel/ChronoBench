```python
import pychrono as chrono
import pychrono.fea as fea
import pychrono.irrlicht as chronoirr

# Initialize the Chrono system with SMC (Smooth Contact)
sys = chrono.ChSystemSMC()

# Create a mesh for FEA elements
mesh = fea.ChMesh()

# Define material properties for ANCF cable elements
material = fea.ChCableANCFMaterial()
material.SetYoungsModulus(1e5)  # Reduced stiffness for visible deformation
material.SetDampingRatio(0.01)
material.SetDensity(1000)
material.SetCrossSectionArea(0.01)

# Beam parameters
num_elements = 10
beam_length = 1.0
cable_radius = 0.02  # Radius for visualization

# Create nodes along the beam
nodes = []
for i in range(num_elements + 1):
    x = i * beam_length / num_elements
    node = fea.ChNodeFEAxyzd(chrono.ChVectorD(x, 0, 0), chrono.ChVectorD(1, 0, 0))
    if i == 0:  # Fix the first node
        node.SetFixed(True)
    mesh.AddNode(node)
    nodes.append(node)

# Create ANCF cable elements connecting the nodes
for i in range(num_elements):
    element = fea.ChElementCableANCF()
    element.SetNodes(nodes[i], nodes[i+1])
    element.SetMaterial(material)
    element.SetDiameter(2 * cable_radius)  # Set cable diameter
    mesh.AddElement(element)

# Add the mesh to the system
sys.Add(mesh)

# Set up Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('ANCF Cable Beam Deformation')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(0, 1, 2))
vis.AddTypicalLights()

# Simulation loop
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    sys.DoStepDynamics(0.001)  # Smaller time step for stability
```

### Explanation:
1. **System Initialization**: Uses `ChSystemSMC` for smooth contact handling, suitable for FEA simulations.
2. **FEA Mesh Setup**:
   - **Nodes**: Created with `ChNodeFEAxyzd` (position + gradient) and spaced along the beam's length.
   - **Elements**: `ChElementCableANCF` elements connect nodes, with material properties adjusted for visible deformation under gravity.
3. **Constraints**: The first node is fixed to simulate a hinge.
4. **Visualization**:
   - **Irrlicht Engine**: Renders the beam with a camera positioned to view deformation.
   - **Cable Visualization**: Elements are rendered as cylinders with specified diameter.
5. **Simulation Loop**: Advances the simulation with a small time step (0.001s) for numerical stability, updating the visual representation in real-time.

This script demonstrates the beam's deformation under gravity, with the fixed end remaining stationary while the rest of the beam bends downward.
