```python
import pychrono as chrono
import pychrono.fea as fea
import pychrono.irrlicht as irr
import numpy as np

# ---------------------------------------------------------------------
#
#  Create the physical system
#
# ---------------------------------------------------------------------

system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# ---------------------------------------------------------------------
#
#  Create the ground body
#
# ---------------------------------------------------------------------

ground = chrono.ChBodyEasyBox(1, 1, 0.1, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
system.Add(ground)

# ---------------------------------------------------------------------
#
#  Create the IGA beam
#
# ---------------------------------------------------------------------

# Define beam geometry and material properties
beam_length = 1.0
beam_radius = 0.05
beam_E = 200e9  # Young's modulus
beam_nu = 0.3  # Poisson's ratio
beam_density = 7850  # Density

# Create a NURBS curve for the beam
knots = np.array([0, 0, 1, 1])
control_points = np.array([[0, 0, 0], [beam_length, 0, 0]])
degree = 1

nurbs_curve = fea.ChNurbsCurve(knots, control_points, degree)

# Create the IGA beam element
beam_element = fea.ChElementBeamIGA(nurbs_curve, beam_radius, beam_E, beam_nu, beam_density)

# Create the beam body
beam_body = fea.ChBodyFEA()
beam_body.AddElement(beam_element)
beam_body.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(beam_body)

# ---------------------------------------------------------------------
#
#  Create the flywheel
#
# ---------------------------------------------------------------------

flywheel_radius = 0.2
flywheel_mass = 10

flywheel = chrono.ChBodyEasyCylinder(flywheel_radius, 0.1, flywheel_mass, True, True)
flywheel.SetPos(chrono.ChVectorD(beam_length / 2, 0, 0))
system.Add(flywheel)

# Create a constraint to attach the flywheel to the beam
constraint = chrono.ChLinkLockRevolute(beam_body, flywheel, chrono.ChVectorD(beam_length / 2, 0, 0))
system.Add(constraint)

# ---------------------------------------------------------------------
#
#  Create the motor
#
# ---------------------------------------------------------------------

motor = chrono.ChLinkMotorRotationSpeed(beam_body)
motor.SetTargetSpeed(100)
system.Add(motor)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization
#
# ---------------------------------------------------------------------

vis = irr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Jeffcott Rotor Simulation")
vis.Initialize()

# Add FEM visualization
fea.ChVisualizationFEA(vis, beam_body)

# Simulation loop
while vis.Run():
    system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:** The script begins by importing necessary PyChrono modules and initializing the physical system (`system`).

2. **Ground Body:** A simple ground body is created using `ChBodyEasyBox` to provide a fixed reference.

3. **IGA Beam:**
   - A NURBS curve is defined using `ChNurbsCurve` to represent the beam's geometry.
   - An `ChElementBeamIGA` object is created, specifying the NURBS curve, beam radius, and material properties.
   - A `ChBodyFEA` is created to hold the beam element and positioned in the scene.

4. **Flywheel:** A cylinder-shaped flywheel is created using `ChBodyEasyCylinder` and attached to the center of the beam using a `ChLinkLockRevolute` constraint.

5. **Motor:** A rotational motor (`ChLinkMotorRotationSpeed`) is attached to the beam body to drive its rotation.

6. **Irrlicht Visualization:** An Irrlicht visualization system (`ChVisualSystemIrrlicht`) is initialized to render the simulation. FEM visualization is enabled for the beam using `ChVisualizationFEA`.

7. **Simulation Loop:** The main loop runs the simulation, performing a dynamics step and rendering the scene in each iteration.

**Key Points:**



* This script demonstrates the use of IGA for beam modeling in PyChrono.

* The Irrlicht visualization allows for real-time observation of the Jeffcott rotor's dynamic behavior.

* You can modify parameters like beam geometry, material properties, motor speed, and simulation time step to explore different scenarios.
