```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Create terrain
terrain = chrono.ChBodyEasyBox(
    200, 10, 200, 1000, True, True, chrono.ChMaterialSurfaceNSC()
)
terrain.SetPos(chrono.ChVectorD(0, -5, 0))
terrain.SetBodyFixed(True)
my_system.Add(terrain)

# 3. Create HMMWV vehicle
vehicle = chronovehicle.ChVehicle(my_system)
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(chrono.ChVectorD(0, 1, 0))
vehicle.Initialize()

# 4. Add driver inputs
driver = chronovehicle.ChDriver(vehicle)
driver.SetSteeringAngle(0)
driver.SetThrottle(0)
driver.SetBraking(0)

# 5. Add IMU and GPS sensors
imu = chronovehicle.ChSensorIMU(vehicle.GetChassis())
imu.SetPos(chrono.ChVectorD(0, 1.5, 0))
vehicle.AddSensor(imu)

gps = chronovehicle.ChSensorGPS(vehicle.GetChassis())
gps.SetPos(chrono.ChVectorD(0, 1.5, 0))
vehicle.AddSensor(gps)

# 6. Initialize Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(1200, 800)
vis.Initialize()
vis.AddTypicalLights()
vis.AddSkyBox()

# 7. Simulation loop
while vis.Run():
    # Update driver inputs (replace with your desired logic)
    driver.SetSteeringAngle(0.1 * chrono.ChTime.GetTime())
    driver.SetThrottle(0.5)

    # Update vehicle
    vehicle.Synchronize(chrono.ChTime.GetTime())
    vehicle.Advance(chrono.ChTime.GetTime())

    # Process sensor data
    imu_data = imu.GetOutput()
    gps_data = gps.GetOutput()

    # Output vehicle mass
    print(f"Vehicle mass: {vehicle.GetMass()}")

    # Render scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

# 8. Clean up
my_system.Finalize()
vis.Shutdown()
```

**Explanation:**

1. **Initialization:**

- Sets the Chrono data path and creates a Chrono system with gravity.
- Creates a simple terrain using a box.

2. **Vehicle:**

- Creates an HMMWV vehicle using `chronovehicle.ChVehicle`.
- Sets the initial position and initializes the vehicle.

3. **Driver Inputs:**

- Creates a driver object (`chronovehicle.ChDriver`) and attaches it to the vehicle.
- Sets initial steering angle, throttle, and braking values.

4. **Sensors:**

- Adds IMU and GPS sensors (`chronovehicle.ChSensorIMU` and `chronovehicle.ChSensorGPS`) to the vehicle's chassis.

5. **Visualization:**

- Initializes Irrlicht visualization (`chronoirr.ChVisualSystemIrrlicht`) and sets window size.
- Adds lights and a skybox for better rendering.

6. **Simulation Loop:**

- Continuously runs until the Irrlicht window is closed.
- Updates driver inputs (replace with your desired logic).
- Synchronizes and advances the vehicle.
- Processes sensor data from IMU and GPS.
- Prints the vehicle's mass.
- Renders the scene using Irrlicht.

7. **Cleanup:**

- Finalizes the Chrono system and shuts down Irrlicht.
