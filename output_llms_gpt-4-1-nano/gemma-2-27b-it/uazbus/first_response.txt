```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Initialize PyChrono environment and core components
#
# ---------------------------------------------------------------------

chrono.SetChronoDataPath("data/")

# Create the physical system
system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("UAZBUS Simulation")
vis.Initialize()

# Add a directional light
light = vis.GetSceneManager().addLightSceneNode(0, chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1))

# ---------------------------------------------------------------------
#
#  Create the terrain
#
# ---------------------------------------------------------------------

terrain = chrono.ChTerrainPlane()
terrain.SetTexture(vis.GetSceneManager().getFileSystem().addFile("terrain.png"))
terrain.SetSize(200, 200)
terrain.SetMaterialSurface(chrono.ChMaterialSurfaceNSC(0.8, 0.4, 0.1))
system.Add(terrain)

# ---------------------------------------------------------------------
#
#  Create the UAZBUS vehicle
#
# ---------------------------------------------------------------------

vehicle = chronovehicle.ChVehicleModel()
vehicle.SetSystem(system)
vehicle.SetChassis(chronovehicle.ChChassis(chrono.ChVectorD(0, 1, 0), chrono.ChQuaternionD(1, 0, 0, 0), chrono.ChVectorD(2.5, 1, 5), 2000))

# Add wheels and suspension
vehicle.AddWheel(chronovehicle.ChWheelInfo(chrono.ChVectorD(1.5, -1, 1.5), chrono.ChVectorD(0, -1, 0), chrono.ChVectorD(0, 1, 0), 0.3, 0.8, 0.5, 0.1))
vehicle.AddWheel(chronovehicle.ChWheelInfo(chrono.ChVectorD(-1.5, -1, 1.5), chrono.ChVectorD(0, -1, 0), chrono.ChVectorD(0, 1, 0), 0.3, 0.8, 0.5, 0.1))
vehicle.AddWheel(chronovehicle.ChWheelInfo(chrono.ChVectorD(1.5, -1, -1.5), chrono.ChVectorD(0, -1, 0), chrono.ChVectorD(0, 1, 0), 0.3, 0.8, 0.5, 0.1))
vehicle.AddWheel(chronovehicle.ChWheelInfo(chrono.ChVectorD(-1.5, -1, -1.5), chrono.ChVectorD(0, -1, 0), chrono.ChVectorD(0, 1, 0), 0.3, 0.8, 0.5, 0.1))

# Load the UAZBUS mesh and attach it to the chassis
vehicle.SetChassisVisualizationType(chronovehicle.VisualizationType_MESH)
vehicle.SetChassisBodyFixed(False)
vehicle.LoadMesh("uazbus.obj")

# ---------------------------------------------------------------------
#
#  Create the driver system
#
# ---------------------------------------------------------------------

driver = chronovehicle.ChDriver()
driver.SetSteering(0)
driver.SetThrottle(0)
driver.SetBraking(0)

# Connect the driver to the vehicle
vehicle.SetDriver(driver)

# ---------------------------------------------------------------------
#
#  Simulation loop
#
# ---------------------------------------------------------------------

time_step = 0.01
simulation_time = 10

while vis.Run():
    time = system.GetChTime()
    
    # Update driver inputs (example: simple steering)
    driver.SetSteering(0.1 * chrono.ChSin(time * 2))

    # Advance the simulation
    system.DoStepDynamics(time_step)

    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

# Cleanup
vis.Destroy()
```

**Explanation:**

1. **Initialization:**

   - Sets up the PyChrono environment, including the physical system and Irrlicht visualization.
   - Defines gravitational acceleration and creates a directional light source.

2. **Terrain:**

   - Creates a flat terrain plane with a texture.
   - Sets friction and restitution properties for the terrain material.

3. **UAZBUS Vehicle:**

   - Creates a `ChVehicleModel` object representing the UAZBUS.
   - Defines the chassis dimensions and mass.
   - Adds four wheels with specified positions, directions, radii, and other parameters.
   - Loads a 3D mesh for the UAZBUS and attaches it to the chassis.

4. **Driver System:**

   - Creates a `ChDriver` object to control the vehicle.
   - Sets initial steering, throttle, and braking values.
   - Connects the driver to the vehicle.

5. **Simulation Loop:**

   - Runs the simulation until the user closes the Irrlicht window.
   - Updates driver inputs (in this example, a simple sinusoidal steering pattern).
   - Advances the simulation using `system.DoStepDynamics(time_step)`.
   - Renders the scene using Irrlicht.

**Important Notes:**



* You'll need to replace `"uazbus.obj"` and `"terrain.png"` with the actual filenames of your UAZBUS mesh and terrain texture.
* This script provides a basic framework. You can customize it further by adding more complex driver behavior, sensor systems, collision detection, and other features.
* Make sure you have the necessary PyChrono and Irrlicht libraries installed.
