```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add physical systems and objects

# Create the terrain
terrain = chrono.ChBodyEasyBox(100, 100, 0.1)  # Create a flat terrain
terrain.SetBodyFixed(True)
terrain.SetPos(chrono.ChVectorD(0, -0.1, 0))
system.Add(terrain)

# Create the vehicle
vehicle = chronovehicle.ChVehicle("E90", system)

# Load vehicle chassis and suspension
vehicle.SetChassis(chronovehicle.ChChassis(
    "E90Chassis",
    chrono.GetChronoDataPath() + "vehicle/E90/chassis.obj",
    chrono.ChVectorD(0, 0, 0.5),
    chrono.ChQuaternionD(1, 0, 0, 0)
))

# Load wheels and tire model
vehicle.AddWheel(chronovehicle.ChWheelInfo(
    "E90Wheel",
    chrono.GetChronoDataPath() + "vehicle/E90/wheel.obj",
    chrono.ChVectorD(-1.5, -0.8, 0.3),
    chrono.ChQuaternionD(1, 0, 0, 0),
    chrono.ChVectorD(0, 0, 1),
    chrono.ChVectorD(0, -1, 0),
    chronovehicle.TMEasyTire(chrono.GetChronoDataPath() + "vehicle/E90/tire.json")
))

vehicle.AddWheel(chronovehicle.ChWheelInfo(
    "E90Wheel",
    chrono.GetChronoDataPath() + "vehicle/E90/wheel.obj",
    chrono.ChVectorD(1.5, -0.8, 0.3),
    chrono.ChQuaternionD(1, 0, 0, 0),
    chrono.ChVectorD(0, 0, 1),
    chrono.ChVectorD(0, -1, 0),
    chronovehicle.TMEasyTire(chrono.GetChronoDataPath() + "vehicle/E90/tire.json")
))

vehicle.AddWheel(chronovehicle.ChWheelInfo(
    "E90Wheel",
    chrono.GetChronoDataPath() + "vehicle/E90/wheel.obj",
    chrono.ChVectorD(-1.5, 0.8, 0.3),
    chrono.ChQuaternionD(1, 0, 0, 0),
    chrono.ChVectorD(0, 0, 1),
    chrono.ChVectorD(0, -1, 0),
    chronovehicle.TMEasyTire(chrono.GetChronoDataPath() + "vehicle/E90/tire.json")
))

vehicle.AddWheel(chronovehicle.ChWheelInfo(
    "E90Wheel",
    chrono.GetChronoDataPath() + "vehicle/E90/wheel.obj",
    chrono.ChVectorD(1.5, 0.8, 0.3),
    chrono.ChQuaternionD(1, 0, 0, 0),
    chrono.ChVectorD(0, 0, 1),
    chrono.ChVectorD(0, -1, 0),
    chronovehicle.TMEasyTire(chrono.GetChronoDataPath() + "vehicle/E90/tire.json")
))

# 3. Set default parameters
vehicle.SetChassisVisualizationType(chronovehicle.VisualizationType_MESH)
vehicle.SetSuspensionVisualizationType(chronovehicle.VisualizationType_PRIMITIVES)
vehicle.SetWheelVisualizationType(chronovehicle.VisualizationType_MESH)

# Collision settings
vehicle.GetChassisBody().SetCollide(True)
vehicle.GetChassisBody().SetBodyFixed(False)
vehicle.GetChassisBody().SetMass(1500)

# Interactive driver system (placeholder)
# Implement your own driver system for real-time control

# 4. Visualization setup

# Create Irrlicht visualization system
vis = chronoirr.ChIrrApp(system, "BMW E90 Simulation")
vis.AddTypicalSky()
vis.AddTypicalLights()
vis.SetCameraChase(vehicle.GetChassisBody())

# Customize terrain textures and logos (optional)

# Simulation loop
while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()
    vis.DoStep()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary Chrono modules.
   - Sets the Chrono data path for loading assets.
   - Creates the main Chrono system (`system`) and sets gravity.

2. **Adding Objects:**
   - Creates a flat terrain using `ChBodyEasyBox`.
   - Creates a `ChVehicle` object named "E90" and loads its chassis, wheels, and tire model from files.
   - Configures wheel positions, orientations, and tire properties using `ChWheelInfo` and `TMEasyTire`.

3. **Default Parameters:**
   - Sets visualization types for the chassis, suspension, and wheels.
   - Enables collisions for the chassis and sets its mass.
   - **Note:** You'll need to implement your own interactive driver system for controlling steering, throttle, and braking.

4. **Visualization:**
   - Creates an Irrlicht visualization system (`vis`).
   - Adds a skybox and typical lighting.
   - Sets a chase camera that follows the vehicle's chassis.
   - You can further customize the terrain's appearance by adding textures and logos.

5. **Simulation Loop:**
   - Runs the Irrlicht application loop.
   - Renders the scene, performs a simulation step, and updates the display.
