```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Vehicle parameters
#
# ---------------------------------------------------------------------

vehicle_location = chrono.ChVectorD(0, 0, 1)
vehicle_orientation = chrono.ChQuaternionD(1, 0, 0, 0)
contact_method = chronovehicle.ChContactMethod_NSC
tire_model = chronovehicle.ChTireModelNSC

# ---------------------------------------------------------------------
#
#  Create the simulation system and set the gravity
#
# ---------------------------------------------------------------------

system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#
# ---------------------------------------------------------------------

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("FEDA Vehicle Simulation")
vis.Initialize()
vis.AddTypicalLights()
vis.AddSkyBox()

# ---------------------------------------------------------------------
#
#  Create the terrain
#
# ---------------------------------------------------------------------

terrain = chrono.ChRigidTerrain(system)
terrain.SetTexture(chrono.GetChronoDataPath() + 'terrain/textures/grass.jpg')
patch_size = chrono.ChVectorD(100, 100)
terrain.SetSize(patch_size)
terrain.Initialize()

# ---------------------------------------------------------------------
#
#  Create the vehicle
#
# ---------------------------------------------------------------------

vehicle = chronovehicle.ChVehicle(system)
vehicle.SetChassisVisualizationType(chrono.ChVisualizationType_MESH)
vehicle.SetSuspensionVisualizationType(chrono.ChVisualizationType_MESH)
vehicle.SetWheelVisualizationType(chrono.ChVisualizationType_MESH)

# Load vehicle chassis, suspension, and wheels
vehicle.SetChassis(chronovehicle.ChChassis(vehicle_location, vehicle_orientation))
vehicle.AddWheel(chronovehicle.ChWheel(chrono.ChVectorD(1, 1, 0), chrono.ChVectorD(0, 0, 1), tire_model))
# ... Add remaining wheels

# Set contact method and other vehicle parameters
vehicle.SetContactMethod(contact_method)
# ... Set other vehicle parameters like mass, inertia, etc.

# ---------------------------------------------------------------------
#
#  Set camera and interactive driver
#
# ---------------------------------------------------------------------

camera = vis.GetCamera()
camera.SetFollowPos(vehicle_location + chrono.ChVectorD(0, 5, 2))
camera.SetTarget(vehicle_location)

driver = chronovehicle.ChInteractiveDriver(vehicle)

# ---------------------------------------------------------------------
#
#  Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    time_step = 1.0 / 50.0
    system.DoStepDynamics(time_step)

    # Update driver input
    driver.Update(time_step)

    vis.Render()

```

**Explanation:**

1. **Initialization:**

   - Imports necessary PyChrono modules.
   - Sets vehicle parameters like location, orientation, contact method, and tire model.
   - Creates a Chrono system and sets gravity.
   - Initializes Irrlicht visualization and adds lights and skybox.

2. **Terrain:**

   - Creates a rigid terrain using `ChRigidTerrain`.
   - Sets a custom texture for the terrain.
   - Defines the size of the terrain patch.

3. **Vehicle:**

   - Creates a `ChVehicle` object and sets visualization type for chassis, suspension, and wheels to `MESH`.
   - Loads chassis, suspension, and wheel models (you'll need to provide these).
   - Sets the contact method and other vehicle parameters.

4. **Camera and Driver:**

   - Sets up the camera to follow the vehicle from a specific position.
   - Creates an interactive driver system to control steering, throttle, and braking.

5. **Simulation Loop:**

   - Runs the simulation loop at 50 frames per second.
   - Performs a dynamics step using `DoStepDynamics`.
   - Updates the driver input.
   - Renders the scene using Irrlicht.

**Remember:**

- You need to replace the placeholders for loading vehicle models with your actual model files.
- Adjust the vehicle parameters and simulation settings according to your specific requirements.
- This script provides a basic framework. You can extend it with additional features like sensors, actuators, and more complex control systems.
