```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add physical systems and objects
# a. Rigid terrain
terrain = chrono.ChBodyEasyBox(100, 100, 1, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, -0.5, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.8)
material.SetRestitution(0.2)
terrain.AddMaterial(material)

# b. Kraz vehicle
vehicle = chronovehicle.ChVehicle("kraz/kraz.json")
vehicle.SetChassisPosition(chrono.ChVectorD(0, 1, 0))
vehicle.SetChassisBodyFixed(False)
system.Add(vehicle)

# c. Driver system
driver = chronovehicle.ChDriver(vehicle)
driver.SetSteeringAngle(0)
driver.SetThrottle(0)
driver.SetBraking(0)

# 3. Set default parameters
# (Already done in previous steps: initial positions, friction, restitution)

# 4. Visualization setup using Irrlicht
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle("Kraz Simulation")
vis.Initialize()
camera = vis.GetCamera()
camera.SetLocation(chrono.ChVectorD(5, 5, 3))
camera.SetLookAt(chrono.ChVectorD(0, 1, 0))
vis.AddLightWithShadow(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(1, 1, 1), 100)

# 5. Simulation loop
while vis.Run():
    time = system.GetChTime()
    dt = system.GetTimestep()

    # Update driver system
    driver.Synchronize(time)

    # Advance simulation
    system.DoStepDynamics(dt)

    # Update visualization
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules.
   - Sets the Chrono data path.
   - Creates a Chrono system with default gravity.

2. **Adding Objects:**
   - Creates a large, fixed box as the terrain.
   - Defines a material with friction and restitution for the terrain.
   - Loads the Kraz vehicle model from a JSON file.
   - Positions the vehicle above the terrain.
   - Creates a driver system to control the vehicle.

3. **Default Parameters:**
   - Initial positions, friction, and restitution are set during object creation.

4. **Visualization:**
   - Initializes Irrlicht visualization system.
   - Sets window size and title.
   - Positions and aims the camera.
   - Adds a light source with shadows.

5. **Simulation Loop:**
   - Continuously runs until the visualization window is closed.
   - Retrieves current time and timestep.
   - Synchronizes the driver system with the simulation time.
   - Advances the Chrono system by one timestep.
   - Renders the scene using Irrlicht.

**Remember:**

- This script requires the Kraz vehicle model (`kraz.json`) to be available in the specified data path.
- You can adjust parameters like initial positions, driver inputs, camera settings, and material properties to customize the simulation.
