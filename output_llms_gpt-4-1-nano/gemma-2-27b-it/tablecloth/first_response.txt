```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")
my_system = chrono.ChSystemNSC()
my_system.SetSolverType(chrono.ChSolver.Type_PARADISO_MKL)
my_system.SetTimestepperType(chrono.ChTimestepper.Type_EULER_IMPLICIT_LINEARIZED)

# 2. Create the tablecloth mesh
tablecloth_width = 2.0
tablecloth_height = 1.5
num_nodes_x = 20
num_nodes_y = 15

# Generate node positions
nodes = np.zeros((num_nodes_x * num_nodes_y, 3))
for i in range(num_nodes_x):
    for j in range(num_nodes_y):
        nodes[i * num_nodes_y + j, :] = [i * tablecloth_width / (num_nodes_x - 1),
                                        j * tablecloth_height / (num_nodes_y - 1), 0]

# Create shell elements
elements = []
for i in range(num_nodes_x - 1):
    for j in range(num_nodes_y - 1):
        node1 = i * num_nodes_y + j
        node2 = i * num_nodes_y + (j + 1)
        node3 = (i + 1) * num_nodes_y + (j + 1)
        node4 = (i + 1) * num_nodes_y + j
        elements.append([node1, node2, node3, node4])

# 3. Add tablecloth to the simulation
tablecloth_material = chrono.ChMaterialShellKirchhoffIsotropic(
    E=10000,  # Young's modulus
    nu=0.3,   # Poisson's ratio
    rho=1000  # Density
)

tablecloth = chrono.ChBody()
tablecloth.SetBodyFixed(False)
tablecloth.SetMass(0.1)  # Adjust mass as needed

mesh = chrono.ChMesh()
for node in nodes:
    mesh.AddNode(chrono.ChNodeFEAxyz(chrono.ChVectorD(node[0], node[1], node[2])))

for element in elements:
    mesh.AddShellElement(tablecloth_material, element)

tablecloth.AddAsset(mesh)
my_system.Add(tablecloth)

# 4. Set up Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Tablecloth Folding Simulation")
vis.Initialize()
vis.AddTypicalSky()
vis.AddCamera(chrono.ChVectorD(0, 5, 5))

# 5. Simulation loop
while vis.Run():
    my_system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:**

   - Imports necessary PyChrono and Irrlicht modules.
   - Sets the Chrono data path.
   - Creates a Chrono system (`my_system`) and sets the solver to PardisoMKL for efficient dynamics.
   - Sets the timestepper to Euler Implicit Linearized for stability.

2. **Tablecloth Mesh:**

   - Defines tablecloth dimensions and node grid resolution.
   - Generates node positions in a rectangular grid.
   - Creates quadrilateral shell elements by connecting the nodes.

3. **Adding Tablecloth:**

   - Creates a Kirchhoff isotropic material with specified Young's modulus, Poisson's ratio, and density.
   - Creates a Chrono body (`tablecloth`) and sets its properties (fixed or free, mass).
   - Creates a Chrono mesh (`mesh`) and adds nodes and shell elements based on the generated data.
   - Attaches the mesh to the tablecloth body and adds it to the Chrono system.

4. **Visualization:**

   - Creates an Irrlicht visualization system (`vis`) and attaches it to the Chrono system.
   - Sets window size, title, and initializes the visualization.
   - Adds a typical sky and a camera for viewing the simulation.

5. **Simulation Loop:**

   - Runs the Irrlicht visualization loop.
   - In each iteration, performs a dynamics step (`DoStepDynamics`) with a time step of 0.01 seconds.
   - Renders the scene using Irrlicht (`vis.Render()`).

**Remember:**

- This script provides a basic framework. You can adjust parameters like material properties, tablecloth dimensions, and simulation settings to explore different folding behaviors.
- You might need to install the required PyChrono and Irrlicht libraries. Refer to the PyChrono documentation for installation instructions.
