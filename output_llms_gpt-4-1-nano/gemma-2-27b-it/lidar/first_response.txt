```python
import pychrono as chrono
import pychrono.postprocess as postprocess
import pychrono.irrlicht as chronoirr
import numpy as np

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files

# Create the simulation system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create a material for the mesh
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.5)
material.SetRestitution(0.2)

# 2. Add the required physical systems and objects
# Load the triangular mesh from .obj file
mesh = chrono.ChTriangleMeshConnected()
mesh.LoadWavefrontMesh("your_mesh.obj")  # Replace "your_mesh.obj" with your file

# Create a fixed body for the mesh
body = chrono.ChBody()
body.SetBodyFixed(True)
body.SetCollide(True)
body.AddAsset(chrono.ChTriangleMeshShape(mesh, material))

# Add the body to the system
system.Add(body)

# 3. Set necessary default parameters

# Create a sensor manager
sensor_manager = chrono.ChSensorManager(system)

# Create a lidar sensor
lidar = chrono.ChLidarSensor()
lidar.SetCollisionEnvelope(0.1)  # Collision detection range
lidar.SetScanAngle(chrono.ChVectorD(-np.pi / 4, np.pi / 4, 0))  # Scan angle
lidar.SetAngularResolution(np.pi / 180)  # Angular resolution

# Apply noise filters
lidar.AddNoiseFilter(chrono.ChLidarNoiseFilterGaussian(0.01))

# Enable visualization
lidar.SetVisualization(True)

# Set saving options
lidar.SetSaveData(True)
lidar.SetSaveFilename("lidar_data.txt")

# Attach the lidar to the body
sensor_manager.AddSensor(lidar)
lidar.AttachToBody(body)

# Initialize Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Lidar Simulation")
vis.Initialize()

# Simulation loop
while vis.Run():
    # Update lidar position in an orbit around the mesh
    angle = system.GetChTime() * 0.5  # Orbit speed
    lidar.SetPos(chrono.ChVectorD(2 * np.cos(angle), 0, 2 * np.sin(angle)))

    # Simulate one time step
    system.DoStepDynamics(0.01)

    # Print lidar buffer data
    print(lidar.GetBuffer())

    # Render the scene
    vis.Render()
```

**Explanation:**

1. **Initialization:** Sets up the Chrono environment, creates a system, and defines gravity.
2. **Mesh and Body:** Loads the mesh from the .obj file, creates a fixed body, assigns the mesh to the body, and adds it to the system.
3. **Lidar Sensor:** Creates a lidar sensor, configures its parameters (collision range, scan angle, resolution), applies noise filters, enables visualization, and sets saving options.
4. **Sensor Manager:** Attaches the lidar to the body using the sensor manager.
5. **Visualization:** Initializes Irrlicht for visualization and sets up the window.
6. **Simulation Loop:**

   - Updates the lidar's position in a circular orbit around the mesh.
   - Performs a single simulation step.
   - Prints the lidar buffer data (point cloud information).
   - Renders the scene using Irrlicht.

**Remember:**

- Replace `"your_mesh.obj"` with the actual path to your .obj file.
- Adjust parameters like orbit speed, lidar settings, and simulation step size as needed.
