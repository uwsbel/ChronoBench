```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize PyChrono environment
chrono.SetChronoDataPath("..")  # Set the path to your Chrono data files
system = chrono.ChSystemNSC()  

# Create the ground plane
ground = chrono.ChBodyEasyBox(10, 10, 0.1)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# Define beam parameters
beam_length = 5
beam_width = 0.1
beam_height = 0.1
num_nodes = 5  

# Create beam nodes and connect them with ANCF cable elements
nodes = []
for i in range(num_nodes + 1):
    node = chrono.ChBodyEasySphere(0.05)
    node.SetPos(chrono.ChVectorD(i * beam_length / num_nodes, 0, 0))
    system.Add(node)
    nodes.append(node)

for i in range(num_nodes):
    cable = chrono.ChLinkCable(nodes[i], nodes[i + 1])
    cable.SetAncf(True)  # Set ANCF cable type
    cable.SetRestLength(beam_length / num_nodes)
    cable.SetMaterial(chrono.ChMaterialSurfaceNSC())
    system.Add(cable)

# Apply gravity
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create Irrlicht visualization
vis = chronoirr.ChIrrApp(system, 'Beam Simulation', chronoirr.dimension2du(1024, 768))
vis.AddTypicalLights()
vis.AddCamera(chrono.ChVectorD(10, 10, 10), chrono.ChVectorD(0, 0, 0))

# Simulation loop
vis.Start()
while vis.GetRunning():
    vis.Render()
    system.DoStepDynamics(chrono.ChTime(0.01))

vis.Stop()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries (`pychrono` and `pychrono.irrlicht`).
   - Set the Chrono data path.
   - Create a `ChSystemNSC` object to represent the simulation environment.

2. **Ground Plane:**
   - Create a rectangular box (`ChBodyEasyBox`) to represent the ground plane.
   - Set its position and fix it in place using `SetBodyFixed(True)`.

3. **Beam Definition:**
   - Define parameters for the beam: length, width, height, and number of nodes.
   - Create a list of nodes (`nodes`) using `ChBodyEasySphere` objects.
   - Position each node along the beam's length.
   - Add each node to the simulation system.

4. **Beam Elements:**
   - Create `ChLinkCable` objects to connect the nodes.
   - Set the `Ancf` property to `True` to use ANCF cable elements.
   - Define the rest length of each cable.
   - Set a material for the cables using `ChMaterialSurfaceNSC()`.
   - Add each cable to the simulation system.

5. **Gravity:**
   - Apply gravity to the system using `Set_G_acc()`.

6. **Visualization:**
   - Create an `ChIrrApp` object to use Irrlicht for rendering.
   - Add typical lights and a camera to the scene.

7. **Simulation Loop:**
   - Start the Irrlicht visualization loop using `vis.Start()`.
   - Inside the loop:
     - Render the scene using `vis.Render()`.
     - Advance the simulation by one time step using `system.DoStepDynamics()`.
   - Stop the visualization loop using `vis.Stop()`.



This script creates a simple beam simulation with ANCF cables. You can modify the parameters (beam length, width, height, number of nodes) to experiment with different beam configurations.
