```python
import pychrono as chrono
import pychrono.irrlicht as vis

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("./")  # Set the path to your Chrono data files
system = chrono.ChSystemNSC()  # Create a new system with no solver
vis.ChVisualizationSystem_Irrlicht(system)  # Initialize visualization with Irrlicht

# 2. Add physical systems and objects
# Create a rigid body for the base
base = chrono.ChBodyEasyBox(1.0, 1.0, 0.5)
base.SetPos(chrono.ChVectorD(0, 0, 0))
system.AddBody(base)

# Create a mesh composed of beams and nodes
mesh = chrono.ChMeshBeam()

# Define nodes
node1 = chrono.ChNode()
node1.SetName("Node1")
node1.SetPos(chrono.ChVectorD(0, 0, 0))
node2 = chrono.ChNode()
node2.SetName("Node2")
node2.SetPos(chrono.ChVectorD(1, 0, 0))
node3 = chrono.ChNode()
node3.SetName("Node3")
node3.SetPos(chrono.ChVectorD(1, 1, 0))
node4 = chrono.ChNode()
node4.SetName("Node4")
node4.SetPos(chrono.ChVectorD(0, 1, 0))

# Define beams
beam1 = chrono.ChBeam(node1, node2, 0.1, 10)  # Beam properties: length, cross-section
beam2 = chrono.ChBeam(node2, node3, 0.1, 10)
beam3 = chrono.ChBeam(node3, node4, 0.1, 10)
beam4 = chrono.ChBeam(node4, node1, 0.1, 10)

# Add nodes and beams to the mesh
mesh.AddNode(node1)
mesh.AddNode(node2)
mesh.AddNode(node3)
mesh.AddNode(node4)
mesh.AddBeam(beam1)
mesh.AddBeam(beam2)
mesh.AddBeam(beam3)
mesh.AddBeam(beam4)

# Add the mesh to the system
system.Add(mesh)

# 3. Set default parameters
# Set material properties for beams (example)
beam_material = chrono.ChMaterialSurfaceNSC()
beam_material.SetYoungModulus(200e9)
beam_material.SetYieldStress(200e6)
beam_material.SetDensity(7850)
beam1.SetMaterial(beam_material)
beam2.SetMaterial(beam_material)
beam3.SetMaterial(beam_material)
beam4.SetMaterial(beam_material)

# Set initial forces or constraints (optional)

# Run the simulation loop
vis.Application().Run()

```

**Explanation:**

1. **Initialization:**
   - `chrono.SetChronoDataPath("./")`: Sets the path to your Chrono data files (e.g., textures, shapes).
   - `system = chrono.ChSystemNSC()`: Creates a new Chrono system without a solver (you'll likely need to add a solver later for dynamics).
   - `vis.ChVisualizationSystem_Irrlicht(system)`: Initializes the Irrlicht visualization engine for real-time rendering.

2. **Adding Physical Systems and Objects:**
   - **Base:** A rigid body `base` is created using `chrono.ChBodyEasyBox()` to represent a simple box-shaped base.
   - **Mesh:** A `chrono.ChMeshBeam()` object is created to represent the beam finite element mesh.
   - **Nodes:** Four `chrono.ChNode()` objects (`node1`, `node2`, `node3`, `node4`) are created and positioned to define the vertices of the mesh.
   - **Beams:** Four `chrono.ChBeam()` objects (`beam1`, `beam2`, `beam3`, `beam4`) are created, connecting the nodes. You need to specify the beam's length and cross-section properties.
   - **Adding to Mesh:** The nodes and beams are added to the `mesh` object using `mesh.AddNode()` and `mesh.AddBeam()`.

3. **Setting Default Parameters:**
   - **Material:** A `chrono.ChMaterialSurfaceNSC()` object is created to define material properties for the beams (Young's modulus, yield stress, density).
   - **Applying Material:** The material is assigned to each beam using `beam.SetMaterial()`.
   - **Forces/Constraints:** You can add initial forces or constraints to the system if needed (not shown in this example).

4. **Simulation Loop:**
   - `vis.Application().Run()`: Starts the Irrlicht visualization and simulation loop. The simulation will run until you manually stop it.



**Remember:**

- You'll likely need to adjust the beam properties, node positions, and other parameters to achieve the desired simulation behavior.
- Consider adding a solver to the system for dynamic simulations.
- Explore the PyChrono documentation for more advanced features and customization options: [https://pychrono.readthedocs.io/](https://pychrono.readthedocs.io/)
