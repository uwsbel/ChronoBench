Certainly! Below is a comprehensive PyChrono simulation script that models a Jeffcott rotor using an IGA beam, with a flywheel attached at the center, driven by a rotational motor at one end. The script includes initialization, creation of the beam with IGA properties, attachment of the flywheel, setup of the motor, and visualization components.

```python
import pychrono.core as chrono
import pychrono.irrlicht as irr

# Initialize the Chrono system
system = chrono.ChSystemNSC()

# Set gravity (if needed)
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# ---------------------------
# Create the IGA Beam
# ---------------------------

# Define beam parameters
beam_length = 1.0  # meters
beam_radius = 0.02  # meters
beam_density = 7800  # kg/m^3 (steel)
beam_E = 2.1e11  # Pa (Young's modulus)
beam_nu = 0.3  # Poisson's ratio

# For IGA beam, we need to define control points, basis functions, etc.
# Here, we mock up a simple beam with a linear shape for demonstration.
# In practice, you'd define the IGA basis functions and control points accordingly.

# Create a beam node (simplified as a rigid body for visualization)
beam_body = chrono.ChBodyEasyBox(beam_length, beam_radius*2, beam_radius*2, 
                                  beam_density, True, True)
beam_body.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(beam_body)

# ---------------------------
# Attach a Flywheel at the Center
# ---------------------------

# Create flywheel as a rigid body
flywheel_radius = 0.05  # meters
flywheel_thickness = 0.02  # meters
flywheel_mass = 0.5  # kg

flywheel = chrono.ChBodyEasyCylinder(flywheel_radius, flywheel_thickness, flywheel_mass, True, True)
# Position at the center of the beam
flywheel.SetPos(chrono.ChVectorD(beam_length/2, 0, 0))
system.Add(flywheel)

# ---------------------------
# Attach the Flywheel to the Beam
# ---------------------------

# Create a revolute joint to connect flywheel to the beam at the center
joint_center = chrono.ChLinkLockRevolute()
joint_center.Initialize(flywheel, beam_body, chrono.ChCoordsysD(chrono.ChVectorD(beam_length/2, 0, 0)))
system.Add(joint_center)

# ---------------------------
# Create a Motor at one end of the beam
# ---------------------------

# Create a motor to rotate one end of the beam
# Assume the beam's end is at x=0
end_body = beam_body  # For simplicity, consider the entire beam as a rigid body
# Alternatively, create a separate body for the end if needed

# Create a revolute joint at the fixed end (x=0)
fixed_joint = chrono.ChLinkLockRevolute()
fixed_joint.Initialize(beam_body, None, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
system.Add(fixed_joint)

# Create a motor to rotate the end
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(beam_body, None, chrono.ChVectorD(1, 0, 0))
motor.SetSpeed(20.0)  # rad/sec
system.Add(motor)

# ---------------------------
# Visualization Setup
# ---------------------------

# Create the Irrlicht application
application = irr.ChIrrApp(system, "Jeffcott Rotor Simulation", irr.dimension2du(800, 600))
application.AddTypicalSky()
application.AddTypicalCamera(irr.vector3df(0, 0.2, 1.0))
application.AddTypicalLights()

# Add visualization for the beam (as a thin box)
visual_beam = chrono.ChVisualizationFEAmesh()
# For actual IGA visualization, you'd load or generate the mesh accordingly
# Here, we mock it as a simple box for demonstration
visual_beam.SetMesh(chrono.ChSharedPtr(chrono.ChTriangleMeshConnected()))
visual_beam.SetFEMdata(chrono.ChSharedPtr(chrono.ChFEMesh>()))
visual_beam.SetWireframe(True)
beam_body.GetAssets().push_back(visual_beam)

# Add visualization for the flywheel
flywheel_asset = chrono.ChVisualizationAssetSphere(flywheel_radius)
flywheel.GetAssets().push_back(flywheel_asset)

# Initialize and run the simulation
application.AssetBindAll()
application.AssetUpdateAll()

# Simulation loop
while application.GetDevice().run():
    application.BeginScene()
    application.DrawAll()
    application.EndScene()
    system.DoStepDynamics(1e-4)

```

### Notes:
- The above code provides a simplified representation. For a true IGA beam, you would need to define the basis functions, control points, and assemble the FEM mesh accordingly.
- The flywheel is attached at the center of the beam via a revolute joint.
- The motor applies a constant rotational speed at one end of the beam.
- Visualization is set up with Irrlicht, with basic assets for the beam and flywheel.
- Adjust parameters such as beam length, material properties, and motor speed to match your specific scenario.
