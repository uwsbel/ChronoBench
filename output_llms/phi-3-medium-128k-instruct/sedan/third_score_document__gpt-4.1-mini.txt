### 2. Correctness (30 points)

- **System Creation**:

- **Collision System Type**:  
  The collision system type is set after vehicle initialization:  
  ```python
  vehicle.GetSystem().SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)
  ```  
  This is acceptable, but best practice is to set collision system type before initialization to ensure proper setup.  
  **Deduction: 5 points** (minor correctness issue).

- **PID Controller Implementation**:  
  The PID controller is defined inside the main script as a function returning an inner function `update`. However, the variables `integral`, `last_speed_error`, and `last_time` are reset to zero every time `pid_controller` is called, which happens inside the simulation loop:  
  ```python
  throttle = pid_controller(current_speed, reference_speed)(time)
  ```  
  This means the integral and derivative terms never accumulate correctly, and the controller behaves like a simple proportional controller with no memory. This is a significant logical error affecting control behavior.  
  **Deduction: 15 points** (major logical error).

  The throttle value from the PID controller is set directly via `driver.SetThrottle(throttle)`. Since the PID output can be outside the valid range [0,1], no clamping is done, which may cause invalid inputs.  
  **Deduction: 5 points** (logical error / missing validation).
