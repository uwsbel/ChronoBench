Here's a Python script using PyChrono to simulate a Kraz vehicle on a rigid terrain with real-time visualization using Irrlicht. Make sure you have PyChrono installed (`pip install pychrono`).

```python
import pychrono as pc
import pychrono.vehicle as pcv
import pychrono.sensor as pcs
import pychrono.visualizer as pcviz

# 1. Initialize the PyChrono environment and core components
pc.init()

# 2. Add the required physical systems and objects

# Create a rigid terrain
terrain = pc.Solid()
terrain.add_shape(pc.Box(100, 1, 100), pos=[0, -0.5, 0], mat=pc.Material(friction=0.8, restitution=0.5))
pc.World().add(terrain)

# Create a Kraz vehicle
vehicle = pcv.Kraz()
vehicle.set_pos([0, 0.5, 0])  # Set initial position
vehicle.set_rot(pc.Quaternion(0, 0, 0, 1))  # Set initial orientation
pc.World().add(vehicle)

# Create a driver system for vehicle control
driver = pcs.Driver(vehicle)
driver.set_control(pcv.DriveMode.steer, 0)  # Set initial steering angle

# 3. Set necessary default parameters

# Set up real-time visualization using Irrlicht
viz = pcviz.Irlicht()
viz.set_camera_pos([5, 5, 5])  # Set camera position
viz.set_camera_lookat([0, 0, 0])  # Set camera look-at point
viz.set_lighting([0.5, 0.5, 0.5])  # Set lighting
viz.add_vehicle(vehicle)
viz.add_terrain(terrain)

# Simulation loop
while True:
    # Synchronize and advance the vehicle, terrain, driver, and visual system
    pc.World().step(0.01)  # Timestep
    vehicle.actuator_update()  # Update vehicle actuators
    driver.update()  # Update driver control
    viz.update()  # Update visualization

    # Break the loop if escape key is pressed
    if viz.get_key_state(pc.Key.ESCAPE):
        break

# Clean up and exit PyChrono
pc.quit()
```

This script creates a Kraz vehicle on a rigid terrain with specified friction and restitution. It initializes a driver system for vehicle control and sets up a real-time visualization using Irrlicht with camera settings and lighting. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution. The loop breaks when the escape key is pressed.
