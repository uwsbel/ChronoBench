Here's a Python script using PyChrono to create the described simulation. Make sure you have PyChrono and the required libraries installed (e.g., `pip install PyChrono`).

```python
import pychrono as chrono
import numpy as np

# 1. Initialize PyChrono environment and core components
sim = chrono.ChSimulation()
sim.SetTimestepper(chrono.ChTimestepper.ChTimestepper_SemiImplicitEuler())
sim.SetSolver(chrono.ChSolver.ChSolver_SOR())
sim.SetSolverMaxIterations(50)
sim.SetSolverTolerance(1e-3)
sim.SetSolverAbsoluteTolerance(1e-3)
sim.SetSolverRelativeTolerance(1e-3)

# 2. Add required physical systems and objects
# Create a rigid terrain
terrain = chrono.ChTerrain()
terrain.SetTexture(chrono.ChTexture.PNG, "terrain.png")
terrain.SetColor(chrono.ChColor(0.8, 0.8, 0.8))
terrain.SetBumpMapping(True)
terrain.SetDimensions(50, 50, 0.1)
terrain.SetMaterial(chrono.ChMaterialSurface.ChMaterialSurface_NSC())
sim.Add(terrain)

# Create a full HMMWV vehicle
vehicle = chrono.ChVehicle()
vehicle.SetChassis(chrono.ChBodyEasyBox(1.5, 3, 2, 1000, True))
vehicle.SetChassisPos(chrono.ChVectorD(0, 0, 1))
vehicle.SetChassisRot(chrono.ChQuaternionD(1, 0, 0, 0))
vehicle.SetContactMethod(chrono.ChVehicle.ChVehicleContactMethod_SIMPLE)

# Add wheels with TMEASY tire model
for i in range(4):
    wheel = chrono.ChWheel()
    wheel.SetSpokeRadius(0.2)
    wheel.SetTireRadius(0.3)
    wheel.SetTireWidth(0.2)
    wheel.SetTireModel(chrono.ChTire.ChTire_TMEASY())
    wheel.SetWheelPos(chrono.ChVectorD(-1.5 + i * 1.5, 1.5, 1))
    wheel.SetWheelRot(chrono.ChQuaternionD(0, 0, 1, 0))
    wheel.SetChassis(vehicle.GetChassis())
    vehicle.AddWheel(wheel)

# Set up an interactive driver system
driver = chrono.ChVehicleDriver()
driver.SetSteeringInput(0)
driver.SetThrottleInput(0)
driver.SetBrakeInput(0)
vehicle.SetDriver(driver)

# 3. Set necessary default parameters
sim.SetTimestep(0.01)
sim.SetSolverStepSize(0.01)
sim.SetSolverIterations(50)

# Set up visualization with Irrlicht
irrlicht = chrono.ChIrrlichtApplication(sim, "PyChrono HMMWV Simulation")
irrlicht.AddTypicalSky(irrlicht.GetVideoDriver())
irrlicht.AddTypicalLights(irrlicht.GetSceneManager())
irrlicht.SetShadows(irrlicht.GetVideoDriver().getFeatureState(irrlicht.vid_fs_SSAO))

# Simulation loop
while irrlicht.GetDevice().run():
    # Update vehicle dynamics
    vehicle.Update(0.01)

    # Render scene
    irrlicht.DoStep()

    # Limit frame rate to 50 FPS
    chrono.ChThreadSleep(0.02)
```

Before running the script, make sure to have a `terrain.png` file in the same directory, which will be used as the texture for the terrain. Also, ensure that you have the required libraries and dependencies installed.

This script creates a simple HMMWV vehicle with four wheels using the TMEASY tire model. The vehicle is placed on a flat rigid terrain with a defined texture. An interactive driver system is set up for steering, throttle, and braking. The simulation runs in real-time at 50 frames per second, updating the vehicle dynamics and rendering the scene using Irrlicht.
