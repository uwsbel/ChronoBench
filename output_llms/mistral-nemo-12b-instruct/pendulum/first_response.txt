Here's a Python script using PyChrono and Irrlicht to simulate a simple pendulum according to the given instructions:

```python
import chrono as ch
import chrono.irrlicht as ci
import numpy as np

# 1. Initialize the PyChrono environment and core components.
ch.SetChronoDataPath("path/to/chrono_data")  # Set the path to Chrono data
my_system = ch.ChSystemSMC()  # Create a new system
my_system.Set_Gravity(ch.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add the required physical systems and objects.
ground = ch.ChBodyEasyBox(10, 10, 0.1, 1000, True)  # Create a ground body
ground.SetBodyFixed(True)  # Fix the ground body
my_system.Add(ground)

pendulum = ch.ChBodyEasyBox(0.1, 0.1, 0.5, 1, True)  # Create a pendulum body
pendulum.SetMass(1)  # Set mass
pendulum.SetInertiaXX(ch.ChVectorD(0.01, 0.01, 0.04))  # Set inertia
my_system.Add(pendulum)

# Create a revolute joint to connect the pendulum to the ground
joint = ch.ChLinkRevolute()
joint.Initialize(ground, pendulum, ch.ChFrameD().SetPos(ch.ChVectorD(0, 0.5, 0)))  # Set joint position
my_system.AddLink(joint)

# 3. Set necessary default parameters such as positions, forces, and interactions.
pendulum.SetPos(ch.ChVectorD(0, 0.5, 0))  # Set initial pendulum position
pendulum.SetRot(ch.ChQuaternionD(ch.Q_from_AngX(ch.CH_C_PI)))  # Set initial pendulum orientation

# Create a visualization system using Irrlicht
app = ci.ChIrrApp(my_system, "Simple Pendulum", ci.w1280, ci.w720)
app.AddTypicalSky()
app.AddTypicalLights()
app.AddTypicalLogo(ci.w1280, ci.w720)
app.AddModel(ground)  # Add ground to the visualization
app.AddModel(pendulum)  # Add pendulum to the visualization
app.AddModel(joint)  # Add joint to the visualization

# Periodically log the pendulum's position and velocity
while app.GetDevice().run():
    app.BeginScene()
    app.DrawAll()
    app.EndScene()

    # Log pendulum's position and velocity
    pos = pendulum.GetPos()
    vel = pendulum.GetPos_dt()
    print(f"Pendulum position: {pos}, velocity: {vel}")

    app.Advance()
```

This script initializes a PyChrono environment, creates a ground body, a pendulum body with appropriate mass and inertia, and connects them with a revolute joint. It then sets up an Irrlicht visualization system to render the simulation and periodically logs the pendulum's position and velocity. Make sure to replace `"path/to/chrono_data"` with the actual path to your Chrono data folder.

To run the script, save it as a `.py` file (e.g., `simple_pendulum.py`) and execute it using Python:

```
python simple_pendulum.py
```
