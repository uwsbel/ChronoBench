Here's a Python script using PyChrono to simulate an M113 vehicle on a rigid terrain with real-time visualization using Irrlicht. Make sure you have PyChrono and its dependencies installed (`pip install PyChrono`).

```python
import pychrono as pc
import numpy as np

# 1. Initialize the PyChrono environment and core components
pc.set_log_level(pc.LogLevel.INFO)
sim = pc.Simulation()
clock = pc.Clock()
sim.set_gravity([0, 0, -9.81])

# 2. Add the required physical systems and objects
# Rigid terrain
terrain = pc.create_terrain("terrain", 100, 100, 0.5, 0.5)
terrain.set_friction(0.8)
terrain.set_restitution(0.5)
sim.add(terrain)

# M113 vehicle
m113 = pc.create_vehicle("m113", "m113.urdf", [0, 0, 0.5])
m113.set_wheels_friction(0.5)
sim.add(m113)

# Driver system
driver = pc.create_driver("driver", m113)
driver.set_throttle(0.5)
driver.set_steering(0.0)
sim.add(driver)

# 3. Set necessary default parameters
# Camera settings
camera = pc.Camera()
camera.set_position([10, 10, 5])
camera.set_lookat([0, 0, 0.5])
sim.set_camera(camera)

# Lighting
light = pc.Light()
light.set_position([10, 10, 10])
light.set_color([1, 1, 1])
sim.add(light)

# Irrlicht visualization
irrlicht = pc.Irrlicht()
irrlicht.set_size(800, 600)
irrlicht.set_title("M113 Vehicle Simulation")
sim.set_irrlicht(irrlicht)

# Simulation loop
while not sim.is_finished():
    # Synchronize and advance the vehicle, terrain, driver, and visual system
    sim.synchronize()
    sim.advance(clock)
    sim.render(irrlicht)

    # Print vehicle position for debugging
    pos = m113.get_position()
    print(f"Vehicle position: {pos}")

    # Break the loop if the vehicle has traveled a certain distance
    if np.linalg.norm(pos[:2]) > 50:
        break

# Finalize the simulation
sim.finalize()
```

This script creates an M113 vehicle on a rigid terrain with specified friction and restitution. It initializes a driver system to control the vehicle and sets up a real-time visualization using Irrlicht with camera settings and lighting. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution. The loop breaks when the vehicle has traveled a certain distance.
