Here's a Python script using PyChrono to create the described simulation. Make sure you have PyChrono and Chrono::Vehicle installed.

```python
import pychrono as pc
import pychrono.vehicle as pv
import pychrono.irrlicht as pi
import numpy as np

# 1. Initialize PyChrono environment and core components
pc.setChronoDataPath("../ChronoData")  # Set data path
pc.setChronoLogLevel(3)  # Set log level

# Create Chrono system and set gravity
sys = pc.ChSystemNSC()
sys.Set_Gravity(ChVectorD(0, -9.81, 0))

# 2. Add physical systems and objects
# Create ground body
ground = pc.ChBodyEasyBox(100, 1, 100, 1000, 1000, 1000)
ground.SetPos(ChVectorD(0, -0.5, 0))
sys.Add(ground)

# Create Viper rover and its driver
chassis = pv.ChViper()
driver = pv.ChViperDriver(chassis)
sys.Add(chassis)
sys.Add(driver)

# Set initial position and orientation of the rover
chassis.SetPos(ChVectorD(0, 0.5, 0))
chassis.SetRot(ChQuaternionD(1, 0, 0, 0))

# 3. Set necessary default parameters
# Set forces and interactions
driver.SetSteering(0)  # Initial steering angle
driver.SetThrottle(0.5)  # Initial throttle

# Create real-time visualization using Irrlicht
app = pi.ChIrrApp(sys, 'Viper Rover Simulation', pc.getChronoDataPath() + 'media/')
app.SetCamera(ChVectorD(1, 1, 1), ChVectorD(0, 0, 0))  # Set camera position and target
app.AddTypicalLights()
app.AddTypicalSkyBox()
app.Asset.AddChBody(ground)
app.Asset.AddChBody(chassis)

# Simulation loop
t_final = 5  # Total simulation time
dt = 0.01  # Timestep
steering_rate = 0.2  # Steering rate change per second

for t in np.arange(0, t_final, dt):
    # Update steering angle
    steering = driver.GetSteering() + steering_rate * dt
    steering = np.clip(steering, -1, 1)  # Clip steering angle between -1 and 1
    driver.SetSteering(steering)

    # Advance simulation
    sys.DoStepDt(dt)

    # Render
    app.Render()
    app.Exit()  # Exit if user closes the window
```

This script creates a PyChrono simulation with a Viper rover on a rigid terrain. The rover's steering gradually changes over a specified time period, updating and rendering the rover at each timestep. The real-time visualization uses Irrlicht with camera settings and lighting.
