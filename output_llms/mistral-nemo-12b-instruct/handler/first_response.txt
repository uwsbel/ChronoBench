Here's a Python script using PyChrono and ROS (Robot Operating System) to simulate a box moving on a floor. This script assumes you have ROS and PyChrono installed and properly configured.

```python
import pychrono as chrono
import rospy
from std_msgs.msg import Int32

# Initialize PyChrono environment and core components
physics = chrono.ChPhysicsEngine()
system = chrono.ChSystem(physics)
manager = chrono.ChSystemManager()
manager.AddSystem(system)

# Set gravitational acceleration
system.Set_Gravity(chrono.ChVectorD(0, -9.81, 0))

# Create physical material properties
material = chrono.ChMaterialSurfaceNSC()
material.SetYoungModulus(1e7)  # Young modulus
material.SetFriction(0.6)  # Friction

# Add fixed floor
floor = chrono.ChBodyEasyBox(0.5, 0.5, 0.01, material)
floor.SetPos(chrono.ChVectorD(0, 0, -0.005))
floor.SetBodyFixed(True)
system.Add(floor)

# Add movable box
box = chrono.ChBodyEasyBox(0.1, 0.1, 0.1, material)
box.SetPos(chrono.ChVectorD(0, 0, 0.05))
box.SetMass(1)
box.SetBuoyancyForce(chrono.ChVectorD(0, 0, -1))
system.Add(box)

# Initialize ROS node
rospy.init_node('pychrono_ros_handler', anonymous=True)

# Create a custom ROS handler to publish integer messages
class CustomROSHandler(chrono.ChROSHandler):
    def __init__(self):
        super(CustomROSHandler, self).__init__()
        self.pub = rospy.Publisher('pychrono_topic', Int32, queue_size=10)

    def OnUpdate(self, mySystem, myItem, clock):
        msg = Int32()
        msg.data = int(box.GetPos().y)
        self.pub.publish(msg)

# Configure ROS manager with clock, body, and transform handlers
manager.AddROSHandler(chrono.ChROSClockHandler())
manager.AddROSHandler(chrono.ChROSBodyHandler())
manager.AddROSHandler(chrono.ChROSLinkHandler())
manager.AddROSHandler(CustomROSHandler())  # Register the custom handler

# Run simulation loop
while not rospy.is_shutdown():
    manager.DoStepDynamics(chrono.GetChronoDataManager().GetTimestep())
    manager.RunROSCommunication()
```

This script creates a PyChrono simulation with a fixed floor and a movable box. It also sets up a ROS node and a custom ROS handler to publish the y-position of the box as an integer message to the 'pychrono_topic' topic. The simulation loop advances the system and updates ROS communication at each timestep, maintaining real-time execution.
