Here's a Python script using PyChrono to create the simulation as described in the instructions. Note that you'll need to have PyChrono and its dependencies installed. You can install them using pip:

```bash
pip install pychrono pybullet
```

Now, here's the script:

```python
import pychrono as pc
import pybullet_data
import numpy as np

# Initialize PyChrono environment
pc.init()

# Set up the simulation
sim = pc.Simulation()
sim.setGravity(0, 0, -9.81)
sim.setTimeStep(0.01)
sim.setRealTimeMode(True)

# Load terrain and set up visualization
terrain = sim.loadTerrainFromHeightfield("terrain_heightmap.png", "terrain_texture.jpg")
sim.setCameraTargetPosition([0, 0, 5])
sim.setCameraDistance(10)
sim.setCameraFieldOfView(60)
sim.setCameraChase(True)

# Load truck model and set up visualization
truck_urdf = "truck_10t.urdf"
truck = sim.loadURDF(truck_urdf, [0, 0, 0.5], useFixedBase=False)
sim.setVisualization(truck, pc.VISUALIZATION.ON, pc.COLLISION.ON)

# Set up tire model
tire_model = "tmeasy_tire.urdf"
tire_index = 0
tire = sim.loadURDF(tire_model, [0, 0, 0], useFixedBase=False, parentBodyIndex=truck, linkIndex=tire_index)
sim.setVisualization(tire, pc.VISUALIZATION.OFF, pc.COLLISION.ON)

# Set up real-time driver controls
steering = 0
throttle = 0
brake = 0

# Set up directional lighting and skybox
light = sim.createLight([0, 0, 5], [1, 1, 1])
skybox = sim.loadSkybox("skybox_images/")

# Simulation loop
while True:
    # Apply driver controls to truck
    sim.applyForce(truck, [0, 0, -9.81 * 10000])  # Apply gravity compensation
    sim.applySteering(truck, steering)
    sim.applyThrottle(truck, throttle)
    sim.applyBrake(truck, brake)

    # Update simulation
    sim.step()

    # Get user input for steering, throttle, and brake
    steering = pc.getKeyboardInput("left", "right") * 0.5
    throttle = pc.getKeyboardInput("up") * 1000
    brake = pc.getKeyboardInput("down") * 1000

    # Break loop on 'q' key press
    if pc.getKeyboardInput("q"):
        break

# Clean up and exit
pc.exit()
```

Make sure to replace `"terrain_heightmap.png"`, `"terrain_texture.jpg"`, `"truck_10t.urdf"`, and `"tmeasy_tire.urdf"` with the paths to your actual files. Also, ensure that the `"skybox_images/"` folder contains the required skybox images.

This script assumes that you have a truck model with a fixed base and that the tire model is attached to the truck's wheel link. The script also uses keyboard input for steering, throttle, and brake control. You can modify the script to suit your specific needs.
