Here's a Python script using PyChrono to simulate a UAZBUS vehicle on a rigid terrain with real-time visualization using Irrlicht. Make sure you have PyChrono and its dependencies installed (`pip install PyChrono`).

```python
import pychrono as pc
import numpy as np

# 1. Initialize the PyChrono environment and core components
pc.set_log_level(pc.LogLevel.INFO)
sim = pc.Simulation()
scene = pc.Scene()
irlicht = pc.IrlichtScene()
sim.set_scene(scene)
sim.set_irlicht(irlicht)

# 2. Add the required physical systems and objects
# Rigid terrain
terrain = pc.RigidBody()
terrain.set_material(pc.Material(0.9, 0.0, 0.0))  # friction, restitution
terrain.set_shape(pc.BoxShape(100, 100, 1))
terrain.set_position([0, 0, -1])
scene.add(terrain)

# UAZBUS vehicle
vehicle = pc.UAZBUS()
vehicle.set_position([0, 0, 1])
vehicle.set_velocity([0, 0, 0])
scene.add(vehicle)

# Driver system
driver = pc.Driver(vehicle)
driver.set_throttle(0.5)
driver.set_steering(0.0)

# 3. Set necessary default parameters
# Camera settings
camera = pc.Camera()
camera.set_position([10, 10, 5])
camera.set_lookat([0, 0, 1])
irlicht.add_camera(camera)

# Lighting
light = pc.Light()
light.set_position([10, 10, 10])
light.set_ambient([1, 1, 1])
light.set_diffuse([1, 1, 1])
irlicht.add_light(light)

# Simulation loop
while not sim.is_finished():
    # Synchronize and advance the vehicle, terrain, driver, and visual system
    sim.synchronize()
    driver.actuate()
    sim.advance()

    # Real-time visualization
    irlicht.render()
    irlicht.render_once()
```

This script initializes a PyChrono simulation with a UAZBUS vehicle on a rigid terrain. It sets up a driver system to control the vehicle and creates a real-time visualization using Irrlicht with specified camera settings and lighting. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.
