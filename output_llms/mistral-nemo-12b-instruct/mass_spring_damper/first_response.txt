Here's a PyChrono script that follows your instructions:

```python
import pychrono as pc
import pychrono.irrlicht as pl

# Initialize PyChrono environment
pc.SetChronoDataPath("../../../../ChronoData")
pc.Initialize()

# Create a new system and add it to the scene manager
mysystem = pc.ChSystemSMC()
myscene = pl.ChIrrApp(mysystem, "PyChrono Single Mass-Spring-Damper", pl.PL irrlicht.COGL_RENDERER, 800, 600)
myscene.AddSystem(mysystem)

# Create a fixed ground
ground = pc.ChBodyEasyBox(10, 10, 0.1, 1000, True)
ground.SetPos(pc.ChVectorD(0, 0, -0.05))
mysystem.Add(ground)

# Create a mass with a visual shape
mass = pc.ChBody()
mass.SetMass(1)
mass.SetPos(pc.ChVectorD(0, 0, 0.5))
mass.SetBodyFixed(False)
vis_mass = pl.ChVisualShapeBox(mass, pc.ChVectorD(0.1, 0.1, 0.1), pc.ChColor(0.8, 0.8, 0.8))
mysystem.Add(mass)

# Create a spring-damper connection with default parameters
link = pc.ChLinkTSDA()
link.Initialize(mass, ground, pc.ChVectorD(0, 0, 0.5), pc.ChVectorD(0, 0, 0), pc.ChVectorD(0, 0, 1))
mysystem.Add(link)

# Set up Irrlicht visualization
myscene.SetCamera(pc.Camera(pc.ChVectorD(1.5, 1.5, 1.5), pc.ChVectorD(0, 0, 0)))
myscene.AddLight(pc.DirLight(), pc.ChVectorD(1, 1, 1), pc.ChVectorD(0, 0, -1))
myscene.SetLightDir(pc.ChVectorD(0, 0, -1))

# Simulation loop
while myscene.GetDevice().run():
    mysystem.DoStepDynamics(0.01)
    myscene.DoStep()

# Clean up and finalize PyChrono
myscene.AssetManager().RemoveAll()
pc.Finalize()
```

This script initializes the PyChrono environment and creates a single mass-spring-damper system using `ChLinkTSDA`. It adds a fixed ground and a mass with a visual shape to the scene. The spring-damper connection uses default linear parameters. The script also sets up Irrlicht visualization with appropriate lighting and camera settings.
