Here's a Python script using PyChrono to create the described simulation. Make sure you have PyChrono and Irrlicht installed before running this script.

```python
import pychrono as pc
import numpy as np

# Initialize PyChrono environment and core components
pc.setChronoOpenglRenderMode(1)  # Use Irrlicht for visualization
sim = pc.ChSimulation()
sim.SetTimestep(0.005)  # Set simulation timestep to 200 Hz

# Create and add RigidTerrain
terrain = pc.ChTerrain()
terrain.SetTexture(pc.ChTexture("terrain.png"))  # Add custom texture
terrain.SetDimensions(100, 100, 1)  # Set terrain dimensions (x, y, z)
sim.Add(terrain)

# Create and initialize ARTcar vehicle
vehicle = pc.ChArtCar()
vehicle.SetChassisBodyPos(pc.Vec3(0, 0, 0.5))  # Set initial location
vehicle.SetChassisBodyRot(pc.Q_from_AngAxis(np.radians(0), pc.Vec3(0, 0, 1)))  # Set initial orientation
vehicle.SetContactMethod(pc.CONTACT_METHOD_SMC)  # Set contact method
vehicle.SetVisualizationType(pc.VISUALIZATION_TYPE_MESH)  # Set visualization type
sim.Add(vehicle)

# Create and add interactive driver system
driver = pc.ChArtCarDriver()
driver.SetVehicle(vehicle)
driver.SetSteering(0)  # Initial steering (0 - no steering)
driver.SetThrottle(0)  # Initial throttle (0 - no throttle)
driver.SetBrake(0)  # Initial brake (0 - no brake)
sim.Add(driver)

# Simulation loop
while True:
    sim.DoStep()

    # Update driver inputs based on user input or AI (not implemented here)
    driver.SetSteering(np.sin(sim.GetTime()))  # Example: Steering oscillates between -1 and 1
    driver.SetThrottle(0.5)  # Example: Constant throttle of 0.5
    driver.SetBrake(0)  # Example: No braking

    # Display the simulation at 50 frames per second
    if sim.GetTime() % (1 / 50) < 0.005:
        sim.ResetContactCache()
        sim.GetIrrlichtDevice().run()
```

Before running the script, make sure to have a texture file named `terrain.png` in the same directory as your script. Also, note that the driver system's inputs are set to example values. You should replace these with actual user input or AI-based control logic.

This script creates a simple ARTcar vehicle on a rigid terrain with a custom texture. The vehicle is controlled by an interactive driver system that sets the steering, throttle, and brake based on example inputs. The simulation runs at 200 Hz and displays the results at 50 frames per second using Irrlicht for visualization.
