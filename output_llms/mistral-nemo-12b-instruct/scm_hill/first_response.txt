Here's a Python script using PyChrono to simulate an HMMWV vehicle on a deformable terrain with real-time visualization using Irrlicht. Make sure you have PyChrono and its dependencies installed.

```python
import pychrono as pc
import numpy as np

# Initialize PyChrono environment
pc.init()

# Create simulation and scene
sim = pc.Simulation()
scene = sim.getScene()

# Add HMMWV vehicle
hmmwv = scene.add(pc.vehicle.HMMWV())
hmmwv.setPosition([0, 0, 0.5])
hmmwv.setVelocity([0, 0, 0])

# Add SCM deformable terrain
terrain = scene.add(pc.terrain.SCM())
terrain.setSoilParameters(1.5e6, 0.3, 0.2, 0.5, 10000)
terrain.setHeightMap(pc.loadHeightMap("path/to/heightmap.png"))
terrain.setSize(100, 100)
terrain.setPosition([0, 0, -1])

# Add driver system for vehicle control
driver = scene.add(pc.vehicle.Driver(hmmwv))
driver.setTargetSpeed(10)

# Add real-time visualization using Irrlicht
vis = pc.irrlicht.RealTimeIrrlicht()
vis.setCameraPosition([5, 5, 5])
vis.setCameraLookAt([0, 0, 0])
vis.setLightDirection([-1, -1, -1])
vis.addScene(scene)

# Simulation loop
while not pc.isSimulationFinished():
    # Synchronize and advance the vehicle, terrain, driver, and visual system
    sim.advance(0.01)

    # Update visualization
    vis.update()

# Clean up and exit PyChrono
pc.exit()
```

Make sure to replace `"path/to/heightmap.png"` with the actual path to your heightmap image.

This script initializes the PyChrono environment, adds an HMMWV vehicle and an SCM deformable terrain with specified soil parameters, initializes a driver system for vehicle control, and creates a real-time visualization using Irrlicht with camera settings and lighting. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.
