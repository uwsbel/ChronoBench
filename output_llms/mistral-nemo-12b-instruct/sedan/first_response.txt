Here's a Python script using PyChrono to create the simulation as described in the instructions. I've made some assumptions about the parameters and models used, as specific details were not provided. You might need to adjust these values to match your needs.

```python
import chrono
from chrono import *
from chrono.irrlicht import *
from chrono.tire import *

# Initialize PyChrono and create the simulation system
my_system = chrono.ChSystemNSC()
my_system.Set_Gravity(chrono.ChVectorD(0, -9.81, 0))

# Create a terrain surface with customizable textures and logos
terrain = chrono.ChTerrain()
terrain.SetTexture(chrono.GetChronoDataPath() + "textures/grass.png")
terrain.SetLogoTexture(chrono.GetChronoDataPath() + "textures/bmw_logo.png")
terrain.SetLogoSize(10)
terrain.SetLogoSpacing(50)
terrain.SetHeightmap(chrono.GetChronoDataPath() + "heightmaps/heightmap.png")
my_system.Add(terrain)

# Create a BMW E90 Sedan vehicle with configurable visualization and collision settings
vehicle = chrono.ChBodyEasyTerrain(terrain, chrono.ChVectorD(0, 1, 0), chrono.ChVectorD(0.5, 0.5, 0.5), "car.dae")
vehicle.SetCollide(True)
vehicle.SetCollideId(1)
my_system.Add(vehicle)

# Add TMEASY tire model to the vehicle
tire = TireMeasy(chrono.ChVectorD(0, -0.5, 0.5), chrono.ChVectorD(0, 1, 0), chrono.ChVectorD(0, 0, 1), 0.3, 0.5, 0.2, 0.01, 0.001, 0.001, 0.001, 0.001, 0.001)
vehicle.Add(tire)

# Create an interactive driver system for real-time control of steering, throttle, and braking
driver = chrono.ChDriver()
driver.SetSteering(0)
driver.SetThrottle(0)
driver.SetBrake(0)
vehicle.Add(driver)

# Set up Irrlicht visualization with a chase camera, directional lighting, and a skybox
my_app = IrrlichtApplication(my_system, chrono.ChVectorD(0, 1.5, -5), chrono.ChVectorD(0, 0, 0))
my_app.SetSkyBox("skybox/blue_skybox.dds")
my_app.AddLight(chrono.ChVectorD(0, 5, 0), chrono.ChColor(1, 1, 1))

# Run the simulation
while my_app.GetDevice().run():
    my_system.DoStepDynamics(0.01)
    my_app.DoStep()
```

This script initializes a PyChrono simulation with a BMW E90 Sedan vehicle driving on a terrain surface. The vehicle is equipped with a TMEASY tire model and an interactive driver system for real-time control. The simulation is visualized using the Irrlicht system with a chase camera, directional lighting, and a skybox. The terrain surface has customizable textures and logos.

To use this script, make sure you have the necessary files (e.g., `car.dae`, `grass.png`, `bmw_logo.png`, `heightmap.png`, and the skybox textures) in the specified paths. You can adjust the parameters and models as needed to match your specific requirements.
