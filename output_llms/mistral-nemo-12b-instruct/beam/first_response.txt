Here's a PyChrono script that follows your instructions. This script creates a simple physical system with a beam finite element, adds visualization, and runs a simulation loop using the Irrlicht engine.

```python
import chrono
from chrono import *
import chrono.irrlicht as chronoirr

# Initialize PyChrono
physics = chrono.Physics()
my_system = chrono.System(physics)

# Create a beam finite element with specific properties
beam = chrono.ChBeam()
beam.SetName("beam")
beam.SetLength(1)
beam.SetSection(chrono.ChBeamSection(0.1, 0.01))  # radius, thickness
beam.SetMaterial(chrono.ChMaterialSurfaceNSC())
beam.SetYieldLimit(1e6)  # yield stress in Pa

# Create nodes for the beam
nodeA = chrono.ChNodeFEA3D()
nodeB = chrono.ChNodeFEA3D()
nodeA.SetPos(chrono.ChVectorD(0, 0, 0))
nodeB.SetPos(chrono.ChVectorD(1, 0, 0))

# Connect nodes with the beam
beam.Connect(nodeA, nodeB)

# Add beam and nodes to the system
my_system.Add(beam)
my_system.Add(nodeA)
my_system.Add(nodeB)

# Create a fixed joint to constrain the first node
fixed_joint = chrono.ChLinkLock()
fixed_joint.Connect(nodeA, None, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 0))
my_system.Add(fixed_joint)

# Set up Irrlicht visualization
app = chronoirr.ChIrrApp(my_system, chronoirr.CH_HARDWARE_OPENGL)
app.SetWindowSize(800, 600)
app.SetWindowTitle("PyChrono Beam Simulation")
app.AddLight(chrono.ChVectorD(2, 2, 2), chrono.ChColor(1, 1, 1), 1000)

# Run the simulation loop
while app.GetDevice().run():
    app.BeginScene(True, True, chronoirr.SColor(255, 130, 110, 100))
    app.DrawAll()
    app.EndScene()
    app.GetDevice().sleep(0.01)
```

This script creates a simple beam of length 1 meter with a circular cross-section (radius 0.1 meters, thickness 0.01 meters). The beam is connected to two nodes, and the first node is fixed in place. The Irrlicht engine is used for real-time rendering, and the simulation loop runs at approximately 100 Hz.
