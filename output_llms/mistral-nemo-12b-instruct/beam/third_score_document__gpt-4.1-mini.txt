- **Beam Section Rotation:**  
  The line:  
  ```python
  msection.SetSectionRotation(45 * chrono.CH_RAD_TO_DEG)
  ```  
  The constant `chrono.CH_RAD_TO_DEG` converts radians to degrees (≈57.2958). Multiplying 45 by this constant results in ~2578 degrees, which is nonsensical. The API expects the rotation in radians, so either the angle should be in radians or the constant should be `chrono.CH_DEG_TO_RAD` (degrees to radians).
