Here's a complete PyChrono simulation script following your specifications. The script creates a Gator vehicle on textured terrain with interactive controls and real-time visualization:

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr
import os

# Set paths to data files
chrono.SetChronoDataPath("path/to/chrono/data/")  # Update to your Chrono data path
veh.SetDataPath("path/to/vehicle/data/")          # Update to your vehicle data path

# 1. Initialize system and contact method
system = chrono.ChSystemNSC()
system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
system.SetSolverMaxIterations(150)
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# 2. Create Gator vehicle
gator = veh.Gator(system)
gator.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0.5), chrono.QUNIT))
gator.SetTireType(veh.TireModelType_TMEASY)
gator.Initialize()

# Set vehicle visualization
gator.SetChassisVisualizationType(veh.VisualizationType_MESH)
gator.SetSuspensionVisualizationType(veh.VisualizationType_MESH)
gator.SetSteeringVisualizationType(veh.VisualizationType_MESH)
gator.SetWheelVisualizationType(veh.VisualizationType_MESH)

# 3. Create rigid terrain
terrain = veh.RigidTerrain(system)
patch_mat = chrono.ChMaterialSurfaceNSC()
patch_mat.SetFriction(0.9)
patch_mat.SetRestitution(0.01)
patch = terrain.AddPatch(patch_mat, chrono.CH_C_SYSTEM, 100, 100)
patch.SetTexture(veh.GetDataFile("terrain/textures/tile4.jpg"), 100, 100)
terrain.Initialize()

# 4. Create Irrlicht visualization
vis = irr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle('Gator Vehicle Simulation')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(6, 6, 1.5), chrono.ChVectorD(0, 0, 0.5))
vis.AddTypicalLights()

# 5. Create interactive driver
driver = veh.ChInteractiveDriverIRR(vis)
steering_controller = veh.ChSteeringControllerSine(0.5, 0.4, 1.0)
driver.SetSteeringController(steering_controller)
driver.Initialize()

# 6. Simulation loop
step_size = 0.005
render_step = 1.0 / 50  # 50 FPS
time = 0
frame = 0

while vis.Run():
    time = system.GetChTime()
    
    # Update vehicle systems
    driver.Synchronize(time)
    gator.Synchronize(time, driver.GetInputs(), terrain)
    terrain.Synchronize(time)
    
    # Advance simulation
    driver.Advance(step_size)
    gator.Advance(step_size)
    terrain.Advance(step_size)
    system.DoStepDynamics(step_size)
    
    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    
    # Maintain real-time rendering
    frame += 1
    if time > frame * render_step:
        vis.GetDevice().sleep(int((time - frame * render_step) * 1000))
```

**Key Components Explained:**

1. **Vehicle Setup:**
   - Uses the Gator vehicle model with TMEASY tires
   - Initializes at position (0,0,0.5) with no rotation
   - All components visualized as meshes

2. **Terrain:**
   - 100x100 meter rigid terrain with high friction
   - Textured with repeating tile pattern
   - Customizable friction and restitution properties

3. **Driver Controls:**
   - WASD keys: Steering and throttle control
   - Space: Emergency braking
   - Mouse: Camera control
   - Sine-wave steering pattern for demonstration

4. **Simulation Parameters:**
   - 5ms physics timestep for accuracy
   - Real-time rendering at 50 FPS
   - Barzilai-Borwein solver for efficient contact resolution

**Usage Instructions:**
1. Replace `"path/to/chrono/data/"` and `"path/to/vehicle/data/"` with actual paths
2. Install required dependencies: `pip install pychrono`
3. Run with Python 3.7+ (requires Chrono::Vehicle module)
4. Controls:
   - W/S: Accelerate/Brake
   - A/D: Steer left/right
   - Mouse: Rotate camera
   - Right-click: Zoom

**Customization Options:**
- Adjust `SetInitPosition()` for different starting positions
- Modify `patch_mat` properties for different terrain physics
- Change texture path in `SetTexture()` for custom terrain appearance
- Adjust camera position in `AddCamera()` for different views

The simulation maintains real-time performance by dynamically adjusting sleep times between frames while preserving physics accuracy through fixed timestepping. The vehicle responds realistically to terrain interactions and driver inputs.
