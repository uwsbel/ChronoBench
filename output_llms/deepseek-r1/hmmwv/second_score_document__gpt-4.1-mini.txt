### 2. Correctness (30 points)

- **Incorrect use of PyChrono API:**

- **Logical errors:**

  - The `ChBezierCurve` is created with these points, which is correct.
  - The PID controller gains are set with `SetGains(0.5, 0.0, 0.1)`, which is plausible.

  - The `vehicle.GetSystem().SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)` is called after vehicle initialization. According to best practices, collision system type should be set before initialization.
  - **Deduction: 10 points** (logical error: collision system type set too late).
