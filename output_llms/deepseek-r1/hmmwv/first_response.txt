Here's a complete PyChrono simulation script following your specifications. The script creates an HMMWV vehicle on rigid terrain with interactive controls and real-time visualization:

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr

# 1. Initialize PyChrono environment
chrono.SetChronoDataPath("path/to/chrono/data/")  # Set your Chrono data directory
system = chrono.ChSystemSMC()
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))
system.SetSolverMaxIterations(150)

# 2. Create terrain
terrain = veh.RigidTerrain(system)
patch_mat = chrono.ChMaterialSurfaceSMC()
patch = terrain.AddPatch(patch_mat, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1), 100, 100)
patch.SetTexture(veh.GetDataFile("terrain/textures/tile4.jpg"), 200, 200)
terrain.Initialize()

# 3. Create and initialize HMMWV vehicle
vehicle = veh.HMMWV_Full(system)
vehicle.SetContactMethod(chrono.ChContactMethod_SMC)
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 1.0), chrono.QUNIT))
vehicle.SetTireType(veh.TireModelType_TMEASY)
vehicle.SetTireStepSize(0.001)
vehicle.Initialize()

# Set visualization modes
vehicle.SetChassisVisualizationType(veh.VisualizationType_PRIMITIVES)
vehicle.SetSuspensionVisualizationType(veh.VisualizationType_PRIMITIVES)
vehicle.SetSteeringVisualizationType(veh.VisualizationType_PRIMITIVES)
vehicle.SetWheelVisualizationType(veh.VisualizationType_PRIMITIVES)
vehicle.SetTireVisualizationType(veh.VisualizationType_PRIMITIVES)

# 4. Create Irrlicht visualization
vis = irr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle('HMMWV Simulation')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(6, 3, 1.5), chrono.ChVectorD(0, 0, 1))
vis.AddTypicalLights()

# 5. Create interactive driver
driver = veh.ChIrrGuiDriver(vis)
steering_time = 1.0  # Time to turn from lock to lock (seconds)
driver.SetSteeringDelta(0.02 / steering_time)
driver.SetThrottleDelta(0.02)
driver.SetBrakingDelta(0.06)
driver.Initialize()

# 6. Configure real-time simulation
step_size = 0.002
render_step = 1.0 / 50  # 50 FPS
realtime_timer = chrono.ChRealtimeStepTimer()
frame_number = 0

# Main simulation loop
while vis.Run():
    time = system.GetChTime()
    
    # Render scene
    if frame_number % int(render_step / step_size) == 0:
        vis.BeginScene()
        vis.Render()
        vis.EndScene()
    
    # Get driver inputs
    driver_inputs = driver.GetInputs()
    vehicle.GetDriverInputs() = driver_inputs
    
    # Update modules
    driver.Synchronize(time)
    terrain.Synchronize(time)
    vehicle.Synchronize(time, driver_inputs, terrain)
    vis.Synchronize(time, driver_inputs)
    
    # Advance simulation
    vehicle.Advance(step_size)
    terrain.Advance(step_size)
    vis.Advance(step_size)
    
    # Step system
    system.DoStepDynamics(step_size)
    
    # Real-time synchronization
    realtime_timer.Spin(step_size)
    frame_number += 1
```

Key features of this simulation:
1. **Vehicle Setup**:
   - Full HMMWV model with TMEASY tires
   - Primitive visualization for all components
   - Initial position at (0,0,1) with default orientation
   - SMC contact method

2. **Terrain**:
   - 100x100 meter rigid terrain
   - Textured surface with tile pattern
   - Defined with SMC material properties

3. **Interactive Controls**:
   - Arrow keys for steering, acceleration, and braking
   - Mouse-controlled camera
   - Real-time parameter adjustments

4. **Simulation Parameters**:
   - 50 FPS visualization update rate
   - 2ms physics time step
   - Real-time synchronization
   - Gravity set to -9.81 m/s² in Z-direction

5. **Visualization**:
   - Skybox and lighting effects
   - Multiple camera angles
   - Chrono logo overlay
   - Dynamic vehicle and terrain rendering

To run this simulation:
1. Replace `"path/to/chrono/data/"` with your actual Chrono data directory path
2. Install required dependencies (PyChrono, Irrlicht)
3. Ensure you have the Chrono::Vehicle module compiled with TMEASY tire support

The driver controls are:
- **Arrow Up/Down**: Accelerate/Brake
- **Arrow Left/Right**: Steer
- **Mouse**: Control camera view
- **GUI Controls**: Real-time parameter adjustments appear automatically

The simulation maintains real-time synchronization with physics calculations running at 500Hz while rendering updates at 50Hz for smooth visualization.
