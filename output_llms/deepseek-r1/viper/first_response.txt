Here's a complete PyChrono simulation script following your instructions. The script creates a Viper rover on rigid terrain with time-varying steering control:

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr

def main():
    # 1. Initialize Chrono system and environment
    chrono.SetChronoDataPath(chrono.GetChronoDataPath())
    system = chrono.ChSystemNSC()
    system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))
    
    # 2. Create rigid terrain
    terrain = veh.RigidTerrain(system)
    patch_mat = chrono.ChMaterialSurfaceNSC()
    patch_mat.SetFriction(0.9)
    patch_mat.SetRestitution(0.01)
    terrain.Initialize(chrono.ChVectorD(0, 0, 0), patch_mat)
    
    # 3. Initialize Viper rover
    rover = veh.Viper(system)
    rover.SetDriverPos(chrono.ChVectorD(0, 0, 0.5))
    rover.Initialize(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0.5), chrono.QUNIT))
    
    # 4. Set up driver and steering parameters
    driver = veh.ViperDCMotorControl()
    rover.SetDriver(driver)
    
    # Steering parameters
    max_steering = 0.3  # radians
    steering_start_time = 1.0
    steering_end_time = 5.0
    
    # 5. Create Irrlicht visualization
    vis = irr.ChVisualSystemIrrlicht()
    vis.AttachSystem(system)
    vis.SetWindowSize(1280, 720)
    vis.SetWindowTitle('Viper Rover Simulation')
    vis.Initialize()
    vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
    vis.AddSkyBox()
    vis.AddCamera(chrono.ChVectorD(2, 2, 1), chrono.ChVectorD(0, 0, 0.5))
    vis.AddTypicalLights()
    vis.AddLightWithShadow(chrono.ChVectorD(2,3,5), chrono.ChVectorD(0,0,0.5), 10, 2, 10, 40, 512)
    
    # 6. Simulation loop
    step_size = 0.005
    time = 0.0
    steering_val = 0.0
    
    while vis.Run():
        time = system.GetChTime()
        
        # Update steering gradually
        if time > steering_start_time and time < steering_end_time:
            t = (time - steering_start_time) / (steering_end_time - steering_start_time)
            steering_val = max_steering * t
        elif time >= steering_end_time:
            steering_val = max_steering
            
        # Apply steering and driving commands
        driver.SetSteering(steering_val)
        driver.SetDriveSpeed(0.5)  # Constant forward speed
        
        # Update systems
        rover.Update()
        vis.BeginScene()
        vis.Render()
        vis.EndScene()
        system.DoStepDynamics(step_size)
        
    return 0

if __name__ == '__main__':
    main()
```

Key features of this simulation:

1. **Environment Setup**:
   - Creates a physical system with Earth gravity (-9.81 m/s² in Z-direction)
   - Adds a rigid terrain with realistic friction properties

2. **Viper Rover**:
   - Initializes the rover at position (0,0,0.5) above ground
   - Uses DC motor control driver model
   - Sets driver position at rover center

3. **Steering Control**:
   - Linearly increases steering angle from 0 to 0.3 radians (≈17°) between 1-5 seconds
   - Maintains constant forward speed (0.5 m/s)

4. **Visualization**:
   - Irrlicht real-time rendering with 1280x720 resolution
   - Camera positioned at (2,2,1) pointing at rover
   - Skybox, logo, and multiple light sources with shadows
   - Frame rate locked to physics timestep (5ms)

To run this script, you'll need:
- PyChrono installed (version 7.0.0 or newer)
- Chrono data files (automatically handled if installed via conda)
- Viper rover assets included with Chrono

The rover will start moving forward at t=0, then gradually turn its wheels over 4 seconds (1-5s simulation time) while maintaining forward motion. You can modify the `max_steering`, speed, and timing parameters to create different maneuver profiles.
