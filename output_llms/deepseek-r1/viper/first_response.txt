
Here's a PyChrono simulation script that meets your requirements. The script initializes a Viper rover on rigid terrain with gravity, implements a driver with time-varying steering, and sets up real-time visualization:

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr

# 1. Initialize Chrono system with gravity
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# 2. Create rigid terrain
terrain = veh.RigidTerrain(system)
patch_mat = chrono.ChMaterialSurfaceNSC()
patch = terrain.AddPatch(patch_mat, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1), 100, 100)
patch.SetTexture(veh.GetDataFile("terrain/textures/tile4.jpg"), 200, 200)
terrain.Initialize()

# 3. Initialize Viper rover
viper = veh.Viper(system)
viper.SetDriverPos(chrono.ChVectorD(0, 0, 1))
viper.Initialize(chrono.ChCoordsysD(chrono.ChVectorD(0, -0.2, 0.5), chrono.QUNIT))

# 4. Create and initialize driver
driver = veh.ViperDCMotorControl()
driver.SetGains(0.4, 0, 0)
viper.SetDriver(driver)

# 5. Setup Irrlicht visualization
vis = irr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle("Viper Rover Simulation")
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(3, 3, 1), chrono.ChVectorD(0, 0, 0.5))
vis.AddTypicalLights()
vis.AddLightWithShadow(chrono.ChVectorD(5, 0, 5), chrono.ChVectorD(0, 0, 0.5), 10, 2, 10, 40, 512)

# 6. Simulation parameters
step_size = 0.005
t_end = 30
t_steer_start = 5
t_steer_end = 25
steering_max = 0.4  # radians (~23 degrees)
current_time = 0

# 7. Main simulation loop
while vis.Run() and current_time < t_end:
    # Update steering based on time
    if t_steer_start <= current_time <= t_steer_end:
        t_normalized = (current_time - t_steer_start) / (t_steer_end - t_steer_start)
        steering = steering_max * chrono.ChSineStep(t_normalized, 0.5)  # Smooth ramp
        driver.SetSteering(steering)
    
    # Update systems
    viper.Update()
    terrain.Update()
    
    # Advance simulation
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    system.DoStepDynamics(step_size)
    current_time += step_size
```

Key features of this implementation:
1. **Physics Setup**:
   - NSC (Non-Smooth Contacts) system with Earth gravity
   - Rigid terrain with textured surface
   - Proper material properties for rover-terrain interaction

2. **Viper Rover**:
   - Correct initialization with DC motor controller
   - Positioned slightly above terrain to prevent penetration
   - Realistic mass and inertia properties (handled internally)

3. **Steering Control**:
   - Smooth steering ramp using `ChSineStep` function
   - Steering gradually increases from 0 to max (0.4 rad) over 20 seconds
   - Steering held at maximum after reaching peak

4. **Visualization**:
   - Optimized camera position focusing on rover
   - Shadow casting and directional lighting
   - Skybox and Chrono logo
   - Real-time rendering at 200 Hz physics steps

5. **Simulation Parameters**:
   - 30-second simulation duration
   - 5-second initialization period before steering starts
   - Physically realistic time step (5ms)

To run this script:
1. Ensure PyChrono and its vehicle module are installed
2. Make sure the Chrono data files are accessible
3. The rover will start stationary and gradually turn its wheels
4. Steering reaches maximum at 15 seconds and holds until 25 seconds

The steering profile follows a smooth S-curve using Chrono's built-in `ChSineStep` function for physically realistic transitions. You can adjust `steering_max`, time parameters, or camera positions as needed for your specific application.
