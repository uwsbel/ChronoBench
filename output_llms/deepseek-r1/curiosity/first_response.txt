Here's a PyChrono simulation script that models a Curiosity rover navigating on rigid terrain with real-time motor control and advanced visualization features:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import os
import math

# =============================================================================
# Main Simulation Setup
# =============================================================================

# Create Chrono system
system = chrono.ChSystemNSC()
system.SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Earth gravity

# =============================================================================
# Terrain Creation
# =============================================================================

# Create rigid ground plane
ground_mat = chrono.ChMaterialSurfaceNSC()
ground_mat.SetFriction(0.8)
ground_mat.SetRestitution(0.1)

ground = chrono.ChBodyEasyBox(50, 1, 50, 1000, True, True, ground_mat)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
ground.SetBodyFixed(True)
ground.GetVisualShape(0).SetTexture(chrono.GetChronoDataFile("textures/concrete.jpg"))
system.Add(ground)

# Add obstacles for navigation
for i in range(5):
    obstacle = chrono.ChBodyEasyBox(1, 0.2, 1, 2000, True, True, ground_mat)
    obstacle.SetPos(chrono.ChVectorD(i*2 - 4, 0, i - 2))
    obstacle.GetVisualShape(0).SetColor(chrono.ChColor(0.8, 0.3, 0.3))
    system.Add(obstacle)

# =============================================================================
# Rover Initialization
# =============================================================================

# Create Curiosity rover (using simplified vehicle model)
rover = veh.Curiosity()
rover.SetDriver(veh.CuriosityDriver())
rover.Initialize(
    chrono.ChCoordsysD(chrono.ChVectorD(0, 1.0, 0), chrono.QUNIT),
    chrono.ChVectorD(0, 0, 0)
)
rover.SetChassisVisualizationType(veh.VisualizationType_PRIMITIVES)
rover.SetWheelVisualizationType(veh.VisualizationType_MESH)
system.Add(rover.GetChassis())

# Add wheel motors with speed control
for wheel in rover.GetWheels():
    motor = chrono.ChLinkMotorRotationSpeed()
    motor.Initialize(rover.GetChassisBody(), wheel.GetBody(),
                    chrono.ChFrameD(wheel.GetPos()))
    motor.SetSpeedFunction(chrono.ChFunction_Const(0))
    system.Add(motor)

# =============================================================================
# Visualization Setup
# =============================================================================

# Create Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle('Curiosity Rover Simulation')
vis.Initialize()

# Configure camera
camera = chronoirr.ChCamera()
camera.SetPosition(chrono.ChVectorD(5, 2, 5))
camera.SetTarget(chrono.ChVectorD(0, 0.5, 0))
vis.AddCamera(camera)

# Lighting and effects
vis.AddLight(chrono.ChVectorD(10, 20, 10), 1000)
vis.AddLight(chrono.ChVectorD(-10, 20, -10), 500)
vis.EnableShadows(True)
vis.EnableContactDrawing(chronoirr.ContactsDrawMode_CONTACT_DISTANCES)

# Add coordinate system indicator
vis.EnableGrid(True)
vis.AddLogo(chrono.GetChronoDataFile("logo_pychrono_alpha.png"))

# =============================================================================
# Simulation Loop
# =============================================================================

# Driver parameters
steering = 0
throttle = 0
speed = 2.0  # m/s

while vis.Run():
    # Process controls
    if vis.GetKey(chronoirr.KEY_KEY_A):
        steering = min(steering + 0.02, 1.0)
    if vis.GetKey(chronoirr.KEY_KEY_D):
        steering = max(steering - 0.02, -1.0)
    if vis.GetKey(chronoirr.KEY_KEY_W):
        throttle = min(throttle + 0.02, 1.0)
    if vis.GetKey(chronoirr.KEY_KEY_S):
        throttle = max(throttle - 0.02, -1.0)
    
    # Apply controls to rover
    rover.GetDriver().SetSteering(steering)
    rover.GetDriver().SetThrottle(throttle)
    rover.GetDriver().Advance(vis.GetStep())
    
    # Update wheel motors
    for i, motor in enumerate(rover.GetWheels()):
        wheel_speed = throttle * speed * (1 - 0.2 * abs(steering))
        if i in [0, 1]:  # Front wheels
            wheel_speed *= (1.0 + steering)
        motor.SetMotorSpeed(wheel_speed)
    
    # Simulation step
    vis.BeginScene()
    vis.Render()
    vis.RenderFrame(rover.GetChassisBody().GetFrame_REF_to_abs(), 1.0)
    vis.EndScene()
    system.DoStepDynamics(1e-3)
```

This script features:

1. **Realistic Terrain**:
   - Textured rigid ground with concrete appearance
   - Obstacles for rover navigation challenges
   - Configurable friction properties

2. **Curiosity Rover Model**:
   - Physics-based vehicle model with chassis and wheels
   - Wheel motors with independent speed control
   - Simplified visual representation with collision

3. **Advanced Visualization**:
   - Customizable camera position and tracking
   - Dynamic lighting with multiple light sources
   - Real-time shadows and contact visualization
   - Grid reference and PyChrono logo
   - Coordinate system indicators

4. **Interactive Controls**:
   - WASD keys for real-time steering and throttle control
   - Differential wheel speed control for turning
   - Visual feedback of control inputs

5. **Physics Configuration**:
   - Gravity setup for Mars/Earth simulation
   - Collision detection with Bullet engine
   - Proper friction and restitution properties

To operate the rover:
- **W/S**: Accelerate forward/backward
- **A/D**: Steer left/right
- Observe how wheel speeds adjust during turns
- Camera follows rover movement automatically

The simulation includes textured terrain, dynamic lighting that casts shadows, and visual indicators showing contact points and forces. The rover responds physically to terrain irregularities and obstacles while maintaining realistic movement characteristics.
