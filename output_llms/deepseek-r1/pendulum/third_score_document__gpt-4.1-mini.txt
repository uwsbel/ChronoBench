### 2. Correctness (30 points)

- **Incorrect API usage:**  
  - `sys.AddBody(pend_1)` and `sys.AddBody(pend_2)` are not part of the documented API. The correct method is `sys.Add(body)`. This could cause runtime errors or the bodies not being added to the system properly.  
  - **Deduct 15 points** for this significant API misuse.

- **Joint Initialization:**  
  - Revolute joints initialized with `chrono.ChFrameD(chrono.ChVector3d(...), chrono.QUNIT)`. The API documentation shows `chrono.ChCoordsysD(position, rotation)` for joint initialization. `ChFrameD` is not documented and likely incorrect.  
  - This could cause the joint frames to be misaligned or the joint to not behave as expected.  
  - **Deduct 10 points** for logical error in joint initialization.

- **Inertia Values:**  
  - The inertia tensor is set as `chrono.ChVector3d(0.2, 1, 1)`. While this is syntactically correct, the values seem arbitrary and not physically consistent with the mass and geometry. This is a minor issue but not critical. No deduction.

- **Use of `chrono.VNULL`:**  
  - `chrono.VNULL` is used in `chrono.ChFrameD(chrono.VNULL, chrono.QuatFromAngleY(chrono.CH_PI_2))`. `VNULL` is not documented in the API. The documented zero vector is `chrono.ChVector3d(0,0,0)`. This may cause an error or unexpected behavior.  
  - **Deduct 5 points** for minor API misuse.

- **Use of `chrono.QUNIT`:**  
  - `chrono.QUNIT` is used for identity quaternion. This is consistent with the API (e.g., `chrono.QUNIT` is used in examples). No deduction.
