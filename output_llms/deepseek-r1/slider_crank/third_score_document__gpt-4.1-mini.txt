The API documentation uses `chrono.ChCoordsysD(...)` for joint initialization frames. `ChFrameD` is not documented and likely incorrect or deprecated. This is a **significant error** because joints may not initialize correctly.

- **Rotation setting:** The crank rotation is set with `mcrank.SetRot(chrono.Q_ROTATE_Y_TO_Z)`. The API documentation does not mention `Q_ROTATE_Y_TO_Z`. This is likely a predefined quaternion constant in PyChrono, so acceptable.

- **Closing visualization device:** The code calls `vis.GetDevice().closeDevice()` after 20 seconds, which is a proper way to close the visualization window.

- **Major API misuse:** `ChBodyEasyCylinder` arguments incorrect → -15 points
