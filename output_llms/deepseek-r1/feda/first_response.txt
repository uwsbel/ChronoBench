Here's a complete PyChrono simulation script following your specifications. The script creates a FEDA vehicle on rigid terrain with interactive controls and Irrlicht visualization:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import os

# Set paths to Chrono data and vehicle data
chrono.SetChronoDataPath("C:/path/to/chrono/data/")  # Update to your path
veh.SetDataPath(chrono.GetChronoDataPath() + "vehicle/")

# Initialize simulation system
system = chrono.ChSystemNSC()
system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
system.SetSolverMaxIterations(150)

# Create the terrain
terrain = veh.RigidTerrain(system)
patch_mat = chrono.ChMaterialSurfaceNSC()
patch = terrain.AddPatch(patch_mat, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1), 100, 100)
patch.SetTexture(veh.GetDataFile("terrain/textures/tile4.jpg"), 200, 200)
terrain.Initialize()

# Create and initialize the FEDA vehicle
feda = veh.FEDA(system)
feda.SetContactMethod(chrono.ChContactMethod_NSC)
feda.SetChassisFixed(False)
feda.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 1), chrono.Q_from_AngZ(0)))
feda.SetTireType(veh.TireModelType_RIGID)
feda.Initialize()

# Set visualization modes
feda.SetChassisVisualizationType(veh.VisualizationType_MESH)
feda.SetSuspensionVisualizationType(veh.VisualizationType_MESH)
feda.SetSteeringVisualizationType(veh.VisualizationType_MESH)
feda.SetWheelVisualizationType(veh.VisualizationType_MESH)
feda.SetTireVisualizationType(veh.VisualizationType_MESH)

# Create Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle('FEDA Vehicle Simulation')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(6, 3, 1.5), chrono.ChVectorD(0, 0, 0.5))
vis.AddTypicalLights()

# Create interactive driver
driver = veh.ChIrrGuiDriver(vis)
steering_time = 1.0  # seconds to steer from lock to lock
driver.SetSteeringDelta(0.02 / steering_time)
driver.SetThrottleDelta(0.02)
driver.SetBrakingDelta(0.06)
feda.GetVehicle().SetChassisDriver(driver)

# Simulation parameters
step_size = 0.002
render_step = 1.0 / 50  # 50 FPS
frame_number = 0

# Main simulation loop
while vis.Run():
    time = system.GetChTime()
    
    # Update driver inputs
    driver_inputs = driver.GetInputs()
    feda.GetVehicle().Synchronize(time, driver_inputs, terrain)
    terrain.Synchronize(time)
    
    # Advance simulation
    driver.Advance(step_size)
    terrain.Advance(step_size)
    feda.Advance(step_size)
    system.DoStepDynamics(step_size)
    
    # Render frame
    if time >= frame_number * render_step:
        vis.BeginScene()
        vis.Render()
        vis.EndScene()
        frame_number += 1

    # Update visualization
    vis.Synchronize(time, driver_inputs)
```

**Key Components Explained:**

1. **Environment Setup:**
   - Uses NSC (Non-Smooth Contacts) solver for better performance
   - Configures data paths for Chrono assets
   - Sets up a 100x100 meter rigid terrain with textured surface

2. **FEDA Vehicle:**
   - Initialized at position (0, 0, 1) with no initial rotation
   - Uses rigid tires for simplified contact
   - All components visualized as meshes

3. **Visualization System:**
   - Irrlicht visualization with 1280x720 resolution
   - Camera positioned at (6, 3, 1.5) facing the vehicle
   - Skybox and logo added for visual context
   - Follows vehicle during motion

4. **Driver Controls:**
   - Interactive steering, throttle, and braking
   - Keyboard controls:
     - Arrow keys: Acceleration/Braking
     - WASD: Steering
     - Space: Emergency stop

5. **Simulation Loop:**
   - Fixed timestep of 2ms for physics accuracy
   - Rendering at 50 FPS (20ms frames)
   - Real-time synchronization between physics and visualization

**Usage Instructions:**
1. Adjust the data path to match your Chrono installation
2. Install required dependencies: `pip install pychrono`
3. Run the script and use:
   - Arrow keys: Acceleration/Braking
   - A/D or Left/Right: Steering
   - W/S: Up/Down gear shifting
   - Space: Emergency brake
   - Mouse: Adjust camera angle
   - Esc: Exit simulation

**Note:** For first-time users, you may need to:
- Download vehicle assets from Chrono's data repository
- Adjust terrain texture path if using custom textures
- Modify camera position for better viewing angles

This simulation provides a realistic vehicle dynamics model with proper suspension, steering, and powertrain characteristics specific to the FEDA military vehicle. The rigid terrain allows for efficient computation while maintaining realistic vehicle-terrain interaction.
