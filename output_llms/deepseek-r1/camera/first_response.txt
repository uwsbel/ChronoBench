
Here's a PyChrono simulation script that meets your requirements. The script loads a mesh from an OBJ file, creates a camera sensor orbiting around it, and displays processed camera images at each timestep:

```python
import pychrono as chrono
import pychrono.sensor as sens
import numpy as np
import os
from matplotlib import pyplot as plt

# Create Chrono system
system = chrono.ChSystemNSC()
system.SetGravity(chrono.ChVector3d(0, 0, 0))

# Load mesh from OBJ file
mesh_path = "path/to/your/mesh.obj"  # UPDATE THIS PATH
mesh = chrono.ChVisualShapeModelFile()
mesh.SetFilename(mesh_path)

# Create fixed mesh body
mesh_body = chrono.ChBody()
mesh_body.SetFixed(True)
mesh_body.AddVisualShape(mesh)
system.Add(mesh_body)

# Create sensor manager
manager = sens.ChSensorManager(system)
manager.scene.AddPointLight(chrono.ChVector3d(2, 2, 2), chrono.ChColor(1, 1, 1), 1000)

# Camera orbit parameters
radius = 5.0     # Orbit radius
height = 1.0     # Camera height
speed = 0.1      # Orbit speed (radians/frame)

# Create camera sensor
offset_pose = chrono.ChFramed(chrono.ChVector3d(radius, 0, height), chrono.Q_ROTATE_Y_TO_Z)
camera = sens.ChCameraSensor(
    mesh_body,          # Parent body
    30,                 # Update rate (Hz)
    offset_pose,        # Offset pose
    1280,               # Image width
    720,                # Image height
    chrono.CH_PI / 3    # Horizontal FOV
)
camera.SetName("Orbiting Camera")
camera.PushFilter(sens.ChFilterRGBA8Access())
camera.PushFilter(sens.ChFilterVisualize(1280, 720, "Camera View"))

# Add Gaussian noise to RGB images
noise_model = sens.ChNoiseNormal(mean=0, stdev=0.02)
camera.PushFilter(sens.ChFilterCameraNoise(noise_model))

manager.AddSensor(camera)

# Simulation loop
time_step = 0.01
total_time = 10.0
time = 0
step = 0

while time < total_time:
    # Update camera orbit position
    angle = speed * step
    cam_pos = chrono.ChVector3d(radius * np.cos(angle), radius * np.sin(angle), height)
    camera.SetOffsetPose(chrono.ChFramed(cam_pos, chrono.Q_ROTATE_Y_TO_Z))

    # Update sensors
    manager.Update()

    # Access and print camera data
    rgba8_data = camera.GetMostRecentRGBA8Buffer()
    if rgba8_data.HasData():
        img_array = rgba8_data.GetRGBA8Data()
        print(f"Step {step}: Camera buffer - Mean: {np.mean(img_array):.2f}, "
              f"Shape: {img_array.shape}, Timestamp: {rgba8_data.Time:.4f}s")

    # Advance simulation
    system.DoStepDynamics(time_step)
    time += time_step
    step += 1
```

**Key features:**
1. Fixed triangular mesh loaded from OBJ file
2. Orbiting camera with dynamic position updates
3. Sensor pipeline with:
   - Gaussian noise filter
   - RGBA8 data access filter
   - Real-time visualization
4. Per-frame data printing showing:
   - Image statistics (mean intensity)
   - Buffer dimensions
   - Timestamp

**Before running:**
1. Replace `"path/to/your/mesh.obj"` with your actual OBJ file path
2. Install required dependencies:
   ```bash
   pip install pychrono numpy matplotlib
   ```

**To modify orbit:**
- Adjust `radius` for orbit size
- Change `height` for vertical position
- Modify `speed` for rotation rate
