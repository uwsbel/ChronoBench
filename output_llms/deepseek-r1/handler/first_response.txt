Here's a PyChrono simulation script integrated with ROS following your specifications:

```python
import pychrono as chrono
import pychrono.ros as chros
import pychrono.irrlicht as irr
import roslibpy

# 1. Initialize PyChrono environment
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravitational acceleration

# 2. Create materials for physical properties
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.5)
material.SetRestitution(0.2)

# 3. Add physical objects
# Create fixed floor
floor = chrono.ChBodyEasyBox(20, 1, 20, 1000, True, True, material)
floor.SetPos(chrono.ChVectorD(0, -0.5, 0))
floor.SetBodyFixed(True)
system.Add(floor)

# Create movable box
box = chrono.ChBodyEasyBox(1, 1, 1, 1000, True, True, material)
box.SetPos(chrono.ChVectorD(0, 1, 0))
system.Add(box)

# 4. Create custom ROS handler
class CustomROSHandler(chros.ChROSHandler):
    def __init__(self, topic_name):
        super().__init__()
        self.topic_name = topic_name
        self.counter = 0
        self.publisher = None

    def Initialize(self, ros_manager):
        self.publisher = roslibpy.Topic(ros_manager.client,
                                      self.topic_name,
                                      'std_msgs/Int32')
        self.publisher.advertise()
        return True

    def Tick(self, time):
        self.publisher.publish(roslibpy.Message({'data': self.counter}))
        self.counter += 1

# 5. Configure ROS manager
ros_manager = chros.ChROSManager(system)
ros_manager.AddHandler(chros.ChROSClockHandler())      # Add clock handler
ros_manager.AddHandler(chros.ChROSBodyHandler())       # Add body handler
ros_manager.AddHandler(chros.ChROSTransformHandler())  # Add transform handler

# Add custom handler
custom_handler = CustomROSHandler('/chrono/counter')
ros_manager.AddHandler(custom_handler)

# Initialize ROS manager
ros_manager.Initialize("chrono_ros_node")

# 6. Set up visualization (optional)
vis = irr.ChIrrApp(system, "PyChrono-ROS Demo", irr.dimension2du(800, 600))
vis.AddTypicalLights()
vis.AddTypicalCamera(irr.vector3df(0, 2, -3))
vis.AssetBindAll()
vis.AssetUpdateAll()

# 7. Simulation loop
time_step = 0.01
realtime_timer = chrono.ChRealtimeStepTimer()

while vis.GetDevice().run():
    vis.BeginScene()
    vis.DrawAll()
    vis.EndScene()
    
    # Advance simulation
    system.DoStepDynamics(time_step)
    
    # Update ROS communication
    ros_manager.Update(system.GetChTime(), time_step)
    
    # Maintain real-time execution
    realtime_timer.Spin(time_step)
```

This script:
1. Creates a Chrono physical system with gravity and material properties
2. Adds a fixed floor and dynamic box using NSC (Non-Smooth Contact) formulation
3. Implements a custom ROS handler to publish integer messages
4. Configures ROS integration with clock, body, and transform handlers
5. Maintains real-time execution using ChRealtimeStepTimer
6. Includes optional Irrlicht visualization

Key features:
- ROS integration handles physics synchronization and transform publishing
- Custom message publishing on '/chrono/counter' topic
- Real-time synchronization for hardware-in-the-loop applications
- Physical parameters can be adjusted through material properties
- Visualization can be removed for headless operation

To use this script:
1. Ensure ROS and chrono_ros are properly installed
2. Run with Python 3.x
3. Use `roscore` in a separate terminal
4. View published topics with `rostopic list`
