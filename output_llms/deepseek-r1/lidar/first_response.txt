```python
            print(f"Lidar Position: {new_pos}")
            print(f"Points captured: {buffer.Width * buffer.Height}")
            
            # Print first 3 points (if available)
            pc = buffer.GetPointCloud()
            if pc:
                for i in range(min(3, len(pc))):
                    print(f"Point {i}: {pc[i]}")

        # Advance simulation
        system.DoStepDynamics(TIME_STEP)
        current_time += TIME_STEP

if __name__ == "__main__":
    main()
```

Key features of this implementation:
1. Creates a fixed triangular mesh body from an OBJ file
2. Implements a lidar sensor with:
   - Gaussian noise model
   - Point cloud visualization
   - Data saving to PCD files
3. Dynamically updates the lidar's position in a circular orbit
4. Prints real-time sensor data including position and point cloud samples

To use this script:
1. Install PyChrono with sensor module support
2. Replace "path/to/mesh.obj" with your actual OBJ file path
3. Adjust parameters (orbit radius, angular speed, lidar specs) as needed
4. Run the script - it will generate PCD files in a "lidar_data" directory

The lidar will orbit around the fixed mesh while collecting and saving depth data. The console will output real-time sensor information including captured point cloud samples.
