```python
        new_body.SetCollide(False)
        return new_body

    # Simulation loop
    while vis.Run():
        vis.BeginScene()
        vis.Render()
        vis.EndScene()

        current_time = my_system.GetChTime()

        # Emit new particles
        if current_time - last_emission_time >= emission_interval:
            new_body = create_particle()
            particles.append(new_body)
            my_system.Add(new_body)
            last_emission_time = current_time

        # Apply gravitational forces between all particles
        for body in particles:
            body.SetForce(chrono.ChVectorD(0, 0, 0))

        for i in range(len(particles)):
            body_i = particles[i]
            for j in range(i + 1, len(particles)):
                body_j = particles[j]
                pos_i = body_i.GetPos()
                pos_j = body_j.GetPos()
                delta = pos_j - pos_i
                r_sq = delta.x**2 + delta.y**2 + delta.z**2
                if r_sq < 1e-6:
                    continue
                r = math.sqrt(r_sq)
                unit_dir = delta / r
                m_i = body_i.GetMass()
                m_j = body_j.GetMass()
                force_magnitude = G * m_i * m_j / r_sq
                force = unit_dir * force_magnitude
                body_i.AddForce(force)
                body_j.AddForce(-force)

        # Step the simulation
        my_system.DoStepDynamics(time_step)

    vis.End()

if __name__ == "__main__":
    main()
```

**Explanation of the code:**

1. **Initialization:**
   - The core simulation system (`ChSystemNSC`) and visualization (`ChVisualSystemIrrlicht`) are initialized.
   - Parameters like gravitational constant `G`, emission interval, and time step are set.

2. **Particle Creation Function (`create_particle`):**
   - Generates particles with random mass, position, velocity, orientation, and shape (sphere, box, or cylinder).
   - Each particle is added to the system and the `particles` list for force calculations.

3. **Simulation Loop:**
   - **Visualization Update:** Renders the scene using Irrlicht.
   - **Particle Emission:** New particles are emitted at regular intervals.
   - **Gravitational Force Calculation:** 
     - Forces between all pairs of particles are computed using Newton's law of gravitation.
     - Forces are applied to each particle's center of mass.
   - **Time Stepping:** Advances the simulation using `DoStepDynamics`.

4. **Force Management:**
   - Forces on each particle are reset to zero at each step before applying new gravitational forces.
   - Pairwise force computation ensures efficient calculation by iterating through unique pairs.

This script provides a dynamic visualization of gravitational interactions between particles, with continuous emission of new particles to simulate a lively system. Adjust parameters like `G`, `emission_interval`, and particle properties to explore different behaviors.
