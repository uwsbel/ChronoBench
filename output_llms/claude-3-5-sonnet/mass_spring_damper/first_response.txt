Here's a PyChrono script that demonstrates a single mass-spring-damper system based on your instructions:

```python
import pychrono as chrono
import pychrono.irrlicht as chrono_irrlicht

# Initialize the ChSystem
system = chrono.ChSystemNSC()

# Set gravity
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body
ground = chrono.ChBodyEasyBox(1, 0.1, 1, 1000, True)
ground.SetBodyFixed(True)
system.Add(ground)

# Create the mass body
mass = chrono.ChBodyEasyBox(0.2, 0.2, 0.2, 1000, True)
mass.SetPos(chrono.ChVectorD(0, 2, 0))
system.Add(mass)

# Create the spring-damper
spring_damper = chrono.ChLinkTSDA()
spring_damper.Initialize(ground, mass, False, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 2, 0))
spring_damper.SetSpringCoefficient(50)
spring_damper.SetDampingCoefficient(1)
system.Add(spring_damper)

# Add visualization assets
col_g = chrono.ChColorAsset()
col_g.SetColor(chrono.ChColor(0.3, 0.3, 0.3))
ground.AddAsset(col_g)

col_m = chrono.ChColorAsset()
col_m.SetColor(chrono.ChColor(0.6, 0.2, 0.2))
mass.AddAsset(col_m)

# Add a spring visualization
spring_asset = chrono.ChPointPointSpring(0.01, 80, 15)
spring_asset.SetColor(chrono.ChColor(0, 0.6, 0.2))
spring_damper.AddAsset(spring_asset)

# Create the Irrlicht visualization
vis = chrono_irrlicht.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle("Mass-Spring-Damper Demo")
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile("logo_pychrono_alpha.png"))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(3, 4, -5))
vis.AddTypicalLights()

# Simulation loop
time_step = 0.001
while vis.Run():
    system.DoStepDynamics(time_step)
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

vis.GetDevice().closeDevice()
```

This script does the following:

1. Initializes the PyChrono environment and core components, including the `ChSystem` and gravity.

2. Creates a ground body (fixed) and a mass body (movable) using `ChBodyEasyBox`.

3. Sets up a `ChLinkTSDA` (Translational Spring-Damper Actuator) to connect the mass to the ground, with default spring and damping coefficients.

4. Adds visual assets to the bodies and the spring for better visualization.

5. Sets up the Irrlicht visualization system with appropriate lighting and camera settings.

6. Runs the simulation loop, updating the system and rendering the scene at each time step.

This script will create a 3D visualization of a mass-spring-damper system, where you'll see a red cube (the mass) connected to a gray box (the ground) by a green spring. The mass will oscillate due to the spring force and gravity.
