Here's a PyChrono script that meets the given instructions:

```python
import chrono
from chrono.irrlicht import *
from chrono import ChSystemSolverLS
from chrono.irrlicht.utils import ChIrrApp
from chrono.fea import ChLinkTSDA

# Initialize the PyChrono environment and core components
my_system = chrono.ChSystem()

# Add the required physical systems and objects as specified
# Create ground body
ground = my_system.AddBody(chrono.ChBody())

# Create mass body
mass = my_system.AddBody(chrono.ChBody())
mass.SetPos(chrono.ChVectorD(0, 1, 0))
mass.SetMass(1.0)

# Add a box shape to the mass body
mass_shape = mass.AddShape(chrono.ChBoxShape(chrono.ChVectorD(0.5, 0.5, 0.5)))

# Connect the mass to the ground using ChLinkTSDA
link = ChLinkTSDA()
link.Initialize(ground, mass)
my_system.AddLink(link)

# Set necessary default parameters such as positions, forces, and interactions
# Set default linear spring-damper parameters for the ChLinkTSDA connection
link.SetStiffness(50.0)
link.SetDamping(1.0)

# Irrlicht visualization with appropriate lighting and camera settings
my_application = ChIrrApp(my_system, "Mass-Spring-Damper System", 800, 600, False)
my_application.AddTypicalLogo()
my_application.AddTypicalSky()
my_application.AddTypicalLights()
my_application.AddCamera(chrono.ChVectorD(3, 4, 0), chrono.ChVectorD(0, 1, 0))

# Provide visual shapes for the mass and spring in the scene
mass_shape.SetColor(chrono.ChColor(0.5, 0.5, 1))
link.SetVisualizationType(ChLinkTSDA.VISUALIZATION_TYPE_SPRING_2)
link.SetVisualizationParam(0.1)
link.SetVisualizationColor(chrono.ChColor(0.5, 0, 0.5))

# Run the simulation
while my_application.GetDevice().run():
    my_system.DoStepDynamics(my_application.GetTimeStep())
    my_application.DrawAll()
    my_application.DoIRRFrame()
```

This script creates a mass-spring-damper system with a single `ChLinkTSDA` connecting the mass to the ground. The Irrlicht visualization is included, with appropriate lighting and camera settings. The mass and spring are also visualized in the scene.
