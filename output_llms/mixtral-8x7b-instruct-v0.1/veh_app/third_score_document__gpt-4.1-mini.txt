- **Incorrect use of `ChFramed` for offset poses:**  
  The script uses `chrono.ChFramed` to create offset poses for sensors, e.g.:  

  According to the PyChrono API, sensor poses should be specified using `chrono.ChFrame` or `chrono.ChCoordsysD` (depending on the API version). `ChFramed` is not a standard class in PyChrono core or sensor modules.   This will cause runtime errors or unexpected behavior.
