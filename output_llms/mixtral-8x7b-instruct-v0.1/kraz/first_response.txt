To create the requested PyChrono simulation, follow the instructions below to set up the environment, add necessary components, and configure the specified settings.

1. Import the required modules and initialize the PyChrono environment:

```python
import chrono
import chrono.collision as col
import chrono.irrlicht as irrl
import chrono.vehicle as veh
import irrlcht

chrono.SetChronoDataPath('path/to/chrono/data')  # Set the path to the Chrono data directory

system = chrono.ChSystemSMC()  # Initialize the Chrono system
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set the gravitational acceleration
```

2. Add the required physical systems and objects:

```python
# Create a rigid terrain
terrain = veh.ChTerrain()
terrain_shape = col.ChHeightFieldShape(terrain.GetHeightfield(), 1, 1, 50, 50, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
system.Add(terrain_shape)
terrain.SetFriction(0.8)
terrain.SetRestitution(0.2)

# Initialize the Kraz vehicle
kraz = veh.ChVehicleModelKraz()
system.Add(kraz)

# Set the initial conditions for the vehicle
kraz.SetChassisWorldTransform(chrono.ChFrameD(chrono.ChVectorD(0, 10, 0)))
kraz.SetWheelPositions(chrono.ChVectorD(-1.5, 0.5, 0), chrono.ChVectorD(1.5, 0.5, 0),
                       chrono.ChVectorD(-1.5, -0.5, 0), chrono.ChVectorD(1.5, -0.5, 0))

# Initialize the driver system for vehicle control
driver = veh.ChVehicleDriver()
system.Add(driver)
kraz.SetDriver(driver)
```

3. Set necessary default parameters such as positions, forces, and interactions:

```python
# Configure the driver
driver.SetSteerValue(0)
driver.SetBrakeValue(0)
driver.SetThrottleValue(0)

# Set up the Irrlicht visualization
vis = irrl.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('PyChrono Kraz Simulation')
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(0, 15, 5), chrono.ChVectorD(0, 0, 0))
vis.SetChaseCamera(kraz, 5)
vis.SetTimestep(1.0 / 60.0)

# Simulation loop
while vis.Run():
    system.DoStepDynamics(vis.GetTimestep())
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

# Clean up
vis.DetachSystem()
```

This script creates a PyChrono simulation with a Kraz vehicle on a rigid terrain, controlled by a driver system and visualized using Irrlicht. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.
