I'll create a comprehensive PyChrono simulation of a crank-slider mechanism. Here's the complete script:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# Initialize the PyChrono environment
chrono.SetChronoDataPath('PYCHRONO_DATA_DIR')  # Set path to ChronoData directory
system = chrono.ChSystemNSC()

# Set default parameters
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Gravity
system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
system.SetSolverMaxIterations(100)

# Material properties
mat = chrono.ChMaterialSurfaceNSC()
mat.SetFriction(0.3)
mat.SetRestitution(0.1)

# =============================================================================
# CREATE PHYSICAL OBJECTS
# =============================================================================

# 1. FLOOR/TRUSS (Fixed base)
floor = chrono.ChBodyEasyBox(4, 0.2, 2, 1000, True, True, mat)
floor.SetPos(chrono.ChVectorD(0, -1, 0))
floor.SetBodyFixed(True)
floor.SetName("floor")
system.Add(floor)

# 2. CRANKSHAFT
crank_length = 0.5
crank_radius = 0.05
crankshaft = chrono.ChBodyEasyCylinder(chrono.ChAxis_Y, crank_radius, 0.3, 2000, True, True, mat)
crankshaft.SetPos(chrono.ChVectorD(0, 0, 0))
crankshaft.SetName("crankshaft")
system.Add(crankshaft)

# Crank arm (offset part of crankshaft)
crank_arm = chrono.ChBodyEasyBox(crank_length, 0.05, 0.05, 1000, True, True, mat)
crank_arm.SetPos(chrono.ChVectorD(crank_length/2, 0, 0))
crank_arm.SetName("crank_arm")
system.Add(crank_arm)

# 3. CONNECTING ROD
rod_length = 1.2
connecting_rod = chrono.ChBodyEasyBox(rod_length, 0.05, 0.05, 1500, True, True, mat)
connecting_rod.SetPos(chrono.ChVectorD(crank_length + rod_length/2, 0, 0))
connecting_rod.SetName("connecting_rod")
system.Add(connecting_rod)

# 4. PISTON
piston = chrono.ChBodyEasyCylinder(chrono.ChAxis_X, 0.1, 0.2, 3000, True, True, mat)
piston.SetPos(chrono.ChVectorD(crank_length + rod_length, 0, 0))
piston.SetName("piston")
system.Add(piston)

# 5. CYLINDER (visual guide for piston)
cylinder = chrono.ChBodyEasyCylinder(chrono.ChAxis_X, 0.12, 0.5, 1000, True, True, mat)
cylinder.SetPos(chrono.ChVectorD(crank_length + rod_length, 0, 0))
cylinder.SetBodyFixed(True)
cylinder.SetName("cylinder")
system.Add(cylinder)

# =============================================================================
# CREATE JOINTS
# =============================================================================

# 1. Revolute joint: Floor <-> Crankshaft (main bearing)
rev_floor_crank = chrono.ChLinkLockRevolute()
rev_floor_crank.Initialize(floor, crankshaft, 
                          chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), 
                                           chrono.Q_from_AngAxis(chrono.CH_C_PI/2, chrono.ChVectorD(0, 0, 1))))
system.AddLink(rev_floor_crank)

# 2. Fixed joint: Crankshaft <-> Crank arm
fixed_crank_arm = chrono.ChLinkMateFix()
fixed_crank_arm.Initialize(crankshaft, crank_arm)
system.AddLink(fixed_crank_arm)

# 3. Revolute joint: Crank arm <-> Connecting rod (crank pin)
rev_crank_rod = chrono.ChLinkLockRevolute()
rev_crank_rod.Initialize(crank_arm, connecting_rod,
                        chrono.ChCoordsysD(chrono.ChVectorD(crank_length, 0, 0),
                                         chrono.Q_from_AngAxis(chrono.CH_C_PI/2, chrono.ChVectorD(0, 0, 1))))
system.AddLink(rev_crank_rod)

# 4. Revolute joint: Connecting rod <-> Piston (wrist pin)
rev_rod_piston = chrono.ChLinkLockRevolute()
rev_rod_piston.Initialize(connecting_rod, piston,
                         chrono.ChCoordsysD(chrono.ChVectorD(crank_length + rod_length, 0, 0),
                                          chrono.Q_from_AngAxis(chrono.CH_C_PI/2, chrono.ChVectorD(0, 0, 1))))
system.AddLink(rev_rod_piston)

# 5. Prismatic joint: Piston <-> Floor (piston slides in cylinder)
prism_piston_floor = chrono.ChLinkLockPrismatic()
prism_piston_floor.Initialize(piston, floor,
                             chrono.ChCoordsysD(chrono.ChVectorD(crank_length + rod_length, 0, 0),
                                              chrono.Q_from_AngAxis(chrono.CH_C_PI/2, chrono.ChVectorD(0, 1, 0))))
system.AddLink(prism_piston_floor)

# =============================================================================
# ADD MOTOR TO DRIVE THE CRANKSHAFT
# =============================================================================

# Create a motor to rotate the crankshaft at constant angular velocity
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(floor, crankshaft,
                chrono.ChFrameD(chrono.ChVectorD(0, 0, 0),
                              chrono.Q_from_AngAxis(chrono.CH_C_PI/2, chrono.ChVectorD(0, 0, 1))))

# Set constant angular speed (2π rad/s = 1 revolution per second)
motor_speed = chrono.ChFunction_Const(2 * chrono.CH_C_PI)
motor.SetSpeedFunction(motor_speed)
system.AddLink(motor)

# =============================================================================
# VISUALIZATION SETUP
# =============================================================================

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('Crank-Slider Mechanism Simulation')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(3, 1, 3))
vis.AddTypicalLights()

# Customize colors and textures
floor.GetVisualShape(0).SetColor(chrono.ChColor(0.6, 0.6, 0.6))  # Gray floor
crankshaft.GetVisualShape(0).SetColor(chrono.ChColor(0.8, 0.2, 0.2))  # Red crankshaft
crank_arm.GetVisualShape(0).SetColor(chrono.ChColor(0.8, 0.2, 0.2))  # Red crank arm
connecting_rod.GetVisualShape(0).SetColor(chrono.ChColor(0.2, 0.8, 0.2))  # Green connecting rod
piston.GetVisualShape(0).SetColor(chrono.ChColor(0.2, 0.2, 0.8))  # Blue piston
cylinder.GetVisualShape(0).SetColor(chrono.ChColor(0.9, 0.9, 0.9))  # Light gray cylinder

# Make cylinder semi-transparent
cylinder.GetVisualShape(0).SetOpacity(0.3)

# =============================================================================
# SIMULATION PARAMETERS
# =============================================================================

# Simulation step size
step_size = 0.01

# Simulation loop
print("Starting Crank-Slider Mechanism Simulation...")
print("Motor speed: {} rad/s ({} RPM)".format(2 * chrono.CH_C_PI, 60))

while vis.Run():
    vis.BeginScene()
    vis.Render()
    
    # Display some real-time information
    time = system.GetChTime()
    crank_angle = (2 * chrono.CH_C_PI * time) % (2 * chrono.CH_C_PI)
    piston_pos = piston.GetPos().x - (crank_length + rod_length)
    
    # Print information every second
    if int(time * 10) % 10 == 0 and time > 0:
        print(f"Time: {time:.1f}s, Crank Angle: {math.degrees(crank_angle):.1f}°, Piston Displacement: {piston_pos:.3f}m")
    
    vis.EndScene()
    system.DoStepDynamics(step_size)

print("Simulation completed.")
```

This script creates a complete crank-slider mechanism simulation with the following features:

## Key Components:
1. **Floor/Truss**: Fixed base structure
2. **Crankshaft**: Rotates about the main bearing
3. **Crank Arm**: Offset arm attached to crankshaft
4. **Connecting Rod**: Links crank arm to piston
5. **Piston**: Slides linearly in the cylinder
6. **Cylinder**: Visual guide (semi-transparent)

## Joints and Constraints:
- **Revolute joints**: Main bearing, crank pin, and wrist pin
- **Prismatic joint**: Piston sliding constraint
- **Fixed joint**: Crank arm to crankshaft connection
- **Motor**: Drives crankshaft at constant 60 RPM

## Visualization Features:
- **Custom colors**: Different colors for each component
- **Transparency**: Semi-transparent cylinder
- **Camera positioning**: Optimal viewing angle
- **Lighting**: Proper illumination
- **Logo and skybox**: Professional appearance
- **Real-time information**: Displays crank angle and piston position

## Physical Parameters:
- Realistic masses and inertias
- Material properties (friction, restitution)
- Appropriate dimensions for smooth operation
- Gravity effects included

The simulation demonstrates the conversion of rotational motion (crankshaft) to linear motion (piston) through the connecting rod, which is the fundamental principle of internal combustion engines and many mechanical systems.
