  **Deduct 15 points for incorrect API usage.**

- **Adding vehicle system to main system:**  
  `system.Add(vehicle.GetSystem())` is incorrect. The vehicle's system is a separate system; you cannot add a system to another system. Instead, the vehicle should be created with the system or the vehicle's bodies added to the system.
