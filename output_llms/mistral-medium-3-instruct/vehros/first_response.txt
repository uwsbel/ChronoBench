# PyChrono HMMWV Simulation with ROS Integration

Below is a comprehensive PyChrono simulation script for an HMMWV vehicle with terrain interaction, driver control, and ROS communication:

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as chronoirr
import pychrono.sensor as sens
import pychrono.ros as ros
import time

# =============================================================================
# Initialize PyChrono and ROS
# =============================================================================

# Set path to Chrono and vehicle data
chrono.SetChronoDataPath("PATH_TO_CHRONO_DATA")
veh.SetDataPath("PATH_TO_VEHICLE_DATA")

# Create systems
vehicle_system = chrono.ChSystemNSC()
terrain_system = chrono.ChSystemNSC()
driver_system = chrono.ChSystemNSC()

# Set collision and solver parameters
vehicle_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))
terrain_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

vehicle_system.SetSolverType(chrono.ChSolver.Type_APGD)
vehicle_system.SetMaxItersSolverSpeed(30)
vehicle_system.SetMaxItersSolverStab(30)
vehicle_system.SetTol(1e-3)
vehicle_system.SetSolverWarmStarting(True)

terrain_system.SetSolverType(chrono.ChSolver.Type_APGD)
terrain_system.SetMaxItersSolverSpeed(30)
terrain_system.SetMaxItersSolverStab(30)
terrain_system.SetTol(1e-3)
terrain_system.SetSolverWarmStarting(True)

# =============================================================================
# Create Terrain
# =============================================================================

# Terrain dimensions and properties
terrain_length = 100.0  # meters
terrain_width = 100.0   # meters
terrain_height = 0.2    # meters

# Create a rigid terrain body
terrain = chrono.ChBodyEasyBox(terrain_length, terrain_height, terrain_width, 1000)
terrain.SetPos(chrono.ChVectorD(0, -terrain_height/2, 0))
terrain.SetBodyFixed(True)
terrain.SetCollide(True)
terrain.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
terrain.GetMaterialSurfaceNSC().SetFriction(0.8)
terrain.GetMaterialSurfaceNSC().SetRestitution(0.1)
terrain_system.Add(terrain)

# =============================================================================
# Create HMMWV Vehicle
# =============================================================================

# Vehicle parameters
hmmwv_params = veh.HMMWV_VehicleParameters()
hmmwv_params.tire_type = veh.TireType::RIGID_MESH
hmmwv_params.contact_method = veh.ContactMethod::NSC
hmmwv_params.engine_type = veh.EngineType::SHAFT
hmmwv_params.tire_step_size = 2e-3

# Create the vehicle
hmmwv = veh.HMMWV(vehicle_system, hmmwv_params)
hmmwv.Initialize(chrono.ChCoordsysD(chrono.ChVectorD(0, 0.5, 0), chrono.QUNIT))
hmmwv.SetChassisFixed(False)
hmmwv.SetChassisVisualizationType(veh.VisualizationType::MESH)
hmmwv.SetSuspensionVisualizationType(veh.VisualizationType::PRIMITIVES)
hmmwv.SetSteeringVisualizationType(veh.VisualizationType::PRIMITIVES)
hmmwv.SetWheelVisualizationType(veh.VisualizationType::MESH)

# Set tire properties
for i in range(hmmwv.GetNumberWheels()):
    wheel = hmmwv.GetWheel(i)
    tire = wheel.GetTire()
    tire.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
    tire.GetMaterialSurfaceNSC().SetFriction(0.9)
    tire.GetMaterialSurfaceNSC().SetRestitution(0.2)

# =============================================================================
# Create Driver System
# =============================================================================

# Create a simple path-following driver
driver = veh.ChPathFollowerDriver(driver_system, hmmwv)
driver.SetSteeringGain(0.5)
driver.SetThrottleGain(0.5)
driver.SetTargetSpeed(10.0)  # m/s

# Create a simple path (straight line)
path = chrono.ChBezierCurve()
path.AddPoint(chrono.ChVectorD(0, 0, 0))
path.AddPoint(chrono.ChVectorD(50, 0, 0))
path.AddPoint(chrono.ChVectorD(100, 0, 0))
driver.SetPath(path)

# =============================================================================
# ROS Integration
# =============================================================================

# Initialize ROS node
ros_node = ros.ChRosNode("hmmwv_simulation")

# Create ROS manager for vehicle
ros_manager = ros.ChRosVehicleManager(hmmwv, ros_node)
ros_manager.SetVehicleStatePublisherTopic("/vehicle/state")
ros_manager.SetVehicleDriverSubscriberTopic("/vehicle/driver_input")

# Add clock synchronization handler
clock_handler = ros.ChRosClockHandler(ros_node, "/clock")
ros_manager.AddHandler(clock_handler)

# Add driver input handler
driver_handler = ros.ChRosDriverInputHandler(ros_node, "/driver_input")
ros_manager.AddHandler(driver_handler)

# Add vehicle state handler
state_handler = ros.ChRosVehicleStateHandler(ros_node, "/vehicle_state")
ros_manager.AddHandler(state_handler)

# =============================================================================
# Visualization
# =============================================================================

# Create Irrlicht application
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(vehicle_system)
vis.AttachSystem(terrain_system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle("HMMWV Simulation")
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(5, 2, 0), chrono.ChVectorD(0, 0, 0))
vis.AddTypicalLights()
vis.SetCameraTrackingPoint(chrono.ChVectorD(0, 0, 0))

# =============================================================================
# Simulation Loop
# =============================================================================

# Simulation parameters
step_size = 1e-3
end_time = 10.0  # seconds
current_time = 0.0

# Simulation loop
while current_time < end_time:
    # Synchronize systems
    vehicle_system.DoStepDynamics(step_size)
    terrain_system.DoStepDynamics(step_size)
    driver_system.DoStepDynamics(step_size)

    # Update vehicle
    hmmwv.Synchronize(step_size)

    # Update driver
    driver.Synchronize(step_size)
    driver.Advance(step_size)

    # Update ROS
    ros_manager.Synchronize(step_size)
    ros_manager.Publish()

    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Update time
    current_time += step_size
    print(f"Simulation time: {current_time:.2f} s")

# Clean up
vis.Close()
ros_node.Shutdown()
```

## Key Components Explained:

1. **Initialization**:
   - Sets up Chrono data paths and creates three systems (vehicle, terrain, driver)
   - Configures solver parameters for accurate physics simulation

2. **Terrain Setup**:
   - Creates a flat terrain with specified dimensions
   - Sets friction (0.8) and restitution (0.1) properties

3. **HMMWV Vehicle**:
   - Uses the HMMWV vehicle template with rigid mesh tires
   - Configures engine type (shaft) and contact method (NSC)
   - Sets visualization types for different vehicle components

4. **Driver System**:
   - Implements a path-following driver with adjustable gains
   - Creates a simple straight-line path for the vehicle to follow

5. **ROS Integration**:
   - Initializes ROS node and creates a vehicle manager
   - Sets up handlers for clock synchronization, driver inputs, and vehicle state
   - Configures topics for communication

6. **Visualization**:
   - Uses Irrlicht for 3D visualization
   - Sets up camera, lighting, and tracking

7. **Simulation Loop**:
   - Synchronizes all systems at each timestep
   - Advances physics, driver, and ROS components
   - Updates visualization and prints progress

To use this script, you'll need to:
1. Set the correct paths to Chrono and vehicle data
2. Ensure ROS is properly installed and configured
3. Adjust parameters as needed for your specific simulation requirements

The script provides a complete framework that can be extended with more complex terrain, advanced driver behaviors, or additional ROS functionalities.
