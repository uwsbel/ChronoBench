# PyChrono Viper Rover Simulation

Here's a complete PyChrono simulation script for a Viper rover on rigid terrain with real-time visualization:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import numpy as np

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("PATH_TO_CHRONO_DATA")  # Update this path

# Create the Chrono physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add physical systems and objects

# Create the terrain
terrain = veh.Terrain(system)
terrain_body = chrono.ChBody()
terrain_body.SetBodyFixed(True)
terrain_body.GetCollisionModel().AddBox(10, 0.1, 10)  # Large flat box for terrain
terrain_body.GetVisualModel().AddBox(10, 0.1, 10, chrono.ChColor(0.5, 0.5, 0.5))
system.Add(terrain_body)
terrain.SetContactFrictionCoefficient(0.8)
terrain.SetContactRestitutionCoefficient(0.1)
terrain.SetContactMaterialProperties(2e7, 0.3)
terrain.Initialize()

# Create the Viper rover
viper = veh.Viper(system)
viper.SetContactMethod(chrono.ChContactMethod_NSC)
viper.SetChassisFixed(False)
viper.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 0.5, 0), chrono.QUNIT))
viper.SetInitFwdVel(0.0)
viper.Initialize()

# Create the driver system
driver = veh.ChDriver()
driver.SetSteeringFunction(veh.ChFunction_Const(0))  # Initially straight
driver.SetThrottleFunction(veh.ChFunction_Const(0.3))  # Constant throttle
viper.SetDriver(driver)

# 3. Set up visualization
app = chronoirr.ChIrrApp(system, "Viper Rover Simulation", chronoirr.dimension2du(1280, 720))
app.AddTypicalLogo()
app.AddTypicalSky()
app.AddTypicalLights()
app.AddTypicalCamera(chrono.ChVectorD(5, 2, 5))

# Customize camera settings
camera = app.GetCamera()
camera.SetPosition(chrono.ChVectorD(5, 2, 5))
camera.SetTarget(chrono.ChVectorD(0, 0.5, 0))

# Add light
light = chrono.ChVectorD(5, 10, 5)
app.AddLightWithShadow(light, light, 10, 0, 10, 40, 512)

# Simulation parameters
time_step = 0.01
sim_time = 10.0
steering_time = 5.0  # Time over which steering changes

# 4. Simulation loop
while app.GetDevice().run():
    app.BeginScene()

    # Update visualization
    app.DrawAll()

    # Render scene
    app.DoStepDynamics(time_step)

    # Update steering gradually
    current_time = system.GetChTime()
    if current_time < steering_time:
        # Gradually change steering from 0 to 0.5 radians over steering_time
        steering_angle = 0.5 * (current_time / steering_time)
        driver.SetSteeringFunction(veh.ChFunction_Const(steering_angle))
    else:
        # After steering_time, maintain the steering angle
        driver.SetSteeringFunction(veh.ChFunction_Const(0.5))

    # Update driver inputs
    driver.Synchronize(time_step)
    viper.Synchronize(time_step, driver.GetSteering(), driver.GetThrottle(), driver.GetBraking())

    app.EndScene()

    # Exit simulation after specified time
    if current_time >= sim_time:
        break
```

## Key Components Explained:

1. **Initialization**:
   - Sets up the Chrono system with gravity
   - Configures the data path (you need to update this)

2. **Terrain**:
   - Creates a large flat rigid terrain
   - Sets contact properties (friction, restitution, material)

3. **Viper Rover**:
   - Initializes the Viper rover model
   - Sets initial position and velocity
   - Configures contact method

4. **Driver System**:
   - Creates a driver with initial steering and throttle settings
   - Connects the driver to the rover

5. **Visualization**:
   - Sets up Irrlicht visualization with camera, lighting, and sky
   - Configures camera position and target

6. **Simulation Loop**:
   - Gradually changes steering angle over `steering_time`
   - Updates driver inputs and synchronizes the rover
   - Runs the simulation for `sim_time` seconds

## Notes:
- Make sure to update `PATH_TO_CHRONO_DATA` to your actual Chrono data directory path
- The steering gradually changes from 0 to 0.5 radians over the first 5 seconds
- The simulation runs for 10 seconds total
- You can adjust parameters like gravity, terrain size, steering angles, etc. as needed

This script provides a complete simulation of the Viper rover on rigid terrain with real-time visualization and gradual steering changes.
