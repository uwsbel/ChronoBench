# PyChrono Simulation of ARTcar Vehicle on Rigid Terrain

Below is a complete PyChrono simulation script for an ARTcar vehicle on rigid terrain with Irrlicht visualization and interactive controls:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import pychrono.driver as driver
import math

# =============================================================================
# Simulation parameters
# =============================================================================

# Simulation step size
step_size = 0.01

# Simulation end time
t_end = 30

# =============================================================================
# Create the simulation system and add items
# =============================================================================

# Create the Chrono::Engine physical system
sys = chrono.ChSystemNSC()
sys.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the vehicle system
vehicle = veh.ARTcar()
vehicle.SetContactMethod(chrono.ChContactMethod_NSC)
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 0.5, 0), chrono.QUNIT))
vehicle.SetInitFwdVel(10)
vehicle.Initialize(sys)

# Create the terrain
terrain = veh.RigidTerrain(sys)
terrain.SetContactFrictionCoefficient(0.9)
terrain.SetContactRestitutionCoefficient(0.1)
terrain.SetContactMaterialProperties(2e7, 0.3)

patch = terrain.AddPatch(chrono.ChVectorD(0, 0, 0),
                         chrono.ChVectorD(20, 0, 0),
                         20, 20)
patch.SetTexture(veh.GetDataFile("terrain/textures/tile4.jpg"), 20, 20)
terrain.Initialize()

# =============================================================================
# Create the vehicle Irrlicht interface
# =============================================================================

# Create the vehicle Irrlicht interface
vis = veh.ChVehicleVisualSystemIrrlicht()
vis.SetWindowTitle("ARTcar Simulation")
vis.SetChaseCamera(chrono.ChVectorD(0.0, 1.75, -5.0),  # Camera location
                   10.0)                               # Look-ahead distance
vis.Initialize()
vis.AddTypicalLogo()
vis.AddTypicalSky()
vis.AddTypicalLights(veh.GetDataFile("terrain/light_01.png"), 100, 100, 50, 50)
vis.AddTypicalLights(veh.GetDataFile("terrain/light_02.png"), -100, -100, 50, 50)
vis.AttachVehicle(vehicle.GetChassisBody())

# =============================================================================
# Create the driver system
# =============================================================================

# Create a driver system
driver = driver.ChInteractiveDriverIRR(vis.GetSystem())
driver.SetSteeringDelta(0.04)
driver.SetThrottleDelta(0.02)
driver.SetBrakingDelta(0.04)
driver.Initialize()

# =============================================================================
# Simulation loop
# =============================================================================

# Number of simulation steps between two 3D view render frames
render_steps = math.ceil(1 / (step_size * 50))

# Initialize simulation frame counter
step_number = 0
render_frame = 0

while vis.Run() and sys.GetChTime() < t_end:
    # Get driver inputs
    driver_inputs = driver.GetInputs()

    # Update the vehicle state
    vehicle.SetDriverInputs(driver_inputs.m_throttle, driver_inputs.m_steering, driver_inputs.m_braking)

    # Update the vehicle system (state, visualization, etc.)
    vehicle.Update(sys.GetChTime())

    # Advance simulation for one timestep for all modules
    driver.Synchronize(sys.GetChTime())
    terrain.Synchronize(sys.GetChTime())
    vis.Synchronize(sys.GetChTime(), driver_inputs)

    # Render scene
    if step_number % render_steps == 0:
        vis.BeginScene()
        vis.Render()
        vis.EndScene()
        render_frame += 1

    # Advance simulation by one step
    sys.DoStepDynamics(step_size)
    step_number += 1

print("Simulation completed")
```

## Key Components Explained:

1. **Simulation Setup**:
   - Initializes a Chrono::Engine physical system with NSC (Non-Smooth Contact) solver
   - Sets gravity to -9.81 m/s² in the Y direction

2. **Vehicle Configuration**:
   - Creates an ARTcar vehicle with NSC contact method
   - Sets initial position (0, 0.5, 0) and orientation (identity quaternion)
   - Initializes with a forward velocity of 10 m/s

3. **Terrain Setup**:
   - Creates a rigid terrain with friction coefficient 0.9 and restitution 0.1
   - Adds a 20x20 meter patch with a custom texture
   - Sets contact material properties (Young's modulus and Poisson ratio)

4. **Visualization**:
   - Uses Irrlicht for 3D visualization
   - Sets up a chase camera following the vehicle
   - Adds typical environment elements (logo, sky, lights)

5. **Driver System**:
   - Creates an interactive driver system with keyboard controls
   - Configures steering, throttle, and braking sensitivities
   - Connects to the Irrlicht visualization system

6. **Simulation Loop**:
   - Runs at 50 FPS (render_steps calculated to match this)
   - Processes driver inputs and updates vehicle state
   - Synchronizes all systems (driver, terrain, visualization)
   - Advances the simulation in time steps

The simulation will run for 30 seconds (simulation time) with real-time visualization and interactive controls for steering, throttle, and braking.
