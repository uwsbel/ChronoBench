# PyChrono Simulation: Jeffcott Rotor with IGA Beam

Below is a complete PyChrono simulation script that models a Jeffcott rotor using an Isogeometric Analysis (IGA) beam with a flywheel and rotational motor:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath('PATH_TO_CHRONO_DATA')  # Set path to Chrono data directory

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Create the IGA beam (Jeffcott rotor)
# Beam parameters
length = 1.0  # Length of the beam
radius = 0.05  # Radius of the beam
density = 7800  # Density of the material (steel)
E = 200e9  # Young's modulus
nu = 0.3  # Poisson's ratio
G = E / (2 * (1 + nu))  # Shear modulus

# Create the IGA beam
beam = chrono.fea.ChBeamIGA()
beam.SetNumSpans(10)  # Number of elements along the beam
beam.SetCrossSection(chrono.fea.ChBeamSectionCircular(radius, density, E, G))
beam.SetLength(length)
beam.SetSolveForDynamics(True)  # Enable dynamics

# Set boundary conditions (fixed at one end)
beam.SetBoundaryConditions(chrono.fea.ChBeamIGA.BCType.FIXED, chrono.fea.ChBeamIGA.BCType.FREE)

# Add the beam to the system
system.Add(beam)

# Create a flywheel at the center of the beam
flywheel = chrono.ChBody()
flywheel.SetMass(10)  # Mass of the flywheel
flywheel.SetInertiaXX(chrono.ChVectorD(0.1, 0.1, 0.2))  # Inertia tensor
flywheel.SetPos(chrono.ChVectorD(0, 0, length/2))  # Position at center of beam

# Visualization for the flywheel
flywheel_vis = chrono.ChCylinderShape()
flywheel_vis.GetCylinderGeometry().rad = 0.1
flywheel_vis.GetCylinderGeometry().p1 = chrono.ChVectorD(0, 0, -0.05)
flywheel_vis.GetCylinderGeometry().p2 = chrono.ChVectorD(0, 0, 0.05)
flywheel.AddVisualShape(flywheel_vis)

# Add the flywheel to the system
system.Add(flywheel)

# Connect the flywheel to the beam at its center
link = chrono.ChLinkLockLock()
link.Initialize(flywheel, beam.GetNode(5), False, chrono.ChVectorD(0, 0, 0), chrono.QUNIT)
system.Add(link)

# 3. Create a rotational motor at one end of the beam
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(beam.GetNode(0), beam.GetNode(0), False, chrono.ChVectorD(0, 0, 1))
motor.SetSpeedFunction(chrono.ChFunction_Const(10.0))  # Constant speed of 10 rad/s
system.Add(motor)

# 4. Visualization setup
# Create the Irrlicht application
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Jeffcott Rotor with IGA Beam')
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(1.5, 0.5, 1.5), chrono.ChVectorD(0, 0, 0.5))
vis.AddTypicalLights()
vis.AddLightWithShadow(chrono.ChVectorD(1.5, 5.5, -2.5), chrono.ChVectorD(0, 0, 0.5), 3, 2, 10, 40, 512)

# FEM visualization for the beam
beam_vis = chrono.fea.ChVisualizationFEAmesh(beam)
beam_vis.SetFEMdataType(chrono.fea.ChVisualizationFEAmesh.E_PLOT_DISPLACEMENTS)
beam_vis.SetSmoothFaces(True)
beam_vis.SetWireframe(False)
beam.AddVisualization(beam_vis)
vis.AddVisualization(beam_vis)

# Simulation parameters
time_step = 1e-4
end_time = 5.0

# Simulation loop
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    system.DoStepDynamics(time_step)

    # Print current simulation time
    current_time = system.GetChTime()
    print(f"Simulation time: {current_time:.2f} s")

    if current_time >= end_time:
        break
```

## Key Components Explained:

1. **IGA Beam Setup**:
   - Created using `ChBeamIGA` with circular cross-section
   - Material properties set for steel (density, Young's modulus, Poisson's ratio)
   - Boundary conditions: fixed at one end, free at the other

2. **Flywheel**:
   - Added as a separate rigid body at the center of the beam
   - Connected to the beam using a lock constraint

3. **Rotational Motor**:
   - Implemented as a speed motor at the fixed end of the beam
   - Constant rotational speed of 10 rad/s

4. **Visualization**:
   - Irrlicht for real-time rendering
   - FEM visualization for the beam with displacement plotting
   - Proper lighting and camera setup

5. **Simulation Parameters**:
   - Time step of 1e-4 seconds
   - Simulation runs for 5 seconds

To run this simulation, you'll need to:
1. Have PyChrono properly installed
2. Set the correct path to Chrono data files
3. Ensure all required dependencies are available

The simulation will show the dynamic behavior of the Jeffcott rotor, including the beam deformation and flywheel motion under the influence of the rotational motor.
