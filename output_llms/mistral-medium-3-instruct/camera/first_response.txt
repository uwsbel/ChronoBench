# PyChrono Simulation with Fixed Triangular Mesh and Orbiting Camera Sensor

Below is a complete PyChrono simulation script that implements the requested functionality:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np
import os
import time

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath('PATH_TO_CHRONO_DATA')  # Update this path

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, 0))  # No gravity for this simulation

# 2. Add the required physical systems and objects

# Create a mesh from OBJ file
mesh_filename = "your_mesh.obj"  # Replace with your OBJ file path
if not os.path.exists(mesh_filename):
    raise FileNotFoundError(f"Mesh file {mesh_filename} not found!")

# Create the fixed body with the mesh
mesh_body = chrono.ChBody()
mesh_body.SetBodyFixed(True)  # Fixed in space
system.Add(mesh_body)

# Load the mesh visualization assets
mesh_visualization = chrono.ChTriangleMeshShape()
mesh_visualization.SetMeshFromFile(mesh_filename)
mesh_body.AddVisualShape(mesh_visualization)

# Create collision geometry (optional, if you want collision detection)
mesh_collision = chrono.ChTriangleMeshShape()
mesh_collision.SetMeshFromFile(mesh_filename)
mesh_body.AddAsset(mesh_collision)

# 3. Set necessary default parameters

# Create the camera sensor
camera = chrono.ChCameraSensor(
    width=640,  # Image width
    height=480,  # Image height
    hfov=55,     # Horizontal field of view in degrees
    vfov=42,     # Vertical field of view in degrees
    update_rate=30  # Update rate in Hz
)

# Set initial camera position (looking at the mesh)
camera.SetPos(chrono.ChVectorD(2, 0, 0))  # Initial position
camera.SetRot(chrono.ChQuaternionD(1, 0, 0, 0))  # Initial rotation (pointing at origin)

# Add the camera to the system
system.Add(camera)

# Create a sensor manager to handle the camera
sensor_manager = chrono.ChSensorManager(system)
sensor_manager.AddSensor(camera)

# Add noise filters to the camera
noise_model = chrono.ChCameraNoiseWhite(0.01)  # White noise with 0.01 intensity
camera.AddNoiseModel(noise_model)

# Create the visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("PyChrono - Fixed Mesh with Orbiting Camera")
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(0, 0, 6))
vis.AddTypicalLights()
vis.AddLightWithShadow(chrono.ChVectorD(1.5, 1.5, 5), chrono.ChVectorD(0, 0, 0), 3, 1, 10)

# Simulation parameters
time_step = 0.01
end_time = 10.0  # Simulation duration in seconds
output_dir = "camera_output"
os.makedirs(output_dir, exist_ok=True)

# Simulation loop
current_time = 0
frame_count = 0
while current_time < end_time:
    # Update the camera position in an orbit around the mesh
    radius = 2.0
    angle = current_time * 0.5  # Angular speed
    camera_pos = chrono.ChVectorD(
        radius * np.cos(angle),
        radius * np.sin(angle),
        0.5  # Small elevation
    )
    camera.SetPos(camera_pos)

    # Make the camera always look at the origin (mesh)
    look_at = chrono.ChVectorD(0, 0, 0)
    camera.SetRot(chrono.ChQuaternionD().Q_from_AngAxis(angle + chrono.CH_C_PI/2, chrono.ChVectorD(0, 0, 1)))

    # Advance the simulation
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Update the sensor manager
    sensor_manager.Update()

    # Get the camera buffer data
    if camera.HasDataReady():
        buffer = camera.GetMostRecentBuffer()
        if buffer:
            # Print some information about the camera buffer
            print(f"Time: {current_time:.2f}s - Camera position: {camera_pos}")
            print(f"Buffer size: {buffer.GetWidth()}x{buffer.GetHeight()}")
            print(f"First pixel value: {buffer.GetPixel(0, 0)}")

            # Save the image (optional)
            if frame_count % 10 == 0:  # Save every 10 frames
                buffer.SaveAsPNG(os.path.join(output_dir, f"frame_{frame_count:04d}.png"))

    # Increment time and frame count
    current_time += time_step
    frame_count += 1
    time.sleep(time_step)  # Real-time simulation

# Clean up
vis.CloseDevice()
```

## Key Features of This Implementation:

1. **System Initialization**:
   - Sets up a ChSystemNSC (non-smooth contact dynamics)
   - Configures the visualization system with Irrlicht

2. **Mesh Loading**:
   - Loads a triangular mesh from a Wavefront .obj file
   - Creates both visual and collision representations
   - Fixes the mesh body in space

3. **Camera Sensor**:
   - Creates a camera sensor with configurable resolution and FOV
   - Adds white noise to simulate real-world sensor noise
   - Implements orbiting behavior around the mesh

4. **Simulation Loop**:
   - Updates camera position in a circular orbit
   - Renders the scene with visualization
   - Processes camera data at each step
   - Saves sample images periodically

5. **Data Output**:
   - Prints camera position and buffer information
   - Saves images to disk for later analysis

## Notes:

1. Replace `PATH_TO_CHRONO_DATA` with your actual PyChrono data path.
2. Replace `your_mesh.obj` with the path to your actual OBJ file.
3. The camera orbit parameters (radius, speed) can be adjusted as needed.
4. The simulation runs in real-time with a small sleep between frames.
5. The output directory will contain sample images from the camera.

This script provides a complete implementation of the requested simulation with all specified components.
