# PyChrono Turtlebot Simulation Script

Here's a complete PyChrono simulation script for a Turtlebot robot on rigid terrain with real-time visualization:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import numpy as np

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("PATH_TO_CHRONO_DATA")  # Update this path

# Create the Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add the required physical systems and objects

# Create the terrain
terrain = chrono.ChBodyEasyBox(20, 0.1, 20, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, -0.1, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)

# Create the Turtlebot
def create_turtlebot(system, position, orientation):
    # Create the Turtlebot chassis
    chassis = chrono.ChBodyEasyBox(0.3, 0.1, 0.2, 10, True, True)
    chassis.SetPos(position)
    chassis.SetRot(orientation)
    chassis.SetBodyFixed(False)
    system.Add(chassis)

    # Create wheels (simplified as cylinders)
    wheel_radius = 0.05
    wheel_width = 0.02

    # Left wheel
    left_wheel = chrono.ChBodyEasyCylinder(wheel_radius, wheel_width, 1, True, True)
    left_wheel.SetPos(position + chrono.ChVectorD(-0.1, -0.05, 0))
    system.Add(left_wheel)

    # Right wheel
    right_wheel = chrono.ChBodyEasyCylinder(wheel_radius, wheel_width, 1, True, True)
    right_wheel.SetPos(position + chrono.ChVectorD(0.1, -0.05, 0))
    system.Add(right_wheel)

    # Create revolute joints for wheels
    left_joint = chrono.ChLinkLockRevolute()
    left_joint.Initialize(left_wheel, chassis, chrono.ChCoordsysD(left_wheel.GetPos(), chrono.Q_from_AngX(chrono.CH_PI_2)))
    system.Add(left_joint)

    right_joint = chrono.ChLinkLockRevolute()
    right_joint.Initialize(right_wheel, chassis, chrono.ChCoordsysD(right_wheel.GetPos(), chrono.Q_from_AngX(chrono.CH_PI_2)))
    system.Add(right_joint)

    return chassis, left_wheel, right_wheel, left_joint, right_joint

# Initialize Turtlebot at position (0, 0.1, 0) with default orientation
turtlebot = create_turtlebot(system, chrono.ChVectorD(0, 0.1, 0), chrono.QUNIT)

# 3. Set up visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle("Turtlebot Simulation")
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(2, 1, 2), chrono.ChVectorD(0, 0, 0))
vis.AddTypicalLights()

# 4. Simulation parameters
time_step = 0.01
sim_time = 10.0
current_time = 0

# 5. Simulation loop
while vis.Run():
    # Update time
    current_time += time_step

    # Control the Turtlebot motors
    if current_time < 2.0:
        # Turn right (left wheel forward, right wheel backward)
        turtlebot[1].SetWvel_loc(chrono.ChVectorD(10, 0, 0))  # Left wheel
        turtlebot[2].SetWvel_loc(chrono.ChVectorD(-10, 0, 0)) # Right wheel
    elif current_time < 4.0:
        # Move forward
        turtlebot[1].SetWvel_loc(chrono.ChVectorD(10, 0, 0))  # Left wheel
        turtlebot[2].SetWvel_loc(chrono.ChVectorD(10, 0, 0))  # Right wheel
    elif current_time < 6.0:
        # Turn left (left wheel backward, right wheel forward)
        turtlebot[1].SetWvel_loc(chrono.ChVectorD(-10, 0, 0))  # Left wheel
        turtlebot[2].SetWvel_loc(chrono.ChVectorD(10, 0, 0))   # Right wheel
    else:
        # Stop
        turtlebot[1].SetWvel_loc(chrono.ChVectorD(0, 0, 0))  # Left wheel
        turtlebot[2].SetWvel_loc(chrono.ChVectorD(0, 0, 0))  # Right wheel

    # Advance simulation
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    system.DoStepDynamics(time_step)

    # Stop simulation after sim_time
    if current_time >= sim_time:
        break
```

## Key Features of This Implementation:

1. **Initialization**:
   - Sets up the Chrono system with gravity
   - Creates a rigid terrain as a fixed box

2. **Turtlebot Creation**:
   - Simplified Turtlebot model with chassis and two wheels
   - Revolute joints connect wheels to the chassis
   - Initial position and orientation can be adjusted

3. **Visualization**:
   - Uses Irrlicht for real-time rendering
   - Includes camera setup and lighting
   - Window size and title can be customized

4. **Simulation Loop**:
   - Implements timed motor control for left/right turns and forward motion
   - Updates visualization at each timestep
   - Simulation runs for 10 seconds by default

5. **Motor Control**:
   - First 2 seconds: Right turn
   - Next 2 seconds: Forward motion
   - Next 2 seconds: Left turn
   - Final 4 seconds: Stopped

To run this script, you'll need to:
1. Install PyChrono (with Irrlicht support)
2. Set the correct path to Chrono data files
3. Adjust parameters as needed for your specific simulation requirements

The simulation provides a basic but functional Turtlebot model that demonstrates differential drive behavior.
