# PyChrono HMMWV Simulation with IMU and GPS Sensors

Below is a comprehensive PyChrono simulation script featuring an HMMWV vehicle with terrain, driver inputs, and visualization, including IMU and GPS sensor integration:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import numpy as np
import time

# =============================================================================
# Simulation parameters
# =============================================================================

# Simulation step size
step_size = 1e-3

# Time interval for sensor updates
sensor_update_interval = 0.01  # 100Hz

# Simulation end time
t_end = 10.0

# =============================================================================
# Create the systems
# =============================================================================

# Create the vehicle system
vehicle_system = veh.ChVehicleSystem()

# Create the terrain
terrain = veh.RigidTerrain(vehicle_system)
patch_size = 20
patch = veh.TerrainPatch(terrain, patch_size, patch_size, 0, 0, 0, 0)
patch.AddConstantZLevel(-0.1)  # Slightly below the vehicle
terrain.AddPatch(patch)
terrain.Initialize()

# =============================================================================
# Create the HMMWV vehicle
# =============================================================================

# Create the HMMWV vehicle
hmmwv = veh.ChHMMWVVehicle(vehicle_system)

# Set vehicle parameters
hmmwv.SetInitPosition(chrono.ChVectorD(0, 0, 0.5))
hmmwv.SetInitFwdVel(5)  # Initial forward velocity

# Initialize the vehicle
hmmwv.Initialize()

# =============================================================================
# Create the driver system
# =============================================================================

# Create a driver system
driver = veh.ChPathFollowerDriver(hmmwv.GetVehicle(), "path/driver", 2.5, 0.6)

# Define a simple path (straight line)
path = veh.ChPath()
path.AddPoint(chrono.ChVectorD(0, 0, 0.5))
path.AddPoint(chrono.ChVectorD(50, 0, 0.5))
driver.SetPath(path)

# =============================================================================
# Create the visual system
# =============================================================================

# Create the Irrlicht application
vis = chronoirr.ChVisualSystemIrrlicht()
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle("HMMWV Simulation with Sensors")
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(5, 0, 2), chrono.ChVectorD(0, 0, 0.5))
vis.AddTypicalLights()
vis.SetCameraMoveScale(0.02)
vis.SetUseSkyBox(True)
vis.SetCameraVertical(chrono.CameraVerticalDir_Z)

# Attach the vehicle visual system
vis.AttachVehicle(hmmwv.GetVehicle())

# =============================================================================
# Create and attach sensors to the vehicle
# =============================================================================

# IMU Sensor
imu_sensor = veh.ChIMUSensor(hmmwv.GetChassisBody(), chrono.ChVectorD(0, 0, 0.5), chrono.ChQuaternionD(1, 0, 0, 0))
imu_sensor.SetName("IMU")
imu_sensor.SetUpdateRate(100)  # 100Hz

# GPS Sensor
gps_sensor = veh.ChGPSSensor(hmmwv.GetChassisBody(), chrono.ChVectorD(0, 0, 0.5), chrono.ChQuaternionD(1, 0, 0, 0))
gps_sensor.SetName("GPS")
gps_sensor.SetUpdateRate(10)  # 10Hz

# Add sensors to the vehicle
hmmwv.GetVehicle().AddSensor(imu_sensor)
hmmwv.GetVehicle().AddSensor(gps_sensor)

# =============================================================================
# Simulation loop
# =============================================================================

# Initialize simulation time
time = 0
last_sensor_update = 0

# Main simulation loop
while time < t_end:
    # Get current time
    start_time = time.time()

    # Update the driver system
    driver.Update(time)

    # Update the vehicle system
    vehicle_system.Update()

    # Update sensors at their specified rates
    current_time = time
    if current_time - last_sensor_update >= sensor_update_interval:
        imu_sensor.Update(current_time)
        gps_sensor.Update(current_time)
        last_sensor_update = current_time

        # Print sensor data
        print(f"Time: {current_time:.2f}s")
        print(f"IMU Data - Acceleration: {imu_sensor.GetAcceleration()}")
        print(f"IMU Data - Angular Velocity: {imu_sensor.GetAngularVelocity()}")
        print(f"GPS Data - Position: {gps_sensor.GetPosition()}")
        print(f"GPS Data - Velocity: {gps_sensor.GetVelocity()}")
        print(f"Vehicle Mass: {hmmwv.GetVehicle().GetMass()} kg")
        print("----------------------------------")

    # Update the visual system
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Advance simulation time
    time += step_size

    # Spin in place for real-time simulation
    while time.time() - start_time < step_size:
        pass

# =============================================================================
# Clean up
# =============================================================================

# Print final vehicle mass
print(f"Final Vehicle Mass: {hmmwv.GetVehicle().GetMass()} kg")

# Close the visual system
vis.Close()
```

## Key Components Explained:

1. **Simulation Setup**:
   - Initializes PyChrono environment with proper step size and simulation duration
   - Creates the vehicle system and terrain with a simple flat patch

2. **HMMWV Vehicle**:
   - Configures the HMMWV with initial position and velocity
   - Sets up the complete vehicle system with chassis, suspension, wheels, etc.

3. **Driver System**:
   - Implements a path-following driver with a simple straight-line path
   - Controls the vehicle's steering and throttle based on the path

4. **Visualization**:
   - Uses Irrlicht for 3D visualization with camera controls
   - Sets up lighting and skybox for better visual quality

5. **Sensor Integration**:
   - Adds IMU sensor for acceleration and angular velocity measurements
   - Adds GPS sensor for position and velocity tracking
   - Updates sensors at their specified rates (100Hz for IMU, 10Hz for GPS)

6. **Simulation Loop**:
   - Coordinates updates between vehicle, driver, sensors, and visualization
   - Outputs sensor data and vehicle mass at each update interval
   - Maintains real-time simulation with proper timing

This script provides a complete simulation environment for the HMMWV with sensor integration, ready for further customization or data analysis.
