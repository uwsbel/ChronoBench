# PyChrono HMMWV Simulation Script

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import pychrono.vehicle.wheeled_vehicle as wheeled_vehicle
import pychrono.vehicle.terrain as terrain
import pychrono.vehicle.driver as driver

# =============================================================================
# Simulation parameters
# =============================================================================

# Simulation step size
step_size = 0.02  # 50 FPS

# Simulation end time
t_end = 10.0

# =============================================================================
# Create the systems and simulation
# =============================================================================

# Create the vehicle system
vehicle_system = veh.WheeledVehicleSystem()

# Create the ground
terrain_system = terrain.RigidTerrain(vehicle_system)

# Create the visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle('HMMWV Simulation')
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(10, 5, 0), chrono.ChVectorD(0, 0, 0))
vis.AddTypicalLights()
vis.AttachSystem(vehicle_system.GetSystem())
vis.AttachSystem(terrain_system.GetSystem())

# =============================================================================
# Create the terrain
# =============================================================================

# Terrain dimensions
terrain_length = 100.0  # meters
terrain_width = 100.0   # meters

# Terrain texture
terrain_texture = "concrete.jpg"

# Create the terrain body
terrain_body = terrain.RigidTerrain.CreateBodyGround(
    vehicle_system.GetSystem(),
    chrono.ChContactMethod_NSC,
    terrain_length,
    terrain_width,
    terrain_texture
)

# =============================================================================
# Create the HMMWV vehicle
# =============================================================================

# Vehicle location and orientation
vehicle_location = chrono.ChVectorD(0, 0.5, 0)
vehicle_rotation = chrono.ChQuaternionD(1, 0, 0, 0)  # Default orientation

# Create the HMMWV vehicle
hmmwv = veh.HMMWV()
hmmwv.SetContactMethod(chrono.ChContactMethod_NSC)
hmmwv.SetChassisFixed(False)
hmmwv.SetInitPosition(chrono.ChCoorSysD(vehicle_location, vehicle_rotation))
hmmwv.SetTireType(veh.TireModelType::TMEASY)
hmmwv.SetTireStepSize(step_size)
hmmwv.Initialize(vehicle_system.GetSystem(), vehicle_location, vehicle_rotation)

# Set visualization type for vehicle components
hmmwv.SetChassisVisualizationType(veh.VisualizationType_PRIMITIVES)
hmmwv.SetSuspensionVisualizationType(veh.VisualizationType_PRIMITIVES)
hmmwv.SetSteeringVisualizationType(veh.VisualizationType_PRIMITIVES)
hmmwv.SetWheelVisualizationType(veh.VisualizationType_PRIMITIVES)

# Add the HMMWV to the vehicle system
vehicle_system.AddVehicle(hmmwv)

# =============================================================================
# Create the interactive driver system
# =============================================================================

# Create the driver system
driver_system = driver.ChInteractiveDriverIRR(vis.GetApplication())

# Set initial driver inputs
driver_system.SetSteeringDelta(0.0)
driver_system.SetThrottleDelta(0.0)
driver_system.SetBrakingDelta(0.0)

# =============================================================================
# Simulation loop
# =============================================================================

# Number of simulation steps
num_steps = int(t_end / step_size)

# Initialize simulation frame counter
step_number = 0

# Simulation loop
while vis.Run() and step_number < num_steps:
    # Get current simulation time
    time = step_number * step_size

    # Update driver inputs
    driver_system.Synchronize(time)
    steering = driver_system.GetSteering()
    throttle = driver_system.GetThrottle()
    braking = driver_system.GetBraking()

    # Apply driver inputs to the vehicle
    hmmwv.SetDriverInput(steering, throttle, braking)

    # Update the vehicle system
    vehicle_system.Update(step_size)

    # Update the terrain system
    terrain_system.Update(step_size)

    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Increment step counter
    step_number += 1

# =============================================================================
# Clean up
# =============================================================================

vis.Close()
```

## Explanation:

1. **Initialization**:
   - We import all necessary PyChrono modules
   - Set simulation parameters (step size, duration)
   - Create the vehicle system, terrain system, and visualization system

2. **Terrain Setup**:
   - Create a flat rigid terrain with specified dimensions (100x100 meters)
   - Add a concrete texture to the terrain

3. **Vehicle Setup**:
   - Create an HMMWV vehicle with TMEASY tire model
   - Set initial position and orientation
   - Configure primitive visualization for all components
   - Add the vehicle to the simulation system

4. **Driver System**:
   - Create an interactive driver system for user control
   - Initialize steering, throttle, and braking inputs

5. **Simulation Loop**:
   - Runs at 50 FPS (0.02 second step size)
   - Updates driver inputs from user interaction
   - Applies inputs to the vehicle
   - Updates vehicle and terrain systems
   - Renders the scene in real-time

6. **Cleanup**:
   - Properly closes the visualization system when done

This script creates a complete HMMWV simulation with interactive controls, realistic tire modeling, and proper visualization. The vehicle can be driven using keyboard inputs (typically arrow keys for steering and W/S for throttle/braking in the Irrlicht viewer).
