# PyChrono Simple Pendulum Simulation

Here's a complete script for simulating a simple pendulum using PyChrono with Irrlicht visualization:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np
import time

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("PATH_TO_CHRONO_DATA")  # Set the path to Chrono data directory

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add the required physical systems and objects

# Create the ground body
ground = chrono.ChBodyEasyBox(4, 0.5, 4, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# Create the pendulum bob
pendulum_length = 2.0
bob_radius = 0.1
bob_mass = 1.0

# Calculate moment of inertia for a sphere (I = 2/5 * m * r^2)
bob_inertia = (2.0/5.0) * bob_mass * bob_radius**2

pendulum = chrono.ChBodyEasySphere(bob_radius, bob_mass, True, True)
pendulum.SetPos(chrono.ChVectorD(0, 0, 0))
pendulum.SetInertiaXX(chrono.ChVectorD(bob_inertia, bob_inertia, bob_inertia))
system.Add(pendulum)

# Create the revolute joint (pendulum pivot)
pivot_point = chrono.ChVectorD(0, 0, 0)
joint = chrono.ChLinkLockRevolute()
joint.Initialize(ground, pendulum, chrono.ChFrameD(pivot_point))
system.Add(joint)

# 3. Set up visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Simple Pendulum Simulation')
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(5, 2, 0))
vis.AddTypicalLights()

# Create a custom application to handle visualization and logging
class PendulumApp(chronoirr.ChIrrApp):
    def __init__(self, system, vis):
        super().__init__(system, vis)
        self.time_step = 0.01
        self.log_interval = 0.1  # seconds
        self.last_log_time = 0

    def Advance(self, step):
        # Log pendulum state periodically
        current_time = self.GetDevice().getTimer().getTime() / 1000.0
        if current_time - self.last_log_time >= self.log_interval:
            # Get pendulum position and velocity
            pos = self.system.Get_bodylist()[1].GetPos()
            vel = self.system.Get_bodylist()[1].GetPos_dt()

            print(f"Time: {current_time:.2f}s")
            print(f"Position: ({pos.x:.3f}, {pos.y:.3f}, {pos.z:.3f})")
            print(f"Velocity: ({vel.x:.3f}, {vel.y:.3f}, {vel.z:.3f})")
            print("---")

            self.last_log_time = current_time

        # Advance simulation
        self.DoStepDynamics(self.time_step)

# Create and run the application
app = PendulumApp(system, vis)

# Give the pendulum an initial push
pendulum.SetPos_dt(chrono.ChVectorD(0.5, 0, 0))  # Initial velocity

# Run the simulation
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    app.Advance(0.01)
```

## Key Features of This Implementation:

1. **Physical System Setup**:
   - Creates a ChSystemNSC (non-smooth contact) system with gravity
   - Sets up a fixed ground body and a spherical pendulum bob

2. **Pendulum Properties**:
   - Configures mass, radius, and calculates proper inertia for a sphere
   - Positions the pendulum at the origin (0,0,0)

3. **Joint Configuration**:
   - Uses a ChLinkLockRevolute to create a perfect pivot joint
   - Connects the pendulum to the ground at the origin

4. **Visualization**:
   - Uses Irrlicht for real-time 3D rendering
   - Sets up camera, lights, and basic scene elements

5. **Logging System**:
   - Periodically logs the pendulum's position and velocity
   - Custom application class handles both simulation and visualization

6. **Initial Conditions**:
   - Gives the pendulum an initial push to start the motion

To run this simulation, you'll need to:
1. Have PyChrono properly installed
2. Set the correct path to Chrono data files
3. Have the Irrlicht visualization dependencies available

The simulation will show a pendulum swinging in 3D space with periodic console output of its state.
