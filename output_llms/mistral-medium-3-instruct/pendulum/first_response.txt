# PyChrono Simple Pendulum Simulation

Below is a complete Python script that creates a simple pendulum simulation using PyChrono with Irrlicht visualization:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np
import time

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("PATH_TO_CHRONO_DATA")  # Update this path to your Chrono data directory

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add the required physical systems and objects

# Create the ground body
ground = chrono.ChBodyEasyBox(10, 0.5, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# Create the pendulum bob
pendulum_length = 2.0
bob_radius = 0.2
bob_mass = 1.0

bob = chrono.ChBodyEasySphere(bob_radius, bob_mass, True, True)
bob.SetPos(chrono.ChVectorD(pendulum_length, 0, 0))

# Calculate inertia for the sphere (I = 2/5 * m * r^2 for solid sphere)
bob_inertia = (2.0/5.0) * bob_mass * bob_radius**2
bob.SetInertiaXX(chrono.ChVectorD(bob_inertia, bob_inertia, bob_inertia))

system.Add(bob)

# Create the revolute joint at the pivot point
pivot_point = chrono.ChVectorD(0, 0, 0)
joint = chrono.ChLinkLockRevolute()
joint.Initialize(ground, bob, chrono.ChFrameD(pivot_point))
system.Add(joint)

# 3. Set up visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Simple Pendulum Simulation")
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(0, 0, 6))
vis.AddTypicalLights()
vis.AddLightWithShadow(chrono.ChVectorD(5, 10, 5), chrono.ChVectorD(0, 0, 0), 15, 1, 15, 40, 512)

# Create some markers for visualization
marker_pivot = chrono.ChMarker(chrono.ChFrameD(pivot_point))
system.Add(marker_pivot)

# Simulation parameters
time_step = 0.01
sim_time = 10.0
output_freq = 10  # Output every 10 steps

# Simulation loop
current_time = 0
output_step = 0

while vis.Run() and current_time < sim_time:
    # Advance simulation for one timestep
    system.DoStepDynamics(time_step)

    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Periodically log the pendulum's position and velocity
    output_step += 1
    if output_step % output_freq == 0:
        bob_pos = bob.GetPos()
        bob_vel = bob.GetPos_dt()
        print(f"Time: {current_time:.2f}s")
        print(f"  Position: ({bob_pos.x:.3f}, {bob_pos.y:.3f}, {bob_pos.z:.3f})")
        print(f"  Velocity: ({bob_vel.x:.3f}, {bob_vel.y:.3f}, {bob_vel.z:.3f})")
        print("---")

    current_time += time_step
    time.sleep(time_step)  # Slow down simulation for better visualization

print("Simulation completed.")
```

## Key Components Explained:

1. **System Setup**:
   - Uses `ChSystemNSC` (non-smooth contact) for the physical system
   - Sets gravity to Earth's standard gravity (9.81 m/s² downward)

2. **Bodies**:
   - **Ground**: A fixed box body to serve as the pendulum's base
   - **Pendulum Bob**: A spherical body with proper mass and inertia properties

3. **Joint**:
   - `ChLinkLockRevolute` creates a revolute joint at the pivot point (0,0,0)
   - Connects the ground to the pendulum bob

4. **Visualization**:
   - Uses Irrlicht for real-time visualization
   - Includes camera, lights, and skybox for better visual quality
   - Adds a marker at the pivot point

5. **Simulation Loop**:
   - Runs for 10 simulated seconds with 0.01s time steps
   - Periodically logs the pendulum's position and velocity
   - Includes a small sleep to make visualization smoother

To run this script, you'll need to:
1. Install PyChrono (with Irrlicht support)
2. Set the correct path to your Chrono data directory
3. Have the required dependencies installed

The simulation will show a pendulum swinging under gravity, with periodic output of its state to the console.
