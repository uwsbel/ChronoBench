# PyChrono Epicyclic Gear Simulation

Below is a complete PyChrono script that simulates an epicyclic gear system with a fixed truss, rotating bar, and two gears (one with a motor). The simulation includes visualization using Irrlicht.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("PATH_TO_CHRONO_DATA")  # Update this path

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))  # Set gravity

# 2. Add physical systems and objects

# Create the fixed truss (ground)
truss = chrono.ChBody()
truss.SetBodyFixed(True)
truss.SetCollide(True)
truss.GetVisualModel().AddBox(0.5, 0.5, 0.1, chrono.ChVectorD(0, 0, -0.05))
truss.GetVisualModel().AddBox(0.1, 0.1, 0.5, chrono.ChVectorD(0, 0, 0.2))
system.Add(truss)

# Create the rotating bar (carrier)
bar = chrono.ChBody()
bar.SetMass(1.0)
bar.SetInertiaXX(chrono.ChVectorD(0.1, 0.1, 0.01))
bar.SetPos(chrono.ChVectorD(0, 0, 0.5))
bar.SetCollide(True)
bar.GetVisualModel().AddCylinder(0.05, 0.5, chrono.ChVectorD(0, 0, 0),
                                chrono.ChVectorD(0, 0, 1), chrono.ChColor(0.5, 0.5, 0.8))
system.Add(bar)

# Create a revolute joint to attach the bar to the truss
revolute = chrono.ChLinkLockRevolute()
revolute.Initialize(truss, bar, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0.5)))
system.Add(revolute)

# Create the sun gear (fixed to the truss)
sun_gear = chrono.ChBody()
sun_gear.SetBodyFixed(True)
sun_gear.SetCollide(True)
sun_gear.GetVisualModel().AddCylinder(0.1, 0.05, chrono.ChVectorD(0, 0, 0.5),
                                     chrono.ChVectorD(0, 0, 1), chrono.ChColor(0.8, 0.2, 0.2))
system.Add(sun_gear)

# Create the planet gear (attached to the bar)
planet_gear = chrono.ChBody()
planet_gear.SetMass(0.5)
planet_gear.SetInertiaXX(chrono.ChVectorD(0.01, 0.01, 0.01))
planet_gear.SetPos(chrono.ChVectorD(0.2, 0, 0.5))
planet_gear.SetCollide(True)
planet_gear.GetVisualModel().AddCylinder(0.05, 0.05, chrono.ChVectorD(0, 0, 0),
                                        chrono.ChVectorD(0, 0, 1), chrono.ChColor(0.2, 0.8, 0.2))
system.Add(planet_gear)

# Create a revolute joint between the bar and planet gear
planet_revolute = chrono.ChLinkLockRevolute()
planet_revolute.Initialize(bar, planet_gear, chrono.ChCoordsysD(chrono.ChVectorD(0.2, 0, 0.5)))
system.Add(planet_revolute)

# Create gear constraints
# Gear ratio: sun_gear_radius / planet_gear_radius = 0.1 / 0.05 = 2
gear_constraint = chrono.ChLinkGear()
gear_constraint.Initialize(sun_gear, planet_gear, 2.0, chrono.ChVectorD(0, 0, 1), chrono.ChVectorD(0, 0, 1))
system.Add(gear_constraint)

# Add a motor to rotate the bar
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(bar, truss, chrono.ChFrameD(chrono.ChVectorD(0, 0, 0.5)))
motor.SetMotorFunction(chrono.ChFunction_Const(1.0))  # 1 rad/s constant speed
system.Add(motor)

# 3. Set up visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Epicyclic Gear System")
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(0.5, 1.5, 0.5), chrono.ChVectorD(0, 0, 0.5))
vis.AddTypicalLights()
vis.AddLight(chrono.ChVectorD(2, 2, 2), chrono.ChVectorD(0, 0, 0.5), 10, chrono.ChColor(1, 1, 1))
vis.SetSymbolScale(0.01)

# Simulation loop
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Advance simulation by 0.01 seconds
    system.DoStepDynamics(0.01)
```

## Key Components Explained:

1. **Physical System Setup**:
   - Creates a ChSystemNSC (non-smooth contact dynamics)
   - Sets gravity to Earth's standard value

2. **Fixed Truss**:
   - Serves as the ground/base of the system
   - Has a box shape for visualization

3. **Rotating Bar (Carrier)**:
   - Represents the carrier in an epicyclic gear system
   - Connected to the truss with a revolute joint
   - Has a motor to enforce constant rotation

4. **Gears**:
   - Sun gear (fixed to the truss)
   - Planet gear (attached to the rotating bar)
   - Gear constraint enforces proper gear ratio (2:1 in this case)

5. **Visualization**:
   - Uses Irrlicht for 3D rendering
   - Includes lighting, camera setup, and materials
   - Real-time visualization of the gear system

To run this simulation, you'll need to:
1. Install PyChrono (with Irrlicht support)
2. Update the data path to point to your Chrono data directory
3. Run the script in a Python environment

The simulation will show the planet gear rotating around the fixed sun gear while also spinning on its own axis, demonstrating the epicyclic motion.
