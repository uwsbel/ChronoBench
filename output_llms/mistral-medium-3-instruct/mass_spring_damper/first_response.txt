# PyChrono Mass-Spring-Damper System Simulation

Here's a complete PyChrono script that demonstrates a single mass-spring-damper system with visualization:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath('PATH_TO_CHRONO_DATA')  # Set this to your Chrono data directory

# Create a Chrono physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add the required physical systems and objects

# Create the ground body (fixed)
ground = chrono.ChBody()
ground.SetBodyFixed(True)
system.Add(ground)

# Create the mass body (dynamic)
mass = chrono.ChBody()
mass.SetMass(1.0)  # 1 kg mass
mass.SetInertiaXX(chrono.ChVectorD(0.1, 0.1, 0.1))  # Small inertia
mass.SetPos(chrono.ChVectorD(0, 1, 0))  # Initial position
system.Add(mass)

# Create the spring-damper connection between ground and mass
spring_damper = chrono.ChLinkTSDA()
spring_damper.Initialize(
    mass,  # Body 1 (the mass)
    ground,  # Body 2 (the ground)
    True,  # Collision between bodies?
    chrono.ChVectorD(0, 0, 0),  # Point on body 1 (local coords)
    chrono.ChVectorD(0, 0, 0),  # Point on body 2 (local coords)
    False  # Automatic rest length calculation
)

# Set spring-damper parameters
spring_damper.SetSpringCoefficient(100.0)  # N/m
spring_damper.SetDampingCoefficient(5.0)   # Ns/m
spring_damper.SetRestLength(1.0)          # Rest length (m)

system.Add(spring_damper)

# 3. Set up visualization

# Create the Irrlicht application
application = chronoirr.ChIrrApp(system, 'Mass-Spring-Damper System', chronoirr.dimension2d(800, 600))

# Set camera position and look at
application.AddTypicalLogo()
application.AddTypicalSky()
application.AddTypicalLights()
application.AddTypicalCamera(chronoirr.vector3df(0, 0.5, 2), chronoirr.vector3df(0, 0, 0))

# Add visual assets for the ground
ground_visual = chrono.ChVisualShapeBox(2, 0.1, 2)
ground_visual.SetColor(chrono.ChColor(0.5, 0.5, 0.5))
ground.AddVisualShape(ground_visual)

# Add visual assets for the mass
mass_visual = chrono.ChVisualShapeBox(0.2, 0.2, 0.2)
mass_visual.SetColor(chrono.ChColor(0.8, 0.2, 0.2))
mass.AddVisualShape(mass_visual)

# Add visual assets for the spring (using a cylinder)
spring_visual = chrono.ChVisualShapeCylinder(0.05, 0.05, 1.0)
spring_visual.SetColor(chrono.ChColor(0.2, 0.8, 0.2))
spring_visual.SetOpacity(0.7)
spring_damper.AddVisualShape(spring_visual)

# Simulation loop
application.AssetBindAll()
application.AssetUpdateAll()

while application.GetDevice().run():
    application.BeginScene()
    application.DrawAll()
    application.DoStep()
    application.EndScene()
```

## Key Components Explained:

1. **System Setup**:
   - We create a `ChSystemNSC` (non-smooth contact) system with gravity
   - A fixed ground body and a dynamic mass body are created

2. **Spring-Damper Connection**:
   - `ChLinkTSDA` is used to connect the mass to the ground
   - Default parameters are set (spring constant = 100 N/m, damping = 5 Ns/m)
   - Rest length is set to 1.0 meter

3. **Visualization**:
   - Irrlicht visualization is set up with proper camera and lighting
   - Visual shapes are added for the ground (gray box), mass (red box), and spring (green cylinder)
   - The simulation runs in a loop with real-time visualization

4. **Simulation**:
   - The mass will oscillate vertically due to gravity and the spring-damper forces
   - Damping will gradually reduce the amplitude of oscillations

To run this script, you'll need to:
1. Have PyChrono installed with Irrlicht visualization support
2. Set the correct path to your Chrono data directory
3. Ensure all required dependencies are installed
