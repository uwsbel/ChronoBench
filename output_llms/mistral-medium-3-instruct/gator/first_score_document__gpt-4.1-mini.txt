The code uses two vectors, which is not consistent with the documented API for `AddPatch`. The typical usage is:  
  ```python

Usually, the driver reads user input and sets steering, throttle, and braking commands to the vehicle. Here, the driver is being set steering from the vehicle, which is logically reversed.
