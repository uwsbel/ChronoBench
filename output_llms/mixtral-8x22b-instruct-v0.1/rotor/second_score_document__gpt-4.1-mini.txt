  ```python
  ChBodyEasyCylinder(radius, height, density, visualize=True, collision=True, material=None)
  ```

  The first argument should be radius, not an axis. The code passes `chrono.ChAxis_Y` (an enum or vector) as the first argument, which is incorrect.

  This is a **major API misuse** that will cause the flywheel body to be incorrectly created or cause an error.

- **Motor function:** `rotmotor1.SetMotorFunction(f_ramp)` is called, but the API uses `SetSpeedFunction()`. This is a **minor API misuse**.
