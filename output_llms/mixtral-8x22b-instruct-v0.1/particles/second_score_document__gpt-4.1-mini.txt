### 2. Correctness (30 points)

- **Use of `ChContactMaterialNSC` in `ChBodyEasySphere`:** The constructor expects a material pointer, but `ChBodyEasySphere` does not take a material argument in the documented API; it takes density, visualize, collision flags. The code passes `sphere_mat` as the last argument, which is not standard. This is a significant API misuse.  
  According to the documentation, `ChBodyEasySphere(radius, density, visualize, collision, material)` is valid, but the material should be a `ChMaterialSurface` object, not `ChContactMaterialNSC`. The correct material type for NSC is `ChMaterialSurfaceNSC`. The code uses `ChContactMaterialNSC()`, which is a contact material, not a surface material. This is a **significant error** that could affect collision behavior.

- **Use of `body.GetVisualShape(0).SetTexture(...)`:** Correct usage.

- **Disabling gyro torque:** `body.SetUseGyroTorque(False)` is valid.

- **Particle emitter setup:** Correct usage of positioner, aligner, velocity, angular velocity, and shape creator.

- **Energy calculations:**

  - No check for zero distance in potential energy calculation, which could cause division by zero if two bodies overlap. This is a **logical error** (edge case not handled).

- **Clearing accumulators:** `body.EmptyAccumulators()` is called every step, which is correct.

- **Solver settings:** Uses PSOR solver with 40 max iterations, acceptable.

- **Gravity set to zero vector:** `sys.SetGravitationalAcceleration(chrono.ChVector3d(0, 0, 0))` is intentional for this simulation.
