The code passes `sphere_mat` which is a `ChContactMaterialNSC` instance. This is incorrect because `ChContactMaterialNSC` is not a `ChMaterialSurface`. The correct approach is to set the material surface on the body’s collision model or use the default material.  
  **Deduct 15 points for incorrect API usage that can affect collision behavior.**
