To create a PyChrono simulation demonstrating the use of beam finite elements, follow the steps below:

1. First, import the necessary modules and initialize the PyChrono environment and core components.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# Create a Chrono::Engine physical system
my_system = chrono.ChSystemNSC()

# Create an Irrlicht application
myapplication = chronoirr.ChIrrApp(my_system, 'PyChrono Beam Simulation', chronoirr.Dim3d(800, 600))
```

2. Now, create a mesh composed of beams and nodes with specific properties.

```python
# Define the number of nodes and beams
num_nodes = 10
num_beams = num_nodes - 1

# Define node positions
node_positions = np.zeros((num_nodes, 3))
node_positions[:, 0] = np.linspace(0, 1, num_nodes)
node_positions[:, 1] = np.zeros(num_nodes)
node_positions[:, 2] = np.zeros(num_nodes)

# Create nodes and beams
nodes = []
beams = []
for i in range(num_nodes):
    node = chrono.ChNodeFEAxyz(my_system)
    node.SetPos(chrono.ChVectorD(*node_positions[i]))
    nodes.append(node)
    if i < num_beams:
        beam = chrono.ChElementBeamEuler(nodes[i], nodes[i + 1])
        beam.SetDiameter(0.01)
        beam.SetYoungModulus(2.0e11)
        beam.SetGshearModulus(7.69e10)
        beam.SetRho(7850)
        beams.append(beam)
        my_system.Add(beam)
```

3. Set necessary default parameters such as positions, forces, and interactions.

```python
# Apply a force at the first node
force = chrono.ChForce()
force.SetMode(chrono.ChForce.FORCE)
force.Set_Fz(1000)
nodes[0].AddForce(force)

# Set the initial velocity of the first node
nodes[0].Set_V(chrono.ChVectorD(0, 0, 1))

# Add a fixed constraint to the last node
constraint = chrono.ChLinkDirframe()
constraint.Initialize(nodes[-1], my_system.GetGround(), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1))
my_system.Add(constraint)
```

4. Add visualization and run the simulation loop using the Irrlicht engine for real-time rendering.

```python
# Create a visualization asset for each node
node_assets = []
for node in nodes:
    node_asset = chronoirr.ChSphereShape()
    node_asset.GetSphereGeometry().rad = 0.02
    node_asset.SetColor(chrono.ChColor(1, 0, 0))
    node.AddAsset(node_asset)

# Create a visualization asset for each beam
beam_assets = []
for beam in beams:
    beam_asset = chronoirr.ChCylinderShape()
    beam_asset.GetCylinderGeometry().rad = 0.005
    beam_asset.GetCylinderGeometry().p2 = chrono.ChVectorD(0, 0, 0.05)
    beam_asset.SetColor(chrono.ChColor(0, 1, 0))
    beam.AddAsset(beam_asset)

# Run the simulation loop
myapplication.Run()
```

This script will create a PyChrono simulation with a mesh composed of beams and nodes, apply a force at the first node, set the initial velocity of the first node, add a fixed constraint to the last node, and visualize the simulation using the Irrlicht engine for real-time rendering.
