Here is a basic script that follows your instructions. Please note that you may need to adjust the script according to your specific requirements, such as the location of the Viper rover model, the terrain geometry, and the exact camera settings.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# Initialize the Chrono system
chrono.SetChronoDataPath("/path/to/chrono/data/")
my_system = chrono.ChSystemNSC()

# Set gravity
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body
ground = chrono.ChBodyEasyBox(20, 1, 20, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
my_system.AddBody(ground)

# Initialize the Viper rover
viper = chrono.ChBodyEasyBox(1, 0.5, 2, 100, True, True)
viper.SetPos(chrono.ChVectorD(0, 0, 0))
viper.SetRot(chrono.ChQuaternionD(1, 0, 0, 0))
my_system.AddBody(viper)

# Initialize the Viper rover's driver
driver = chrono.ChLinkMotorRotationSpeed()
driver.Initialize(ground, viper, chrono.ChVectorD(0, 1, 0), chrono.ChVectorD(0, 1, 0))
my_system.AddLink(driver)

# Set up the real-time visualization
visualizer = chronoirr.ChIrrApp(my_system, "Viper Rover Simulation", chronoirr.Dimensions(800, 600))
visualizer.AddTypicalLogo()
visualizer.AddTypicalSky()
visualizer.AddTypicalLights()
visualizer.AddTypicalCamera(chronoirr.OrbitCamera(chrono.ChVectorD(0, 5, -10), chrono.ChVectorD(0, 0, 0)))

# Simulation loop
sim_time = 0
total_time = 10
steering_change_time = 5
steering_change_rate = 180  # degrees per second

while (visualizer.GetDevice().run() and (sim_time < total_time)):
    # Update the steering
    if (sim_time < steering_change_time):
        driver.Set_speed_reference(steering_change_rate * sim_time / steering_change_time)
    else:
        driver.Set_speed_reference(steering_change_rate)

    # Update the system
    my_system.DoStepDynamics(0.01)
    sim_time += 0.01

    # Render the scene
    visualizer.BeginScene()
    visualizer.DrawAll()
    visualizer.EndScene()

# Close the visualizer
visualizer.GetDevice().closeDevice()
```

This script creates a simple simulation with a Viper rover on a flat ground. The rover's steering gradually changes over the first 5 seconds of the simulation, and then remains constant. The simulation is visualized in real-time using Irrlicht.
