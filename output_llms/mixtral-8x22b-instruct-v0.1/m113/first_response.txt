```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize PyChrono and Irrlicht
chrono.SetChronoDataPath("/path/to/chrono/data")
application = chronoirr.ChIrrApp(chronoirr.NullMaterial(), chronoirr.GetChronoDataPath() + "IRRLICHT/")

# Create the physical systems
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# Create the M113 vehicle
vehicle = chrono.ChVehicleM113()
vehicle.SetContactMaterial(0.9, 0.01)  # Friction and restitution
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(chrono.ChVectorD(0, 0, 0.5))
system.Add(vehicle)

# Create the rigid terrain
terrain = chrono.ChBodyEasyBox(20, 20, 1, 1000, True, True)
terrain.SetBodyFixed(True)
terrain.SetFriction(0.9)
terrain.SetRestitution(0.01)
system.Add(terrain)

# Create the driver system
driver = chrono.ChIrrGuiDriver()
driver.Initialize(application)
driver.SetCamera(chrono.ChVectorD(10, 10, 5), chrono.ChVectorD(0, 0, 0))
driver.SetLight(chrono.ChVectorD(10, 10, 10), chrono.ChVectorD(0, 0, 0), 1, 0, 100)

# Implement the simulation loop
application.SetTimestep(0.02)
while application.GetDevice().run():
    system.DoStepDynamics(application.GetTimestep())
    driver.BeginScene()
    driver.DrawAll()
    driver.EndScene()

application.GetSystem().Kill()
```

This script creates an M113 vehicle, a rigid terrain, and a driver system for controlling the vehicle and visualizing the simulation. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution. You may need to adjust the parameters, such as the initial position of the vehicle and the camera settings, to better suit your specific requirements.
