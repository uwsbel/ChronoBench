Here is a basic script that should meet your requirements. Please note that you may need to adjust the parameters to fit your specific needs. Also, you will need to have PyChrono and Irrlicht installed and properly configured in your Python environment.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle
import pychrono.fea as chrono_fea
import pychrono.postprocess as chrono_postprocess

# ---------------------------------------------------------------------
# Create the PyChrono physical system

my_system = chrono.ChSystemNSC()

# ---------------------------------------------------------------------
# Create the Irrlicht application

myapplication = chronoirr.ChIrrApp(my_system, 'HMMWV Demo', chronoirr.Dim3d(800, 600))

# ---------------------------------------------------------------------
# Create the HMMWV vehicle

m_vehicle = chronovehicle.ChVehicle.FromFile('HMMWV_TMEasy.xml')

# Set the location and orientation
m_vehicle.SetPos(chrono.ChVectorD(0, 0, 0.5))
m_vehicle.SetRot(chrono.ChQuaternionD(1, 0, 0, 0))

# Add the vehicle to the system
m_system.Add(m_vehicle)

# ---------------------------------------------------------------------
# Create the terrain

terrain = chrono.ChRigidTerrain(chrono.GetPhysicsItemSettings())
terrain.SetTexture(chrono.GetChronoDataFile('terrain/textures/tarmac.jpg'), 200, 200)
terrain.Initialize(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(1, 0, 0), chrono.ChVectorD(0, 1, 0), 100, 100, 10)
my_system.Add(terrain)

# ---------------------------------------------------------------------
# Create the driver system

driver = chronovehicle.ChIrrGuiDriver(m_vehicle)

# ---------------------------------------------------------------------
# Set up the simulation loop

myapplication.AddTypicalSproingyGround(my_system.Get_ground())
myapplication.AddTypicalLights()
myapplication.AddTypicalCamera(chrono.ChVectorD(0, 0, 1.5))
myapplication.AddSkyBox()
myapplication.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
myapplication.AddShadowAll()

myapplication.SetTimestep(0.02)

while myapplication.Run():
    my_system.DoStepDynamics(0.02)
    myapplication.BeginScene()
    myapplication.DrawAll()
    myapplication.DoStep()
    myapplication.EndScene()

myapplication.Stop()
```

This script will create a PyChrono simulation of a HMMWV on a flat rigid terrain using Irrlicht for visualization. The vehicle is initialized with specific parameters such as location, orientation, contact method, and TMEASY tire model. The script also sets up a RigidTerrain with defined dimensions and texture, and configures an interactive driver system for steering, throttle, and braking. The simulation loop runs in real time at 50 frames per second, updating the vehicle dynamics and rendering the scene.
