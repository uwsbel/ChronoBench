Here is a basic script that follows your instructions. Please note that you will need to adjust the script according to your specific requirements, such as the exact location, orientation, and tire model of the vehicle, as well as the texture for the terrain.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# Initialize PyChrono and Irrlicht
my_application = chronoirr.ChIrrApp(chronoirr.NullCamera(), "Chrono Vehicle Demo", chrono.Dimensions(800, 600))

# Create a vehicle system
vehicle_system = chrono.ChSystemNSC()

# Create a rigid terrain
terrain = chrono.ChRigidTerrain(vehicle_system.GetGroundBody())
terrain.SetTexture(chrono.ChTexture(chrono.GetChronoDataFile("terrain/textures/concrete.jpg")))

# Create a city bus vehicle
city_bus = chrono.ChVehicle(chrono.ChBodyEasyCylinder(2.0, 0.5, 1000, 500, True, True))
city_bus.SetName("CityBus")
city_bus.SetChassisFixed(False)
city_bus.SetChassisPosition(chrono.ChVectorD(0, 0, 1.5))
city_bus.SetChassisOrientation(chrono.ChQuaternionD(1, 0, 0, 0))
city_bus.SetTireType(chrono.ChVehicleTire.Type_TMEASY)

# Add the vehicle to the system
vehicle_system.Add(city_bus)

# Add the terrain to the system
vehicle_system.Add(terrain)

# Create a driver system
driver = chrono.ChIrrGuiDriver(my_application, vehicle_system)

# Set the camera to follow the vehicle
my_application.AddTypicalCamera(chrono.ChVectorD(0, 0, 5))

# Set the simulation parameters
driver.SetSleep(False)
driver.SetTimestep(0.02)

# Run the simulation
my_application.SetTimestep(0.02)
my_application.SetTryRealtime(True)
my_application.Run()
```

This script initializes the PyChrono environment and core components, adds a CityBus vehicle and a rigid terrain, sets the vehicle's position and orientation, and implements a driver system that allows for control of the vehicle's steering, throttle, and braking. The simulation runs at 50 frames per second and updates the vehicle dynamics and renders the scene in real time. The camera follows the vehicle from a specified position.
