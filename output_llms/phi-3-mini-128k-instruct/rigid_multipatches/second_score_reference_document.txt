- **Terrain visual mesh creation:**

  - The reference script correctly loads a `ChTriangleMeshConnected` from the OBJ file and sets it via `SetMesh()`.
  - This is an incorrect API usage that will likely cause the visual mesh not to render correctly.
  - **Deduction: 15 points** for incorrect use of visual mesh API.

  - No additional deduction here.
