### 2. Correctness (30 points)

- **Force Calculation:**

  - `G_constant` is assigned **after** it is used in the force and potential energy calculations. This is a logical error. The constant should be defined before use. **Deduct 10 points for logical error.**

  - `D_attract` is used but never defined anywhere. This will cause a runtime error. **Deduct 15 points for incorrect API usage / missing variable.**

  - The force vector `F_attract` is computed as `(D_attract / r_attract) * f_attract`, but `f_attract` is a scalar magnitude. Multiplying a scalar by a scalar does not produce a vector force. The force vector should be along the direction vector `(abodyB.GetPos() - abodyA.GetPos())` normalized. This is a significant error in physics force application. **Deduct 15 points for incorrect force vector calculation.**

- **Kinetic Energy Calculation:**

  - Uses `body.GetLinearVelocity().Length2()`, which returns the squared length of velocity vector, so kinetic energy is `0.5 * m * v^2`. This is correct. **No deduction.**
