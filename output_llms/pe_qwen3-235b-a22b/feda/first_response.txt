```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as chronoirr

# Initialize the PyChrono system
sys = chrono.ChSystemNSC()

# Set up Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('FEDA Vehicle Simulation')
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(0, 3, 6), chrono.ChVector3d(0, 0, 0))  # Camera follows vehicle
vis.AddTypicalLights()
vis.Initialize()

# Create rigid terrain with custom texture
terrain_mat = chrono.ChContactMaterialNSC()
terrain = veh.RigidTerrain(sys)
patch = terrain.AddPatch(terrain_mat, chrono.ChCoordsysd(chrono.ChVector3d(0, 0, 0), chrono.QUNIT), 100, 100)
patch.SetTexture(chrono.GetChronoDataFile("terrain/textures/tile.png"))  # Custom texture
terrain.Initialize()

# Initialize FEDA vehicle with mesh visualization
car = veh.FEDA(sys)
car.SetContactMethod(chrono.ChContactMethod_NSC)
car.SetChassisCollisionType(veh.ChassisCollisionType_NONE)
car.SetChassisVisualizationType(veh.VisualizationType_MESH)
car.SetSuspensionVisualizationType(veh.VisualizationType_MESH)
car.SetSteeringVisualizationType(veh.VisualizationType_MESH)
car.SetWheelVisualizationType(veh.VisualizationType_MESH)
car.SetTireType(veh.TireModelType_TMEASY)
car.SetTireVisualizationType(veh.VisualizationType_MESH)
car.SetInitPosition(chrono.ChCoordsysd(chrono.ChVector3d(0, 0.5, 0), chrono.QuatFromAngleZ(chrono.CH_PI)))
car.Initialize()

# Set up interactive driver system
driver = veh.ChDriverIRR(vis.GetDevice(), car.GetVehicle())
driver.Initialize()

# Simulation loop at 50 FPS
time_step = 0.02  # 1/50 seconds
while vis.Run():
    time = sys.GetChTime()
    
    # Synchronize driver inputs and vehicle dynamics
    driver_inputs = driver.GetInputs()
    driver.Synchronize(time)
    car.Synchronize(time, driver_inputs, time_step)
    
    # Advance simulation
    sys.DoStepDynamics(time_step)
    
    # Render scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
```

---

### **Explanation of Key Components**

1. **System Initialization**:
   - `chrono.ChSystemNSC()` is used for non-smooth contact handling, suitable for vehicle-terrain interactions.

2. **Visualization Setup**:
   - **Camera**: Positioned at `(0, 3, 6)` to follow the vehicle from a rear perspective.
   - **Skybox & Lights**: Enhance realism and visibility in the scene.

3. **Rigid Terrain**:
   - A `RigidTerrain` patch is created with a custom texture (`tile.png`) from Chrono's data directory.

4. **FEDA Vehicle Configuration**:
   - **Mesh Visualization**: All components (chassis, suspension, wheels, tires) use `VisualizationType_MESH`.
   - **Tire Model**: Uses the `TMEASY` tire model for realistic road interaction.
   - **Initial Position**: Placed at `(0, 0.5, 0)` with a 180° rotation around the Z-axis.

5. **Interactive Driver**:
   - `ChDriverIRR` captures keyboard inputs (WASD for steering/throttle/braking) via Irrlicht's device.

6. **Simulation Loop**:
   - Runs at **50 FPS** with a fixed time step of `0.02` seconds.
   - Updates vehicle dynamics, driver inputs, and renders the scene in real-time.

---

### **Customization Notes**
- **Texture Path**: Replace `"terrain/textures/tile.png"` with a custom texture path if needed.
- **Camera**: Adjust the camera position (`ChVector3d(0, 3, 6)`) for different viewing angles.
- **Tire Model**: Switch to `RIGID` or `TMSIMPLE` if a simpler tire model is preferred.

This script provides a complete, interactive vehicle simulation with mesh-based visualization and real-time control.
