  The first argument should be dimensions or radius, not the system. The system is not passed to the constructor.

  The revolute joint is created as `chrono.ChLinkRevolute()`, but the API specifies `ChLinkLockRevolute()` for revolute joints.

  But the API expects:

  ```python
  joint.Initialize(body1, body2, chrono.ChCoordsysD(position, rotation))
  ```
