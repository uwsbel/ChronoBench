### 2. Correctness (30 points)

- **API Usage:**  
  - `veh.MAN_10t()` is correctly used and initialized.  
  - Visualization system is correctly created and attached.  
  - Terrain patch material is created with NSC material and friction/restitution set properly.  
  - Boxes are created with `ChBodyEasyBox` but the constructor is used incorrectly:  
    The signature from docs is:  
    ```python
    chrono.ChBodyEasyBox(lengthX, lengthY, lengthZ, density, visualize, collision, material)
    ```  
    But in the code:  
    ```python
    box = chrono.ChBodyEasyBox(vehicle.GetSystem(), box_size, 1000, True)
    ```  
    Here, `vehicle.GetSystem()` is passed as the first argument, which is incorrect. The first argument should be lengthX (float), not a system object. Also, `box_size` is a `ChVector3d`, but the constructor expects three floats for dimensions.  
    This is a **significant API misuse** that would cause runtime errors or incorrect box creation.  
    **Deduct 15 points for incorrect use of `ChBodyEasyBox`.**

- **Box Mass Setting:**  
  The code calls `box.SetMass(box_mass)` after creating the box with density 1000. This is acceptable if the user wants to override mass, but the box inertia is not updated accordingly. This can cause incorrect dynamics.  
  **Deduct 10 points for logical error: mass set without updating inertia tensor.**

- **Box Material:**  
  The boxes are assigned a new `ChMaterialSurfaceNSC()` without setting friction or other parameters. This is not incorrect but suboptimal. No deduction here.

- **Driver Input Handling:**  
  Driver inputs are retrieved but not used explicitly in the synchronization calls. However, the vehicle's `Synchronize` method uses them, so this is correct.

- **Visualization Synchronization:**  
  `vis.Synchronize(time, driver_inputs)` is called, which is correct.

- **Sensor Manager Update:**  
  Sensor manager is updated every loop, which is correct.

- **Real-time Timer:**  
  `realtime_timer.Spin(step_size)` is used correctly.

- **Other minor API calls:**  
  No other significant API misuse detected.
