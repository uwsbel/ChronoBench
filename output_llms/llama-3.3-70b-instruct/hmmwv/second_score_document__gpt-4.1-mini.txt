### 2. Correctness (30 points)

- **System Initialization:**  
  No explicit system creation is a minor correctness issue but not critical here.

- **Vehicle Initialization:**  
  Correct use of `SetContactMethod`, `SetChassisCollisionType`, `SetInitPosition`, `SetTireType`, `SetTireStepSize`, and `Initialize()`.

- **Collision System Type:**  
  The collision system type is set after vehicle initialization via `vehicle.GetSystem().SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)`. According to best practices, collision system type should be set before adding bodies or initializing the vehicle to ensure proper collision system setup. Setting it afterward may not have the intended effect.  
  **Deduction:** -10 points (logical error affecting simulation behavior).

- **PID Steering Control:**  
  The steering angle is computed as:  
  ```python
  error = (target_point - vehicle.GetChassisBody().GetPos()).Length()
  steering_angle = Kp * error + Ki * error * step_size + Kd * (error - (target_point - vehicle.GetChassisBody().GetPos()).Length()) / step_size
  ```  
  The derivative term `(error - (target_point - vehicle.GetChassisBody().GetPos()).Length()) / step_size` is always zero because the expression subtracts the same value from itself in the same iteration (no stored previous error). This is a logical error in the PID implementation.  
  **Deduction:** -10 points (logical error in control logic).

- **Use of `ChBodyEasySphere`:**  
  The constructor is called as:  
  ```python
  chrono.ChBodyEasySphere(vehicle.GetSystem(), 1.0, 1000, chrono.ChVector3d(...), chrono.ChColor(...))
  ```  
  According to the API, `ChBodyEasySphere` signature is:  
  ```python
  ChBodyEasySphere(radius, density, visualize=True, collision=True, material=None)
  ```  
  The script passes `vehicle.GetSystem()` as the first argument, which is incorrect. The system is not a parameter to `ChBodyEasySphere`. Instead, the created body must be added to the system via `sys.Add(body)`.  
  This is a significant API misuse and will cause errors or unexpected behavior.  
  **Deduction:** -15 points (incorrect API usage).

- **Setting Steering Angle:**  
  `vehicle.GetSteering().SetSteering(steering_angle)` is correct usage.

- **Throttle Setting:**  
  `vehicle.GetTransmission().SetThrottle(throttle)` is correct.

- **Advancing Simulation:**
