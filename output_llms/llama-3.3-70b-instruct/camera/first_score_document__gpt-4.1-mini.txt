  is incorrect. According to the PyChrono API, there is no `ChBodyEasyMesh` constructor that takes `(sys, mesh, ...)`. The typical way to create a body from a mesh is to create a `ChBody()`, then add the mesh as a visual shape or collision shape, or use `ChBodyEasyBox`, `ChBodyEasySphere`, etc.
