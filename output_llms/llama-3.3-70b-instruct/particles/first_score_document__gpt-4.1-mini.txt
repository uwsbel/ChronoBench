### 1. Completeness (40 points)

- **System Initialization**:  
  The script uses `chrono.ChSystem()`. According to the documentation, the recommended system classes are `chrono.ChSystemNSC()` or `chrono.ChSystemSMC()`. The base `ChSystem()` is not documented and likely deprecated or incomplete.  
  **Deduction: 15 points** (missing essential component: correct system initialization)

- **Body Creation**:  
  Bodies are created using `chrono.ChBodyEasySphere`, `chrono.ChBodyEasyBox`, and `chrono.ChBodyEasyCylinder`. However, the constructors are called incorrectly:  
  - The documented signature is:  
    `ChBodyEasySphere(radius, density, visualize, collision, material=None)`  
    but the code calls:  
    `chrono.ChBodyEasySphere(sys, 0.1, 1000, True)`  
    passing `sys` as the first argument, which is incorrect.  
  Similarly for box and cylinder, the arguments are not matching the documented API.  
  **Deduction: 15 points** (incorrect use of body constructors)

- **Visualization Setup**:  
  The visualization system is created and configured, but **`vis.AttachSystem(sys)`** is missing, which is essential to link the physical system to the visualization. Also, **`vis.Initialize()`** is not called before the simulation loop, which is necessary to prepare the visualization system.  
  **Deduction: 15 points** (missing essential visualization setup steps)

- **Force Application**:  
  The custom gravitational force is implemented as a subclass of `chrono.ChForce`. However, the method `ComputeF` is not a documented or standard method to override for applying forces in PyChrono. The typical way to apply forces is to override `Update` or use `AddForce` with a force vector. Also, the force calculation ignores the masses of the particles and applies a force proportional only to position difference and a constant G, which is physically incorrect.  
  **Deduction: 10 points** (force application is incomplete and incorrect)

- **Simulation Loop**:  
  The loop uses `sys.DoStepDynamics(time_step)` and visualization calls, but the loop condition is `while sys.GetChTime() < total_time:` without checking `vis.Run()`. The recommended pattern is to use `while vis.Run():` to ensure the visualization window is open.  
  **Deduction: 5 points** (minor omission in simulation loop control)
