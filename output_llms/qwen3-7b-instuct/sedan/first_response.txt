```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh

# 1. Initialize the PyChrono environment
chrono.Ch纪元()
system = chrono.ChSystemNSC()

# 2. Add the required physical systems and objects
# BMW E90 Sedan
vehicle = veh.ChVehicleSystemBMWE90()
vehicle.Initialize(system)

# Rigid terrain
terrain = chrono.ChTerrain()
terrain.Initialize(system)

# TMEASY tire model
vehicle.SetTireModel(veh.ChTireModelTMEASY())

# Interactive driver system
driver = veh.ChDriverInteractive()
driver.Initialize(vehicle)

# Irrlicht visualization
irr = chronoirr.ChIrrApp(system, "BMW E90 Sedan Driving on Rigid Terrain", chronoirr.dimension2du(1024, 768))
irr.AddTypicalLogo()
irr.AddTypicalSky()
irr.AddTypicalLights()
irr.AddTypicalCamera(chronoirr.vector3df(0, 10, 10))

# Set terrain visualization
terrain.SetTexture(chrono.GetChronoDataFile("terrain/terrain.jpg"))
terrain.SetLogo(chrono.GetChronoDataFile("terrain/logo.png"))

# 3. Set necessary default parameters
# Positions, forces, and interactions can be set here using chrono's physics engine
# For example, setting initial position of the vehicle
vehicle.SetPos(chrono.ChVectorD(0, 0, 0))

# Setting up the Irrlicht visualization and driver controls
irr.AddVehicle(vehicle)
irr.AddLogo(chrono.GetChronoDataFile("logo.png"), 0.08)
irr.AddSkyBox()
irr.AddTypicalLights()
irr.AddCamera(chrono.ChVectorD(0, 10, 10))

# Start the simulation loop
irr.run()
```

This script initializes a PyChrono environment, adds a BMW E90 Sedan vehicle, a rigid terrain, and an interactive driver system. It sets up the Irrlicht visualization with a chase camera, directional lighting, a skybox, and customizable textures and logos on the terrain surface. The simulation is configured for real-time control of steering, throttle, and braking through the interactive driver system.
