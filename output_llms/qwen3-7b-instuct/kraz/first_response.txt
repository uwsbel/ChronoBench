To create a PyChrono simulation based on the provided instructions, we'll follow these steps:

1. Initialize the PyChrono environment.
2. Define the Kraz vehicle and set its initial conditions.
3. Create the terrain with specified friction and restitution.
4. Set up the driver system for vehicle control.
5. Configure the Irrlicht visualization system with camera settings and lighting.
6. Implement the simulation loop for real-time execution.

Here's a Python script that accomplishes this:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment
chrono.Ch纪元().Initialize()

# 2. Define the Kraz vehicle and set its initial conditions
vehicle = chrono.ChBodyEasyCylinder(0.3, 2.0, 0.01, 1000, True, True)
vehicle.SetPos(chrono.ChVectorD(0, 0, 0))
vehicle.SetPos_dt(chrono.ChVectorD(0, 0, 0))
vehicle.SetRot(chrono.Q_from_AngZ(chrono.CH_C_PI / 2))
vehicle.SetBodyFixed(False)
vehicle.SetCollide(True)
vehicle.SetName("Kraz")

# 3. Create the terrain with specified friction and restitution
terrain = chrono.ChTerrain()
terrain.SetFriction(0.8)
terrain.SetRestitution(0.2)
terrain.SetGroundHeight(0.0)
terrain.SetGroundWidth(100.0)
terrain.SetGroundLength(100.0)
terrain.SetTerrainDensity(1000.0)
terrain.SetTerrainSize(100.0)
terrain.SetTerrainResolution(50)
terrain.SetTerrainType(chrono.TERRAIN_TYPE_GRASS)

# 4. Set up the driver system for vehicle control
driver = chrono.ChDriverVehicleKraz()
driver.Initialize(vehicle, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 0))

# 5. Configure the Irrlicht visualization system
gui = chronoirr.ChIrrApp(chrono.Get纪元(), "PyChrono Kraz Vehicle Simulation", chronoirr.SLAVE_MODE)
gui.AddTypicalCamera(chrono.ChVectorD(0, 0, 10), chrono.ChVectorD(0, 0, 0))
gui.AddTypicalLighting()
gui.AddTypicalSky()
gui.AddTypicalLogo(chrono.GetChronoDataFile("logo_pychrono_alpha.png"))
gui.AddTypicalMenu()
gui.AddMenuEntry("Step size:", "Change the time step size.")
gui.AddMenuEntry("Pause/Resume:", "Pause/resume the simulation.")
gui.AddMenuEntry("Reset camera:", "Reset camera position.")
gui.AddMenuEntry("Quit", "Quit the simulation.")
gui.SetTimestep(0.001)

# 6. Implement the simulation loop
while gui.Get纪元().IsRunning():
    gui.Get纪元().Step()
    gui.Get纪元().GetLogfileManager().ClearLog()
    gui.Get纪元().GetLogfileManager().OpenLogfile("log.txt")
    gui.Get纪元().GetLogfileManager().LogEvent(chrono.Get紀元())
    gui.Get纪元().GetLogfileManager().CloseLogfile()
    gui.DoStep()
    gui.DrawAll()
    gui.Set纪元().GetLogfileManager().LogFrameData()
    gui.Set纪元().GetLogfileManager().LogFrameData()

chrono.Ch纪元().Finalize()
```

This script initializes the PyChrono environment, sets up the Kraz vehicle, creates a terrain with specified properties, configures the Irrlicht visualization system, and implements a real-time simulation loop.
