### 2. Correctness (30 points)

- **Element Node Assignment:**  
  The `fea.ChElementShellBST()` elements are created with boundary nodes assigned in a way that is inconsistent and likely incorrect:

  - For `melementA`, `boundary_1` is `mynodes[(iz + 1) * (nsections_x + 1) + ix + 1]` which is the top-right node of the current element, which is fine.  
  - But `boundary_2` is `mynodes[(iz + 1) * (nsections_x + 1) + ix - 1] if ix > 0 else None`, which is the node to the left of `boundary_1` but only if `ix > 0`. If `ix == 0`, it is `None`.  
  - `boundary_3` is `mynodes[(iz - 1) * (nsections_x + 1) + ix + 1] if iz > 0 else None`, which is the node above and to the right, only if `iz > 0`.  
  - This logic is inconsistent and does not follow the typical pattern for BST shell elements, which require three boundary nodes adjacent to the main triangle nodes in a specific order.  
  - Similarly, for `melementB`, the boundary nodes are assigned with indices that can go out of range or be `None` inconsistently.

  This incorrect node assignment can cause simulation errors or incorrect element behavior.  
  **Deduct 15 points for incorrect API usage that affects simulation behavior.**
