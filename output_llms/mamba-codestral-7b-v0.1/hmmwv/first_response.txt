To generate a simulation script for a full HMMWV on a flat rigid terrain using PyChrono, I will follow these steps:

1. Import the necessary PyChrono modules and initialize the PyChrono environment.
2. Create a RigidTerrain object and set its dimensions and texture.
3. Create a ChVehicle object and initialize it with the specified parameters such as location, orientation, contact method, and TMEASY tire model.
4. Add the necessary vehicle components such as the chassis, wheels, and suspension systems using primitive visualization.
5. Create an interactive driver system for steering, throttle, and braking.
6. Set up the simulation loop to run in real time at 50 frames per second.
7. Update the vehicle dynamics and render the scene within the simulation loop.

Here's the Python code to generate the simulation script:

```python
import pychrono

# Initialize PyChrono environment
system = pychrono.ChSystemNSC()

# Create RigidTerrain
terrain = pychrono.ChTerrainRigid()
terrain.SetContactMethod(pychrono.ChContactMethod.NSC)
terrain.SetTexture(pychrono.ChTextureWrapper(pychrono.GetChronoDataFile("terrain/textures/tile4.png")))
terrain.SetColor(pychrono.ChColor(0.8, 0.8, 0.8))
terrain.SetDimensions(10, 10)
system.Add(terrain)

# Create HMMWV vehicle
vehicle = pychrono.ChVehicle()
vehicle.SetInitPosition(pychrono.ChCoordsysD(pychrono.ChVectorD(0, 0, 0.5), pychrono.ChQuaternionD(1, 0, 0, 0)))
vehicle.SetInitForwardVelocity(pychrono.ChVectorD(0, 0, 0))
vehicle.SetInitForwardAcceleration(pychrono.ChVectorD(0, 0, 0))
vehicle.SetContactMethod(pychrono.ChContactMethod.NSC)
vehicle.SetTireModel(pychrono.ChTireModelType.TMEASY)

# Add vehicle components
vehicle.AddWheel(pychrono.ChVectorD(1, 1, 0), pychrono.ChQuaternionD(1, 0, 0, 0), 0.3, 0.15, 0.1, 0.1, True, True, True)
vehicle.AddWheel(pychrono.ChVectorD(-1, 1, 0), pychrono.ChQuaternionD(1, 0, 0, 0), 0.3, 0.15, 0.1, 0.1, True, True, True)
vehicle.AddWheel(pychrono.ChVectorD(1, -1, 0), pychrono.ChQuaternionD(1, 0, 0, 0), 0.3, 0.15, 0.1, 0.1, True, True, True)
vehicle.AddWheel(pychrono.ChVectorD(-1, -1, 0), pychrono.ChQuaternionD(1, 0, 0, 0), 0.3, 0.15, 0.1, 0.1, True, True, True)
vehicle.AddChassis()
vehicle.AddAxle()
vehicle.AddDifferential()
vehicle.AddSteering()
vehicle.AddSuspension()
vehicle.AddBrakes()
vehicle.AddShocks()
vehicle.AddTire()
vehicle.AddVisualization()
system.Add(vehicle)

# Create interactive driver system
driver = pychrono.ChIrrlichtDriver()
driver.SetVehicle(vehicle)
driver.SetSteering(0.5)
driver.SetThrottle(0.5)
driver.SetBraking(0.5)
system.Add(driver)

# Set up simulation loop
system.SetTimestep(0.02)
system.SetSolverType(pychrono.ChSolverType.APDS)
system.SetSolverMaxIterations(20)
system.SetSolverForceTolerances(1e-8)

# Run simulation loop
while system.GetChTime() < 10:
    system.DoStepDynamics(system.GetTimestep())
    driver.Render()
```

You can run this code in a Python environment with PyChrono installed to simulate the HMMWV vehicle on a flat rigid terrain using Irrlicht for visualization.
