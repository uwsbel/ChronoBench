To generate a simulation script based on the given instructions, we will use the PyChrono library. PyChrono is a high-performance, multi-physics simulation library for vehicle dynamics, robotics, and other engineering applications.

Here is a Python script that sets up a simulation featuring a UAZBUS vehicle with specified initial conditions and visualization settings. It also includes a rigid terrain with defined friction and restitution, a driver system for vehicle control, and a real-time visualization using Irrlicht with camera settings and lighting.

```python
import pychrono

# Initialize the PyChrono environment and core components
system = pychrono.ChSystemSMC()

# Add the UAZBUS vehicle
vehicle = pychrono.ChVehicleUaz()
system.Add(vehicle)

# Set the default parameters for the vehicle
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(pychrono.ChVectorD(0, 0, 0.5))
vehicle.SetInitForwardVelocity(pychrono.ChVectorD(30, 0, 0))

# Add a rigid terrain
terrain = pychrono.ChTerrainRigid()
system.Add(terrain)

# Set the default parameters for the terrain
terrain.SetContactFrictionCoefficient(0.9)
terrain.SetContactRestitution(0.01)

# Initialize the driver system for vehicle control
driver = pychrono.ChVehicleDriverUser()
system.Add(driver)

# Create the real-time visualization using Irrlicht
visualization = pychrono.ChVisualizationIrrlicht()
visualization.SetWindowSize(800, 600)
visualization.SetWindowTitle("PyChrono UAZBUS Simulation")
visualization.SetCameraVertical(pychrono.ChVectorD(0, 0, 1))
visualization.SetCameraPosition(pychrono.ChVectorD(0, -15, 5))
visualization.SetCameraFocusPoint(pychrono.ChVectorD(0, 0, 0))
visualization.AttachSystem(system)

# Set the camera settings and lighting
visualization.SetRenderMode(pychrono.ChVisualizationIrrlicht.RENDER_SOLID)
visualization.SetAmbientLight(pychrono.ChColor(0.8, 0.8, 0.8))
visualization.SetBackgroundColor(pychrono.ChColor(0.4, 0.4, 0.4))

# Implement a simulation loop
system.SetTimestep(0.01)
system.SetSolverType(pychrono.ChSolver.Type_BARZILAIBORWEIN)

while system.GetTime() < 10.0:
    system.DoStepDynamics(system.GetTimestep())
    visualization.Render()

# Clean up the simulation
del visualization
del system
```

This script sets up a PyChrono simulation with a UAZBUS vehicle, a rigid terrain, a driver system for vehicle control, and a real-time visualization using Irrlicht. The simulation loop runs for 10 seconds, and the visualization displays the scene with the specified camera settings and lighting.
