To generate a simulation script based on the given instructions, we will use the PyChrono library to create a simulation of a BMW E90 Sedan driving on a rigid terrain. Here is the script:

```python
import pychrono

# Initialize PyChrono environment and core components
system = pychrono.ChSystemSMC()

# Add the required physical systems and objects
# 1. Add the terrain
terrain = pychrono.ChTerrainPlane()
terrain.SetTexture(pychrono.GetChronoDataFile("textures/terrain/grass.jpg"))
terrain.SetFriction(0.8)
terrain.SetColor(pychrono.ChColor(0.5, 0.5, 0.5))
terrain.SetLogoTexture(pychrono.GetChronoDataFile("textures/terrain/logo_pychrono.png"))
system.Add(terrain)

# 2. Add the vehicle
vehicle = pychrono.ChVehicle(pychrono.ChContactMethod.NSC, system)
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(pychrono.ChVectorD(0, 0, 0))
vehicle.SetInitForwardVelocity(pychrono.ChVectorD(10, 0, 0))
system.Add(vehicle)

# Set necessary default parameters
# 1. Set positions
vehicle.SetChassisLocalPos(pychrono.ChVectorD(0, 0, 0))

# 2. Set forces
vehicle.SetEngineForce(1000)
vehicle.SetBrakeForce(500)
vehicle.SetSteering(0.2)

# 3. Set interactions
vehicle.SetTireInteractionType(pychrono.ChTireInteractionType.RIGID)

# Initialize Irrlicht visualization
system.SetVisualizationType(pychrono.VisualizationType.IRRLICHT)

# Add camera, directional lighting, skybox, and customizable textures and logos on the terrain surface
camera = pychrono.ChIrrlichtCamera()
camera.SetPosition(pychrono.ChVectorD(0, 2, -5))
camera.SetTarget(pychrono.ChVectorD(0, 0, 0))
system.AddCamera(camera)

directional_light = pychrono.ChIrrlichtDirectionalLight()
directional_light.SetDirection(pychrono.ChVectorD(0, -1, -1))
directional_light.SetColor(pychrono.ChColor(1, 1, 1))
system.AddLight(directional_light)

skybox = pychrono.ChIrrlichtSkyBox()
skybox.SetTexture(pychrono.GetChronoDataFile("textures/sky/skybox.jpg"))
system.AddSkyBox(skybox)

# Start the simulation
system.SetTimestep(0.01)
system.SetSolverType(pychrono.ChSolver.Type.BARZILAIBORWEIN)
system.Start()

while system.GetTime() < 10:
    system.DoStep()

# Stop the simulation
system.Stop()
```

This script initializes the PyChrono environment and core components, adds the required physical systems and objects (terrain, vehicle), sets necessary default parameters (positions, forces, interactions), and initializes the Irrlicht visualization. It then starts the simulation and runs it for 10 seconds. Finally, it stops the simulation.
