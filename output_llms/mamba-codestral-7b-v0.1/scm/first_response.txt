To generate a simulation script for a full HMMWV on SCM deformable terrain using PyChrono, we will follow the given instructions and initialize the PyChrono environment, add the required physical systems and objects, set default parameters, and configure the simulation.

Here is the Python code for the simulation script:

```python
import pychrono

# Initialize PyChrono environment
pychrono.SetChronoPath("path_to_chrono_directory")
pychrono.SetChronoDataPath("path_to_chrono_data_directory")

# Create the vehicle system
vehicle_system = pychrono.ChVehicleSystem()

# Add the vehicle components
vehicle_system.AddVehicleComponent(pychrono.ChWheeledVehicleRigidTire())
vehicle_system.AddVehicleComponent(pychrono.ChWheeledVehicleMeshVisualization())

# Set default parameters
vehicle_system.SetVehiclePosition(pychrono.ChVectorD(0, 0, 0))
vehicle_system.SetVehicleOrientation(pychrono.ChQuaternionD(0, 0, 0))
vehicle_system.SetTireModel(pychrono.ChTireModelRigid())

# Configure SCM terrain
terrain_system = pychrono.ChSCMTerrainSystem()
terrain_system.SetSoilParameters(1e6, 0.3, 0.01)
terrain_system.EnableMovingPatch(True)
terrain_system.EnableSinkageVisualization(True)

# Set up the simulation
simulation = pychrono.ChSimulation()
simulation.SetTimestep(0.02)
simulation.SetVisualizationType(pychrono.ChVisualizationType.OPENGL)
simulation.SetVisualizationFPS(50)
simulation.AddSystem(vehicle_system)
simulation.AddSystem(terrain_system)

# Run the simulation
simulation.Run()
```

Please note that you need to replace `"path_to_chrono_directory"` and `"path_to_chrono_data_directory"` with the actual paths to the Chrono directory and data directory on your system.

This script initializes the PyChrono environment, creates a vehicle system with a rigid tire model and mesh visualization, sets default parameters for the vehicle, configures the SCM terrain with custom soil parameters and enables moving patch and sinkage visualization, sets up the simulation with a timestep of 0.02 seconds and visualization type of OpenGL at 50 frames per second, and runs the simulation.
