To generate a simulation script based on the given instructions, we will use the PyChrono library in Python. PyChrono is a multi-physics simulation tool that allows us to model and simulate various physical systems, including particle systems.

Here is an outline of the steps we will follow to create the simulation script:

1. Initialize the PyChrono environment and core components.
2. Add the required physical systems and objects, including the particle emitter and gravitational force.
3. Set default parameters such as positions, forces, and interactions for the particles.
4. Visualize the simulation using Irrlicht, applying custom gravitational forces to simulate particle attraction dynamically.

Let's start by initializing the PyChrono environment and core components.
```python
import pychrono

# Initialize the PyChrono environment
system = pychrono.ChSystemSMC()

# Add a particle emitter
particle_emitter = pychrono.ChParticleEmitter()
system.Add(particle_emitter)

# Add gravitational force
gravity = pychrono.ChVectorD(0, -9.81, 0)
system.Set_G_acc(gravity)

# Visualize the simulation using Irrlicht
irrlicht_app = pychrono.ChIrrApp(system, 'Particle Simulation', (1280, 720))
irrlicht_app.SetShowInfos(True)
irrlicht_app.SetShowFPS(True)
irrlicht_app.SetShowContactForces(False)
irrlicht_app.SetPaused(False)
irrlicht_app.AddTypicalLogo()
irrlicht_app.AddTypicalSky()
irrlicht_app.AddTypicalLights()
irrlicht_app.AddTypicalCamera(pychrono.ChVectorD(0, 2, -5), pychrono.ChVectorD(0, 0, 0))
irrlicht_app.AddCustomSceneEventReceiver(particle_emitter)

# Run the simulation
system.SetTimestepperType(pychrono.ChTimestepperType.ChTimestepperType_HHT)
system.SetSolverType(pychrono.ChSolverType.ChSolverType_BARZILAIBORWEIN)
system.SetMaxItersSolverIt(20)
system.SetMaxItersSolverVi(100)
system.SetSolverMaxIterations(100)
system.SetSolverAbsTol(1e-4)
system.SetSolverRelTol(1e-2)
system.SetSolverForceTolerance(1e-4)
system.SetSolverMaxBounceIterations(5)
system.SetSolverContactRegularization(1e-8)

irrlicht_app.AssetBindAll()
irrlicht_app.AssetUpdateAll()

irrlicht_app.Run()
```
