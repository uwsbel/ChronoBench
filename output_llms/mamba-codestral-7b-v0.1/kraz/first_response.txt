To generate a simulation script based on the given instructions, we will use the PyChrono library. PyChrono is a high-performance, multi-physics simulation library for vehicle dynamics and control. Here is an outline of the steps we will take to create the simulation script:

1. Initialize the PyChrono environment and core components.
2. Add the required physical systems and objects, including the Kraz vehicle, rigid terrain, and driver system.
3. Set the necessary default parameters, such as positions, forces, and interactions.
4. Set up visualization settings using Irrlicht and configure the camera and lighting.
5. Implement a simulation loop that synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, ensuring real-time execution.

Let's start by initializing the PyChrono environment and core components.
```python
import pychrono

# Initialize the PyChrono environment
system = pychrono.ChSystemNSC()

# Set the time step and gravity
system.SetTimestep(0.01)
system.Set_G_acc(pychrono.ChVectorD(0, -9.81, 0))

# Create the Kraz vehicle
vehicle = pychrono.ChVehicle(system)

# Add the vehicle to the system
system.Add(vehicle)

# Set the default parameters for the vehicle
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(pychrono.ChCoordsysD(pychrono.ChVectorD(0, 0, 0), pychrono.Q_from_AngY(0)))
vehicle.SetInitLinVel(pychrono.ChVectorD(0, 0, 0))
vehicle.SetInitAngVel(pychrono.ChVectorD(0, 0, 0))

# Create the rigid terrain
terrain = pychrono.ChTerrainRigid(system)

# Add the terrain to the system
system.Add(terrain)

# Set the default parameters for the terrain
terrain.SetContactMethod(pychrono.ChContactMethod.NSC)
terrain.SetFriction(0.8)
terrain.SetRestitution(0.3)

# Initialize the driver system for vehicle control
driver = pychrono.ChVehicleDriverUser(vehicle)

# Add the driver system to the system
system.Add(driver)

# Create the Irrlicht visualization system
visual_system = pychrono.ChVisualSystemIrrlicht()

# Set the camera settings and lighting
visual_system.SetWindowSize(800, 600)
visual_system.SetWindowTitle('PyChrono Vehicle Simulation')
visual_system.SetCameraPosition(pychrono.ChVectorD(0, 5, -5), pychrono.ChVectorD(0, 0, 0))
visual_system.SetCameraVertical(pychrono.ChVectorD(0, -1, 0))
visual_system.SetRenderMode(pychrono.ChVisualSystemIrrlicht.SHADED)
visual_system.SetSkyBox(True, pychrono.ChColor(0.7, 0.7, 0.7))
visual_system.SetAmbientLight(True, pychrono.ChColor(0.3, 0.3, 0.3))
visual_system.SetPointLight(pychrono.ChVectorD(2, 5, 2), pychrono.ChColor(1, 1, 1), 2000)

# Initialize the visualization system
visual_system.Initialize()

# Start the simulation loop
while system.GetChTime() < 10:
    # Synchronize the simulation
    system.DoStepDynamics(vehicle.GetChTimeStep())

    # Advance the visualization
    visual_system.BeginScene()
    visual_system.Render()
    visual_system.EndScene()

    # Update the driver system
    driver.Synchronize(vehicle.GetVehicleState(), vehicle.GetVehicleInputs(), vehicle.GetVehicleOutputs())
    driver.Run()

# Close the visualization system
visual_system.Close()
```
