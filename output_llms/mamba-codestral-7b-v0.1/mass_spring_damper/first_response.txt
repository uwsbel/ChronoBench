Here is a Python script that uses PyChrono to create a simulation of a mass-spring-damper system. This script uses the `ChLinkTSDA` class to connect a mass to the ground with a linear spring-damper system. It also uses Irrlicht for visualization and sets appropriate lighting and camera settings.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize the PyChrono environment
chrono.SetChronoDataPath('../../data/')

# Create the Irrlicht application
app = chronoirr.ChIrrApp(chrono.GetChronoDataPath())
app.AddTypicalLogo()
app.AddTypicalSky()
app.AddTypicalLights(chrono.ChVectorD(0, 8, -15), chrono.ChVectorD(0, 0, 0), 600, 600, chrono.ChColor(0.8, 0.8, 0.8), chrono.ChColor(0, 0, 0))

# Create the physical system
system = chrono.ChSystemSMC()

# Create the ground
ground = chrono.ChBody()
ground.SetBodyFixed(True)
system.Add(ground)

# Create the mass
mass = chrono.ChBody()
mass.SetMass(1.0)
mass.SetInertiaXX(chrono.ChVectorD(1, 1, 1))
mass.SetPos(chrono.ChVectorD(0, 2, 0))
system.Add(mass)

# Create the spring
spring = chrono.ChLinkTSDA()
spring.SetSpringCoefficient(10.0)
spring.SetDampingCoefficient(1.0)
spring.SetRestLength(1.0)
spring.SetEndPoint1(mass.GetPos())
spring.SetEndPoint2(chrono.ChVectorD(0, 0, 0))
system.Add(spring)

# Set the visualization
visualization = chronoirr.ChIrrWizard(app, system, chrono.GetChronoDataPath() + 'data/')
visualization.AddAsset(mass, 'sphere_radius_0.25.obj')
visualization.AddAsset(spring, 'spring_length_1.obj')
visualization.AddAsset(ground, 'cube_side_1.obj')

# Run the simulation
app.AddVisualization(visualization)
app.SetTimestep(0.01)
app.SetTryRealtime(True)
app.Run()
```

This script initializes the PyChrono environment, creates the Irrlicht application with lighting and camera settings, creates the physical system and objects, and sets the visualization. The mass-spring-damper system is created with default parameters, and the simulation is run using the Irrlicht visualization.
