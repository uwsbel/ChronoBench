    According to the API, `ChBodyEasyBox` constructor signature is:
    ```python
    ChBodyEasyBox(lengthX, lengthY, lengthZ, density, visualize, collision, material=None)
    ```
    The last argument is `material` (optional), not position. Position should be set via `SetPos()`.  
    So passing `chrono.ChVectorD(0, -5, 0)` as the last argument is incorrect and will be interpreted as `material`, which is wrong.  
    Similarly for the sphere, the last argument is also a position vector, which is incorrect.
