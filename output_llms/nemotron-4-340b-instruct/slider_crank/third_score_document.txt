### 2. Correctness (30 points)

- **API usage:** Mostly correct usage of PyChrono API.

- **Body creation:**

  - `ChBodyEasyCylinder` is called with `chrono.ChAxis_Y` as the first argument, but according to PyChrono docs, `ChBodyEasyCylinder` expects radius, height, density, and optional visualize/collision/material arguments. The code uses `ChBodyEasyCylinder(chrono.ChAxis_Y, crank_rad, crank_thick, 1000)`, which is incorrect.

  - The correct signature is: `ChBodyEasyCylinder(radius, height, density, visualize=True, collision=True, material=None)`

  - The code passes `chrono.ChAxis_Y` as the first argument, which is invalid.

- This is a **significant API misuse** that will cause runtime errors or incorrect body creation.

- The same applies to the piston creation: `ChBodyEasyCylinder(chrono.ChAxis_Y, 0.2, 0.3, 1000)` — again, first argument is axis, which is invalid.

- The code attempts to rotate the crank and piston bodies to orient the cylinders correctly, which is good, but the initial creation is wrong.

- The motor joint is created with `chrono.ChLinkMotorRotationSpeed()`, which is correct, but the motor function is set with `SetMotorFunction` instead of `SetSpeedFunction`. According to the API, the method is `SetSpeedFunction(func)`. The code uses `my_motor.SetMotorFunction(my_angularspeed)`, which is incorrect.

- The spherical joints are initialized with `chrono.ChLinkLockSpherical()`, which is correct.

- The plane-plane joint is created with `chrono.ChLinkMatePlanePlane()`, initialized with two frames. The second frame is at `(0, -0.5, 0)` with rotation `Q_ROTATE_Z_TO_X`. This is the floor position, but the first frame is at the piston position. This seems correct.

- The simulation loop calls `sys.DoStepDynamics(1e-3)` which is correct.

- The visualization loop calls `vis.Run()` and inside calls `vis.BeginScene()`, `vis.Render()`, `vis.EndScene()`, which is correct.

- The simulation stop condition calls `vis.GetDevice().closeDevice()`, which is the correct way to close the Irrlicht device.

**Deductions:**

- **-15 points** for incorrect use of `ChBodyEasyCylinder` constructor (passing axis as first argument).

- **-15 points** for incorrect method `SetMotorFunction` instead of `SetSpeedFunction` on motor joint.

- No other major logical errors detected.
