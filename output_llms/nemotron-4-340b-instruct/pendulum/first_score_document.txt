This is incorrect because the first argument to `ChBodyEasySphere` is **radius**, the second is **density**. Here, `pendulum_mass` (1) is passed as radius, and `pendulum_length` (1) as density, which is semantically wrong. The pendulum is a sphere, but the radius should be a length, and density should be mass/volume. This is a significant error.

Also, inertia should be set with `SetInertiaXX()`, and the vector should be the principal moments of inertia. The code uses `SetInertia()`, which is not a documented method for `ChBody`.
