#### 2. **Correctness (30 points)**

- **Terrain Heightfield Lambda**:  
  ```python
  lambda x,y: 0.1*chrono.ChFunctionSine(x*0.015).GetVal(y*0.03)
  ```  
  This is incorrect usage. `ChFunctionSine` is a function of one variable; calling `GetVal(y*0.03)` on it is invalid. The lambda should be a function of `(x,y)` returning a scalar height. Possibly intended to be something like:  
  ```python
  lambda x,y: 0.1 * math.sin(x*0.015) * math.sin(y*0.03)
  ```  
  or use `ChFunctionSine` properly with one argument.  
  **Deduct 15 points for incorrect heightfield lambda function usage.**

- **Vehicle Initialization**:  
  - `fwd = veh.FWD(sys)` is unusual; `FWD` is not a standard vehicle class in PyChrono vehicle module.  
  - Then `vehicle = veh.Turtlebot(fwd)` is called, passing the `fwd` object as an argument. According to PyChrono vehicle API, vehicle classes are instantiated with no arguments or with system and contact method.  
  - Also, `vehicle.SetEngineShafts(fwd.GetEngine().GetMotorOutputs()[0].GetShafts()[0])` and similar calls are suspicious because `fwd` is not a vehicle but is used as one.  
  - `fwd.SetContactMethod(chrono.ChContactMethod_NSC)` is called after `fwd.Initialize()`, which is too late; contact method should be set before initialization.  
  **Deduct 15 points for incorrect vehicle creation and initialization sequence.**

- **Simulation Loop**:  
  - The loop does not check `vis.Run()` to continue; instead, it checks once before the loop and returns if false. This means if the window is closed during simulation, the loop continues regardless.  
  - Missing calls to `vis.BeginScene()`, `vis.Render()`, and `vis.EndScene()` will cause no rendering updates.  
  - `time_left` and `tick_time` variables are defined but unused.  
  **Deduct 10 points for logical errors in simulation loop and visualization update.**

  - `step_size` is defined globally but used inside `main()` without `global` declaration. This is acceptable in Python if only reading, but better practice is to pass as argument or define inside main.
