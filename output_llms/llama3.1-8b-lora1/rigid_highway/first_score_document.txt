#### 2. Correctness (30 points)

- **Contact Method Usage**:  
  The contact method is set correctly on the vehicle (`hmmwv.SetContactMethod(contact_method)`). The variable `contact_method` is set to `chrono.ChContactMethod_SMC`, which is valid.

- **Terrain Patch Creation**:  
  The terrain patch is created with `chrono.CSYSNORM` as the coordinate system, which is correct for a flat patch. The patch size parameters are passed as `(terrainLength, 0, terrainWidth, terrainWidth)`.  
  According to the API, the `AddPatch` method signature is:  
  `AddPatch(material, location, length, width)`  
  The second argument should be a coordinate system (`chrono.ChCoordsysd` or `chrono.CSYSNORM`), then length and width as floats. The code passes `terrainLength, 0, terrainWidth, terrainWidth` — **this is incorrect**. The second argument is `chrono.CSYSNORM`, which is fine, but then four floats are passed instead of two. This is likely a mistake. The correct call should be:  
  ```python
  patch = terrain.AddPatch(patch_mat, chrono.CSYSNORM, terrainLength, terrainWidth)
  ```  
  The extra zero and extra `terrainWidth` are incorrect and will cause an error or unexpected behavior.  
  **Deduction: 15 points (incorrect API usage that affects simulation behavior)**

- **Vehicle Initialization**:  
  The vehicle is initialized without passing the initial chassis collision type, which is important for collision detection. This omission can cause the chassis to have no collision or default collision, which may not be intended.
