    This is the node diagonally opposite the base triangle, which is correct.
  - `boundary_2 = mynodes[(iz + 1) * (nsections_x + 1) + ix - 1] if ix > 0 else None`  
    This is a node to the left of `boundary_1`, but for `ix == 0` it is None, which might be acceptable.
  - `boundary_3 = mynodes[(iz - 1) * (nsections_x + 1) + ix + 1] if iz > 0 else None`  
    This is a node above `boundary_1`, None if `iz == 0`.

  For `melementB.SetNodes(...)`:
  - `boundary_1 = mynodes[iz * (nsections_x + 1) + ix]`  
    This is the lower-left node of the quad.
