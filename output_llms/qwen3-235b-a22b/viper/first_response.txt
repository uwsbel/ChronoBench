```python
import pychrono as chrono
import pychrono.irrlicht as irr
import pychrono.vehicle as veh

# Initialize Chrono system with gravity
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# Create a rigid ground plane
ground = chrono.ChBody()
ground.SetBodyFixed(True)
ground.SetCollide(False)
ground.AddAsset(chrono.ChBoxShape(10, 10, 1))  # Ground dimensions
ground.AddAsset(chrono.ChColorAsset(0.5, 0.5, 0.5))  # Gray color
system.Add(ground)

# Initialize the Viper rover
viper = veh.Viper(system)  # Assuming Viper class exists in vehicle module
viper.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0.5), chrono.QUNIT))  # Initial position and orientation
viper.Initialize()

# Create and initialize the driver
driver = veh.ChDriver(viper)
driver.Initialize()

# Set up Irrlicht visualization
vis = irr.ChIrrApp(system, 'Viper Simulation', irr.dimension2du(800, 600))
vis.AddTypicalLights()  # Add default lighting
vis.AddCamera(chrono.ChVectorD(0, -5, 1), chrono.ChVectorD(0, 0, 0))  # Camera position and target
vis.AssetBindAll()  # Bind assets
vis.AssetUpdateAll()  # Update assets

# Simulation loop parameters
time = 0.0
step = 1e-3  # Time step (0.001 seconds)
duration = 10.0  # Time to reach max steering (seconds)
max_steer = 0.5  # Maximum steering value (adjust based on rover's steering range)

# Run simulation loop
while vis.GetDevice().run():
    # Update steering input gradually over time
    if time < duration:
        steering = (time / duration) * max_steer
    else:
        steering = max_steer
    driver.SetSteering(steering)  # Apply steering to the driver

    # Advance the simulation by one time step
    system.DoStepDynamics(step)
    time += step

    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
```

---

### **Explanation of Key Components**

1. **Chrono System Initialization**:
   - A `ChSystemNSC` object is created to represent the physical system with non-smooth contact (NSC) method.
   - Gravity is set to `-9.81 m/s²` in the z-direction.

2. **Rigid Terrain**:
   - A `ChBody` is created for the ground, fixed in place and non-colliding.
   - A box shape and gray color are added for visualization.

3. **Viper Rover**:
   - The `Viper` class is assumed to be part of the `vehicle` module, representing a predefined rover model.
   - The rover is initialized at a height of `0.5` meters above the ground with no initial rotation.

4. **Driver Setup**:
   - A `ChDriver` is created and associated with the Viper rover.
   - The driver is used to control the rover's steering input.

5. **Irrlicht Visualization**:
   - An `ChIrrApp` object is created for real-time rendering.
   - Default lighting and a fixed camera are added to view the simulation.
   - Assets are bound and updated for rendering.

6. **Simulation Loop**:
   - The loop runs while the Irrlicht window is open.
   - Steering input is gradually increased from `0` to `max_steer` over `duration` seconds.
   - The simulation is advanced using `DoStepDynamics`, and the scene is rendered each frame.

---

### **Notes**
- This script assumes the existence of a `Viper` class in the `vehicle` module. If not available, you may need to load a JSON configuration or define the rover manually.
- The `ChDriver` is used to apply steering inputs. If the Viper requires additional synchronization (e.g., throttle, braking), those can be added similarly.
- The camera is fixed; for dynamic camera tracking, consider using `AddChaseCamera` or updating the camera position dynamically.
