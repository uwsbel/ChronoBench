Here is a well-structured and documented PyChrono simulation script that implements a Curiosity rover navigating on a rigid terrain, complete with real-time steering via a motor control driver and enhanced visualization using Irrlicht:

---

### ✅ **PyChrono Simulation Script: Curiosity Rover on Rigid Terrain**

```cpp
#include "chrono/physics/ChSystemNSC.h"
#include "chrono/physics/ChBody.h"
#include "chrono/assets/ChTexture.h"
#include "chrono/assets/ChColorAsset.h"
#include "chrono_vehicle/curiosity/ChCuriosity.h"
#include "chrono_vehicle/driver/ChIrrGuiDriver.h"
#include "chrono_irrlicht/ChIrrApp.h"

using namespace chrono;
using namespace chrono::vehicle;
using namespace chrono::irrlicht;
using namespace irr;

int main() {
    // 1. Initialize the Chrono system
    ChSystemNSC system;
    system.Set_G_acc(ChVector<>(0, -3.711, 0)); // Mars gravity

    // 2. Create a rigid terrain with collision and visualization
    auto terrain = chrono_types::make_shared<ChRigidTerrain>(&system);
    terrain->SetContactMaterial(ChMaterialSurfaceNSC());
    terrain->SetFriction(0.8f);
    terrain->SetRestitution(0.1f);
    terrain->Initialize(ChVector<>(0, 0, 0), 100, 100, 0.1); // Position, length, width, height
    terrain->SetTexture(GetChronoDataFile("textures/terrain/grass.jpg"));
    system.Add(terrain);

    // 3. Create and configure the Curiosity rover
    auto curiosity = chrono_types::make_shared<ChCuriosity>(&system);
    ChVector<> init_pos(0, 1, 0); // Start 1 unit above the terrain
    ChQuaternion<> init_rot = QUNIT; // No rotation
    curiosity->Initialize(ChFrame<>(init_pos, init_rot));
    curiosity->SetChassisVisualizationType(VisualizationType::Mesh);
    curiosity->SetWheelVisualizationType(VisualizationType::Mesh);
    curiosity->SetContactMethod(ChContactMethod::NSC);

    // 4. Initialize the Irrlicht visualization system
    ChIrrApp app(&system, L"Curiosity Rover Simulation", core::dimension2d<u32>(1024, 768));
    app.AddLogo();
    app.AddSkyBox();
    app.AddCamera(ChVector<>(0, 5, -10), ChVector<>(0, 0, 0)); // Camera position and target
    app.AddLightWithShadow(ChVector<>(5, 10, 5), ChVector<>(0, 0, 0), 10, 0.1, 10, 100, 512, video::SColorf(1, 1, 1));

    // Enable lighting and shadows
    app.GetSceneManager()->getVideoDriver()->setMaterialFlag(video::EMF_LIGHTING, true);
    app.GetSceneManager()->getVideoDriver()->setLighting(video::EMT_ON);

    // 5. Create the driver interface for real-time input
    auto driver = chrono_types::make_shared<ChIrrGuiDriver>(app);
    driver->SetSteeringDelta(0.05);
    driver->SetThrottleDelta(0.05);
    driver->SetBrakingDelta(0.05);

    // 6. Simulation loop
    app.SetTimestep(0.01);
    while (app.GetDevice()->run()) {
        // Update driver inputs
        driver->Update();

        // Synchronize the rover with current time and driver inputs
        double time = system.GetChTime();
        curiosity->Synchronize(time, driver->GetInputs(), *terrain);
        curiosity->Advance(app.GetTimestep());

        // Advance the simulation
        system.DoStepDynamics(app.GetTimestep());

        // Render the scene
        app.BeginScene();
        app.DrawAll();
        app.EndScene();
    }

    return 0;
}
```

---

### 📌 **Key Components and Features Explained**

#### 🧱 **Physical Environment**
- **System Gravity:** Set to Mars gravity (`3.711 m/s²`) for realism.
- **Rigid Terrain:** Implemented using `ChRigidTerrain` with collision properties and a grass texture for visual realism.
- **Collision Handling:** Uses NSC (Non-Smooth Contact) method for robust and stable contact handling.

#### 🚀 **Curiosity Rover Model**
- **Model Initialization:** Loaded using `ChCuriosity` class from Chrono::Vehicle.
- **Visualization:** Mesh-based visualization for both chassis and wheels.
- **Contact Method:** Uses the same NSC method as the terrain for consistency.

#### 🎮 **Real-Time Motor Control**
- **Driver Interface:** `ChIrrGuiDriver` captures real-time keyboard input for steering, throttle, and braking.
- **Input Mapping:** Adjusted sensitivity with `SetSteeringDelta`, `SetThrottleDelta`, and `SetBrakingDelta`.

#### 🎨 **Irrlicht Visualization**
- **Camera Setup:** Positioned to follow the rover with a clear view of the terrain.
- **Lighting and Shadows:** A directional light with shadow casting enabled for enhanced realism.
- **Visual Enhancements:** Skybox, logo, and texture mapping for immersive experience.

### 📦 **Requirements and Notes**

- Ensure that the Chrono library is built with the `VEHICLE` and `IRR` modules enabled.
- The `GetChronoDataFile()` function assumes that the Chrono data directory is correctly set up.
- This simulation assumes the presence of the `ChCuriosity` class and its dependencies in the Chrono installation.
- For more advanced terrain, consider using heightmaps or more complex collision meshes.

---

### 🧪 **To Run the Simulation**
1. Compile the code using CMake and a compatible compiler.
2. Ensure that the Chrono shared libraries and data files are accessible.
3. Run the executable and use the keyboard to control the rover:
   - Arrow keys or WASD for steering and throttle.
   - Spacebar for brake.
