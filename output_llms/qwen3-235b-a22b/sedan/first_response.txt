Here's a well-structured PyChrono simulation script that fulfills the requirements for a BMW E90 Sedan driving on a rigid terrain with interactive controls and advanced visualization features:

---

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr
import pychrono.driver as driver

# 1. Initialize the PyChrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Load and configure the BMW E90 Sedan vehicle
vehicle = veh.WheeledVehicle(system, veh.GetDataFile("vehicle/BMW_E90/BMW_E90.json"))
vehicle.Initialize(chrono.ChCoordsysD(chrono.ChVectorD(0, 0.5, 0), chrono.QUNIT))
vehicle.SetChassisVisualizationType(veh.VisualizationType_MESH)
vehicle.SetSuspensionVisualizationType(veh.VisualizationType_PRIMITIVES)
vehicle.SetSteeringVisualizationType(veh.VisualizationType_PRIMITIVES)
vehicle.SetWheelVisualizationType(veh.VisualizationType_MESH)

# 3. Configure TMeasy tire models for each wheel
for axle in vehicle.GetAxles():
    for wheel in axle.GetWheels():
        tire = veh.TMeasyTire(veh.GetDataFile("vehicle/BMW_E90/BMW_E90_TMeasy.json"))
        wheel.SetTire(tire)

# 4. Create the rigid terrain with customizable textures
terrain = veh.RigidTerrain(system)
patch = terrain.AddPatch(chrono.ChCoordsysD(), chrono.ChVectorD(200, 1, 200), "terrain_texture.png")
patch.SetColor(chrono.ChColor(0.8, 0.8, 0.5))
terrain.Initialize()

# Optional: Add a logo patch (replace with actual texture path)
logo_patch = terrain.AddPatch(
    chrono.ChCoordsysD(chrono.ChVectorD(0, 0.01, 50), chrono.QUNIT),
    chrono.ChVectorD(10, 1, 2),
    "logo_texture.png"
)
logo_patch.SetColor(chrono.ChColor(1.0, 1.0, 1.0))

# 5. Set up the interactive driver system
driver = veh.ChIrrGuiDriver(vehicle.GetVehicle())
driver.SetSteeringDelta(0.05)
driver.SetThrottleDelta(0.05)
driver.SetBrakingDelta(0.05)

# 6. Initialize the Irrlicht visualization system
application = irr.ChIrrApp(vehicle.GetSystem(), "BMW E90 Simulation", irr.dimension2du(1024, 768))
application.AddTypicalLights()
application.AddSkyBox()
application.AddCamera(chrono.ChVectorD(0, 2, -5), chrono.ChVectorD(0, 0, 0))

# Optional: Use a chase camera for better vehicle tracking
chase_camera = veh.ChChaseCamera(vehicle.GetVehicle(), 6.0, 0.5)
application.SetChaseCamera(chase_camera)

application.AssetBindAll()
application.AssetUpdateAll()

# 7. Simulation loop
while application.GetDevice().run():
    time = system.GetChTime()
    
    # Update driver inputs
    driver_inputs = driver.GetInputs()
    driver.Synchronize(time)
    
    # Synchronize vehicle and terrain
    vehicle.Synchronize(time, driver_inputs, terrain)
    terrain.Synchronize(time)
    
    # Advance the simulation
    system.DoStepDynamics(1e-3)
    
    # Render the scene
    application.BeginScene()
    application.DrawAll()
    application.EndScene()
```

---

### Key Features Implemented:

- **Vehicle Dynamics**: Uses the `WheeledVehicle` class with the BMW E90 model from PyChrono's data files.
- **Tire Model**: Implements the `TMeasyTire` model for realistic tire-terrain interaction.
- **Terrain**: A rigid terrain with customizable textures and an optional logo patch.
- **Interactive Driver**: Real-time control via keyboard using `ChIrrGuiDriver`.
- **Visualization**:
  - **Chase Camera**: Follows the vehicle for immersive driving experience.
  - **Skybox**: Adds a realistic background.
  - **Directional Lighting**: Enhances visual realism.
  - **Custom Textures**: Allows for terrain and logo customization.

---

### Notes:

- Ensure the JSON and texture files (`BMW_E90.json`, `BMW_E90_TMeasy.json`, `terrain_texture.png`, `logo_texture.png`) are in the correct data directory or adjust the paths accordingly.
- This script assumes the PyChrono Python bindings are installed and configured properly.
- The simulation uses a fixed time step of `0.001` seconds for numerical stability.

This script provides a complete, interactive, and visually rich simulation environment for the BMW E90 Sedan in PyChrono.
