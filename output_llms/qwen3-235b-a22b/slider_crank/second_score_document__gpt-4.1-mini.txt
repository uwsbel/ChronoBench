### 2. Correctness (30 points)

- **API Usage**:  
  - `ChBodyEasyCylinder` is called with `chrono.ChAxis_Y` as the first argument, which is **incorrect**. According to the PyChrono API, `ChBodyEasyCylinder` expects `(radius, height, density, visualize=True, collision=True, material=None)`. The axis is not an argument. The code uses `chrono.ChBodyEasyCylinder(chrono.ChAxis_Y, crank_rad, crank_thick, 1000)`, which is wrong and will cause errors or unexpected behavior.  
  - Similarly, `mpiston` is created with `ChBodyEasyCylinder(chrono.ChAxis_Y, 0.2, 0.3, 1000)`, again incorrect usage.  
  This is a **significant API misuse** and could break the simulation or cause wrong geometry.  
  Deduct **15 points**.

- **Joint Initialization**:  
  - Joints are initialized with `chrono.ChFramed(...)`. The API documentation specifies `chrono.ChCoordsysD` for frames, but `ChFramed` is an alias or similar. Assuming `ChFramed` is a valid alias or imported correctly, this is acceptable.  
  - Motor joint uses `SetMotorFunction` instead of `SetSpeedFunction`. The API documentation shows `SetSpeedFunction` as the correct method name. This is a **minor API misuse**. Deduct **5 points**.

- **Rotation Quaternions**:  
  - `mcrank.SetRot(chrono.Q_ROTATE_Y_TO_Z)` and `mpiston.SetRot(chrono.Q_ROTATE_Y_TO_X)` are used. These constants are not standard in the documented API. The documentation mentions `chrono.QUNIT` and `chrono.QuatFromAngleX/Y/Z`. These constants may exist but are not documented here.  
  - This could be a minor issue if these constants are undefined or not standard. Deduct **5 points** for minor inaccuracy.

- **Data Collection**:  
  - `array_angle.append(chrono.CH_PI * current_time)` is used to compute crank angle. This assumes constant angular speed of π rad/s, which matches the motor speed. This is logically consistent. No deduction.

- **Visualization Camera**:  
  - `vis.AddCamera(chrono.ChVector3d(1, 1, 3), chrono.ChVector3d(0, 1, 0))` is used, but the API documentation shows `AddCamera(position)` with only one argument. The second argument is not documented. This could be an error or misuse. Deduct **5 points**.
