```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.ros as chros

# 1. Initialize the PyChrono system
system = chrono.ChSystemNSC()
system.SetGravitationalAcceleration(chrono.ChVector3d(0, 0, -9.81))

# 2. Create the HMMWV vehicle with specified parameters
vehicle = veh.HMMWV_Full(system)
vehicle.SetContactMethod(chrono.ChContactMethod_NSC)  # Non-Smooth Contact
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(chrono.ChCoordsysd(chrono.ChVector3d(0, 0, 1.0), chrono.QUNIT))
vehicle.SetTireType(veh.TireModelType_TMeasy)  # TMeasy tire model
vehicle.SetTireStepSize(1e-3)  # Tire integration step size
vehicle.Initialize()

# Set engine type (Simple Engine model)
vehicle.SetEngineType(veh.EngineModelType_SIMPLE)

# 3. Create the terrain with defined friction and restitution
terrain = veh.RigidTerrain(vehicle.GetSystem())
patch_mat = chrono.ChContactMaterialNSC()
patch_mat.SetFriction(0.9)  # Friction coefficient
patch_mat.SetRestitution(0.01)  # Restitution coefficient
patch = terrain.AddPatch(patch_mat, chrono.ChCoordsysd(), 200, 100)  # Flat patch
patch.SetTexture(veh.GetDataFile("terrain/textures/tile4.jpg"), 200, 100)
terrain.Initialize()

# 4. Initialize the driver system for vehicle control
driver = veh.ChDriver(vehicle)
driver.Initialize()

# 5. Integrate ROS for communication
ros_manager = chros.ChROSManager()
ros_manager.Initialize()

# Register ROS handlers
clock_handler = chros.ChROSClockSynchronizer()
clock_handler.Register(ros_manager)

driver_inputs_handler = chros.ChROSDriverInputsSubscriber(driver)
driver_inputs_handler.Register(ros_manager)

vehicle_state_handler = chros.ChROSBodyPublisher(vehicle.GetChassisBody())
vehicle_state_handler.Register(ros_manager)

# 6. Simulation loop
time_step = 1e-3  # Simulation time step
sim_time = 0.0
total_sim_time = 10.0  # Total simulation time in seconds

while sim_time < total_sim_time:
    # Synchronize systems
    driver_inputs = driver.GetInputs()
    vehicle.Synchronize(sim_time, driver_inputs, terrain)
    terrain.Synchronize(sim_time)
    
    # Advance the simulation
    system.DoStepDynamics(time_step)
    sim_time += time_step

    # Update ROS communication
    ros_manager.Update(sim_time, time_step)

print("Simulation completed.")
```

### Explanation:
1. **System Initialization**: The `ChSystemNSC` is used for non-smooth contact dynamics with gravity set to standard Earth acceleration.
2. **Vehicle Setup**: The HMMWV vehicle is configured with NSC contact method, TMeasy tire model, and a simple engine. The initial position is set with a slight height to avoid ground penetration.
3. **Terrain Configuration**: A rigid terrain patch is created with specified friction and restitution values, using a texture for visualization.
4. **Driver System**: A basic driver is initialized to handle vehicle inputs, which can be extended for path-following or user control.
5. **ROS Integration**: The `ChROSManager` handles ROS communication with handlers for clock synchronization, driver input subscription, and vehicle state publishing.
6. **Simulation Loop**: The loop synchronizes vehicle, terrain, and driver systems, advances the simulation, and updates ROS data at each timestep until the total simulation time is reached.
