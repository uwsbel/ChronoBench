```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr

# Initialize the Chrono system with NSC solver
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create the Irrlicht visualization system with customizable settings
application = irr.ChIrrApp(system, 'MAN 10t Truck Simulation', irr.dimension2du(1280, 720))
application.AddSkyBox()  # Add skybox for realism
application.AddLogo()    # Add Chrono logo

# Add directional lighting for enhanced visuals
light = irr.ChIrrLight()
light.SetType(irr.ELT_DIRECTIONAL)
light.SetDirection(chrono.ChVectorD(1, -1, 0).GetNormalized())  # Directional light from top-front
application.GetSceneManager().addLight(light)

# Create and configure the MAN 10t truck
truck = veh.MAN_10t(system)  # Initialize the MAN 10t vehicle model
truck.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 1, 0), chrono.ChQuaternionD(1, 0, 0, 0)))  # Position and orientation
truck.SetEngineType(veh.EngineModelType_SIMPLE_MAP)  # Simple engine model
truck.SetTransmissionType(veh.TransmissionModelType_AUTOMATIC_SIMPLE_MAP)  # Automatic transmission
truck.SetTireType(veh.TireModelType_TMEASY)  # Use TMEASY tire model for realistic dynamics
truck.SetChassisVisualizationType(veh.VisualizationType_MESH)  # 3D mesh for chassis
truck.SetWheelVisualizationType(veh.VisualizationType_MESH)   # 3D mesh for wheels
truck.Initialize()  # Finalize truck setup

# Create rigid terrain with customizable texture
terrain = veh.RigidTerrain(system)
patch = terrain.AddPatch(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(200, 1, 200), 0.9, 0.01)  # Terrain dimensions and material properties
patch.SetTexture(chrono.GetChronoDataFile("terrain/textures/tile.png"), 100, 100)  # Apply texture
terrain.Initialize()  # Finalize terrain setup

# Configure real-time driver controls
driver = veh.ChIrrGuiDriver(application.GetDevice())  # Link driver to Irrlicht window
driver.SetSteeringDelta(0.05)     # Sensitivity for steering
driver.SetThrottleDelta(0.05)     # Sensitivity for throttle
driver.SetBrakingDelta(0.05)      # Sensitivity for braking
truck.GetVehicle().SetDriver(driver)  # Connect driver to the truck

# Set up chase camera to follow the vehicle
application.SetChaseCamera(truck.GetChassisBody(), 6.0, 0.5)  # Distance and height from chassis

# Simulation loop
application.SetTimestep(0.01)  # Set fixed time step for real-time simulation
while application.GetDevice().run():
    time = system.GetChTime()  # Get current simulation time
    
    # Synchronize components for current time step
    driver.Synchronize(time)
    truck.Synchronize(time)
    terrain.Synchronize(time)
    
    # Advance the simulation
    system.DoStepDynamics(0.01)
    
    # Render the scene
    application.BeginScene()
    application.DrawAll()
    application.EndScene()
```

### Key Features Implemented:
1. **Chrono System Setup**: Initializes the physical system with gravity.
2. **Vehicle Model**: Uses the MAN 10t truck with configurable visualization (3D mesh) and TMEASY tire dynamics.
3. **Rigid Terrain**: Creates a textured terrain with customizable friction and restitution.
4. **Real-Time Controls**: Implements steering, throttle, and braking via keyboard inputs.
5. **Irrlicht Visualization**: Includes chase camera, directional lighting, skybox, and Chrono logo.
6. **Simulation Loop**: Handles synchronization and rendering at a fixed time step for real-time performance.

### Notes:
- **Texture Path**: Ensure the `tile.png` texture exists in the Chrono data directory or modify the path accordingly.
- **Camera Control**: The chase camera follows the truck's chassis with adjustable distance and height.
- **Driver Inputs**: Arrow keys control steering, throttle, and braking, with sensitivity set via `Set*Delta` methods.
