Here is the corrected and modified PyChrono script to simulate a double pendulum system, with identified bugs fixed and new features added as per the instructions:

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr

# Initialize the Chrono simulation system
sys = chrono.ChSystemNSC()

# Set the gravitational acceleration for the system (in m/s^2)
sys.SetGravitationalAcceleration(chrono.ChVector3d(0, -9.81, 0))  # g = 9.81 m/s^2

# Create the ground body and add it to the simulation
ground = chrono.ChBody()
sys.Add(ground)
ground.SetFixed(True)  # The ground is fixed and does not move
ground.EnableCollision(False)  # Disable collision detection for the ground

# Add a visualization cylinder to the ground
cyl_ground = chrono.ChVisualShapeCylinder(0.2, 0.4)  # Cylinder with radius 0.2 and height 0.4
ground.AddVisualShape(cyl_ground, chrono.ChFramed(chrono.ChVector3d(0, 0, +1)))

# Create the first pendulum body and add it to the simulation
pend_1 = chrono.ChBody()
sys.AddBody(pend_1)
pend_1.SetFixed(False)  # The pendulum can move
pend_1.EnableCollision(False)  # Disable collision detection for the pendulum
pend_1.SetMass(1)  # Set the mass of the pendulum (in kg)
# Corrected inertia tensor for a cylinder with radius 0.2m and length 2m
pend_1.SetInertiaXX(chrono.ChVector3d(0.02, 0.343, 0.343))  # Ixx = 0.5*m*r², Iyy = Izz = (1/12)*m*(3r² + L²)

# Add a visualization cylinder to the first pendulum
cyl_pend1 = chrono.ChVisualShapeCylinder(0.2, 2)  # Cylinder with radius 0.2 and height 2
cyl_pend1.SetColor(chrono.ChColor(0.6, 0, 0))  # Set the color of the cylinder (RGB)
# Corrected rotation to align the cylinder along the X-axis
pend_1.AddVisualShape(cyl_pend1, chrono.ChFramed(chrono.VNULL, chrono.QuatFromAngleZ(chrono.CH_PI_2)))

# Set the initial position of the first pendulum (center of mass) in the absolute frame
pend_1.SetPos(chrono.ChVector3d(1, 0, 1))  # COM at (1, 0, 1)

# Create a revolute joint to connect the first pendulum to the ground
rev_1 = chrono.ChLinkLockRevolute()
rev_1.Initialize(ground, pend_1, chrono.ChFramed(chrono.ChVector3d(0, 0, 1), chrono.ChQuaterniond(1, 0, 0, 0)))
sys.AddLink(rev_1)

# Create the second pendulum body and add it to the simulation
pend_2 = chrono.ChBody()
sys.AddBody(pend_2)
pend_2.SetFixed(False)
pend_2.EnableCollision(False)
pend_2.SetMass(1)
# Corrected inertia tensor for the second pendulum (same as the first)
pend_2.SetInertiaXX(chrono.ChVector3d(0.02, 0.343, 0.343))

# Add a visualization cylinder to the second pendulum
cyl_pend2 = chrono.ChVisualShapeCylinder(0.2, 2)  # Cylinder with radius 0.2 and height 2
cyl_pend2.SetColor(chrono.ChColor(0, 0.6, 0))  # Green color for the second pendulum
# Corrected rotation to align the cylinder along the X-axis
pend_2.AddVisualShape(cyl_pend2, chrono.ChFramed(chrono.VNULL, chrono.QuatFromAngleZ(chrono.CH_PI_2)))

# Set the initial position of the second pendulum (center of mass)
pend_2.SetPos(chrono.ChVector3d(3, 0, 1))  # COM at (3, 0, 1)

# Create a revolute joint to connect the second pendulum to the first
rev_2 = chrono.ChLinkLockRevolute()
rev_2.Initialize(pend_1, pend_2, chrono.ChFramed(chrono.ChVector3d(2, 0, 1), chrono.ChQuaterniond(1, 0, 0, 0)))
sys.AddLink(rev_2)

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)  # Attach the Chrono system to the visualization
vis.SetWindowSize(1024, 768)  # Set the window size for the visualization
vis.SetWindowTitle('Double Pendulum Simulation')  # Updated window title
vis.Initialize()  # Initialize the visualization system
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))  # Add a logo to the visualization
vis.AddSkyBox()  # Add a skybox for better visual appearance
vis.AddCamera(chrono.ChVector3d(0, 3, 6))  # Add a camera to the visualization
vis.AddTypicalLights()  # Add typical lights for better visualization

# Simulation loop
log_info = True  # Flag to control logging
while vis.Run():
    vis.BeginScene()  # Begin the scene for rendering
    vis.Render()  # Render the scene
    vis.EndScene()  # End the scene
    sys.DoStepDynamics(1e-3)  # Advance the simulation by a time step of 0.001 seconds

    # Log information after 1 second of simulation time
    if log_info and sys.GetChTime() > 1:
        pos_1 = pend_1.GetPos()  # Get the position of the first pendulum
        print("t = ", sys.GetChTime())
        print("Pendulum 1 Position: ", pos_1.x, "  ", pos_1.y)
        lin_vel_1 = pend_1.GetPosDt()  # Get the linear velocity of the first pendulum
        print("Pendulum 1 Velocity: ", lin_vel_1.x, "  ", lin_vel_1.y)
        
        pos_2 = pend_2.GetPos()  # Get the position of the second pendulum
        print("Pendulum 2 Position: ", pos_2.x, "  ", pos_2.y)
        lin_vel_2 = pend_2.GetPosDt()  # Get the linear velocity of the second pendulum
        print("Pendulum 2 Velocity: ", lin_vel_2.x, "  ", lin_vel_2.y)
        log_info = False  # Disable further logging
```

### Key Corrections and Additions:
1. **Visual Shape Rotation Fix**:  
   - The original code incorrectly rotated the pendulum's visual shape around the Y-axis. This was corrected to rotate around the Z-axis using `chrono.QuatFromAngleZ(chrono.CH_PI_2)` to align the cylinder along the X-axis.

2. **Inertia Tensor Correction**:  
   - The inertia tensor for the pendulum was updated to reflect the correct physical properties of a cylinder with radius 0.2m and length 2m. The corrected values are:
     - `Ixx = 0.02 kg·m²` (rotation about the cylinder's axis)
     - `Iyy = Izz = 0.343 kg·m²` (rotation perpendicular to the cylinder's axis)

3. **Double Pendulum Implementation**:  
   - A second pendulum (`pend_2`) was added with identical physical properties to the first pendulum.
   - A revolute joint (`rev_2`) was created to connect `pend_1` and `pend_2` at the end of the first pendulum, allowing independent rotation.

4. **Enhanced Logging**:  
   - The logging functionality was extended to include position and velocity data for both pendulums after 1 second of simulation time.

5. **Improved Visualization**:  
   - The second pendulum was assigned a distinct green color for better visual differentiation.
   - The window title was updated to reflect the double pendulum simulation.

This script now accurately simulates a double pendulum system with corrected dynamics and visualization, ensuring both pendulums move independently and realistically under the influence of gravity.
