Here is a well-documented PyChrono simulation script that demonstrates an epicyclic gear system with a fixed truss, a rotating bar (acting as a carrier), and two gears (sun and planet). A motor is applied to the sun gear to enforce constant angular velocity. The simulation is visualized using the Irrlicht engine with appropriate materials and lighting.

---

### 🧰 Simulation Overview

- **Fixed Truss**: Acts as the base of the system.
- **Rotating Bar (Carrier)**: Connected to the truss via a revolute joint, allowing it to rotate freely.
- **Sun Gear**: Mounted at the center and driven by a motor to rotate at a constant angular velocity.
- **Planet Gear**: Mounted on the rotating bar and meshes with the sun gear.
- **Gear Constraint**: Enforces a 1:1 gear ratio between the sun and planet gears.
- **Visualization**: Uses Irrlicht for 3D rendering with lighting, camera, and materials.

---

### 🧪 Python Script

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Set the Chrono data path (update this to your Chrono data directory)
chrono.SetChronoDataPath('path_to_chrono_data')

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, 0))  # No gravity for simplicity

# Create the fixed truss (base)
truss = chrono.ChBody()
truss.SetBodyFixed(True)
truss.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(truss)

# Add a box shape to the truss
truss_shape = chrono.ChBoxShape()
truss_shape.GetBoxGeometry().Size = chrono.ChVectorD(1, 1, 0.05)
truss.AddAsset(truss_shape)

# Create the rotating bar (carrier)
bar = chrono.ChBody()
bar.SetMass(1)
bar.SetInertiaXX(chrono.ChVectorD(0.1, 0.1, 0.1))
bar.SetPos(chrono.ChVectorD(0, 0, 0.2))
system.Add(bar)

# Add a box shape to the bar
bar_shape = chrono.ChBoxShape()
bar_shape.GetBoxGeometry().Size = chrono.ChVectorD(0.25, 0.05, 0.05)  # Length = 0.5
bar.AddAsset(bar_shape)

# Add a revolute joint between the truss and the bar
revolute_bar = chrono.ChLinkRevolute()
revolute_bar.Initialize(truss, bar, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0.2), chrono.QUNIT))
system.AddLink(revolute_bar)

# Create the sun gear
sun = chrono.ChBody()
sun.SetPos(chrono.ChVectorD(0, 0, 0.2))
sun.SetMass(0.5)
sun.SetInertiaXX(chrono.ChVectorD(0.01, 0.01, 0.01))
system.Add(sun)

# Add a cylinder shape to the sun gear
sun_shape = chrono.ChCylinderShape()
sun_shape.GetCylinderGeometry().rad = 0.05
sun_shape.GetCylinderGeometry().p1 = chrono.ChVectorD(0, 0, -0.02)
sun_shape.GetCylinderGeometry().p2 = chrono.ChVectorD(0, 0, 0.02)
sun.AddAsset(sun_shape)

# Add a revolute joint between the truss and the sun gear
sun_revolute = chrono.ChLinkRevolute()
sun_revolute.Initialize(truss, sun, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0.2), chrono.QUNIT))
system.AddLink(sun_revolute)

# Add a motor to the sun gear to enforce constant angular velocity
omega = 10  # rad/s
motor = chrono.ChLinkMotorRotationAngle()
motor.Initialize(sun, truss, chrono.ChFrameD(chrono.ChVectorD(0, 0, 0.2), chrono.QUNIT))

# Use a ramp function to define the angular position over time (constant angular velocity)
ramp = chrono.ChFunction_Ramp()
ramp.SetAngularCoeff(omega)  # slope = angular velocity
motor.SetMotorFunction(ramp)
system.AddLink(motor)

# Create the planet gear
planet = chrono.ChBody()
planet.SetMass(0.5)
planet.SetInertiaXX(chrono.ChVectorD(0.01, 0.01, 0.01))
planet.SetPos(chrono.ChVectorD(0.25, 0, 0.2))  # Positioned at the end of the bar
system.Add(planet)

# Add a cylinder shape to the planet gear
planet_shape = chrono.ChCylinderShape()
planet_shape.GetCylinderGeometry().rad = 0.05
planet_shape.GetCylinderGeometry().p1 = chrono.ChVectorD(0, 0, -0.02)
planet_shape.GetCylinderGeometry().p2 = chrono.ChVectorD(0, 0, 0.02)
planet.AddAsset(planet_shape)

# Add a revolute joint between the bar and the planet gear
planet_revolute = chrono.ChLinkRevolute()
planet_revolute.Initialize(bar, planet, chrono.ChCoordsysD(chrono.ChVectorD(0.25, 0, 0), chrono.QUNIT))
system.AddLink(planet_revolute)

# Add a gear constraint between the sun and planet gears
gear_ratio = 1.0  # 1:1 gear ratio
link_gear = chrono.ChLinkGear()
link_gear.Initialize(sun, planet, chrono.ChVectorD(0, 0, 1))  # Z-axis
link_gear.SetTransmissionRatio(gear_ratio)
system.AddLink(link_gear)

# Set material properties for all bodies
mat = chrono.ChMaterialSurfaceNSC()
mat.SetFriction(0.2)
mat.SetDampingF(0.01)
mat.SetCompliance(0.0001)
mat.SetComplianceT(0.0001)

for body in [truss, bar, sun, planet]:
    body.SetMaterialSurface(mat)

# Set up Irrlicht visualization
application = chronoirr.ChIrrApp(system, 'Epicyclic Gears', chronoirr.dimension2du(1024, 768))
application.AddTypicalLogo()
application.AddTypicalSky()
application.AddTypicalLights()
application.AddCamera(chronoirr.vector3df(0, 1, -1), chronoirr.vector3df(0, 0, 0.2))

# Bind and update all assets
application.AssetBindAll()
application.AssetUpdateAll()

# Set simulation time step and real-time rendering
application.SetTimestep(0.01)
application.SetTryRealtime(True)

# Simulation loop
while application.GetDevice().run():
    application.BeginScene()
    application.DrawAll()
    application.DoStep()
    application.EndScene()
```

---

### 📌 Notes

- **Gear Ratio**: The gear ratio is set to 1.0 for simplicity. You can adjust this by changing the `gear_ratio` variable.
- **Motor Function**: A `ChFunction_Ramp` is used to define the angular position over time, resulting in constant angular velocity.
- **Visualization**: The camera is positioned to provide a clear view of the rotating bar and gears. You can adjust the camera position for better angles.
- **Materials**: A basic material is applied to all bodies for friction and damping effects.
