### 2. Correctness (30 points)

- **Incorrect API usage:**  
  - `mesh_body.SetMesh(mesh)` is not a valid method for `ChBody`. Meshes are typically added as visual shapes or collision shapes, e.g., via `AddVisualShape` or `GetCollisionModel().AddTriangleMesh(...)`. This is a significant API misuse and will cause the mesh not to appear or be used in simulation.  
  **Deduct 15 points** for incorrect mesh assignment.

- **Lidar Sensor Parameters:** The parameters passed to `ChLidarSensor` appear reasonable and consistent with the API (parent body, number of channels, points per channel, frame, max distance, horizontal FOV, vertical FOV, min and max angle increments). No issues.

- **Quaternion Construction:**  
  - `chrono.ChQuaternionD(chrono.ChAngleAxisD(yaw, chrono.ChVectorD(0, 0, 1)))` is not the correct way to construct a quaternion from an angle-axis in PyChrono. The constructor expects four doubles (w, x, y, z) or a copy of another quaternion. The correct way is to use `chrono.Q_from_AngAxis(yaw, chrono.ChVectorD(0,0,1))` or `chrono.ChQuaternionD(chrono.ChVectorD(0,0,1), yaw)`.  
  This is a significant correctness issue that will cause runtime errors or incorrect orientation.  
  **Deduct 15 points** for incorrect quaternion construction.

- **Use of `lidar.SetParentFrame(...)`:** Correct usage to update sensor pose dynamically.
