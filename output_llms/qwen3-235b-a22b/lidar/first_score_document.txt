### 2. Correctness (30 points)

- **Use of `SetMesh()` on `ChBody`:**  
  - `SetMesh()` is not a standard method for `ChBody` in PyChrono API. The typical way to add a mesh for visualization is to create a `ChTriangleMeshShape` and add it as a visual shape to the body.  
  - The code calls `mesh_body.SetMesh(mesh)`, which is **not a documented or standard API call**.  
  - Correct approach would be:  
    ```python
    mesh_shape = chrono.ChTriangleMeshShape()
    mesh_shape.SetMesh(mesh)
    mesh_body.AddVisualShape(mesh_shape)
    ```

  - **Deduct 15 points** for incorrect API usage.
