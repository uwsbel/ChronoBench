Here is a well-documented PyChrono simulation script that fulfills the specified requirements. It loads a triangular mesh from a `.obj` file, attaches a lidar sensor to a dynamically moving body, and orbits the sensor around the mesh while applying noise, visualization, and saving filters. The lidar data is printed at each simulation step.

---

### ✅ **PyChrono Simulation Script: Lidar Orbiting a Mesh**

```python
import pychrono as chrono
import pychrono.sensor as sens
import math
import pychrono.irrlicht as chronoirr

# ----------------------------
# Initialize the PyChrono system
# ----------------------------
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, 0))  # No gravity

# ----------------------------
# Load the mesh from a Wavefront .obj file
# ----------------------------
mesh = chrono.ChTriangleMeshConnected()
mesh.LoadWavefrontMesh("path_to_your_mesh.obj", True, True)  # Replace with actual path

# Create a fixed body for the mesh
mesh_body = chrono.ChBody()
mesh_body.SetMesh(mesh)
mesh_body.SetBodyFixed(True)
system.Add(mesh_body)

# ----------------------------
# Create a body for the lidar sensor
# ----------------------------
lidar_body = chrono.ChBody()
lidar_body.SetPos(chrono.ChVectorD(2, 0, 0.5))  # Initial position
lidar_body.SetBodyFixed(False)  # Dynamic body
system.Add(lidar_body)

# ----------------------------
# Create and configure the lidar sensor
# ----------------------------
offset_pose = chrono.ChFrameD(chrono.ChVectorD(0, 0, 0), chrono.ChQuaternionD(1, 0, 0, 0))

lidar = sens.ChLidarSensor(
    lidar_body,          # body to attach
    10,                  # update rate in Hz
    offset_pose,         # offset from body
    800,                 # horizontal samples
    32,                  # vertical samples
    chrono.CH_C_PI,      # horizontal field of view (radians)
    chrono.CH_C_PI / 4,  # vertical field of view
    100                  # max distance
)
lidar.SetName("Lidar Sensor")
lidar.SetLag(0)
lidar.SetCollectionWindow(0.1)

# ----------------------------
# Add filters to the lidar
# ----------------------------
# Add Gaussian noise filter
lidar.AddFilter(sens.ChFilterLidarNoiseGaussian(0.01))  # 1% noise

# Add visualization filter for point cloud
lidar.AddFilter(sens.ChFilterVisualizePointCloud(640, 480, 1.0, "Point Cloud"))

# Add saving filter for point cloud data
lidar.AddFilter(sens.ChFilterSavePtCloud("lidar_data/"))

# ----------------------------
# Create and attach the sensor manager
# ----------------------------
manager = sens.ChSensorManager(system)
manager.AddSensor(lidar)

# ----------------------------
# Set up Irrlicht visualization
# ----------------------------
application = chronoirr.ChIrrApp(system, 'PyChrono Lidar Simulation', chronoirr.dimension2du(800, 600))
application.AddTypicalLights()
application.AddCamera(chrono.ChVectorD(0, 0, 5), chrono.ChVectorD(0, 0, 0))
application.AssetBindAll()
application.AssetUpdateAll()

# ----------------------------
# Simulation loop parameters
# ----------------------------
step_size = 1e-3
end_time = 10
orbit_radius = 2.0
orbit_height = 0.5
omega = 2 * math.pi / 5  # Orbit period of 5 seconds

# ----------------------------
# Main simulation loop
# ----------------------------
while application.GetDevice().run():
    time = system.GetChTime()
    if time > end_time:
        break

    # Update lidar position in orbit
    theta = omega * time
    x = orbit_radius * math.cos(theta)
    y = orbit_radius * math.sin(theta)
    z = orbit_height
    new_pos = chrono.ChVectorD(x, y, z)
    lidar_body.SetPos(new_pos)

    # Compute direction towards the origin (mesh center)
    direction = (chrono.ChVectorD(0, 0, 0) - new_pos).GetNormalized()

    # Compute rotation to align X-axis with direction
    rot = chrono.ChQuaternionD()
    rot.Q_from_Vect(chrono.ChVectorD(1, 0, 0), direction)
    lidar_body.SetRot(rot)

    # Step the simulation
    system.DoStepDynamics(step_size)

    # Update sensor manager
    manager.Update()

    # Access and print lidar data
    buffer = lidar.GetMostRecentBuffer()
    if buffer and buffer.HasData():
        points = buffer.GetPoints()
        print(f"Time: {time:.3f}s, Points: {points.shape[0]}")

    # Render the scene
    application.BeginScene()
    application.DrawAll()
    application.EndScene()
```

---

### 📌 **Notes and Customization**

- **Mesh Path**: Replace `"path_to_your_mesh.obj"` with the actual path to your `.obj` file.
- **Lidar Parameters**: Adjust `horizontal_samples`, `vertical_samples`, `horizontal_fov`, and `max_distance` as needed for your application.
- **Noise Model**: The Gaussian noise filter can be replaced with other models like `ChFilterLidarNoiseUniform` or `ChFilterLidarNoiseNone`.
- **Visualization**: The point cloud visualization can be toggled or replaced with depth image visualization if preferred.
- **Saving Data**: The lidar data is saved in the `lidar_data/` directory. You can change the path or disable saving by removing the `ChFilterSavePtCloud` line.

### 🧪 **Expected Output**

- A 3D visualization of the mesh and the lidar orbiting around it.

- Saved lidar data in the specified directory for post-processing.
