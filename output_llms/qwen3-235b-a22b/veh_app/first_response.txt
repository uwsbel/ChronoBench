```python
import pychrono as chrono
import pychrono.vehicle as vehicle
import pychrono.sensor as sensor
import pychrono.irrlicht as irrlicht

# Initialize the Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the rigid terrain
terrain = vehicle.RigidTerrain(system)
patch_mat = chrono.ChMaterialSurfaceNSC()
patch_mat.SetFriction(0.9)
patch_mat.SetRestitution(0.01)
patch = terrain.AddPatch(patch_mat, chrono.ChCoordsysD(), 200, 200)
patch.SetTexture(chrono.GetChronoDataFile("terrain/textures/tile.png"))
terrain.Initialize()

# Create and initialize the Gator vehicle
gator = vehicle.Gator(system)
gator.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 0.5, 0), chrono.ChQuaternionD(1, 0, 0, 0)))
gator.SetTireType(vehicle.TireModelType_TMEASY)
gator.SetTireStepSize(1e-3)
gator.Initialize()

# Set visualization types for vehicle components
gator.GetChassis().SetVisualizationType(vehicle.VisualizationType_MESH)
for axle in gator.GetAxles():
    for wheel in axle.GetWheels():
        wheel.SetVisualizationType(vehicle.VisualizationType_WIREFRAME)

# Set up Irrlicht visualization
vis = irrlicht.ChIrrApp(system, 'PyChrono Gator Simulation', irrlicht.dimension2du(1024, 768))
vis.AddTypicalLights()
vis.AddCamera(chrono.ChVectorD(0, 3, -6), chrono.ChVectorD(0, 0, 0))
vis.AssetBindAll()
vis.AssetUpdateAll()

# Initialize the interactive driver
driver = vehicle.ChInteractiveDriverIRR(vis)
driver.Initialize()

# Set up the sensor manager with point light and camera
manager = sensor.ChSensorManager(system)

# Add a point light
light = sensor.ChPointLight(chrono.ChVectorF(0, 3, 0), chrono.ChColor(1, 1, 1), 50.0)
manager.AddLight(light)

# Attach a camera to the chassis
camera = sensor.ChCameraSensor(
    gator.GetChassisBody(),
    60,  # Update rate in Hz
    chrono.ChFrameD(chrono.ChVectorD(0, 1, 0), chrono.Q_from_AngAxis(0, chrono.ChVectorD(0, 1, 0))),
    1280,  # Image width
    720,   # Image height
    60     # Field of view in degrees
)
camera.SetName("Camera Sensor")
manager.AddSensor(camera)

# Simulation loop
step_size = 1e-3  # Define step size
while vis.GetDevice().run():
    # Update driver input
    driver.BeginStep()
    driver.Synchronize(system.GetChTime())
    driver.EndStep()

    # Synchronize vehicle, terrain, and sensors
    gator.Synchronize(system.GetChTime(), driver.GetInputs(), terrain)
    terrain.Synchronize(system.GetChTime())
    manager.Update()

    # Advance the simulation
    system.DoStepDynamics(step_size)

    # Update Irrlicht visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
```

### Explanation:
1. **Chrono System Initialization**: The `ChSystemNSC` is created with gravity enabled.
2. **Rigid Terrain**: A `RigidTerrain` object is initialized with a frictional surface and a texture.
3. **Gator Vehicle**: The Gator vehicle is created and positioned. Tire models and visualization types are set.
4. **Irrlicht Visualization**: An Irrlicht application window is set up with default lighting and a camera view.
5. **Interactive Driver**: An interactive driver using Irrlicht's input handling is initialized for user control.
6. **Sensor Manager**: 
   - A `ChSensorManager` is created to handle sensors.
   - A `ChPointLight` is added to illuminate the scene.
   - A `ChCameraSensor` is attached to the vehicle's chassis for rendering images.
7. **Simulation Loop**:
   - The driver inputs are synchronized.
   - Vehicle, terrain, and sensors are updated.
   - Dynamics are stepped forward.
   - The Irrlicht visualization is refreshed each iteration.

This script sets up a complete simulation environment with a controllable Gator vehicle, a textured terrain, and a sensor system capturing camera data, all visualized interactively.
