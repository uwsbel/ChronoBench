Here is a well-documented PyChrono script that simulates a **single mass-spring-damper system** using the `ChLinkTSDA` class to connect a mass to the ground. The simulation includes **Irrlicht visualization** with appropriate lighting and camera settings, and **visual shapes** for both the mass and the spring.

---

### ✅ Key Features Implemented

- **Mass-Spring-Damper System** using `ChLinkTSDA`
- **Irrlicht Visualization** with lighting and camera
- **Visual Shapes** for the mass (box) and spring
- **Default Linear Spring-Damper Parameters** (K = 100 N/m, R = 10 Ns/m)
- **Gravity Enabled** (default in PyChrono)

---

### 🧩 Python Script

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Create the physical system
sys = chrono.ChSystemNSC()

# Create the ground body (fixed)
ground = chrono.ChBody()
sys.Add(ground)
ground.SetBodyFixed(True)

# Create the mass body
mass = chrono.ChBody()
sys.Add(mass)
mass.SetMass(1.0)  # Mass in kg
mass.SetInertiaXX(chrono.ChVector(1, 1, 1))  # Arbitrary inertia
mass.SetPos(chrono.ChVector(0, -1, 0))  # Position the mass below the ground

# Add a box shape to the mass for visualization
box_shape = chrono.ChBoxShape()
box_shape.GetBoxGeometry().Size = chrono.ChVector(0.1, 0.1, 0.1)  # Size of the box
mass.GetAssets().push_back(box_shape)

# Create the TSDA (Translational Spring-Damper Actuator) link
tsda = chrono.ChLinkTSDA()

# Initialize the TSDA between the ground and the mass
# Attach at (0,0,0) on both bodies (relative to their own coordinate systems)
tsda.Initialize(ground, mass, chrono.ChVector(0, 0, 0), chrono.ChVector(0, 0, 0))

# Set spring and damping coefficients
tsda.SetSpringK(100)   # Spring stiffness (N/m)
tsda.SetDampingR(10)   # Damping coefficient (Ns/m)

# Set the rest length of the spring to match the initial distance between the two points
tsda.SetRestLength(1.0)  # Matches the initial distance between ground and mass

# Add the TSDA to the system
sys.Add(tsda)

# Add a visual spring shape to the TSDA link
spring_shape = chrono.ChSpringShape()
spring_shape.SetSpringGeometry(0.05, 0.4, 0.02, 10, 20)  # (radius, length, wire_radius, num_coils, num_segments)
tsda.AddAsset(spring_shape)

# Create the Irrlicht visualization application
vis = chronoirr.ChIrrApp(sys, 'Mass-Spring-Damper System', chronoirr.dimension2du(800, 600))

# Add typical Irrlicht components
vis.AddTypicalSky()
vis.AddTypicalLights()
vis.AddTypicalCamera(chronoirr.vector3df(0, -1, 3))  # Camera position

# Bind and update all assets
vis.AssetBindAll()
vis.AssetUpdateAll()

# Simulation loop
while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()
    chronoirr.drawAll(vis)
    vis.EndScene()
    sys.DoStepDynamics(1e-3)  # Time step of 1 millisecond
```

---

### 📌 Notes

- **Gravity** is enabled by default in `ChSystemNSC`, so the mass will be pulled downward, causing the spring to stretch and oscillate.
- The **initial position** of the mass is set such that the spring is at its **rest length**, so the system starts in equilibrium.
- The **camera** is positioned to view the system from above, allowing clear visualization of the mass and spring.
- The **spring visualization** uses `ChSpringShape` to render a coiled spring between the two attachment points.

---

### 🧪 Expected Behavior

- The mass will oscillate vertically due to the spring-damper system.
- The spring will stretch and compress as the mass moves.
- The simulation will run in real-time with a 1 millisecond time step for smooth dynamics.

This script provides a complete and visually informative simulation of a basic mass-spring-damper system using PyChrono and Irrlicht.
