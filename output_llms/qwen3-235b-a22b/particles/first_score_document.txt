- **Body Creation**:  
  The `create_particle()` function creates bodies with randomized position, velocity, orientation, mass, and inertia. It sets collision shapes (sphere or box), builds the collision model, and adds the body to the system.

The API documentation shows contact materials are typically assigned to collision models or contact containers, not directly to bodies.   - The collision shapes are added via `body.GetCollisionModel().AddSphere()` or `.AddBox()`, but the collision model is not cleared before adding shapes, which can cause issues if the function is called multiple times on the same body (not a problem here since bodies are new each time).
