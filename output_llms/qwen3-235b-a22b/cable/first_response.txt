```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize the PyChrono system
sys = chrono.ChSystemNSC()

# Beam parameters
length = 1.0  # Length of the beam in meters
num_elements = 10  # Number of ANCF cable elements
radius = 0.01  # Radius of the beam cross-section
young_modulus = 1e8  # Young's modulus (Pa)
density = 7800  # Density (kg/m^3)
area = chrono.CH_C_PI * radius**2  # Cross-sectional area
inertia = (chrono.CH_C_PI / 4.0) * radius**4  # Area moment of inertia

# Create the FEA mesh
mesh = chrono.ChMesh()

# Generate nodes along the beam's length
nodes = []
dx = length / num_elements
for i in range(num_elements + 1):
    pos = chrono.ChVectorD(i * dx, 0, 0)  # Nodes along the x-axis
    node = chrono.ChNodeFEAxyzD(pos)  # Create a node with position and gradient DOFs
    nodes.append(node)
    mesh.AddNode(node)  # Add node to the mesh

# Create ANCF cable elements between consecutive nodes
for i in range(num_elements):
    element = chrono.ChElementCableANCF()  # Create an ANCF cable element
    element.SetNodes(nodes[i], nodes[i+1])  # Connect to two nodes
    element.SetDiameter(2 * radius)  # Set diameter for visualization
    element.SetArea(area)  # Cross-sectional area
    element.SetI(inertia)  # Area moment of inertia
    element.SetE(young_modulus)  # Young's modulus
    element.SetDensity(density)  # Material density
    mesh.AddElement(element)  # Add element to the mesh

# Add the mesh to the system
sys.Add(mesh)

# Fix the first node (hinged end)
nodes[0].SetFixed(True)

# Set up Irrlicht visualization
app = chronoirr.ChIrrApp(sys, 'ANCF Beam Simulation', chronoirr.dimension2du(1024, 768))
app.AddTypicalLights()
app.AddCamera(chronoirr.vector3df(0, 0, -2), chronoirr.vector3df(0, 0, 0))

# Create visualization assets for the mesh
vis_shape = chrono.ChVisualShapeFEA(mesh)
vis_shape.SetFEMdataType(chrono.ChVisualShapeFEA.DataType_SURFACE)
vis_shape.SetWireframe(True)  # Show mesh as wireframe
mesh.AddVisualShapeFEA(vis_shape)

# Finalize visualization setup
app.AssetBindAll()
app.AssetUpdateAll()

# Simulation loop
while app.GetDevice().run():
    app.BeginScene()
    app.DrawAll()
    app.EndScene()
    sys.DoStepDynamics(1e-3)  # Advance the simulation by a time step
```

### Explanation:
1. **System Initialization**: A `ChSystemNSC` is created to handle non-smooth contact dynamics.
2. **Beam Setup**: 
   - The beam is divided into `num_elements` ANCF cable elements with `num_elements + 1` nodes.
   - Nodes are positioned along the x-axis, and each node uses `ChNodeFEAxyzD` to support position and gradient degrees of freedom.
3. **Element Properties**: Each `ChElementCableANCF` is configured with geometric and material properties (area, inertia, Young's modulus, density).
4. **Constraints**: The first node is fixed to simulate a hinge using `SetFixed(True)`.
5. **Visualization**: 
   - The Irrlicht engine is initialized with a camera and lights.
   - A `ChVisualShapeFEA` is added to the mesh to visualize the beam in wireframe mode.
6. **Simulation Loop**: The system is stepped forward in time with a fixed time step of 1 ms, and the Irrlicht window updates to show the beam's deformation. 

This script simulates a deformable beam under gravity with one end fixed, visualizing the nodal displacements and element deformation using PyChrono's FEA and Irrlicht modules.
