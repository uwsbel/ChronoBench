Here is a PyChrono simulation script based on the provided instructions:

```python
# Import necessary modules
import pychrono.core as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as chronoirr
import numpy as np

# Initialize PyChrono environment and core components
chrono.SetChronoDataPath('/path/to/chrono/data/')
my_system = chrono.ChSystemNSC()

# Add the HMMWV vehicle with initial conditions
vehicle = veh.ChPart_HMMWV()
vehicle.SetInitPosition(chrono.ChVectorD(0, 1.5, 0))
vehicle.SetInitRotation(chrono.ChQuaternionD(1, 0, 0, 0))
my_system.Add(vehicle)

# Add SCM deformable terrain with defined soil parameters
terrain = veh.SCMDeformableTerrain(my_system)
terrain.SetSoilParameters(0.1,  # cohesion
                          30,   # friction angle
                          0.01, # damping ratio
                          1e6,  # elastic modulus
                          0.3   # poisson ratio
                          )
terrain.SetHeightMap('/path/to/heightmap.png')
my_system.Add(terrain)

# Initialize driver system for vehicle control
driver = veh.ChIrrNodeDriver(vehicle)
driver.Initialize()

# Create real-time visualization using Irrlicht
application = chronoirr.ChVisualSystemIrrlicht()
application.SetWindowTitle('PyChrono Simulation')
application.SetWindowSize(800, 600)
application.SetCameraPosition(chrono.ChVectorD(0, 5, -10))
application.SetCameraTarget(chrono.ChVectorD(0, 1.5, 0))
application.AddSkyBox()
application.AddTypicalLights()
application.AddCamera()
application.AddShadowMaps()

# Simulation loop
application.AssetBindAll()
application.AssetUpdateAll()
application.AddDriver(driver)

while application.GetDevice().run():
    # Synchronize and advance vehicle, terrain, driver, and visual system
    my_system.DoStepDynamics(chrono.ChTimeStep(1e-3))
    application.BeginScene()
    application.DrawAll()
    application.EndScene()
```

Note: Replace `'/path/to/chrono/data/'` and `'/path/to/heightmap.png'` with the actual paths to your Chrono data directory and height map image, respectively.

This script creates a PyChrono simulation with an HMMWV vehicle and SCM deformable terrain, and visualizes it using Irrlicht. The vehicle is controlled by a driver system, and the simulation loop advances the vehicle, terrain, driver, and visual system at each timestep while maintaining real-time execution.
