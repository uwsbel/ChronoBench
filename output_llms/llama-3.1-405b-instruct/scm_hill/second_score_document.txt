The parameters `-1,1, 0.02` are unclear and undocumented in the provided API snippet. This could be a misuse or a custom extension.

  ```python
  Initialize(length, width, mesh_resolution_x, mesh_resolution_y)
  ```

  ```python
  Initialize(height_map_file, length, width, mesh_resolution_x, mesh_resolution_y, height_scale)
  ```

  So the call is likely:

  ```python
  terrain.Initialize(height_map_file, length, width, mesh_res_x, mesh_res_y, height_scale)
  ```
