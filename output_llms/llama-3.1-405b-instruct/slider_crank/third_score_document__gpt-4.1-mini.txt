### 2. Correctness (30 points)

- **API Usage:**  
  - `ChBodyEasyCylinder` is called with `chrono.ChAxis_Y` as the first argument. According to the API, `ChBodyEasyCylinder` expects `(radius, height, density, visualize=True, collision=True, material=None)`. The first argument should be radius, not an axis. This is a **significant API misuse** that will cause an error or incorrect body creation.  
  - The crank cylinder is created incorrectly due to this misuse.  
  - Similarly, the piston cylinder is created with the same incorrect signature.  
- **Joint Initialization:**  
  - Motor joint is initialized with `chrono.ChFramed(crank_center)`. The API expects `chrono.ChCoordsysD` or `chrono.ChCoordsys` for the frame, not `ChFramed`. `ChFramed` is not a standard PyChrono class per the documentation. This is an **incorrect use of API** and will cause an error or unexpected behavior.  
  - The same applies to spherical and planar joints: they use `chrono.ChFramed(...)` instead of `chrono.ChCoordsysD` or `chrono.ChCoordsys`.  
- **Motor Speed Function:**  
  - The motor speed function is created as `chrono.ChFunctionConst(chrono.CH_PI)`, but the method called is `SetMotorFunction()`. According to the API, the method is `SetSpeedFunction()`. This is an **incorrect API call**.  
- **Simulation Loop:**  
  - The time step is `1e-3`, which is reasonable.  
  - The loop calls `vis.Run()`, `BeginScene()`, `Render()`, `EndScene()`, and `sys.DoStepDynamics()`, which is correct.  
  - The condition to close the device after 20 seconds is done by `vis.GetDevice().closeDevice()`, which is acceptable but could be improved by breaking the loop instead. Not a correctness error, more of a style point.

**Deductions:**

- Incorrect `ChBodyEasyCylinder` usage (twice): **-15 points** (counted once since it's the same error repeated)  
- Incorrect use of `chrono.ChFramed` instead of `chrono.ChCoordsysD` for joint initialization (multiple joints): **-15 points**  
- Incorrect method name `SetMotorFunction` instead of `SetSpeedFunction`: **-15 points**

**Subtotal Correctness: 30 - 45 = -15 points (minimum 0)**
