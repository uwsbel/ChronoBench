Below is a sample Python script that demonstrates how to create the specified simulation using PyChrono:

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import pychrono.scm as scm

# Initialize the PyChrono environment
chrono.SetChronoDataPath('/path/to/chrono/data/')

# Create the simulation system
sys = chrono.ChSystemNSC()

# Create the SCM terrain
terrain = scm.ChSoil()
terrain.SetSoilParameters(scm.ChSoil.Parameters(scm.ChSoil.Type_SAND,  # Soil type
                                                 0.1,  # Friction angle (rad)
                                                 0.05,  # Dilation angle (rad)
                                                 0.0,  # Cohesion (Pa)
                                                 0.0,  # Elastic modulus (Pa)
                                                 0.0))  # Poisson's ratio

# Create a moving patch that follows the vehicle chassis
patch = scm.ChMovingPatch()
patch.SetSize(10, 10)  # Size of the patch (m)
patch.SetLocation(chrono.ChVectorD(0, 0, 0))  # Initial location of the patch
terrain.AddMovingPatch(patch)

# Create the HMMWV vehicle
vehicle = veh.ChPart()
vehicle.SetMass(2500)  # Mass of the vehicle (kg)
vehicle.SetInertiaXX(500)  # Moment of inertia about the x-axis (kg*m^2)
vehicle.SetInertiaYY(1000)  # Moment of inertia about the y-axis (kg*m^2)
vehicle.SetInertiaZZ(1500)  # Moment of inertia about the z-axis (kg*m^2)
vehicle.SetPos(chrono.ChVectorD(0, 1, 0))  # Initial position of the vehicle
vehicle.SetRot(chrono.Q_from_AngY(0.5))  # Initial orientation of the vehicle

# Add a rigid tire model to the vehicle
tire = veh.ChRigidTire()
tire.SetRadius(0.5)  # Radius of the tire (m)
tire.SetWidth(0.2)  # Width of the tire (m)
vehicle.AddTire(tire)

# Add mesh visualization to all vehicle components
vehicle.AddVisualizationMesh('/path/to/vehicle/mesh.obj')

# Create an interactive driver system
driver = veh.ChIrrDriver()
driver.Initialize()
driver.SetSteeringIncrement(0.1)  # Steering increment (rad)
driver.SetThrottleIncrement(0.1)  # Throttle increment
driver.SetBrakingIncrement(0.1)  # Braking increment

# Create the Irrlicht application
app = chronoirr.ChIrrApp(sys, 'HMMWV Simulation', chronoirr.dimension2du(800, 600))

# Set up the simulation
app.AddTypicalSky()
app.AddTypicalLights()
app.AddCamera(chrono.ChVectorD(0, 2, -5))
app.SetTimestep(0.02)  # Time step (s)
app.SetSolverType(chrono.ChSolver.Type_APGD)  # Solver type

# Add the vehicle and terrain to the simulation
sys.Add(vehicle)
sys.Add(terrain)

# Run the simulation
while app.GetDevice().run():
    # Update the vehicle dynamics
    driver.Update()
    vehicle.Update(0.02)

    # Update the moving patch
    patch.SetLocation(vehicle.GetPos())

    # Render the scene
    app.BeginScene()
    app.DrawAll()
    app.EndScene()

    # Limit the simulation to 50 frames per second
    app.GetDevice().setEventReceiver(app.GetEventReceiver())
    app.GetDevice().runOnEvent()
```

This script creates a PyChrono simulation of a full HMMWV on SCM deformable terrain using Irrlicht for visualization. It initializes the vehicle with specific parameters, applies mesh visualization to all vehicle components, and configures the SCM terrain with custom soil parameters. The script also sets up an interactive driver system to control steering, throttle, and braking, and ensures the simulation runs in real time, updating vehicle dynamics and rendering the scene at 50 frames per second.

Note that you'll need to replace `'/path/to/chrono/data/'` and `'/path/to/vehicle/mesh.obj'` with the actual paths to the Chrono data directory and the vehicle mesh file, respectively. Additionally, you may need to adjust the parameters and settings to match your specific simulation requirements.
