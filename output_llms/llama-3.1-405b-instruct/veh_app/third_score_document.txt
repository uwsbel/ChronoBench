  According to PyChrono API, `ChBodyEasyCylinder` expects parameters: radius, height, density, and optionally visualization and collision flags.   **Deduct 15 points** for incorrect use of `ChBodyEasyCylinder`. The correct call should be something like:  
  ```python
  cylinder = chrono.ChBodyEasyCylinder(0.5, 1, 1000)
  ```  
  If an orientation is needed, it should be set via `SetRot()` or similar.
