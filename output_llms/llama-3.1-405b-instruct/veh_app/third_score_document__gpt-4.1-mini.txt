  According to best practices, this should be set *before* vehicle initialization to ensure all collision models are created with the correct system. Setting it after might cause inconsistent collision behavior or require reinitialization.

  ```python

  ```  
  According to the API, `ChBodyEasyCylinder` expects `(radius, height, density, ...)` as parameters. Passing `chrono.ChAxis_Y` as the first argument is incorrect. This will cause an error or unexpected behavior.  
  **Deduct 15 points** for incorrect API usage here.
