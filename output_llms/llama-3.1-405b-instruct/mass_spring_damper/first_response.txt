Below is a Python script that follows the instructions to simulate a mass-spring-damper system using PyChrono. This script initializes the environment, sets up a mass-spring-damper system, and includes visualization using Irrlicht.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr

# Initialize the PyChrono environment
chrono.SetChronoDataPath("/path/to/chrono/data/")  # Set path to Chrono::Engine data directory

# Create a Chrono::Engine physical system
sys = chrono.ChSystemNSC()

# Create the ground body
ground = chrono.ChBodyEasyBox(sys,  # Parent system
                              10, 10, 1,  # Box dimensions (x, y, z)
                              1000,  # Density
                              True,  # Visualization
                              True)  # Collision
ground.SetBodyFixed(True)

# Create the mass body
mass = chrono.ChBodyEasySphere(sys,  # Parent system
                               0.5,  # Radius
                               1000,  # Density
                               True,  # Visualization
                               True)  # Collision
mass.SetPos(chrono.ChVectorD(0, 0, 5))  # Initial position

# Create a ChLinkTSDA to connect the mass to the ground
spring = chrono.ChLinkTSDA()
spring.Initialize(mass, ground,  # Connected bodies
                 chrono.ChFrameD(chrono.ChVectorD(0, 0, 0), chrono.QUNIT),  # Spring reference frame
                 chrono.ChFrameD(chrono.ChVectorD(0, 0, 5), chrono.QUNIT))  # Spring end frame
spring.SetSpringCoefficient(100.0)  # Spring coefficient (N/m)
spring.SetDampingCoefficient(10.0)  # Damping coefficient (N*s/m)
sys.AddLink(spring)

# Create an Irrlicht application
app = chronoirr.ChIrrApp(sys, "Mass-Spring-Damper System", chronoirr.dimension2du(800, 600))
app.AddTypicalSky()
app.AddTypicalLights()
app.AddCamera(chronoirr.vector3df(0, 5, -10),  # Camera position
              chronoirr.vector3df(0, 0, 0))  # Camera target

# Set up visualization assets for the mass and spring
app.AssetBindAll()
app.AssetUpdateAll()

# Simulation loop
app.SetTimestep(0.01)  # Time step (s)
app.SetTryRealtime(True)
while app.GetDevice().run():
    app.BeginScene()
    app.DrawAll()
    app.DoStep()
    app.EndScene()

# Clean up
del app
del sys
```

This script initializes a PyChrono environment, creates a ground body and a mass body, connects the mass to the ground using a `ChLinkTSDA`, and sets up Irrlicht visualization with lighting and camera settings. The mass-spring-damper system is simulated, and the scene is updated in real-time.

Please replace `"/path/to/chrono/data/"` with the actual path to your Chrono::Engine data directory.

Make sure you have the necessary dependencies installed, including PyChrono and Irrlicht. If you encounter any issues or have questions, feel free to ask!
