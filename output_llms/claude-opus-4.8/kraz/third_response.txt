### Summary of changes and corrections

**Corrections / important notes**
- The terrain mesh patch no longer calls `SetTexture` with tiling parameters (textures are baked into a mesh patch; only `SetColor` is kept).
- Both vehicles must share **one** `ChSystem`; the sedan is therefore created with `veh.BMW_E90(vehicle.GetSystem())` so it lives in the same world as the truck.

**Modifications per instructions**
1. **Truck initial pose changed** — `initLoc` moved to `(-10, 0, 0.5)`.
2. **Sedan initial pose added** — `initLoc_sedan`, `initRot_sedan`.

4. **Terrain switched to the predefined highway mesh** — `AddPatch(..., veh.GetDataFile("terrain/meshes/Highway_col.obj"))`.
5. **Second vehicle (sedan) created and initialized**.
6. **Second driver system added** — `driver_sedan = veh.ChDriver(sedan.GetVehicle())`.
7. **Sedan controlled with fixed throttle/steering** — `SetThrottle(0.5)`, `SetSteering(0.0)`.
8. **Truck tractor and trailer states stored** — appended to `tractor_states` / `trailer_states` each step.
