Here's a complete PyChrono simulation demonstrating beam finite elements with FEA, mesh creation, and Irrlicht visualization:

```python
import pychrono as chrono
import pychrono.fea as fea
import pychrono.irrlicht as chronoirr
import math

# ---------------------------------------------------------------------
# 1. Initialize the PyChrono environment and core components
# ---------------------------------------------------------------------

# Create the physical system
sys = chrono.ChSystemSMC()

# Set gravitational acceleration
sys.SetGravitationalAcceleration(chrono.ChVector3d(0, -9.81, 0))

# ---------------------------------------------------------------------
# 2. Create a mesh composed of beams and nodes
# ---------------------------------------------------------------------

# Create a FEA mesh (container for nodes and elements)
mesh = fea.ChMesh()

# ---------------------------------------------------------------------
# Define the section properties of the beam.
# We use an Euler-Bernoulli beam section with given geometry & material.
# ---------------------------------------------------------------------
beam_section = fea.ChBeamSectionEulerAdvanced()

# Geometry of the cross-section (rectangular)
beam_width  = 0.012   # [m]
beam_height = 0.025   # [m]
beam_section.SetAsRectangularSection(beam_width, beam_height)

# Material properties
beam_section.SetYoungModulus(0.01e9)        # Young's modulus [Pa]
beam_section.SetShearModulusFromPoisson(0.3)  # Shear modulus from Poisson ratio
beam_section.SetRayleighDamping(0.000)       # Rayleigh damping
beam_section.SetDensity(1000)                # Density [kg/m^3]

# ---------------------------------------------------------------------
# Create the beam nodes manually
# ---------------------------------------------------------------------
beam_length = 0.5            # total length of the beam [m]
num_elements = 8             # number of beam elements
num_nodes = num_elements + 1

nodes = []
for i in range(num_nodes):
    x = i * (beam_length / num_elements)
    # Create a node with a position and an aligned frame (rotation = identity)
    node = fea.ChNodeFEAxyzrot(chrono.ChFramed(chrono.ChVector3d(x, 0, 0)))
    mesh.AddNode(node)
    nodes.append(node)

# Fix the first node (clamped boundary condition)
nodes[0].SetFixed(True)

# ---------------------------------------------------------------------
# Create the beam elements connecting the nodes
# ---------------------------------------------------------------------
for i in range(num_elements):
    element = fea.ChElementBeamEuler()
    element.SetNodes(nodes[i], nodes[i + 1])
    element.SetSection(beam_section)
    mesh.AddElement(element)

# ---------------------------------------------------------------------
# Apply a force/torque at the free end node
# ---------------------------------------------------------------------
nodes[-1].SetForce(chrono.ChVector3d(0, -1.0, 0))     # downward force [N]
# nodes[-1].SetTorque(chrono.ChVector3d(0, 0, 0.1))   # optional torque

# Add the mesh to the system
sys.Add(mesh)

# ---------------------------------------------------------------------
# 3. Add visualization for the FEA mesh
# ---------------------------------------------------------------------

# Visualize the beam elements (e.g. by bending moment magnitude)
vis_beam = chrono.ChVisualShapeFEA(mesh)
vis_beam.SetFEMdataType(chrono.ChVisualShapeFEA.DataType_ELEM_BEAM_MZ)
vis_beam.SetColorscaleMinMax(-0.4, 0.4)
vis_beam.SetSmoothFaces(True)
vis_beam.SetWireframe(False)
mesh.AddVisualShapeFEA(vis_beam)

# Visualize the nodes as small coordinate systems / points
vis_nodes = chrono.ChVisualShapeFEA(mesh)
vis_nodes.SetFEMglyphType(chrono.ChVisualShapeFEA.GlyphType_NODE_CSYS)
vis_nodes.SetFEMdataType(chrono.ChVisualShapeFEA.DataType_NONE)
vis_nodes.SetSymbolsThickness(0.006)
vis_nodes.SetSymbolsScale(0.01)
vis_nodes.SetZbufferHide(False)
mesh.AddVisualShapeFEA(vis_nodes)

# ---------------------------------------------------------------------
# Create the Irrlicht visualization system
# ---------------------------------------------------------------------
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle("PyChrono - Beam Finite Elements (FEA)")
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile("logo_pychrono_alpha.png"))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(0.0, 0.3, -0.6),
              chrono.ChVector3d(0.25, 0.0, 0.0))
vis.AddTypicalLights()

# ---------------------------------------------------------------------
# Configure the solver and integrator (good for stiff FEA problems)
# ---------------------------------------------------------------------
solver = chrono.ChSolverMINRES()
sys.SetSolver(solver)
solver.SetMaxIterations(200)
solver.SetTolerance(1e-12)
solver.EnableDiagonalPreconditioner(True)
solver.SetVerbose(False)

# Use HHT time integrator for accuracy
sys.SetTimestepperType(chrono.ChTimestepper.Type_HHT)
stepper = chrono.CastToChTimestepperHHT(sys.GetTimestepper())
if stepper is not None:
    stepper.SetAlpha(-0.2)
    stepper.SetMaxIters(8)
    stepper.SetAbsTolerances(1e-6)

# ---------------------------------------------------------------------
# 4. Run the simulation loop
# ---------------------------------------------------------------------
time_step = 0.001

while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    sys.DoStepDynamics(time_step)

print("Simulation finished.")
```

## Key Components Explained

**1. Physical System & Core Setup**
- `ChSystemSMC()` creates a smooth-contact physical system suitable for FEA.
- Gravity is set along the negative Y-axis.

**2. Beam Mesh & Nodes**
- `ChMesh` is the container for all FEA nodes and elements.
- `ChBeamSectionEulerAdvanced` defines geometry (rectangular cross-section) and material (Young's modulus, shear modulus, density, damping).
- `ChNodeFEAxyzrot` nodes carry both position and rotation degrees of freedom.
- The first node is **fixed** to create a cantilever beam, and a downward force is applied at the free tip.

**3. Beam Elements**
- `ChElementBeamEuler` connects consecutive nodes using the defined section.

**4. Visualization**
- Two `ChVisualShapeFEA` objects: one colors the beam by bending moment (`ELEM_BEAM_MZ`), the other renders node coordinate systems.

**5. Solver & Loop**
- `ChSolverMINRES` with HHT integrator provides stable results for stiff FEA systems.
- The Irrlicht render loop advances the dynamics with a fixed time step.

You can tune `num_elements`, `beam_length`, material properties, or the tip force to observe different bending behaviors in real time.
