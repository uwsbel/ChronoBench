Certainly! Below is a complete PyChrono script that sets up a single mass-spring-damper system using `ChLinkTSDA`, with Irrlicht visualization, lighting, camera, and visual shapes for both the mass and the spring. The script uses default parameters for the spring-damper.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath(chrono.GetChronoDataPath())
system = chrono.ChSystemNSC()

# 2. Add the ground (fixed body)
ground = chrono.ChBody()
ground.SetBodyFixed(True)
system.Add(ground)

# 3. Add the mass (dynamic body)
mass = 1.0  # kg
size = chrono.ChVectorD(0.2, 0.2, 0.2)  # box size
init_pos = chrono.ChVectorD(0, 0.5, 0)  # initial position

body = chrono.ChBodyEasyBox(size.x, size.y, size.z,  # x, y, z size
                            mass,                   # mass
                            True,                   # visualization?
                            True)                   # collision?
body.SetPos(init_pos)
system.Add(body)

# 4. Add the spring-damper (ChLinkTSDA)
# Anchor point on ground
pos_ground = chrono.ChVectorD(0, 0, 0)
# Anchor point on mass (relative to mass center)
pos_body = chrono.ChVectorD(0, -size.y/2, 0)

spring = chrono.ChLinkTSDA()
spring.Initialize(ground, body, False, pos_ground, body.GetPos() + pos_body)

# Default parameters
spring.SetSpringCoefficient(100)   # N/m
spring.SetDampingCoefficient(2)    # N*s/m
spring.SetRestLength(0.5)          # m

system.AddLink(spring)

# 5. Visualization: add a visual shape to the mass (already present with ChBodyEasyBox)
# Add a visual spring shape
spring_shape = chrono.ChLinkTSDAvisualShape()
spring_shape.SetColor(chrono.ChColor(0.6, 0.8, 0.2))
spring_shape.SetResolution(80)
spring.AddVisualShape(spring_shape)

# 6. Irrlicht visualization setup
application = chronoirr.ChVisualSystemIrrlicht()
application.AttachSystem(system)
application.SetWindowSize(1024, 768)
application.SetWindowTitle('PyChrono: Mass-Spring-Damper (ChLinkTSDA)')
application.Initialize()
application.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
application.AddSkyBox()
application.AddCamera(chrono.ChVectorD(1.0, 0.7, 1.0), chrono.ChVectorD(0, 0.2, 0))  # Camera position and target
application.AddTypicalLights()

# 7. Simulation loop
application.AssetBindAll()
application.AssetUpdateAll()

timestep = 0.001

while application.Run():
    application.BeginScene()
    application.DrawAll()
    application.EndScene()
    system.DoStepDynamics(timestep)
```

**How it works:**
- A fixed ground and a dynamic box mass are created.
- The mass is connected to the ground with a `ChLinkTSDA` spring-damper, using default parameters.
- The mass is visualized as a box; the spring is visualized with a colored, coiled shape.
- Irrlicht visualization is set up with lighting, camera, and a skybox.
- The simulation runs in real time, showing the oscillation of the mass.

**Requirements:**  
Make sure you have PyChrono and its Irrlicht module installed.  
You can run this script as-is to see the mass-spring-damper system in action.
