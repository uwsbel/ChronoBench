Certainly! Below is a **PyChrono** simulation script that creates a UAZBUS vehicle on a rigid terrain, sets up a driver, and visualizes the simulation in real time using Irrlicht. The script includes initialization, parameter settings, and a simulation loop as per your instructions.

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr
import time

# 1. Initialize PyChrono
chrono.SetChronoDataPath(chrono.GetChronoDataPath())
veh.SetDataPath(chrono.GetChronoDataPath() + 'vehicle/')

# 2. Create the physical system
system = chrono.ChSystemNSC()

# 3. Create the vehicle (UAZBUS)
initLoc = chrono.ChVectorD(0, 0, 1.0)  # Initial position (x, y, z)
initRot = chrono.QUNIT  # No initial rotation
vehicle = veh.UAZBUS_Vehicle(system, False, veh.ChassisCollisionType.NONE)
vehicle.SetInitPosition(chrono.ChCoordsysD(initLoc, initRot))
vehicle.SetInitFwdVel(0.0)
vehicle.Initialize()

# 4. Create the terrain
terrain = veh.RigidTerrain(system)
patch = terrain.AddPatch(
    chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.QUNIT),
    length=200.0, width=200.0
)
patch.SetContactFrictionCoefficient(0.9)
patch.SetContactRestitutionCoefficient(0.01)
patch.SetMaterialSurface(chrono.ChContactMaterialNSC())
patch.SetTexture(veh.GetDataFile("terrain/textures/grass.jpg"), 200, 200)
terrain.Initialize()

# 5. Create the driver system (simple driver)
driver = veh.ChDriver(vehicle)
# Optionally, use a more advanced driver:
# driver = veh.ChIrrGuiDriver(vehicle, irr.device)
# For now, set constant throttle, steering, and braking
driver_inputs = veh.DriverInputs()
driver_inputs.m_throttle = 0.5
driver_inputs.m_steering = 0.0
driver_inputs.m_braking = 0.0

# 6. Visualization with Irrlicht
vis = veh.ChWheeledVehicleIrrApp(vehicle, 'UAZBUS Demo', irr.dimension2du(1024,768))
vis.SetSkyBox()
vis.AddTypicalLights(chrono.ChVectorD(30, 100, 120), chrono.ChVectorD(-30, -80, 100), 250, 130)
vis.AddTypicalLogo()
vis.SetChaseCamera(chrono.ChVectorD(0.0, 0.0, 1.75), 6.0, 0.5)
vis.SetTimestep(0.01)
vis.AssetBindAll()
vis.AssetUpdateAll()

# 7. Simulation loop
step_size = 0.01
realtime_timer = chrono.ChRealtimeStepTimer()

while vis.Run():
    vis.BeginScene()
    vis.DrawAll()

    # Synchronize systems
    time = system.GetChTime()
    driver.Synchronize(time)
    terrain.Synchronize(time)
    vehicle.Synchronize(time, driver_inputs, terrain)
    vis.Synchronize('UAZBUS Demo', driver_inputs)

    # Advance simulation
    driver.Advance(step_size)
    terrain.Advance(step_size)
    vehicle.Advance(step_size)
    vis.Advance(step_size)
    system.DoStepDynamics(step_size)

    vis.EndScene()
    realtime_timer.Spin(step_size)

# Clean up
vis.GetDevice().closeDevice()
```

**Key Points:**
- **Vehicle:** UAZBUS, initialized at (0,0,1.0), no initial rotation, zero forward velocity.
- **Terrain:** Rigid, 200x200 meters, friction 0.9, restitution 0.01, grass texture.
- **Driver:** Simple constant input (throttle 0.5, steering 0, braking 0).
- **Visualization:** Irrlicht, chase camera, skybox, lighting, real-time step.
- **Simulation Loop:** Synchronizes and advances all components, maintains real-time execution.

**Note:**  
- Make sure you have the PyChrono Python bindings installed and the Chrono data path set correctly.
- You can adjust driver inputs or use a more interactive driver if desired.
- This script is ready to run as-is for a basic UAZBUS simulation.
