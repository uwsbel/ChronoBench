Certainly! Below is a **PyChrono** simulation script that fulfills your requirements. This script:

- Initializes the Chrono system with gravity.
- Adds a rigid ground body.
- Loads a Turtlebot robot at a specified position and orientation.
- Sets up Irrlicht visualization with camera and lighting.
- Implements a simulation loop where the Turtlebot's left and right wheel motors are controlled to turn at specified times.
- Updates and renders the simulation in real time.

**Note:** This script assumes you have the PyChrono and PyChrono::Robot modules installed, and that the Turtlebot URDF or model is available. Adjust the path to the Turtlebot model as needed.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.robot as robot
import math

# 1. Initialize Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# 2. Add rigid ground body
ground = chrono.ChBodyEasyBox(2, 2, 0.1, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, 0, -0.05))
ground.SetBodyFixed(True)
system.Add(ground)

# 3. Load Turtlebot robot
# Adjust the path to your Turtlebot model as needed
turtlebot = robot.Turtlebot(system)
# Set initial position and orientation
init_pos = chrono.ChVectorD(0, 0, 0.1)
init_rot = chrono.Q_from_AngZ(math.radians(0))  # Facing along X axis
turtlebot.SetChassisPosition(init_pos)
turtlebot.SetChassisRotation(init_rot)

# 4. Visualization with Irrlicht
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('PyChrono Turtlebot Simulation')
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(1, 1, 0.7), chrono.ChVectorD(0, 0, 0.1))
vis.AddTypicalLights()

# 5. Simulation parameters
timestep = 0.01
end_time = 10.0

# Motor control parameters
left_speed = 0.0
right_speed = 0.0
max_speed = 5.0  # rad/s

# 6. Simulation loop
time = 0.0
while vis.Run() and time < end_time:
    # Control logic: turn left for 2s, then right for 2s, then go straight
    if time < 2.0:
        left_speed = 1.0
        right_speed = 2.0
    elif time < 4.0:
        left_speed = 2.0
        right_speed = 1.0
    else:
        left_speed = 2.0
        right_speed = 2.0

    # Apply motor speeds
    turtlebot.SetMotorSpeeds(left_speed, right_speed)

    # Advance simulation
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    system.DoStepDynamics(timestep)
    time += timestep

vis.GetDevice().closeDevice()
```

---

**Key Points:**
- The Turtlebot is initialized at (0, 0, 0.1) facing along the X axis.
- The robot turns left for 2 seconds, right for 2 seconds, then goes straight.
- The simulation uses Irrlicht for real-time visualization.
- Adjust the Turtlebot model path if needed.
