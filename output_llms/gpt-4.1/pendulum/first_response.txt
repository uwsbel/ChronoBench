Certainly! Below is a complete PyChrono script that sets up a simple pendulum simulation with Irrlicht visualization. The script:

- Initializes the Chrono system and Irrlicht visualization.
- Creates a fixed ground body.
- Creates a pendulum body with specified mass and inertia.
- Connects the pendulum to the ground with a revolute joint.
- Runs the simulation loop, rendering the scene and logging the pendulum’s position and velocity at intervals.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the Chrono system
chrono.SetChronoDataPath(chrono.GetChronoDataPath())
system = chrono.ChSystemNSC()

# 2. Create the ground body (fixed)
ground = chrono.ChBody()
ground.SetBodyFixed(True)
system.Add(ground)

# 3. Create the pendulum body
pend_length = 2.0   # meters
pend_radius = 0.05  # meters
pend_mass = 1.0     # kg

# Inertia for a solid cylinder about center (Ixx = Iyy = 1/12*m*L^2 + 1/4*m*r^2, Izz = 1/2*m*r^2)
Ixx = (1/12)*pend_mass*pend_length**2 + 0.25*pend_mass*pend_radius**2
Izz = 0.5*pend_mass*pend_radius**2
pend_inertia = chrono.ChVectorD(Ixx, Ixx, Izz)

pendulum = chrono.ChBodyEasyCylinder(pend_radius, pend_length, pend_mass, True, True)
pendulum.SetPos(chrono.ChVectorD(0, -pend_length/2, 0))  # Hang down from origin
pendulum.SetInertiaXX(pend_inertia)
system.Add(pendulum)

# 4. Create the revolute joint at the origin (top of pendulum)
joint = chrono.ChLinkLockRevolute()
joint.Initialize(pendulum, ground, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.Q_from_AngAxis(0, chrono.ChVectorD(0,0,1))))
system.AddLink(joint)

# 5. Visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('PyChrono: Simple Pendulum')
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(2, 0, 2), chrono.ChVectorD(0, -1, 0))
vis.AddTypicalLights()

# Add visualization assets to pendulum
pendulum.GetVisualShape(0).SetColor(chrono.ChColor(0.6, 0.4, 0.2))

# 6. Simulation loop
timestep = 0.002
log_interval = 0.1  # seconds
next_log_time = 0.0

print("time\tpos_y\tvel_y")
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Log pendulum position and velocity periodically
    time = system.GetChTime()
    if time >= next_log_time:
        pos = pendulum.GetPos()
        vel = pendulum.GetPos_dt()
        print(f"{time:.3f}\t{pos.y:.4f}\t{vel.y:.4f}")
        next_log_time += log_interval

    system.DoStepDynamics(timestep)
```

**How it works:**
- The pendulum is modeled as a cylinder, hanging from the origin.
- The revolute joint constrains the pendulum to swing in the X-Z plane.
- The simulation window visualizes the pendulum in real time.
- The script logs the vertical position and velocity of the pendulum at regular intervals.

**Requirements:**
- Install PyChrono with Irrlicht bindings (`pip install pychrono`).
- Run the script in an environment where a window can be created (not headless).
