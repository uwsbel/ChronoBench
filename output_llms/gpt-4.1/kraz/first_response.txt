Certainly! Below is a **PyChrono** simulation script that fulfills your requirements. This script:

- Initializes the PyChrono environment.
- Sets up a **Kraz vehicle** with initial conditions.
- Adds a **rigid terrain** with specified friction and restitution.
- Initializes a **driver system** for vehicle control.
- Configures **Irrlicht visualization** with camera and lighting.
- Implements a simulation loop that synchronizes and advances all systems, maintaining real-time execution.

**Note:** This script assumes you have the `PyChrono` and `PyChronoVehicle` modules installed and accessible.

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as chronoirr
import time

# 1. Initialize PyChrono
chrono.SetChronoDataPath(chrono.GetChronoDataPath())
veh.SetDataPath(veh.GetDataPath())

# 2. Create the physical system
system = chrono.ChSystemNSC()

# 3. Create the Kraz vehicle
initLoc = chrono.ChVectorD(0, 0, 1.0)  # Initial position (x, y, z)
initRot = chrono.QUNIT  # No rotation
kraz = veh.Kraz()
kraz.SetContactMethod(chrono.ChContactMethod_NSC)
kraz.SetChassisFixed(False)
kraz.SetInitPosition(chrono.ChCoordsysD(initLoc, initRot))
kraz.SetInitFwdVel(0.0)
kraz.Initialize()

# 4. Create the terrain
terrain = veh.RigidTerrain(system)
terrain_mat = chrono.ChMaterialSurfaceNSC()
terrain_mat.SetFriction(0.9)      # Friction coefficient
terrain_mat.SetRestitution(0.01)  # Restitution coefficient

patch = terrain.AddPatch(
    terrain_mat,
    chrono.ChVectorD(0, 0, 0),  # Center position
    chrono.ChVectorD(0, 0, 1),  # Normal vector
    200, 200                    # Size X, Y (meters)
)
patch.SetTexture(veh.GetDataFile("terrain/textures/grass.jpg"), 200, 200)
patch.SetColor(chrono.ChColor(0.8, 0.8, 0.5))
terrain.Initialize()

# 5. Create the driver system (keyboard driver)
driver = veh.ChDriverInputs()
driver_system = veh.ChIrrGuiDriver(kraz.GetVehicle())
driver_system.SetSteeringDelta(0.04)
driver_system.SetThrottleDelta(0.02)
driver_system.SetBrakingDelta(0.1)
driver_system.Initialize()

# 6. Visualization with Irrlicht
vis = veh.ChWheeledVehicleIrrApp(
    kraz.GetVehicle(),
    "Kraz Vehicle Demo",
    chronoirr.dimension2du(1024, 768)
)
vis.SetSkyBox()
vis.AddTypicalLights(chrono.ChVectorD(30, 30, 100), chrono.ChVectorD(-30, -30, 100), 250, 130)
vis.AddTypicalLogo()
vis.SetChaseCamera(chrono.ChVectorD(0.0, 0.0, 1.75), 6.0, 0.5)
vis.SetTimestep(0.01)
vis.AssetBindAll()
vis.AssetUpdateAll()

# 7. Simulation loop
step_size = 0.01
realtime_timer = chrono.ChRealtimeStepTimer()

while vis.Run():
    vis.BeginScene()
    vis.DrawAll()

    # Get driver inputs
    driver_inputs = driver_system.GetInputs()

    # Synchronize all modules
    time = kraz.GetVehicle().GetChTime()
    driver_system.Synchronize(time)
    kraz.Synchronize(time, driver_inputs, terrain)
    terrain.Synchronize(time)
    vis.Synchronize("Kraz Vehicle Demo", driver_inputs)

    # Advance simulation for one timestep
    driver_system.Advance(step_size)
    kraz.Advance(step_size)
    terrain.Advance(step_size)
    vis.Advance(step_size)

    vis.EndScene()
    realtime_timer.Spin(step_size)

    # Optional: End after a certain time
    # if time > 20:
    #     break

# Clean up
vis.GetDevice().closeDevice()
```

---

**Key Points:**

- **Kraz vehicle** is initialized at (0, 0, 1.0) with zero initial velocity.
- **Terrain** patch is 200x200 meters, with friction 0.9 and restitution 0.01.
- **Driver** uses keyboard input for steering, throttle, and braking.
- **Visualization** uses Irrlicht with a chase camera and typical lighting.
- **Simulation loop** synchronizes and advances all modules, maintaining real-time execution.

**Dependencies:**  
Make sure you have installed `pychrono`, `pychrono.vehicle`, and `pychrono.irrlicht` Python modules.
