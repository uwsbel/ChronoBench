To create a PyChrono simulation modeling gravitational attraction between particles with a particle emitter and visualization using Irrlicht, follow these steps:

### Step-by-Step Explanation

1. **Import Necessary Libraries and Initialize PyChrono:**
   - Import PyChrono modules.
   - Initialize the simulation, physics, and visualization components.

2. **Set Up the Simulation Environment:**
   - Create a container for rigid spheres to hold particles.
   - Add a ground plane to prevent particles from falling indefinitely.

3. **Create a Particle Emitter:**
   - Define parameters for particle generation (shape, position, velocity, orientation).
   - Generate particles in a loop until the container reaches maximum capacity.

4. **Apply Gravitational Forces:**
   - Use a custom force field to apply gravitational attraction between particles.
   - Calculate the force between each pair of particles based on their distance.

5. **Set Up Visualization:**
   - Configure Irrlicht to render particles and the ground plane.
   - Enable wireframe mode for containers to visualize connections.

6. **Run the Simulation:**
   - Update physics and visualize the simulation each timestep.

### Solution Code

```python
import pychrono as pc
import random
import numpy as np

# Initialize PyChrono components
simulation = pc.Simulation()
physics = pc.Phiysics()
irrlicht = pc.Irrlicht()
simulation.setPhysics(physics)
simulation.setRenderer(irrlicht)

# Set simulation parameters
simulation.setTimestep(0.01)
simulation.setMaxParticles(1000)

# Create a container for rigid spheres
particles_container = pc.RigidSphereContainer()
particles_container.setRadius(0.05)
particles_container.setPosition(pc.Vec3d(0, 0, 0))
simulation.addSystem(particles_container)

# Add a ground plane
ground_container = pc.PlaneContainer()
ground_container.setNormal(pc.Vec3d(0, 0, 1))
ground_container.setPosition(pc.Vec3d(0, 0, 0))
simulation.addSystem(ground_container)

# Define particle emission parameters
particle_shapes = [pc.Sphere(), pc.Cylinder()]
particle_mass = 1.0
particle_size = 0.05
particle_count = 1000

# Emitter loop to create particles
for _ in range(particle_count):
    # Random position around the origin
    pos = pc.Vec3d(
        random.uniform(-1, 1) * 0.5,
        random.uniform(-1, 1) * 0.5,
        random.uniform(-1, 1) * 0.5
    )
    
    # Random orientation
    orient = pc.Vec3d(random.uniform(-1, 1), random.uniform(-1, 1), random.uniform(-1, 1))
    orient.normalize()
    
    # Random velocity with some variation
    vel = pc.Vec3d(
        random.uniform(-1, 1) * 0.1,
        random.uniform(-1, 1) * 0.1,
        random.uniform(-1, 1) * 0.1
    )
    
    # Random shape
    shape = random.choice(particle_shapes)
    
    # Create a new particle
    particle = pc.RigidSphere(
        mass=particle_mass,
        position=pos,
        shape=shape,
        size=particle_size
    )
    particle.setOrientation(orient)
    particle.setVelocity(vel)
    particles_container.add(particle)

# Apply custom gravitational force
force_field = pc.CustomForceField()
simulation.addSystem(force_field)

# Loop through all particle pairs
for i in range(particle_count):
    for j in range(i + 1, particle_count):
        p1 = particles_container.get(i)
        p2 = particles_container.get(j)
        
        # Calculate distance between particles
        r = pc.Vec3d(p1.position - p2.position).magnitude()
        if r > 1e-5:  # Avoid division by zero
            force = pc.Vec3d(p1.position - p2.position).normalized() * (10 / r**2)
            
            # Apply force to both particles
            p1.addForce(force)
            p2.addForce(-force)

# Configure visualization
irrlicht.setClearColor(pc.Vec4d(1, 1, 1, 1))
irrlicht.setCameraPosition(pc.Vec3d(5, 5, 5))
irrlicht.setCameraLookat(pc.Vec3d(0, 0, 0))
irrlicht.setRenderWireframe(particles_container)
irrlicht.setRenderWireframe(ground_container)
irrlicht.show()

# Run the simulation
simulation.run()

# Cleanup
del simulation
del physics
del irrlicht
```

### Explanation

- **Initialization:** We start by importing necessary libraries and initializing the PyChrono components, including the simulation, physics, and visualization systems.
- **Simulation Setup:** We create a container for particles and a ground plane to provide a stable environment.
- **Particle Emission:** Each particle is generated with random properties, ensuring variety in their shapes, positions, velocities, and orientations.
- **Force Application:** A custom force field is used to apply gravitational forces between particles, calculating the force based on their distance.
- **Visualization:** The simulation is rendered using Irrlicht, displaying particles and the ground plane with wireframe mode for clarity.

This setup allows us to model gravitational interactions dynamically, observe particle behavior, and visualize the effects of gravitational forces in real-time.
