To create a simple pendulum simulation using PyChrono with Irrlicht for visualization, follow these steps:

1. **Import Necessary Modules**: Include PyChrono and Irrlicht for visualization.
2. **Initialize PyChrono Environment**: Set up the simulation and visualization systems.
3. **Create Bodies and Joints**: Define the ground and pendulum bodies, then connect them with a revolute joint.
4. **Set Up Visualization**: Configure the camera and renderer to display the simulation.
5. **Apply Initial Conditions**: Add forces to start the pendulum's motion.
6. **Simulate and Render**: Run the simulation loop, updating the joint and rendering each frame.
7. **Log Data**: Capture the pendulum's position and velocity over time.

Here is the complete code implementing these steps:

```python
import pychrono as pychrono
import pychrono.trajectory as trajectory
import pychrono.visualization.irrutil as irrutil

# Initialize PyChrono and visualization
pychrono.init()
sim = pychrono.Simulation()
vis = pychrono.Visualization()
vis.setRenderSize(800, 600)

# Create ground body
ground = pychrono.Body.createStaticBody(sim)
ground.setPosition(0, 0, 0)
ground.setMass(0)
ground.setMaterial(pychrono.Material.Ground)

# Create pendulum body
pendulum = pychrono.Body.createDynamicBody(sim)
pendulum.setMass(1)
pendulum.setMomentOfInertia(
    pychrono.Shape.Sphere,
    pendulum.getMass() * pendulum.getRadius() ** 2
)
pendulum.setPosition(0, 5, 0)
pendulum.setRotationX(pychrono.Rotation.DegreesToRadians(90))  # Initial angle

# Create revolute joint between ground and pendulum
joint = pychrono.Joint.createRevoluteJoint(sim)
joint.setPivotPoint(ground, 0, 5, 0)
joint.setBody1(ground)
joint.setBody2(pendulum)
joint.setInitialRotationX(pychrono.Rotation.DegreesToRadians(90))
joint.setInitialRotationXAxis(0)
joint.setDamping(0.1)

# Apply torque to start the pendulum
force = pychrono.Force.create力的模拟
力 = pychrono.Force.create力(sim)
力.setPoint(ground, 0, 5, 0)
力.setMagnitude(0.1)
pendulum.addForce(力)

# Set up camera and renderer
cam = pychrono.Camera.create()
cam.setLookAt(0, 10, 0)
cam.setUp(0, 0, 1)
vis.setCamera(cam)

# Enable ground rendering
ground.setRenderable(True)

# Simulation loop
t = 0
while True:
    sim.step()
    t += 1e-6  # Adjust time step based on desired simulation speed

    # Update joint angle
    joint.setInitialRotationX(pychrono.Rotation.DegreesToRadians(joint.getAngleX() * 2))

    # Render the scene
    vis.render()

    # Log pendulum position and velocity
    pos = pendulum.getLinearPosition()
    vel = pendulum.getLinearVelocity()
    ang_vel = pendulum.getAngularVelocity()
    print(f"Time: {t:.3f}, Position: {pos}, Velocity: {vel}, Angular Velocity: {ang_vel}")

    # Break loop if desired (for testing)
    if t >= 10:
        break

# Cleanup
pychrono.finalize()
```

**Explanation:**

- **Initialization**: The simulation and visualization systems are set up to handle the pendulum's dynamics and rendering.
- **Body Creation**: The ground is a static body, while the pendulum is a dynamic body with appropriate mass and inertia.
- **Joint Setup**: The revolute joint allows the pendulum to swing freely around the pivot point.
- **Visualization Configuration**: The camera is positioned to view the pendulum, and the ground is made renderable.
- **Simulation Loop**: The loop updates the joint's angle each frame, renders the scene, and logs the pendulum's position and velocity.
- **Logging**: Data about the pendulum's motion is captured periodically for analysis.

This setup creates a realistic pendulum simulation that can be visualized and analyzed using PyChrono and Irrlicht.
