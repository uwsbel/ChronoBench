```python
import chrono as chrono
import numpy as np

# Initialize PyChrono
chrono.init()

# Create simulation
sim = chrono.Simulation(seed=42)

# Create ground body
ground_body = chrono.Body(mass=0, position=[0, 0, 0])
sim.add_body(ground_body)

# Create mesh for visualization
ground_mesh = np.array([[0, 0], [0, 1]])
ground_mesh_visual = chrono.Mesh(
    body=ground_body,
    visual=chrono.MeshVisual(
        mesh=ground_mesh,
        color=[1, 0, 0],
        wireframe=False,
        mesh_size=1,
        static=True
    )
)
sim.add_visual(ground_mesh_visual)

# Initialize sensors
sensor_manager = sim.add_sensor_manager()
sensor_manager.camera = chrono.Sensor(
    position=[1, 1, 1],
    rotation=[0, 0, 0],
    size=[512, 512],
    sensor_type=chrono.SensorType.CAMERA
)
sensor_manager.lidar = chrono.Sensor(
    position=[2, 1.5, 1],
    rotation=[0, 0, 0],
    sensor_type=chrono.SensorType.LIDAR
)
sensor_manager.gps = chrono.Sensor(
    position=[0, 0, 0],
    antenna_position=[1, 0, 0],
    sensor_type=chrono.SensorType.GPS
)
accelerometer = sensor_manager.add_accelerometer(
    body=ground_body,
    position=[0, 0, 0],
    orientation=[0, 0, 0]
)
gyroscope = sensor_manager.add_gyroscope(
    body=ground_body,
    position=[0, 0, 0],
    orientation=[0, 0, 0]
)
magnetometer = sensor_manager.add_magnetometer(
    body=ground_body,
    position=[0, 0, 0],
    orientation=[0, 0, 0]
)

# Register sensors with ROS manager
ros_manager = sim.add_ros_manager()
ros_manager.register_sensor(
    sensor=sensor_manager.camera,
    topic='/camera_data'
)
ros_manager.register_sensor(
    sensor=sensor_manager.lidar,
    topic='/lidar_data'
)
ros_manager.register_sensor(
    sensor=accelerometer,
    topic='/accelerometer_data'
)
ros_manager.register_sensor(
    sensor=gyroscope,
    topic='/gyroscope_data'
)
ros_manager.register_sensor(
    sensor=magnetometer,
    topic='/magnetometer_data'
)

# Simulation loop
while True:
    sensor_manager.update()
    sim.step()
    if sim.input.key_press('r'):  # Press 'r' for reset
        sim.reset()
    print("Simulation is running...")
```

This script:
1. Initializes the PyChrono environment
2. Creates a ground body with a mesh for visualization
3. Sets up multiple sensors (camera, lidar, GPS, accelerometer, gyroscope, magnetometer)
4. Registers these sensors with a ROS manager
5. Creates a simulation loop that updates sensors and advances time
6. Includes real-time execution control with key presses

The simulation can be controlled with:
- Left Arrow: Move forward
- Right Arrow: Move backward
- Up Arrow: Move up
- Down Arrow: Move down
- Page Up: Move camera up
- Page Down: Move camera down
- Space: Reset simulation

The sensors will publish data to their respective ROS topics at each simulation step.
