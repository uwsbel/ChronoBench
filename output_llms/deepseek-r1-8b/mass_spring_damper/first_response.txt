Here's a PyChrono simulation script for a mass-spring-damper system:

```python
# Import required modules
import PyChrono as pc
import numpy as np

# Initialize simulation
sim = pc.Simulation(pc.get_default_device(), pc.SimulationSetup(
    time_step=0.001,
    num_steps=1000,
    visualization=True,
    visualization_window="pychrono",
    enable Irrlicht=True,
    camera=pc.Camera(
        position=[5, 5, 5],
        look_at=[0, 0, 0],
        up=[0, 1, 0],
    ),
))

# Create ground
ground = pc.createGround(
    position=[0, 0, 0],
    size=[50, 50, 5],
    properties=pc.GroundProperties(
        friction=10,
        normal_force=1000,
    ),
)

# Create mass
mass = pc.createSphere(
    radius=0.5,
    mass=1,
    position=[0, 0, 0],
    shape=pc.Shape.SPHERE,
    material=pc.Material(
        color=[1, 1, 1],
        specularity=0.5,
        emissivity=0.8,
    ),
)

# Create spring
spring = pc.createRod(
    length=2,
    cross_section=0.1,
    material=pc.Material(
        color=[0.5, 0.5, 0.5],
        specularity=0.5,
        emissivity=0.8,
    ),
)

# Create damper
damper = pc.createDamper(
    damping=0.5,
    position=[0, 0, 0],
)

# Create link with TSDA connection
link = pc.createLink(
    name="Mass-Spring-Damper",
    body1=ground,
    body2=mass,
    anchor1=[0, 0, 0],
    anchor2=[0, 0, 0],
    type=pc.LinkType.TSDA,
    properties=pc.LinkProperties(
        spring_constant=1000,
        damper_damping=0.5,
        spring_force=0,
        damper_force=0,
    ),
)

# Add lighting
light = pc.createLight(
    position=[5, 5, 5],
    direction=[-1, -1, -1],
    color=[1, 1, 1],
    intensity=1,
    attenuation=1000,
)

# Set visualization properties
sim.setVisualizationProperties(
    ground_properties=pc.VisualProperties(
        color=[1, 1, 1],
        wireframe=False,
        visible=True,
    ),
    mass_properties=pc.VisualProperties(
        color=[1, 1, 1],
        wireframe=False,
        visible=True,
    ),
    spring_properties=pc.VisualProperties(
        color=[0.5, 0.5, 0.5],
        wireframe=False,
        visible=True,
    ),
    link_properties=pc.VisualProperties(
        color=[0, 0, 0],
        wireframe=False,
        visible=True,
    ),
)

# Run simulation
sim.run()
```

This script creates a simple mass-spring-damper system connected to the ground using a TSDA (Two-Stage Distance Actuation) link. The system includes:

1. A ground plane with realistic friction and normal force properties
2. A mass represented by a sphere
3. A spring represented by a rod
4. A damper
5. A TSDA link connecting the mass to the ground
6. Irrlicht visualization with:
   - Proper lighting setup
   - Clear camera view
   - Visual shapes for the mass, spring, and ground
   - Realistic material properties

The spring constant is set to 1000 N/m, and the damping coefficient is set to 0.5. The system will oscillate with these parameters, and the visualization will show the mass and spring in action.

To run this simulation, execute the script with Python. The visualization will open automatically in a window, showing the system in real-time.
