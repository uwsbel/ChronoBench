To create a PyChrono simulation integrated with ROS, follow these steps:

1. **Import Necessary Libraries**: Include PyChrono, numpy, and ROS modules.

2. **Initialize PyChrono Environment**: Set up the simulation with gravity and define the world.

3. **Add Physical Objects**: Create a fixed floor and a movable box with necessary constraints.

4. **Set Up ROS Communication**: Define a custom handler to publish integer messages and configure the ROS manager with handlers.

5. **Run Simulation Loop**: Update the simulation and ROS communication at each timestep to ensure real-time execution.

Here's the complete code:

```python
import numpy as np
import chrono as c
from chrono_ros import ROSHandler, ROSManager
import rospy
from std_msgs.msg import Int32

# Initialize PyChrono
chrono_system = c.Chrono()
chrono_system.enable_gravity = True
chrono_system.set_ground("floor", c.Box(m=1000, height=1))

# Create a movable box
box_body = c.DynamicBox(m=1, position=(0.5, 0.5, 1))
box_body.set_velocity((0.5, 0, 0.5))
box_body.add_ground_contact(c.GroundContact(box_body, "floor"))

# Define custom ROS handler
class ROSHandler(c.ROSHandler):
    def on_message(self, msg):
        if isinstance(msg, Int32):
            print(f"Received message: {msg.data}")
            self.pub.publish(msg.data)

# Configure ROS manager
ros_manager = ROSManager()
ros_manager.clock = c.get_default_clock()
ros_manager.body = box_body
ros_manager.transform_handler = c.TransformBroadcaster()
ros_manager.setup()

# Register the custom handler
ros_manager.register_handler("int_msgs", ROSHandler())

# Run simulation
simulation_running = True
timestep = 0.01  # 100Hz

while simulation_running:
    # Update simulation
    c.step(timestep)
    
    # Check for ROS messages
    try:
        msg = rospy.wait_for_message("int_msgs", Int32, timeout=1)
        handler = ros_manager.get_handler("int_msgs")
        handler.on_message(msg)
    except:
        pass
    
    # Spin ROS loop
    rospy.sleep(0.01)

# Cleanup
rospy.shutdown()
chrono_system.stop()
```

**Explanation**:

- **PyChrono Setup**: The simulation is initialized with gravity enabled, and a fixed floor is created using a static box.
- **Movable Box**: A dynamic box is added with initial velocity and mass, allowing it to move and interact with the floor.
- **ROS Integration**: A custom handler is defined to handle integer messages. The ROS manager is configured with necessary components, and the handler is registered.
- **Simulation Loop**: The loop updates the simulation and checks for ROS messages, ensuring real-time communication and execution.

This setup allows for a dynamic environment where the box moves under gravity, and ROS can communicate with the simulation in real-time.
