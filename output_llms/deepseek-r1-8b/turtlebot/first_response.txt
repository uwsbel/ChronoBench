To create a PyChrono simulation with a Turtlebot on rigid terrain, follow these steps:

### Step-by-Step Explanation

1. **Import Required Libraries**
   - Install and import necessary libraries: `chrono`, `irrlicht`, and `opencv`.
   - Set up the physics and visualization flags.

2. **Initialize the PyChrono Environment**
   - Create a `chrono::ChSystem` instance to set up the physics simulation.
   - Enable the visualization using `chrono::ChVisualization` with Irrlicht.

3. **Set Up the Ground Body**
   - Create a ground body as a static rigid body.
   - Define its dimensions, mass, and position to represent the terrain.

4. **Add Gravity to the System**
   - Use the `addGravity` method to enable gravity in the simulation.

5. **Initialize the Turtlebot**
   - Create a Turtlebot with a specific position and orientation.
   - Position it above the ground and set its initial orientation.

6. **Set Up Visualization**
   - Create a camera node with a perspective view.
   - Position the camera to view the Turtlebot.
   - Add lighting to enhance the visualization.

7. **Define the Simulation Loop**
   - Use a loop to update the robot's position and render the scene in real-time.
   - In each iteration:
     - Update the Turtlebot's motors.
     - Control left and right turns using motor angles.
     - Update the robot's orientation and position.
     - Render the scene with the latest state.

8. **Add Interactivity**
   - Use arrow keys to control the robot's left and right turns.
   - Check for key presses and adjust motor angles accordingly.

9. **Optimize Performance**
   - Use a small delay in the loop to ensure smooth rendering without overloading the system.

### Sample Code

```python
importchrono
importOpenCV
importIrrlicht

# Initialize PyChrono components
chrono.init()
chrono.setVisualizationEnabled(True)

# Set physics and visualization flags
chrono.setPhysicsEnabled(True)
chrono.setVisualizationEnabled(True)

# Create ground body
ground_body = chrono.RigidBody("ground")
ground_body.setMass(0)
ground_body.setDimensions(10, 10, 10)
ground_body.setPosition(0, 0, 0)
chrono.addRigidBody(ground_body)

# Add gravity
chrono.addGravity(0, 0, -9.81)

# Initialize Turtlebot
turtlebot = chrono.RigidBody("turtlebot")
turtlebot.setMass(1)
turtlebot.setDimensions(0.5, 0.5, 0.5)
turtlebot.setPosition(0, 1, 0)
turtlebot.setOrientation(0, 0, 0)  # Initial orientation: flat

# Setup camera
camera = chrono.Camera("camera")
camera.setPerspective(45, 800, 0.1, 1000)
camera.setPosition(5, 5, 5)
chrono.addCamera(camera)

# Setup lighting
light = chrono.Light("light")
light.setAmbientColor(255, 255, 255)
chrono.addLight(light)

# Create visualization window
window = chrono.VisWindow.create("Turtlebot Simulation", 800, 600)

# Get motor states
left_motor = 0
right_motor = 0

# Simulation loop
while True:
    # Update motor states
    motors = turtlebot.getMotors()
    left_motor = motors[0]
    right_motor = motors[1]
    
    # Control left and right turns
    if chr(input().strip()) == 'ArrowLeft':
        left_motor = 0.1
    elif chr(input().strip()) == 'ArrowRight':
        right_motor = 0.1
    
    # Update motors
    turtlebot.setMotors(left_motor, right_motor)
    
    # Update and render
    window.clear()
    window.update()
    turtlebot.update()
    ground_body.update()
    
    # Render objects
    ground_mesh = ground_body.getMesh()
    turtle_mesh = turtlebot.getMesh()
    ground_mesh.draw()
    turtle_mesh.draw()
    
    # Display text
    window.drawText("Turtlebot on Rigid Terrain", 5, 5, 1, 1, 1, 1)
    window.show()
    
    # Add small delay for real-time
    import time
    time.sleep(1/60)
```

### Explanation

- **Initialization**: The code starts by importing necessary libraries and initializing the PyChrono environment.
- **Ground Setup**: A static rigid body represents the ground, providing a surface for the Turtlebot to stand on.
- **Gravity**: Gravity is added to the simulation to give the Turtlebot realistic movement.
- **Turtlebot**: The Turtlebot is initialized with a specific position and orientation, ready to move on the ground.
- **Visualization**: The Irrlicht renderer is set up with a camera and lighting to provide a clear view of the simulation.
- **Simulation Loop**: The loop updates the Turtlebot's position based on motor controls and renders the scene in real-time.
- **Interactivity**: The user can control the Turtlebot's turns using arrow keys, enhancing the simulation's interactivity.

This setup allows for a realistic and interactive simulation of the Turtlebot navigating on rigid terrain, with real-time visualization and control.
