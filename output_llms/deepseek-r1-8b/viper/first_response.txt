To create a PyChrono simulation with a Viper rover on a rigid terrain, follow these steps:

### Step-by-Step Explanation

1. **Import Necessary Libraries**
   - Import PyChrono (`pychrono as pc`) for physics simulation.
   - Import Irrlicht for real-time visualization.

2. **Initialize the PyChrono Environment**
   - Create a new scene with `pc.Scene()`.
   - Initialize the Chrono system with `pc.Chrono()`.
   - Set gravity using `pc.addGravity()`.
   - Create a ground body as a static plane.

3. **Set Up the Ground Body**
   - Define a ground body with dimensions (100m x 100m) using `pc.Ground()`.
   - Attach the ground body to the Chrono system.
   - Position the ground at the origin.

4. **Create the Viper Rover**
   - Define a rover body using a cylinder.
   - Position the rover on the ground at (0, 0, 0.5).
   - Attach the rover to the ground body.
   - Set the mass and inertia properties of the rover.

5. **Add the Driver Seat**
   - Create a driver body positioned in front of the rover.
   - Attach the driver to the rover body.
   - Set the driver's orientation using Euler angles to face forward.

6. **Set Up Visualization with Irrlicht**
   - Create a camera positioned above the ground.
   - Set up lighting to simulate realistic terrain.

7. **Implement the Simulation Loop**
   - Define the simulation timestep (e.g., 0.01 seconds).
   - Use a loop to continuously update the simulation.
   - Apply steering input to the driver's orientation over time.

8. **Update and Render the Scene**
   - In each timestep, update the driver's position and orientation.
   - Render the scene using the Irrlicht renderer.
   - Clear the previous frame before drawing to avoid visual artifacts.

### Sample Code

```python
import pychrono as pc
import Irrlicht

# Initialize PyChrono and Irrlicht
scene = pc.Scene()
chrono = pc.Chrono()
chrono.addGravity()

# Create ground body
ground = pc.Ground(100, 100, 0.5)
chrono.addBody(ground)
chrono.bodyAttach(ground)

# Create Viper rover
rover_body = pc.Body(pc.Cylinder(0.5, 0.5, 0.3), pc.Mass(150), pc.Inertia(5))
rover_body.setPos(0, 0, 0.5)
chrono.addBody(rover_body)
chrono.bodyAttach(rover_body)

# Create driver seat
driver_body = pc.Body(pc.Box(0.3, 0.3, 0.2), pc.Mass(60))
driver_body.setPos(2, 1.5, 0.5)
driver_body.setOrientation(pc.Euler(0, 0, 0.85))  # Face forward
chrono.addBody(driver_body)
chrono.bodyAttach(driver_body)

# Setup Irrlicht visualization
cam = scene.addCamera(" Irrlicht Camera", pc.CAMERA_PERSPECTIVE)
cam.setPos(5, 5, 5)
cam.lookAt(0, 0, 0)
cam.setFieldOfView(45)

# Add lighting
light = scene.addLight(pc.DirectionalLight(0, 0, 0, 1, 1, 1))
light.setPos(10, 10, 10)

# Simulation loop
t = 0
while True:
    t += 0.01
    # Update driver orientation with steering
    angle = 0.1 * pc.sin(t)  # Smooth steering input
    driver_body.setOrientation(pc.Euler(0, angle, 0.85))
    
    # Update renderer
    scene.clear()
    renderer = scene.getRenderer()
    renderer.render()
    
    # Display debug info
    print(f"Time: {t:.3f}, Driver Angle: {angle:.2f}")
```

### Explanation

- **Initialization**: The code starts by setting up the PyChrono environment, including gravity and the ground body.
- **Rover and Driver Setup**: The Viper rover is created as a cylinder and positioned on the ground. The driver's seat is attached to the rover and oriented to face forward.
- **Visualization**: Irrlicht is used to create a real-time visualization with a camera positioned above the ground, providing a clear view of the rover's movements.
- **Simulation Loop**: The loop updates the driver's orientation based on a sine function, simulating steering. The renderer updates the scene each frame, ensuring smooth visualization of the simulation.

This setup allows for a realistic simulation of the Viper rover navigating a rigid terrain, with real-time visualization and physics-based movement.
