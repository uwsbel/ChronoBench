To create the simulation script for the CityBus vehicle, we'll follow a structured approach that initializes the necessary components, sets up the vehicle and terrain, configures the visualization, and implements the interactive control system. Here's the step-by-step solution:

### Step 1: Initialize PyChrono and Irrlicht

3. **Create Renderer**: Set up the Irrlicht renderer with a window size, fullscreen mode, and clear background.

3. **Attach Vehicle to Scene**: Add the vehicle to the scene and position it appropriately.

1. **Create Terrain**: Generate a flat terrain using a plane geometry.
2. **Apply Custom Texture**: Use a .dds texture for the terrain. Ensure the texture is loaded correctly and centered on the terrain.

### Step 4: Visualization Configuration

### Step 6: Simulation Loop
1. **Update Physics**: Each frame, update the vehicle's physics to reflect the latest control inputs.

3. **Loop Execution**: Continue the simulation loop at the specified frame rate (50 FPS) to ensure real-time updates.

### Step 7: Testing and Debugging

### Final Code
Here's the complete Python script implementing the simulation:

```python
import PyChrono
import PyIrrlicht

# Initialize PyChrono
simulation = PyChrono.Simulation("CityBus Simulation", PyChrono.Simulation.PHYSICS_TYPE_DEFAULT)
renderer = PyIrrlicht.Renderer(1024, 768, PyIrrlicht.Renderer.WINDOWED, PyIrrlicht.Color(255, 255, 255))
simulation.addRenderer(renderer)
simulation.setPhysicsTimeStep(1.0 / 50)  # 50 FPS

# Create Vehicle
vehicle_mesh = PyChrono.Mesh("citybus", "citybus.gmesh")
vehicle = simulation.addVehicle(vehicle_mesh, PyChrono.VehicleDynamics(
    mass=1000,
    inertia=PyChrono.Vec3(0, 0, 0),
    position=PyChrono.Vec3(0, 0, 0),
    orientation=PyChrono.Vec3(1, 0, 0),
    tire_model=PyChrono.TireModel.TYPE_DEFAULT
))
vehicle.setTireParameters(400, 0.1, 0.1, 0.5)

# Create Rigid Terrain
terrain = simulation.addRigidTerrain("rigid_terrain", PyChrono.Mesh("terrain", "plane.gmesh"), PyChrono.Texture(
    "terrain.dds",
    PyIrrlicht.TextureType.TEXTURE_FLOOR,
    PyIrrlicht.TextureFilter.TEXTURE_FILTER_BILINEAR,
    PyIrrlicht.TextureWrapMode.TEXTURE_WRAP_CLAMP
))
terrain.setMass(0)
terrain.setPosition(PyChrono.Vec3(0, 0, 0))

# Setup Camera
camera = simulation.getRenderer().getCamera()
camera.setPosition(PyChrono.Vec3(10, 10, 10))
camera.setLookAt(PyChrono.Vec3(0, 0, 0))
camera.setFieldOfView(45.0)
camera.setAspectRatio(16.0 / 9.0)

# Interactive Driver System
def handle_key_event(key, scancode, modifiers):
    if key == ord('ArrowLeft'):
        vehicle.setSteering(-0.5)
    elif key == ord('ArrowRight'):
        vehicle.setSteering(0.5)
    elif key == ord('ArrowUp'):
        vehicle.setEngineTorque(0.5)
    elif key == ord('ArrowDown'):
        vehicle.setBraking(0.5)

simulation.getRenderer().setEventCallback(handle_key_event)

# Simulation Loop
simulation.start()
while True:
    simulation.update()
    renderer.draw()
    camera.setPositionAndLookAt(
        PyChrono.Vec3(10 + vehicle.getPosition().x, 10, 10),
        PyChrono.Vec3(0, 0, 0)
    )
    renderer.drawCall()
    renderer.render()
    # Control loop to maintain 50 FPS
    if simulation.getPhysicsTimeStep() < 1.0 / 50:
        simulation.setPhysicsTimeStep(1.0 / 50)
```

### Explanation
This script initializes the simulation environment, sets up the vehicle with necessary physics parameters, configures the terrain with a custom texture, and implements an interactive control system. The camera follows the vehicle, and the simulation runs at 50 FPS, updating the vehicle's dynamics and rendering the scene in real time. The input handling allows controlling the vehicle's steering, throttle, and braking through keyboard inputs.
