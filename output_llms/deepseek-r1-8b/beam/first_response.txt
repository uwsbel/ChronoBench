To create a PyChrono simulation using beam finite elements, follow these steps:

### Step-by-Step Explanation

1. **Import Necessary Libraries and Initialize PyChrono**
   - Import PyChrono and numpy.
   - Initialize the physics kernel and renderer.
   - Set up the simulation with a time step.

2. **Define the Ground Plane**
   - Create a ground plane with specified thickness and material properties.

3. **Create the Beam Structure**
   - Define a box beam with given dimensions and position on the ground.

4. **Define Node Positions and Masses**
   - Assign coordinates to each node and calculate their masses based on uniform density.

5. **Set Up Node Connections**
   - Define edges connecting the nodes and their directions.

6. **Simulate the System in a Loop**
   - Apply gravity, compute contact forces, update node positions, and render the scene.

### Python Code

```python
import pychrono as pc
import numpy as np

# Initialize PyChrono and Irrlicht
pc.init()
renderer = pc.IrrRenderer("PyChrono", pc.RendererSceneType.PYCHRONO)
physics = pc.PyChonoPhysics()
physics.set_renderer(renderer)

# Ground plane
ground = pc.Plane2D(physics, 0, 0, 0.1, 20e9, 0.2)

# Beam definition
beam = pc.BoxBeam(physics, 2, 1, 0.5, 20e9, 0.2)

# Node positions
nodes = []
nodes.append(pc.Node2D(physics, np.array([0, 0, 1.0])))
nodes.append(pc.Node2D(physics, np.array([2, 0, 1.0])))
nodes.append(pc.Node2D(physics, np.array([2, 1, 1.0])))
nodes.append(pc.Node2D(physics, np.array([2, 1, 0.5, 1.0])))
nodes.append(pc.Node2D(physics, np.array([1, 1, 1.0])))
nodes.append(pc.Node2D(physics, np.array([1, 0, 1.0])))
nodes.append(pc.Node2D(physics, np.array([0, 1, 1.0])))
nodes.append(pc.Node2D(physics, np.array([0, 0, 0.5, 1.0])))

# Assign masses
density = 8000  # kg/m³
mass = (0.5 ** 3) * density  # 1000 kg per node
for node in nodes:
    node.set_mass(mass)

# Define edges (connections)
edges = []
edges.append(pc.Edge(nodes[0], nodes[1], np.array([2, 0, 0])))
edges.append(pc.Edge(nodes[1], nodes[2], np.array([0, 2, 0])))
edges.append(pc.Edge(nodes[2], nodes[3], np.array([0, 0, 2])))
edges.append(pc.Edge(nodes[3], nodes[4], np.array([2, 0, 0])))
edges.append(pc.Edge(nodes[4], nodes[5], np.array([0, 2, 0])))
edges.append(pc.Edge(nodes[5], nodes[6], np.array([0, 0, 2])))
edges.append(pc.Edge(nodes[6], nodes[7], np.array([2, 0, 0])))
edges.append(pc.Edge(nodes[7], nodes[0], np.array([0, 0, 2])))

# Simulation loop
t = 0
while True:
    # Clear previous states
    physics.clear()
    
    # Apply gravity
    gravity = np.array([0, 0, -9.81])
    for node in nodes:
        node.set_position(node.get_position() - gravity * pc.TIMESTEP)
    
    # Compute contact forces
    contact_forces = []
    for i, node in enumerate(nodes):
        if node.get_z() < ground.get_z() - 0.05:
            normal_force = -gravity[2] * pc.TIMESTEP
            contact_forces.append(normal_force)
        else:
            contact_forces.append(0)
    
    # Update positions
    for i, node in enumerate(nodes):
        node.set_position(node.get_position() + np.array([0, 0, contact_forces[i]]))
    
    # Update meshes
    meshes = []
    for node in nodes:
        mesh = pc.Mesh()
        for edge in edges:
            mesh.add_edge(edge)
        meshes.append(mesh)
    
    # Compute strain and stress
    for edge in edges:
        node1 = edge.get_node1()
        node2 = edge.get_node2()
        pos1 = node1.get_position()
        pos2 = node2.get_position()
        disp = pos2 - pos1
        strain = np.linalg.norm(disp) / np.linalg.norm(disp - edge.get_length())
        if strain > 0.5:
            print("Beam failed at edge", edge)
    
    # Draw scene
    renderer.clear()
    renderer.draw_mesh(ground, 0, 0, 0.1, 20e9, 0.2)
    for mesh in meshes:
        renderer.draw_mesh(mesh, 0, 0, 0.1, 20e9, 0.2)
    for node in nodes:
        renderer.draw_sphere(node, 0.05, 255, 0, 255)
    
    t += 1e-6
```

2. **Ground Plane**: A ground plane is created with specified thickness and material properties to provide a foundation for the beam.

3. **Beam Definition**: A box beam is defined with given dimensions and positioned on top of the ground plane.

4. **Node Setup**: Each node's position and mass are defined. The nodes are connected to form the edges of the beam.

5. **Simulation Loop**: The loop updates the positions of the nodes, applies gravity, computes contact forces, updates meshes, checks for beam failure, and renders the scene in real-time.
