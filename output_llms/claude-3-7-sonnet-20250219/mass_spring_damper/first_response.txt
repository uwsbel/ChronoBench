# PyChrono Mass-Spring-Damper System Simulation

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# Initialize the Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create the ground body
ground = chrono.ChBody()
ground.SetIdentifier(-1)
ground.SetName("ground")
ground.SetBodyFixed(True)
system.Add(ground)

# Add a visual shape to represent the ground
ground_box = chrono.ChBoxShape()
ground_box.GetBoxGeometry().SetLengths(chrono.ChVectorD(10, 0.1, 10))
ground.AddVisualShape(ground_box, chrono.ChFrameD(chrono.ChVectorD(0, -1, 0)))

# Create the mass body
mass = chrono.ChBody()
mass.SetIdentifier(1)
mass.SetName("mass")
mass.SetMass(1.0)  # 1 kg mass
mass.SetInertiaXX(chrono.ChVectorD(0.01, 0.01, 0.01))
mass.SetPos(chrono.ChVectorD(0, 2, 0))  # Initial position
mass.SetPos_dt(chrono.ChVectorD(0, 0, 0))  # Initial velocity
system.Add(mass)

# Add a visual shape to represent the mass
mass_sphere = chrono.ChSphereShape()
mass_sphere.GetSphereGeometry().rad = 0.2
mass.AddVisualShape(mass_sphere)

# Create attachment points
ground_attachment = chrono.ChVectorD(0, 3, 0)  # Point on ground (actually in air)
mass_attachment = chrono.ChVectorD(0, 0, 0)    # Point on mass (local coordinates)

# Create a spring-damper between the ground and the mass
spring_damper = chrono.ChLinkTSDA()
spring_damper.Initialize(mass, ground, False, mass_attachment, ground_attachment)
spring_damper.SetSpringCoefficient(50.0)  # Spring constant: 50 N/m
spring_damper.SetDampingCoefficient(1.0)  # Damping coefficient: 1 N·s/m
spring_damper.SetRestLength(1.0)          # Rest length: 1 m
system.Add(spring_damper)

# Add visualization for the spring
spring_damper.AddVisualShape(chrono.ChVisualShapeSpring(0.05, 80, 15))

# Setup the Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle("Mass-Spring-Damper Demo")
vis.Initialize()
vis.AddCamera(chrono.ChVectorD(4, 2, 0), chrono.ChVectorD(0, 2, 0))
vis.AddTypicalLights()

# Set the simulation step size
time_step = 0.001
realtime_timer = chrono.ChRealtimeStepTimer()

# Run the simulation
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    
    system.DoStepDynamics(time_step)
    realtime_timer.Spin(time_step)
```

This script creates a simple mass-spring-damper system with the following components:

1. A fixed ground body
2. A 1kg mass represented by a sphere
3. A spring-damper connection (ChLinkTSDA) between the ground and mass
4. Visualization of both the mass and the spring

The simulation shows the mass oscillating under the influence of gravity and the spring-damper force. The spring has a stiffness of 50 N/m and a damping coefficient of 1 N·s/m. The mass starts at position (0, 2, 0) and the spring has a rest length of 1 meter.

You can adjust the spring and damper parameters, mass value, or initial conditions to observe different dynamic behaviors of the system.
