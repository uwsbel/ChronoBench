The API documentation and typical usage suggest `ChFrame` or `ChCoordsys` is used for poses. `ChFramed` is not a standard PyChrono class for poses. This likely causes an error or unexpected behavior. The correct class is `ch.ChFrameD` or `ch.ChCoordsysD`.
