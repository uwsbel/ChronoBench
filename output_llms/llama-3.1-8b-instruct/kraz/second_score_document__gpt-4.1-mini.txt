### 2. Correctness (30 points)

- **Quaternion Initialization:**  
  `initRot = chrono.ChQuaterniond(0, 0, 1, 0)` is used. Quaternions are usually in the form (w, x, y, z). The quaternion here is (0,0,1,0), which corresponds to zero scalar part and vector part (0,1,0). This is not a unit quaternion and likely represents a 180-degree rotation around the Y-axis or invalid rotation. The API typically uses `chrono.QUNIT` for identity or `chrono.ChQuaterniond(w,x,y,z)` with w as scalar.  
  This could cause incorrect initial orientation.  
  **Deduct 15 points for incorrect quaternion initialization.**

- **Visualization Attachment:**  
  As noted, `vis.AttachVehicle(vehicle.GetTractor())` is incorrect; `Kraz` does not have `GetTractor()`. The correct call should be `vis.AttachVehicle(vehicle)` or `vehicle.GetVehicle()` depending on the API. This will cause runtime errors or no visualization.  
  **Deduct 15 points for incorrect API usage affecting simulation behavior.**

- **Driver Steering Delta Adjustment:**  
  Inside the loop, the steering delta is set to fixed values (0.5, -0.5, 0.0) during lane change, but the driver’s `SetSteeringDelta()` is intended to set the rate of change of steering input, not the steering input itself. This may cause unexpected steering behavior. The correct way would be to set the steering input directly or use a steering function.  
  **Deduct 10 points for logical error in driver control.**
