```python
import chrono as chrono
from chrono import IrrlichtVisualizer
import numpy as np

# Initialize PyChrono environment and core components
chrono.Initialize()

# Create a world object
world = chrono.ChWorld()

# Set up the solver
solver = chrono.ChSolverPardisoMKL()

# Create an isotropic Kirchhoff material
material = chrono.ChMaterialTool.IsotropicElastoplastic(1e9, 0.4, 1e-6)

# Define the tablecloth dimensions
L = 2.0
W = 1.0
H = 0.1

# Generate a mesh grid for the tablecloth
n_x = 10
n_y = 10
dx = L / (n_x - 1)
dy = W / (n_y - 1)

# Create nodes and elements for the tablecloth
nodes = []
elements = []
for i in range(n_x):
    for j in range(n_y):
        x = i * dx
        y = j * dy
        node = chrono.ChNodeShell(x, y, 0, H)
        nodes.append(node)
        if i < n_x - 1 and j < n_y - 1:
            element = chrono.ChShellTriangle(node, nodes[(i + 1) * n_y + j], nodes[i * n_y + j + 1])
            elements.append(element)

# Add nodes and elements to the world
for node in nodes:
    world.Add(node)
for element in elements:
    world.Add(element)

# Set up the visualization system
visualizer = IrrlichtVisualizer(world)
visualizer.SetAmbientLight(0.5, 0.5, 0.5)
visualizer.SetCameraPosition(0, 0, 10)
visualizer.SetCameraTarget(0, 0, 0)

# Set default parameters for the simulation
world.SetGravity(0, 0, -9.81)
solver.SetMaxIterations(1000)
solver.SetTolerance(1e-6)

# Run the simulation
for i in range(100):
    world.DoStep()
    visualizer.Render()

# Clean up
chrono FINALIZE()
```
This script initializes the PyChrono environment, creates a world object, sets up the solver, and defines an isotropic Kirchhoff material. It then generates a mesh grid for the tablecloth and creates nodes and elements accordingly. The script adds the nodes and elements to the world, sets up the visualization system, and defines default parameters for the simulation. Finally, it runs the simulation for 100 steps and cleans up the environment.
