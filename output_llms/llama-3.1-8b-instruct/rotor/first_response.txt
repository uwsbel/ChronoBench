```python
import chrono as ch
import numpy as np

# Initialize the PyChrono environment
ch.InitChronic()

# Create a world object
world = ch.ChWorld()

# Create a beam object with IGA (Isogeometric Analysis) properties
beam = ch.ChBodyIGABeam()
beam.SetBodyFixed(False)
beam.SetMass(10.0)
beam.SetInertia(0.1, 0.1, 0.1)
beam.SetPosition(ch.Vec3(0, 0, 0))
beam.SetOrientation(ch.Mat33(ch.PI/2, 0, 0))

# Create a flywheel object and attach it to the center of the beam
flywheel = ch.ChBodyFlywheel()
flywheel.SetBodyFixed(True)
flywheel.SetMass(5.0)
flywheel.SetInertia(0.05, 0.05, 0.05)
flywheel.SetPosition(ch.Vec3(0, 0, 0))
flywheel.SetOrientation(ch.Mat33(0, 0, 0))
ch.ChAttachPoint().Attach(beam, flywheel, ch.Vec3(0, 0, 0), ch.Vec3(0, 0, 0))

# Create a rotational motor object and attach it to one end of the beam
motor = ch.ChBodyMotor()
motor.SetBodyFixed(False)
motor.SetMass(2.0)
motor.SetInertia(0.01, 0.01, 0.01)
motor.SetPosition(ch.Vec3(1, 0, 0))
motor.SetOrientation(ch.Mat33(0, 0, 0))
ch.ChAttachPoint().Attach(beam, motor, ch.Vec3(1, 0, 0), ch.Vec3(0, 0, 0))

# Set default parameters for the simulation
world.SetGravity(ch.Vec3(0, 0, -9.81))
world.SetTimeStep(0.01)
world.SetIterations(10)

# Create a FEM visualization object
fem = ch.ChFemVisualizer()
fem.SetBeam(beam)

# Create an Irrlicht window object
irrlicht = ch.ChIrrAppSimpleT(beam, "Jeffcott Rotor Simulation", ch dimension_2D)

# Run the simulation
world.Run()
```

This script will create a PyChrono simulation that models the dynamic behavior of a Jeffcott rotor using an Isogeometric Analysis (IGA) beam. The simulation includes the creation of a beam, attachment of a flywheel at its center, and a rotational motor that drives one end of the beam. The visual setup includes FEM visualization and an Irrlicht window to observe the dynamics of the beam and flywheel system.
