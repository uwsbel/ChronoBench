Here's the Python code that meets the given specifications:
```python
import chrono as ch
import chrono irrlicht as ir
import numpy as np

# Initialize PyChrono environment
ch.InitChronic()

# Define simulation parameters
dt = 1e-3  # Timestep
t_max = 10  # Simulation duration

# Initialize core components
sim = ch.Simulation()
scene = ir.Scene()
sim.Add(ir.Renderer(scene))

# Define soil parameters
soil_density = 1800  # kg/m^3
soil_young_modulus = 1e6  # Pa
soil_poisson_ratio = 0.3

# Initialize SCM deformable terrain
terrain = ch.SCMDeformableTerrain(sim, 
                                 soil_density, 
                                 soil_young_modulus, 
                                 soil_poisson_ratio, 
                                 width=100, 
                                 height=100)

# Initialize height map
height_map = np.random.rand(100, 100) * 10  # Random height map
terrain.SetHeightMap(height_map)

# Initialize HMMWV vehicle
vehicle = ch.HMMWV(sim, 
                   mass=1500, 
                   position=[0, 0, 0], 
                   orientation=[0, 0, 0])

# Initialize driver system
driver = ch.Driver(sim, 
                   vehicle, 
                   steering_gain=0.1, 
                   acceleration_gain=0.5)

# Set up visualization settings
scene.SetCameraPosition([0, 0, 10])
scene.SetCameraTarget([0, 0, 0])
scene.SetLighting(ir.LightingType.LIGHTING_DIRECTIONAL)

# Simulation loop
while sim.GetTime() < t_max:
    # Synchronize and advance vehicle, terrain, driver, and visual system
    sim.Step(dt)
    scene.Render()

# Finalize simulation
sim.DetachAll()
ch.CloseChronic()
```
This code initializes the PyChrono environment, sets up the required physical systems and objects, and implements a simulation loop that synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep. The simulation runs for a specified duration, and the final simulation is finalized.
