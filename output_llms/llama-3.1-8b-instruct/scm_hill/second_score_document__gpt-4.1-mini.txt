  - The `lidar.SetRotation(chrono.ChQuaterniond(0, 0, 0, 1))` is used. The quaternion (0,0,0,1) is a valid identity quaternion, but the order of quaternion components in PyChrono is (w,x,y,z). The code uses `ChQuaterniond(1,0,0,0)` for `initRot` (which is correct). Here, `ChQuaterniond(0,0,0,1)` sets w=0, x=0, y=0, z=1, which is not identity but a 180-degree rotation around z-axis. According to the API, sensors are usually added to the sensor manager, not directly to the system. This is a logical error: the sensor should be added to `sensor_manager`, not directly to the system.
