### 2. Correctness (30 points)

  ```python
  ChBodyEasyBox(lengthX, lengthY, lengthZ, density, visualize=True, collision=True, material=None)
  ChBodyEasyCylinder(radius, height, density, visualize=True, collision=True, material=None)
  ```  
  Passing a coordinate system instead of dimensions is incorrect and will cause runtime errors or unexpected behavior.  
  **Deduction: -15 points**

- **Joints:**  
  - Revolute joints should be created with `ChLinkLockRevolute()`, but the code uses `ChLinkRevolute()`, which does not exist in the documented API.  
  - The joint between connecting rod and piston is created as `ChLinkRevoluteSpherical()`, which is not a documented class. The correct approach is to use a combination of a spherical joint (`ChLinkLockSpherical()`) or a universal joint plus prismatic joint, or a `ChLinkLockPrismatic()` for the piston slider.  
  - The prismatic joint is created with `ChLinkPrismatic()`, but the documented class is `ChLinkLockPrismatic()`.  
  These mismatches will cause errors or incorrect joint behavior.  
  **Deduction: -15 points**
