  **No deduction.**

  - Similarly, dynamic bodies call `SetBodyFixed(False)`. The correct method is `SetFixed(False)`.  
  This is a significant API misuse and will cause the fixed state not to be set properly, potentially leading to simulation errors or unexpected behavior.  
  **Deduct 15 points for incorrect API usage.**

- **Visual Shape Initialization:**

  - Similarly, `chrono.ChVisualShapeSphere(0.1)` is correct.  
  This is a significant API misuse and will cause runtime errors or incorrect visualization.  
  **Deduct 15 points for incorrect API usage.**
