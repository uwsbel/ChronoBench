### 2. Correctness (30 points)

- **API Usage:**  
  - `sys.Set_G_acc(chrono.ChVectorD(0, 0, 0))` is correct to disable default gravity. ✔️  
  - Particle shapes are created using `chrono.ChSphereShape()` and `chrono.ChBoxShape()`. However, these are **visual assets**, not collision shapes or body shapes. The code adds these shapes as assets (`AddAsset`) but does not define collision shapes or enable collision on bodies. This means particles will not collide or interact physically, which is likely unintended. This is a **significant correctness issue**.  
  - The bodies are created with mass and inertia but no collision model is defined or enabled (`EnableCollision(True)` is missing). Without collision shapes and collision enabled, the simulation will not handle contacts properly.  
  - The `SetInertiaXX` is set to (1,1,1) for all particles regardless of shape or size, which is a simplification but acceptable for a demo.  
  - The custom gravity function applies forces between all pairs of bodies, including the fixed container (which has infinite mass). This could cause issues or unexpected behavior since the container is fixed and has no mass set explicitly.  
  - The use of `body.SetPos_dt()` to set initial velocity is correct.  
  - The rotation is set using `chrono.Q_from_Euler123`, which is correct.  
  - Visualization setup uses `chrono.ChVectorD` for camera position, but the API documentation uses `chrono.ChVector3d`. This is a minor inconsistency but likely acceptable since `ChVectorD` is an alias for double precision vector.  
  - The logo path is constructed manually using string concatenation instead of `chrono.GetChronoDataFile()`, which is the recommended way. This is a minor correctness issue.  
  - The simulation loop calls `ApplyCustomGravity(sys)` every frame, which is logically correct but inefficient (see efficiency).  
  - The `sys.DoStepDynamics(0.01)` call is correct.  

**Deductions:**  
- Major correctness issue: missing collision shapes and collision enabling on bodies → **-15 points**  
- Minor correctness issue: logo path not using `GetChronoDataFile()` → **-5 points**  

**Subtotal:** 30 - 15 - 5 = **10 points**
