To generate a PyChrono simulation that demonstrates the use of beam finite elements as per the given instructions, we will follow a step-by-step approach. This involves initializing the PyChrono environment, creating a physical system with a mesh composed of beams and nodes, setting necessary parameters, and visualizing the simulation using the Irrlicht engine.

First, ensure you have PyChrono installed. If not, you can install it using pip:

```bash
pip install pychrono
```

Here's a Python script that fulfills the requirements:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# 1. Initialize the PyChrono environment and core components.
print("Copyright (c) 2023 Project PyChrono")

# Create a Chrono physical system
sys = chrono.ChSystemSMC()

# 2. Add the required physical systems and objects as specified.
# Create a mesh composed of beams and nodes
num_nodes = 10
length = 10.0
nodes = []
beams = []

# Create nodes
for i in range(num_nodes):
    node = chrono.ChNodeFEAxyz(chrono.ChVectorD(i * length / (num_nodes - 1), 0, 0))
    node.SetMass(0.1)
    sys.Add(node)
    nodes.append(node)

# Create beam elements
for i in range(num_nodes - 1):
    beam = chrono.ChElementBeamEuler(
        nodes[i], nodes[i + 1], 10, chrono.ChVectorD(0.1, 0.1, 0.1), chrono.ChVectorD(0.1, 0.1, 0.1)
    )
    beam.SetYoungModulus(0.01e9)
    beam.SetGshearModulus(0.01e9 / (2 * 0.3 + 2))
    beam.SetBeamRaleyghDamping(0.01)
    sys.Add(beam)
    beams.append(beam)

# 3. Set necessary default parameters such as positions, forces, and interactions.
# Constrain the first node
nodes[0].SetFixed(True)

# Apply a force to the last node
force = chrono.ChForce()
force.SetDir(chrono.VECT_Y)
nodes[-1].AddForce(force)
force.SetModulus(100)

# Create the Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('Beams FEA')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(0, 1, -3))
vis.AddTypicalLights()

# Run the simulation loop
while vis.Run():
    vis.BeginScene()
    vis.Render()
    chronoirr.drawAllCOGs(vis, 2)
    chronoirr.drawAllLinkframes(vis, 1)
    vis.EndScene()
    sys.DoStepDynamics(0.001)
```

### Key Points:
1. **Initialization**: The script initializes a PyChrono simulation environment by creating a `ChSystemSMC` object, which is a Chrono physical system that handles contacts with the SMC (Sphere Mesh Contact) method.
   
2. **Creating Mesh**: It creates a mesh of nodes and beam elements. The nodes are positioned along the X-axis, and beam elements are created between successive nodes. Each node has a mass, and each beam element is assigned material properties like Young's modulus and shear modulus.

3. **Boundary Conditions**: The first node is fixed, and a force is applied to the last node in the positive Y-direction.

4. **Visualization**: The Irrlicht engine is used for real-time visualization. The simulation window displays the beam mesh, and the dynamics of the beam under the applied force are rendered in real-time.

5. **Simulation Loop**: The simulation runs in a loop, with each iteration advancing the system dynamics by a small time step (`0.001` seconds in this case) and rendering the current state of the system.

This script is a basic demonstration of using PyChrono for simulating beam finite elements. Depending on your specific requirements, you may need to adjust parameters like the number of nodes, material properties, and the applied forces.
