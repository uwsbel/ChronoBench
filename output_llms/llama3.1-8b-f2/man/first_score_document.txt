### 2. Correctness (30 points)

- **Use of `step_size` before definition:**  
  The variables `steering_time`, `throttle_time`, and `braking_time` are used to compute deltas for the driver inputs as:  
  ```python
  driver.SetSteeringDelta(10 * step_size / steering_time)
  driver.SetThrottleDelta(10 * step_size / throttle_time)
  driver.SetBrakingDelta(10 * step_size / braking_time)
  ```  
  But `step_size` is defined **after** the `main()` function, at the bottom of the script:  
  ```python
  step_size = 1e-3
  ```  
  This means that when the `main()` function runs, `step_size` is not yet defined, which will raise a `NameError`.  
  This is a **significant correctness error** that will prevent the script from running.  
  **Deduct 15 points.**

- **Use of semicolons:**  
  The code uses semicolons at the end of some lines (e.g., `truck.SetChassisFixed(False);`). While syntactically allowed in Python, this is unnecessary and non-idiomatic.  
  **Minor style issue, deduct 1 point.**

- **Setting collision system type:**  
  The collision system is set via:  
  ```python
  truck.GetSystem().SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)
  ```  
  This is correct and recommended for vehicle simulations.  
  **No deduction.**

- **Initialization order:**  
  The vehicle is initialized before setting visualization types. According to best practices, visualization types should be set **before** `Initialize()`. Here, the code calls `truck.Initialize()` before setting visualization types:  
  ```python

  truck.SetChassisVisualizationType(...)
  ```  
  This is incorrect because visualization types should be set before initialization to take effect.
