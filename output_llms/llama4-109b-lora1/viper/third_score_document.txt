  ```python
  plane = chrono.ChPlane()
  plane.SetPointNormal(chrono.ChVector3d(0,0,0), chrono.ChVector3d(0,0,1))
  ```  

  This is a **significant API misuse** that would cause runtime errors or incorrect terrain setup.
