### 2. Correctness (30 points)

- **Use of `chrono.ChMatrix33d(2)` in `mmesh.Transform`:**  
  The `Transform` method expects a position and a rotation matrix. Passing `chrono.ChMatrix33d(2)` attempts to create a rotation matrix with a scalar argument `2`. According to PyChrono API, `ChMatrix33d` constructor does not accept a scalar to scale the matrix. This is an incorrect way to scale the mesh. The correct approach is to scale the mesh vertices or use a scaling transform matrix explicitly.  
  **Deduct 15 points** for incorrect mesh scaling.

- **Camera Offset Pose Creation:**  
  The camera offset pose is created using `chrono.ChFramed` with a position and a quaternion from `chrono.QuatFromAngleAxis(2, chrono.ChVector3d(0, 1, 0))`. The angle `2` is in radians (~114.6 degrees), which is acceptable but unusual. No API error here, but the choice of angle is arbitrary and not explained.  
  **No deduction** (minor style choice).

- **Use of `cam.SetLag(lag)` and `cam.SetCollectionWindow(exposure_time)`:**  
  Correct API usage.
