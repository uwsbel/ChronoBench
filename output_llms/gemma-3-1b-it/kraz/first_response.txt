```python
import pychrono
import pychrono.core as chrono
import irict
import numpy as np

# --- 1. Initialization & Core Components ---

# Define Simulation Parameters
simulation_time = 10  # Simulation duration in seconds
time_step = 0.01  # Time step for calculations (smaller = more accuracy)
initial_position = [0, 0, 0]  # Initial x, y, z position
initial_velocity = [10, 0, 0]  # Initial x, y, z velocity
friction_coefficient = 0.8  # Adjust for desired realism
restitution_coefficient = 0.7  # Adjust for desired realism

# Create PyChrono Environment
env = chrono.Environment(
    simulation_time,
    time_step,
    initial_position,
    initial_velocity,
    friction_coefficient,
    restitution_coefficient
)

# --- 2. Physical Systems & Objects ---

# Kraz Vehicle
vehicle = chrono.Vehicle(
    position=initial_position,
    velocity=initial_velocity,
    mass=100.0,  # Adjust mass as needed
    orientation=chrono.Orientation(
        angle=0.0,
        axis=chrono.Axis(x=0, y=0, z=0)
    )
)


# Terrain
terrain = chrono.Terrain(
    position=initial_position,
    heightmap=np.zeros((100, 100), dtype=np.float32),  # Heightmap
    friction=0.5,  # Friction coefficient for the terrain
    restitution=0.7, # Rebound coefficient for the terrain
    resolution=100
)


# --- 3. Driver System ---

driver = chrono.Driver(
    vehicle=vehicle,
    control_method='linear_velocity', # Can be 'linear' or 'angular'
    control_method_type='linear' # Use linear control
)


# --- 4. Visualization (Irrlicht) ---

# Create Irrlicht Scene
scene = chrono.Scene()
scene.add_camera(chrono.Camera(
    position=(0, 0, 0),
    look_at=(0, 0, 0),
    width=800,
    height=600,
    color=(1, 1, 1, 1)  # White
))

# Set Camera Settings
scene.camera.set_color_mode(chrono.ColorMode.RGB)
scene.camera.set_brightness(0.8)

# Add the driver to the scene
driver.add_to_scene(scene)


# --- 5. Simulation Loop ---

def update_simulation():
    """
    This function is called repeatedly to update the simulation.
    """
    global vehicle, terrain, driver

    # Update Vehicle Position and Velocity
    vehicle.update()
    terrain.update()

    # Update Driver Control
    driver.update()

    # Render the Scene
    scene.render()

    # Optional:  Print some info
    print("Simulation Time:", simulation_time)
    print("Time Step:", time_step)


# --- Main Execution ---
if __name__ == "__main__":
    print("Starting PyChrono Simulation...")
    chrono.run(update_simulation)
    print("Simulation Complete.")
```

**Explanation and Key Improvements:**

1. **Imports:**  All necessary libraries are imported.

2. **Environment Setup:**
   - `chrono.Environment`: Creates the simulation environment.  Crucially, we specify the `simulation_time`, `time_step`, and initial conditions.
   - `chrono.Vehicle`:  Defines the Kraz vehicle with position, velocity, and mass.  The `orientation` is set to a simple rotation.

3. **Physical Systems:**
   - `chrono.Terrain`: Defines the terrain.  `heightmap` is used for visualization, and `friction` and `restitution` are set to realistic values.

4. **Driver System:**
   - `chrono.Driver`: Defines the driver control system.  `control_method` is set to 'linear' for simplicity.  You can change this to 'angular' for more complex control.

5. **Visualization (Irrlicht):**
   - `chrono.Scene`: Creates the Irrlicht scene.
   - `chrono.Camera`: Creates a camera to visualize the scene.  The camera's position and look-at point are set to the origin.
   - `scene.camera.set_color_mode()` and `scene.camera.set_brightness()` are used to control the appearance of the camera.
   - `driver.add_to_scene(scene)` adds the driver to the scene.

6. **Simulation Loop (`update_simulation`)**:
   - This function is the heart of the simulation.  It's called repeatedly.
   - `vehicle.update()` and `terrain.update()`: Update the vehicle and terrain positions and velocities.
   - `driver.update()`: Update the driver's control.
   - `scene.render()`: Renders the scene to the Irrlicht window.

7. **`if __name__ == "__main__":`**: Ensures the simulation only runs when the script is executed directly (not imported as a module).
