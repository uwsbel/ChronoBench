Okay, let's craft a PyChrono simulation script for a simple pendulum, incorporating Irrlicht for visualization and logging.  Here's a detailed script, broken down into sections with explanations, followed by considerations for expanding it.

```python
import pychrono
import pychrono.visuals as v
import pychrono.physics as ph
import numpy as np
import time

# --- 1. Environment Setup ---
# Define the ground body (e.g., a simple plane)
ground_x = 0
ground_y = 0
ground_z = 0

# Define the pendulum's mass (kg) - Adjust as needed
mass = 1.0  # kg

# Define the pendulum's length (m) - Adjust as needed
length = 1.0  # m

# Define the initial angle (degrees) - Adjust as needed
initial_angle = 30.0  # degrees

# --- 2. Physical Systems & Objects ---
# Create a pendulum object
pendulum = ph.Pendulum(mass, length, initial_angle)

# --- 3. Visual Setup ---
# Create a visual environment
visual = v.Visual()
visual.set_background(v.Color("white"))  # Set background color
visual.set_frame_size(1000, 1000) # Adjust frame size as needed

# --- 4. Simulation Parameters ---
# Set simulation parameters
simulation_time = 10  # seconds
time_step = 0.01  # seconds

# --- 5. Simulation Loop ---
try:
    while True:
        # Simulate the pendulum's motion
        pendulum.update()

        # Log the pendulum's position and velocity
        log_position = pendulum.get_position()
        log_velocity = pendulum.get_velocity()

        # Print the log data (for debugging and observation)
        print(f"Time: {time.time_ns():.2f}, Position: {log_position}, Velocity: {log_velocity}")

        # Pause for a short time to control the simulation speed
        time.sleep(time_step)

except KeyboardInterrupt:
    print("Simulation interrupted.")

# --- 6.  Visualization (Optional - for debugging) ---
#  You can uncomment this to display the simulation in Irrlicht
#  This section is not strictly required for the core functionality.
```
