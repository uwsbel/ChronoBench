```python
import pychrono
import irlayout
import numpy as np
import time

# Simulation parameters
simulation_duration = 50  # seconds
frames_per_second = 50
time_step = 0.01  # seconds
gravity = 9.81
vehicle_mass = 1000  # kg (adjust for vehicle weight)
tire_radius = 0.2  # meters
vehicle_position = np.array([0.0, 0.0, 0.0])  # meters
vehicle_orientation = np.array([0.0, 0.0, 0.0])  # radians
vehicle_model = "simple_tire"  # "simple_tire", "balloon", "wheel"

# Initialize PyChrono
pychrono.init()

# Create the RigidTerrain
terrain = irlayout.Ir রহমান()
terrain.set_width(100)
terrain.set_height(100)
terrain.set_color("lightgray")
terrain.set_texture("texture_road")  # Replace with a road texture
terrain.set_thickness(1)

# Create the vehicle mesh
vehicle_mesh = pychrono.Mesh(
    "vehicle_mesh",
    "triangle",
    "simple_tire",  # Use a simple tire for demonstration
    radius=tire_radius,
    scale=1.0
)

# Create the driver system
driver = pychrono.Driver(
    "driver_system",
    "rigid_terrain",
    vehicle_mesh,
    terrain,
    vehicle_position,
    vehicle_orientation,
    vehicle_mass,
    gravity,
    time_step
)


# Simulation loop
try:
    while True:
        # Update vehicle dynamics
        vehicle_position += vehicle_mass * time_step
        vehicle_orientation += vehicle_mass * time_step * 0.5 # Simplified movement

        # Render the scene
        driver.render()

        # Update the display
        time.sleep(time_step)

except KeyboardInterrupt:
    print("Simulation stopped.")
    driver.render() # Render before exiting
    pychrono.end()
```

**Explanation and Breakdown:**

1. **Import Libraries:**
   - `pychrono`: For simulation and visualization.
   - `irlayout`:  For creating the driver interface (UI).
   - `numpy`: For numerical operations (creating arrays).
   - `time`: For time-related functions.

2. **Simulation Parameters:**
   - `simulation_duration`:  The total time the simulation will run (seconds).
   - `frames_per_second`:  The frame rate (frames per second) for the simulation.
   - `time_step`:  The time interval between each frame (seconds).  Smaller values lead to smoother but slower simulations.
   - `gravity`:  The acceleration due to gravity (m/s^2).
   - `vehicle_mass`:  The mass of the vehicle (kg).  Adjust this value to change the vehicle's weight and behavior.
   - `tire_radius`: The radius of the tires (meters).
   - `vehicle_position`: The initial position of the vehicle (x, y, z).
   - `vehicle_orientation`: The initial orientation of the vehicle (radians).
   - `vehicle_model`: The type of vehicle model. "simple_tire" is a basic, easy-to-visualize model.

3. **Initialize PyChrono:**
   - `pychrono.init()`: Initializes the PyChrono environment.

4. **Create RigidTerrain:**
   - `irlayout.Ir রহমান()`: Creates an Ir রহমান object, which is a UI element for the driver system.
   - `terrain.set_width()` and `terrain.set_height()`:  Sets the dimensions of the terrain.
   - `terrain.set_color()`: Sets the color of the terrain.
   - `terrain.set_texture()`: Sets the texture of the terrain.
   - `terrain.set_thickness()`: Sets the thickness of the terrain.

5. **Create Vehicle Mesh:**
   - `pychrono.Mesh()`: Creates a mesh object from a specified type.
   - `"vehicle_mesh"`:  Specifies the type of mesh to create.
   - `"triangle"`:  Uses a triangle mesh.
   - `"simple_tire"`:  Uses a simple tire mesh.  You can experiment with other types (e.g., "balloon", "wheel").
   - `radius`: Sets the radius of the tire.
   - `scale`:  Scales the mesh.

6. **Create Driver System:**
   - `pychrono.Driver()`: Creates a driver object that manages the simulation.
   - `"driver_system"`:  The name of the driver system.
   - `"rigid_terrain"`:  Specifies the terrain to use for the driver.
   - `vehicle_mesh`:  Specifies the vehicle mesh.
   - `terrain`:  Specifies the terrain.
   - `vehicle_position`:  Specifies the initial position of the vehicle.
   - `vehicle_orientation`:  Specifies the initial orientation of the vehicle.
   - `vehicle_mass`:  Specifies the mass of the vehicle.
   - `gravity`:  Specifies the acceleration due to gravity.
   - `time_step`:  Specifies the time step.

7. **Simulation Loop:**
   - `while True:`:  Creates an infinite loop.
   - `vehicle_position += vehicle_mass * time_step`: Updates the vehicle's position based on its mass and time step.
   - `vehicle_orientation += vehicle_mass * time_step * 0.5`: Updates the vehicle's orientation based on its mass and time step.
   - `driver.render()`:  Renders the scene to the display.
   - `time.sleep(time_step)`:  Pauses the simulation for the specified time step.
   - `KeyboardInterrupt`:  Handles Ctrl+C to gracefully exit the simulation.  It renders the final scene before exiting.
