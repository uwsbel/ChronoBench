```python
import pychrono
import pychrono.core as pc
import pychrono.visual as v
import irlayout as lr
import numpy as np

# --- 1. Environment Setup & Core Initialization ---

# Define the terrain dimensions
terrain_width = 10
terrain_height = 5
terrain_x = 0
terrain_y = 0

# Define the vehicle's initial position and orientation
vehicle_x = 1
vehicle_y = 1
vehicle_orientation = 0  # 0 = Facing Right, 90 = Facing Forward, 180 = Facing Backward
vehicle_velocity = 0.1

# Define the HMMWV parameters
hmmwv_type = "HMMWV"
hmmwv_mobility = 2  # Higher mobility = larger vehicle
hmmwv_armor = 3
hmmwv_max_speed = 1.5
hmmwv_contact_method = "Contact Method" # "Contact Method" or "Static Contact"
hmmwv_tire_model = "Irrlicht Tire Model" # Default Irrlicht Tire Model

# Initialize PyChrono environment
try:
    env = pc.Environment(
        terrain_width,
        terrain_height,
        vehicle_x,
        vehicle_y,
        vehicle_orientation,
        hmmwv_type,
        hmmwv_mobility,
        hmmwv_armor,
        hmmwv_max_speed,
        hmmwv_contact_method,
        hmmwv_tire_model
    )
except Exception as e:
    print(f"Error initializing environment: {e}")
    exit()

# --- 2. Physical Systems & Objects ---

# Create the RigidTerrain object
terrain = lr.Terrain(
    width=terrain_width,
    height=terrain_height,
    texture='white',
    color='white'
)

# Create the vehicle primitive
vehicle = pc.Primitive(
    name='Vehicle',
    type=pc.VehicleType.Vehicle,
    x=vehicle_x,
    y=vehicle_y,
    orientation=vehicle_orientation,
    velocity=vehicle_velocity,
    contact_method=hmmwv_contact_method,
    tire_model=hmmwv_tire_model
)

# --- 3.  Interaction System (Simplified) ---

# Define a simple steering input (simplified for demonstration)
steering_input = pc.Input(
    name='steering_input',
    type='control',
    value=0.0
)

# Define a simple throttle input
throttle_input = pc.Input(
    name='throttle_input',
    type='control',
    value=0.0
)

# Define a simple braking input
brake_input = pc.Input(
    name='brake_input',
    type='control',
    value=0.0
)

# Connect the inputs to the vehicle's control system
vehicle.set_input(steering_input, throttle_input, brake_input)

# --- 4. Simulation Loop ---

# Set up the simulation loop
simulation = pc.Simulation(
    env,
    vehicle=vehicle,
    time_step=0.01,  # Adjust for desired simulation speed
    frame_rate=50,
    # Add any other simulation parameters here (e.g., damping, etc.)
)

# Start the simulation
simulation.run()

# --- 5. Visualization ---

#  Use irlayout to render the vehicle
try:
    lr.Render(env, vehicle)
except Exception as e:
    print(f"Error rendering: {e}")

# --- 6.  Clean Up (Optional) ---
#  You might want to clean up resources here.
#  For example, close the environment.
# env.close()
```

**Explanation and Key Considerations:**

1. **Import Libraries:**  We import `pychrono`, `pychrono.core`, `pychrono.visual`, `irlayout`, and `numpy`.
2. **Environment Setup:**
   - `pc.Environment()`:  Creates the simulation environment, defining the terrain, vehicle position, orientation, and other parameters.  The `hmmwv_type` is crucial for setting up the HMMWV's behavior.
   - `terrain = lr.Terrain(...)`: Creates the terrain object.
3. **Vehicle Creation:**
   - `pc.Primitive()`:  Creates the vehicle object.
   - `type=pc.VehicleType.Vehicle`: Specifies the vehicle type.
   - `x`, `y`, `orientation`:  Define the vehicle's position and orientation.
4. **Interaction System:**
   - `pc.Input()`:  Creates input objects for steering, throttle, and braking. These are *very* basic for demonstration.  In a real simulation, you'd likely use more sophisticated input methods.
   - `vehicle.set_input()`: Connects the input objects to the vehicle's control system.
5. **Simulation Loop:**
   - `pc.Simulation()`:  Creates the simulation object.
   - `time_step`: Controls the frequency of updates in the simulation. Smaller values lead to more accurate results but increase computation time.
   - `frame_rate`:  The number of frames per second.
6. **Visualization:**
   - `lr.Render(env, vehicle)`:  Uses `irlayout` to render the vehicle.  This is a basic visualization; you can customize the appearance further.
7. **Cleanup (Optional):**  The `env.close()` line is commented out, but it's a good practice to close the environment when you're finished to release resources.
