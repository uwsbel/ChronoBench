```python
import pychrono
import pychrono.core as pc
import pychrono.visuals as v
import pychrono.sensors as s
import numpy as np
import matplotlib.pyplot as plt  # For visualization (optional, but highly recommended)

# 1. Initialization & Core Components

# Define the mesh (Wavefront .obj file)
mesh_file = "triangle_mesh.obj"  # Replace with your .obj file
mesh = pc.Mesh.from_obj(mesh_file)

# Define the body (the triangular mesh)
body = mesh.body

# Define the sensor manager
sensor_manager = pc.SensorManager()

# Define the lidar sensor
lidar_sensor = pc.LidarSensor(sensor_manager)

# Define the simulation parameters
simulation_time = 10  # Simulation duration in seconds
time_step = 0.1  # Time step for simulation
initial_lidar_position = 0.0  # Initial lidar position (x, y, z)
initial_velocity = 0.0  # Initial lidar velocity (x, y, z)
gravity = 0.0  # Gravity (m/s^2)
rotation_rate = 0.0  # Rotation rate of the body (degrees/second)
noise_level = 0.1 #Noise level for lidar data.

# 2. Adding Physical Systems & Objects

# Define the initial position of the body
body.position = initial_lidar_position

# 3. Simulation Loop

try:
    simulation = pc.Simulation(
        time_step=time_step,
        initial_time=0,
        initial_position=body.position,
        initial_velocity=initial_velocity,
        gravity=gravity,
        rotation_rate=rotation_rate,
        noise_level=noise_level,
        sensor_manager=sensor_manager,
        lidar_sensor=lidar_sensor
    )

    print("Simulation started.")

    for step in range(simulation_time):
        print(f"Step: {step + 1}")
        # Simulate the system
        body.update()

        # Generate lidar data
        lidar_data = body.get_lidar_data()
        print(f"Lidar Data - Step {step + 1}: {lidar_data}")

        # print("Lidar data saved to lidar_data_step.npy")

except Exception as e:
    print(f"An error occurred: {e}")

finally:
    simulation.stop()
    print("Simulation stopped.")
```

1. **Imports:**  Includes all necessary modules from `pychrono`.

2. **Mesh Initialization:**

   - `mesh.body`:  Gets the body object from the mesh.

3. **Sensor Manager:**
   - `pc.SensorManager()`: Creates a sensor manager to manage the lidar sensor.

4. **Lidar Sensor:**
   - `pc.LidarSensor(sensor_manager)`: Creates an instance of the lidar sensor.  This is crucial for the simulation.

5. **Simulation Parameters:**
   - `simulation_time`, `time_step`, `initial_lidar_position`, `initial_velocity`, `gravity`, `rotation_rate`, `noise_level`: These are the core simulation parameters.  Adjust these to fine-tune the simulation.

6. **Simulation Loop:**
   - `pc.Simulation(...)`: Creates the simulation object.  Crucially, the `initial_time` is set to 0, so the simulation starts from the beginning.
   - `body.update()`:  This is the core update step.  It simulates the movement of the body based on the gravity and rotation.
   - `lidar_data = body.get_lidar_data()`:  Retrieves the lidar data.
   - The loop iterates through each step of the simulation.
