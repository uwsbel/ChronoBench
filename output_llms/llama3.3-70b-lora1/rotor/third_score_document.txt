According to the API, `ChBodyEasyCylinder` expects parameters `(radius, height, density, visualize=True, collision=True, material=None)`. The code uses `chrono.ChFramed`, which is not a documented class in the provided API; the correct class is `chrono.ChCoordsysd`. This is a **minor API misuse**.
