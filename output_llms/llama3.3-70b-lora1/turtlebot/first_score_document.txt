### 2. Correctness (30 points)

- **Collision System Usage:**  
  As noted, the collision system is created but never attached to the system. This means the system will use the default collision system, not the Bullet one intended. This is a significant correctness issue.  
  **Deduct 15 points.**

- **Robot Rotation:**  
  The rotation is set as `chrono.ChQuaterniond(1, 0, 0, -0.5 * m.pi)`.  
  Quaternion components are (w, x, y, z). The w component is 1, and z is `-0.5 * pi ≈ -1.57`. This is not a normalized quaternion and likely incorrect.  
  Quaternions must be normalized and represent a valid rotation.  
  This is a logical error that could cause incorrect robot orientation.  
  **Deduct 10 points.**

- **Use of Bitwise AND in Loop Condition:**  
  The loop condition is `while (vis.Run() & (system.GetChTime() < time_end)):`  
  The `&` operator is a bitwise AND, not logical AND.  
  In Python, logical AND is `and`. Using `&` here is incorrect and can cause unexpected behavior or errors.  
  **Deduct 15 points** for incorrect use of API/logical operators affecting simulation behavior.

- **Motor Speeds:**  
  The motor speeds are set with `turtlebot.SetMotorsSpeeds(...)` which is correct usage.  
  **No deduction.**
