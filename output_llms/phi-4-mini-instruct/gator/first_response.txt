Below is a PyChrono simulation script that fulfills your requirements:

```python
import PyChrono as chrono
import PyChrono.Irrlicht as Irrlicht
import PyChrono.Terrain as Terrain
import PyChrono.Vehicle as Vehicle
import PyChrono.TMEASY as TMEASY
import PyChrono.Visualization as Visualization
import PyChrono.Contact as Contact
import PyChrono.Physics as Physics

# Initialize PyChrono environment and core components
chrono.init()

# Create a Gator vehicle with specified parameters
gator_vehicle = Vehicle.Vehicle()
gator_vehicle.setName('Gator')
gator_vehicle.setLocation(0, 0, 0)  # Initial location (x, y, z)
gator_vehicle.setOrientation(0, 0, 0)  # Initial orientation (roll, pitch, yaw)
gator_vehicle.setContactMethod(Contact.HardContact)  # Hard contact method
gator_vehicle.setTMEASY(TMEASY.TMEASY)  # TMEASY tire model

# Add mesh visualization for all vehicle components
gator_vehicle.addMesh('gator_mesh.obj')  # Mesh file for the Gator vehicle

# Set up a RigidTerrain with specified dimensions and a custom texture
terrain = Terrain.RigidTerrain()
terrain.setDimensions(100, 100, 10)  # Width, length, height
terrain.setTexture('terrain_texture.jpg')  # Custom terrain texture

# Add the terrain to the simulation
chrono.add(terrain)

# Add the Gator vehicle to the simulation
chrono.add(gator_vehicle)

# Set up an interactive driver system
driver = Vehicle.Driver()
driver.setSteering(0)  # Initial steering angle
driver.setThrottle(0)  # Initial throttle
driver.setBraking(0)  # Initial braking

# Simulation loop
while True:
    # Update vehicle dynamics
    gator_vehicle.update()

    # Update driver control
    driver.update()

    # Render the scene
    Irrlicht.render()

    # Update the simulation at 50 frames per second
    chrono.update(1/50.0)

    # Break the loop if the simulation is finished
    if gator_vehicle.isFinished():
        break
```

Make sure to replace `'gator_mesh.obj'` and `'terrain_texture.jpg'` with the actual paths to your mesh and texture files. This script initializes the PyChrono environment, adds the Gator vehicle and terrain, and sets up an interactive driver system to control the vehicle's steering, throttle, and braking. The simulation loop updates the vehicle dynamics and rendering at 50 frames per second in real time.
