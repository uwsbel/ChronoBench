### 2. Correctness (30 points)

- **Visualization API Usage**:  
  - `vis.SetCameraVertical(CameraUp::Z)` is invalid Python syntax. The correct usage is `vis.SetCameraVertical(chronoirr.CameraVerticalDir_Z)` or similar.  
  - `vis.SetWindowCaption()` is not in the API; the correct method is `vis.SetWindowTitle()`.  
  - `vis.EnableShadow(True)` should be `vis.EnableShadows(True)` (plural).  
  - `vis.EnableContactPoints(False)` and `vis.EnableCollisionShapes(False)` are not documented methods in the provided API.  
  - The visualization system is never initialized with `vis.Initialize()`.  
  These errors will cause runtime failures or incorrect visualization behavior.  
  **Deduct 15 points** for incorrect visualization API usage.

- **Time Management in Loop**:  
  The variable `time` is updated inside the loop by querying `hmmwv.GetSystem().GetChTime()`. This is acceptable.  
  **No deduction.**

- **Driver Synchronization**:  
  The driver is synchronized with the current time, and inputs are retrieved correctly.  
  **No deduction.**

- **Vehicle Synchronization**:  
  The vehicle is synchronized with time, driver inputs, and terrain.  
  **No deduction.**

- **Advancing Simulation**:  
  The driver, terrain, and vehicle are advanced by the time step.  
  **No deduction.**

- **ROS Manager Update**:  
  The ROS manager is updated with time and time step, and the loop breaks if it returns False.  
  **No deduction.**

- **Enabling Realtime**:  
  `hmmwv.GetVehicle().EnableRealtime(True)` is called, which is correct.  
  **No deduction.**

- **Use of `veh.SetDataPath()`**:  
  The code uses `veh.SetDataPath(ch.GetChronoDataPath() + 'vehicle/')`. According to the API, the data path should be set with a trailing slash, but concatenation without a path separator may cause issues on some OSes. Better to use `os.path.join()` or ensure the slash is present. Minor issue.  
  **Deduct 5 points** for minor correctness issue.

- **Material Setup**:  
  The contact material is created and friction and restitution are set. No damping or compliance is set, which is acceptable for NSC.  
  **No deduction.**

- **Chassis Collision Type**:  
  Set to `CollisionType_NONE`, which disables chassis collision. This is acceptable if intentional.  
  **No deduction.**

- **Use of `ch.CSYSNORM`**:  
  The terrain patch is added with `ch.CSYSNORM`, which is correct for a horizontal patch.  
  **No deduction.**

**Total Correctness deduction: 20 points (15 + 5)**
