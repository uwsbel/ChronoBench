### PyChrono Simulation Script for HMMWV Vehicle

```python
import chrono as ch
import chrono_vehicle as chv
import chrono_ros as chr
import rospy

# Initialize PyChrono environment and core components
ch.Initialize()

# Create the simulation system
system = ch.ChronoSystemMultibody()

# Set up the HMMWV vehicle
vehicle_file = "path/to/hmmwv/vehicle_hmmwv.json"
vehicle = chv.ChronoVehicle(system, vehicle_file)

# Set contact method, engine type, and tire model
vehicle.SetContactMethod(ch.ContactMethod_NSC)
vehicle.SetEngineType(ch.EngineType_SHAFTS)
vehicle.SetTireModel(ch.TireModel_FM)

# Create the terrain
terrain_file = "path/to/terrain/terrain_irregular.json"
terrain = chv.ChronoTerrain(system, terrain_file)
terrain.SetFrictionCoefficient(0.8)
terrain.SetRestitutionCoefficient(0.7)

# Initialize the driver system
driver = chv.ChronoDriver(vehicle)
driver.SetSteeringType(chv.SteeringType_PURE_PURSUIT)

# Initialize ROS integration
chr.ChronoRosManager(system)

# Define ROS handlers
def clock_cb(time):
    system.Update()

def driver_inputs_cb(inputs):
    driver.SetInputs(inputs)

def vehicle_state_cb(state):
    vehicle.SetState(state)

# Register ROS handlers
chr.RegisterClockCallback(clock_cb)
chr.RegisterDriverInputsCallback(driver_inputs_cb)
chr.RegisterVehicleStateCallback(vehicle_state_cb)

# Simulation loop
def simulate():
    rate = rospy.Rate(100)  # 100 Hz
    while not rospy.is_shutdown():
        # Synchronize and advance systems
        system.Advance(0.01)  # 10 ms timestep
        driver.Advance(0.01)
        terrain.Advance(0.01)
        
        # Update ROS manager
        chr.UpdateRosManager()
        
        rate.sleep()

if __name__ == "__main__":
    rospy.init_node("hmmwv_simulation")
    simulate()
```

### Explanation

The provided Python script initializes a PyChrono simulation featuring an HMMWV vehicle with specific parameters. Here's a step-by-step breakdown:

1.  **Initialization**: The PyChrono environment and core components are initialized using `ch.Initialize()`.
2.  **Simulation System**: A multibody simulation system is created using `ch.ChronoSystemMultibody()`.
3.  **HMMWV Vehicle**: The HMMWV vehicle is created using `chv.ChronoVehicle()` and loaded from a JSON file. The contact method, engine type, and tire model are set using `vehicle.SetContactMethod()`, `vehicle.SetEngineType()`, and `vehicle.SetTireModel()`, respectively.
4.  **Terrain**: The terrain is created using `chv.ChronoTerrain()` and loaded from a JSON file. Friction and restitution coefficients are set using `terrain.SetFrictionCoefficient()` and `terrain.SetRestitutionCoefficient()`, respectively.
5.  **Driver System**: A driver system is initialized using `chv.ChronoDriver()` and set to use pure pursuit steering.
6.  **ROS Integration**: The Chrono ROS manager is initialized using `chr.ChronoRosManager()`.
7.  **ROS Handlers**: Callbacks for clock synchronization, driver inputs, and vehicle state are defined and registered using `chr.RegisterClockCallback()`, `chr.RegisterDriverInputsCallback()`, and `chr.RegisterVehicleStateCallback()`, respectively.
8.  **Simulation Loop**: The simulation loop advances the vehicle, terrain, and driver systems at each timestep and updates the ROS manager for data publishing.

### Usage

To run the simulation:

*   Ensure you have PyChrono, PyChrono-Vehicle, and PyChrono-ROS installed.
*   Replace `"path/to/hmmwv/vehicle_hmmwv.json"` and `"path/to/terrain/terrain_irregular.json"` with the actual file paths for the HMMWV vehicle and terrain.
*   Run the script using Python (e.g., `python hmmwv_simulation.py`).

The simulation will run at 100 Hz, and the ROS manager will publish data at each timestep. You can modify the simulation parameters, such as the timestep and friction coefficients, to suit your specific needs.
