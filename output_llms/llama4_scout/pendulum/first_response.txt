**Simple Pendulum Simulation using PyChrono and Irrlicht**

### Prerequisites

* PyChrono library installed
* Irrlicht library installed

### Simulation Script

```python
import pychrono as chrono
import pychrono.irrlicht as irr

# Initialize PyChrono environment
chrono.ChEngine.Initialize()

# Create the Irrlicht application
app = irr.ChIrrApp()

# Create the simulation system
system = chrono.ChSystem()

# Create the ground body
ground = chrono.ChBody()
ground.SetBodyFixed(True)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(ground)

# Create the pendulum body
pendulum = chrono.ChBody()
pendulum.SetMass(1.0)
pendulum.SetInertiaXX(chrono.ChVectorD(0.1, 0.1, 0.1))
pendulum.SetPos(chrono.ChVectorD(1.0, 0.0, 0.0))
system.Add(pendulum)

# Create a revolute joint between the ground and pendulum
joint = chrono.ChLinkLockRevolute()
joint.Init(ground, pendulum, chrono.ChFrameD(chrono.ChVectorD(0, 0, 0), chrono.ChQuaternionD(1, 0, 0, 0)))
system.Add(joint)

# Add gravity to the system
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = irr.ChIrrApp(system, "Simple Pendulum", chrono.ChVectorD(800, 600), True)

# Set visualization parameters
vis.SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)
vis.SetFrameRate(60)
vis.SetTimeStep(0.01)

# Log pendulum's position and velocity periodically
def LogPendulumState(t):
    print(f"Time: {t:.2f} s")
    print(f"Pendulum position: {pendulum.GetPos()}")
    print(f"Pendulum velocity: {pendulum.GetPos_dt()}")

# Run the simulation
while vis.Run():
    vis.ComputeSimulationStep()
    LogPendulumState(vis.GetChTime())
```

### Explanation

1. The PyChrono environment is initialized, and the core components are created.
2. A ground body and a pendulum body are created with their respective properties (mass, inertia, position).
3. A revolute joint is created to connect the ground and pendulum bodies.
4. The simulation system is set up with gravity and the Irrlicht visualization system.
5. The simulation is run, and the pendulum's position and velocity are periodically logged.

### Running the Simulation

Save this script to a file (e.g., `simple_pendulum.py`) and run it using Python (e.g., `python simple_pendulum.py`). This will launch the Irrlicht visualization window, and the simulation will start. The pendulum's position and velocity will be logged to the console periodically.
