### Simple Pendulum Simulation with PyChrono and Irrlicht

Below is a Python script that sets up a simple pendulum simulation using PyChrono with Irrlicht for visualization. This script initializes the PyChrono environment, creates a ground body and a pendulum, connects them with a revolute joint, and visualizes the simulation.

```python
import chrono as ch
import chrono.irrlicht as irr

# Initialize PyChrono environment
ch.CHGlobals.Initialize()

# Create the Irrlicht application
app = irr.IrrlichtApplication()

# Create the simulation system
system = ch.ChSystem()

# Create the ground body
ground = ch.ChBodyEasyBox(1, 1, 1, 1000, False, False)
ground.SetPos(ch.ChVector3d(0, -5, 0))
ground.SetFixed(True)
system.AddBody(ground)

# Create the pendulum body
pendulum = ch.ChBodyEasyBox(0.1, 1, 0.1, 10, False, False)
pendulum.SetPos(ch.ChVector3d(0, 0, 0))
pendulum.SetRot(ch.ChQuaternion(0, 0, 0, 1))
system.AddBody(pendulum)

# Add a revolute joint between ground and pendulum
joint = ch.ChRevoluteJoint(ground, pendulum, ch.ChVector3d(0, -5, 0), ch.ChVector3d(0, 0, 0))
joint.SetModulusOfElasticity(1e6)
joint.SetDissipation(0.5)
system.AddJoint(joint)

# Add a torque to simulate gravity
torque = ch.ChTorque()
torque.SetTorque(0, 0, -0.5)
pendulum.AddTorque(torque)

# Create the Irrlicht visual system
visual_system = irr.IrrlichtSystem(system)
visual_system.SetWindowSize(ch.ChVector2i(800, 600))
visual_system.SetWindowTitle("Simple Pendulum Simulation")
visual_system.EnableShadows()
app.SetVisualSystem(visual_system)

# Simulation loop
while True:
    # Advance the simulation
    system.DoStepDynamics(0.01)

    # Log pendulum's position and velocity
    print("Pendulum position: ", pendulum.GetPos())
    print("Pendulum velocity: ", pendulum.GetPos_dt())

    # Render the visualization
    app.DoStep()
```

### Instructions for Running the Script

1. Ensure you have PyChrono installed. If not, you can install it via pip: `pip install pychrono`.
2. Make sure you have Irrlicht installed and properly configured on your system.
3. Save the script to a file, for example, `pendulum_simulation.py`.
4. Run the script using Python: `python pendulum_simulation.py`.

This script sets up a basic simulation of a simple pendulum using PyChrono for physics and Irrlicht for visualization. It logs the pendulum's position and velocity periodically and renders the simulation in real-time.
