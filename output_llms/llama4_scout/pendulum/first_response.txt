### Simple Pendulum Simulation with PyChrono and Irrlicht

Below is a Python script that sets up a simple pendulum simulation using PyChrono with Irrlicht for visualization. This script initializes the PyChrono environment, creates a ground body and a pendulum, connects them with a revolute joint, and visualizes the simulation.

```python
import chrono as ch
import chrono.irrlicht as irr

# Initialize the PyChrono environment
ch.ChEngine.Initialize()

# Create the Irrlicht application
app = irr.ChIrrApp()

# Create the ground body
ground = ch.ChBody()
ground.SetPos(ch.ChVector3d(0, 0, -10))
ground.SetFixed(True)

# Create the pendulum body
pendulum = ch.ChBody()
pendulum.SetMass(1.0)
pendulum.SetPos(ch.ChVector3d(5, 0, 0))
pendulum.SetRot(ch.ChQuaterniond(1, 0, 0, 0))

# Define inertia for the pendulum
inertia = ch.ChMatrix33d(1, 0, 0, 0, 1, 0, 0, 0, 1)
inertia(0, 0) = 0.1
inertia(1, 1) = 0.1
inertia(2, 2) = 0.1
pendulum.SetInertia(inertia)

# Create a revolute joint
joint = ch.ChRevolute()
joint.Init(ground, pendulum, ch.ChFrame3d(ch.ChVector3d(0, 0, 0), ch.ChQuaterniond(1, 0, 0, 0)))

# Create a motor (optional, for actuating the pendulum)
# motor = ch.ChFunction()
# motor = ch.ChSinCosEasePow(0, 1, 0.1, 10)
# joint.SetMotorFunction(motor)

# Create the Irrlicht scene
scene = irr.ChIrrScene()
scene.AddBody(ground)
scene.AddBody(pendulum)
scene.AddLink(joint)

# Set visualization parameters
scene.SetCameraPos(ch.ChVector3d(0, -20, 10))
scene.SetCameraTarget(ch.ChVector3d(0, 0, 0))

# Simulation loop
time = 0
dt = 0.02
while time < 30 and app.Run():
    # Update the simulation
    pendulum.Update()
    joint.Update()
    
    # Log pendulum's position and velocity
    print(f"Time: {time:.2f}, Pendulum Position: {pendulum.GetPos()}, Pendulum Velocity: {pendulum.GetPos_dt()}")
    
    # Increment time
    time += dt

    # Render the scene
    scene.Render()
```

### Explanation:

1. **Initialization**: The PyChrono environment and the Irrlicht application are initialized.
2. **Ground and Pendulum Bodies**: A fixed ground body and a pendulum body with specified mass and inertia are created.
3. **Revolute Joint**: A revolute joint connects the ground and pendulum bodies, allowing rotational motion around a single axis.
4. **Visualization**: The Irrlicht scene is set up with the ground, pendulum, and joint. The camera position and target are defined for visualization.
5. **Simulation Loop**: The simulation updates the system state, logs the pendulum's position and velocity, and renders the scene at each time step.

### Running the Simulation:

- Ensure PyChrono and Irrlicht are properly installed and configured.
- Execute the script in a Python environment.
- The simulation will run for 30 seconds, displaying the pendulum's motion and logging its position and velocity at each time step.
