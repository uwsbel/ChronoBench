### 2. Correctness (30 points)

- **Use of `chrono.ChFramed` in `AddVisualShape` and `Initialize` of joint:**  
  - The documentation specifies `chrono.ChCoordsysD` (or `chrono.ChCoordsys`) for joint initialization frames, not `chrono.ChFramed`.  
  - `chrono.ChFramed` is not a standard PyChrono class for frames; the correct class is `chrono.ChCoordsysD` or `chrono.ChCoordsys`.  
  - Using `chrono.ChFramed` will cause an error or unexpected behavior. This is a **significant API misuse**. Deduct 15 points.
- **Setting angular velocity:**  
  - The method `SetAngVelParent` is used, but the documentation and typical PyChrono usage use `SetWvel_par()` or `SetWvel_loc()` for angular velocity.  
  - `SetAngVelParent` is not a standard documented method. This is likely incorrect or a typo. Deduct 15 points.
- **Visual shape creation:**  
  - Visual shapes are created correctly, but the second cylinder visual shape is added with `chrono.VNULL` and `chrono.QuatFromAngleY(chrono.CH_PI_2)`.  
  - `chrono.VNULL` is not defined in the documentation; the correct zero vector is `chrono.ChVectorD(0,0,0)` or `chrono.ChVector3d(0,0,0)`.  
  - Similarly, `chrono.QuatFromAngleY` is not documented; the documented function is `chrono.ChQuaterniond` or `chrono.Q_from_AngAxis`.  
  - These are minor inaccuracies but could cause runtime errors. Deduct 5 points.
- **Joint initialization:**  
  - The joint is initialized with `chrono.ChFramed(chrono.ChVector3d(0,0,1), chrono.ChQuaterniond(1,0,0,0))`.  
  - The documentation shows `Initialize(body1, body2, chrono.ChCoordsysD(position, rotation))`.  
  - Using `chrono.ChQuaterniond(1,0,0,0)` is acceptable as identity quaternion, but the frame class is wrong.  
  - Deducted above.
- **Use of `AddVisualShape` on joint:**  
  - The joint `sph_1` is a `ChLinkLockSpherical` object, which does not have `AddVisualShape` method according to the documentation. Visual shapes are added to bodies, not joints.  
  - This is a **logical error** and could cause runtime error or be ignored silently. Deduct 10 points.
- **Use of `SetRot` with `chrono.ChQuaterniond(1,0,0,0)`:**  
  - This is acceptable as identity quaternion. No deduction.
- **Use of `sys.DoStepDynamics(1e-3)`:**  
  - Correct usage. No deduction.
- **Use of `vis.Run()` loop:**  
  - Correct usage. No deduction.

**Correctness deductions total:** 15 + 15 + 5 + 10 = 45 points, but max deduction is 30, so capped at 30.
