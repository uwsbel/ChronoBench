However, the documentation states that joints should be initialized with `chrono.ChCoordsysD` (which is an alias for `ChCoordsys` with double precision), not `ChFramed`. `ChFramed` is a deprecated or older class replaced by `ChCoordsys` or `ChCoordsysD`. This is a significant API misuse that can cause incorrect joint frames or errors.

- **Joint initialization frames:**
  - `rev_1.Initialize(ground, pend_1, chrono.ChFramed(chrono.ChVector3d(0, 0, 1), chrono.ChQuaterniond(1, 0, 0, 0)))`

The joint frames do not align with the pendulum positions, which may cause unexpected behavior or joint constraints not matching the bodies' positions. This is a **logical error** in joint initialization.
