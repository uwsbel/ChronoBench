### 2. Correctness (30 points)

- **API usage correctness:**  
  - `ChBodyEasyCylinder` is called with `chrono.ChAxis_Y` as first argument, which is **incorrect**. According to the API, `ChBodyEasyCylinder` constructor signature is:  
    ```python
    ChBodyEasyCylinder(radius, height, density, visualize=True, collision=True, material=None)
    ```  
    The axis is not a parameter here. The code uses:  
    ```python
    mcrank = chrono.ChBodyEasyCylinder(chrono.ChAxis_Y, crank_rad, crank_thick, 1000)
    ```  
    This is a misuse of the API and will cause an error or unexpected behavior. The axis alignment should be done via rotation, not by passing an axis to the constructor.  
    **Deduct 15 points for incorrect API usage.**

- **Joint initialization frames:**  
  - Motor initialized with `chrono.ChFramed(crank_center)` — `ChFramed` is not a documented class or function in PyChrono API; the correct class for frames is `chrono.ChCoordsysD` or `chrono.ChCoordsys`.  
  - Similarly, revolute and prismatic joints are initialized with `chrono.ChFramed(...)`.  
  - This is a **significant error** because `ChFramed` does not exist in PyChrono API, and the correct frame class is `chrono.ChCoordsysD` (or `chrono.ChCoordsys` in Python).  
  **Deduct 15 points for incorrect joint initialization frames.**

- **Motor speed function:**  
  - Uses `chrono.ChFunctionConst(chrono.CH_PI)`, which is correct.  
  **No deduction.**

- **Data collection:**  
  - `array_speed` is computed as difference of positions between current and previous step without dividing by time step, so it is actually a displacement, not speed.  
  - This is a **logical error** in calculation of speed.  
  **Deduct 10 points for logical error in speed calculation.**

- **Rotation angle extraction:**  
  - `mcrank.GetRot().GetAngleZ()` is used to get crank angle.  
  - `GetAngleZ()` is not a standard method in PyChrono's quaternion or rotation API.  
  - The correct way to get angle about Z-axis would be to convert quaternion to Euler angles or extract rotation axis and angle.  
  - This is a **logical error** or incorrect method call.  
  **Deduct 10 points for incorrect rotation angle extraction.**
