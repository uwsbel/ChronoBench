### 2. Correctness (30 points)

- **Body Creation:**

  - The crank is created with `ChBodyEasyCylinder(chrono.ChAxis_Y, crank_rad, crank_thick, 1000)`. According to the documentation, `ChBodyEasyCylinder` expects `(radius, height, density, visualize=True, collision=True, material=None)`. The first argument should be radius, not an axis. The code passes `chrono.ChAxis_Y` as the first argument, which is incorrect.

  - Similarly, the piston is created with `ChBodyEasyCylinder(chrono.ChAxis_X, 0.2, 0.3, 1000)`, again passing an axis as the first argument.

  - This is a **significant API misuse** that will cause errors or unexpected behavior.

- **Joint Initialization:**

  - The joints are initialized with `chrono.ChFramed(...)`. The documentation uses `chrono.ChCoordsysD` for frames. `ChFramed` is an alias or shorthand for `ChCoordsysD` in PyChrono Python bindings, so this is acceptable.

- **Motor Initialization:**

  - The motor is initialized with `my_motor.Initialize(mcrank, mfloor, chrono.ChFramed(crank_center))` and speed function set with `SetMotorFunction`. According to the documentation, the method is `SetSpeedFunction`. This is a **minor API misuse**.

- **Data Collection:**

  - The crank angle is obtained by `mcrank.GetRot().GetAngleZ()`. `GetRot()` returns a quaternion; `GetAngleZ()` is not a documented method on quaternion. The correct way to get rotation about Z would be to convert quaternion to Euler angles or use `GetRot().Q_to_Euler123()` or similar.

  - This is a **logical error** in extracting the crank angle.

- **Speed Calculation:**

  - Speed is computed as the difference in piston x-position between current and previous step, without dividing by the time step. This gives a displacement, not speed.

  - This is a **logical error**.

**Deductions:**

- 15 points for incorrect use of `ChBodyEasyCylinder` constructor (significant API misuse).
- 10 points for logical errors in angle extraction and speed calculation.
- 5 points for minor API misuse in motor speed function method name.
