**PyChrono Simulation Script: Kraz Vehicle on Rigid Terrain**
===========================================================

### Import necessary modules

```python
import pychrono as chrono
import pychrono.irrlicht as irr
from pychrono.vehicle import *
```

### Initialize PyChrono Environment and Core Components
--------------------------------------------------------

```python
# Initialize PyChrono environment
chrono.ChEngine.Initialize()

# Set up the simulation parameters
SIMULATION_TIME = 10.0  # seconds
TIME_STEP = 0.01  # seconds

# Create a Chrono engine
engine = chrono.ChEngine()

# Set the time step and simulation end time
engine.SetTimestep(TIME_STEP)
engine.SetSimulationEndTime(SIMULATION_TIME)
```

### Create Kraz Vehicle and Rigid Terrain
-----------------------------------------

```python
# Create a Kraz vehicle
kraz = chrono.vehicle.Kraz()

# Set the initial position and orientation of the vehicle
kraz.SetInitialPosition(chrono.ChVector3d(0, 0, 1.0))
kraz.SetInitialOrientation(chrono.Quat(1, 0, 0, 0))

# Add the vehicle to the simulation
engine.AddSystem(kraz.GetChassisBody())

# Create a rigid terrain
terrain = chrono.vehicle.RigidTerrain(engine)

# Set terrain parameters
terrain.SetFriction(0.8)
terrain.SetRestitution(0.3)

# Add the terrain to the simulation
engine.AddSystem(terrain.GetGroundBody())
```

### Initialize Driver System and Visualization
---------------------------------------------

```python
# Create a driver system for vehicle control
driver = chrono.vehicle.Driver(kraz)

# Set the driver inputs (e.g., throttle, steering)
driver.SetThrottle(0.5)
driver.SetSteering(0.2)

# Create an Irrlicht application for visualization
vis = irr.ChIrrApp(engine, "Kraz Vehicle Simulation")

# Set up the camera
vis.SetCamera(chrono.ChVector3d(0, -10, 2), chrono.ChVector3d(0, 0, 1))

# Enable lighting
vis.SetLight(chrono.ChVector3d(10, -10, 10), chrono.ChVector3d(0, 0, 0), True)
```

### Simulation Loop
-------------------

```python
while engine.GetSimulationTime() < SIMULATION_TIME:
    # Synchronize and advance the vehicle, terrain, driver, and visual system
    kraz.Synchronize(engine.GetSimulationTime())
    terrain.Synchronize(engine.GetSimulationTime())
    driver.Synchronize(engine.GetSimulationTime())
    vis.Synchronize(engine.GetSimulationTime())

    # Advance the systems
    kraz.Advance(TIME_STEP)
    terrain.Advance(TIME_STEP)
    driver.Advance(TIME_STEP)
    vis.Advance(TIME_STEP)

    # Render the visualization
    vis.Render()
```

### Run the Simulation
----------------------

```python
# Run the simulation
vis.Run()
```

This script sets up a PyChrono simulation featuring a Kraz vehicle on a rigid terrain with specified initial conditions and visualization settings. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each time step, maintaining real-time execution.
