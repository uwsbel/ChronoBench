### PyChrono Simulation Script for M113 Vehicle

```python
import chrono as ch
import chrono.irrlicht as chirr
import chrono.vehicle as chvehicle

# 1. Initialize the PyChrono environment and core components
ch.ChEngine.Initialize()

# 2. Create the M113 vehicle
vehicle = chvehicle.ChM113()

# Set initial conditions
vehicle.SetPos(ch.ChVector3d(0, 0, 1.1))
vehicle.SetRot(ch.ChQuaterniond(1, 0, 0, 0))

# 3. Create a rigid terrain
terrain = chvehicle.ChTerrainRigid()
terrain.SetFrictionCoefficient(0.8)
terrain.SetRestitutionCoefficient(0.3)
terrain.SetPlane(ch.ChPlane(0, 0, 1, 0))

# Set terrain size and position
terrain.SetSize(ch.ChVector3d(100, 100, 0))

# 4. Initialize a driver system for vehicle control
driver = chvehicle.ChDriver(vehicle)
driver.SetThrottle(0.5)
driver.SetSteering(0.0)

# 5. Create a real-time visualization using Irrlicht
vis = chirr.ChVisualSystemIrrlicht()
vis.AttachVehicle(vehicle)
vis.SetCameraVerticalDir(ch.ChVector3d(0, 0, -1))
vis.SetCameraPos(ch.ChVector3d(0, -10, 1))
vis.EnableDirectionalLights()

# 6. Simulation loop
while vis.Run() and not vis.ExitRequested():
    # Synchronize subsystems
    vehicle.Synchronize(vis.GetChTimeStep())
    terrain.Synchronize(vis.GetChTimeStep())
    driver.Synchronize(vis.GetChTimeStep())

    # Advance subsystems
    vehicle.Advance(vis.GetChTimeStep())
    terrain.Advance(vis.GetChTimeStep())
    driver.Advance(vis.GetChTimeStep())

    # Render visualization
    vis.Render()
```

### Explanation

The provided Python script utilizes the PyChrono library to simulate an M113 vehicle on a rigid terrain with real-time visualization using Irrlicht.

1.  **Initialization**: The PyChrono environment and core components are initialized using `ch.ChEngine.Initialize()`.
2.  **M113 Vehicle**: An instance of the `chvehicle.ChM113` class is created to represent the M113 vehicle. Initial conditions such as position and rotation are set using `SetPos` and `SetRot`.
3.  **Rigid Terrain**: A rigid terrain is created using `chvehicle.ChTerrainRigid`. Friction and restitution coefficients are set to simulate realistic interactions. The terrain's size and position are defined using `SetSize`.
4.  **Driver System**: A driver system is initialized using `chvehicle.ChDriver` to control the vehicle's throttle and steering.
5.  **Real-time Visualization**: A real-time visualization is created using `chirr.ChVisualSystemIrrlicht`. The vehicle is attached to the visual system, and camera settings such as position and orientation are defined. Directional lighting is enabled for better visualization.
6.  **Simulation Loop**: The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each time step. The loop continues until the visualization is closed or the exit request is made.

This script provides a basic framework for simulating an M113 vehicle with PyChrono and can be further customized and extended to suit specific requirements.
