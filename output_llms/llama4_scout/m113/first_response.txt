### PyChrono Simulation Script for M113 Vehicle

```python
import chrono as ch
import chrono.irrlicht as irr

# 1. Initialize the PyChrono environment and core components
ch.CH_Environment().Set_G_acc(ch.ChVector3d(0, 0, -9.81))

# 2. Create the M113 vehicle
vehicle = ch.ChVehicle()

# Create the chassis
chassis = ch.ChBody()
chassis.SetName('chassis')
chassis.SetPos(ch.ChVector3d(0, 0, 1))
vehicle.SetChassis(chassis)

# Add wheels and other vehicle components
# For simplicity, this example omits detailed vehicle setup

# 3. Create a rigid terrain
terrain = ch.ChTerrain()
terrain.SetName('terrain')
terrain.SetFrictionCoefficient(0.8)
terrain.SetRestitutionCoefficient(0.3)
terrain.SetDimensions(100, 100)

# 4. Initialize a driver system for vehicle control
driver = ch.ChDriver()
driver.SetVehicle(vehicle)
driver.SetMode(ch.DriverMode_Autonomous())

# 5. Create a real-time visualization using Irrlicht
vis = irr.ChVisualSystemIrrlicht()
vis.AttachVehicle(vehicle)
vis.SetCameraVerticalDir(ch.ChVector3d(0, 0, 1))
vis.SetCameraPos(ch.ChVector3d(0, -10, 5))
vis.EnableStatsDisplay()
vis.EnableRealTime(False)

# Set up lighting
vis.SetLight(0, ch.ChVector3d(10, 10, 10), ch.ChColor(1, 1, 1), True)

# Simulation parameters
step_size = 0.01
end_time = 10.0

# Simulation loop
while vis.GetChTime() < end_time:
    # Advance the simulation
    vehicle.Advance(step_size)
    terrain.Advance(step_size)
    driver.Advance(step_size)
    
    # Synchronize and update the visual system
    vis.Synchronize('', vehicle.GetChTime())
    vis.Render()

    # Ensure real-time execution
    vis.SpinEventLoop()
```

### Explanation

This script initializes a basic PyChrono simulation featuring an M113 vehicle, rigid terrain, a driver system, and real-time visualization using Irrlicht.

1.  **Environment Initialization**: The PyChrono environment is initialized, and the gravitational acceleration is set.
2.  **Vehicle Creation**: A basic vehicle (M113) is created. Detailed vehicle setup, including wheels and other components, is omitted for simplicity.
3.  **Terrain Setup**: A rigid terrain with specified friction and restitution coefficients is created.
4.  **Driver System**: A driver system for vehicle control is initialized.
5.  **Visualization**: A real-time visualization is set up using Irrlicht, including camera settings and lighting.
6.  **Simulation Loop**: The simulation loop advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.

### Note

*   Detailed vehicle setup (e.g., adding wheels, suspensions, and an engine) is not included in this example for brevity.
*   You may need to adjust parameters like `step_size` and `end_time` based on your specific simulation requirements.
*   Ensure that you have the necessary PyChrono and Irrlicht modules installed and properly configured in your Python environment.
