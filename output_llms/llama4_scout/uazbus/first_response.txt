### PyChrono Simulation Script

```python
import chrono as ch
import chrono.vehicle as veh
import chrono.irrlicht as irr

# 1. Initialize the PyChrono environment and core components
ch.ChEngine.Initialize()

# 2. Create the simulation system
system = ch.ChSystem_EulerImplicit()

# 3. Create a rigid terrain
terrain = veh.ChTerrain(system)
terrain.SetTerrainMass(1e12)  # Set a large mass to make it immovable
terrain.SetFrictionCoefficient(0.8)  # Friction coefficient
terrain.SetRestitutionCoefficient(0.3)  # Restitution coefficient
terrain.EnableCollisionResponse(True)

# 4. Create a UAZBUS vehicle
vehicle = veh.ChVehicle(veh.VehicleType.Rigid, system, veh.ChContactMaterial())
vehicle.Initialize(veh.ChCoordsys(ch.ChVectorD(0, 0, 1), ch.ChQuaternionD(1, 0, 0, 0)))

# 5. Initialize a driver system for vehicle control
driver = veh.ChDriver(vehicle)
driver.Initialize()

# 6. Create a real-time visualization using Irrlicht
vis = irr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetCameraVertical(0, -20, 5)
vis.SetLight(0, ch.ChVectorD(10, 10, 10), ch.ChVectorD(-1, -1, -1), ch.ChColor(1, 1, 1))

# 7. Simulation loop
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Advance the simulation
    system.DoStepDynamics(0.02)

    # Synchronize systems
    driver.Synchronize(0.02)
    terrain.Synchronize(0.02)
    vis.Synchronize(0.02)
```

### Explanation

*   The PyChrono environment and core components are initialized.
*   A `ChSystem_EulerImplicit` is created as the simulation system.
*   A rigid terrain with specified friction and restitution coefficients is created and added to the simulation system.
*   A UAZBUS vehicle is created and initialized with specified initial conditions.
*   A driver system is initialized for vehicle control.
*   A real-time visualization using Irrlicht is created with camera settings and lighting.
*   The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.

### Usage

*   Run the script using a Python environment with PyChrono installed.
*   The simulation will display a UAZBUS vehicle on a rigid terrain with real-time visualization.

### Notes

*   Ensure that the PyChrono library is properly installed and configured in your Python environment.
*   You can adjust the simulation parameters, such as timestep and friction coefficients, as needed for your specific use case.
