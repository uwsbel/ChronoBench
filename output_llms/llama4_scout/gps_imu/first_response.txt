### PyChrono Simulation Script

Below is a Python script that sets up a PyChrono simulation as per your instructions. This script initializes the PyChrono environment, sets up an HMMWV vehicle with a full system, including terrain, driver inputs, and a visual interface using Irrlicht. It also adds and manages IMU and GPS sensors attached to the vehicle's chassis.

```python
import pychrono as chrono
import pychrono.irrlicht as irr
import pychrono.vehicle as veh

# 1. Initialize the PyChrono environment and core components
chrono.ChEngine.Initialize()

# 2. Create the HMMWV vehicle
veh_system = veh.ChHMMWV()

# Set the vehicle chassis position
veh_system.SetChassisPos(chrono.ChVector3d(0, 0, 1))

# 3. Create the terrain
terrain = veh.ChTerrain()
terrain.SetGridSize(200, 200)
terrain.SetPlane(chrono.ChVector3d(0, 0, 0), chrono.ChVector3d(0, 0, 1))
terrain.SetKSoil(1e4)
terrain.SetDampingSoil(0)

# 4. Create the driver
driver = veh.ChDriver(veh_system.GetVehicle())
driver.SetSpeed(10)

# 5. Create the Irrlicht application
app = irr.ChIrrApp(veh_system.GetSystem(), "HMMWV Simulation", irr.DIM_800x600)

# Enable Irrlicht camera control
app.SetCameraMoveSpeed(5)

# 6. Add IMU and GPS sensors
imu = veh.ChIMU(veh_system.GetChassisBody())
gps = veh.ChGPS(veh_system.GetChassisBody())

# Function to update sensor data at each simulation step
def UpdateSensorData(vehicle, imu, gps, time):
    imu.Update(time)
    gps.Update(time)

# Simulation loop
while app.Run():
    # Synchronize and advance the vehicle, terrain, driver, and visual system modules
    driver.Advance(0.02)
    terrain.Advance(0.02)
    veh_system.Update(0.02)

    # Process and update sensor data
    time = veh_system.GetSystem().GetChTime()
    UpdateSensorData(veh_system.GetVehicle(), imu, gps, time)

    # Output vehicle mass
    print("Vehicle Mass: ", veh_system.GetVehicle().GetMass())

    # Render scenes
    app.BeginScene()
    app.SetCameraPosition(chrono.ChVector3d(0, -5, 2))
    app.EndScene()

chrono.ChEngine.Finalize()
```

### Explanation

This script initializes a PyChrono simulation with an HMMWV vehicle, terrain, driver inputs, and a visual interface using Irrlicht. It also sets up and manages IMU and GPS sensors attached to the vehicle's chassis, updating their data at each simulation step. The simulation loop synchronizes and advances all modules, outputs the vehicle mass, and renders the scene.

### Note

This script assumes that you have PyChrono and its dependencies installed and configured properly. Make sure to adjust paths and parameters as necessary for your specific environment and simulation requirements.
