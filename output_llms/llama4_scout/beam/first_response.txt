### PyChrono Simulation with Beam Finite Elements

Below is a Python script that demonstrates a PyChrono simulation using beam finite elements. This script initializes the PyChrono environment, creates a physical system with a mesh composed of beams and nodes, and visualizes the simulation using the Irrlicht engine.

```python
import chrono as ch
import chrono.irrlicht as irr

# 1. Initialize the PyChrono environment and core components
ch.ChEngine.Initialize()

# 2. Create the physical system
system = ch.ChSystem()

# 3. Create a mesh with beam finite elements
mesh = ch.ChBeamBodyEasy()

# Define the beam properties
beam_section = ch.ChBeamSectionEuler()
beam_section.SetYoungModulus(2e9)  # Young's modulus (Pa)
beam_section.SetArea(0.01)  # Cross-sectional area (m^2)
beam_section.SetInertiaY(0.0001)  # Moment of inertia about y-axis (m^4)
beam_section.SetInertiaZ(0.0001)  # Moment of inertia about z-axis (m^4)

# Create nodes
node_A = ch.ChNodeBase(beam_section)
node_A.SetPos([0, 0, 0])
node_B = ch.ChNodeBase(beam_section)
node_B.SetPos([1, 0, 0])

# Add nodes to the system
system.Add(node_A)
system.Add(node_B)

# Create beam element
beam = ch.ChBeamEuler(beam_section, node_A, node_B)
beam.SetLength(1.0)

# Add beam to the system
system.Add(beam)

# 4. Add visualization and run the simulation loop
irr.ChIrrApp(system, 'Beam Finite Element Simulation').Run()
```

### Explanation

*   We start by importing the necessary modules from the PyChrono library.
*   We initialize the PyChrono environment using `ch.ChEngine.Initialize()`.
*   A physical system `ch.ChSystem()` is created to manage the simulation.
*   We define a beam section with specific properties (Young's modulus, cross-sectional area, and moments of inertia) using `ch.ChBeamSectionEuler()`.
*   Two nodes, `node_A` and `node_B`, are created with positions and added to the system.
*   A beam element is created by connecting the two nodes using `ch.ChBeamEuler()`.
*   Finally, we create an Irrlicht application `ChIrrApp` to visualize the simulation and run it using the `Run()` method.

### Advice

*   Ensure that you have the PyChrono library installed and properly configured in your Python environment.
*   You can adjust the beam properties, node positions, and simulation parameters to explore different scenarios.
*   For more complex simulations, consider using other PyChrono features, such as contacts, constraints, and external forces.
