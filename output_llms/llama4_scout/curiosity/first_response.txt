### PyChrono Simulation: Curiosity Rover on Rigid Terrain

Below is a Python script that sets up a PyChrono simulation of a Curiosity rover navigating on a rigid terrain. This script initializes the PyChrono environment, adds the required physical systems and objects, and sets up the visualization using Irrlicht.

```python
import pychrono as chrono
import pychrono.irrlicht as irr

# Initialize PyChrono environment
chrono.ChEngine.Initialize()

# Create the Irrlicht application
app = irr.ChIrrApp()

# Create the simulation system
system = chrono.ChSystem()

# Create a fixed ground with collision properties
ground = chrono.ChBodyEasyBox(chrono.Vector(100, 10, 100),  # dimensions
                              chrono.Vector(0, -5, 0),  # position
                              True,  # create collision shape
                              True)  # create visualization shape
ground.SetBodyFixed(True)
ground.GetCollisionShape().SetFriction(0.8)
system.Add(ground)

# Load the Curiosity rover model
rover = chrono.ChBodyEasyMesh('path/to/curiosity_rover.obj',  # mesh file path
                              chrono.Vector(0, 0, 0),  # position
                              True,  # create collision shape
                              True)  # create visualization shape
rover.SetMass(1000)  # set rover mass
system.Add(rover)

# Add a motor control driver for real-time steering inputs
steering_driver = chrono.ChSteeringDriver(rover)
steering_driver.SetSteeringFunction(chrono.ChSteeringFunction_Sine(0.1,  # amplitude
                                                                0.5))  # frequency
system.Add(steering_driver)

# Set up visualization using Irrlicht
vis = irr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetCameraPosition(chrono.Vector(10, 10, 10))
vis.SetCameraTarget(chrono.Vector(0, 0, 0))
vis.EnableShadows()
vis.EnableSFX(irr.SOUND_FX_NONE)
vis.EnableLights()

# Add textures and logos (assuming they are in the same directory)
vis.AddLogo(irr.ChLogo('chronologo.png'))
vis.AddTexture(irr.ChTexture('terrain.jpg'))

# Run the simulation
app.SetSystem(system)
app.SetVisualSystem(vis)
app.DoRun()

# Clean up
chrono.ChEngine.Finalize()
```

### Instructions for Use:

1. **Mesh and Texture Files:** Make sure to replace `'path/to/curiosity_rover.obj'`, `'chronologo.png'`, and `'terrain.jpg'` with the actual paths to your Curiosity rover mesh file, logo image, and terrain texture image, respectively.

2. **Simulation Run:** The simulation will run until manually stopped. You can adjust the simulation duration and time step by adding `system.SetTimestep(0.01)` and `system.SetEndTime(10.0)`, for example.

3. **Customization:** You can customize camera settings, lighting, shadows, and visual elements through the Irrlicht visual system interface.

4. **Dependencies:** Ensure that you have PyChrono and Irrlicht installed and properly configured in your Python environment.

This script provides a basic framework. Depending on your specific requirements, you might need to adjust parameters, add more complexity to the rover's dynamics, or modify the visualization settings.
