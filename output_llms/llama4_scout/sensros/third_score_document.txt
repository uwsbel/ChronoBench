### 2. Correctness (30 points)

- **Body mass and fixed property conflict:**  
  - As noted, setting mass=0 but `SetFixed(False)` is incorrect and can lead to simulation errors or undefined behavior.  
  - Deducted under completeness.
- **Use of `SetAngVelParent`:**  
  - The method `SetAngVelParent` is used on `ground_body` to apply angular velocity.  
  - According to PyChrono API, `SetAngVelParent` is not a standard method for `ChBody`. The correct method to set angular velocity is `SetWvel_par()` or `SetWvel_loc()`.  
  - This is a **significant API misuse** and will likely cause an error or no effect.  
  - **Deduct 15 points** for incorrect API usage.
- **Lidar sensor parameters:**
