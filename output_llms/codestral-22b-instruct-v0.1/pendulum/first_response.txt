I have created a simulation script based on the provided instructions. The script initializes the PyChrono environment and sets up a simple pendulum system. Here's a breakdown of the script:

1. The necessary PyChrono modules are imported.
2. A function `create_scene` is defined to create the simulation scene.
3. Inside the `create_scene` function, a system object is created to manage the simulation.
4. A ground body is created and added to the system.
5. A pendulum body is created with a mass of 1 kg and a radius of 0.5 meters. The inertia tensor is calculated based on the mass and radius.
6. The pendulum body is translated and rotated to the desired position.
7. A revolute joint is created to connect the ground body and the pendulum body. The joint is set to be positioned at the pendulum's center and allows only rotational movement.
8. The pendulum body and the ground body are added to the system.
9. The visualization system is initialized with the created system.
10. A while loop is used to run the simulation. Inside the loop, the system is advanced by a time step, and the pendulum's position and velocity are logged.

Here's the Python code for the simulation script:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

def create_scene():
    # Create the system object
    system = chrono.ChSystemNSC()

    # Create the ground body
    ground = chrono.ChBodyEasyBox(10, 1, 1, 1000, True, True)
    system.Add(ground)

    # Create the pendulum body
    pendulum_mass = 1
    pendulum_radius = 0.5
    pendulum_inertia = 2/5 * pendulum_mass * pendulum_radius**2
    pendulum = chrono.ChBodyEasyCylinder(pendulum_radius, pendulum_radius, pendulum_mass, True, True)
    pendulum.SetInertiaXX(chrono.ChVectorD(pendulum_inertia, pendulum_inertia, pendulum_inertia))
    pendulum.SetPos(chrono.ChVectorD(0, -1, 0))
    pendulum.SetRot(chrono.ChQuaternionD(1, 0, 0, 0))

    # Create the revolute joint
    joint = chrono.ChLinkLockRevolute()
    joint.Initialize(ground, pendulum, chrono.ChCoordsysD(chrono.ChVectorD(0, -1, 0), chrono.ChQuaternionD(1, 0, 0, 0)))
    system.Add(joint)

    # Add the pendulum body to the system
    system.Add(pendulum)

    # Create the visualization system
    vis = chronoirr.ChIrrApp(system, 'Simple Pendulum', chronoirr.dimension2du(800, 600))
    vis.AddTypicalLogo()
    vis.AddTypicalCamera(chronoirr.vector3df(0, 0, -1))
    vis.AddTypicalLights()
    vis.AddSkyBox()
    vis.AddLightWithShadow(chronoirr.vector3df(3, 3, -3), chronoirr.vector3df(0, 0, 0), 9, 1, 7, 40, 512, chronoirr.SColorf(0.8, 0.8, 0.8))

    # Run the simulation
    while vis.GetDevice().run():
        vis.BeginScene()
        vis.DrawAll()
        vis.DoStep()

        # Log the pendulum's position and velocity
        pendulum_position = pendulum.GetPos()
        pendulum_velocity = pendulum.GetPos_dt()
        print(f"Position: {pendulum_position.x}, {pendulum_position.y}, {pendulum_position.z}")
        print(f"Velocity: {pendulum_velocity.x}, {pendulum_velocity.y}, {pendulum_velocity.z}")

        vis.EndScene()

# Run the simulation
create_scene()
```
