```python
import pychrono as chrono
import pychrono.irrlicht as irr

# Initialize the PyChrono environment
chrono.SetChronoDataPath("../data/")
my_system = chrono.ChSystemNSC()

# Add a Kraz vehicle
kraz = chrono.vehicle.Kraz()
kraz.Initialize(my_system)
kraz.SetChassisFixed(False)
kraz.SetInitPosition(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 1)))

# Add a rigid terrain
terrain = chrono.vehicle.RigidTerrain(kraz.GetSystem())
terrain.SetContactFriction(0.3)
terrain.SetContactRestitution(0.2)

# Initialize a driver system for vehicle control
driver = chrono.vehicle.ChDriver(kraz)
kraz.SetDriver(driver)

# Create a real-time visualization using Irrlicht
application = irr.ChIrrApp(kraz.GetSystem(), "Kraz Simulation", irr.dimension2du(1024, 768))
application.AddTypicalLogo()
application.AddTypicalSky()
application.AddTypicalLights()
application.AddTypicalCamera(chrono.ChVectorD(0, -10, 5))
application.AssetBindAll()
application.AssetUpdateAll()

# Simulation loop
while application.GetDevice().run():
    application.BeginScene()
    application.DrawAll()
    application.DoStep()
    application.EndScene()
    my_system.DoStepDynamics(0.01)
```

This script initializes a PyChrono simulation featuring a Kraz vehicle on a rigid terrain. The Kraz vehicle is set up with specified initial conditions, and the rigid terrain is configured with defined friction and restitution. A driver system is initialized for vehicle control, and a real-time visualization using Irrlicht is created with camera settings and lighting. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.
