To create a PyChrono simulation showcasing the dynamics of a BMW E90 Sedan driving on a rigid terrain, we need to initialize the PyChrono environment, add the required physical systems and objects, and set the necessary default parameters.

Here is the Python script that follows the instructions:

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as irr

# Initialize PyChrono environment and core components
chrono.SetChronoDataPath('path/to/chrono/data/folder')
my_system = chrono.ChSystemNSC()

# Create the vehicle
bmw_vehicle = veh.WheeledVehicle(my_system)
bmw_vehicle.Initialize("BMW_E90_Sedan")
bmw_vehicle.SetChassisVisualizationType(veh.VisualizationType_MESH)
bmw_vehicle.SetChassisCollisionType(chrono.ChCollisionModelType_TRIANGLE_MESH)
bmw_vehicle.SetTireType(veh.TireModelType_TMEASY)

# Create the driver system
driver = veh.ChDriver(bmw_vehicle)
driver.SetSteeringControllerType(veh.SteeringControllerType_PS)
driver.SetSpeedControllerType(veh.SpeedControllerType_PID)
driver.SetBrakingControllerType(veh.BrakingControllerType_PID)

# Create the terrain
terrain = veh.RigidTerrain(my_system)
terrain.Initialize(chrono.ChCoordsys<>(chrono.ChVector<>(0, 0, 0), chrono.Q_from_AngX(0)))

# Set default parameters
bmw_vehicle.SetPos(chrono.ChCoordsys<>(chrono.ChVector<>(0, 0, 1), chrono.Q_from_AngX(0)))
bmw_vehicle.SetInitPosition(chrono.ChCoordsys<>(chrono.ChVector<>(0, 0, 1), chrono.Q_from_AngX(0)))
driver.SetThrottle(0.5)

# Visualize the simulation using Irrlicht system
app = irr.ChIrrApp(bmw_vehicle, "BMW E90 Sedan Simulation", irr.dimension2du(1280, 720))
app.AddTypicalLogo()
app.AddTypicalSky()
app.AddTypicalLights()
app.AddTypicalCamera(irr.vector3df(0, 5, -10))
app.SetChaseCamera(vehicle=bmw_vehicle.GetChassisBody(),
                    distance=5.0,
                    height=2.0,
                    angle=30)
app.SetTimestep(0.01)

# Run the simulation
app.AssetBindAll()
app.AssetUpdateAll()
app.Run()
```

Please replace `'path/to/chrono/data/folder'` with the actual path to the Chrono data folder.

This script initializes the PyChrono environment, creates a BMW E90 Sedan vehicle with configurable visualization and collision settings, sets the tire model to TMEASY, adds an interactive driver system, creates a rigid terrain, sets default parameters, visualizes the simulation using the Irrlicht system with a chase camera, directional lighting, a skybox, and customizable textures and logos on the terrain surface, and runs the simulation.
