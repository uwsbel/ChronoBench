```python
import pychrono as chrono
import pychrono.irrlicht as irr

# Initialize the Chrono engine
chrono.SetChronoDataPath('PATH_TO_CHRONO_DATA')

# Create a Chrono system
my_system = chrono.ChSystemNSC()

# Create a ground body
ground = chrono.ChBodyEasyBox(20, 1, 20, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
ground.SetBodyFixed(True)
my_system.Add(ground)

# Create a beam composed of ANCF cable elements
beam = chrono.ChBody()
beam.SetPos(chrono.ChVectorD(0, 5, 0))

# Add beam elements
num_elements = 10
for i in range(num_elements):
    element = chrono.ChLinkANCF()
    element.Initialize(beam, ground if i == 0 else my_system.Get_body(i-1), chrono.ChVectorD(0, -1, 0), chrono.ChVectorD(0, -1, 0))
    my_system.Add(element)

my_system.Add(beam)

# Set gravity
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create an Irrlicht application to visualize the system
my_application = irr.ChIrrApp(my_system, 'Beam Deformation', irr.dimension2du(1024, 768))
my_application.AddTypicalLogo()
my_application.AddTypicalSky()
my_application.AddTypicalCamera(irr.vector3df(0, 3, -10))
my_application.AddTypicalLights()

# Run the simulation
while(my_application.GetDevice().run()):
    my_application.BeginScene()
    my_application.DrawAll()
    my_application.DoStep()
    my_application.EndScene()
```

This script initializes a Chrono system, creates a ground body, and then creates a beam composed of ANCF cable elements. Each element is connected to the ground at one end and to the previous element at the other end. The system is then subjected to gravity. The Irrlicht application is used to visualize the system, and the simulation is run in a loop.
