```python
import pychrono as chrono
import pychrono.irrlicht as irr

# Initialize the PyChrono environment
chrono.SetChronoDataPath('/path/to/chrono/data/')

# Create a system
my_system = chrono.ChSystemNSC()

# Create a rigid terrain
terrain = chrono.ChBodyEasyBox(100, 0.5, 100, 1000, True, True)
my_system.Add(terrain)

# Set terrain friction and restitution
terrain_material = chrono.ChMaterialSurfaceNSC()
terrain_material.SetFriction(0.8)
terrain_material.SetRestitution(0.01)
terrain.SetMaterialSurface(terrain_material)

# Create an M113 vehicle
m113 = chrono.ChBodyEasyBox(2, 1, 4, 1000)
m113.SetPos(chrono.ChVectorD(0, 1, 0))
my_system.Add(m113)

# Initialize a driver system for vehicle control
driver = chrono.ChDriver(m113)

# Create a real-time visualization using Irrlicht
app = irr.ChIrrApp(my_system, 'M113 Vehicle Simulation', irr.dimension2du(1024, 768))
app.AddTypicalLogo()
app.AddTypicalSky()
app.AddTypicalCamera(irr.vector3df(0, 3, -6))
app.AddTypicalLights()

# Set camera settings and lighting
app.SetTimestep(0.01)
app.SetTryRealtime(True)

# Simulation loop
while app.GetDevice().run():
    app.BeginScene()
    app.DrawAll()
    app.DoStep()
    app.EndScene()
```

In this script, we first initialize the PyChrono environment and create a system. Then, we add a rigid terrain to the system and set its friction and restitution. After that, we create an M113 vehicle and add it to the system. We also initialize a driver system for vehicle control.

Next, we create a real-time visualization using Irrlicht and set up the camera settings and lighting. Finally, we enter a simulation loop that synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.
