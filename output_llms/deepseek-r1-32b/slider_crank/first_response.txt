I'll help you create a PyChrono simulation script for a crank-slider mechanism. Here's a complete solution:

```python
importchrono
fromchrono import ChSystem, ChBody, ChBox, ChCylinder, ChVector, ChQuaternion
fromchrono import ChFixedConstraint, ChSphericalJoint, ChPrismaticJoint, ChMotorRotationAngular
fromchrono import ChColor, ChTexture, ChLight
fromchrono import ChIrrApp, ChIrrDriver, ChIrrCamera, ChIrrGUI

# Initialize simulation system
system = ChSystem()
system.Set_G_acc(ChVector(0, -9.81, 0))
system.SetTimestep(0.001)

# Visualization setup
application = ChIrrApp(system, "Crank-Slider Mechanism", ChVector(640, 480, 0))
application.AddLightWithDirection(ChVector(0, 1, 1), ChColor(1, 1, 1), 100)
application.AddTypicalLogo()
application.AddTypicalSky()
application.AddTypicalGrid()
application.SetCameraPosition(ChVector(1, 1, 1), ChVector(0, 0, 0), ChVector(0, 1, 0))

# Floor (truss)
floor = ChBody()
floor.SetBodyType(ChBodyType.STATIC)
floor.SetPos(ChVector(0, 0, 0))
floor.AddCollisionShape(ChBox(5, 1, 5))
floor.GetVisualShape(0).SetTexture(ChTexture("textures/metal.jpg"))
system.AddBody(floor)

# Crankshaft
crankshaft = ChBody()
crankshaft.SetBodyType(ChBodyType.DYNAMIC)
crankshaft.SetMass(1)
crankshaft.SetPos(ChVector(0, 0.5, 0))
crankshaft.AddCollisionShape(ChCylinder(0.2, 1))
crankshaft.GetVisualShape(0).SetColor(ChColor(0.1, 0.1, 0.7))
system.AddBody(crankshaft)

# Connecting rod
connecting_rod = ChBody()
connecting_rod.SetBodyType(ChBodyType.DYNAMIC)
connecting_rod.SetMass(0.5)
connecting_rod.SetPos(ChVector(1, 0.5, 0))
connecting_rod.AddCollisionShape(ChBox(0.2, 0.5, 0.2))
connecting_rod.GetVisualShape(0).SetColor(ChColor(0.7, 0.1, 0.1))
system.AddBody(connecting_rod)

# Piston
piston = ChBody()
piston.SetBodyType(ChBodyType.DYNAMIC)
piston.SetMass(2)
piston.SetPos(ChVector(2, 0.5, 0))
piston.AddCollisionShape(ChBox(0.5, 0.5, 0.5))
piston.GetVisualShape(0).SetColor(ChColor(0.1, 0.7, 0.1))
system.AddBody(piston)

# Joints
fixed_joint = ChFixedConstraint()
fixed_joint.Initialize(floor, crankshaft, ChVector(0, 0, 0), ChVector(0, 0, 0))
system.Add(fixed_joint)

spherical_joint = ChSphericalJoint()
spherical_joint.Initialize(crankshaft, connecting_rod, ChVector(0.5, 0, 0), ChVector(0, 0, 0))
system.Add(spherical_joint)

prismatic_joint = ChPrismaticJoint()
prismatic_joint.Initialize(floor, piston, ChVector(2, 0, 0), ChVector(1, 0, 0))
system.Add(prismatic_joint)

# Motor
motor = ChMotorRotationAngular()
motor.Initialize(crankshaft, floor, ChVector(0, 0, 0))
motor.SetVelocityTarget(2)  # Angular velocity in rad/s
system.Add(motor)

# Add constraints
connecting_rod_piston_joint = ChSphericalJoint()
connecting_rod_piston_joint.Initialize(connecting_rod, piston, ChVector(0.5, 0, 0), ChVector(0, 0, 0))
system.Add(connecting_rod_piston_joint)

# Run simulation
application.SetTimestep(0.001)
application.SetTryRealTime(True)

while application.GetDevice().run():
    application.BeginScene()
    application.DrawAll()
    application.DoStep()
    application.EndScene()
```

This script creates a crank-slider mechanism with the following features:

1. A static floor with a metallic texture
2. A rotating crankshaft driven by a motor
3. A connecting rod
4. A sliding piston
5. Appropriate joints (fixed, spherical, prismatic)
6. Irrlicht visualization with:
   - Camera positioned for optimal viewing
   - Lighting setup
   - Textures and colors for different components
   - Grid and sky background

The mechanism is driven by a motor that spins the crankshaft at a constant angular velocity of 2 rad/s. The connecting rod transfers the rotational motion to the piston, which moves linearly.

Key components:

- `ChFixedConstraint`: Connects the crankshaft to the floor
- `ChSphericalJoint`: Allows rotation between crankshaft and connecting rod
- `ChPrismaticJoint`: Constrains piston movement to linear motion
- `ChMotorRotationAngular`: Provides constant angular velocity to the crankshaft
