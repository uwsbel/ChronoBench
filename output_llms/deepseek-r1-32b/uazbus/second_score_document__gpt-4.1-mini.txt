  The code uses `vehicle.GetVehicle()` when attaching to visualization and getting mass. This is correct as `vehicle` is a wrapper, and `GetVehicle()` returns the underlying vehicle object.

  Using `exit()` without importing `sys` or calling `sys.exit()` is not best practice but works in scripts. Minor issue.
