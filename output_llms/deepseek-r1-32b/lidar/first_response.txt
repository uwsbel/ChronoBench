To create a PyChrono simulation that visualizes a triangular mesh from a Wavefront .obj file as a fixed body and includes a lidar sensor that orbits around the mesh, follow these steps:

1. **Initialize the PyChrono Environment:**
   - Import necessary modules.
   - Create a system and a renderer for visualization.

2. **Load and Position the Triangular Mesh:**
   - Use `ChTriangleMeshShape` to load the .obj file.
   - Create a fixed body and attach the mesh.

3. **Set Up the Lidar Sensor:**
   - Create a `ChSensorManager` and add a lidar sensor with specified parameters.
   - Enable noise for realism.

4. **Orbit the Lidar Sensor:**
   - Create a separate body for the lidar or update its position each simulation step using trigonometric functions.

5. **Simulate and Process Lidar Data:**
   - Run the simulation loop, updating the sensor manager each step.
   - Process and visualize lidar data, saving it as needed.

Here's the code implementing these steps:

```python
importchrono
import math
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# Initialize the Chrono system and renderer
sys = chrono.ChSystem()
renderer = chrono.ChRendererOpenGL()
renderer.SetWindowTitle('Lidar Simulation')
renderer.AttachSystem(sys)
renderer.SetCamera(chrono.ChVectorD(2, 2, 2), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
renderer.AddLight(chrono.ChVectorD(0, 1, 3), chrono.ChColor(1, 1, 1))

# Create a fixed body with the triangular mesh
mesh = chrono.ChTriangleMeshShape()
mesh.SetFilename("your_mesh.obj")
mesh.SetScale(1)
body = chrono.ChBody()
body.SetMass(0)  # Fixed body
body.AddVisualShape(mesh)
body.SetPos(chrono.ChVectorD(0, 0, 0))
sys.AddBody(body)

# Set up the lidar sensor
sensor_manager = chrono.ChSensorManager(sys)
lidar = sensor_manager.AddLidar(
    name="lidar",
    pos=chrono.ChVectorD(0, 0, 0),
    angle_h_min=-45,
    angle_h_max=45,
    angle_v_min=-22.5,
    angle_v_max=22.5,
    h_res=180,
    v_res=45,
    range_max=10,
    noise_mean=0,
    noise_std_dev=0.1,
    enable_noise=True
)

# Enable lidar data visualization and saving
lidar.EnableVisualization(True)
lidar.EnableSave(True)

# Simulation parameters
simulation_time = 10.0
step_size = 0.01
num_steps = int(simulation_time / step_size)

# Initialize visualization figure
fig = plt.figure()
ax = fig.add_subplot(111, projection='3d')
plt.ion()
plt.show()

# Simulation loop
for step in range(num_steps):
    # Update lidar position in orbit
    angle = step * 2 * math.pi / num_steps
    lidar_pos = chrono.ChVectorD(
        2 * math.cos(angle),
        2 * math.sin(angle),
        1
    )
    lidar.SetPos(lidar_pos)
    
    # Update sensor manager
    sensor_manager.Update()
    
    # Check for new lidar data
    if lidar.GetLatestData():
        data = lidar.GetLatestData()
        points = []
        for hit in data.m_hits:
            points.append([hit.m_x, hit.m_y, hit.m_z])
        
        # Add noise to points
        noise = np.random.normal(0, 0.1, len(points))
        points = np.array(points) + noise.reshape(-1, 1)
        
        # Print buffer data
        print("Lidar buffer data at step", step)
        print(points)
        
        # Visualize points
        ax.clear()
        ax.scatter(points[:,0], points[:,1], points[:,2], c='r', marker='o')
        ax.set_xlabel('X')
        ax.set_ylabel('Y')
        ax.set_zlabel('Z')
        plt.draw()
        plt.pause(0.001)
        
        # Save points to file
        np.savetxt('lidar_data_step_' + str(step) + '.txt', points)
    
    # Advance simulation
    sys.DoStepDynamics(step_size)

# Close visualization
plt.ioff()
plt.close()
```

**Explanation:**

- **Initialization:** The environment is set up with a system and renderer. The mesh is loaded and positioned at the origin as a fixed body.
- **Lidar Setup:** A lidar sensor is added with specified parameters, including noise to simulate real-world conditions.
- **Orbiting Lidar:** The lidar's position is updated in each step to move in a circular orbit around the mesh.
- **Simulation Loop:** The simulation runs for a set time, updating the lidar position and processing data each step. Lidar data is visualized in real-time and saved to files.
- **Data Handling:** Lidar hits are processed, noise is added, and the data is printed and visualized. Points are saved to text files for later analysis.

This script provides a comprehensive simulation setup for visualizing and analyzing lidar data in a dynamic environment.
