  The code uses `msection.SetSectionRotation(45 * chrono.CH_RAD_TO_DEG)`.  
  `CH_RAD_TO_DEG` converts radians to degrees, but the argument is 45 (likely degrees), so multiplying by `CH_RAD_TO_DEG` (≈57.2958) results in a very large number (~2578 degrees), which is incorrect. The correct usage would be either:  
  - `msection.SetSectionRotation(45 * chrono.CH_DEG_TO_RAD)` (to convert degrees to radians), or
