### Step-by-Step Explanation:

   - `chrono` for the core simulation functionality.
   - `chronoirr` for Irrlicht visualization.

2. **Initialize the Simulation System**:
   - Create a `ChSystemNSC` object to represent the physical system.
   - Set up the Irrlicht application with a window title and enable camera and lighting.

3. **Create the Ground Body**:
   - Add a static body to represent the ground.
   - Position it at the origin and add a visualization asset.

4. **Create the Pendulum Body**:
   - Define a spherical body with mass and inertia.
   - Position it above the ground and add a visualization asset.

5. **Connect with a Revolute Joint**:
   - Use `ChLinkRevolute` to create a hinge joint between the ground and pendulum.
   - Set the joint axis and enable angular motor.

6. **Add Collision Shapes**:
   - Define collision models for both bodies using spheres.

7. **Set Up Logging**:
   - Create a log file to record position and velocity over time.

8. **Run the Simulation**:
   - Set simulation parameters and start the visualization loop.
   - Update the log at each timestep and run the simulation.

### Complete Code:

```python
importchrono
import chronoirr

# Initialize the Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Gravity

# Set up Irrlicht visualization
application = chronoirr.ChIrrApp(system, "Simple Pendulum", chronoirr.dimension2du(800, 600))
application.AddTypicalSky()
application.AddTypicalLights()
application.SetCameraPosition(chrono.ChVectorD(0, 1.5, 2))
application.SetCameraRotation(chrono.ChQuaternionD(1, 0, 0, 0))

# Create ground body
ground = chrono.ChBody()
ground.SetMass(0)  # Static body
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.GetVisualShape().SetMaterialColor(chrono.ChColor(0.2, 0.2, 0.2))
ground.GetVisualShape().SetDimensions(chrono.ChVectorD(2, 2, 2))
system.AddBody(ground)

# Create pendulum body
pendulum = chrono.ChBody()
pendulum.SetMass(1)  # Mass in kg
pendulum.SetInertiaXX(chrono.ChMatrix33D(0.1666667, 0, 0, 0, 0.1666667, 0, 0, 0, 0.1666667))  # Inertia for a sphere
pendulum.SetPos(chrono.ChVectorD(0, 0, 1))  # Position above ground
pendulum.GetVisualShape().SetMaterialColor(chrono.ChColor(0.8, 0, 0))
pendulum.GetVisualShape().SetDimensions(chrono.ChVectorD(0.1, 0.1, 0.1))
system.AddBody(pendulum)

# Create revolute joint between ground and pendulum
joint = chrono.ChLinkRevolute()
joint.Initialize(ground, pendulum, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.ChQuaternionD(1, 0, 0, 0)))
joint.SetAxisX(chrono.ChVectorD(1, 0, 0))  # Joint axis along X
joint.SetEnableAngularMotor(True, 0, 10000)  # Enable motor with max torque
system.AddLink(joint)

# Add collision shapes
ground.GetCollisionModel().AddSphere(chrono.ChCollisionShape(), 1, chrono.ChVectorD(0, 0, 0))
pendulum.GetCollisionModel().AddSphere(chrono.ChCollisionShape(), 0.1, chrono.ChVectorD(0, 0, 0))

# Set up logging
log = chrono.ChLog()
log_file = chrono.ChLogFile()
log_file.SetFileName("pendulum_log.txt")
log_file.Open()
log.AddItem(chrono.ChLogVariables("Time", "Position X", "Position Y", "Position Z", "Velocity X", "Velocity Y", "Velocity Z"))
log.AddStream(log_file)

# Run the simulation
application.SetTimestep(0.001)
application.SetRealTimeFactor(1)
application.SetVsync(True)

while application.GetDevice().Run():
    application.BeginScene()
    application.DrawAll()
    
    # Log pendulum position and velocity
    pos = pendulum.GetPos()
    vel = pendulum.GetPos_dt()
    log.WriteRow([application.GetSystem().GetChTime(), pos.x, pos.y, pos.z, vel.x, vel.y, vel.z])
    
    application.DoStep()
    application.EndScene()

# Close the log file
log_file.Close()
```

### Explanation of Key Components:

- **Chrono System Initialization**: The simulation environment is set up with gravity and a time step.
- **Ground Body**: A static body representing the ground where the pendulum is attached.
- **Pendulum Body**: A spherical body with mass and inertia, positioned above the ground.
- **Revolute Joint**: Connects the pendulum to the ground, allowing rotation around the X-axis.
- **Visualization**: Irrlicht is used to render the simulation in real-time.
- **Logging**: Position and velocity data is recorded to a file for analysis.

This script creates a simple pendulum simulation that can be visualized in real-time and logged for further analysis.
