Here's a PyChrono script that demonstrates a mass-spring-damper system with visualization:

```python
importchrono
import math

# Initialize the Chrono system
chrono.SetChronoAPIKey("your_api_key_here")

# Create the Chrono system
system = chrono.ChSystemNSC()

# Create an Irrlicht application for visualization
application = chrono.ChIrrApp(system, "Mass-Spring-Damper System", chrono.CHDimension(800, 600))
application.SetLightEnabled(True)
application.SetShadowEnabled(True)
application.SetCameraPosition(chrono.ChVectorD(0, 5, 5))
application.SetCameraRotation(chrono.ChVectorD(0, -45, 0))

# Create a mass body
mass = chrono.ChBody()
mass.SetMass(1.0)  # Mass in kg
mass.SetPos(chrono.ChVectorD(0, 0, 0))
mass.SetBodyFixed(False)

# Create a visual shape for the mass
mass_shape = chrono.ChSphere()
mass_shape.SetRadius(0.2)
mass_shape.SetPos(chrono.ChVectorD(0, 0, 0))
mass_shape.SetMaterialSurface(chrono.ChVisualMaterial())
mass_shape.GetMaterialSurface().SetTexture(chrono.GetChronoDataPath() + "textures/blue.png")
mass.AddVisualShape(mass_shape)

# Create ground body
ground = chrono.ChBody()
ground.SetBodyFixed(True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))

# Create a visual shape for the ground
ground_shape = chrono.ChBox()
ground_shape.SetDimensions(chrono.ChVectorD(2, 0.2, 2))
ground_shape.SetPos(chrono.ChVectorD(0, -1, 0))
ground_shape.SetMaterialSurface(chrono.ChVisualMaterial())
ground_shape.GetMaterialSurface().SetTexture(chrono.ChGetChronoDataPath() + "textures/concrete.png")
ground.AddVisualShape(ground_shape)

# Create spring-damper link using ChLinkTSDA
spring = chrono.ChLinkTSDA()
spring.Initialize(mass, ground, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.ChMatrix33D()))
spring.SetRestLength(1.0)  # Rest length in meters
spring.SetSpringCoefficient(100.0)  # Spring constant in N/m
spring.SetDampingCoefficient(10.0)  # Damping coefficient in Ns/m

# Add all components to the system
system.Add(mass)
system.Add(ground)
system.Add(spring)

# Add grid to the scene
application.AddGrid()

# Run the simulation
application.AssetBindAll()
application.AssetUpdateAll()

while application.GetDevice().Run():
    application.BeginScene()
    application.DrawAll()
    application.DoStep()
    application.EndScene()

print("Simulation completed successfully")
```

This script creates a simple mass-spring-damper system with the following features:

1. A ChSystemNSC object for the core simulation
2. An Irrlicht visualization window with:
   - Size: 800x600 pixels
   - Lighting and shadows enabled
   - Camera positioned at (0,5,5) with rotation (0,-45,0)
   - Grid background
3. A mass body:
   - Mass: 1 kg
   - Visualized as a sphere with radius 0.2 m
   - Blue texture
4. A ground body:
   - Visualized as a box (2x0.2x2 m)
   - Concrete texture
5. A spring-damper link (ChLinkTSDA) with:
   - Rest length: 1 m
   - Spring constant: 100 N/m
   - Damping coefficient: 10 Ns/m

The simulation runs until the user closes the window. The mass will oscillate due to the spring force and damping effect.

To run this script, you'll need to:
1. Replace "your_api_key_here" with a valid Chrono API key
2. Make sure you have the required textures in your texture path
3. Run it in an environment with Irrlicht visualization support

The system will demonstrate the basic behavior of a mass-spring-damper system with visualization of the motion and forces.
