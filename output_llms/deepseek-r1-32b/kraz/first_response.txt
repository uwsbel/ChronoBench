To create a PyChrono simulation featuring a Kraz vehicle, follow the step-by-step explanation below. This guide will walk you through setting up the simulation environment, adding the vehicle and terrain, configuring the driver system, and implementing the visualization and simulation loop.

### Step-by-Step Explanation

1. **Import Necessary Modules**
   - Import the required PyChrono modules for system setup, vehicle creation, and visualization.

2. **Initialize the Chrono System**
   - Create a `ChSystem` object to serve as the core of the simulation.
   - Configure the solver for physics calculations.

3. **Create the Kraz Vehicle**
   - Instantiate the `ChKraz` vehicle object.
   - Set the initial position of the vehicle.

4. **Add the Vehicle to the System**
   - Integrate the vehicle into the simulation environment.

5. **Set Up the Terrain**
   - Create a ground body to serve as the terrain.
   - Define its collision shape, mass, and physical properties (friction, restitution).
   - Add the ground to the simulation system.

6. **Initialize the Driver System**
   - Create a `ChDriver` object for vehicle control.
   - Set the driver's control mode and initial inputs.
   - Attach the driver to the vehicle.

7. **Configure Visualization**
   - Set up an Irrlicht visualization window.
   - Configure camera position and lighting for better visualization.

8. **Add Visualization Assets**
   - Add the vehicle and ground to the visualization system.
   - Configure lighting to enhance the visual appearance.

9. **Set Up Real-Time Simulation**
   - Define the time step and number of steps per second for real-time execution.
   - Implement the simulation loop to update the system, synchronize components, and render the scene.

10. **Run the Simulation**
    - Execute the simulation loop, handling user input for control and termination.

### Solution Code

```python
importchrono
importchrono.vehicle as veh
importchrono.visual as vis

# Initialize the Chrono system
system = chrono.ChSystem()
system.SetSolverType(chrono.ChSolverType.DIRECT_SOR)

# Create the Kraz vehicle
vehicle = veh.ChKraz()
vehicle.SetPos(chrono.ChVectorD(0, 0, 1))

# Add vehicle to the system
system.AddBody(vehicle)

# Create ground
ground = chrono.ChBody()
ground.SetMass(0)  # Make it static
ground.SetCollide(True)
ground.GetCollisionModel().AddBox(chrono.ChCollisionBox(100, 100, 1))
ground.SetMaterialSurface(chrono.ChMaterialSurface(0.5, 0.3))  # Friction, restitution
system.AddBody(ground)

# Initialize driver
driver = veh.ChDriver()
driver.SetControlMode(veh.ChDriver.ControlType.KEYBOARD)
driver.SetInputs(0, 0, 0)  # Throttle, steering, braking
vehicle.SetDriver(driver)

# Set up visualization
visualSystem = vis.ChVisualSystemIrrlicht()
visualSystem.AttachSystem(system)
visualSystem.SetWindowSize(1024, 768)
visualSystem.SetWindowTitle("Kraz Vehicle Simulation")
visualSystem.EnableLighting(True)
visualSystem.EnableShadows(True)

# Set camera position and orientation
camera = visualSystem.GetCamera()
camera.SetPos(chrono.ChVectorD(0, -10, 3))
camera.SetRot(chrono.ChQuaternionD(0.7071, 0, 0, 0.7071))  # Looking at the vehicle
camera.SetFieldOfView(60)

# Add vehicle and ground to visualization
vehicle.GetCollisionModel().SetVisualShape(chrono.ChVisualShape(chrono.ChColor(0.5, 0, 0)))
ground.GetCollisionModel().SetVisualShape(chrono.ChVisualShape(chrono.ChColor(0.2, 0.3, 0.1)))
visualSystem.AddLight(chrono.ChVectorD(0, 0, 5), chrono.ChColor(1, 1, 1))

# Set up simulation parameters
time_step = 0.001
num_steps = 1000  # Steps per second for real-time

# Run the simulation
while visualSystem.Run():
    # Update driver inputs (example: keyboard control)
    driver.Update(time_step)
    
    # Synchronize vehicle and driver
    vehicle.Synchronize(time_step)
    
    # Advance the system
    system.DoStepDynamics(time_step)
    
    # Render the scene
    visualSystem.Render()
    
    # Check for exit condition (e.g., escape key)
    if visualSystem.GetKeyboard().KeyDown(chrono.KEY_ESCAPE):
        break

# End the application
visualSystem.End()
```

### Explanation

- **Initialization**: The simulation starts by initializing the Chrono system and setting up the solver for physics calculations.
- **Vehicle Setup**: A Kraz vehicle is created and positioned above the ground to prevent initial collision.
- **Terrain Setup**: A static ground body is created with specified friction and restitution properties to simulate a realistic terrain.
- **Driver System**: A driver is initialized with keyboard controls, allowing real-time interaction with the vehicle.
- **Visualization**: The Irrlicht visualization system is set up with a camera positioned to view the vehicle and appropriate lighting for better visual appeal.
- **Simulation Loop**: The loop updates the driver inputs, synchronizes the vehicle, advances the simulation, and renders the scene at each time step, ensuring real-time execution.

This setup provides a comprehensive simulation environment where the Kraz vehicle can be controlled in real-time while visualizing its interaction with the terrain.
