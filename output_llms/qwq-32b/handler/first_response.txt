To create a PyChrono simulation integrated with ROS, follow the steps below. The code sets up a Chrono system with a floor and a box, integrates ROS communication, and maintains real-time execution.

```python
import pychrono as chrono
import rospy
from std_msgs.msg import Int32

def main():
    # Initialize Chrono system with gravity
    my_system = chrono.ChSystemNS()
    my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

    # Create a fixed floor
    floor = chrono.ChBodyEasyBox(10, 0.1, 10, 1000, True, True)
    floor.SetPos(chrono.ChVectorD(0, -0.1, 0))
    floor.SetBodyFixed(True)
    my_system.Add(floor)

    # Create a movable box
    box = chrono.ChBodyEasyBox(1, 1, 1, 1000, True, True)
    box.SetPos(chrono.ChVectorD(0, 2, 0))
    my_system.Add(box)

    # Initialize ROS node
    rospy.init_node('chrono_ros_node', anonymous=True)

    # Create ROS manager
    ros_manager = chrono.ChManager()

    # Add standard ROS handlers
    ros_clock = chrono.ChRtClock()
    ros_manager.Add(ros_clock)

    body_handler = chrono.ChRtBodyLoader()
    ros_manager.Add(body_handler)

    transform_handler = chrono.ChRtTransformPublisher()
    ros_manager.Add(transform_handler)

    # Custom ROS handler to publish integer messages
    class CustomROSPublisher(chrono.ChRtFunction):
        def __init__(self):
            super().__init__()
            self.publisher = rospy.Publisher('custom_topic', Int32, queue_size=10)
        
        def Update(self):
            msg = Int32()
            msg.data = int(box.GetPos().y)  # Example: Publish box's y-position as integer
            self.publisher.publish(msg)

    custom_publisher = CustomROSPublisher()
    ros_manager.Add(custom_publisher)

    # Setup real-time step manager
    realtime_stepper = chrono.ChRealtimeStepManager()
    realtime_stepper.SetTimestep(0.001)  # Time step of 1 ms
    realtime_stepper.Initialize(my_system)

    # Simulation loop
    while not rospy.is_shutdown():
        my_system.DoStepDynamics()
        ros_manager.DoStep()
        realtime_stepper.Synchronize()

if __name__ == "__main__":
    main()
```

1. **Chrono Environment Setup**:
   - A `ChSystemNS` system is initialized with gravitational acceleration.
   - A fixed floor and a dynamic box are added to the system with appropriate material properties.

2. **ROS Integration**:
   - A ROS node is initialized, and a `ChManager` is created to handle ROS communication.
   - Standard ROS handlers (clock, body, transform) are added to the manager.
   - A custom `CustomROSPublisher` class inherits from `ChRtFunction` to publish the box's y-position as an integer message to the topic `custom_topic`.

3. **Real-Time Simulation Loop**:
   - The simulation loop advances the Chrono system, updates ROS handlers, and synchronizes with real-time using `ChRealtimeStepManager`.
