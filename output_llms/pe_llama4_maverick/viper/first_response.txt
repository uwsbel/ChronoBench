### PyChrono Simulation: Viper Rover on Rigid Terrain

Below is a Python script that creates a PyChrono simulation featuring a Viper rover on a rigid terrain. The simulation includes a Chrono system setup with gravity, a ground body, Viper rover initialization, and a real-time Irrlicht visualization.

```python
import pychrono as chrono
import pychrono.vehicle as veh
import pychrono.irrlicht as chronoirr
import math

# =============================================================================
# Set up the Chrono system
# =============================================================================

# Create a Chrono system with gravity
sys = chrono.ChSystemNSC()
sys.Set_G_acc(chrono.ChVector3d(0, 0, -9.81))  # Set gravity

# Create the ground body
ground_mat = chrono.ChContactMaterialNSC()
ground = chrono.ChBodyEasyBox(100, 100, 1, 1000, True, True, ground_mat)
ground.SetPos(chrono.ChVector3d(0, 0, -0.5))
ground.SetBodyFixed(True)
ground.GetVisualShape(0).SetColor(chrono.ChColor(0.5, 0.5, 0.5))  # Gray color
sys.Add(ground)

# =============================================================================
# Initialize the Viper rover
# =============================================================================

# Set the path to the Chrono data directory
chrono.SetChronoDataPath('/path/to/chrono/data')

# Create the Viper rover
rover = veh.Viper(sys)
rover.SetInitPosition(chrono.ChCoordsysd(chrono.ChVector3d(0, 0, 0.5), chrono.QuatFromAngleX(chrono.CH_PI / 2)))
rover.Initialize()

# Create the Viper driver
driver = veh.ViperDriver()

# =============================================================================
# Create the Irrlicht visualization
# =============================================================================

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('Viper Rover Simulation')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(5, 5, 5))
vis.AddTypicalLights()

# =============================================================================
# Simulation loop
# =============================================================================

# Simulation parameters
time_step = 1e-3
end_time = 10
steering_time = 5

# Simulation loop
while vis.Run() and sys.GetChTime() < end_time:
    time = sys.GetChTime()
    steering = 0.5 * math.sin(chrono.CH_PI * time / steering_time)
    driver.SetSteering(steering)
    driver.SetThrottle(0.3)  # Constant throttle
    
    # Update the rover
    rover.Update(driver, time_step)
    
    # Advance the simulation
    sys.DoStepDynamics(time_step)
    
    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

# Clean up
vis.GetDevice().closeDevice()
```

### Key Components of the Script:

1. **Chrono System Initialization**: The script begins by setting up a Chrono system (`ChSystemNSC`) with gravity and creating a ground body (`ChBodyEasyBox`) to serve as the terrain.

2. **Viper Rover Initialization**: It initializes a Viper rover (`veh.Viper`) on the terrain with a specified initial position and orientation.

3. **Irrlicht Visualization**: The script sets up an Irrlicht visualization (`ChVisualSystemIrrlicht`) to render the simulation in real-time, including camera positioning and lighting.

4. **Simulation Loop**: The main simulation loop controls the rover's steering over time using a sinusoidal function and updates the rover's state at each timestep. The simulation advances using `DoStepDynamics`, and the scene is rendered using Irrlicht's rendering functions.

### Usage:

1. Ensure you have PyChrono and its dependencies installed.
2. Replace `'/path/to/chrono/data'` with the actual path to your Chrono data directory.
3. Run the script to execute the simulation.

This script provides a basic framework for simulating a Viper rover on a rigid terrain with PyChrono, including real-time visualization and dynamic control inputs.
