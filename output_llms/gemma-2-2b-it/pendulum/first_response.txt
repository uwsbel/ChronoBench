```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import numpy as np

# Initialize PyChrono
chrono.init()

# Create the Irrlicht engine
engine = irrlicht.IrrlichtEngine()

# Create the simulation world
world = chrono.World()

# Create the ground body
ground = chrono.Body("Ground", chrono.BodyType.STATIC, chrono.Vector3(0, 0, 0))
world.addBody(ground)

# Create the pendulum
pendulum = chrono.Body("Pendulum", chrono.BodyType.DYNAMIC, chrono.Vector3(0, 1, 0))
pendulum.setMass(1.0)
pendulum.setInertia(chrono.Vector3(0.1, 0.1, 0.1))
world.addBody(pendulum)

# Create the revolute joint
joint = chrono.RevoluteJoint(pendulum, ground)
world.addJoint(joint)

# Set the pendulum's initial position and velocity
pendulum.setPosition(chrono.Vector3(0, 1, 0))
pendulum.setVelocity(chrono.Vector3(0, 0, 0))

# Set the visualization system
vis = irrlicht.IrrlichtScene()
vis.addBody(ground)
vis.addBody(pendulum)
vis.addJoint(joint)

# Set the simulation parameters
dt = 0.01  # Time step
duration = 10  # Simulation duration

# Start the simulation loop
while True:
    # Update the simulation
    world.update(dt)

    # Get the pendulum's position and velocity
    position = pendulum.getPosition()
    velocity = pendulum.getVelocity()

    # Log the pendulum's position and velocity
    print(f"Position: {position}")
    print(f"Velocity: {velocity}")

    # Render the simulation
    vis.render()

    # Sleep for the simulation time step
    chrono.sleep(dt)

# Clean up
vis.shutdown()
world.shutdown()
chrono.shutdown()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries: `pychrono`, `pychrono.irrlicht`, and `numpy`.
   - Initializes PyChrono.
   - Creates an Irrlicht engine for visualization.

2. **World and Bodies:**
   - Creates a `World` object to hold all the bodies and joints.
   - Creates a `Ground` body representing the base.
   - Creates a `Pendulum` body with mass and inertia.

3. **Joint:**
   - Creates a `RevoluteJoint` connecting the pendulum to the ground.

4. **Parameters:**
   - Sets the time step (`dt`) and simulation duration (`duration`).

5. **Simulation Loop:**
   - Runs a loop that updates the simulation with each time step.
   - Gets the pendulum's current position and velocity.
   - Prints the position and velocity to the console.
   - Renders the scene using Irrlicht.
   - Sleeps for the time step to control the simulation speed.

6. **Cleanup:**
   - Shuts down the Irrlicht engine and PyChrono.

**Key Points:**

- **Visualization:** The Irrlicht library provides 3D visualization capabilities for the simulation.
- **Time Step:** The `dt` parameter controls the time step for the simulation. A smaller `dt` leads to a more accurate simulation but requires more computational power.
- **Body Properties:** The `Body` objects are created with specific mass, inertia, and position.
- **Joint Properties:** The `RevoluteJoint` defines the connection between the pendulum and the ground, allowing rotation.
