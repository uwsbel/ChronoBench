```python
from pychrono import Chrono
from pychrono.core import Body, RevoluteJoint, Position, Velocity, TimeStep, World
from pychrono.irrlicht import IrrlichtContext, IrrlichtDevice, IrrlichtRenderer
from pychrono.irrlicht.utils import IrrlichtScene

# Initialize PyChrono
chrono = Chrono()

# Create the world
world = World(chrono)

# Create the ground body
ground = Body(chrono, "ground", 
             Position(0, 0, 0), 
             Mass(1.0), 
             Inertia(0.01))

# Create the pendulum body
pendulum = Body(chrono, "pendulum", 
                Position(0, 0.5, 0), 
                Mass(0.1), 
                Inertia(0.001))

# Create the revolute joint
joint = RevoluteJoint(chrono, "joint", pendulum, ground, 
                     Axis(0, 1, 0))

# Set initial parameters
pendulum.SetVelocity(Velocity(0, 0, 0))
pendulum.SetPosition(Position(0, 0.5, 0))

# Set simulation parameters
time_step = 0.01
duration = 10.0

# Run the simulation
world.Run(time_step, duration)

# Create Irrlicht visualization
irrlicht_context = IrrlichtContext()
irrlicht_device = IrrlichtDevice(irrlicht_context)
irrlicht_renderer = IrrlichtRenderer(irrlicht_device)
scene = IrrlichtScene(irrlicht_renderer)

# Render the simulation
while world.Running():
    # Get the current state of the pendulum
    position = pendulum.GetPosition()
    velocity = pendulum.GetVelocity()

    # Render the pendulum
    scene.AddBody(pendulum)

    # Log the pendulum's position and velocity
    print(f"Position: {position.x}, {position.y}, {position.z}")
    print(f"Velocity: {velocity.x}, {velocity.y}, {velocity.z}")

    # Update the scene
    irrlicht_renderer.Render()

```


**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht libraries.
   - Initializes the PyChrono environment.
   - Creates a `World` object to manage the simulation.

2. **Bodies and Joints:**
   - Creates a `ground` body with mass and position.
   - Creates a `pendulum` body with mass, inertia, and initial position.
   - Creates a `RevoluteJoint` to connect the pendulum to the ground.
   
3. **Parameters:**
   - Sets initial velocity and position for the pendulum.
   - Sets the simulation time step and duration.

4. **Simulation:**
   - Starts the simulation using `world.Run()`.

5. **Irrlicht Visualization:**
   - Creates an Irrlicht context, device, and renderer.
   - Creates an `IrrlichtScene` to manage the visualization.
   - Enters a loop to continuously render the simulation.

6. **Rendering and Logging:**
   - Retrieves the current pendulum position and velocity.
   - Renders the pendulum in the Irrlicht scene.
   - Prints the pendulum's position and velocity to the console.
