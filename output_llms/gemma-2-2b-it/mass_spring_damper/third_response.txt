```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

rest_length = 1.5
spring_coef = 50
damping_coef = 1

# Create the system
sys = chrono.ChSystemNSC()
sys.SetGravitationalAcceleration(chrono.ChVector3d(0, 0, 0))

# Ground body
ground = chrono.ChBody()
sys.AddBody(ground)
ground.SetFixed(True)
ground.EnableCollision(False)

# Sphere body
sph_1 = chrono.ChVisualShapeSphere(0.1)
ground.AddVisualShape(sph_1, chrono.ChFramed(chrono.ChVector3d(-1, 0, 0)))

# Body 1
body_1 = chrono.ChBody()
sys.AddBody(body_1)
body_1.SetPos(chrono.ChVector3d(-1, -3, 0))
body_1.SetFixed(False)
body_1.EnableCollision(False)
body_1.SetMass(1)
body_1.SetInertiaXX(chrono.ChVector3d(1, 1, 1))

# Visual shape for body 1
box_1 = chrono.ChVisualShapeBox(1, 1, 1)
box_1.SetColor(chrono.ChColor(0.6, 0, 0))
body_1.AddVisualShape(box_1)

# Body 2
body_2 = chrono.ChBody()
sys.AddBody(body_2)
body_2.SetPos(chrono.ChVector3d(0, -3, 0))
body_2.SetFixed(False)
body_2.SetMass(1)
body_2.SetInertiaXX(chrono.ChVector3d(1, 1, 1))

# Visual shape for body 2
box_2 = chrono.ChVisualShapeBox(1, 1, 1)
box_2.SetColor(chrono.ChColor(0, 0.6, 0))
body_2.AddVisualShape(box_2)

# Body 3
body_3 = chrono.ChBody()
sys.AddBody(body_3)
body_3.SetPos(chrono.ChVector3d(2, -3, 0))
body_3.SetFixed(False)
body_3.SetMass(1)
body_3.SetInertiaXX(chrono.ChVector3d(1, 1, 1))

# Visual shape for body 3
box_3 = chrono.ChVisualShapeBox(1, 1, 1)
box_3.SetColor(chrono.ChColor(0, 0, 0.6))
body_3.AddVisualShape(box_3)

# Spring between body_1 and body_2
spring_1 = chrono.ChLinkTSDA()
spring_1.Initialize(body_1, body_2, True, chrono.ChVector3d(0, 0, 0), chrono.ChVector3d(0, 0, -1))
spring_1.SetRestLength(rest_length)
spring_1.SetSpringCoefficient(spring_coef)
spring_1.SetDampingCoefficient(damping_coef)
sys.AddLink(spring_1)

# Spring between body_2 and body_3
spring_2 = chrono.ChLinkTSDA()
spring_2.Initialize(body_2, body_3, True, chrono.ChVector3d(0, 0, 0), chrono.ChVector3d(0, 0, 1))
spring_2.SetRestLength(rest_length)
spring_2.SetSpringCoefficient(spring_coef)
spring_2.SetDampingCoefficient(damping_coef)
sys.AddLink(spring_2)

# Create the visual system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)
vis.SetWindowSize(1024, 768)
vis.SetWindowTitle('ChLinkTSDA demo')
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
vis.AddSkyBox()
vis.AddCamera(chrono.ChVector3d(0, 0, 6))
vis.AddTypicalLights()

while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    sys.DoStepDynamics(1e-3)
```


**Explanation of Changes:**

1. **New Bodies:**
   - `body_2` and `body_3` are added to the system.
   - Their positions, masses, and inertias are set.

2. **Springs:**
   - Springs are created to connect `body_1` and `body_2`, and `body_2` and `body_3`.
   - These springs are initialized using the `Initialize()` method of the `ChLinkTSDA` class, specifying the connection points.
   - The `SetRestLength` and `SetSpringCoefficient` methods are used to set the spring's length and stiffness.
   - The `SetDampingCoefficient` method is used to control the damping of the spring.

**Key Points:**

- **Error Handling:** This script does not include error handling. You might want to add error handling for cases where the bodies or springs are not properly created or initialized.
- **Visualization:** The script uses the Irrlicht engine to visualize the simulation. This might require additional setup or configuration depending on your environment.
- **Dynamics:** The `DoStepDynamics()` method is used to update the simulation and calculate the forces on the bodies.
- **Time Step:** The time step value `1e-3` (1 millisecond) is used for the simulation. You might need to adjust this value based on the desired simulation speed.

Remember that this is a basic simulation. You can add more complex features, like different types of springs, more bodies, or more advanced physics to create a more realistic simulation.
