```python
from pychrono import *
from pychrono.irrlicht import *

# Initialize PyChrono
init_chrono()

# Create the scene
scene = Scene()

# Create the ground
ground = ChBody(ChBodyType.GROUND)
ground.setPosition(0, 0, 0)
ground.setInertiaTensor(ChVector3(0.0, 0.0, 0.0))
scene.addBody(ground)

# Create the mass
mass = ChBody(ChBodyType.SOLID)
mass.setPosition(0, 1, 0)
mass.setInertiaTensor(ChVector3(1.0, 1.0, 1.0))
mass.setMass(1.0)

# Create the spring
spring = ChLinkTSDA(mass, ground, ChLinkTSDA.LINEAR, 10.0, 10.0)

# Set initial positions and velocities
mass.setPosition(0, 1, 0)
ground.setPosition(0, 0, 0)
spring.setPosition(0, 0, 0)

# Set default parameters for the spring
spring.setLinearStiffness(1000.0)
spring.setDamping(0.1)

# Set up Irrlicht visualization
irrlicht_scene = IrrlichtScene()
irrlicht_scene.setCameraPosition(ChVector3(0, 0, 5))
irrlicht_scene.setCameraRotation(ChVector3(0, 0, 0))
irrlicht_scene.setAmbientLight(ChVector3(0.2, 0.2, 0.2))
irrlicht_scene.setDirectionalLight(ChVector3(1, 1, 1), ChVector3(0, 0, 1))

# Add the scene to Irrlicht
irrlicht_scene.addBody(ground)
irrlicht_scene.addBody(mass)
irrlicht_scene.addBody(spring)

# Render the scene
irrlicht_scene.render()

# Run the simulation
run_chrono()
```

**Explanation:**

1. **Initialization:**
   - `init_chrono()` initializes PyChrono.
   - `Scene()` creates a scene object.

2. **Objects:**
   - `ground`: A ground object representing the base.
   - `mass`: A mass object representing the object being attached to the ground.
   - `spring`: A spring object connecting the mass to the ground.

3. **Parameters:**
   - `mass.setPosition()`: Sets the position of the mass.
   - `ground.setPosition()`: Sets the position of the ground.
   - `spring.setPosition()`: Sets the initial position of the spring.
   - `spring.setLinearStiffness()`: Sets the stiffness of the spring.
   - `spring.setDamping()`: Sets the damping of the spring.

4. **Irrlicht Visualization:**
   - `irrlicht_scene`: An Irrlicht scene object.
   - `setCameraPosition()`: Sets the camera position.
   - `setCameraRotation()`: Sets the camera rotation.
   - `setAmbientLight()`: Sets the ambient light.
   - `setDirectionalLight()`: Sets the directional light.

5. **Rendering:**
   - `irrlicht_scene.render()`: Renders the scene.

6. **Simulation:**
   - `run_chrono()`: Starts the simulation.

**Note:** This script provides a basic framework. You can customize it further by adding more objects, changing parameters, and adding additional features like visual effects and physics calculations.
