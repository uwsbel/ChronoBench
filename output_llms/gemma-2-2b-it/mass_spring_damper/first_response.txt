```python
import pychrono as chrono
import pychrono.irr as irr
import pychrono.irr.core as core

# Initialize PyChrono
chrono.init()

# Create the scene
scene = chrono.Scene()

# Create the ground
ground = chrono.Ground(chrono.Vec3(0, 0, 0), chrono.Vec3(0, 0, 0))
scene.add(ground)

# Create the mass
mass = chrono.Mass(chrono.Vec3(0, 1, 0), 1.0)
scene.add(mass)

# Create the spring
spring = chrono.Spring(chrono.Vec3(0, 0, 0), chrono.Vec3(0, 1, 0), 1.0)
scene.add(spring)

# Create the damper
damper = chrono.Damper(chrono.Vec3(0, 0, 0), chrono.Vec3(0, 1, 0), 1.0)
scene.add(damper)

# Connect the mass to the ground
link = chrono.LinkTSDA(mass, ground, 
                        chrono.Vec3(0, 0, 0), 
                        chrono.Vec3(0, 1, 0), 
                        chrono.Vec3(0, 0, 0), 
                        chrono.Vec3(0, 0, 0))
scene.add(link)

# Set the default parameters
link.set_damping(1.0)
link.set_stiffness(1.0)

# Set the visualization parameters
irr.setup_scene(scene)
irr.set_camera(chrono.Vec3(0, 0, 10), chrono.Vec3(0, 0, 0), chrono.Vec3(0, 1, 0))
irr.set_lighting(chrono.Vec3(1, 1, 1), chrono.Vec3(0.5, 0.5, 0.5))

# Run the simulation
chrono.run()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries.
   - Initializes PyChrono using `chrono.init()`.

2. **Scene Creation:**
   - Creates a `Scene` object to hold all the components.

3. **Ground:**
   - Creates a `Ground` object representing the base.

4. **Mass:**
   - Creates a `Mass` object representing the mass.
   - Sets its position, mass, and initial velocity.

5. **Spring:**
   - Creates a `Spring` object connecting the mass to the ground.
   - Sets its stiffness and initial length.

6. **Damper:**
   - Creates a `Damper` object to simulate damping.
   - Sets its damping coefficient.

7. **Link:**
   - Creates a `LinkTSDA` object to connect the mass to the ground.
   - Sets the connection point, direction, and other parameters.

8. **Visualization:**
   - Uses Irrlicht library to set up the scene and camera.
   - Enables lighting and visual shapes.

9. **Simulation:**
   - Runs the simulation using `chrono.run()`.

**Note:**

- You can customize the mass, spring, and damper parameters to modify the system's behavior.
- The Irrlicht visualization provides a basic visual representation of the simulation.
- The script assumes you have the PyChrono and Irrlicht libraries installed.

This script provides a basic framework for a mass-spring-damper system simulation in PyChrono with Irrlicht visualization. You can extend it by adding more objects, parameters, and visualization elements to create more complex simulations.
