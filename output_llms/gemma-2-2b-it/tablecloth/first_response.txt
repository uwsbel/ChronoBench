```python
import pychrono as chrono
import pychrono.core as core
import pychrono.geometry as geom
import pychrono.material as mat
import pychrono.solver as solver
import pychrono.visualization as vis

# Initialize PyChrono
chrono.init()

# Create the simulation environment
env = chrono.Environment()

# Define the material properties
material = mat.IsotropicKirchhoff(
    elasticity=1e3,  # Young's modulus
    poisson_ratio=0.3,  # Poisson's ratio
    density=0.1  # Density
)

# Create a mesh grid for the tablecloth
# Generate a 10x10 grid with 100 nodes and 200 elements
mesh = geom.Mesh(
    nodes=100,  # Number of nodes
    elements=200,  # Number of elements
    geometry=geom.Rectangle(size=(1, 1))  # Rectangle shape
)

# Add the mesh to the simulation
env.add_mesh(mesh)

# Define the tablecloth object
tablecloth = core.Object()
tablecloth.add_mesh(mesh)
tablecloth.set_material(material)

# Define the forces and interactions
# Apply a constant force to the tablecloth at its center
force = chrono.Vector(0, 0, 100)  # Force in Newtons
tablecloth.add_force(force)

# Set up the Irrlicht visualization system
vis.init()

# Create the Irrlicht scene
scene = vis.Scene()
scene.add_object(tablecloth)

# Set the visualization parameters
vis.set_camera_position(chrono.Vector(0, 0, 5))
vis.set_camera_look_at(chrono.Vector(0, 0, 0))
vis.set_background_color(chrono.Color(0.2, 0.2, 0.2))

# Initialize the solver
solver = solver.PardisoMKL(env)

# Start the simulation
env.run(solver)

# Stop the simulation
env.stop()

# Clean up the simulation
env.clear()
vis.clear()
```


**Explanation:**

1. **Initialization:** The code initializes PyChrono and sets up the environment.
2. **Material Definition:**  It defines an isotropic Kirchhoff material with specified elastic properties, density, and Poisson's ratio.
3. **Mesh Generation:** A mesh is created using a rectangular geometry.
4. **Object Creation:** A tablecloth object is created, assigned the mesh, and set with the defined material.
5. **Force Application:** A constant force is applied to the tablecloth at its center.
6. **Visualization Setup:** The Irrlicht visualization system is initialized and a scene is created. The tablecloth is added to the scene.
7. **Solver Initialization:** The PardisoMKL solver is initialized for efficient dynamics.
8. **Simulation Run:** The simulation is run with the solver.
9. **Clean Up:** The environment and visualization are cleared.

**Key Points:**

* **Shell Elements:** The simulation uses shell elements to model the tablecloth.
* **Kirchhoff Material:** The Kirchhoff material is used for its isotropic behavior.
* **Irrlicht Visualization:** Irrlicht is used for visualization.
* **PardisoMKL Solver:** The PardisoMKL solver is used for efficient dynamic simulation.
