```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import pychrono.irrlicht.irrlicht as irrlicht

# Initialize PyChrono
chrono.Init()

# Create Chrono system
chrono.SetGravity(chrono.Vector3D(0, -9.81, 0))
chrono.SetGroundBody(chrono.GroundBody(chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 1, 0), 1.0))

# Create Viper rover
rover = chrono.Vehicle(chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 1))
rover.AddWheel(chrono.Wheel(chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 1, 0), 0.5))
rover.AddWheel(chrono.Wheel(chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 1, 0), 0.5))

# Create driver
driver = chrono.Character(chrono.Vector3D(0, 0, 0), chrono.Vector3D(0, 0, 1))

# Set initial rover state
rover.SetPosition(chrono.Vector3D(0, 0, 0))
rover.SetVelocity(chrono.Vector3D(0, 0, 0))

# Irrlicht setup
irrlicht_app = irrlicht.IrrlichtApplication(chrono.GetIrrlichtContext())
irrlicht_app.CreateWindow("Viper Rover Simulation", 800, 600)
irrlicht_app.SetCamera(chrono.Vector3D(0, 0, 100), chrono.Vector3D(0, 0, 0))
irrlicht_app.SetLighting(chrono.Vector3D(0.5, 0.5, 0.5))

# Simulation loop
while True:
    # Update rover steering
    steering_angle = (chrono.GetTime() / 10) * 360
    rover.SetSteeringAngle(steering_angle)

    # Update rover state
    chrono.Update(1/60)

    # Render the scene
    irrlicht_app.Render()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Initialize PyChrono with `chrono.Init()`.
   - Set gravity using `chrono.SetGravity()`.
   - Create a ground body using `chrono.GroundBody()`.

2. **Create Objects:**
   - Create the `Viper rover` with wheels using `chrono.Vehicle()` and `chrono.Wheel()`.
   - Create the `driver` using `chrono.Character()`.

3. **Initial State:**
   - Set the rover's initial position and velocity using `SetPosition()` and `SetVelocity()`.

4. **Irrlicht Setup:**
   - Create an `IrrlichtApplication` object using `irrlicht.IrrlichtApplication()`.
   - Create a window using `CreateWindow()`.
   - Set the camera position and direction using `SetCamera()`.
   - Set the lighting using `SetLighting()`.

5. **Simulation Loop:**
   - Inside the loop, update the rover's steering angle based on time.
   - Update the rover's state using `chrono.Update()`.
   - Render the scene using `irrlicht_app.Render()`.

**Notes:**

- This script provides a basic framework. You can customize the rover's behavior, terrain, and visualization based on your requirements.
- The steering angle is linearly scaled based on time.
- You need to install the `pychrono` and `irrlicht` libraries.
- The Irrlicht setup might require further configuration depending on your system. 
- The simulation loop runs at 60 frames per second.
