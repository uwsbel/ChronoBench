However, the plane is defined as `chrono.ChPlane(chrono.ChVector3d(0, 0, 0), chrono.ChVector3d(1, 0, 0))`. According to PyChrono docs, the plane normal should be a unit vector pointing *up* (usually Z-axis) for a horizontal ground plane. This is an incorrect API usage.  
  **Deduct 15 points for incorrect body initialization API usage.**
