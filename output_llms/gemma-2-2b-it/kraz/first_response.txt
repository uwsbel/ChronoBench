```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import numpy as np

# Initialize PyChrono environment
chrono.init()

# Create a PyChrono world
world = chrono.World()

# Define terrain properties
terrain_height = 0.5
terrain_friction = 0.5
terrain_restitution = 0.2

# Create a terrain object
terrain = chrono.Terrain(
    height=terrain_height,
    friction=terrain_friction,
    restitution=terrain_restitution
)

# Create a Kraz vehicle
vehicle = chrono.Vehicle(
    model_name="Kraz",
    mass=1000,
    initial_position=chrono.Vec3(0, 0, 0),
    initial_velocity=chrono.Vec3(0, 10, 0),
    rotation=chrono.Vec3(0, 0, 0)
)

# Create a driver system
driver = chrono.Driver(vehicle)

# Create an Irrlicht engine and scene
irrlicht_engine = irrlicht.IrrlichtEngine()
irrlicht_scene = irrlicht.IrrlichtScene()

# Set camera and lighting
camera = irrlicht.IrrlichtCamera()
camera.setPosition(chrono.Vec3(0, 0, 10))
camera.setLookAt(chrono.Vec3(0, 0, 0))
irrlicht_scene.addCamera(camera)

# Set lighting
irrlicht_scene.setAmbientLight(chrono.Vec3(0.2, 0.2, 0.2))
irrlicht_scene.setDirectionalLight(chrono.Vec3(1, 1, 1), chrono.Vec3(0, 0, -1))

# Initialize visualization loop
while True:
    # Update simulation
    world.update()

    # Update driver system
    driver.update()

    # Update vehicle
    vehicle.update()

    # Update terrain
    terrain.update()

    # Update Irrlicht scene
    irrlicht_engine.renderScene(irrlicht_scene)

    # Wait for the next frame
    irrlicht_engine.run()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries (pychrono, pychrono.irrlicht, numpy).
   - Initialize PyChrono using `chrono.init()`.
   - Create a PyChrono world using `chrono.World()`.

2. **Terrain:**
   - Define terrain properties (height, friction, restitution).
   - Create a terrain object using `chrono.Terrain()`.

3. **Vehicle:**
   - Define vehicle properties (model name, mass, initial position, velocity, rotation).
   - Create a vehicle object using `chrono.Vehicle()`.

4. **Driver:**
   - Create a driver system for vehicle control.

5. **Irrlicht Integration:**
   - Initialize Irrlicht engine and scene.
   - Set camera and lighting using Irrlicht functions.

6. **Simulation Loop:**
   - Use a `while True` loop for continuous simulation.
   - Update the simulation world using `world.update()`.
   - Update the driver system using `driver.update()`.
   - Update the vehicle using `vehicle.update()`.
   - Update the terrain using `terrain.update()`.
   - Render the Irrlicht scene using `irrlicht_engine.renderScene(irrlicht_scene)`.
   - Run the Irrlicht engine for rendering.


**Customization:**

- You can customize the vehicle model, terrain properties, and driver system to fit your specific simulation requirements.
- Adjust the Irrlicht settings (camera position, lighting) to create the desired visual effect.

- This script provides a basic framework. You'll need to install the required libraries and adapt it to your specific simulation needs.
