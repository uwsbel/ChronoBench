```python
from pychrono import *
from pychrono.irrlicht import IrrlichtRenderer

# Initialize PyChrono
chrono.init()

# Create the scene
world = chrono.createWorld()
scene = chrono.createScene(world)

# Define terrain properties
terrain_height = 0.5
terrain_friction = 0.5
terrain_restitution = 0.2

# Create terrain
terrain = chrono.createTerrain(
    world,
    chrono.createBox(
        chrono.Vec3(0, 0, 0),
        chrono.Vec3(10, 10, 1),
        chrono.Vec3(terrain_height, terrain_height, terrain_height),
    ),
    chrono.Vec3(0, 0, 0),
    chrono.Vec3(10, 10, 1),
    chrono.Vec3(terrain_height, terrain_height, terrain_height),
    terrain_friction,
    terrain_restitution,
)

# Create Kraz vehicle
vehicle = chrono.createVehicle(
    world,
    chrono.createBox(
        chrono.Vec3(0, 0, 0),
        chrono.Vec3(5, 5, 1),
        chrono.Vec3(terrain_height, terrain_height, 0.5),
    ),
    chrono.Vec3(0, 0, 0),
    chrono.Vec3(5, 5, 1),
    chrono.Vec3(terrain_height, terrain_height, 0.5),
)

# Define vehicle parameters
vehicle_mass = 1000
vehicle_length = 5
vehicle_width = 2
vehicle_height = 1
vehicle_speed = 5

# Initialize driver system
driver = chrono.createDriver(
    vehicle,
    chrono.Vec3(0, 0, 0),
    chrono.Vec3(vehicle_length, vehicle_width, vehicle_height),
    chrono.Vec3(vehicle_mass, vehicle_mass, vehicle_mass),
)

# Set camera settings
camera = chrono.createCamera(
    scene,
    chrono.Vec3(0, 0, 10),
    chrono.Vec3(0, 0, 0),
    chrono.Vec3(0, 0, 0),
)

# Set lighting
light = chrono.createLight(
    scene,
    chrono.Vec3(0, 0, 1),
    chrono.Vec3(0.5, 0.5, 0.5),
)

# Initialize Irrlicht renderer
renderer = IrrlichtRenderer()
renderer.init(scene)

# Set camera position and look at
camera.setPosition(chrono.Vec3(0, 0, 10))
camera.setLookAt(chrono.Vec3(0, 0, 0))

# Set rendering parameters
renderer.setCamera(camera)
renderer.setLighting(light)

# Simulation loop
while True:
    # Update the simulation
    chrono.update(1.0 / 60.0)
    
    # Render the scene
    renderer.render()

    # Update the Irrlicht renderer
    renderer.update()

```

**Explanation:**

1. **Initialization:** The script initializes PyChrono and creates the world, scene, and necessary components like terrain, vehicle, and driver.
2. **Terrain Creation:** A simple box-shaped terrain is created with specified height, friction, and restitution values.
3. **Vehicle Creation:** A Kraz vehicle is created with specified dimensions and mass.
4. **Driver System:** A driver system is created to control the vehicle's movement.
5. **Camera and Lighting:** A camera is set up to view the simulation and a light source is added for illumination.
6. **Irrlicht Rendering:** An Irrlicht renderer is initialized to handle visual rendering.
7. **Simulation Loop:** A continuous loop simulates the environment, updating physics, rendering, and camera position.

**Key Points:**

* **Physics:** The script utilizes PyChrono's physics engine for vehicle movement, terrain interaction, and other forces.
* **Visualization:** Irrlicht is used for real-time rendering of the simulation, providing a visual representation of the environment and vehicle.
* **Real-Time Execution:** The simulation loop ensures a smooth and responsive experience by synchronizing physics, rendering, and camera updates.
