```python
import pychrono as pch
import pychrono.irrlicht as irr
import pychrono.irrlicht.irrlicht as irr
import numpy as np

# Initialize PyChrono
p = pch.PyChrono()

# Create a new world
world = pch.World()

# Create a terrain
terrain = pch.Terrain(p, "terrain.obj")
terrain.setFriction(0.2)
terrain.setRestitution(0.8)

# Create a Kraz vehicle
vehicle = pch.Vehicle(p, "kraz.obj")
vehicle.setMass(1000)
vehicle.setEnginePower(1000)

# Define vehicle initial conditions
vehicle.setPosition(p.Vec3(0, 0, 0))
vehicle.setVelocity(p.Vec3(0, 10, 0))

# Create a driver system
driver = pch.Driver(p, vehicle)
driver.setSteeringAngle(0)

# Initialize Irrlicht visualization
irr_world = irr.IrrlichtWorld(p.Vec2(800, 600))
irr_world.setCamera(p.Vec3(0, 0, 0), p.Vec3(0, 1, 0))
irr_world.setAmbientLight(p.Vec3(0.2, 0.2, 0.2))

# Create a simulation loop
def simulation_loop():
    # Update vehicle position, velocity, and steering angle
    driver.update()

    # Update terrain and physics
    terrain.update()

    # Update visual system
    irr_world.update()

    # Render the scene
    irr_world.render()

# Run the simulation loop
simulation_loop()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries.
   - Initializes PyChrono (`p`) and creates a new world (`world`).
   - Creates a terrain (`terrain`) with friction and restitution values.
   - Creates a Kraz vehicle (`vehicle`) with mass and engine power.
   - Sets initial position, velocity, and steering angle for the vehicle.
   - Creates a driver system (`driver`) for vehicle control.
   - Initializes Irrlicht visualization (`irr_world`) with camera settings and lighting.

2. **Simulation Loop:**
   - Calls the `simulation_loop()` function to handle the main simulation logic.
   - Updates the vehicle's position, velocity, and steering angle based on the driver's input.
   - Updates the terrain's physics based on the vehicle's movement.
   - Updates the Irrlicht visualization to render the scene.

3. **Visualization:**
   - Irrlicht's `render()` method is called to display the simulation.


**Notes:**

- This script provides a basic framework for a PyChrono simulation with a Kraz vehicle. 
- You'll need to replace `"terrain.obj"` and `"kraz.obj"` with the actual paths to your 3D model files.
- You can customize the simulation parameters (friction, restitution, etc.) and add more systems (e.g., collision detection, sensors, etc.) to enhance the simulation. 
- The Irrlicht visualization settings can be further adjusted to improve the visual quality of the simulation.
