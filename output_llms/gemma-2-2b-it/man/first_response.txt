```python
import pychrono as chrono
import pychrono.core as core
import pychrono.visualization as visualization
import pychrono.collision as collision
import pychrono.vehicle as vehicle
import pychrono.tire as tire
import pychrono.terrain as terrain

# Initialize PyChrono environment
app = chrono.Application()

# Create core components
chrono.initialize()
chrono.set_default_time_step(0.01)
chrono.set_default_solver_type(chrono.SolverType.euler)

# Create terrain
terrain_data = terrain.TerrainData(
    size=chrono.Vec3(100, 100, 100),
    texture="terrain.png",
    color=chrono.Vec3(0.5, 0.5, 0.5)
)
terrain = terrain.Terrain(terrain_data)

# Create vehicle
vehicle_data = vehicle.VehicleData(
    mass=10000,
    center_of_gravity=chrono.Vec3(0, 0, 0),
    dimensions=chrono.Vec3(4, 2, 1)
)
vehicle = vehicle.Vehicle(vehicle_data)
vehicle.set_visualizer(visualization.Visualizer())

# Add tire model
tire_model = tire.TireModel(
    tire_type=tire.TireType.tmeasy,
    friction=0.5
)
vehicle.add_tire(tire_model)

# Add driver controls
driver = vehicle.Driver()
driver.set_controls(
    steering_range=100,
    throttle_range=100,
    brake_range=100
)

# Set initial positions and velocities
vehicle.set_position(chrono.Vec3(0, 0, 0))
vehicle.set_velocity(chrono.Vec3(0, 0, 0))

# Set initial contact points
vehicle.set_contact_points(chrono.Vec3(0, 0, 0))

# Create Irrlicht visualization
irrlicht = visualization.IrrlichtVisualization()
irrlicht.set_camera(
    chrono.Vec3(0, 0, 10),
    chrono.Vec3(0, 0, 0),
    chrono.Vec3(0, 1, 0)
)
irrlicht.set_skybox(
    "skybox.png"
)
irrlicht.set_terrain(terrain)
irrlicht.set_vehicle(vehicle)

# Start the simulation
app.run()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Initialize PyChrono.
   - Set default time step and solver type.

2. **Terrain Creation:**
   - Create a `TerrainData` object with dimensions, texture, and color.
   - Create a `Terrain` object using the data.

3. **Vehicle Creation:**
   - Create a `VehicleData` object with mass, center of gravity, and dimensions.
   - Create a `Vehicle` object using the data.
   - Set the visualizer for visualization.

4. **Tire Model:**
   - Create a `TireModel` object using the TMEASY model and friction coefficient.
   - Add the tire model to the vehicle.

5. **Driver Controls:**
   - Create a `Driver` object.
   - Set the control range for steering, throttle, and braking.

6. **Initial Conditions:**
   - Set the initial position and velocity of the vehicle.
   - Set the initial contact points.

7. **Irrlicht Visualization:**
   - Create an `IrrlichtVisualization` object.
   - Set camera position, direction, and field of view.
   - Set the skybox texture.
   - Set the terrain and vehicle to be visualized.

8. **Simulation Execution:**
   - Start the simulation using the `app.run()` method.

**Note:**

- Replace "terrain.png", "skybox.png", and "vehicle.png" with the actual paths to your texture files.
- You can customize the vehicle model, tire model, and driver controls according to your needs.
- The Irrlicht visualization system provides a wide range of options for customizing the simulation's appearance.
