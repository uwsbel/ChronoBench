```python
# Import necessary libraries
from pychrono import Chrono, ChronoEngine, Body, Vector3, RigidBody, Constraint, Spring, Material
from pychrono.Irrlicht import IrrlichtEngine, IrrlichtDevice
from pychrono.Irrlicht import IrrlichtScene
from pychrono.Irrlicht import IrrlichtMaterial
from pychrono.Irrlicht import IrrlichtCamera
from pychrono.Irrlicht import IrrlichtLight
from pychrono.Irrlicht import IrrlichtViewport
from pychrono.Irrlicht import IrrlichtNode
from pychrono.Irrlicht import IrrlichtEvent

# Initialize PyChrono
chrono = Chrono()

# Initialize Irrlicht Engine
engine = IrrlichtEngine()
device = IrrlichtDevice(engine)
scene = IrrlichtScene(device)
camera = IrrlichtCamera(scene)
viewport = IrrlichtViewport(scene)

# Define material properties
material = IrrlichtMaterial(scene, "material")
material.diffuseColor = Vector3(0.8, 0.8, 0.8)
material.specularColor = Vector3(0.8, 0.8, 0.8)

# Define beam geometry
beam_length = 1.0
beam_width = 0.1
beam_height = 0.2

# Create beam body
beam_body = Body(chrono, "beam")
beam_body.mass = 1.0
beam_body.inertia = Vector3(0.0, 0.0, 0.0)
beam_body.position = Vector3(0.0, 0.0, 0.0)
beam_body.dimensions = Vector3(beam_width, beam_height, beam_length)

# Create ground hinge
ground_hinge = Constraint(chrono, "ground_hinge", beam_body, "ground")
ground_hinge.axis = Vector3(0.0, 1.0, 0.0)
ground_hinge.position = Vector3(0.0, 0.0, 0.0)

# Create cable elements
cable_length = 1.0
cable_diameter = 0.01
cable_material = Material(scene, "cable_material")
cable_material.diffuseColor = Vector3(0.0, 0.0, 1.0)

# Create cable elements
for i in range(10):
    cable = Spring(chrono, "cable_" + str(i))
    cable.position = Vector3(0.0, 0.0, 0.0)
    cable.length = cable_length
    cable.diameter = cable_diameter
    cable.material = cable_material

# Initialize simulation
chrono.run()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries from PyChrono and Irrlicht.
   - Initializes PyChrono and Irrlicht engines.
   - Defines material properties for the beam and cable elements.
   - Defines beam geometry (length, width, height).

2. **Creating Beam and Ground Hinge:**
   - Creates a `Body` object for the beam and assigns it properties like mass and position.
   - Creates a `Constraint` object to simulate a hinge at the ground.

3. **Cable Elements:**
   - Creates a loop to create 10 cable elements with defined length, diameter, and material properties.
   - Each cable element is assigned a name and position.

4. **Simulation:**
   - Initializes the PyChrono simulation loop.
