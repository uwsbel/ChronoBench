```python
import pychrono as chrono
import pychrono.physics as physics
import pychrono.visualization as visualization
import pychrono.irrlicht as irrlicht

# Initialize PyChrono
chrono.init()

# Create the simulation environment
engine = chrono.Engine()

# Create the beam
beam = physics.Beam(
    name="Jeffcott Rotor Beam",
    length=1.0,
    diameter=0.05,
    material="Aluminum",
    properties={"density": 2700.0, "YoungsModulus": 70e9, "PoissonRatio": 0.3}
)

# Create the flywheel
flywheel = physics.RigidBody(
    name="Flywheel",
    mass=0.1,
    position=[0.0, 0.0, 0.0],
    rotation=[0.0, 0.0, 0.0],
    properties={"mass": 0.1, "inertia": 0.01}
)

# Create the motor
motor = physics.RigidBody(
    name="Motor",
    mass=0.1,
    position=[0.5, 0.0, 0.0],
    rotation=[0.0, 0.0, 0.0],
    properties={"mass": 0.1, "inertia": 0.01}
)

# Attach the flywheel to the beam
beam.attach(flywheel)

# Set the motor's torque to create rotational force
motor.setTorque(10.0)

# Set the beam's initial position and rotation
beam.setTranslation([0.0, 0.0, 0.0])
beam.setRotation([0.0, 0.0, 0.0])

# Create a visualization window
irrlicht_window = irrlicht.IrrlichtWindow()

# Set the visualization parameters
irrlicht_window.setFullscreen(True)
irrlicht_window.setResolution(1920, 1080)

# Create the visualization objects
visualization.addVisualization(beam, irrlicht_window)
visualization.addVisualization(flywheel, irrlicht_window)
visualization.addVisualization(motor, irrlicht_window)

# Start the simulation
engine.run()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries for PyChrono, Irrlicht, and visualization.
   - Initializes PyChrono using `chrono.init()`.

2. **Creating Objects:**
   - Creates a beam with specified length, diameter, material, and properties.
   - Creates a flywheel with mass, position, rotation, and properties.
   - Creates a motor with mass, position, rotation, and properties.
   - Attaches the flywheel to the beam using `beam.attach(flywheel)`.

3. **Setting Parameters:**
   - Sets the motor's torque to create rotational force.
   - Sets the beam's initial position and rotation.

4. **Visualization Setup:**
   - Creates an Irrlicht window for visualization.
   - Sets the window's fullscreen mode and resolution.
   - Adds visualizations of the beam, flywheel, and motor to the Irrlicht window.

5. **Simulation Run:**
   - Starts the simulation using `engine.run()`.


**Key Considerations:**

- **IGA Beam:** This script assumes you've implemented IGA for the beam. You'll need to adapt the beam creation code to use your specific IGA model.
- **Motor Dynamics:** The script sets a constant torque to the motor. You can replace this with a more realistic motor model, including speed, power, and torque characteristics.
- **Visualization:** You can customize the visualization parameters in Irrlicht to enhance the simulation's visual appeal.
