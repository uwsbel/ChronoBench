```python
import pychrono as pchrono
import pychrono.core as core
import pychrono.physics as physics
import pychrono.visualization as visualization
import pychrono.irrlicht as irrlicht

# Initialize PyChrono
pchrono.init()

# Create a new world
world = pchrono.World()

# Create a rigid body for the rotor
rotor_body = pchrono.RigidBody(world)
rotor_body.mass = 1.0  # kg
rotor_body.inertia = pchrono.Vector3(0.0, 0.0, 0.0)  # kg*m^2
rotor_body.position = pchrono.Vector3(0.0, 0.0, 0.0)  # m

# Create a beam
beam = pchrono.Beam(world)
beam.length = 0.5  # m
beam.width = 0.05  # m
beam.material = pchrono.Material("beam")
beam.inertia = pchrono.Vector3(0.0, 0.0, 0.0)  # kg*m^2
beam.mass = 0.1  # kg
beam.position = pchrono.Vector3(0.0, 0.0, 0.0)  # m

# Attach a flywheel to the beam's center
flywheel = pchrono.RigidBody(world)
flywheel.mass = 0.5  # kg
flywheel.inertia = pchrono.Vector3(0.0, 0.0, 0.0)  # kg*m^2
flywheel.position = pchrono.Vector3(0.25, 0.0, 0.0)  # m
flywheel.rotation = pchrono.Vector3(0.0, 0.0, 0.0)  # rad

# Create a rotational motor
motor = pchrono.Motor(world)
motor.torque = 1.0  # Nm
motor.position = pchrono.Vector3(0.0, 0.0, 0.0)  # m

# Define the force and interaction parameters
rotor_force = pchrono.Force(rotor_body, pchrono.Vector3(0.0, 0.0, 1.0))  # N
beam_force = pchrono.Force(beam, pchrono.Vector3(0.0, 0.0, 1.0))  # N

# Define the IGA beam properties
beam.IGA_properties = pchrono.IGAProperties(
    element_type="Beam",
    boundary_type="Free",
    mesh_type="Quad",
    solver_type="Newton",
    damping_factor=0.1,
)

# Add the components to the world
world.add_body(rotor_body)
world.add_body(flywheel)
world.add_body(motor)
world.add_body(beam)

# Set up visualization
visualization.init()
visualization.add_mesh(beam, "beam_mesh")
visualization.add_mesh(flywheel, "flywheel_mesh")
visualization.add_mesh(rotor_body, "rotor_body_mesh")

# Irrlicht window setup
irrlicht_window = irrlicht.IrrlichtWindow()
irrlicht_window.show()

# Run the simulation
pchrono.run(world)
```

**Explanation:**

1. **Initialization:** The script starts by initializing PyChrono and creating a new world.
2. **Components:** It creates the rotor, flywheel, beam, and motor components, setting their mass, inertia, position, and rotation.
3. **Forces and Interactions:** The script defines forces and interactions for the rotor and beam.
4. **IGA Beam:** The beam is defined with its IGA properties.
5. **Visualization:** It sets up visualization for the simulation using PyChrono's visualization module and Irrlicht window.
6. **Simulation:** Finally, the script runs the simulation using PyChrono's `run()` function.

**Notes:**

* You can adjust the parameters like mass, inertia, and position to change the dynamics of the system.
* You can customize the IGA properties to change the beam's behavior.
* The Irrlicht window allows you to visualize the simulation in real-time.

This script provides a basic framework for a Jeffcott rotor simulation. You can expand it by adding more complex components, forces, and interactions, and adjusting the simulation parameters to study the rotor's dynamics.
