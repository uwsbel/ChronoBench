```python
import pychrono as chrono
import pychrono.physics as physics
import pychrono.visualization as visualization
import numpy as np

# Initialize PyChrono
chrono.init()

# Create the world
world = chrono.World()

# Create a triangular mesh
mesh_path = "path/to/your/mesh.obj"  # Replace with your mesh file path
mesh = chrono.Mesh.from_file(mesh_path)

# Create a fixed body from the mesh
body = chrono.RigidBody(mesh)
body.set_mass(1.0)  # Set mass, adjust as needed
body.set_inertia(chrono.Inertia(mass=body.get_mass()))  # Set inertia
body.set_position(chrono.Vector3(0, 0, 0))  # Initial position

# Create a camera sensor
camera = chrono.CameraSensor(body)
camera.set_position(chrono.Vector3(0, 0, 10))  # Initial position of the camera
camera.set_rotation(chrono.Quaternion(0, 0, 0, 1))  # Initial rotation of the camera
camera.set_noise_filter(chrono.NoiseFilter(0.1))  # Apply noise filter
camera.set_visualization(visualization.Visualizer())  # Set visualization

# Create a sensor manager
sensor_manager = chrono.SensorManager()
sensor_manager.add_sensor(camera)  # Add the camera to the sensor manager

# Set simulation parameters
dt = 0.01  # Time step
steps = 1000  # Number of simulation steps

# Simulation loop
for step in range(steps):
    # Update sensor data
    sensor_manager.update_sensor_data(camera)
    
    # Print camera buffer data
    print(f"Camera Buffer Data: {camera.get_buffer_data()}")

    # Update the world
    world.update(dt)

# Finalize PyChrono
chrono.finalize()
```


**Explanation:**

1. **Initialization:**
   - Imports necessary libraries: `pychrono`, `numpy`, and `chrono`.
   - Initializes PyChrono using `chrono.init()`.

2. **World Creation:**
   - Creates a `chrono.World` object to hold the simulation.

3. **Mesh Creation:**
   - Defines the path to your triangular mesh file (`mesh_path`).
   - Loads the mesh using `chrono.Mesh.from_file()`.

4. **Body Creation:**
   - Creates a `chrono.RigidBody` object from the mesh.
   - Sets the body's mass, inertia, and initial position.

5. **Camera Sensor:**
   - Creates a `chrono.CameraSensor` object attached to the body.
   - Sets the initial camera position and rotation.
   - Applies a noise filter to the camera's sensor data.
   - Sets up a visualization object.

6. **Sensor Manager:**
   - Creates a `chrono.SensorManager` to manage the camera sensor.
   - Adds the camera sensor to the manager.

7. **Simulation Loop:**
   - Sets the simulation time step (`dt`) and the number of simulation steps (`steps`).
   - Loops through the simulation steps.
   - Updates the sensor data within the sensor manager.
   - Prints the camera buffer data at each step.
   - Updates the world using `world.update(dt)`.

8. **Finalize:**
   - Finalizes PyChrono using `chrono.finalize()`.


**To use this script:**

- Replace `path/to/your/mesh.obj` with the actual path to your mesh file.
- You can adjust the camera position, rotation, noise filter, and visualization settings as needed.
- You can also modify the simulation parameters (`dt`, `steps`) to control the simulation speed.
