```python
import pychrono as chrono
import pychrono.visualization as vis
import pychrono.core as core
import pychrono.sensor as sensor
import numpy as np

# Initialize PyChrono
chrono.init()

# Create a world
world = chrono.World()

# Create a triangular mesh
mesh_path = "mesh.obj"  # Replace with your mesh file path
mesh = chrono.Mesh.Load(mesh_path)

# Create a fixed body
body = chrono.Body(mesh)
body.SetMass(1.0)  # Adjust mass as needed
body.SetInertiaTensor(chrono.InertiaTensor(mesh.vertices, mesh.faces))

# Add a camera sensor to the body
camera_sensor = sensor.Sensor(body)

# Define camera properties
camera_sensor.SetFocalLength(100)
camera_sensor.SetAperture(1)
camera_sensor.SetNoiseFilter(sensor.NoiseFilter.Gaussian(sigma=0.1))

# Set camera position and orientation
camera_sensor.SetPosition(chrono.Vec3(0, 0, 0))
camera_sensor.SetOrientation(chrono.Quaternion(0, 0, 0, 1))

# Create a sensor manager
sensor_manager = sensor.SensorManager(camera_sensor)

# Simulate the system
chrono.Simulate(world, 1000)

# Print camera buffer data
for i in range(100):
    # Get camera buffer data
    camera_buffer = camera_sensor.GetBuffer()

    # Print buffer data
    print(f"Camera Buffer at step {i}: {camera_buffer}")

# Cleanup
chrono.Finalize()
```

**Explanation:**

1. **Initialization:** The script starts by initializing PyChrono and creating a world.
2. **Mesh Loading:** It loads a triangular mesh from a Wavefront .obj file.
3. **Body Creation:** A fixed body is created from the loaded mesh.
4. **Camera Sensor:** A camera sensor is attached to the body.
5. **Sensor Properties:** Camera properties like focal length, aperture, and noise filter are set.
6. **Sensor Manager:** A sensor manager is created to handle the camera sensor.
7. **Simulation:** The simulation is run for 1000 steps.
8. **Buffer Data:** The script prints the camera buffer data at each step.

**Notes:**

* **Replace `mesh.obj`:** Replace the path to your triangular mesh file.
* **Adjust Parameters:** You can adjust the camera properties and sensor parameters to suit your needs.
* **Visualization:** You can visualize the mesh and the camera sensor using the `vis` module.
* **Noise Filters:** You can experiment with different noise filters to control the quality of the camera images.
