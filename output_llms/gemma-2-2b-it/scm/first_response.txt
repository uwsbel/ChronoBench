```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import pychrono.terrain as terrain

# Initialize PyChrono environment
chrono.initialize()

# Create the Irrlicht engine
engine = irrlicht.IrrlichtEngine()

# Create the SCM terrain
terrain_heightmap = terrain.HeightmapTerrain(
    size=(100, 100),  # Adjust terrain dimensions as needed
    resolution=16,  # Adjust terrain resolution
    terrain_type="grass",  # Choose terrain type
    soil_parameters=terrain.SoilParameters(
        friction=0.4,  # Adjust soil friction
        density=0.1,  # Adjust soil density
        viscosity=0.01,  # Adjust soil viscosity
        elasticity=0.5,  # Adjust soil elasticity
    )
)

# Create the HMMWV model
vehicle = chrono.Vehicle(
    model_name="HMMWV",  # Specify HMMWV model
    position=(0, 0, 0),  # Initial vehicle position
    orientation=(0, 0, 0),  # Initial vehicle orientation
    mass=1000,  # Adjust vehicle mass
    friction=0.5,  # Adjust vehicle friction
    # ... add other vehicle properties here ...
)

# Configure the vehicle's tire model
vehicle.tire_model = chrono.TireModel(
    radius=0.2,  # Adjust tire radius
    stiffness=100,  # Adjust tire stiffness
    damping=0.1,  # Adjust tire damping
    # ... other tire model parameters ...
)

# Initialize the Irrlicht visualization
irrlicht_scene = irrlicht.IrrlichtScene()
irrlicht_scene.add_terrain(terrain_heightmap)
irrlicht_scene.add_vehicle(vehicle)

# Create an interactive driver system
driver = chrono.Driver(
    vehicle=vehicle,
    steering_sensitivity=0.1,  # Adjust steering sensitivity
    throttle_sensitivity=0.1,  # Adjust throttle sensitivity
    brake_sensitivity=0.1,  # Adjust brake sensitivity
)

# Set up the simulation loop
chrono.run(
    engine=engine,
    scene=irrlicht_scene,
    driver=driver,
    frame_rate=50,  # Set desired frame rate
)
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Initialize PyChrono and Irrlicht.
   - Create the Irrlicht engine.
   - Create a SCM terrain with custom soil parameters.

2. **Vehicle Model:**
   - Create a HMMWV vehicle model using PyChrono.
   - Define initial position, orientation, and mass.
   - Configure the vehicle's tire model for realistic tire behavior.

3. **Terrain and Visualization:**
   - Create a HeightmapTerrain object for the SCM terrain.
   - Add the terrain to the Irrlicht scene.
   - Add the vehicle to the scene.

4. **Driver System:**
   - Create a Driver object to control the vehicle's steering, throttle, and braking.
   - Set sensitivity parameters for driver inputs.

5. **Simulation Loop:**
   - Run the simulation using PyChrono's `run` function.
   - Update vehicle dynamics and render the scene at 50 frames per second.
