```python
# Import necessary libraries
import pychrono as chrono
import pychrono.irrlicht as irr
from pychrono.irrlicht import IrrlichtEngine

# Initialize PyChrono
chrono.init()

# Create Irrlicht Engine
engine = IrrlichtEngine()

# Create PyChrono world
world = chrono.World()

# Define vehicle parameters
vehicle_mass = 2000.0  # kg
vehicle_length = 4.0  # m
vehicle_width = 2.0  # m
vehicle_height = 1.5  # m
vehicle_center_of_mass = (0.0, 0.0, 0.0)  # m
vehicle_orientation = chrono.Vector3(0.0, 0.0, 1.0)  # radians

# Create vehicle model
vehicle = chrono.Vehicle(world, vehicle_mass, vehicle_length, vehicle_width, vehicle_height, vehicle_center_of_mass, vehicle_orientation)

# Define tire model
tire_model = chrono.RigidTire(vehicle)

# Define SCM terrain parameters
terrain_width = 10.0  # m
terrain_height = 0.5  # m
terrain_density = 1000.0  # kg/m^3
terrain_friction = 0.8  # coefficient of friction
terrain_parameters = chrono.TerrainParameters(terrain_width, terrain_height, terrain_density, terrain_friction)

# Create SCM terrain
terrain = chrono.Terrain(world, terrain_parameters)

# Define moving patch feature
moving_patch_size = 2.0  # m
moving_patch_speed = 0.1  # m/s
moving_patch_parameters = chrono.MovingPatchParameters(moving_patch_size, moving_patch_speed)

# Create moving patch
moving_patch = chrono.MovingPatch(terrain, moving_patch_parameters)

# Initialize sinkage visualization
sinkage_color = (0.0, 0.0, 1.0)  # blue
sinkage_visualization = chrono.SinkageVisualization(terrain, sinkage_color)

# Set up driver system
driver_system = chrono.DriverSystem(vehicle)

# Set up steering, throttle, and braking controls
driver_system.set_steering_control(chrono.SteeringControlType.linear)
driver_system.set_throttle_control(chrono.ThrottleControlType.linear)
driver_system.set_brake_control(chrono.BrakeControlType.linear)

# Set up simulation parameters
simulation_time = 10.0  # seconds
simulation_step_size = 0.01  # seconds

# Start simulation
engine.run()

# Update simulation at 50 frames per second
while engine.isRunning():
    # Update vehicle dynamics
    vehicle.update(simulation_step_size)

    # Update SCM terrain
    terrain.update(simulation_step_size)

    # Update moving patch
    moving_patch.update(simulation_step_size)

    # Update sinkage visualization
    sinkage_visualization.update(simulation_step_size)

    # Render scene
    engine.render()

    # Wait for next frame
    engine.waitForNextFrame()

```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries (PyChrono, Irrlicht).
   - Initialize PyChrono and create an Irrlicht engine.
   - Create a PyChrono world.

2. **Vehicle Setup:**
   - Define vehicle parameters (mass, length, width, height, center of mass, orientation).
   - Create a vehicle object with the specified parameters and add a rigid tire model.

3. **Terrain Creation:**
   - Define terrain parameters (width, height, density, friction).
   - Create a SCM terrain object with the specified parameters.
   - Define a moving patch feature for dynamic terrain interaction.

4. **Visualization:**
   - Set up sinkage visualization to visualize terrain deformation.
   - Set up rendering and visualization using Irrlicht.

5. **Driver System:**
   - Create a driver system to control steering, throttle, and braking.

6. **Simulation:**
   - Set simulation parameters (time, step size).
   - Run the simulation using Irrlicht engine.
   - Update vehicle dynamics, terrain, and moving patch at each simulation step.
   - Render the scene and wait for the next frame.
