```python
import pychrono as chrono
import pychrono.core as core
import pychrono.visuals as visuals
import pychrono.sensor_manager as sensor_manager
import numpy as np

# Initialize PyChrono
app = chrono.App()

# Create a new world
world = app.create_world()

# Load the triangular mesh
mesh_file = "your_mesh.obj"  # Replace with your mesh file path
mesh = chrono.Mesh.from_file(mesh_file)

# Add the mesh as a fixed body
body = chrono.Body(mesh, chrono.Body.BodyType.FIXED)
world.add_body(body)

# Create a lidar sensor
lidar_sensor = sensor_manager.LidarSensor(
    body,
    sensor_manager.LidarSensor.SensorType.LIDAR_POINT_CLOUD,
    sensor_manager.LidarSensor.SensorType.LIDAR_RANGE_IMAGE,
    sensor_manager.LidarSensor.SensorType.LIDAR_DEPTH_IMAGE,
)

# Define lidar parameters
lidar_range = 10.0  # Lidar range in meters
lidar_noise_threshold = 0.1  # Noise threshold for filtering
lidar_visualization_threshold = 0.5  # Visualization threshold for lidar data

# Configure lidar data saving
lidar_save_path = "lidar_data.ply"
lidar_save_format = chrono.Visualization.SaveFormat.PLY

# Set lidar sensor properties
lidar_sensor.set_range(lidar_range)
lidar_sensor.set_noise_threshold(lidar_noise_threshold)
lidar_sensor.set_visualization_threshold(lidar_visualization_threshold)
lidar_sensor.set_save_path(lidar_save_path)
lidar_sensor.set_save_format(lidar_save_format)

# Set the lidar sensor's position to orbit the mesh
lidar_sensor.set_position(chrono.Vec3(0, 0, 0))  # Initial position
lidar_sensor.set_orbit_radius(5.0)  # Orbit radius in meters
lidar_sensor.set_orbit_period(1.0)  # Orbit period in seconds

# Set the simulation parameters
dt = 0.01  # Time step in seconds
num_steps = 1000  # Number of simulation steps

# Start the simulation
app.run(dt, num_steps)

# Print lidar buffer data at each step
for step in range(num_steps):
    # Get the lidar sensor's data
    lidar_data = lidar_sensor.get_data()

    # Print the lidar data
    print(f"Lidar data at step {step}: {lidar_data}")

```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Create a PyChrono application (`app`) and a world (`world`).
   - Load the triangular mesh from the `.obj` file.
   - Create a fixed body (`body`) from the mesh.
   - Create a lidar sensor (`lidar_sensor`) and configure its properties.

2. **Lidar Sensor Configuration:**
   - Set the lidar range, noise threshold, and visualization threshold.
   - Configure the lidar data saving path and format.
   - Set the lidar sensor's initial position, orbit radius, and orbit period.

3. **Simulation Setup:**
   - Define the time step (`dt`) and number of simulation steps (`num_steps`).

4. **Simulation Execution:**
   - Run the simulation using the `app.run()` function.

5. **Lidar Data Output:**
   - Print the lidar data at each step using a loop.

**Notes:**

- Replace `"your_mesh.obj"` with the actual path to your mesh file.
- Adjust the lidar sensor parameters and simulation settings as needed.
- You can add more complex lidar sensor configurations and visualizations.
- The `lidar_data` variable will contain the lidar sensor's data, which you can then use for further analysis or processing. 


This script provides a basic framework for simulating a lidar sensor on a fixed body. You can expand upon it by adding more complex sensor configurations, visualizations, and physics interactions.
