```python
import pychrono as chrono
import pychrono.core as core
import pychrono.visualization as vis
import pychrono.sensors as sensors
import pychrono.data as data
import numpy as np
import matplotlib.pyplot as plt

# Initialize PyChrono environment
app = chrono.Application()

# Create a scene
scene = chrono.Scene()

# Create a mesh object
mesh_file = "your_mesh.obj"  # Replace with your mesh file path
mesh = chrono.Mesh(mesh_file)

# Set the mesh as a fixed body
mesh_body = chrono.Body(mesh)
mesh_body.set_mass(1.0)  # Adjust mass as needed
mesh_body.set_inertia(chrono.Inertia(mesh.get_vertices(), mesh.get_faces()))
mesh_body.set_position(chrono.Vector3(0.0, 0.0, 0.0))
mesh_body.set_fixed_position(True)  # Make the mesh body fixed

# Create a lidar sensor
lidar_sensor = sensors.LidarSensor(mesh_body)
lidar_sensor.set_noise_filter(sensors.GaussianFilter(stddev=0.1))
lidar_sensor.set_visualization(vis.Visualizer())
lidar_sensor.set_save_options(data.SaveOptions(filename="lidar_data.csv"))

# Create a sensor manager
sensor_manager = sensors.SensorManager()
sensor_manager.add_sensor(lidar_sensor)

# Set the lidar sensor's initial position
lidar_sensor.set_position(chrono.Vector3(0.0, 0.0, 5.0))

# Set simulation parameters
dt = 0.01  # Time step
duration = 10.0  # Simulation duration
max_iterations = 1000  # Maximum simulation iterations

# Start the simulation
app.run(duration, dt, max_iterations)

# Print lidar buffer data at each simulation step
for i in range(max_iterations):
    print(lidar_sensor.get_buffer_data())

# Visualize the scene
app.visualize()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Create a PyChrono application (`app`) and a scene (`scene`).

2. **Mesh Object:**
   - Load a triangular mesh from a `.obj` file.
   - Create a `Body` object (`mesh_body`) representing the mesh.
   - Set the mesh body's mass, inertia, and initial position.
   - Set the mesh body as fixed.

3. **Lidar Sensor:**
   - Create a `LidarSensor` object (`lidar_sensor`) attached to the mesh body.
   - Apply noise filters to the sensor data.
   - Configure visualization and save options for the sensor data.

4. **Sensor Manager:**
   - Create a `SensorManager` to manage the lidar sensor.
   - Add the lidar sensor to the manager.

5. **Simulation Parameters:**
   - Set the time step (`dt`) and simulation duration (`duration`).
   - Set the maximum number of iterations (`max_iterations`).

6. **Simulation Execution:**
   - Run the simulation using the `app.run()` method.

7. **Lidar Data Output:**
   - Print lidar buffer data at each iteration.


**Notes:**

- Replace `"your_mesh.obj"` with the actual path to your mesh file.
- Adjust the noise filter parameters (e.g., `stddev`) to control the noise level in the lidar data.
- Modify the visualization settings in the `vis.Visualizer()` object to customize the lidar visualization.
- Explore different save options for the lidar data in the `data.SaveOptions()` object.



This script provides a basic framework for simulating a lidar sensor attached to a fixed mesh body. You can further enhance the simulation by adding additional physical systems, applying more complex sensor configurations, and customizing the visualization and data analysis aspects.
