```python
import pychrono as chrono
import pychrono.irrlicht as irr
import random

# Initialize PyChrono
chrono.init()

# Create the Irrlicht engine
engine = irr.IrrlichtEngine()

# Create a scene and a particle emitter
scene = engine.createScene()
emitter = scene.createParticleEmitter(chrono.ParticleEmitterType.GRAVITY)

# Define particle properties
particle_count = 1000
particle_size = 0.1
particle_lifetime = 10.0

# Define gravitational parameters
g = 9.81  # Acceleration due to gravity

# Define particle properties
particle_shape = chrono.ShapeType.SPHERE
particle_color = (1, 0, 0)  # Red

# Generate particles
for i in range(particle_count):
    # Random position, velocity, and orientation
    position = chrono.Vec3(random.uniform(-10, 10), random.uniform(-10, 10), random.uniform(-10, 10))
    velocity = chrono.Vec3(random.uniform(-5, 5), random.uniform(-5, 5), random.uniform(-5, 5))
    orientation = chrono.Vec3(random.uniform(-1, 1), random.uniform(-1, 1), random.uniform(-1, 1))

    # Create a particle
    particle = scene.createParticle(
        chrono.Particle(
            chrono.Shape(particle_shape),
            chrono.Color(particle_color),
            chrono.Vec3(position),
            chrono.Vec3(velocity),
            chrono.Vec3(orientation),
            chrono.ParticleLifetime(particle_lifetime)
        )
    )

# Apply gravitational force to particles
for particle in emitter.getParticles():
    particle.applyForce(chrono.Vec3(0, 0, -g * particle.getMass()))

# Render the simulation
engine.run()
```

**Explanation:**

1. **Initialization:**
   - The script imports necessary libraries, including `pychrono`, `pychrono.irrlicht`, and `random`.
   - `chrono.init()` initializes PyChrono.
   - `engine = irr.IrrlichtEngine()` creates an Irrlicht engine instance.

2. **Particle Emission:**
   - A particle emitter is created with `scene.createParticleEmitter()`.
   - The emitter is configured with `particle_count`, `particle_size`, and `particle_lifetime`.

3. **Particle Properties:**
   - Particle shape, color, and lifetime are defined.

4. **Particle Generation:**
   - A loop generates `particle_count` particles.
   - Random positions, velocities, and orientations are assigned to each particle.

5. **Gravity Simulation:**
   - A loop iterates through all particles in the emitter.
   - The gravitational force is applied to each particle using `particle.applyForce()`.

6. **Rendering:**
   - `engine.run()` starts the Irrlicht rendering loop.
