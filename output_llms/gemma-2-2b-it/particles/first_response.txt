```python
import pychrono as chrono
import pychrono.irrlicht as irr
import random

# Initialize PyChrono environment
chrono.init()

# Create the Irrlicht engine
engine = irr.IrrlichtEngine()

# Set up the scene
scene = engine.createScene()

# Create a particle emitter
emitter = chrono.ParticleEmitter()
emitter.position = chrono.Vec3(0, 0, 0)
emitter.radius = 1.0
emitter.mass = 1.0
emitter.maxParticles = 1000

# Create particle system
particleSystem = chrono.ParticleSystem()
particleSystem.emitter = emitter

# Create particles
for i in range(1000):
    particle = chrono.Particle()
    particle.position = chrono.Vec3(random.uniform(-10, 10), random.uniform(-10, 10), random.uniform(-10, 10))
    particle.velocity = chrono.Vec3(random.uniform(-10, 10), random.uniform(-10, 10), random.uniform(-10, 10))
    particle.orientation = chrono.Vec3(random.uniform(0, 2 * 3.14159), random.uniform(0, 2 * 3.14159), random.uniform(0, 2 * 3.14159))
    particleSystem.addParticle(particle)

# Set up the gravitational force
def calculate_force(particle, other_particle):
    distance = chrono.Vec3(other_particle.position - particle.position).length()
    force = chrono.Vec3(
        other_particle.position.x - particle.position.x,
        other_particle.position.y - particle.position.y,
        other_particle.position.z - particle.position.z
    )
    force = force / (distance ** 2)
    return force

# Apply gravitational force to particles
for particle in particleSystem.particles:
    for other_particle in particleSystem.particles:
        if particle != other_particle:
            force = calculate_force(particle, other_particle)
            particle.acceleration = force
            other_particle.acceleration = force

# Render the simulation
engine.run()

# Cleanup
engine.shutdown()
```

**Explanation:**

1. **Initialization:** The script starts by importing necessary libraries and initializing PyChrono.
2. **Irrlicht Setup:** It creates an Irrlicht engine and scene to visualize the simulation.
3. **Particle Emitter:** A particle emitter is created with specified properties like radius, mass, and maximum particles.
4. **Particle System:** A particle system is created and linked to the emitter.
5. **Particle Generation:** A loop generates 1000 particles with random positions, velocities, and orientations.
6. **Gravitational Force:** A function `calculate_force` calculates the gravitational force between two particles based on their positions and mass.
7. **Force Application:** The script iterates through all particles and applies the calculated gravitational force to each particle, simulating attraction.
8. **Rendering:** The Irrlicht engine is used to render the simulation.
9. **Cleanup:** The Irrlicht engine is shut down after the simulation.

**Note:**

* This script provides a basic framework for gravitational attraction simulation. 
* You can customize the particle properties, emitter settings, and force calculations to achieve different behaviors. 
* The visualization in Irrlicht can be further customized with additional features and shaders. 

This script is a starting point for a more complex simulation. You can expand upon it by adding more particles, different types of forces, and more sophisticated rendering techniques.
