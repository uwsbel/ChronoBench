```python
import pychrono as chrono
import pychrono.irrlicht as irr
import pychrono.utils as utils

# Initialize PyChrono
chrono.init()

# Create Irrlicht environment
irr_env = irr.IrrlichtEngine()

# Create RigidTerrain
terrain_size = (100, 100)  # Width and height in meters
terrain = chrono.RigidTerrain(
    size=terrain_size,
    texture="terrain.png",  # Replace with your texture path
    friction=0.5,
    damping=0.05,
)

# Create Gator Vehicle
vehicle = chrono.Vehicle(
    name="Gator",
    position=(0, 0, 0),  # Initial position in meters
    orientation=(0, 0, 0),  # Initial orientation in radians
    contact_method=chrono.ContactMethod.CONTACT_METHOD_STATIC,
)

# Add TMEASY tire model
vehicle.addTireModel(
    chrono.TireModel.TMEASY,
    friction=0.7,
    damping=0.1,
)

# Add vehicle mesh
vehicle.addMesh("gator_model.obj")

# Add components to vehicle
vehicle.addWheel(
    chrono.WheelType.WHEEL_TYPE_NORMAL,
    position=(0, 0, 0),
    orientation=(0, 0, 0),
)

# Set vehicle parameters
vehicle.setMass(1000)
vehicle.setInertia(chrono.Vector3D(100, 100, 100))

# Set Irrlicht parameters
irr_env.setDevice(chrono.Device.getIrrDevice())
irr_env.setCamera(chrono.Camera(0, 0, 0))

# Create simulation loop
simulation = chrono.Simulation()
simulation.add(terrain)
simulation.add(vehicle)
simulation.run(50)
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Initialize PyChrono and Irrlicht.

2. **Terrain:**
   - Create a `RigidTerrain` with specified dimensions and a custom texture.
   - Set friction and damping for realistic behavior.

3. **Vehicle:**
   - Create a `Vehicle` with initial position, orientation, and contact method.
   - Add a `TMEASY` tire model for realistic tire dynamics.
   - Add a mesh representing the Gator vehicle.
   - Add wheels to the vehicle.
   - Set mass and inertia for the vehicle.

4. **Irrlicht Setup:**
   - Create an Irrlicht environment and set the device and camera.

5. **Simulation Loop:**
   - Create a `Simulation` object.
   - Add the terrain and vehicle to the simulation.
   - Run the simulation at 50 frames per second.

**Notes:**

- Replace `"terrain.png"` with the path to your terrain texture.
- Replace `"gator_model.obj"` with the path to your Gator vehicle mesh.
- You can customize the vehicle's parameters, tire model, and Irrlicht settings as needed.

**To run the simulation:**

1. Make sure you have PyChrono and Irrlicht installed.
2. Save the script as a Python file (e.g., `gator_simulation.py`).
3. Run the script from your terminal using `python gator_simulation.py`.
