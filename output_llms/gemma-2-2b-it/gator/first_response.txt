```python
from pychrono import *
from pychrono.irrlicht import IrrlichtEngine
from pychrono.irrlicht.irrlicht import IrrlichtScene
from pychrono.irrlicht.irrlicht import IrrlichtDevice
from pychrono.irrlicht.irrlicht import IrrlichtMaterial

# Initialize PyChrono
initPyChrono()

# Create Irrlicht engine and scene
engine = IrrlichtEngine()
scene = IrrlichtScene()
device = IrrlichtDevice(engine)

# Create RigidTerrain
terrain_width = 100
terrain_height = 50
terrain = RigidTerrain(
    width=terrain_width,
    height=terrain_height,
    material=IrrlichtMaterial(color=(0.5, 0.5, 0.5)),
    texture=device.getTexture("path.png"),
)

# Create Gator vehicle
vehicle = Vehicle(
    name="Gator",
    position=Vec3(0, 0, 0),
    orientation=Vec3(0, 0, 0),
    contactMethod=ContactMethod.CONTACT_POINT,
    tireModel=TMEASY,
)

# Set vehicle mesh visualization
vehicle.mesh.setVisualizationType(VisualizationType.MESH)

# Add the vehicle to the scene
scene.add(vehicle)
scene.add(terrain)

# Create a driver system
driver = Driver(vehicle)

# Set up the simulation loop
engine.run(50)
```

**Explanation:**

1. **Initialization:**
   - The script imports necessary modules from `pychrono` and `irrlicht`.
   - `initPyChrono()` initializes the PyChrono environment.
   - An Irrlicht engine, scene, and device are created for visualization.

2. **Terrain Creation:**
   - A `RigidTerrain` object is created with specified width and height, a custom texture, and a material.

3. **Vehicle Creation:**
   - A `Vehicle` object is created with a name, position, orientation, contact method, and tire model.
   - `tireModel` is set to `TMEASY` for tire simulation.
   - The vehicle's mesh is set to be visualized using `VisualizationType.MESH`.

4. **Adding Components:**
   - The vehicle and terrain are added to the Irrlicht scene.

5. **Driver System:**
   - A `Driver` object is created to control the vehicle's steering, throttle, and braking.

6. **Simulation Loop:**
   - `engine.run(50)` starts the Irrlicht engine, running the simulation at 50 frames per second.

**Note:**

- You'll need to install `pychrono` and `irrlicht` libraries.
- Replace "path.png" with the actual path to your texture file.
- You'll need to adjust the vehicle parameters and driver system behavior according to your simulation needs.


This script provides a basic framework for a PyChrono simulation of a Gator vehicle on a flat terrain. You can expand this by adding more complex physics, interactions, and vehicle behavior.
