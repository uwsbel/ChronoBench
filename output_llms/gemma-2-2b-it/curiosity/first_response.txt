```python
from pychrono import *
from pychrono.irrlicht import IrrlichtRenderer
from pychrono.irrlicht import IrrlichtDevice

# Initialize PyChrono
chrono.Init()

# Create the Irrlicht renderer
renderer = IrrlichtRenderer()
device = IrrlichtDevice(renderer)

# Create the terrain
ground = Ground(
    pos=(0, 0, 0),
    size=(100, 100, 100),
    material=Material(
        color=(1, 0, 0),  # Red
        diffuse=true,
        specular=false,
        shininess=10.0
    ),
    collision_properties=CollisionProperties(
        elasticity=0.5,
        friction=0.1,
        density=1000.0
    )
)

# Create the rover
rover = Vehicle(
    pos=(0, 0, 0),
    size=(0.5, 0.5, 0.5),
    material=Material(
        color=(0, 1, 0),  # Green
        diffuse=true,
        specular=false,
        shininess=10.0
    ),
    collision_properties=CollisionProperties(
        elasticity=0.5,
        friction=0.1,
        density=1000.0
    )
)

# Set the rover's motor control driver
rover.motor_control_driver = MotorControlDriver(
    max_torque=100.0,
    max_speed=10.0
)

# Set the rover's wheels
rover.wheels = [Wheel(
    pos=(0, 0, 0),
    size=(0.2, 0.2, 0.2),
    material=Material(
        color=(0, 0, 1),  # Blue
        diffuse=true,
        specular=false,
        shininess=10.0
    )
) for _ in range(4)]

# Add the rover to the ground
ground.add_object(rover)

# Set camera parameters
camera = Camera(
    pos=(0, 0, 5),
    target=(0, 0, 0),
    fov=45.0,
    zoom=1.0
)

# Run the simulation
chrono.Run()

# Save the simulation
renderer.save_image("curiosity_rover.png")

# Clean up
renderer.destroy()
device.destroy()
```


**Explanation:**

1. **Initialization:**
   - Import necessary modules from `pychrono` and `pychrono.irrlicht`.
   - Initialize PyChrono using `chrono.Init()`.
   - Create an `IrrlichtRenderer` and `IrrlichtDevice` to handle the Irrlicht visualization.

2. **Terrain and Rover:**
   - Create a `Ground` object representing the rigid terrain with a specified color, size, and collision properties.
   - Create a `Vehicle` object representing the rover with a specified color, size, and collision properties.
   - Set the rover's `motor_control_driver` for steering control.
   - Add the rover to the ground.

3. **Camera:**
   - Create a `Camera` object to control the view of the simulation.

4. **Simulation:**
   - Use `chrono.Run()` to start the simulation.

5. **Visualization:**
   - Use `renderer.save_image()` to save the simulation as an image.

6. **Cleanup:**
   - Destroy the Irrlicht renderer and device to free resources.

**Additional Notes:**
