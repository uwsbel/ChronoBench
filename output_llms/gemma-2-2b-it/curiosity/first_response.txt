```python
# Import necessary modules
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import pychrono.irrlicht.core as irrcore

# Initialize PyChrono
chrono.init()

# Create a PyChrono world
world = chrono.World()

# Create a rigid terrain
terrain = chrono.RigidBody(chrono.Box(chrono.Vector(10, 10, 10)))
terrain.setCollisionProperties(chrono.CollisionType.COLLISION_STATIC)
terrain.setMass(100)

# Create a rover model
rover = chrono.RigidBody(chrono.Capsule(chrono.Vector(0, 0, 0), 1, 1, 1))
rover.setMass(50)
rover.setCollisionProperties(chrono.CollisionType.COLLISION_DYNAMIC)

# Define rover motor control driver
motor_driver = chrono.MotorControlDriver(rover)

# Set default parameters
rover.setLinearVelocity(chrono.Vector(0, 0, 0))
rover.setAngularVelocity(chrono.Vector(0, 0, 0))

# Define rover wheel properties
wheel_radius = 0.1
wheel_mass = 1

# Set rover wheel properties
for i in range(4):
    wheel = chrono.Wheel(chrono.Vector(0, 0, 0), wheel_radius, wheel_mass)
    wheel.setMass(wheel_mass)
    rover.addWheel(wheel)

# Define Irrlicht engine
irr = irrlicht.IrrlichtEngine()

# Configure Irrlicht engine
irr.createWindow("Curiosity Rover Simulation")
irr.setCameraPosition(chrono.Vector(0, 0, 10))

# Set Irrlicht rendering parameters
irr.setLightingEnabled(True)
irr.setShadowsEnabled(True)
irr.setAmbientLight(chrono.Vector(0.2, 0.2, 0.2))
irr.setDiffuseLight(chrono.Vector(0.8, 0.8, 0.8))

# Add visual elements to the scene
irr.addTexture("textures/rover.png")
irr.addTexture("textures/terrain.png")
irr.addLogo("logo.png")

# Run the simulation
world.run()

# Render the scene
irr.render()
```

**Explanation:**

1. **PyChrono Initialization:**
   - Imports necessary modules from `pychrono` and `pychrono.irrlicht`.
   - Initializes PyChrono using `chrono.init()`.
   - Creates a PyChrono world object.

2. **Terrain and Rover Creation:**
   - Creates a rigid terrain box with specified dimensions and collision properties.
   - Creates a rover capsule with specified dimensions and collision properties.
   - Initializes rover's linear and angular velocities.

3. **Motor Control Driver:**
   - Creates a motor control driver for the rover.

4. **Irrlicht Engine Setup:**
   - Initializes an Irrlicht engine.
   - Creates a window for the simulation.
   - Sets camera position and other rendering parameters.

5. **Irrlicht Rendering:**
   - Enables lighting, shadows, and ambient/diffuse lighting.
   - Adds textures for rover and terrain.
   - Adds a logo to the scene.

6. **Simulation Run:**
   - Runs the PyChrono simulation.

7. **Rendering:**
   - Renders the scene using Irrlicht.
