```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht

# Initialize PyChrono
chrono.init()

# Create the Irrlicht rendering system
irr = irrlicht.IrrlichtDevice()

# Create the simulation world
world = chrono.World()

# Create the HMMWV vehicle
vehicle = chrono.Vehicle(world, "HMMWV", "vehicle_model.obj")
vehicle.set_mass(1500)  # Set vehicle mass

# Add terrain
terrain = chrono.Terrain(world, "terrain_model.obj")
terrain.set_height(100)

# Create driver
driver = chrono.Driver(world, "driver_model.obj")

# Create IMU and GPS sensors
imu = chrono.IMU(vehicle)
gps = chrono.GPS(vehicle)

# Define default parameters
vehicle.set_position(chrono.Vec3(0, 0, 0))
vehicle.set_velocity(chrono.Vec3(0, 0, 0))

# Set initial sensor data
imu.set_orientation(chrono.Vec3(0, 0, 0))  # Initial orientation
gps.set_position(chrono.Vec3(0, 0, 0))  # Initial position

# Define sensor update frequency
sensor_update_frequency = 100  # Hz

# Simulation loop
while True:
    # Update sensor data
    imu.update(chrono.dt)
    gps.update(chrono.dt)

    # Update vehicle position and velocity
    vehicle.update(chrono.dt)

    # Render the scene
    irr.render()

    # Output vehicle mass
    print("Vehicle Mass:", vehicle.get_mass())

    # Sleep for the specified update frequency
    chrono.sleep(1/sensor_update_frequency)

# Clean up PyChrono resources
chrono.shutdown()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries: `pychrono` and `pychrono.irrlicht`.
   - Initialize PyChrono using `chrono.init()`.
   - Create an Irrlicht device using `irrlicht.IrrlichtDevice()`.

2. **World Creation:**
   - Create a `chrono.World()` object to represent the simulation environment.

3. **Vehicle Setup:**
   - Load a 3D model for the HMMWV vehicle using `vehicle.set_model("vehicle_model.obj")`.
   - Set the vehicle's mass using `vehicle.set_mass(1500)`.
   - Set initial position and velocity using `vehicle.set_position` and `vehicle.set_velocity`.

4. **Terrain and Driver:**
   - Create a `chrono.Terrain()` object to represent the terrain.
   - Create a `chrono.Driver()` object to represent the driver.

5. **Sensor Initialization:**
   - Create `chrono.IMU()` and `chrono.GPS()` objects to represent the vehicle's IMU and GPS sensors.
   - Set initial sensor data (orientation and position) using `imu.set_orientation` and `gps.set_position`.

6. **Sensor Update Frequency:**
   - Define the update frequency for the sensors using `sensor_update_frequency`.

7. **Simulation Loop:**
   - Enter a continuous loop that runs indefinitely.
   - Inside the loop:
     - **Update Sensor Data:** Call `imu.update` and `gps.update` to get the latest sensor readings.
     - **Update Vehicle:** Call `vehicle.update` to update the vehicle's position, velocity, and other properties based on sensor data and other factors.
     - **Render Scene:** Use Irrlicht's rendering capabilities to render the scene with the updated vehicle and terrain.
     - **Output Mass:** Print the vehicle's mass.
     - **Sleep:** Use `chrono.sleep` to pause the loop for the specified time interval.

8. **Cleanup:**
   - Clean up PyChrono resources after the simulation ends.
