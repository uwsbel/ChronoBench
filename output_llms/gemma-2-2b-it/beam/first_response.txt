```python
import pychrono as chrono
import pychrono.irrlicht as irr
import numpy as np

# Initialize PyChrono
chrono.init()

# Create a new scene
scene = chrono.Scene()

# Create the Irrlicht engine
irr_engine = irr.IrrlichtEngine()

# Create a mesh
mesh = chrono.Mesh()

# Create beams
beam_nodes = [
    chrono.Node(chrono.Vec3(0, 0, 0), chrono.Vec3(1, 0, 0)),
    chrono.Node(chrono.Vec3(1, 0, 0), chrono.Vec3(2, 0, 0)),
    chrono.Node(chrono.Vec3(2, 0, 0), chrono.Vec3(3, 0, 0)),
]

# Define beam properties
beam_properties = {
    "material": chrono.Material("BeamMaterial"),
    "elasticity": 200e9,
    "density": 7850,
}

# Create beams
for i in range(len(beam_nodes)):
    beam = chrono.Beam(mesh, beam_nodes[i], beam_nodes[(i + 1) % len(beam_nodes)], beam_properties)
    mesh.add_element(beam)

# Set visualization parameters
irr_engine.set_viewport(0, 0, 800, 600)
irr_engine.set_camera(chrono.Vec3(0, 0, 5), chrono.Vec3(0, 0, 0), chrono.Vec3(0, 1, 0))

# Set up the simulation loop
for step in range(100):
    # Update the simulation
    chrono.update(scene)
    
    # Render the scene
    irr_engine.render()

# Destroy the Irrlicht engine
irr_engine.destroy()

# Cleanup PyChrono
chrono.cleanup()
```


**Explanation:**

1. **Initialization:** 
    - Import necessary libraries: `pychrono`, `pychrono.irrlicht`, and `numpy`.
    - Initialize PyChrono using `chrono.init()`.
    - Create a new scene using `chrono.Scene()`.
    - Create an Irrlicht engine using `irr.IrrlichtEngine()`.
2. **Mesh Creation:**
    - Create a mesh using `chrono.Mesh()`.
3. **Beam Creation:**
    - Define a list of beam nodes.
    - Define beam properties, including material, elasticity, and density.
    - Create beams using `chrono.Beam()` and add them to the mesh.
4. **Visualization:**
    - Set up the Irrlicht engine viewport and camera.
5. **Simulation Loop:**
    - Iterate through a simulation loop, updating the simulation and rendering the scene in each iteration.
6. **Cleanup:**
    - Destroy the Irrlicht engine and clean up PyChrono.

**Key Points:**

- This script provides a basic framework for a beam finite element simulation. 
- You will need to customize the beam properties, node positions, and simulation parameters to match your specific scenario.
- You can use the Irrlicht engine to visualize the simulation results in real-time.
