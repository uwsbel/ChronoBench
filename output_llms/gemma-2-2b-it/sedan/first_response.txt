```python
# Import necessary modules
from pychrono import *
from pychrono.core import *
from pychrono.visualization import *
from pychrono.collision import *
from pychrono.terrain import *
from pychrono.vehicle import *
from pychrono.tire import *
from pychrono.driver import *

# Initialize PyChrono environment
chrono = Chrono()

# Create the world
world = chrono.world()

# Create the terrain
terrain = Terrain(
    position=Vec3(0, 0, 0),
    size=Vec3(100, 100, 100),
    material=Material(color=Color(1, 0, 0)),
)
world.add(terrain)

# Create the BMW E90 Sedan
car = Vehicle(
    model="BMW E90",
    position=Vec3(0, 0, 0),
    scale=Vec3(1.0, 1.0, 1.0),
    collision_settings=CollisionSettings(
        mass=1000.0,
        friction=0.1,
        elasticity=0.5,
    ),
)
world.add(car)

# Create the TMEASY tire model
tire = Tire(
    model="TMEASY",
    position=Vec3(0, 0, 0),
    scale=Vec3(1.0, 1.0, 1.0),
    friction=0.5,
)
world.add(tire)

# Create the Irrlicht visualization system
irrlicht = Irrlicht()
irrlicht.set_camera_position(Vec3(0, 5, 5))
irrlicht.set_camera_rotation(Vec3(0, 0, 0))

# Set the visualization parameters
irrlicht.set_background_color(Color(0, 0, 0))
irrlicht.set_skybox(Skybox("skybox.jpg"))
irrlicht.set_directional_light(Vec3(1, 1, 1))

# Create the chase camera
chase_camera = Irrlicht.Camera()
chase_camera.set_position(Vec3(0, 5, 5))
chase_camera.set_rotation(Vec3(0, 0, 0))

# Create the driver system
driver = Driver(
    position=Vec3(0, 0, 0),
    speed=0.0,
    steering_angle=0.0,
    throttle=0.0,
    brake=0.0,
)

# Add the driver system to the car
car.add_driver(driver)

# Run the simulation
chrono.run()

```

**Explanation:**

1. **Import necessary modules:** The script imports necessary modules from the PyChrono library.
2. **Initialize PyChrono environment:** The `chrono` object initializes the PyChrono environment.
3. **Create the world:** A `world` object is created to hold all the objects and systems in the simulation.
4. **Create the terrain:** A `Terrain` object is created to represent the ground surface.
5. **Create the BMW E90 Sedan:** A `Vehicle` object is created to represent the BMW E90 Sedan, including its model, position, scale, and collision settings.
6. **Create the TMEASY tire model:** A `Tire` object is created to represent the tires of the car.
7. **Create the Irrlicht visualization system:** An `Irrlicht` object is created to handle the visualization of the simulation.
8. **Set the visualization parameters:** The script sets the background color, skybox, and directional light.
9. **Create the chase camera:** A `chase_camera` object is created to follow the car.
10. **Create the driver system:** A `Driver` object is created to control the car's steering, throttle, and braking.
11. **Add the driver system to the car:** The driver system is added to the car.
12. **Run the simulation:** The `chrono.run()` function starts the simulation.
