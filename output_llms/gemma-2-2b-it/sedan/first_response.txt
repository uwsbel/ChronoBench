```python
# Import necessary PyChrono libraries
from pychrono import *

# Initialize PyChrono environment
chrono = Chrono()

# Define simulation parameters
dt = 0.01  # Time step
time_duration = 10  # Simulation duration in seconds

# Set up Irrlicht visualization
irrlicht = IrrlichtEngine()
irrlicht.init()

# Create a rigid terrain
terrain = Terrain("terrain.png")
terrain.set_material("dirt")
terrain.set_collision_mode(CollisionMode.STATIC)

# Create a BMW E90 Sedan
car = Vehicle("bmw_e90.obj")
car.set_collision_mode(CollisionMode.DYNAMIC)
car.set_visual_model("bmw_e90.obj")

# Configure TMEASY tire model
tire_model = TMEASY(car)
tire_model.set_friction(0.7)
tire_model.set_rolling_resistance(0.05)

# Define driver system
driver = Driver(car)
driver.set_steering_sensitivity(0.1)
driver.set_throttle_sensitivity(0.2)
driver.set_braking_sensitivity(0.1)

# Set initial conditions
car.set_position(chrono.get_world_size() / 2, 0, 0)
car.set_velocity(0, 0, 0)

# Set up camera and lighting
camera = Camera()
camera.set_position(chrono.get_world_size() / 2, 0, 0)
camera.set_target(car.get_position())

directional_light = DirectionalLight()
directional_light.set_position(chrono.get_world_size() / 2, 0, 0)
directional_light.set_color(Color.WHITE)

skybox = Skybox("skybox.jpg")

# Run the simulation
chrono.run(time_duration)

# Render the simulation
irrlicht.render()

# Cleanup
irrlicht.shutdown()
```


**Explanation:**

1. **Initialization:**
   - Import necessary PyChrono libraries.
   - Initialize the PyChrono environment with `chrono = Chrono()`.
   - Set simulation parameters like time step (`dt`) and duration (`time_duration`).
   - Initialize Irrlicht engine for visualization.

2. **Physical Systems:**
   - **Terrain:** Creates a rigid terrain object with a texture ("terrain.png") and collision settings.
   - **Vehicle:** Creates a vehicle object ("bmw_e90.obj") with collision settings.
   - **Tire Model:** Uses the TMEASY tire model for realistic tire behavior.

3. **Driver System:**
   - Creates a driver system for controlling steering, throttle, and braking.

4. **Initial Conditions:**
   - Sets initial position and velocity for the car.

5. **Visualization:**
   - Creates a camera for a chase view and a directional light for ambient lighting.
   - Uses a skybox for background.

6. **Simulation:**
   - Runs the simulation using `chrono.run(time_duration)`.

7. **Rendering:**
   - Renders the simulation using Irrlicht.

8. **Cleanup:**
   - Shuts down the Irrlicht engine.



**Note:** 

- You will need to install PyChrono and Irrlicht libraries.
- You need to replace the placeholder paths for the terrain, vehicle, and skybox textures.
- The script provides a basic framework. You can add more complex features like:
    - More realistic tire model parameters
    - Different road types and surfaces
    - Advanced driver behavior (e.g., traffic lights, road signs)
    - More sophisticated camera movement
    - Detailed car model with interior and lights 
    - A detailed physics engine that can handle the dynamic interaction between the car and the environment.
