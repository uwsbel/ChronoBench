```python
# Import necessary modules
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import pychrono.irrlicht.scene as scene
import pychrono.irrlicht.materials as materials
import pychrono.irrlicht.collision as collision
import pychrono.irrlicht.geometry as geometry
import pychrono.irrlicht.shapes as shapes
import pychrono.irrlicht.cameras as cameras
import pychrono.vehicle as vehicle
import pychrono.vehicle.tires as tires

# Initialize PyChrono
chrono.init()

# Create Irrlicht engine and scene
engine = irrlicht.IrrlichtEngine()
scene = scene.IrrlichtScene()

# Set up rendering
renderer = engine.getRenderer()
renderer.setCamera(cameras.Camera(scene))

# Load terrain meshes
terrain_collision = collision.Mesh(engine, "Highway_col.obj")
terrain_visual = geometry.Mesh(engine, "Highway_vis.obj")

# Create HMMWV model
vehicle_model = vehicle.Vehicle(engine)
vehicle_model.addShape(shapes.Cylinder(engine, 0.5, 1.0))
vehicle_model.addShape(shapes.Sphere(engine, 0.2))
vehicle_model.addShape(shapes.Box(engine, 0.5, 0.5, 1.0))

# Configure vehicle parameters
vehicle_model.setContactMethod(vehicle.ContactMethod.CONTACT)
vehicle_model.setTireModel(tires.TMEASY)

# Set initial vehicle position and orientation
vehicle_model.setPosition(chrono.Vec3(0, 0, 0))
vehicle_model.setOrientation(chrono.Quaternion(0, 0, 0, 1))

# Initialize driver system
driver_system = vehicle.DriverSystem(vehicle_model)

# Set simulation parameters
dt = 0.01  # Time step
fps = 50  # Frames per second

# Simulation loop
while True:
    # Update driver system
    driver_system.update()

    # Update vehicle dynamics
    vehicle_model.update(dt)

    # Render the scene
    renderer.render()

    # Wait for the next frame
    engine.run()
```


**Explanation:**

1. **Initialization:**
   - Imports necessary modules from PyChrono and Irrlicht.
   - Initializes PyChrono.
   - Creates an Irrlicht engine and scene.
   - Sets up rendering with the Irrlicht renderer.
   - Loads the terrain meshes using Irrlicht's geometry system.
   - Creates a vehicle model using PyChrono's vehicle system.
   - Configures the vehicle's contact method and tire model.

2. **Vehicle Setup:**
   - Sets initial position and orientation for the vehicle.
   - Initializes a driver system for controlling the vehicle's movements.

3. **Simulation Loop:**
   - Runs in a continuous loop, updating the simulation.
   - **Driver System:** Updates the driver system based on user input (steering, throttle, braking).
   - **Vehicle Dynamics:** Updates the vehicle's position, orientation, and other dynamics based on the time step and driver system actions.
   - **Rendering:** Renders the scene using the Irrlicht renderer.
   - **Frame Rate:**  Maintains a consistent frame rate of 50 frames per second.
