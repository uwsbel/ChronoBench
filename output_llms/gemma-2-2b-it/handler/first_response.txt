```python
import pychrono as chrono
import pychrono.ros
import rospy
import numpy as np

# --- PyChrono Initialization ---
# Create a Chrono system
chrono.init()
chrono.set_gravity(9.81)  # m/s^2

# Create the world
world = chrono.World()
world.set_gravity(chrono.Vector3(0, -9.81, 0))

# --- Physical Systems and Objects ---
# Define the floor
floor = chrono.Body(chrono.BodyType.PLANE)
floor.set_material(chrono.Material(
    density=1000,
    elasticity=0.3,
    viscosity=0.01
))
floor.set_position(chrono.Vector3(0, 0, 0))
world.add_body(floor)

# Define the box
box = chrono.Body(chrono.BodyType.BOX)
box.set_material(chrono.Material(
    density=1000,
    elasticity=0.3,
    viscosity=0.01
))
box.set_position(chrono.Vector3(1, 0, 0))
box.set_mass(10)
world.add_body(box)

# --- ROS Integration ---
# ROS node setup
rospy.init_node("chrono_ros_demo")
ros_handler = pychrono.ros.ROSHandler(world)

# ROS topic for publishing
pub_topic = rospy.Publisher("/box_position", int, queue_size=10)

# --- Clock, Body, and Transform Handlers ---
# Configure clock handler
clock_handler = chrono.ClockHandler()
world.set_clock(clock_handler)

# Configure body handler
body_handler = chrono.BodyHandler()
world.set_body_handler(body_handler)

# Configure transform handler
transform_handler = chrono.TransformHandler()
world.set_transform_handler(transform_handler)

# --- Simulation Loop ---
# Main simulation loop
while True:
    # Advance simulation
    world.step()

    # Update ROS messages
    ros_handler.publish_message(box.get_position())

    # Sleep for a short duration
    rospy.sleep(0.01)
```

**Explanation:**

1. **PyChrono Initialization:**
   - Import necessary modules.
   - Initialize PyChrono with `chrono.init()`.
   - Set gravitational acceleration using `chrono.set_gravity()`.

2. **Physical Systems and Objects:**
   - Create a `Floor` body with a specified material and position.
   - Create a `Box` body with a specified material, position, and mass.
   - Add both bodies to the world using `world.add_body()`.

3. **ROS Integration:**
   - Initialize the ROS node with `rospy.init_node()`.
   - Create a ROS handler using `pychrono.ros.ROSHandler(world)`.
   - Create a ROS publisher to publish the box's position to the `/box_position` topic.

4. **Clock, Body, and Transform Handlers:**
   - Configure clock, body, and transform handlers for the simulation.

5. **Simulation Loop:**
   - Run a continuous simulation loop using a `while True` loop.
   - Advance the simulation using `world.step()`.
   - Publish the box's position to the ROS topic using `ros_handler.publish_message()`.
   - Sleep for a short duration using `rospy.sleep()` to control the simulation's speed.


**Running the Script:**

1. Save the script as a Python file (e.g., `chrono_ros_demo.py`).
2. Run the script from your terminal using `python chrono_ros_demo.py`.
3. You should see messages published to the `/box_position` topic in your ROS console.

**Customization:**

- **Material Properties:** Modify the `Material` properties in the `floor` and `box` bodies to change their properties.
- **Gravity:** Adjust the gravitational acceleration using `chrono.set_gravity()`.
- **Box Position:** Change the `box.set_position()` call to modify the box's position.
- **ROS Topic:** Modify the `pub_topic` variable to publish different types of messages.
- **Simulation Time:** Adjust the `rospy.sleep()` duration to control the simulation's speed.
