```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import pychrono.utils as utils

# Initialize PyChrono
chrono.init()

# Create the Irrlicht visualization system
irr = irrlicht.IrrlichtEngine()

# Create the scene
scene = irr.createScene()

# Create the floor (truss)
floor = chrono.createTruss(scene, 
                          position=(0, 0, 0), 
                          dimensions=(10, 10, 10))
floor.setMaterial("wood")

# Create the crankshaft
crankshaft = chrono.createCylinder(scene, 
                                  position=(0, 0, 5), 
                                  dimensions=(1, 1, 50), 
                                  material="steel")
crankshaft.setRotation(chrono.Quaternion(0, 0, 0, 1))

# Create the connecting rod
connecting_rod = chrono.createCylinder(scene, 
                                      position=(0, 0, 10), 
                                      dimensions=(1, 1, 10), 
                                      material="steel")
connecting_rod.setRotation(chrono.Quaternion(0, 0, 0, 1))

# Create the piston
piston = chrono.createCylinder(scene, 
                             position=(0, 0, 15), 
                             dimensions=(1, 1, 10), 
                             material="steel")
piston.setRotation(chrono.Quaternion(0, 0, 0, 1))

# Connect the components
floor.connectTo(crankshaft)
crankshaft.connectTo(connecting_rod)
connecting_rod.connectTo(piston)

# Set the motor
motor = chrono.createMotor(scene, 
                          position=(0, 0, 20), 
                          dimensions=(1, 1, 10), 
                          rotation=(0, 0, 0, 1))
motor.setSpeed(10)  # Set the angular speed of the motor

# Set the camera settings
camera = irr.createCamera(scene)
camera.setPosition(0, 0, 10)
camera.setLookAt(0, 0, 0)

# Set the lighting
light = irr.createLight(scene)
light.setPosition(0, 1, 0)
light.setDirection(0, 0, 1)

# Run the simulation
chrono.run()

# Render the scene
irr.render()
```

**Explanation:**

1. **Initialization:** The script starts by importing necessary libraries and initializing PyChrono.
2. **Irrlicht Setup:** It creates an Irrlicht engine instance and a scene to visualize the simulation.
3. **Object Creation:** The script creates the floor, crankshaft, connecting rod, and piston using `chrono.create*` functions. These objects are given positions, dimensions, and materials.
4. **Connection:** The components are connected using `connectTo` to simulate a crank-slider mechanism.
5. **Motor:** A motor is added to drive the crankshaft.
6. **Camera and Lighting:**  The script sets up a camera and light for visualization.
7. **Simulation:** `chrono.run()` starts the simulation, and `irr.render()` renders the scene for visualization.
