```python
# Import necessary modules
import pychrono as chrono
import pychrono.irrlicht as irr
import pychrono.irrlicht.irrlicht as irrlicht
import pychrono.irrlicht.irrlicht_types as irr_types

# Initialize PyChrono
chrono.init()

# Create a PyChrono environment
env = chrono.Environment()

# Create a floor truss
floor = chrono.Truss(chrono.Vector(0, 0, 0), chrono.Vector(0, 0, 0), 
                      chrono.Vector(1, 1, 1))

# Create a crankshaft
crankshaft = chrono.RigidBody(chrono.Vector(0, 0, 0), chrono.Vector(0, 0, 0), 
                              chrono.Vector(1, 1, 1), chrono.Vector(0, 0, 0))

# Create a connecting rod
connecting_rod = chrono.RigidBody(chrono.Vector(0, 0, 0), chrono.Vector(0, 0, 0), 
                                  chrono.Vector(1, 1, 1), chrono.Vector(0, 0, 0))

# Create a piston
piston = chrono.RigidBody(chrono.Vector(0, 0, 0), chrono.Vector(0, 0, 0), 
                         chrono.Vector(1, 1, 1), chrono.Vector(0, 0, 0))

# Define joints
joint = chrono.Joint(crankshaft, connecting_rod)

# Define motor
motor = chrono.Motor(chrono.Vector(0, 0, 0), chrono.Vector(0, 0, 0))

# Connect motor to crankshaft
motor.connect(crankshaft)

# Set default parameters
crankshaft.set_angular_velocity(10.0)
piston.set_position(chrono.Vector(0, 0, 0))

# Add visual elements
irr.create_camera(
    position=(0, 0, 10),
    target=(0, 0, 0),
    rotation=(0, 0, 0),
    zoom=10
)

# Set lighting
irr.set_ambient_light(chrono.Vector(0.2, 0.2, 0.2))
irr.set_diffuse_light(chrono.Vector(0.8, 0.8, 0.8))

# Add visual elements to the scene
floor.add_texture("floor.png")
crankshaft.add_texture("crankshaft.png")
connecting_rod.add_texture("connecting_rod.png")
piston.add_texture("piston.png")

# Set the scene
env.set_scene(floor, crankshaft, connecting_rod, piston, motor)

# Run the simulation
env.run()
```

**Explanation:**

1. **Import Libraries:** Import necessary PyChrono, Irrlicht, and Irrlicht_types libraries.
2. **Initialize PyChrono:** Initialize PyChrono environment.
3. **Create Objects:**
   - Create a floor truss, crankshaft, connecting rod, and piston objects.
   - Define joints connecting the components.
   - Create a motor to drive the crankshaft.
4. **Set Default Parameters:**
   - Set initial angular velocity for the crankshaft.
   - Set initial position for the piston.
5. **Visualize:**
   - Create a camera with desired position, target, rotation, and zoom.
   - Set ambient and diffuse lighting.
   - Add textures to each object.
6. **Set the Scene:**
   - Set the floor, crankshaft, connecting rod, piston, and motor as part of the scene.
7. **Run Simulation:**
   - Run the simulation using the `env.run()` method.

**Note:** 

- Replace "floor.png", "crankshaft.png", "connecting_rod.png", "piston.png" with actual file paths to your textures.
- This is a basic example. You can add more objects, joints, and constraints to create a more complex simulation.
- You can customize the Irrlicht visualization settings further.

This script provides a foundation for a crank-slider mechanism simulation. You can expand on this by adding more objects, forces, and interactions to create a more realistic and complex simulation.
