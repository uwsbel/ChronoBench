```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import pychrono.irrlicht.irrlicht_utils as irr_utils

# Initialize PyChrono
chrono.init()

# Create Irrlicht engine
engine = irrlicht.IrrlichtEngine()

# Create a RigidTerrain with custom texture
terrain = chrono.RigidTerrain(
    chrono.Vector3(0, 0, 0),
    chrono.Vector3(1, 1, 1),
    chrono.Vector3(1, 1, 1),
    "terrain.png",
    chrono.Material(chrono.Color(0.2, 0.2, 0.2, 1)),
)

# Create a FEDA vehicle
vehicle = chrono.Vehicle(
    chrono.Vector3(0, 0, 0),
    chrono.Vector3(1, 0, 0),
    chrono.Vector3(0, 1, 0),
    chrono.VehicleType.FEDA,
    chrono.ContactMethod.Wheel,
    chrono.TireModel.Default,
)

# Set vehicle parameters
vehicle.set_wheel_diameter(0.5)
vehicle.set_wheel_offset(0.2)
vehicle.set_tire_pressure(1.0)

# Create a camera to follow the vehicle
camera = irrlicht.IrrCamera(engine, irr_utils.get_camera_position(), irr_utils.get_camera_rotation())

# Set the camera to follow the vehicle
camera.follow_object(vehicle)

# Initialize the simulation loop
engine.run()

# Simulation loop
while engine.running():
    # Update vehicle dynamics
    vehicle.update()

    # Render the scene
    engine.render()

    # Control the vehicle
    # ...

    # Sleep for 1/50th of a second
    chrono.sleep(1/50)

# Shutdown PyChrono
chrono.shutdown()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries: `pychrono`, `pychrono.irrlicht`, and `pychrono.irrlicht.irrlicht_utils`.
   - Initializes PyChrono using `chrono.init()`.
   - Creates an Irrlicht engine using `irrlicht.IrrlichtEngine()`.
   - Creates a `RigidTerrain` object with a custom texture.
   - Creates a `Vehicle` object with specific parameters (location, orientation, contact method, tire model).
   - Sets vehicle parameters like wheel diameter, offset, and tire pressure.

2. **Rendering:**
   - Creates a `IrrCamera` object to follow the vehicle.
   - Sets the camera to follow the vehicle using `camera.follow_object(vehicle)`.

3. **Simulation Loop:**
   - Runs the simulation loop using `engine.run()`.
   - Inside the loop:
     - Updates the vehicle's dynamics using `vehicle.update()`.
     - Renders the scene using `engine.render()`.
     - Controls the vehicle (e.g., steering, throttle, braking) using a separate section of code.
     - Uses `chrono.sleep(1/50)` to pause the simulation for 1/50th of a second.

4. **Shutdown:**
   - Shuts down PyChrono using `chrono.shutdown()`.
