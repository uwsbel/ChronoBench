- **Motor speed commands:** The `move` function calls `robot.SetMotorSpeed(left_speed, right_speed)`. However, the calls are:

  ```python

  robot.SetMotorSpeed(-math.pi, 0)   # left
  robot.SetMotorSpeed(math.pi, 0)    # right
  ```

  This is suspicious because:

  - For moving straight, both motors should have the same speed, e.g., `(v, v)`, not `(0,0)` which means no movement.

  - For turning left or right, typically one motor is positive speed and the other negative speed, or one motor stopped and the other moving, but here the second motor speed is always zero.

  - The API documentation for `SetMotorSpeed` is not explicitly given, but logically, setting both motor speeds to zero means the robot will not move straight.

  This is a **logical error** in controlling the robot's movement.

  **Deduct 10 points for logical error in motor speed commands.**

This is a **logical error** in time management.
