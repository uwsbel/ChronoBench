```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht

# Initialize PyChrono
chrono.initialize()

# Create Chrono system
chrono.set_gravity(9.81)  # m/s^2

# Create ground body
ground = chrono.Body(chrono.BodyType.GROUND)
ground.set_position(chrono.Vector3(0, 0, 0))
ground.set_mass(1000)  # kg

# Create Turtlebot
turtlebot = chrono.Body(chrono.BodyType.ROBOT)
turtlebot.set_position(chrono.Vector3(1, 0, 0))  # Initial position
turtlebot.set_orientation(chrono.Vector3(0, 0, 0))  # Initial orientation

# Set Turtlebot parameters
turtlebot.set_mass(10)  # kg
turtlebot.set_friction(0.1)  # for wheels

# Set motor parameters
turtlebot.set_motor_power(0.5)  # initial motor power

# Create Irrlicht engine and setup
irr = irrlicht.IrrlichtEngine()
irr.create_window("Turtlebot Simulation", 800, 600)
irr.set_camera_position(chrono.Vector3(0, 0, 10))
irr.set_camera_angle(chrono.Vector3(0, 0, 0))
irr.set_light(chrono.Vector3(1, 1, 1))

# Simulation loop
while True:
    # Update simulation
    chrono.update_physics()

    # Render scene
    irr.render()

    # Update camera position
    irr.set_camera_position(chrono.Vector3(0, 0, 10))
    
    # Update motor power
    # ... your logic for turning based on time 
    
    # Sleep for a small amount of time
    chrono.sleep(0.1)

# Clean up
chrono.finalize()
```


**Explanation:**

1. **Initialization:**
   - Imports necessary libraries: `pychrono` and `pychrono.irrlicht`.
   - Initializes PyChrono.
   - Sets the gravity to 9.81 m/s².
2. **Creating Objects:**
   - Creates a `ground` body representing the terrain.
   - Creates a `turtlebot` body representing the robot.
3. **Setting Properties:**
   - Sets the initial position and orientation of the `turtlebot`.
   - Sets the mass, friction, and motor power of the `turtlebot`.
4. **Irrlicht Setup:**
   - Creates an Irrlicht engine and window.
   - Sets camera position and angle.
   - Sets up a light source.
5. **Simulation Loop:**
   - Runs a continuous loop to simulate the robot's movement.
   - Calls `chrono.update_physics()` to update the simulation.
   - Renders the scene using `irr.render()`.
   - Updates the camera position.
   - Controls the robot's motor power to control the left and right turns.
   - Uses `chrono.sleep()` to pause for a short time.
6. **Cleanup:**
   - Finalizes PyChrono.
