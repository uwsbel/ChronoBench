Sure, let's create a PyChrono simulation script that meets the specified requirements. We'll initialize the PyChrono environment, set up the beam using ANCF cable elements, and visualize the beam's deformation and nodal positions using the Irrlicht engine.

Here's the complete script:

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.fea as fea

# Initialize the PyChrono environment
chrono.SetChronoDataPath('path/to/chrono/data')  # Set the path to Chrono data directory

# Create the system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create the Irrlicht visualization system
visualization = chronoirr.ChVisualSystemIrrlicht()
visualization.AttachSystem(system)
visualization.SetWindowSize(800, 600)
visualization.SetWindowTitle('ANCF Beam Simulation')
visualization.Initialize()
visualization.AddLogo()
visualization.AddSkyBox()
visualization.AddTypicalLights()

# Create the ground
ground = chrono.ChBodyEasyBox(10, 0.1, 10, 1000)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# Create the ANCF beam
beam = fea.ChElementCableANCF()
beam.SetYoungModulus(210e9)  # Young's modulus
beam.SetCrossSectionArea(0.01)  # Cross-sectional area
beam.SetDensity(7800)  # Density
beam.SetLength(5)  # Length of the beam

# Create nodes for the beam
node1 = fea.ChNodeFEAxyzD()
node1.SetPos(chrono.ChVectorD(0, 0, 0))
node1.SetBodyFixed(True)
system.Add(node1)
beam.AddNode(node1, True)

node2 = fea.ChNodeFEAxyzD()
node2.SetPos(chrono.ChVectorD(5, 0, 0))
system.Add(node2)
beam.AddNode(node2, False)

# Add the beam to the system
system.Add(beam)

# Create a hinge constraint to fix one end of the beam to the ground
hinge = chrono.ChLinkLockRevolute()
hinge.Initialize(node1, ground, chrono.ChFrameD(chrono.ChVectorD(0, 0, 0)))
system.Add(hinge)

# Create a visualization shape for the beam
beam_shape = chrono.ChVisualShapeSphere(0.05)
beam_shape.SetColor(chrono.ChColor(0, 1, 0))
beam_shape.SetChMaterialSurface(chrono.ChMaterialSurfaceNSC())
beam_shape.SetPos(chrono.ChVectorD(0, 0, 0))
beam_shape.SetName("beam_shape")
beam.GetVisualModel().AddChild(beam_shape)

# Run the simulation
run_time = 10.0  # Simulation duration in seconds
time_step = 0.01  # Time step size
current_time = 0.0

while current_time < run_time:
    system.DoStepDynamics(time_step)
    visualization.Render()
    current_time += time_step

# Clean up
visualization.Close()
```

### Explanation:
1. **Initialization**:
   - The PyChrono environment is initialized with `chrono.SetChronoDataPath`.
   - The system is created using `chrono.ChSystemNSC`, and gravity is set.

2. **Visualization**:
   - The Irrlicht visualization system is set up with `chronoirr.ChVisualSystemIrrlicht`.
   - Window size, title, and typical visual elements like logo and skybox are added.

3. **Ground**:
   - A ground plane is created using `chrono.ChBodyEasyBox` and fixed in place.

4. **ANCF Beam**:
   - An ANCF cable element is created using `fea.ChElementCableANCF`.
   - Two nodes are created and added to the beam. The first node is fixed to the ground.
   - The beam is added to the system.

5. **Hinge Constraint**:
   - A hinge constraint is created to fix one end of the beam to the ground.

6. **Visualization Shape**:
   - A visualization shape (sphere) is added to the beam for better visualization.

7. **Simulation Loop**:
   - The simulation runs for a specified duration with a given time step.
   - The system is stepped forward in time, and the visualization is updated in each step.

8. **Cleanup**:
   - The visualization window is closed at the end of the simulation.

Make sure to replace `'path/to/chrono/data'` with the actual path to your Chrono data directory. This script should give you a basic simulation of an ANCF beam subjected to gravity with visualization using the Irrlicht engine.
