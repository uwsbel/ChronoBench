Certainly! Below is a Python script that sets up a PyChrono simulation of a Gator vehicle on a flat rigid terrain using Irrlicht for visualization. The script includes the initialization of the PyChrono environment, adding the necessary physical systems and objects, setting default parameters, and implementing an interactive driver system.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh

# Initialize the Chrono::Engine system
chrono.SetChronoDataPath('../data/')

# Create a Chrono::Engine system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
visualization = chronoirr.ChVisualSystemIrrlicht()
visualization.AttachSystem(system)
visualization.SetWindowSize(1280, 720)
visualization.SetWindowTitle('Gator Vehicle Simulation')
visualization.Initialize()
visualization.AddTypicalSky()
visualization.AddTypicalLights()

# Create a flat rigid terrain
terrain = chrono.ChBodyEasyBox(10, 0.1, 10, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, -0.05, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)

# Create the Gator vehicle
gator = veh.ChVehicleGator()
gator.SetChassisBody(system)
gator.SetInitPosition(chrono.ChVectorD(0, 0.5, 0))
gator.SetInitOrientation(chrono.Q_from_AngAxis(chrono.ChMatrix33D(1)))

# Set up the TMEASY tire model
for wheel in gator.GetVehicle().GetWheelList():
    wheel.GetTire().SetContactMethod(veh.ChTireContactMethod::TMEASY)

# Set up mesh visualization for all vehicle components
for mesh in gator.GetVehicle().GetChassisBody().GetAssets():
    if isinstance(mesh, chrono.ChTriangleMeshShape):
        mesh.SetVisualizationType(chrono.ChTriangleMeshShape.VisualizationType::MESH)

# Set up the RigidTerrain with a custom texture
terrain_mesh = chrono.ChTriangleMeshConnected()
terrain_mesh.LoadFromWavefrontFile("../data/terrain.obj")
terrain_shape = chrono.ChTriangleMeshShape()
terrain_shape.SetMesh(terrain_mesh)
terrain_shape.SetTextureFilename("../data/terrain_texture.jpg")
terrain_shape.SetVisualizationType(chrono.ChTriangleMeshShape.VisualizationType::MESH)
terrain.GetAssets().push_back(terrain_shape)

# Create an interactive driver system
driver = veh.ChDriver()
driver.Initialize(gator.GetVehicle())
driver.SetSteeringInput(0)
driver.SetThrottleInput(0)
driver.SetBrakingInput(0)

# Set up the simulation loop
step_size = 1.0 / 50.0  # 50 frames per second
chrono.ChFunction_RK::SetDefaultStepSize(step_size)

# Main simulation loop
while visualization.Run():
    visualization.BeginScene()
    visualization.Render()

    system.DoStepDynamics(step_size)

    # Update the driver inputs (this would typically be controlled by user input)
    driver.SyncInputs()

    visualization.EndScene()

# Clean up
visualization.Close()
```

### Explanation:
1. **Initialization**:
   - The Chrono::Engine system is initialized with gravity set to Earth's gravity.
   - The Irrlicht visualization system is set up with a window size of 1280x720 and a title.

2. **Terrain**:
   - A flat rigid terrain is created using a box shape and fixed in place.
   - A custom texture is applied to the terrain using a mesh loaded from an OBJ file.

3. **Vehicle**:
   - The Gator vehicle is initialized with specified position and orientation.
   - The TMEASY tire model is set for all wheels.
   - Mesh visualization is enabled for all vehicle components.

4. **Driver System**:
   - An interactive driver system is created to control the vehicle's steering, throttle, and braking.

5. **Simulation Loop**:
   - The simulation runs at 50 frames per second, updating the vehicle dynamics and rendering the scene.

### Notes:
- Ensure that the paths to the OBJ and texture files are correct.
- The driver inputs are currently set to zero. In a real application, these would be controlled by user input.
- The script assumes that the necessary Chrono::Vehicle modules and data files are available in the specified paths.
