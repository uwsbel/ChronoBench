Certainly! Below is a Python script that sets up a PyChrono simulation featuring an M113 vehicle on a rigid terrain with specific initial conditions and visualization settings. The script includes initialization of the PyChrono environment, adding the required physical systems and objects, setting necessary default parameters, and implementing a simulation loop with real-time visualization using Irrlicht.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh

# Initialize the PyChrono environment
chrono.SetChronoDataPath('path/to/chrono/data')  # Set the path to the Chrono::Engine data directory

# Create the system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create the terrain
terrain = chrono.ChBodyEasyBox(100, 0.5, 100, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, -0.25, 0))  # Position the terrain
terrain.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
terrain.GetMaterialSurface().SetFriction(0.9)  # Set friction
terrain.GetMaterialSurface().SetRestitution(0.2)  # Set restitution
system.Add(terrain)

# Create the M113 vehicle
m113 = veh.M113()
m113.SetChassisBodyVisualizationType(veh.ChVisualizationType::PRIMITIVES)
m113.SetChassisBodyCollisionType(veh.ChCollisionType::MESH)
m113.SetChassisBodyShapeType(veh.ChCollisionShapeType::BOX)
m113.SetInitPosition(chrono.ChVectorD(0, 0.5, 0))  # Initial position of the vehicle
m113.SetInitOrientation(chrono.ChQuaternionD(1, 0, 0, 0))  # Initial orientation of the vehicle
m113.SetDriver(veh.ChDriver())  # Initialize the driver system

# Add the vehicle to the system
m113.Initialize(system)

# Create the Irrlicht visualization
visualization = chronoirr.ChVisualSystemIrrlicht()
visualization.AttachSystem(system)
visualization.SetWindowSize(1280, 720)
visualization.SetWindowTitle('M113 Vehicle Simulation')
visualization.SetCamera(chrono.ChVectorD(0, 2, -3), chrono.ChVectorD(0, 0, 0))  # Camera position and target
visualization.SetLightDirection(chrono.ChVectorD(1, -1, -1))  # Light direction

# Create a simulation manager
manager = chronoirr.ChIrrApp()
manager.AddVisualSystem(visualization)
manager.SetTimestep(0.01)  # Simulation timestep
manager.SetTryRealTimeRate(1.0)  # Real-time execution

# Simulation loop
while manager.Run():
    manager.BeginScene()
    manager.Render()
    manager.EndScene()

    # Synchronize and advance the simulation
    system.DoStepDynamics(manager.GetTimestep())

# Cleanup
manager.Close()
```

### Explanation:
1. **Initialization**: The script initializes the PyChrono environment and sets the path to the Chrono::Engine data directory.
2. **Terrain**: A rigid terrain is created with specified friction and restitution properties.
3. **Vehicle**: An M113 vehicle is initialized with specific initial conditions (position and orientation) and a driver system.
4. **Visualization**: The Irrlicht visualization system is set up with camera settings and lighting.
5. **Simulation Loop**: The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.
