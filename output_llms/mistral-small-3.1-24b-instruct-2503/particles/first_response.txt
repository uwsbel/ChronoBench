Certainly! Below is a Python script that sets up a PyChrono simulation to model the gravitational attraction between particles. It includes a particle emitter to generate particles with random shapes, positions, velocities, and orientations. The simulation is visualized using Irrlicht, and custom gravitational forces are applied to simulate particle attraction dynamically.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.physics as chronophysics
import random

# Initialize the Chrono::Engine
chrono.ChSystemNSC msystem = chrono.ChSystemNSC()
chrono.ChCollisionModel::SetDefaultSuggestedEnvelope(0.001)
chrono.ChCollisionModel::SetDefaultSuggestedMargin(0.001)

# Set up the Irrlicht visualization
visualization = chronoirr.ChIrrApp(mystem, L"Gravitational Attraction Simulation", chronoirr.dimension2du(800, 600))
visualization.AddTypicalSky()
visualization.AddTypicalLogo(chrono.GetChronoDataPath() + 'logo_chrono_small.png')
visualization.AddLightWithShadow(chrono.ChVector(1, 1, 1), chrono.ChVector(0, 0, 0), 10, 10, 30, 50, 50)
visualization.SetSymbolScale(0.02)
visualization.SetContactVisualizationType(chronoirr.ChIrrApp.ES_CONTACTSURFACENORMAL)
visualization.SetTimestep(0.01)
visualization.SetTryRealTime(True)

# Create a particle emitter
class ParticleEmitter:
    def __init__(self, system):
        self.system = system

    def emit_particle(self):
        # Create a particle
        particle = chrono.ChParticle()
        particle.SetPos(chrono.ChVectorD(random.uniform(-1, 1), random.uniform(-1, 1), random.uniform(-1, 1)))
        particle.SetMass(1.0)
        particle.SetBodyFixed(False)

        # Random velocity
        velocity = chrono.ChVectorD(random.uniform(-0.1, 0.1), random.uniform(-0.1, 0.1), random.uniform(-0.1, 0.1))
        particle.SetPos_dt(velocity)

        # Add the particle to the system
        self.system.Add(particle)

        # Create a visual shape for the particle
        body_shape = chrono.ChSphereShape()
        body_shape.GetSphereGeometry().rad = 0.05
        body_asset = chronoirr.ChIrrNodepointpoint(body_shape, chrono.ChVector(0, 0, 0), 0.1, chrono.ChColor(1, 0, 0))
        particle.AddAsset(body_asset)

# Create the particle emitter
emitter = ParticleEmitter(mystem)

# Function to apply gravitational forces
def apply_gravitational_forces(system):
    particles = system.Get_physics_items(chrono.ChPhysicsItemType_CH_PARTICLE)
    for i in range(len(particles)):
        for j in range(i + 1, len(particles)):
            p1 = particles[i]
            p2 = particles[j]
            pos1 = p1.GetPos()
            pos2 = p2.GetPos()
            dist = (pos2 - pos1).Length()
            if dist > 0:
                force_magnitude = 1.0 / (dist ** 2)
                force_direction = (pos2 - pos1).GetNormalized()
                force = force_direction * force_magnitude
                p1.AddForce(force)
                p2.AddForce(-force)

# Main simulation loop
def main():
    visualization.SetStepCallback(apply_gravitational_forces, mystem)

    # Emit particles at the beginning
    for _ in range(10):
        emitter.emit_particle()

    # Run the simulation
    while visualization.Run():
        mystem.DoStepDynamics(0.01)

        # Emit particles periodically
        if mystem.GetChTime() % 1.0 < 0.01:
            emitter.emit_particle()

# Run the simulation
if __name__ == "__main__":
    main()
```

### Explanation:
1. **Initialization**:
   - The Chrono::Engine is initialized, and default collision parameters are set.
   - The Irrlicht visualization is set up with typical sky, logo, and lighting.

2. **Particle Emitter**:
   - A `ParticleEmitter` class is defined to create particles with random positions, velocities, and shapes.
   - Particles are added to the system, and visual shapes are created for them.

3. **Gravitational Forces**:
   - The `apply_gravitational_forces` function calculates the gravitational attraction between particles and applies the corresponding forces.

4. **Simulation Loop**:
   - The simulation runs in a loop, updating the system dynamics and visualizing the particles.
   - Particles are emitted periodically to keep the simulation dynamic.

This script provides a basic framework for simulating gravitational attraction between particles using PyChrono and visualizing it with Irrlicht. You can further customize the particle properties, emission rates, and gravitational constants as needed.
