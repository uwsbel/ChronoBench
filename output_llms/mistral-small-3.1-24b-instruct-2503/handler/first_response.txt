To create a PyChrono simulation integrated with ROS as specified, follow the steps below. This script will initialize the PyChrono environment, set up the necessary physical systems, and integrate with ROS to publish messages.

Here's the complete script:

```python
import chrono
import chrono.physics
import chrono.ros
import rospy
from std_msgs.msg import Int32

# Initialize ROS node
rospy.init_node('pychrono_ros_simulation')

# Initialize Chrono
chrono.SetChronoDataPath('path_to_chrono_data')  # Set this to your Chrono data path
system = chrono.physics.System()
system.Set_Gravity(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create a fixed floor
floor = system.NewBody()
floor.SetBodyFixed(True)
floor.SetPos(chrono.ChVectorD(0, -1, 0))
floor.SetCollide(True)
floor.GetCollisionModel().ClearModel()
floor.GetCollisionModel().AddBox(10, 0.1, 10)
floor.GetCollisionModel().BuildModel()

# Create a movable box
box = system.NewBody()
box.SetPos(chrono.ChVectorD(0, 1, 0))
box.SetCollide(True)
box.GetCollisionModel().ClearModel()
box.GetCollisionModel().AddBox(0.5, 0.5, 0.5)
box.GetCollisionModel().BuildModel()

# Create a material for the box
material = chrono.physics.ChMaterialSurfaceNSC()
material.SetFriction(0.6)
material.SetRestitution(0.2)
box.GetMaterialSurface().SetMaterial(material)

# Create a ROS manager
ros_manager = chrono.ros.RosManager()
ros_manager.SetSystem(system)

# Create a custom ROS handler to publish integer messages
class CustomRosHandler(chrono.ros.RosHandler):
    def __init__(self, topic_name):
        self.topic_name = topic_name
        self.publisher = rospy.Publisher(topic_name, Int32, queue_size=10)
        self.counter = 0

    def Publish(self, time):
        self.counter += 1
        self.publisher.publish(Int32(self.counter))

# Register the custom ROS handler
custom_handler = CustomRosHandler('/pychrono_counter')
ros_manager.RegisterHandler(custom_handler)

# Configure the ROS manager with clock, body, and transform handlers
ros_manager.RegisterClockHandler()
ros_manager.RegisterBodyHandler()
ros_manager.RegisterTransformHandler()

# Set up the simulation parameters
time_step = 0.01  # Simulation time step
max_time = 10.0  # Maximum simulation time

# Run the simulation loop
current_time = 0.0
while current_time < max_time:
    system.DoStepDynamics(time_step)
    ros_manager.Update(time_step)
    current_time += time_step

    # Maintain real-time execution
    if current_time % 1.0 < time_step:
        rospy.loginfo(f"Simulation time: {current_time:.2f} seconds")

# Shutdown ROS node
rospy.signal_shutdown("Simulation complete")
```

### Explanation:
1. **Initialize ROS Node**: The script starts by initializing a ROS node named `pychrono_ros_simulation`.
2. **Initialize Chrono**: The Chrono environment is set up with the necessary data path and gravitational acceleration.
3. **Create Physical Systems**:
   - A fixed floor is created using a box shape.
   - A movable box is created with specified dimensions and material properties.
4. **Create ROS Manager**: A `RosManager` is created to handle ROS communication.
5. **Custom ROS Handler**: A custom ROS handler is defined to publish integer messages to a specified topic.
6. **Register Handlers**: The custom handler and default handlers for clock, body, and transform are registered with the ROS manager.
7. **Simulation Loop**: The simulation runs in a loop, advancing the system and updating ROS communication at each timestep. The loop maintains real-time execution by logging the simulation time periodically.

Make sure to replace `'path_to_chrono_data'` with the actual path to your Chrono data directory.

This script provides a basic framework for integrating PyChrono with ROS. You can further customize it based on your specific requirements.
