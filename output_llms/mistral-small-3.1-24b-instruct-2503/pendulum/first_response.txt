Sure! Below is a Python script that sets up a simple pendulum simulation using the PyChrono library with Irrlicht for visualization. This script initializes the PyChrono environment, adds the necessary physical systems and objects, sets the required parameters, and visualizes the simulation while logging the pendulum's position and velocity.

```python
import chrono
import chrono.irrlicht as ch_irr
import chrono.serialization as ch_serialization
import chrono.utils as ch_utils
import numpy as np

# Initialize the PyChrono environment
chrono.SetChronoDataPath('path/to/chrono/data')  # Set the path to the Chrono data directory

# Create the system
system = chrono.ChSystemNSC()

# Create the ground body
ground = chrono.ChBody()
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.SetBodyFixed(True)
system.AddBody(ground)

# Create the pendulum body
pendulum = chrono.ChBody()
pendulum.SetMass(1.0)  # Set the mass of the pendulum
pendulum.SetInertiaXX(chrono.ChVectorD(0.01, 0.01, 0.01))  # Set the inertia of the pendulum
pendulum.SetPos(chrono.ChVectorD(0, 1, 0))  # Initial position of the pendulum
system.AddBody(pendulum)

# Create a revolute joint to connect the pendulum to the ground
revolute_joint = chrono.ChLinkRevolute()
revolute_joint.Initialize(ground, pendulum, chrono.ChFrameD(chrono.ChVectorD(0, 0, 0)))
system.AddLink(revolute_joint)

# Set up the visualization system
visualization = ch_irr.ChVisualSystemIrrlicht()
visualization.AttachSystem(system)
visualization.SetWindowSize(800, 600)
visualization.SetWindowTitle('Simple Pendulum Simulation')
visualization.Initialize()
visualization.AddLogo()
visualization.AddSkyBox()
visualization.AddLightWithShadow(chrono.ChVectorD(1.0, -1.0, 1.0), chrono.ChVectorD(0.7, 0.7, 0.9), 1000)

# Create a function to log the pendulum's position and velocity
def log_pendulum_state(system):
    pendulum_pos = pendulum.GetPos()
    pendulum_vel = pendulum.GetPos_dt()
    print(f"Time: {system.GetChTime()} s, Position: {pendulum_pos}, Velocity: {pendulum_vel}")

# Simulation settings
system.SetTimestepperType(chrono.ChTimestepper.HYBRID)
system.SetSolverType(chrono.ChSolver.BARZILAIBORWEIN)
system.SetSolverMaxIterations(100)

# Simulation loop
step_size = 0.01
total_time = 10.0

current_time = 0.0
while current_time < total_time:
    system.DoStepDynamics(step_size)
    log_pendulum_state(system)
    visualization.Render()
    current_time += step_size

# Close the visualization window
visualization.Close()
```

### Explanation:
1. **Initialize the PyChrono Environment:**
   - `chrono.SetChronoDataPath('path/to/chrono/data')`: Set the path to the Chrono data directory.
   - `system = chrono.ChSystemNSC()`: Create the Chrono system.

2. **Add the Required Physical Systems and Objects:**
   - **Ground Body:** Created and fixed in place.
   - **Pendulum Body:** Created with specified mass and inertia, and positioned at `(0, 1, 0)`.
   - **Revolute Joint:** Connects the pendulum to the ground.

3. **Set Necessary Default Parameters:**
   - Mass and inertia of the pendulum.
   - Initial position of the pendulum.
   - Simulation timestepper and solver settings.

4. **Visualization:**
   - `ch_irr.ChVisualSystemIrrlicht()`: Initialize the Irrlicht visualization system.
   - `visualization.Render()`: Render the simulation in each step.

5. **Logging:**
   - `log_pendulum_state(system)`: Logs the pendulum's position and velocity at each time step.

6. **Simulation Loop:**
   - Runs the simulation for a specified total time, logging and rendering at each step.

Make sure to replace `'path/to/chrono/data'` with the actual path to your Chrono data directory. This script will create a simple pendulum simulation, visualize it using Irrlicht, and log the pendulum's state periodically.
