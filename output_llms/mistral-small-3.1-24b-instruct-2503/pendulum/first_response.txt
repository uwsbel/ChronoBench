Sure, here is a Python script that sets up a simple pendulum simulation using the PyChrono library with Irrlicht for visualization. The script includes the necessary components and parameters as specified:

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize the PyChrono environment
chrono.SetChronoDataPath('path/to/chrono/data')  # Set the path to Chrono data files

# Create the simulation system
system = chrono.ChSystemNSC()

# Create the ground body
ground = chrono.ChBody()
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# Create the pendulum body
pendulum = chrono.ChBody()
pendulum.SetMass(1.0)  # Set the mass of the pendulum
pendulum.SetInertiaXX(chrono.ChVectorD(0.01, 0.01, 0.01))  # Set the inertia tensor
pendulum.SetPos(chrono.ChVectorD(0, 1, 0))  # Set the initial position of the pendulum
system.Add(pendulum)

# Create the revolute joint to connect the pendulum to the ground
revolute = chrono.ChLinkRevolute()
revolute.Initialize(ground, pendulum, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
system.Add(revolute)

# Set up the visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Simple Pendulum Simulation')
vis.Initialize()
vis.AddLogo()
vis.AddSkyBox()
vis.AddLightWithShadow(chrono.ChVectorD(1.0, -1.0, 1.0), chrono.ChVectorD(0.8, 0.8, 0.8), 1000)

# Create a camera to view the pendulum
camera = vis.AddCamera(chrono.ChVectorD(2, 2, 2), chrono.ChVectorD(0, 0, 0))
camera.SetNearFarPlane(0.1, 100)

# Run the simulation
step_size = 0.01
end_time = 10.0
current_time = 0.0

while current_time < end_time:
    system.DoStepDynamics(step_size)
    vis.Render()
    vis.Update()

    # Log the pendulum's position and velocity
    pendulum_pos = pendulum.GetPos()
    pendulum_vel = pendulum.GetPos_dt()
    print(f"Time: {current_time:.2f}, Position: {pendulum_pos}, Velocity: {pendulum_vel}")

    current_time += step_size

# Close the visualization system
vis.Close()
```

### Notes:
1. Make sure to replace `'path/to/chrono/data'` with the actual path to your Chrono data files.
2. The script sets up a simple pendulum with a mass of 1 kg and an inertia tensor of `[0.01, 0.01, 0.01]`.
3. The pendulum is initially positioned at `(0, 1, 0)`.
4. The simulation runs for 10 seconds with a time step of 0.01 seconds.
5. The pendulum's position and velocity are logged periodically during the simulation.
