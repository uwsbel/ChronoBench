To create a PyChrono simulation that showcases a Curiosity rover navigating on a rigid terrain, we'll follow the steps outlined in your instructions. Below is a complete Python script that initializes the PyChrono environment, sets up the required physical systems and objects, and configures visualization using the Irrlicht visualization system.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize the PyChrono environment
chrono.SetChronoDataPath('path_to_your_chrono_data')  # Set the path to Chrono::Engine data files

# Create a Chrono::Engine system
system = chrono.ChSystemNSC()

# Set the time step of the simulation
time_step = 0.01
system.SetTimestepperType(chrono.ChTimestepper.Type_HHT)
system.SetT(0)
system.SetStep(0)
system.SetMaxPenetrationRecoverySpeed(2.0)

# Create the ground
ground = chrono.ChBodyEasyBox(100, 1, 100, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# Create the rover model
# Assuming we have a pre-defined Curiosity rover model saved in a .chr file
rover = chrono.ChLoader_Urdf().LoadChronoModel('path_to_your_rover_model.chr')
rover.SetPos(chrono.ChVectorD(0, 0.5, 0))
system.Add(rover)

# Add a motor control driver for real-time steering inputs
motor_driver = chrono.ChFunction_Ramp(0, 1)
steering_driver = chrono.ChFunction_Sine(1, 0.5, 0, 0)

# Assuming the rover has wheels that can be controlled by motors
for wheel in rover.GetListModel().GetComponents(chrono.ChChassisWheel):
    wheel.SetMotorTorque(motor_driver)
    wheel.SetSteerAngle(steering_driver)

# Set up visualization using Irrlicht
application = chronoirr.ChIrrApp(system, 'Curiosity Rover Simulation', chronoirr.dimension2du(800, 600))
application.AddTypicalSky()
application.AddTypicalLogo(chrono.GetChronoDataFile('logo_pychrono_small.png'))
application.AddTypicalLights()
application.AddTypicalCamera(chrono.ChVectorD(0, 5, -10), chrono.ChVectorD(0, 0, 0))

# Set camera settings
camera = application.GetSceneManager().getActiveCamera()
camera.setPosition(chrono.ChVectorD(0, 5, -10))
camera.setTarget(chrono.ChVectorD(0, 0, 0))
camera.setFarValue(1000)

# Add custom textures and visual elements
material = chronoirr.ChIrrMaterial()
material.setTexture(0, chronoirr.irrlicht.IrrlichtManager.getTexture('path_to_your_texture.png'))
material.setTexture(1, chronoirr.irrlicht.IrrlichtManager.getTexture('path_to_your_texture.png'))
application.AssetBind(ground.GetAssets(), material)

# Run the simulation
application.SetStepSize(time_step)
application.SetTryRealTime(True)

# Main simulation loop
while application.GetDevice().run():
    application.BeginScene()
    application.DrawAll()
    system.DoStepDynamics(time_step)
    application.EndScene()
```

### Explanation:
1. **Initialization**: We initialize the PyChrono environment and set the path to Chrono::Engine data files.
2. **System Creation**: We create a Chrono::Engine system and set the time step and timestepper type.
3. **Ground Creation**: We create a fixed ground with collision properties.
4. **Rover Model**: We load a pre-defined Curiosity rover model (assuming it's saved in a `.chr` file) and add it to the system.
5. **Motor Control**: We add a motor control driver for real-time steering inputs to the rover's wheels.
6. **Visualization**: We set up the Irrlicht visualization system with customizable camera settings, lighting, shadows, and additional visual elements like textures and logos.
7. **Simulation Loop**: We run the simulation in a loop, updating the physics and rendering the scene.

### Notes:
- Ensure you have the correct paths to your Chrono::Engine data files, rover model, and textures.
- The rover model and motor control logic assume a specific structure. You may need to adjust the script based on your actual rover model and control requirements.
- The Irrlicht visualization system requires additional setup and dependencies. Make sure you have Irrlicht installed and properly configured with PyChrono.
