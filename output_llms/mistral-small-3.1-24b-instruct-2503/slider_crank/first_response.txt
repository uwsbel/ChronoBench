To create a PyChrono simulation showcasing a simple crank-slider mechanism, you can follow the steps outlined below. This script initializes the PyChrono environment, sets up the necessary components, and configures the visualization using the Irrlicht visualization system.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.engine as engine
import pychrono.physics as physics

# Initialize the Chrono::Engine system
chrono.SetChronoDataPath('path/to/chrono/data')  # Set the path to Chrono data directory

# Create a Chrono::Engine system
system = chrono.ChSystemNSC()

# Create the floor (truss)
floor = chrono.ChBodyEasyBox(10, 0.1, 10, 1000, True, True)
floor.SetPos(chrono.ChVectorD(0, -0.1, 0))
system.Add(floor)

# Create the crankshaft
crankshaft = chrono.ChBodyEasyCylinder(0.1, 0.5, 1000, True, True)
crankshaft.SetPos(chrono.ChVectorD(0, 0.25, 0))
system.Add(crankshaft)

# Create the connecting rod
connecting_rod = chrono.ChBodyEasyBox(0.1, 0.01, 1.5, 1000, True, True)
connecting_rod.SetPos(chrono.ChVectorD(0.75, 0.25, 0))
system.Add(connecting_rod)

# Create the piston
piston = chrono.ChBodyEasyCylinder(0.1, 0.1, 1000, True, True)
piston.SetPos(chrono.ChVectorD(1.5, 0.25, 0))
system.Add(piston)

# Create joints
crank_pivot = chrono.ChLinkLockRevolute()
crank_pivot.Initialize(crankshaft, floor)
crank_pivot.SetName("crank_pivot")
system.Add(crank_pivot)

rod_pivot = chrono.ChLinkLockRevolute()
rod_pivot.Initialize(connecting_rod, crankshaft)
rod_pivot.SetName("rod_pivot")
system.Add(rod_pivot)

piston_slider = chrono.ChLinkLockPrismatic()
piston_slider.Initialize(piston, floor)
piston_slider.SetName("piston_slider")
system.Add(piston_slider)

# Apply a motor to the crankshaft
motor = chrono.ChFunction_Const(chrono.CH_C_PI / 2)  # 90 degrees per second
driver = chrono.ChLinkMotorRotationAngle()
driver.Initialize(crankshaft, floor)
driver.SetAngleFunction(motor)
system.Add(driver)

# Set up the visualization (Irrlicht)
application = chronoirr.ChIrrApp(system, 'Crank-slider mechanism', chronoirr.dimension2du(800, 600))

application.AddTypicalSky()
application.AddTypicalLogo(chrono.GetChronoDataPath() + 'logo_chrono_engine.png')
application.AddTypicalCamera(chrono.ChVectorD(1, 1, 1), chrono.ChVectorD(0, 0, 0))
application.SetSymbolScale(0.05)

application.AssetBindAll()
application.AssetUpdateAll()

# Run the simulation
application.SetTimestep(0.01)
application.SetTryRealTime(True)

while application.GetDevice().run():
    application.BeginScene()
    application.DrawAll()
    application.DoStep()
    application.EndScene()

application.GetDevice().closeDevice()
```

### Explanation:
1. **Initialize the PyChrono environment**:
   - Set the path to the Chrono data directory.
   - Create a `ChSystemNSC` object to manage the simulation.

2. **Add physical systems and objects**:
   - Create a floor using `ChBodyEasyBox`.
   - Create a crankshaft using `ChBodyEasyCylinder`.
   - Create a connecting rod using `ChBodyEasyBox`.
   - Create a piston using `ChBodyEasyCylinder`.

3. **Set necessary default parameters**:
   - Position the objects appropriately.
   - Create joints to connect the crankshaft, connecting rod, and piston.
   - Apply a motor to the crankshaft to drive it at a constant angular speed.

4. **Visualization using Irrlicht**:
   - Initialize the Irrlicht visualization system.
   - Add typical sky, logo, and camera settings.
   - Run the simulation loop to visualize the crank-slider mechanism.

Make sure to replace `'path/to/chrono/data'` with the actual path to your Chrono data directory. This script provides a basic setup for the crank-slider mechanism and can be further customized as needed.
