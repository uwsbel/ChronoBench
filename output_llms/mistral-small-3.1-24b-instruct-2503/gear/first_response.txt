Sure! Below is a PyChrono simulation script that sets up an epicyclic gear system with a fixed truss, a rotating bar, two gears, and a gear motor to enforce a constant rotation speed. The script also includes visualization using the Irrlicht visualization system.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize the PyChrono environment
chrono.SetChronoDataPath('path/to/chrono/data')  # Update with your actual Chrono data path

# Create a simulation system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create a fixed truss (assume a simple box for simplicity)
truss_body = chrono.ChBodyEasyBox(1, 1, 0.1, 1000)
truss_body.SetPos(chrono.ChVectorD(0, 0.5, 0))
truss_body.SetBodyFixed(True)
system.Add(truss_body)

# Create a rotating bar
rotating_bar = chrono.ChBodyEasyCylinder(0.1, 1, 1000, True, True)
rotating_bar.SetPos(chrono.ChVectorD(0, 1, 0))
rotating_bar.SetRot(chrono.Q_from_AngAxis(chrono.ChMatrix33D(1)))
system.Add(rotating_bar)

# Create two gears
gear1 = chrono.ChBodyEasyCylinder(0.2, 0.05, 1000, True, True)
gear1.SetPos(chrono.ChVectorD(0.5, 1, 0))
gear1.SetRot(chrono.Q_from_AngAxis(chrono.ChMatrix33D(1)))
system.Add(gear1)

gear2 = chrono.ChBodyEasyCylinder(0.2, 0.05, 1000, True, True)
gear2.SetPos(chrono.ChVectorD(-0.5, 1, 0))
gear2.SetRot(chrono.Q_from_AngAxis(chrono.ChMatrix33D(1)))
system.Add(gear2)

# Create a gear motor to enforce constant rotation speed
gear_motor = chrono.ChLinkMotorRotationAngle()
gear_motor.Initialize(rotating_bar, gear1)
gear_motor.SetAngle(chrono.CH_C_PI / 2)
gear_motor.SetMotorFunction(chrono.ChFunction_Const(chrono.CH_C_PI / 2))
system.AddLink(gear_motor)

# Set up visualization
application = chronoirr.ChIrrApp(system, 'Epicyclic Gear System', chronoirr.dimension2du(800, 600))

application.AddTypicalSky()
application.AddTypicalLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))
application.AddTypicalCamera(chrono.ChVectorD(1, 1, 1), chrono.ChVectorD(0, 0, 0))

application.AssetBindAll()
application.AssetUpdateAll()

# Set material properties for visualization
truss_body.GetVisualShape(0).SetTexture(chrono.GetChronoDataFile('textures/concrete.jpg'))
rotating_bar.GetVisualShape(0).SetTexture(chrono.GetChronoDataFile('textures/bluewhitegrid.jpg'))
gear1.GetVisualShape(0).SetTexture(chrono.GetChronoDataFile('textures/redmetal.jpg'))
gear2.GetVisualShape(0).SetTexture(chrono.GetChronoDataFile('textures/greenmetal.jpg'))

# Run the simulation
application.SetTimestep(0.01)
application.SetTryRealTime(True)

while application.GetDevice().run():
    application.BeginScene()
    application.DrawAll()
    application.DoStep()
    application.EndScene()

application.Close()
```

### Explanation:
1. **Initialization**: The PyChrono environment is initialized, and the Chrono data path is set.
2. **Physical Systems and Objects**:
   - A fixed truss is created as a simple box.
   - A rotating bar is created as a cylinder.
   - Two gears are created as cylinders.
3. **Gear Motor**: A gear motor is added to enforce a constant rotation speed between the rotating bar and one of the gears.
4. **Visualization**: The Irrlicht visualization system is set up with appropriate materials and lighting.
5. **Simulation Loop**: The simulation runs in a loop, updating the visualization and stepping through the simulation.

Make sure to update the `chrono.SetChronoDataPath` with the actual path to your Chrono data directory. Also, ensure that the texture files exist in the specified paths or update them accordingly.
