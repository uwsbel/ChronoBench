```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.postprocess as postprocess
import pychrono.vehicle as veh

# Initialize the Chrono::Engine
chrono.SetChronoDataPath('../../data/')  # Path to Chrono data files

# Create a Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
visualization = chronoirr.ChVisualSystemIrrlicht()
visualization.AttachSystem(system)
visualization.SetWindowSize(1280, 720)
visualization.SetWindowTitle('HMMWV Simulation')
visualization.Initialize()
visualization.AddTypicalSky()
visualization.AddTypicalLogo(chrono.GetChronoDataFile('logo_pychrono.png'))
visualization.AddLightWithShadow(chrono.ChVectorD(1.0, 0.0, 1.0), chrono.ChVectorD(0.5, 0.5, 0.5), 100, 100, 10, 40, 512)

# Create the HMMWV vehicle
vehicle = veh.ChVehicleHMMWV()
vehicle.Initialize()
vehicle.SetChassisBodyVisualizationType(veh.ChVehicleVisualizationType::MESH)
vehicle.SetChassisBodyShapeFilename(chrono.GetChronoDataFile('vehicle/hmmwv/chassis_chassis_body.obj'))
vehicle.SetInitPosition(chrono.ChVectorD(0, 0, 1.5))
vehicle.SetInitOrientation(chrono.Q_from_AngAxis(chrono.ChVectorD(1, 0, 0), chrono.CHR_PI / 2))
vehicle.SetEngineType(veh.ChVehicleEngineType::ENGINE_TYPE_4STROKE)
vehicle.SetDrivetrainType(veh.ChVehicleDrivetrainType::DRIVETRAIN_TYPE_4WD)
vehicle.SetTireType(veh.ChVehicleTireType::TIRE_TYPE_FIALA)
vehicle.SetDriverBehavior(veh.ChDriverBehaviorType::DRIVER_BEHAVIOR_TYPE_INTERACTIVE)

# Create the terrain
terrain = veh.ChTerrain()
terrain.Initialize(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(100, 100, 0))
terrain.AddPatch(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(50, 50, 0), veh.ChTerrainPatchType::PATCH_TYPE_FLAT, veh.ChTerrainMaterialType::MATERIAL_TYPE_GRASS)
terrain.AddPatch(chrono.ChVectorD(50, 0, 0), chrono.ChVectorD(50, 50, 0), veh.ChTerrainPatchType::PATCH_TYPE_FLAT, veh.ChTerrainMaterialType::MATERIAL_TYPE_ASPHALT)
terrain.AddPatch(chrono.ChVectorD(0, 50, 0), chrono.ChVectorD(50, 50, 0), veh.ChTerrainPatchType::PATCH_TYPE_MESH, veh.ChTerrainMaterialType::MATERIAL_TYPE_GRAVEL, chrono.GetChronoDataFile('terrain/bump.obj'))
terrain.AddPatch(chrono.ChVectorD(50, 50, 0), chrono.ChVectorD(50, 50, 0), veh.ChTerrainPatchType::PATCH_TYPE_HEIGHTMAP, veh.ChTerrainMaterialType::MATERIAL_TYPE_SAND, chrono.GetChronoDataFile('terrain/heightmap.bmp'))

# Add the vehicle and terrain to the system
system.Add(vehicle.GetVehicle())
system.Add(terrain.GetTerrainBody())

# Create a driver system
driver = veh.ChDriver()
driver.Initialize(vehicle, system)
driver.SetSteeringController(veh.ChSteeringControllerType::STEERING_CONTROLLER_TYPE_PI)
driver.SetThrottleController(veh.ChThrottleControllerType::THROTTLE_CONTROLLER_TYPE_PI)
driver.SetBrakingController(veh.ChBrakingControllerType::BRAKING_CONTROLLER_TYPE_PI)
driver.SetInteractiveMode(True)

# Set the simulation timestep
timestep = 0.01
system.SetTimestepperType(chrono.ChTimestepperType::ChTimestepperEulerImplicit)
system.SetMaxPenetrationRecoverySpeed(1.0)
system.SetMaxIterationsSpeed(100)
system.SetMaxIterationsStab(100)
system.SetIterLCPmaxIters(100)

# Run the simulation
while visualization.Run():
    system.DoStepDynamics(timestep)
    visualization.Render()

# Close the visualization
visualization.Close()
```

### Explanation:
1. **Initialization**:
   - The Chrono::Engine and Irrlicht visualization system are initialized.
   - The simulation system is created and configured with gravity.

2. **Vehicle Initialization**:
   - An HMMWV vehicle is created and initialized with specific parameters such as position, orientation, engine type, drivetrain type, and tire type.
   - Mesh visualization is applied to the vehicle chassis.

3. **Terrain Construction**:
   - A terrain is created with multiple patches of different types (flat, mesh-based, and heightmap-based) and materials.

4. **Driver System**:
   - An interactive driver system is set up to control steering, throttle, and braking.

5. **Simulation Loop**:
   - The simulation runs in a loop, updating the physics at each timestep and rendering the scene in real time.

This script provides a comprehensive setup for simulating an HMMWV on a complex terrain with real-time visualization and interactive control.
