To create a simulation script based on the provided instructions using PyChrono and Irrlicht for visualization, follow the steps below. This script will initialize the environment, set up the CityBus vehicle on a rigid terrain, and implement the necessary controls and visualization.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.postprocess as postprocess

# Initialize the PyChrono environment
chrono.SetChronoDataPath('path/to/chrono/data')

# Create a Chrono::Engine physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle('CityBus Simulation')
vis.Initialize()
vis.AddTypicalSky()
vis.AddTypicalLogo()
vis.AddLightWithShadow(chrono.ChVectorD(1, 1, 1), chrono.ChVectorD(0, 0, 0), 1, 1, 10, 50, 512)
vis.AddCamera(chrono.ChVectorD(0, 10, -20), chrono.ChVectorD(0, 0, 0))

# Create a RigidTerrain with a custom texture
terrain = chrono.ChTerrain()
terrain.SetTexture(chrono.GetChronoDataFile('textures/concrete.jpg'), True)
terrain.SetSmooth(False)
terrain.Initialize(system)

# Load the CityBus vehicle
vehicle = chrono.ChVehicle()
vehicle.SetChassisBody(chrono.ChBody())
vehicle.GetChassisBody().SetPos(chrono.ChVectorD(0, 1, 0))
vehicle.GetChassisBody().SetRot(chrono.Q_from_AngAxis(chrono.CHR_PI / 2, chrono.ChVectorD(1, 0, 0)))

# Add wheels to the vehicle
wheel1 = chrono.ChWheel()
wheel1.SetRadius(0.4)
wheel1.SetSuspensionRestLength(0.4)
wheel1.SetSuspensionSpringStiffness(20000)
wheel1.SetSuspensionDamping(400)
vehicle.AddWheel(wheel1, chrono.ChVectorD(1.5, 0, 1.5))
vehicle.AddWheel(wheel1, chrono.ChVectorD(-1.5, 0, 1.5))
vehicle.AddWheel(wheel1, chrono.ChVectorD(1.5, 0, -1.5))
vehicle.AddWheel(wheel1, chrono.ChVectorD(-1.5, 0, -1.5))

# Set up the driver system
driver = chrono.ChDriver()
driver.Initialize(vehicle)
driver.SetSteering(0)
driver.SetThrottle(0)
driver.SetBraking(0)

# Add the vehicle to the system
system.Add(vehicle.GetChassisBody())
for wheel in vehicle.GetWheels():
    system.Add(wheel.GetChassis())

# Set up the simulation parameters
system.SetTimestepperType(chrono.ChTimestepperType.HHT)
system.SetSolverType(chrono.ChSolverType.BARZILAIBORWEIN)
system.SetSolverMaxIterations(100)
system.SetSolverTolerance(1e-10)

# Set up the visualization loop
step_size = 1.0 / 50.0  # 50 frames per second
total_time = 10.0  # total simulation time in seconds

# Run the simulation loop
while vis.Run() and system.GetChTime() < total_time:
    system.DoStepDynamics(step_size)
    vis.Render()

# Finalize the visualization system
vis.Close()

# Optionally, save the simulation data for post-processing
postprocess.ChGnuplot.WritePlotFile(system, "simulation_data.txt")
```

### Explanation:
1. **Initialize the PyChrono environment**: Set the Chrono data path and create the physical system.
2. **Create the Irrlicht visualization system**: Set up the window size, title, and add typical elements like sky, logo, and lights.
3. **Create a RigidTerrain**: Initialize the terrain with a custom texture.
4. **Load the CityBus vehicle**: Set up the chassis and wheels with specified parameters.
5. **Set up the driver system**: Initialize the driver and set initial controls.
6. **Add the vehicle to the system**: Add the chassis and wheels to the physical system.
7. **Set up the simulation parameters**: Configure the timestepper and solver.
8. **Run the simulation loop**: Update the vehicle dynamics and render the scene in real-time at 50 frames per second.
9. **Finalize the visualization system**: Close the visualization window and optionally save the simulation data.

This script provides a basic framework for simulating a CityBus vehicle on a rigid terrain with PyChrono and Irrlicht. You can further customize the vehicle parameters, terrain, and driver controls as needed.
