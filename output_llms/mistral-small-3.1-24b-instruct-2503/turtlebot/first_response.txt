This script initializes the PyChrono environment, sets up a Turtlebot robot on a rigid terrain, and implements a real-time visualization using Irrlicht. The simulation loop controls the Turtlebot's motors to perform left and right turns at specified times.

```python
import chrono
import chrono.irrlicht as ch_irr
import chrono.engine as cheng
import chrono.vehicle as veh

# Initialize the Chrono::Engine system
system = cheng.System()
system.Set_Gravity(cheng.ChVectorD(0, -9.81, 0))

# Create the ground body
ground_body = system.NewBody(cheng.ChBodyEasyBox(20, 20, 0.5, 1000, True, True))
ground_body.SetPos(cheng.ChVectorD(0, -0.25, 0))

# Load the Turtlebot model
turtlebot = veh.Turtlebot()
chassis_body = turtlebot.GetChassisBody()
chassis_body.SetPos(cheng.ChVectorD(0, 0.5, 0))
chassis_body.SetRot(cheng.Q_from_AngAxis(0.785398, cheng.ChVectorD(0, 0, 1)))  # 45 degrees around Z-axis

# Add the Turtlebot to the system
system.Add(turtlebot)

# Initialize Irrlicht visualization
myapplication = ch_irr.ChIrrApp(system, 'Turtlebot Simulation', ch_irr.dimension2du(800, 600))
myapplication.AddTypicalSky()
myapplication.AddTypicalLogo(ch_irr.logo_position.bottom_right)
myapplication.AddTypicalCamera(cheng.ChVectorD(2, 2, 2), cheng.ChVectorD(0, 0, 0))
myapplication.SetSymbolScale(1.0)
myapplication.SetContactDrawSize(0.01)
myapplication.SetPaused(False)
myapplication.SetTimestep(0.01)

# Set up the simulation loop
def simulate(system, application):
    # Timestep and simulation time
    step_size = 0.01
    end_time = 10.0  # Simulate for 10 seconds

    # Control the Turtlebot's motors
    left_motor = turtlebot.GetLeftMotor()
    right_motor = turtlebot.GetRightMotor()

    start_time = cheng.ChTimeStep(0.0)
    while application.GetDevice().run():
        time = application.GetTime()

        if time < 2.0:
            left_motor.SetMotorSpeed(1.0)  # Forward
            right_motor.SetMotorSpeed(1.0)
        elif time < 4.0:
            left_motor.SetMotorSpeed(-1.0)  # Turn left
            right_motor.SetMotorSpeed(1.0)
        elif time < 6.0:
            left_motor.SetMotorSpeed(1.0)  # Turn right
            right_motor.SetMotorSpeed(-1.0)
        else:
            left_motor.SetMotorSpeed(0.0)  # Stop
            right_motor.SetMotorSpeed(0.0)

        application.BeginScene()
        application.DrawAll()
        application.DoStep()
        application.EndScene()

        if time >= end_time:
            break

# Run the simulation
simulate(system, myapplication)
```

### Explanation:
1. **Initialization**: The Chrono::Engine system is initialized with gravity, and a ground body is created.
2. **Turtlebot Setup**: The Turtlebot is loaded and positioned at (0, 0.5, 0) with a 45-degree rotation around the Z-axis.
3. **Irrlicht Visualization**: The Irrlicht visualization is set up with a typical sky, logo, camera, and contact drawing settings.
4. **Simulation Loop**: The simulation loop controls the Turtlebot's motors to perform left and right turns at specified times. The simulation runs for 10 seconds.

This script provides a basic framework for simulating a Turtlebot on a rigid terrain with real-time visualization and motor control. You can further customize the simulation parameters and control logic as needed.
