Certainly! Below is a Python script to create a PyChrono simulation that showcases the dynamics of a MAN 10t truck driving on a rigid terrain. The script initializes the PyChrono environment, adds the necessary physical systems and objects, and sets up the visualization using the Irrlicht visualization system.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.postprocess as postprocess

# ------------------------------
# Initialize the PyChrono environment
# ------------------------------
chrono.SetChronoDataPath('path/to/chrono/data')

# Create a Chrono::Engine physical system
system = chrono.ChSystemNSC()

# Create an Irrlicht visualization system
visualization = chronoirr.ChVisualSystemIrrlicht()
visualization.AttachSystem(system)
visualization.SetWindowSize(1280, 720)
visualization.SetWindowTitle('MAN 10t Truck Simulation')
visualization.Initialize()
visualization.AddLogo(chrono.GetChronoDataFile('logo_pychrono_white.png'))
visualization.AddSkyBox()
visualization.AddLightDirectional()

# Set up the chase camera
camera = visualization.GetSceneManager().addCameraSceneNode()
camera.setPosition(chrono.ChVectorD(0, 10, -20))
camera.setTarget(chrono.ChVectorD(0, 0, 0))

# ------------------------------
# Add the MAN 10t truck model
# ------------------------------
vehicle = chrono.vehicle.ChVehicle(
    system,
    chrono.vehicle.get_data_file('vehicle/MAN_10t/MAN_10t_truck_chassis.json'),
    chrono.vehicle.get_data_file('vehicle/MAN_10t/MAN_10t_truck_setup.json')
)

# Set initial position and orientation of the vehicle
vehicle.SetChassisPosition(chrono.ChVectorD(0, 0.5, 0))
vehicle.SetChassisOrientation(chrono.ChQuaternionD(1, 0, 0, 0))

# Set tire model to TMEASY
for wheel in vehicle.GetWheelList():
    wheel.SetTireModelType(chrono.vehicle.ChTireModelType.TMEASY)

# ------------------------------
# Add the rigid terrain
# ------------------------------
terrain = chrono.ChBodyEasyBox(200, 0.1, 200, 1000, False, True)
terrain.SetPos(chrono.ChVectorD(0, -0.05, 0))
terrain.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
terrain.GetMaterialSurface().SetFriction(0.9)
terrain.GetMaterialSurface().SetRestitution(0.2)
system.Add(terrain)

# ------------------------------
# Real-time driver controls
# ------------------------------
driver = chrono.vehicle.ChDriver(
    vehicle,
    chrono.vehicle.ChDriverInputSimple(
        steering=0.0,  # initial steering angle
        throttle=0.0,  # initial throttle position
        braking=0.0    # initial braking position
    )
)

# ------------------------------
# Simulation settings
# ------------------------------
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Set the time step
time_step = 1e-3
system.SetTimestepperType(chrono.ChTimestepper.Type.HHH)
system.SetTimestepper(chrono.ChTimestepperHHH(time_step))

# ------------------------------
# Run the simulation
# ------------------------------
run_time = 10  # simulation time in seconds
current_time = 0.0

while current_time < run_time:
    visualization.BeginScene()
    visualization.Render()
    visualization.EndScene()

    system.DoStepDynamics(time_step)

    current_time += time_step

# Close the visualization
visualization.Close()
```

### Explanation:
1. **Initialization**:
   - The script initializes the PyChrono environment and sets the path to Chrono data.
   - It creates a physical system and an Irrlicht visualization system.

2. **Vehicle Model**:
   - The script loads the MAN 10t truck model using JSON configuration files.
   - It sets the initial position and orientation of the vehicle.
   - It configures the tires to use the TMEASY tire model.

3. **Terrain**:
   - A rigid terrain is created as a box and added to the system.
   - The terrain's material properties are set to simulate friction and restitution.

4. **Driver Controls**:
   - A simple driver model is created to control the vehicle's steering, throttle, and braking.

5. **Simulation Settings**:
   - The gravity vector is set.
   - The time step and timestepper type are configured.

6. **Simulation Loop**:
   - The script runs the simulation for a specified duration, updating the visualization and performing dynamics steps.

7. **Visualization**:
   - The Irrlicht visualization system is configured with a chase camera, directional lighting, a skybox, and customizable terrain textures and logos.

Make sure to replace `'path/to/chrono/data'` with the actual path to your Chrono data directory. Additionally, ensure that the JSON files for the vehicle model are correctly placed in the specified directories.

This script provides a basic framework for the simulation. You can further customize the driver controls, terrain properties, and visualization settings as needed.
