Below is a Python script that sets up a PyChrono simulation of a FEDA vehicle on a rigid terrain using Irrlicht for visualization. This script initializes the environment, adds the necessary components, and configures the visualization and interaction as specified.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh
import pychrono.fea as fea

# Initialize the PyChrono environment
chrono.SetChronoDataPath('path/to/chrono/data')  # Set the path to Chrono data files

# Create a Chrono::Engine physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle('FEDA Vehicle Simulation')
vis.Initialize()
vis.AddTypicalSky()
vis.AddTypicalLogo(chrono.GetChronoDataFile('logo_pychrono.png'))
vis.AddLightWithShadow(chrono.ChVectorD(1.0, -1.0, 1.0), chrono.ChVectorD(0, 0, 0), 1.0, 1.5)

# Load the FEDA vehicle
vehicle = veh.FEDA_Vehicle(system, veh.FEDA_VehicleParameters())

# Set the initial position and orientation of the vehicle
vehicle.SetChassisPosition(chrono.ChVectorD(0, 0, 0.5))
vehicle.SetChassisOrientation(chrono.Q_from_AngAxis(chrono.ChMatrix33D(1)))

# Set the tire model and contact method
vehicle.SetTireModel(veh.FEDA_TireModel.FEDA_TIRE_MODEL_FIALA)
vehicle.SetContactMethod(chrono.ChContactMethodNSC)

# Add the vehicle to the system
system.Add(vehicle.GetVehicle())

# Create a RigidTerrain with a custom texture
terrain = chrono.ChRigidTerrain()
terrain.SetTexture(chrono.GetChronoDataFile('terrain/texture.png'), True)
terrain.SetTextureTiling(10, 10)
terrain.SetContactMaterial(chrono.ChMaterialSurfaceNSC())
terrain.SetContactMaterialFriction(0.9)
terrain.SetContactMaterialRestitution(0.01)
terrain.SetContactMaterialCompliance(1e-4)
terrain.SetContactMaterialComplianceT(1e-4)
terrain.SetContactMaterialComplianceR(1e-4)
system.Add(terrain)

# Set the camera to follow the vehicle
camera = vis.AddCamera(chrono.ChVectorD(0, -5, 2), chrono.ChVectorD(0, 0, 0))
camera.SetActive(True)
camera.SetNearClip(0.1)
camera.SetFarClip(100)
camera.SetFOV(0.78)

# Integrate an interactive driver system
driver = veh.FEDA_Driver(vehicle)
driver.SetSteeringController(veh.FEDA_SteeringController())
driver.SetThrottleController(veh.FEDA_ThrottleController())
driver.SetBrakingController(veh.FEDA_BrakingController())

# Set the simulation step size and frame rate
step_size = 0.02  # 50 frames per second
simulation_time = 10.0  # Total simulation time

# Simulation loop
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    # Update the vehicle dynamics
    system.DoStepDynamics(step_size)
    driver.Update(driver.GetInput(), step_size)

    # Update the camera position to follow the vehicle
    camera.SetPosition(vehicle.GetChassisPosition() + chrono.ChVectorD(0, -5, 2))
    camera.SetTargetPosition(vehicle.GetChassisPosition())

    # Check for user input to control the vehicle
    if vis.GetDevice().isKeyPressed(chrono.irrlicht.KEY_KEY_W):
        driver.SetThrottle(1.0)
    elif vis.GetDevice().isKeyPressed(chrono.irrlicht.KEY_KEY_S):
        driver.SetThrottle(-1.0)
    else:
        driver.SetThrottle(0.0)

    if vis.GetDevice().isKeyPressed(chrono.irrlicht.KEY_KEY_A):
        driver.SetSteering(-1.0)
    elif vis.GetDevice().isKeyPressed(chrono.irrlicht.KEY_KEY_D):
        driver.SetSteering(1.0)
    else:
        driver.SetSteering(0.0)

    if vis.GetDevice().isKeyPressed(chrono.irrlicht.KEY_KEY_SPACE):
        driver.SetBraking(1.0)
    else:
        driver.SetBraking(0.0)

    # Exit condition
    if vis.GetDevice().isKeyPressed(chrono.irrlicht.KEY_ESCAPE):
        break

# Clean up
vis.Close()
```

### Explanation:
1. **Initialization**: The script initializes the PyChrono environment and sets up the physical system and visualization using Irrlicht.
2. **Vehicle Setup**: The FEDA vehicle is loaded with specific parameters for position, orientation, tire model, and contact method.
3. **Terrain Setup**: A rigid terrain with a custom texture is created and added to the system.
4. **Camera Setup**: The camera is set to follow the vehicle from a designated position.
5. **Driver System**: An interactive driver system is integrated to control the vehicle’s steering, throttle, and braking.
6. **Simulation Loop**: The simulation runs at 50 frames per second, updating the vehicle dynamics and rendering the scene in real time. User input is handled to control the vehicle.

Make sure to replace `'path/to/chrono/data'` and `'terrain/texture.png'` with the actual paths to your Chrono data files and texture image, respectively.

This script provides a basic framework and can be further customized based on specific requirements and additional features.
