  - Sensor creation uses `chrono.ChCameraSensor()` and sets pose, FoV, resolution, and projection type. However, the syntax used for FoV and projection type is incorrect:

    ```python

    camera_sensor.SetProjectionType(chrono.ChCameraSensor::e_PERSPECTIVE)
    ```

    - Python does not use `::` for scope resolution; this is C++ syntax.

      ```python
      camera_sensor.SetFoV(chrono.ChFov(chrono.ChFov.e_HORIZONTAL, 60 * chrono.CH_C_DEG_TO_RAD))
      camera_sensor.SetProjectionType(chrono.ChCameraSensor.e_PERSPECTIVE)
      ```
