Certainly! Below is a PyChrono simulation script that models the dynamic behavior of a Jeffcott rotor using an Isogeometric Analysis (IGA) beam. The script includes the creation of a beam, attachment of a flywheel at its center, and a rotational motor that drives one end of the beam. The visual setup includes FEM visualization and an Irrlicht window to observe the dynamics of the beam and flywheel system.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.fem as chronofem
import pychrono.fea as chronofea
import pychrono.engine as engine

# Initialize the PyChrono environment
chrono.SetChronoDataPath('path/to/chrono/data')

# Create the system
system = chrono.ChSystemNSC()

# Create the Irrlicht visualization system
visualization = chronoirr.ChIrrApp()
visualization.AddSystem(system)
visualization.SetWindowTitle('Jeffcott Rotor with IGA Beam')
visualization.SetWindowSize(1024, 768)
visualization.SetTryUseShaders(True)
visualization.SetPauseOnLoad(True)
visualization.SetShowInfos(True)
visualization.SetShowStats(True)
visualization.SetShowFPS(True)
visualization.SetShowAxis(3)

# Create the beam using IGA
beam = chronofem.ChBeamIGA()
beam.SetName('IGA Beam')
beam.SetLength(1.0)  # Length of the beam
beam.SetCrossSectionArea(0.01)  # Cross-sectional area
beam.SetYoungModulus(210e9)  # Young's modulus
beam.SetDensity(7800)  # Density
beam.SetPoissonRatio(0.3)  # Poisson's ratio

# Add the beam to the system
system.Add(beam)

# Create the flywheel and attach it to the center of the beam
flywheel = chrono.ChBodyEasySphere(0.1, 1000, True, True)
flywheel.SetPos(chrono.ChVectorD(0.5, 0, 0))  # Center of the beam
flywheel.SetName('Flywheel')
system.Add(flywheel)

# Attach the flywheel to the beam
constraint = chrono.ChLinkLockLock()
constraint.Initialize(flywheel, beam.GetBody())
system.Add(constraint)

# Create the rotational motor to drive one end of the beam
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(beam.GetBody(), chrono.ChFrameD(chrono.ChVectorD(0, 0, 0)))
motor.SetMotorFunction(chrono.ChFunction_Const(chrono.ChVectorD(10)))  # Constant speed of 10 rad/s
system.Add(motor)

# Create the FEM visualization
visualization_system = chronofea.ChVisualizationFEAbeam()
visualization_system.SetFEAbeam(beam)
visualization_system.SetSmoothFaces(True)
visualization_system.SetDrawMode(chronofea.ChVisualizationFEAbeam.DrawMode_WIREFRAME)
visualization_system.SetWireframeThickness(2)
visualization_system.SetLineColor(chrono.ChColor(0.1, 0.1, 0.1))
visualization_system.SetSurfaceColor(chrono.ChColor(0.1, 0.1, 0.1))
visualization_system.SetPerElementColor(True)
visualization.AddVisualSystem(visualization_system)

# Run the simulation
visualization.SetTimestep(0.01)
while visualization.Run():
    system.DoStepDynamics(visualization.GetTimestep())

# Clean up
visualization.Close()
```

### Explanation:
1. **Initialization**:
   - The PyChrono environment is initialized with `chrono.SetChronoDataPath`.
   - The main system (`ChSystemNSC`) and visualization system (`ChIrrApp`) are created.

2. **Beam Creation**:
   - An IGA beam is created using `ChBeamIGA` with specified properties such as length, cross-sectional area, Young's modulus, density, and Poisson's ratio.
   - The beam is added to the system.

3. **Flywheel Creation and Attachment**:
   - A flywheel is created as a sphere and positioned at the center of the beam.
   - The flywheel is attached to the beam using a `ChLinkLockLock` constraint.

4. **Rotational Motor**:
   - A rotational motor is created to drive one end of the beam with a constant speed of 10 rad/s.

5. **Visualization**:
   - The FEM visualization of the beam is set up using `ChVisualizationFEAbeam`.
   - The Irrlicht window is configured to visualize the dynamics of the beam and flywheel system.

6. **Simulation Loop**:
   - The simulation runs in a loop, updating the system dynamics and rendering the visualization.

### Note:
- Ensure that the path to the Chrono data directory is correctly set in `chrono.SetChronoDataPath`.
- Adjust the parameters such as beam length, cross-sectional area, Young's modulus, density, and Poisson's ratio as needed for your specific application.
