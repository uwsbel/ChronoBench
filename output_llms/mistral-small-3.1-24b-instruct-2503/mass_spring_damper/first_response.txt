To create a PyChrono simulation script that demonstrates a single mass-spring-damper system using `ChLinkTSDA` and includes Irrlicht visualization, follow these steps:

1. Initialize the PyChrono environment and core components.
2. Add the required physical systems and objects (mass, spring, damper).
3. Set necessary default parameters such as positions, forces, and interactions.
4. Configure Irrlicht visualization with appropriate lighting and camera settings.

Here's the complete script:

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr

# Initialize the Chrono::Engine system
system = chrono.ChSystemNSC()

# Create a ground body
ground = chrono.ChBody()
ground.SetPos(chrono.ChVectorD(0, -1, 0))
ground.SetBodyFixed(True)
system.AddBody(ground)

# Create a mass body
mass = chrono.ChBody()
mass.SetMass(10)  # 10 kg
mass.SetPos(chrono.ChVectorD(0, 0, 0))
mass.SetCollide(True)
system.AddBody(mass)

# Create a visual shape for the mass
mass_shape = chrono.ChSphereShape()
mass_shape.GetRadius() = 0.2
mass_shape.GetMaterialSurface().SetFriction(0.6)
mass_shape.GetMaterialSurface().SetRestitution(0.2)
mass.GetAssets().Add(mass_shape)

# Create a spring-damper link between the mass and the ground
spring_damper = chrono.ChLinkTSDA()
spring_damper.Initialize(mass, ground, False, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 0))
spring_damper.Set_SpringK(1000)  # Spring stiffness
spring_damper.Set_DamperR(10)    # Damping coefficient
system.AddLink(spring_damper)

# Create a visual shape for the spring
spring_shape = chrono.ChCylinderShape()
spring_shape.GetCylinderGeometry().p1 = chrono.ChVectorD(0, -0.5, 0)
spring_shape.GetCylinderGeometry().p2 = chrono.ChVectorD(0, 0.5, 0)
spring_shape.GetCylinderGeometry().rad = 0.02
spring_shape.GetMaterialSurface().SetFriction(0.6)
spring_shape.GetMaterialSurface().SetRestitution(0.2)
spring_shape.GetMaterialSurface().SetUseTexture(True)
spring_shape.GetMaterialSurface().SetTextureFilename("data/textures/white.jpg")
spring_shape.SetChColor(chrono.ChColor(0.2, 0.2, 0.2))
spring_shape.GetCylinderGeometry().h = 0.5
spring_shape.GetCylinderGeometry().rad = 0.02

# Create a visualization system
visualization = chronoirr.ChVisualSystemIrrlicht()
visualization.AttachSystem(system)
visualization.SetWindowSize(800, 600)
visualization.SetWindowTitle('Mass-Spring-Damper System')
visualization.Initialize()
visualization.AddLogo()
visualization.AddSkyBox()
visualization.AddCamera(chrono.ChVectorD(1, 1, 1), chrono.ChVectorD(0, 0, 0))
visualization.AddTypicalLights()

# Set the camera position and target
camera = visualization.GetSceneManager().getActiveCamera()
camera.setPosition(chrono.ChVectorD(1, 1, 1))
camera.setTarget(chrono.ChVectorD(0, 0, 0))

# Run the simulation
while visualization.Run():
    system.DoStepDynamics(0.01)
    visualization.Render()

# Close the visualization
visualization.Close()
```

### Explanation:

1. **Initialization**:
   - `chrono.ChSystemNSC()`: Creates the Chrono::Engine system.
   - `chrono.ChBody()`: Creates bodies for the ground and the mass.
   - `chrono.ChLinkTSDA()`: Creates the spring-damper link between the mass and the ground.

2. **Physical Systems and Objects**:
   - The ground is fixed, and the mass has a specified mass and position.
   - Visual shapes are added to the mass and spring for visualization.

3. **Default Parameters**:
   - Spring stiffness (`Set_SpringK`) and damping coefficient (`Set_DamperR`) are set to default values.

4. **Irrlicht Visualization**:
   - `chronoirr.ChVisualSystemIrrlicht()`: Initializes the Irrlicht visualization system.
   - Camera settings and lighting are configured for better visualization.
   - The simulation loop runs with a time step of 0.01 seconds.

This script sets up a basic mass-spring-damper system with visualization, allowing you to observe the dynamics of the system in real-time.
