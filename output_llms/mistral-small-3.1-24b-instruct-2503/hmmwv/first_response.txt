Certainly! Below is a PyChrono script to create a simulation of a full HMMWV on a flat rigid terrain using Irrlicht for visualization. The script initializes the PyChrono environment, sets up the HMMWV with the specified parameters, configures the terrain, and sets up an interactive driver system.

```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.postprocess as postprocess
import pychrono.utils as utils

# Initialize the PyChrono environment
chrono.SetChronoDataPath(chrono.GetChronoDataPath())

# Create the system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization
visualization = chronoirr.ChVisualSystemIrrlicht()
visualization.AttachSystem(system)
visualization.SetWindowSize(1280, 720)
visualization.SetWindowTitle('HMMWV Simulation')
visualization.Initialize()
visualization.AddTypicalSky()
visualization.AddTypicalLogo(chrono.GetChronoDataFile('logo_pychrono_small.png'))
visualization.AddLightWithShadow(chrono.ChVectorD(1.0, 1.0, 1.0), chrono.ChVectorD(0.5, 0.5, 0.5), 1000, 1000, 100, 40, 512)

# Create the HMMWV vehicle
hmmwv = utils.Create_HMMWV_Vehicle(system)
hmmwv.SetChassisCollide(True)
hmmwv.SetChassisFixed(False)
hmmwv.SetInitPosition(chrono.ChVectorD(0, 1, 0), chrono.ChQuaternionD(1, 0, 0, 0))
hmmwv.SetContactMethod(chrono.ChMaterialSurface.NSC)
hmmwv.SetTireModelType(chrono.ChVehicleTireModel.TMEASY)

# Create the rigid terrain
terrain = chrono.ChRigidTerrain()
terrain.SetTexture(chrono.GetChronoDataFile('textures/concrete.jpg'), 1000, 1000)
terrain.SetPlane(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
system.Add(terrain)

# Create the driver system
driver = chrono.ChDriver()
driver.Initialize(hmmwv, system)
driver.SetSteeringController(chrono.ChSteeringControllerType.PI)
driver.SetSteeringGain(1.0)
driver.SetSteeringTimeDelay(0.1)
driver.SetSteeringRelaxation(0.5)
driver.SetThrottleController(chrono.ChThrottleControllerType.PID)
driver.SetThrottleGain(1.0)
driver.SetThrottleTimeDelay(0.1)
driver.SetBrakingController(chrono.ChBrakingControllerType.PID)
driver.SetBrakingGain(1.0)
driver.SetBrakingTimeDelay(0.1)

# Set up the simulation loop
run_time = 10.0  # seconds
step_size = 1.0 / 50.0  # 50 frames per second
time = 0.0
while time < run_time:
    time = system.GetChTime()
    system.DoStepDynamics(step_size)
    visualization.Render()
    visualization.Update()
    chrono.sleep_if_necessary(step_size)

# Close the visualization
visualization.Close()
```

### Explanation:
1. **Initialization**:
   - The PyChrono environment is initialized, and the system is created with gravity set to Earth's standard.
   - The Irrlicht visualization system is set up with typical sky, logo, and lighting.

2. **HMMWV Vehicle**:
   - The HMMWV vehicle is created using the `utils.Create_HMMWV_Vehicle` function.
   - The vehicle's chassis is set to collide and is not fixed.
   - The initial position and orientation of the vehicle are set.
   - The contact method is set to NSC (Non-Smooth Contact), and the tire model is set to TMEASY.

3. **Rigid Terrain**:
   - A flat rigid terrain is created with a texture applied.
   - The terrain is added to the system.

4. **Driver System**:
   - An interactive driver system is set up for steering, throttle, and braking.
   - PID controllers are configured for steering, throttle, and braking.

5. **Simulation Loop**:
   - The simulation runs for a specified duration (`run_time`) at 50 frames per second.
   - The system dynamics are updated, and the scene is rendered in each step.

6. **Cleanup**:
   - The visualization window is closed after the simulation completes.

This script should provide a basic setup for simulating an HMMWV on a flat terrain with interactive controls and visualization. Adjustments can be made to parameters and configurations as needed for specific use cases.
