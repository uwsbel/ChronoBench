  According to the API documentation, the `Initialize` method expects a `chrono.ChCoordsysD` (or `ChCoordsys`) object, not a `ChFramed`. `ChFramed` is not a standard PyChrono class for joint frames.


  or equivalently:

  ```python
  sph_1.Initialize(ground, pend_1, chrono.ChCoordsysD(chrono.ChVector3d(0, 0, 1), chrono.ChQuaterniond(1, 0, 0, 0)))
  ```
