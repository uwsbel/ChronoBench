The API documentation and typical usage use `chrono.ChCoordsysD` or `chrono.ChCoordsys` for frames. This is a significant issue because `ChFramed` does not exist in PyChrono API and will cause runtime errors.  
  **Deduct 15 points for incorrect API usage here.**

- **Visual Shape Creation:**  
  `chrono.ChVisualShapeBox(0.03, 0.25, 0.12)` is called with three floats directly. According to the API, `ChVisualShapeBox` expects a `ChVector3d` for size, e.g., `chrono.ChVisualShapeBox(chrono.ChVector3d(x,y,z))`. The code passes three floats directly, which is incorrect and will cause errors.  
  Similarly, `chrono.ChVisualShapeBox(K, 0.03, 0.03)` has the same issue.  
  **Deduct 15 points for incorrect visual shape creation.**
