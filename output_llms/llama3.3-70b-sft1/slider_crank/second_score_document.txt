- **Joint Initialization Frames:**  
  The joints are initialized with `chrono.ChFramed(...)`. The API expects `chrono.ChCoordsysD` or `chrono.ChCoordsys` for frames. `ChFramed` is not a standard PyChrono class or alias. This is likely a typo or misunderstanding. The correct call should be:

  ```python
  chrono.ChCoordsysD(position, rotation)
  ```

  or simply:

  ```python
  chrono.ChCoordsys(position)
  ```

  Using `chrono.ChFramed` will cause an error or undefined behavior.
