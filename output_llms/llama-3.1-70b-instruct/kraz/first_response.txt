Here's a Python script that implements the PyChrono simulation based on the provided instructions:

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chrono_vehicle

# Initialize the PyChrono environment and core components
system = chrono.ChSystemNSC()

# Create the Kraz vehicle
vehicle = chrono_vehicle.Kraz()
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(chrono.ChVectorD(0, 0, 1.5))
vehicle.SetInitRotation(chrono.ChQuaternionD(1, 0, 0, 0))
vehicle.Initialize(system)

# Create the rigid terrain
terrain = chrono.ChBodyEasyBox(system, 10, 10, 1, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, 0, -1))
terrain.SetMaterial(chrono.ChMaterialSurfaceNSC())
terrain.GetMaterial().SetFriction(0.9)
terrain.GetMaterial().SetRestitution(0.1)

# Create the driver system for vehicle control
driver = chrono_vehicle.ChIrrlichtDriver(vehicle.GetPart(chrono_vehicle.Kraz.Id.chassis))
driver.SetTrackMode(chrono_vehicle.ChIrrlichtDriver.TrackingMode.TRACKING_MODE_CAMERA_RIG)
driver.SetZDistance(5)
driver.SetRotFactor(0.1)
driver.SetYaw(chrono.ChAngleD(chrono.CH_C_PI / 4))
driver.SetPitch(chrono.ChAngleD(chrono.CH_C_PI / 4))
driver.SetPos(chrono.ChVectorD(0, 0, 2))

# Create the real-time visualization using Irrlicht
visual_system = chronoirr.ChVisualSystemIrrlicht(system)
visual_system.SetWindowSize(1024, 768)
visual_system.SetWindowTitle("Kraz Vehicle Simulation")
visual_system.AddCamera(chronoirr.ChCamera(chrono.ChVectorD(0, 0, 1.5), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0)))
visual_system.AddTypicalLights()

# Add the vehicle and terrain to the visual system
visual_system.AddVehicle(vehicle)
visual_system.Add(terrain)

# Set the simulation step and frame rate
system.SetStep(0.01)
visual_system.SetStep(0.01)

# Simulation loop
while visual_system.Run():
    system.DoStepDynamics(0.01)
    visual_system.BeginScene()
    visual_system.DrawAll()
    visual_system.EndScene()
```

This script initializes the PyChrono environment and creates the Kraz vehicle with specified initial conditions. It also sets up a rigid terrain with defined friction and restitution, and initializes a driver system for vehicle control. The script then creates a real-time visualization using Irrlicht with camera settings and lighting. Finally, it implements a simulation loop that synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.
