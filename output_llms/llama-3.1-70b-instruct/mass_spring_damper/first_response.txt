Here is the PyChrono script that meets the requirements:
```python
# Import necessary modules
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("./chrono_data/")

# Create the simulation system
system = chrono.ChSystemNSC()

# Create the ground body
ground = chrono.ChBodyEasyBox(system, 10, 1, 10, 1000, True, True)

# Create the mass body
mass = chrono.ChBodyEasySphere(system, 1, 1000, True, True)
mass.SetPos(chrono.ChVectorD(0, 5, 0))

# Create the mass-spring-damper system using ChLinkTSDA
link = chrono.ChLinkTSDA()
link.Initialize(ground, mass, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 5, 0))
link.SetSpringCoefficient(100)
link.SetDampingCoefficient(5)
link.SetCompliance(0.01)
system.Add(link)

# Add visual shapes for the mass and spring
mass.AddVisualShape(chrono.ChVisualShape(chrono.ChVisualShape::E_SHAPECYLINDER, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0), 0.5))
link.AddVisualShape(chrono.ChVisualShape(chrono.ChVisualShape::E_SHAPETRIMESH, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0), 0.1))

# Create the Irrlicht visualization
irrApp = chronoirr.ChVisualSystemIrrlicht()
irrApp.SetWindowSize(800, 600)
irrApp.SetWindowTitle("Mass-Spring-Damper System")
irrApp.AddCamera(chrono.ChVectorD(0, 5, -10), chrono.ChVectorD(0, 2, 0))
irrApp.AddTypicalLights()
irrApp.AddSkyBox()
irrApp.AddGrid(chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1), 10, 10)

# Simulation loop
while irrApp.Run():
    system.DoStepDynamics(0.01)
    irrApp.BeginScene()
    irrApp.DrawAll()
    irrApp.EndScene()
```
This script initializes the PyChrono environment, creates a mass-spring-damper system using `ChLinkTSDA`, and sets up the Irrlicht visualization with a camera, lighting, and visual shapes for the mass and spring. The simulation loop runs until the user closes the visualization window.

Note that this script uses the `ChSystemNSC` class, which is a non-smooth contact (NSC) system that can handle contacts and collisions between bodies. The `ChLinkTSDA` class is used to create the mass-spring-damper system, which connects the mass to the ground. The default linear spring-damper parameters are used for the `ChLinkTSDA` connection.
