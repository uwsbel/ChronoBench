```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh

# Initialize the PyChrono environment
chrono.SetChronoDataPath('./')

# Create the Chrono system
system = chrono.ChSystemNSC()

# Set the gravity
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body
ground = chrono.ChBodyEasyBox(system, 10, 2, 10, 1000, True, chrono.ChVectorD(0, -3, 0))
ground.SetBodyFixed(True)

# Create the Turtlebot robot
turtlebot = veh.Turtlebot(system, chrono.ChVectorD(0, 1, 0), chrono.ChQuaternionD(1, 0, 0, 0))

# Set the motor control
motor_control = veh.TurtlebotMotorControl(turtlebot)

# Create the Irrlicht visualization
viz = chronoirr.ChVisualSystemIrrlicht()
viz.SetWindowSize(800, 600)
viz.SetWindowTitle('Turtlebot Simulation')
viz.SetCamera(chrono.ChVectorD(0, 2, -5), chrono.ChVectorD(0, 1, 0))
viz.AddTypicalLights()

# Add the objects to the visualization
viz.Add(turtlebot.GetChassisBody())
viz.Add(ground)

# Set the simulation loop parameters
t_step = 0.01
t_end = 10

# Simulation loop
t = 0
while t < t_end:
    # Control the motors
    if t < 2:
        motor_control.SetMotorTorque(10, 10)
    elif t < 4:
        motor_control.SetMotorTorque(-10, 10)
    elif t < 6:
        motor_control.SetMotorTorque(10, -10)
    else:
        motor_control.SetMotorTorque(0, 0)

    # Update the simulation
    system.DoStepDynamics(t_step)

    # Update the visualization
    viz.Render()

    # Increment time
    t += t_step
```

This script initializes the PyChrono environment, sets up the Chrono system with gravity and a ground body, and creates a Turtlebot robot with a specific position and orientation. It then sets up a real-time visualization using Irrlicht with camera settings and lighting. The simulation loop controls the Turtlebot's motors to turn left and right at specified times, updating and rendering the robot at each timestep.
