### 1. Completeness (40 points)

- **Contact Material Setup:**  
  The script creates a `chrono.ChMaterialSurfaceNSC()` and sets friction, damping, compliance, and complianceT.  
  **Issue:** According to the documentation, the correct class for NSC contact materials is `chrono.ChContactMaterialNSC()`, not `chrono.ChMaterialSurfaceNSC()`. This is a significant API misuse (see correctness below).  
  Also, the system does not have a method `SetContactMaterial()` in the PyChrono API documentation. Contact materials are typically assigned to bodies or collision shapes, not globally to the system.  
  **Deduction:** Missing correct contact material setup and incorrect usage → Deduct 15 points.

- **Body Creation:**  
  The script attempts to create a body from a mesh using `chrono.ChBodyEasyMesh(mysystem, mesh, False, 1000, 1e-3)`.  
  **Issue:** There is no `ChBodyEasyMesh` constructor documented. The documented "easy" bodies are `ChBodyEasySphere`, `ChBodyEasyBox`, etc. For mesh-based bodies, one typically uses `ChBody()` and then adds collision and visual shapes manually, or uses `ChTriangleMeshShape` for visualization and collision.  
  Also, the first argument to `ChBodyEasy*` constructors is not the system, but parameters like size, density, visualize, collision, and material.  
  **Deduction:** Missing proper body creation from mesh and incorrect constructor usage → Deduct 15 points.
