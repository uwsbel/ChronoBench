Here's a Python script that implements the PyChrono simulation based on the provided instructions:

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chrono_vehicle

# Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("/path/to/data")

# Create the simulation
mysim = chrono.ChSystemNSC()

# Create the M113 vehicle
m113 = chrono_vehicle.ChM113()
m113.SetChassisCollisionModel(chrono_vehicle.ChVehicleCollisionModel.COLLISION_MESH)
m113.SetChassisSimplified(false)
m113.SetSuspensionTravel(0.4)
m113.SetTireModel(chrono_vehicle.ChTireModel.TIRE_RIGID_RING)

# Set initial conditions for the vehicle
m113.SetPos(chrono.ChVectorD(0, 0, 1.5))
m113.SetRot(chrono.ChQuaternionD(1, 0, 0, 0))

# Add the vehicle to the simulation
mysim.Add(m113.GetPart())

# Create the rigid terrain
terrain = chrono.ChBodyEasyBox(mysim, 10, 10, 1, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, 0, 0))
terrain.SetMaterial(chrono.ChMaterialSurfaceNSC())
terrain.GetMaterial().SetFriction(0.9)
terrain.GetMaterial().SetRestitution(0.1)

# Add the terrain to the simulation
mysim.Add(terrain)

# Create the driver system for vehicle control
driver = chrono_vehicle.ChIrrlichtDriver()
driver.SetVehicle(m113)
driver.SetSteering(0.0)
driver.SetThrottle(0.0)

# Create the real-time visualization using Irrlicht
vis = chronoirr.ChVisualSystemIrrlicht(mysim)

# Set camera settings and lighting
vis.SetCamera(chrono.ChVectorD(0, 0, 1.5), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
vis.SetTypicalLigthing()
vis.AddTypicalLights()

# Set the visualization window size
vis.SetWindowSize(800, 600)

# Set the simulation timestep and duration
dt = 0.01
sim_duration = 10

# Simulation loop
while mysim.GetChTime() < sim_duration:
    # Synchronize and advance the vehicle, terrain, driver, and visual system
    driver.Synchronize(mysim.GetChTime())
    m113.Synchronize(mysim.GetChTime())
    terrain.Synchronize(mysim.GetChTime())
    vis.Synchronize(mysim.GetChTime())

    # Advance the simulation
    mysim.DoStepDynamics(dt)

    # Render the visualization
    vis.Render()

    # Sleep to maintain real-time execution
    chrono.ChSleep(dt)
```

This script initializes the PyChrono environment, creates an M113 vehicle with specific initial conditions, sets up a rigid terrain with defined friction and restitution, and creates a driver system for vehicle control. It also sets up a real-time visualization using Irrlicht with camera settings and lighting. The simulation loop synchronizes and advances the vehicle, terrain, driver, and visual system at each timestep, maintaining real-time execution.
