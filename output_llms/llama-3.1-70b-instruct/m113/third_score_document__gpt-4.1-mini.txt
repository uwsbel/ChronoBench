  The box is created with `ChBodyEasyBox(vehicle.GetSystem(), 10, 2, 1, 1000, True, False)`.

  `ChBodyEasyBox(lengthX, lengthY, lengthZ, density, visualize, collision, material)`  
  Here, the first argument is `vehicle.GetSystem()`, which is incorrect. The system is not the first argument for `ChBodyEasyBox`. The correct call should be:  
  ```python
  box = chrono.ChBodyEasyBox(10, 2, 1, 1000, True, False)
  ```
  Then the box should be added to the system via `vehicle.GetSystem().Add(box)`.
