Here's a Python script that implements the simulation of a simple pendulum using PyChrono with Irrlicht for visualization.

```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr

# Create the simulation system and add a contact material
mysystem = chrono.ChSystemNSC()
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.4)
material.SetRestitution(0.1)
material.SetYoungModulus(1e8)
material.SetRoughness(0.01)

# Create the ground body
ground = chrono.ChBodyEasyBox(mysystem, 4, 1, 4, 1000, True, material)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
ground.SetBodyFixed(True)

# Create the pendulum body
pendulum = chrono.ChBodyEasyCylinder(mysystem, 0.5, 1, 1000, True, material)
pendulum.SetPos(chrono.ChVectorD(0, 1, 0))

# Create a revolute joint between the pendulum and the ground
revolute_joint = chrono.ChLinkRevolute()
revolute_joint.Initialize(ground, pendulum, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1))
mysystem.Add(revolute_joint)

# Create the Irrlicht visualization system
visualsystem = chronoirr.ChVisualSystemIrrlicht(mysystem)
visualsystem.SetWindowSize(800, 600)
visualsystem.SetWindowTitle("Simple Pendulum Simulation")
visualsystem.Initialize()

# Set the camera position and orientation
camera = visualsystem.GetCamera()
camera.SetPosition(chrono.ChVectorD(0, 1, 3))
camera.SetLookAt(chrono.ChVectorD(0, 1, 0))

# Create a timer to periodically log the pendulum's position and velocity
import time
start_time = time.time()

# Simulation loop
while visualsystem.Run():
    mysystem.DoStepDynamics(0.01)

    # Periodically log the pendulum's position and velocity
    current_time = time.time()
    if current_time - start_time >= 1:
        start_time = current_time
        print("Pendulum position: ", pendulum.GetPos())
        print("Pendulum velocity: ", pendulum.GetPos_dt())
```

This script initializes the PyChrono environment, creates the required physical systems and objects (ground body, pendulum, and revolute joint), sets necessary default parameters, and uses the Irrlicht visualization system to render the simulation. The pendulum's position and velocity are periodically logged to the console.
