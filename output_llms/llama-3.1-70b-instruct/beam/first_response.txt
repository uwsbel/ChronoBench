Here's a Python script that initializes a PyChrono environment and sets up a physical system with beam finite elements, visualization, and a simulation loop using the Irrlicht engine:

```python
# Import necessary modules
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.fea as fea

# Create the simulation system and set the default units
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity acceleration

# Create a mesh with beam finite elements
beam_mesh = fea.ChBeamSectionEuler()
beam_mesh.SetYoungModulus(2e11)  # Young's modulus in Pa
beam_mesh.SetArea(1e-4)  # Cross-sectional area in m^2
beam_mesh.SetIyy(1e-6)  # Moment of inertia about y-axis in m^4
beam_mesh.SetIzz(1e-6)  # Moment of inertia about z-axis in m^4

# Create nodes for the beam
node1 = fea.ChNodeFEAxyzrot(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.Q_from_AngX(0)))
node2 = fea.ChNodeFEAxyzrot(chrono.ChCoordsysD(chrono.ChVectorD(1, 0, 0), chrono.Q_from_AngX(0)))

# Create beam elements
beam1 = fea.ChElementBeamEulerBernoulli(beam_mesh, node1, node2)

# Add the beam to the system
system.Add(beam1)

# Add visualization
application = chronoirr.ChVisualSystemIrrlicht()
application.SetWindowSize(1024, 768)
application.SetWindowTitle("PyChrono Beam Simulation")
application.AddTypicalLights()
application.AddSkyBox()
application.AddCamera(chrono.ChVectorD(0, 0, 5), chrono.ChVectorD(0, 0, 0))

# Add visualization assets
application.AssetBindAll()
application.AssetUpdateAll()

# Run the simulation loop
while application.Run():
    system.DoStepDynamics(0.01)
    application.BeginScene()
    application.DrawAll()
    application.EndScene()

# Delete the visualization system and the simulation system
del application
del system
```

This script creates a simple simulation with a single beam element, sets up visualization using the Irrlicht engine, and runs the simulation loop. The beam has a Young's modulus of 2e11 Pa, a cross-sectional area of 1e-4 m^2, and moments of inertia about the y-axis and z-axis of 1e-6 m^4. The simulation runs with a time step of 0.01 seconds.

Note that this script assumes you have PyChrono and the Irrlicht engine installed and configured properly. You may need to modify the script to suit your specific requirements and environment.
