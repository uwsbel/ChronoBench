### 2. Correctness (30 points)

- **Use of `ChContactMaterialNSC` in `ChBodyEasySphere`:**  
  According to the API, `ChBodyEasySphere` expects a `ChMaterialSurface` object, but `ChContactMaterialNSC` is a contact material, not a surface material. This is a subtle but important distinction. The correct approach is to create a `ChMaterialSurfaceNSC` or `ChMaterialSurfaceSMC` and assign friction to it.  
  This misuse could lead to incorrect contact behavior or runtime errors.  
  **Deduct 15 points for incorrect API usage.**

- **Setting velocities directly on bodies:**  
  `SetVel` is used, which is acceptable for initial velocity.  
  **No deduction.**

- **Use of `SetUseGyroTorque(False)`:**  
  This disables gyroscopic torque. While not necessarily wrong, it should be justified. No error here.  
  **No deduction.**

- **Gravitational acceleration set to zero:**  
  The system gravity is set to zero, which is consistent with the custom gravitational force applied manually.  
  **No deduction.**

- **Manual gravitational force calculation:**  
  The code calculates pairwise gravitational forces and applies them correctly with `AccumulateForce`.
