```python
# Import necessary modules
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as veh

# Create the ChronoEngine physical system
system = chrono.ChSystemNSC()

# Set the gravity
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body
ground = chrono.ChBodyEasyBox(system, 10, 1, 10, 1000, True, chrono.ChVectorD(0, -1, 0))
ground.SetBodyFixed(True)

# Create the Viper rover
viper = veh.ViperRover(system, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.Q_from_AngX(chrono.CH_C_PI_2)))

# Create the driver system
driver = veh.ChIrrlichtDriver(viper)

# Set the driver parameters
driver.SetTrackSmoothSteering(True)
driver.SetSteeringSmoothSpeed(chrono.CH_C_PI / 4)
driver.SetSteeringMin(chrono.CH_C_PI / 4)
driver.SetSteeringMax(chrono.CH_C_PI / 2)

# Create the Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht(system)

# Set the camera settings
vis.SetCamera(chrono.ChVectorD(0, 1.5, -3), chrono.ChVectorD(0, 1, 0), chrono.ChVectorD(0, 1, 0))

# Set the lighting
vis.AddTypicalLights()

# Create a simulation loop
time_end = 10
tstep = 0.01
time = 0

while time < time_end:
    # Update the driver's steering
    driver.SetSteering(chrono.CH_C_PI / 4 * chrono.ChMath.Cos(time))

    # Update the simulation
    system.DoStepDynamics(tstep)

    # Render the visualization
    vis.BeginScene()
    vis.DrawAll()
    vis.EndScene()

    # Increment the time
    time += tstep

# Wait for the simulation to finish
while vis.Run():
    vis.BeginScene()
    vis.DrawAll()
    vis.EndScene()
```

This script initializes a PyChrono simulation with a Viper rover on a rigid terrain. The simulation includes gravity, a ground body, and the Viper rover with its driver. A real-time visualization is created using Irrlicht, and the simulation loop updates the rover's steering over a specified time period. The script also includes camera settings and lighting for the visualization.
