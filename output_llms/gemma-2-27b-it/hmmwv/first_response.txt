```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# ---------------------------------------------------------------------
#
#  Create the simulation system and set up Irrlicht visualization
#
# ---------------------------------------------------------------------

system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

vis = chronoirr.ChIrrApp(system, "HMMWV Simulation", chronoirr.dimension2du(1280, 720))
vis.AddTypicalSky()
vis.AddTypicalCamera(chrono.ChVectorD(0, 2, -5), chrono.ChVectorD(0, 0, 0))
vis.SetSymbolSize(0.1)
vis.SetShowInfos(True)

# ---------------------------------------------------------------------
#
#   Create the HMMWV vehicle
#
# ---------------------------------------------------------------------

# Vehicle chassis
chassis = chrono.ChBody()
chassis.SetBodyFixed(False)
chassis.SetMass(2500)
chassis.SetInertiaXX(chrono.ChVectorD(1000, 2000, 1500))
chassis.SetPos(chrono.ChVectorD(0, 1, 0))

# Add a visualization shape for the chassis
chassis_vis = chronoirr.ChBodySceneNode(chassis, vis.GetSceneManager())
chassis_vis.add_primitive(chrono.ChCylinderShape(1.5, 2), chrono.ChColor(0.8, 0.2, 0.2))

# Add wheels
wheel_radius = 0.4
wheel_width = 0.2

wheels = []
for i in range(4):
    wheel = chrono.ChWheel4()
    wheel.SetSystem(system)
    wheel.SetBody(chassis)
    wheel.SetContactMethod(chrono.ChContactMethod_NSC)
    wheel.SetTireModel(chrono.ChTMeasyTire())

    # Set wheel parameters (adjust as needed)
    wheel.SetRadius(wheel_radius)
    wheel.SetWidth(wheel_width)
    wheel.SetFriction(2.0)

    # Position wheels
    if i < 2:
        wheel.SetPos(chrono.ChVectorD(-1.2 + i * 2.4, -wheel_radius, 1.2))
    else:
        wheel.SetPos(chrono.ChVectorD(-1.2 + (i - 2) * 2.4, -wheel_radius, -1.2))

    wheels.append(wheel)

    # Add visualization for the wheels
    wheel_vis = chronoirr.ChBodySceneNode(wheel.GetBody(), vis.GetSceneManager())
    wheel_vis.add_primitive(chrono.ChCylinderShape(wheel_radius, wheel_width), chrono.ChColor(0.2, 0.2, 0.8))

# ---------------------------------------------------------------------
#
#   Create the terrain
#
# ---------------------------------------------------------------------

terrain = chrono.ChRigidTerrain()
terrain.SetSystem(system)
terrain.SetTexture(chrono.GetChronoDataPath() + 'terrain/textures/grass.jpg')
patch = chrono.ChRigidTerrain::Patch(terrain, 200, 200, 0.5)
patch.SetTexture(chrono.GetChronoDataPath() + 'terrain/textures/grass.jpg')
patch.SetHeight(0)

# ---------------------------------------------------------------------
#
#   Set up the driver system
#
# ---------------------------------------------------------------------

driver = chrono.ChDriver()
driver.SetSystem(system)
driver.SetSteering(0)
driver.SetThrottle(0)
driver.SetBraking(0)

# ---------------------------------------------------------------------
#
#   Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    vis.BeginScene()

    # Get input from keyboard/controller
    driver.SetSteering(vis.GetDeviceSteering())
    driver.SetThrottle(vis.GetDeviceThrottle())
    driver.SetBraking(vis.GetDeviceBraking())

    # Update the simulation
    system.DoStepDynamics(0.02)

    # Render the scene
    vis.EndScene()

    # Limit to 50 FPS
    chrono.ChTime.Wait(0.02)
```

**Explanation:**

1. **Initialization:** The script begins by importing necessary libraries, creating a Chrono system, and initializing the Irrlicht visualization.

2. **Vehicle Creation:**
   - A `ChBody` is created for the chassis with mass, inertia, and initial position.
   - Four `ChWheel4` objects are created, each representing a wheel. Parameters like radius, width, friction, and contact method are set.
   - Visualization shapes (cylinders) are added for both the chassis and wheels using Irrlicht.

3. **Terrain Creation:** A `ChRigidTerrain` object is created with a texture and dimensions.

4. **Driver System:** A `ChDriver` object is created to handle steering, throttle, and braking inputs.

5. **Simulation Loop:**
   - The main loop runs until the Irrlicht window is closed.
   - It reads input from the keyboard/controller and updates the driver system.
   - The Chrono system performs a dynamics step (`DoStepDynamics`).
   - The scene is rendered using Irrlicht.
   - The loop is limited to 50 FPS using `ChTime.Wait`.

**Notes:**



* This script provides a basic framework. You'll likely need to adjust parameters (mass, inertia, tire properties, etc.) to achieve realistic behavior.
* Consider adding more detailed vehicle components (suspension, steering system) for increased realism.
