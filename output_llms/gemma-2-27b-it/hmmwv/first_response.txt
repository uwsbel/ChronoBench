```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Create the simulation system and set up the terrain
#
# ---------------------------------------------------------------------

my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Set the simulation step size
my_system.SetTimestepperType(chrono.ChTimestepperType.CHRONO_TS_FIXED_STEP)
my_system.SetStep(1.0 / 50.0)

# Create the terrain
terrain_width = 200
terrain_length = 200
terrain = chrono.ChRigidTerrain(my_system, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0), chrono.Q_from_AngAxis(0, chrono.ChVectorD(0, 0, 1))))
patch = terrain.AddPatch(chrono.ChVectorD(-terrain_width / 2, 0, -terrain_length / 2),
                        chrono.ChVectorD(terrain_width / 2, 0, terrain_length / 2))
patch.SetTexture(chrono.GetChronoDataPath() + 'terrain/textures/grass.jpg')
patch.SetFriction(0.8)

# ---------------------------------------------------------------------
#
# Create the HMMWV vehicle
#
# ---------------------------------------------------------------------

vehicle = chronovehicle.ChVehicle(my_system)

# Set vehicle parameters
vehicle.SetChassisFixed(False)
vehicle.SetChassisPosition(chrono.ChVectorD(0, 1.5, 0))
vehicle.SetChassisBody(chrono.ChBodyEasyBox(2.5, 1.2, 0.8, 1000))
vehicle.SetInitWheelPos(chrono.ChVectorD(1.2, -0.6, 1.2), chrono.ChVectorD(-1.2, -0.6, 1.2), chrono.ChVectorD(1.2, -0.6, -1.2), chrono.ChVectorD(-1.2, -0.6, -1.2))
vehicle.SetWheelRadius(0.4)
vehicle.SetWheelWidth(0.2)

# Set tire model
for wheel in vehicle.GetWheels():
    wheel.SetTireModel(chronovehicle.TMEasyTire(wheel))

# Set contact method
vehicle.SetSuspensionType(chronovehicle.SuspensionType.DOUBLE_WISHBONE)
vehicle.SetContactMethod(chrono.ChContactMethod.NSC)

# ---------------------------------------------------------------------
#
# Create the Irrlicht visualization
#
# ---------------------------------------------------------------------

vis = chronoirr.ChIrrApp(my_system, chronoirr.driver. IrrlichtDevice())
vis.SetWindowSize(1280, 720)
vis.SetCameraPosition(chrono.ChVectorD(0, 20, 0))
vis.SetCameraLookAt(chrono.ChVectorD(0, 1, 0))

# Add vehicle visualization
vehicle.SetVisualizationType(chronovehicle.VisualizationType.PRIMITIVES)
vis.Add(vehicle)

# Add terrain visualization
vis.Add(terrain)

# ---------------------------------------------------------------------
#
# Create the interactive driver system
#
# ---------------------------------------------------------------------

driver = chronovehicle.ChDriver(vehicle)
driver.SetSteeringSpeed(1.0)
driver.SetThrottleSpeed(1.0)
driver.SetBrakingSpeed(1.0)

vis.SetDriver(driver)

# ---------------------------------------------------------------------
#
# Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    my_system.DoStepDynamics(1.0 / 50.0)

    driver.Update(vis.GetDeltaTime())
```

**Explanation:**

1. **Initialization:**
   - Creates a `ChSystemNSC` for the simulation.
   - Sets gravity and timestepper for real-time simulation at 50 FPS.
   - Creates a `ChRigidTerrain` with specified dimensions and texture.

2. **HMMWV Vehicle:**
   - Creates a `ChVehicle` object.
   - Sets chassis properties (position, fixed status, and shape).
   - Defines wheel positions, radius, and width.
   - Uses the `TMEasyTire` model for tire simulation.
   - Sets suspension type and contact method.

3. **Visualization:**
   - Creates a `ChIrrApp` for Irrlicht visualization.
   - Sets window size, camera position, and look-at point.
   - Adds the vehicle and terrain to the visualization.
   - Sets the vehicle visualization to use primitives.

4. **Interactive Driver:**
   - Creates a `ChDriver` object for interactive control.
   - Sets steering, throttle, and braking speeds.
   - Assigns the driver to the Irrlicht application for user input.

5. **Simulation Loop:**
   - Runs the Irrlicht application loop.
   - Renders the scene and updates the vehicle dynamics in each frame.
   - Updates the driver based on user input.

**Note:**



* This script provides a basic framework. You can customize vehicle parameters, tire models, terrain properties, and driver behavior according to your specific needs.
* Make sure you have the required PyChrono and Irrlicht libraries installed.
