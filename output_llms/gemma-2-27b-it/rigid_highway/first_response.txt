```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))
timestep = 1.0 / 50.0  # 50 Hz simulation

# 2. Add physical systems and objects
# -----------------------------------
# Terrain
terrain_col = chrono.ChTriangleMeshShape()
terrain_col.LoadMesh(chrono.GetChronoDataPath() + "terrain/Highway_col.obj")
terrain_body = chrono.ChBody()
terrain_body.SetShape(terrain_col)
terrain_body.SetBodyFixed(True)
system.Add(terrain_body)

terrain_vis = chrono.ChVisualShape()
terrain_vis.LoadMesh(chrono.GetChronoDataPath() + "terrain/Highway_vis.obj")
terrain_body.AddVisualShape(terrain_vis)

# HMMWV Vehicle
vehicle = chronovehicle.ChVehicle("HMMWV")
vehicle.SetSystem(system)

# Set initial position and orientation
vehicle.SetChassisPosition(chrono.ChVectorD(0, 1, 0))
vehicle.SetChassisOrientation(chrono.Q_from_AngAxis(0, chrono.ChVectorD(0, 1, 0)))

# Load vehicle chassis and components (replace with actual HMMWV model files)
vehicle.SetChassisBody(chrono.ChBodyEasyBox(2.5, 1.2, 0.8, 1000))
vehicle.AddWheel(chrono.ChWheelInfo("front_left", chrono.ChVectorD(1.2, 1.0, 0.5), chrono.ChVectorD(0, -1, 0), 0.3, 0.6, 0.2))
vehicle.AddWheel(chrono.ChWheelInfo("front_right", chrono.ChVectorD(-1.2, 1.0, 0.5), chrono.ChVectorD(0, -1, 0), 0.3, 0.6, 0.2))
vehicle.AddWheel(chrono.ChWheelInfo("rear_left", chrono.ChVectorD(1.2, -1.0, 0.5), chrono.ChVectorD(0, -1, 0), 0.3, 0.6, 0.2))
vehicle.AddWheel(chrono.ChWheelInfo("rear_right", chrono.ChVectorD(-1.2, -1.0, 0.5), chrono.ChVectorD(0, -1, 0), 0.3, 0.6, 0.2))

# Set tire model (TMEASY)
for wheel in vehicle.GetWheels():
    wheel.SetTireModel(chronovehicle.TMeasyTire(vehicle.GetSystem()))

# Set contact method
vehicle.SetContactMethod(chrono.ChContactMethod_NSC)

# 3. Configure visualization
# ---------------------------
vis = chronoirr.ChIrrApp(system, "HMMWV Simulation", chronoirr.dimension2du(1280, 720))
vis.AddTypicalLights()
vis.AddSkyBox()
vis.SetCameraPosition(chrono.ChVectorD(0, 5, -10))
vis.SetCameraLookAt(chrono.ChVectorD(0, 1, 0))

# Add vehicle visualization
vehicle.AddVisualizationAssets(vis)

# 4. Implement driver system
# ---------------------------
driver = chronovehicle.ChDriver(vehicle)

# 5. Simulation loop
# ------------------
while vis.GetDevice()->run():
    vis.BeginScene()
    vis.Render()
    system.DoStepDynamics(timestep)
    driver.Synchronize(timestep)
    vis.EndScene()



```

**Explanation:**

1. **Initialization:** Sets up the Chrono environment, system, and gravity.
2. **Terrain:** Loads a custom terrain mesh for both collision and visualization.
3. **HMMWV:**
   - Creates a `ChVehicle` object for the HMMWV.
   - Sets initial position and orientation.
   - Loads chassis and wheels (replace placeholder files with actual HMMWV models).
   - Configures TMEASY tire model for each wheel.
   - Sets contact method to NSC.
4. **Visualization:**
   - Initializes Irrlicht visualization with a window and camera.
   - Adds lighting and skybox.
   - Adds visualization assets for the vehicle.
5. **Driver System:** Creates a `ChDriver` object for interactive control.
6. **Simulation Loop:**
   - Runs the simulation loop at 50 Hz.
   - Renders the scene using Irrlicht.
   - Updates vehicle dynamics using `DoStepDynamics`.
   - Synchronizes driver input with the simulation.

**Important Notes:**

- Replace the placeholder file names for the HMMWV chassis and wheels with your actual model files.
- You'll need to have the Irrlicht library installed and configured for visualization.
- This script provides a basic framework. You can extend it by adding more vehicle components, sensors, controllers, and other features as needed.
