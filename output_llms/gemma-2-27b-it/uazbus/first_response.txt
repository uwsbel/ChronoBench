```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#
# ---------------------------------------------------------------------

# Create a physical system
mysystem = chrono.ChSystemNSC()

# Set gravitational acceleration
mysystem.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the terrain
terrain = chrono.ChBodyEasyBox(100, 1, 100, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, -1, 0))
terrain.SetBodyFixed(True)
mysystem.Add(terrain)

# Set terrain properties
terrain.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
terrain.GetMaterialSurface().SetFriction(0.8)
terrain.GetMaterialSurface().SetRestitution(0.2)

# Create the UAZBUS vehicle
vehicle = chrono.ChVehicle(mysystem)
vehicle.SetChassisBody(chrono.ChBodyEasyBox(2.5, 1, 5, 1000))
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(chrono.ChVectorD(0, 1, 0))
mysystem.Add(vehicle)

# Add wheels
wheel_radius = 0.4
wheel_width = 0.2
wheel_mass = 20
for i in range(4):
    wheel = chrono.ChWheel(vehicle.GetChassisBody())
    wheel.SetRadius(wheel_radius)
    wheel.SetWidth(wheel_width)
    wheel.SetMass(wheel_mass)
    wheel.SetFriction(0.8)
    wheel.SetSuspensionForce(10000)
    wheel.SetSuspensionCompression(0.2)
    wheel.SetSuspensionDamping(1000)

    # Position the wheels
    if i < 2:
        wheel.SetPos(chrono.ChVectorD(1.25 * (-1)**i, -wheel_radius, 2.5))
    else:
        wheel.SetPos(chrono.ChVectorD(1.25 * (-1)**(i-2), -wheel_radius, -2.5))
    vehicle.AddWheel(wheel)

# Create a driver system
driver = chrono.ChDriver(vehicle)

# ---------------------------------------------------------------------
#
#  Set up Irrlicht visualization
#
# ---------------------------------------------------------------------

vis = chronoirr.ChIrrApp(mysystem, 'UAZBUS Simulation', chronoirr.dimension2du(1280, 720))
vis.AddTypicalSky()
vis.AddTypicalLights()
vis.SetCameraLocation(chrono.ChVectorD(5, 5, 5))
vis.SetCameraLookAt(chrono.ChVectorD(0, 1, 0))

# ---------------------------------------------------------------------
#
# Simulation loop
#
# ---------------------------------------------------------------------

while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()

    # Advance the simulation
    mysystem.DoStepDynamics(0.01)

    # Update the driver system (e.g., steering, acceleration)
    driver.Update(0.01)

    vis.EndScene()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a `ChSystemNSC` for the physics simulation.
   - Sets gravitational acceleration.

2. **Terrain:**
   - Creates a simple box-shaped terrain using `ChBodyEasyBox`.
   - Positions the terrain at y=-1.
   - Fixes the terrain in place.
   - Sets friction and restitution properties for the terrain's surface.

3. **Vehicle:**
   - Creates a `ChVehicle` object.
   - Sets up a simple box chassis for the vehicle.
   - Positions the vehicle initially at (0, 1, 0).
   - Adds four wheels to the vehicle, specifying radius, width, mass, friction, suspension properties, and positions.

4. **Driver:**
   - Creates a `ChDriver` object to control the vehicle (implementation of driver logic not shown here).

5. **Visualization:**
   - Creates an Irrlicht visualization window using `ChIrrApp`.
   - Adds a sky and lights for better visual rendering.
   - Sets initial camera position and view direction.

6. **Simulation Loop:**
   - Enters a loop that continues until the Irrlicht window is closed.
   - Renders the scene using Irrlicht.
   - Advances the physics simulation by one timestep (0.01 seconds).
   - Updates the driver system (placeholder for actual driver control logic).

**Important Notes:**

- This script provides a basic framework. You'll need to implement the actual driver logic (steering, acceleration, braking) within the `driver.Update()` function.
- You can customize the vehicle model, terrain, and driver behavior to create more complex and realistic simulations.
