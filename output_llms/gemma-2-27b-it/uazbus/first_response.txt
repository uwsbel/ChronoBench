```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#
# ---------------------------------------------------------------------

system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the terrain
terrain = chrono.ChBodyEasyBox(100, 1, 100, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, -0.5, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)

# Set terrain material properties
terrain_material = chrono.ChMaterialSurfaceNSC()
terrain_material.SetFriction(0.8)
terrain_material.SetRestitution(0.2)
terrain.AddMaterial(terrain_material)

# Create the UAZBUS vehicle
vehicle = chrono.ChVehicle(system)
vehicle.SetChassis(chrono.ChBodyEasyBox(2.5, 1, 5, 1000))
vehicle.SetChassisPosition(chrono.ChVectorD(0, 1, 0))

# Add wheels to the vehicle
wheel_radius = 0.4
wheel_width = 0.2
for i in range(4):
    wheel = chrono.ChWheel(vehicle.GetSystem())
    wheel.SetRadius(wheel_radius)
    wheel.SetWidth(wheel_width)
    wheel.SetFriction(1.0)
    wheel.SetSuspensionForce(2000)
    wheel.SetSpringCoefficient(1000)
    wheel.SetDampingCoefficient(100)
    vehicle.AddWheel(wheel)

# Create a driver system for vehicle control
driver = chrono.ChDriver(vehicle)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#
# ---------------------------------------------------------------------

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("UAZBUS Simulation")
vis.Initialize()

# Set camera position and lighting
camera = vis.GetCamera()
camera.SetEyepoint(chrono.ChVectorD(5, 5, 5))
camera.SetLookAt(chrono.ChVectorD(0, 1, 0))
vis.SetLightAmbient(chrono.ChColor(0.5, 0.5, 0.5))
vis.SetLightDiffuse(chrono.ChColor(1, 1, 1))
vis.SetLightDirection(chrono.ChVectorD(0, -1, 0))

# ---------------------------------------------------------------------
#
#  Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    # Advance the simulation
    system.DoStepDynamics(0.01)

    # Update driver input (example: steering and acceleration)
    driver.SetSteeringAngle(0.1)
    driver.SetAcceleration(0.5)

    # Update visualization
    vis.Render()

```

**Explanation:**

1. **Initialization:**

- Imports necessary Chrono and Irrlicht modules.
- Creates a Chrono simulation system (`system`).
- Sets gravitational acceleration.
- Creates a terrain using a box shape and sets its position, material properties (friction and restitution), and fixes it in place.
- Creates a UAZBUS vehicle using a simplified box chassis and adds four wheels with specified properties (radius, width, friction, suspension, etc.).
- Creates a driver system (`driver`) to control the vehicle.

2. **Visualization:**

- Creates an Irrlicht visualization system (`vis`) and attaches it to the simulation system.
- Sets window size, title, and initializes the visualization.
- Configures camera position and lighting for better visualization.

3. **Simulation Loop:**

- Enters a loop that runs until the visualization window is closed.
- Advances the simulation by one timestep using `system.DoStepDynamics(0.01)`.
- Updates the driver input (steering angle and acceleration) as an example.
- Renders the scene using `vis.Render()`, updating the visualization at each timestep.



This script provides a basic framework for simulating a UAZBUS vehicle on a rigid terrain with Irrlicht visualization. You can expand upon this by adding more complex vehicle models, terrain features, sensor systems, and control algorithms.
