```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system
#

mysystem = chrono.ChSystemNSC()
mysystem.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# ---------------------------------------------------------------------
#
# Create the terrain
#

terrain = chrono.ChBodyEasyBox(100, 1, 100, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, -1, 0))
terrain.SetBodyFixed(True)
mysystem.Add(terrain)

# Set terrain material properties
terrain.GetMaterialSurfaceNSC().SetFriction(0.8)
terrain.GetMaterialSurfaceNSC().SetRestitution(0.2)

# ---------------------------------------------------------------------
#
# Create the UAZBUS vehicle
#

vehicle = chrono.ChVehicle(mysystem)

# Load vehicle model (replace with your UAZBUS model path)
vehicle.SetChassis(chrono.ChBodyEasyBox(2.5, 0.8, 4, 1000))
vehicle.GetChassisBody().SetPos(chrono.ChVectorD(0, 1.5, 0))

# Add wheels (adjust parameters as needed)
wheel_radius = 0.4
wheel_width = 0.2
wheel_mass = 20
vehicle.AddWheel(chrono.ChWheelInfo(
    chrono.ChVectorD(-1.2, -0.4, 1.5),  # Location
    wheel_radius,
    wheel_width,
    wheel_mass,
    0.5,  # Suspension stiffness
    0.2,  # Suspension damping
    0.8,  # Friction coefficient
))
vehicle.AddWheel(chrono.ChWheelInfo(
    chrono.ChVectorD(1.2, -0.4, 1.5),
    wheel_radius,
    wheel_width,
    wheel_mass,
    0.5,
    0.2,
    0.8,
))
vehicle.AddWheel(chrono.ChWheelInfo(
    chrono.ChVectorD(-1.2, -0.4, -1.5),
    wheel_radius,
    wheel_width,
    wheel_mass,
    0.5,
    0.2,
    0.8,
))
vehicle.AddWheel(chrono.ChWheelInfo(
    chrono.ChVectorD(1.2, -0.4, -1.5),
    wheel_radius,
    wheel_width,
    wheel_mass,
    0.5,
    0.2,
    0.8,
))

# ---------------------------------------------------------------------
#
# Create the driver system
#

driver = chrono.ChDriver(vehicle)

# Set initial driver controls (e.g., steering, acceleration)
driver.SetSteering(0)
driver.SetAcceleration(0)

# ---------------------------------------------------------------------
#
# Create the Irrlicht visualization system
#

vis = chronoirr.ChIrrApp(mysystem, "UAZBUS Simulation", chronoirr.dimension2du(1280, 720))
vis.AddTypicalSky()
vis.AddTypicalLights()
vis.SetCameraPosition(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0))

# ---------------------------------------------------------------------
#
# Simulation loop
#

while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()

    # Update driver controls (example: simple keyboard input)
    if vis.GetDevice().IsKeyDown(chronoirr.KEY_LEFT):
        driver.SetSteering(-0.5)
    elif vis.GetDevice().IsKeyDown(chronoirr.KEY_RIGHT):
        driver.SetSteering(0.5)
    else:
        driver.SetSteering(0)

    if vis.GetDevice().IsKeyDown(chronoirr.KEY_UP):
        driver.SetAcceleration(1)
    elif vis.GetDevice().IsKeyDown(chronoirr.KEY_DOWN):
        driver.SetAcceleration(-1)
    else:
        driver.SetAcceleration(0)

    # Advance the simulation
    mysystem.DoStepDynamics(vis.GetTimeStep())

    vis.EndScene()
```

**Explanation:**

1. **Initialization:**
   - Creates a Chrono system (`mysystem`) and sets gravity.
   - Creates a terrain (`terrain`) as a box with specified dimensions, position, and material properties (friction and restitution).
   - Creates a UAZBUS vehicle (`vehicle`) using `ChVehicle` and `ChBodyEasyBox` for the chassis.

2. **Vehicle Setup:**
   - Adds four wheels to the vehicle using `ChWheelInfo`, defining their locations, radii, widths, masses, suspension parameters, and friction coefficients.

3. **Driver System:**
   - Creates a driver (`driver`) using `ChDriver` to control the vehicle.
   - Sets initial driver controls (steering and acceleration) to 0.

4. **Visualization:**
   - Creates an Irrlicht visualization system (`vis`) with a window title, resolution, and default sky and lighting.
   - Sets the initial camera position and target.

5. **Simulation Loop:**
   - Enters a loop that continues until the Irrlicht window is closed.
   - Inside the loop:
     - Renders the scene using `vis.Render()`.
     - Updates driver controls based on keyboard input.
     - Advances the simulation using `mysystem.DoStepDynamics()` with the Irrlicht timestep.
     - Ends the scene rendering.

**Remember:**



* Replace the placeholder UAZBUS model path with the actual path to your vehicle model.
* Adjust the vehicle parameters (wheel dimensions, suspension, etc.) to match your UAZBUS model.
