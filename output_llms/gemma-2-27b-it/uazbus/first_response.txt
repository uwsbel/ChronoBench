```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Simulation setup
#

# Set path to UAZBUS vehicle model
vehicle_path = "path/to/UAZBUS/model"

# Initialize Chrono environment
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("UAZBUS Simulation")
vis.Initialize()

# Create camera
camera = vis.GetSceneManager().addCameraSceneNode()
camera.setPosition(chrono.ChVectorD(0, 2, -5))
camera.setTarget(chrono.ChVectorD(0, 0, 0))
camera.setFarValue(1000)

# Set lighting
light = vis.GetSceneManager().addLightSceneNode(0, chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1))

# ---------------------------------------------------------------------
#
#  Terrain setup
#

# Create rigid terrain
terrain = chrono.ChBodyEasyBox(100, 1, 100, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, -0.5, 0))
terrain.SetBodyFixed(True)
my_system.AddBody(terrain)

# Set terrain material properties
terrain.GetMaterialSurfaceNSC().SetFriction(0.8)
terrain.GetMaterialSurfaceNSC().SetRestitution(0.2)

# ---------------------------------------------------------------------
#
#  Vehicle setup
#

# Load UAZBUS vehicle
vehicle = chronovehicle.ChVehicleModelData(vehicle_path)
vehicle.SetChassisInitialization(chrono.ChVectorD(0, 1, 0), chrono.ChQuaternionD(1, 0, 0, 0))

# Create vehicle system
vehicle_system = chronovehicle.ChVehicle(vehicle, my_system)

# Initialize driver system
driver = chronovehicle.ChDriver(vehicle_system)
driver.SetSteeringAngle(0)
driver.SetThrottle(0)

# ---------------------------------------------------------------------
#
#  Simulation loop
#

# Set simulation parameters
timestep = 0.01
sim_time = 0

while vis.Run():
    # Update driver input (example: keyboard control)
    if vis.GetDevice()->IsKeyDown(chrono.irr::KEY_LEFT):
        driver.SetSteeringAngle(-0.5)
    elif vis.GetDevice()->IsKeyDown(chrono.irr::KEY_RIGHT):
        driver.SetSteeringAngle(0.5)
    else:
        driver.SetSteeringAngle(0)

    if vis.GetDevice()->IsKeyDown(chrono.irr::KEY_UP):
        driver.SetThrottle(1)
    elif vis.GetDevice()->IsKeyDown(chrono.irr::KEY_DOWN):
        driver.SetThrottle(-1)
    else:
        driver.SetThrottle(0)

    # Advance simulation
    sim_time += timestep
    my_system.DoStepDynamics(timestep)

    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary Chrono modules.
   - Sets the path to the UAZBUS vehicle model.
   - Creates a Chrono system and sets gravity.
   - Initializes the Irrlicht visualization system, sets window size and title, and starts it.
   - Creates a camera, positions it, and sets target and far value.
   - Adds a light source for better visibility.

2. **Terrain Setup:**
   - Creates a rigid terrain using `ChBodyEasyBox`.
   - Positions the terrain and sets it as fixed.
   - Defines friction and restitution properties for the terrain material.

3. **Vehicle Setup:**
   - Loads the UAZBUS vehicle model data.
   - Initializes the vehicle chassis position and orientation.
   - Creates a `ChVehicle` system using the loaded data and adds it to the Chrono system.
   - Initializes a `ChDriver` system for controlling the vehicle.

4. **Simulation Loop:**
   - Sets the simulation timestep and initializes simulation time.
   - Enters the main loop, which continues as long as the Irrlicht window is running.
   - Handles driver input (steering and throttle) based on keyboard presses.
   - Advances the simulation using `DoStepDynamics`.
   - Updates the visualization by rendering the scene.

**Notes:**

- Replace `"path/to/UAZBUS/model"` with the actual path to your UAZBUS vehicle model.
- This script provides a basic framework. You can extend it by adding more complex vehicle controls, sensors, obstacles, and other simulation elements.
- Remember to install the required Chrono and Irrlicht libraries before running the script.
