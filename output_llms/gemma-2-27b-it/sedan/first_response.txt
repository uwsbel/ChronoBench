```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files

# Create the simulation system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add physical systems and objects
# a) Vehicle
vehicle = chronovehicle.ChVehicle("BMW E90 Sedan")

# Load vehicle model (replace with your actual vehicle model file)
vehicle.SetChassisFile("vehicle/BMW_E90/chassis.obj")

# Configure visualization
vehicle.SetChassisVisualizationType(chronovehicle.VisualizationType_MESH)
vehicle.SetSuspensionVisualizationType(chronovehicle.VisualizationType_PRIMITIVES)
vehicle.SetWheelVisualizationType(chronovehicle.VisualizationType_MESH)

# Set collision settings
vehicle.SetCollisionType(chrono.CollisionType_BOX)

# b) Tire model
tire_model = chronovehicle.TMeasyTire()  # Use TMEASY tire model
vehicle.SetTireModel(tire_model)

# c) Driver system
driver = chronovehicle.ChDriverSystem(vehicle)
driver.SetSteeringControl(chrono.ChFunction_Const(0.0))  # Initial steering
driver.SetThrottleControl(chrono.ChFunction_Const(0.0))  # Initial throttle
driver.SetBrakingControl(chrono.ChFunction_Const(0.0))  # Initial braking

# d) Terrain
terrain = chrono.ChBodyEasyBox(200, 10, 200, 1000, True, True)  # Create a rigid terrain
terrain.SetPos(chrono.ChVectorD(0, -5, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)

# 3. Set default parameters
# a) Vehicle position and orientation
vehicle.SetPos(chrono.ChVectorD(0, 1, 0))

# b) Terrain surface properties
terrain.SetMaterialSurface(chrono.ChMaterialSurfaceNSC())
terrain.GetMaterialSurface().SetFriction(0.8)  # Set friction coefficient

# 4. Visualization with Irrlicht
vis = chronoirr.ChIrrApp(system, "BMW E90 Simulation", chronoirr.dimension2du(1280, 720))
vis.AddTypicalSky()
vis.AddTypicalLights()

# a) Chase camera
camera = vis.GetCamera()
camera.SetFollow(vehicle.GetChassis())
camera.SetDistance(10)

# b) Customize terrain textures and logos (replace with your actual files)
terrain_texture = chronoirr.irr::io::path("terrain_texture.jpg")
terrain.GetVisualModel().SetTexture(0, terrain_texture)

# c) Add vehicle logo (replace with your actual logo file)
vehicle_logo = chronoirr.irr::io::path("vehicle_logo.png")
vehicle.GetChassis().GetVisualModel().SetTexture(1, vehicle_logo)

# 5. Simulation loop
while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()
    system.DoStepDynamics(0.01)
    vis.EndScene()
```

**Explanation:**

1. **Initialization:**
   - Sets up the Chrono environment and creates a simulation system with gravity.

2. **Adding Objects:**
   - Creates a `ChVehicle` object representing the BMW E90 Sedan.
   - Loads the vehicle model from a file (replace with your actual file).
   - Configures visualization (mesh, primitives), collision settings (box), and tire model (TMEASY).
   - Creates a `ChDriverSystem` for real-time control of steering, throttle, and braking.
   - Adds a rigid terrain using `ChBodyEasyBox`.

3. **Default Parameters:**
   - Sets the initial position and orientation of the vehicle.
   - Defines the friction coefficient for the terrain surface.

4. **Visualization:**
   - Initializes Irrlicht visualization with a window, skybox, and lights.
   - Sets up a chase camera that follows the vehicle.
   - Adds textures and logos to the terrain and vehicle (replace placeholders with your actual files).

5. **Simulation Loop:**
   - Runs the simulation loop, rendering the scene and updating the physics at each step.
