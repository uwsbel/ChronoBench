```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")

# Create the simulation system
system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add physical systems and objects
# Create the terrain
terrain = chrono.ChBodyEasyBox(
    200, 200, 1, 1000, True, True, chrono.ChMaterialSurfaceNSC()
)
terrain.SetPos(chrono.ChVectorD(0, -1, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)

# Create the vehicle
vehicle = chronovehicle.ChVehicle("BMW E90", system)

# Load vehicle chassis and suspension
vehicle.SetChassis(chronovehicle.ChChassis(
    "data/vehicle/e90/chassis.obj",
    chrono.ChVectorD(0, 0, 0),
    chrono.ChQuaternionD(1, 0, 0, 0),
    chrono.ChMaterialSurfaceNSC()
))

# Add wheels with TMEASY tire model
vehicle.AddWheel(chronovehicle.ChWheelInfo("data/vehicle/e90/wheel.obj",
                                       chrono.ChVectorD(1.5, -0.8, 0.5),
                                       chrono.ChVectorD(0, -1, 0),
                                       chrono.ChMaterialSurfaceNSC(),
                                       chrono.ChTMeasyTire(
                                           chrono.ChVectorD(0.3, 0.6, 0.1),
                                           chrono.ChVectorD(0.1, 0.1, 0.1),
                                           chrono.ChVectorD(10000, 10000, 10000)
                                       )
                                      ))

# Add remaining wheels (adjust positions as needed)
# ...

# 3. Set default parameters and configure visualization

# Interactive driver system
driver = chronovehicle.ChDriver(vehicle)

# Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("BMW E90 Simulation")

# Chase camera
camera = vis.GetSceneManager().addCameraSceneNode()
camera.setPosition(chrono.ChVectorD(0, 5, -10))
camera.setTarget(vehicle.GetChassis().GetPos())

# Directional lighting and skybox
vis.AddLight(chrono.ChLightPoint(chrono.ChVectorD(0, 10, 0)))
vis.SetSkyBox("data/skybox/blue.jpg")

# Customize terrain textures and logos
terrain_texture = vis.AddTexture("data/terrain/grass.jpg")
terrain.AddAsset(chronoirr.ChIrrNodeAsset(terrain_texture))

# Start the simulation
while vis.Run():
    # Update driver input (steering, throttle, braking)
    driver.Update(vis.GetDeltaTime())

    # Update the simulation
    system.DoStepDynamics(vis.GetDeltaTime())

    # Render the scene
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules.
   - Sets the Chrono data path for loading assets.
   - Creates a `ChSystemNSC` object for the simulation.
   - Sets gravitational acceleration.

2. **Physical Systems and Objects:**
   - Creates a rigid terrain using `ChBodyEasyBox`.
   - Creates a `ChVehicle` object representing the BMW E90.
   - Loads chassis and suspension data from OBJ files.
   - Adds wheels with the TMEASY tire model, specifying tire parameters.
   - You'll need to add the remaining wheels and adjust their positions accordingly.

3. **Visualization and Configuration:**
   - Creates an `ChVisualSystemIrrlicht` object for Irrlicht visualization.
   - Sets window size and title.
   - Adds a chase camera following the vehicle.
   - Adds directional lighting and a skybox.
   - Customizes terrain texture using Irrlicht nodes.

4. **Simulation Loop:**
   - The `while vis.Run():` loop handles the simulation and rendering.
   - Inside the loop:
     - The `driver.Update()` function simulates user input (steering, throttle, braking).
     - `system.DoStepDynamics()` performs the physics simulation step.
     - `vis.Render()` renders the scene.

**Important Notes:**

- This script provides a basic framework. You'll need to:
    - Complete the wheel configuration for all four wheels.
    - Adjust tire parameters in the `ChTMeasyTire` constructor based on your desired tire behavior.
    - Customize the driver input logic in the `driver.Update()` function.
- Remember to replace placeholder file paths with the actual paths to your data files.
