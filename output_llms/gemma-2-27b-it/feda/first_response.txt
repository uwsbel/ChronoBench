```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#

# Create the physical system
system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht application
app = chronoirr.ChIrrApp(system, "FEDA Vehicle Simulation", chronoirr.dimension2du(1280, 720))
app.AddTypicalSky()
app.AddTypicalLights()
app.SetCameraLocation(chrono.ChVectorD(0, 2, -5))
app.SetCameraLookAt(chrono.ChVectorD(0, 0, 0))

# ---------------------------------------------------------------------
#
#  Create the terrain
#

# Create a rigid terrain
terrain = chrono.ChRigidTerrain(system)
heightmap = chrono.ChHeightmap(chrono.GetChronoDataPath() + "heightmap/terrain.png")
terrain.SetHeightmap(heightmap)
terrain.SetTexture(chrono.GetChronoDataPath() + "texture/terrain.jpg")

# ---------------------------------------------------------------------
#
#  Create the FEDA vehicle
#

# Create the vehicle chassis
vehicle = chronovehicle.ChVehicle(system)
vehicle.SetChassisFixed(False)
vehicle.SetChassisPosition(chrono.ChVectorD(0, 0.5, 0))
vehicle.SetChassisVisualizationType(chronovehicle.ChVehicle.VisualizationType_MESH)

# Load the vehicle model
vehicle.SetVehicleModel(chronovehicle.ChVehicleModelFile("FEDA/vehicle.json"))

# Set tire model and contact method
vehicle.SetTireModel(chronovehicle.ChTireModelNSC())
vehicle.SetContactMethod(chronovehicle.ChContactMethodNSC())

# ---------------------------------------------------------------------
#
#  Set up the interactive driver system
#

# Create the driver system
driver = chronovehicle.ChInteractiveDriver(vehicle)
driver.SetSteeringSensitivity(0.05)
driver.SetThrottleSensitivity(0.5)
driver.SetBrakingSensitivity(0.5)

# ---------------------------------------------------------------------
#
#  Simulation loop
#

while app.GetDevice().run():
    app.BeginScene()

    # Update the driver input
    driver.Update(app.GetDevice().GetElapsedSeconds())

    # Advance the simulation
    system.DoStepDynamics(app.GetDevice().GetTimerStep())

    # Render the scene
    app.DrawAll()

    app.EndScene()

    # Set the frame rate
    app.GetDevice().sleep(0.02)
```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono modules.
   - Creates a `ChSystemNSC` object to represent the physical system.
   - Sets gravitational acceleration.
   - Initializes an Irrlicht application (`ChIrrApp`) for visualization.
   - Sets camera position and look-at point.

2. **Terrain:**
   - Creates a `ChRigidTerrain` object.
   - Loads a heightmap and texture for the terrain.

3. **Vehicle:**
   - Creates a `ChVehicle` object to represent the FEDA vehicle.
   - Sets initial position and visualization type.
   - Loads the vehicle model from a JSON file.
   - Sets tire model and contact method.

4. **Driver:**
   - Creates an `ChInteractiveDriver` object to control the vehicle.
   - Sets steering, throttle, and braking sensitivities.

5. **Simulation Loop:**
   - Runs the Irrlicht application loop.
   - Updates the driver input based on user interaction.
   - Advances the simulation using `DoStepDynamics`.
   - Renders the scene using Irrlicht.
   - Sleeps for a short time to maintain a frame rate of 50 FPS.

**Notes:**



* This script assumes you have the FEDA vehicle model files (`vehicle.json`, textures, etc.) in a directory named "FEDA". Adjust the paths accordingly.
* You may need to install additional PyChrono dependencies, such as Irrlicht, depending on your setup.
* This is a basic example and can be further customized by adding more features, such as sensors, actuators, and advanced control systems.
