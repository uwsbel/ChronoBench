```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")

# Create the system and the Irrlicht visualization
system = chrono.ChSystemNSC()
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("FEDA Vehicle Simulation")
vis.Initialize()

# 2. Add physical systems and objects

# Create a rigid terrain
terrain = chrono.ChRigidTerrain(system)
terrain.SetTexture(chrono.GetChronoDataPath() + 'terrain/textures/grass.png')
patch = chrono.ChRigidTerrainPatch(terrain)
patch.SetSize(200, 200)
patch.SetHeight(0)
terrain.AddPatch(patch)

# Create the FEDA vehicle
vehicle = chronovehicle.ChVehicle(system)

# Load vehicle chassis
vehicle.SetChassis(chronovehicle.ChChassis(chrono.ChBodyEasyBox(2.5, 1.2, 0.8, 1000)))
vehicle.GetChassis().SetPos(chrono.ChVectorD(0, 0.5, 0))

# Set contact method and tire model
vehicle.SetCollisionSystemType(chronovehicle.ChCollisionSystemType_NSC)
vehicle.AddWheel(chronovehicle.ChWheelInfo(
    location=chrono.ChVectorD(-1.2, -0.6, 0),
    radius=0.3,
    width=0.15,
    mass=20,
    inertia=0.5,
    damping=0.5,
    friction=1.0,
    tiremodel=chronovehicle.ChTireModelNSC(chrono.ChVectorD(1.0, 1.0, 1.0)),
))
vehicle.AddWheel(chronovehicle.ChWheelInfo(
    location=chrono.ChVectorD(1.2, -0.6, 0),
    radius=0.3,
    width=0.15,
    mass=20,
    inertia=0.5,
    damping=0.5,
    friction=1.0,
    tiremodel=chronovehicle.ChTireModelNSC(chrono.ChVectorD(1.0, 1.0, 1.0)),
))

# 3. Set default parameters

# Set initial vehicle orientation
vehicle.GetChassis().SetRot(chrono.Q_from_AngAxis(chrono.CH_C_PI / 4, chrono.ChVectorD(0, 0, 1)))

# Set camera to follow vehicle
camera = vis.GetCamera()
camera.SetFollowPos(vehicle.GetChassis().GetPos())
camera.SetFollowDist(5)

# Set visualization type for vehicle parts
vehicle.SetVisualizationType(chronovehicle.ChVisualizationType_MESH)
```

**Explanation:**

1. **Initialization:** The script starts by initializing the PyChrono environment, creating a physical system, and setting up the Irrlicht visualization.

2. **Terrain and Vehicle:** A rigid terrain with a custom texture is created using `ChRigidTerrain`. A FEDA vehicle is instantiated using `ChVehicle`, with its chassis defined as a box.

3. **Contact and Tires:** The vehicle's contact method is set to NSC, and a simple tire model (`ChTireModelNSC`) is used for each wheel.

4. **Parameters:** Initial vehicle position and orientation are defined. The camera is set to follow the vehicle from a specific distance.

5. **Visualization:** The vehicle parts are set to be visualized using meshes for better realism.

6. **Driver System:** A placeholder is included for implementing an interactive driver system, which would allow the user to control the vehicle's steering, throttle, and braking.

7. **Simulation Loop:** The main loop runs at 50 frames per second, updating the vehicle dynamics using `DoStepDynamics` and rendering the scene using `vis.Render`.
