```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# 1. Initialize the PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add physical systems and objects

# Create a material for the tablecloth
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.3)
material.SetRestitution(0.2)

# Define tablecloth dimensions
width = 2.0
length = 3.0
num_nodes_x = 20
num_nodes_y = 30

# Generate mesh grid for the tablecloth
nodes = []
for i in range(num_nodes_x):
    for j in range(num_nodes_y):
        x = i * width / (num_nodes_x - 1)
        y = j * length / (num_nodes_y - 1)
        nodes.append(chrono.ChNodeFEAxyz(chrono.ChVectorD(x, y, 0)))

# Create shell elements using the nodes
elements = []
for i in range(num_nodes_x - 1):
    for j in range(num_nodes_y - 1):
        node1 = i * num_nodes_y + j
        node2 = (i + 1) * num_nodes_y + j
        node3 = (i + 1) * num_nodes_y + (j + 1)
        node4 = i * num_nodes_y + (j + 1)
        elements.append(chrono.ChElementShellANCF(nodes[node1], nodes[node2], nodes[node3], nodes[node4]))

# Create a shell mesh
mesh = chrono.ChMesh()
mesh.AddNodes(nodes)
mesh.AddElements(elements)
mesh.SetMaterial(material)

# Create a body for the tablecloth
tablecloth = chrono.ChBody()
tablecloth.SetMesh(mesh)
tablecloth.SetBodyFixed(False)
my_system.AddBody(tablecloth)

# 3. Set necessary default parameters

# Apply gravity to the tablecloth
tablecloth.SetMass(0.5)

# Define isotropic Kirchhoff material properties
young_modulus = 100000
poisson_ratio = 0.3
thickness = 0.01

# Set material properties for the shell elements
for element in elements:
    element.SetYoungModulus(young_modulus)
    element.SetPoissonRatio(poisson_ratio)
    element.SetThickness(thickness)

# 4. Visualization setup

# Create an Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Tablecloth Folding Simulation")
vis.Initialize()

# 5. Solver setup

# Use PardisoMKL solver for efficient dynamics handling
solver = chrono.ChSolverPardisoMKL()
my_system.SetSolver(solver)

# Simulation loop
while vis.Run():
    my_system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Creates a `ChSystemNSC` object to represent the physical system.
   - Sets gravity.

2. **Physical Systems and Objects:**
   - Defines a material with friction and restitution.
   - Generates a mesh grid for the tablecloth using specified dimensions and number of nodes.
   - Creates shell elements using the generated nodes.
   - Assembles the shell mesh and assigns the material.
   - Creates a `ChBody` object to represent the tablecloth, attaches the mesh, and adds it to the system.

3. **Default Parameters:**
   - Sets mass for the tablecloth.
   - Defines material properties (Young's modulus, Poisson's ratio, thickness) for the isotropic Kirchhoff material.
   - Applies these properties to each shell element.

4. **Visualization:**
   - Creates an Irrlicht visualization system (`chronoirr.ChVisualSystemIrrlicht`) and attaches it to the simulation system.
   - Sets window size and title.
   - Initializes the visualization.

5. **Solver:**
   - Uses the PardisoMKL solver (`chrono.ChSolverPardisoMKL`) for efficient handling of the system's dynamics.
   - Assigns the solver to the system.

6. **Simulation Loop:**
   - Runs the simulation loop until the visualization window is closed.
   - Performs a dynamics step (`DoStepDynamics`) with a time step of 0.01 seconds.
   - Renders the scene using the Irrlicht visualization system.
