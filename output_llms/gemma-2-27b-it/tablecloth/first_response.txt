```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# 1. Initialize the PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Create the tablecloth mesh
tablecloth_width = 2.0
tablecloth_height = 1.5
num_nodes_x = 20
num_nodes_y = 15

# Generate node positions
nodes = np.zeros((num_nodes_x * num_nodes_y, 3))
for i in range(num_nodes_x):
    for j in range(num_nodes_y):
        nodes[i * num_nodes_y + j, :] = [i * tablecloth_width / (num_nodes_x - 1),
                                        j * tablecloth_height / (num_nodes_y - 1),
                                        0]

# Create shell elements
elements = []
for i in range(num_nodes_x - 1):
    for j in range(num_nodes_y - 1):
        elements.append([i * num_nodes_y + j,
                         i * num_nodes_y + j + 1,
                         (i + 1) * num_nodes_y + j + 1,
                         (i + 1) * num_nodes_y + j])

# 3. Add the tablecloth to the simulation
tablecloth_mesh = chrono.ChMesh()
tablecloth_material = chrono.ChMaterialSurfaceNSC()
tablecloth_material.SetFriction(0.3)
tablecloth_material.SetRestitution(0.1)

for node_pos in nodes:
    tablecloth_mesh.AddNode(chrono.ChNodeFEAxyz(chrono.ChVectorD(node_pos)))

for element in elements:
    tablecloth_mesh.AddShellElement(chrono.ChShellElementKirchhoff(element, tablecloth_material))

tablecloth = chrono.ChBodyEasyMesh(tablecloth_mesh)
tablecloth.SetMass(0.1)  # Adjust mass as needed
tablecloth.SetPos(chrono.ChVectorD(0, 0.75, 0))  # Initial position
my_system.Add(tablecloth)

# 4. Set up Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Tablecloth Folding Simulation")
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataPath() + 'logo_pychrono.png')
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(2, 2, 2))
vis.EnableShadows(True)

# 5. Set solver
solver = chrono.ChSolverPardisoMKL()
my_system.SetSolver(solver)

# 6. Simulation loop
while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    my_system.DoStepDynamics(0.01)

```

**Explanation:**

1. **Initialization:** We create the `ChSystemNSC` object, which represents the physical system, and set the gravitational acceleration.

2. **Mesh Creation:** We define the tablecloth's dimensions and the number of nodes in each direction. We then generate the node positions and create shell elements by connecting the nodes.

3. **Tablecloth Object:** A `ChMesh` object is created to hold the mesh data. We define a `ChMaterialSurfaceNSC` for the tablecloth's material properties (friction and restitution). Nodes and shell elements are added to the mesh. Finally, a `ChBodyEasyMesh` is created, representing the tablecloth body, and added to the system.

4. **Visualization:** The `chronoirr` module is used to set up Irrlicht visualization. We create a `ChVisualSystemIrrlicht` object, attach it to the system, and configure window settings, camera, and other visualization aspects.

5. **Solver:** We choose the `ChSolverPardisoMKL` solver for efficient handling of the simulation's dynamics.

6. **Simulation Loop:** The `while` loop runs the simulation. In each iteration, the Irrlicht visualization renders the scene, and the `DoStepDynamics` method advances the simulation by a specified time step.
