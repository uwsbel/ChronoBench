```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# ---------------------------------------------------------------------
#
#  Create the simulation system
#

my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Set solver
solver = chrono.ChSolverPardisoMKL()
my_system.SetSolver(solver)

# ---------------------------------------------------------------------
#
# Create the tablecloth mesh
#

# Define tablecloth dimensions
width = 2.0
height = 1.5

# Define mesh resolution
nx = 20  # Number of nodes along width
ny = 15  # Number of nodes along height

# Create nodes
nodes = []
for i in range(nx):
    for j in range(ny):
        x = i * width / (nx - 1)
        y = j * height / (ny - 1)
        nodes.append(chrono.ChNodeFEAxyz(chrono.ChVectorD(x, y, 0)))

# Create elements
elements = []
for i in range(nx - 1):
    for j in range(ny - 1):
        node1 = i * ny + j
        node2 = i * ny + (j + 1)
        node3 = (i + 1) * ny + (j + 1)
        node4 = (i + 1) * ny + j
        elements.append(chrono.ChElementShellANCF(nodes[node1], nodes[node2], nodes[node3], nodes[node4]))

# Create shell mesh
mesh = chrono.ChMesh()
for node in nodes:
    mesh.AddNode(node)
for element in elements:
    mesh.AddElement(element)

# ---------------------------------------------------------------------
#
# Create material and attach it to the mesh
#

material = chrono.ChMaterialShellKirchhoff()
material.SetYoungModulus(1000)
material.SetPoissonRatio(0.3)
material.SetDensity(1000)
material.SetThickness(0.01)

mesh.SetMaterial(material)

# ---------------------------------------------------------------------
#
# Add the mesh to the system
#

body = chrono.ChBody()
body.SetMesh(mesh)
my_system.Add(body)

# ---------------------------------------------------------------------
#
# Set up Irrlicht visualization
#

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Tablecloth Folding")
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataPath() + 'logo_pychrono.png')
vis.AddSkyBox()
vis.AddCamera(chrono.ChVectorD(0, 2, -4))

# ---------------------------------------------------------------------
#
# Simulation loop
#

while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
    my_system.DoStepDynamics(0.01)

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a `ChSystemNSC` object to manage the simulation.
   - Sets gravity and chooses the PardisoMKL solver for efficiency.

2. **Tablecloth Mesh:**
   - Defines tablecloth dimensions and mesh resolution.
   - Creates nodes using a grid pattern and elements connecting them.
   - Assembles nodes and elements into a `ChMesh` object.

3. **Material:**
   - Creates a Kirchhoff material with isotropic properties (Young's modulus, Poisson ratio, density, thickness).
   - Assigns the material to the tablecloth mesh.

4. **Body and System:**
   - Creates a `ChBody` object to hold the mesh.
   - Adds the body to the simulation system.

5. **Visualization:**
   - Initializes an Irrlicht visualization system (`chronoirr.ChVisualSystemIrrlicht`).
   - Sets window size, title, and adds a logo and skybox.
   - Positions the camera for a good view.

6. **Simulation Loop:**
   - Enters a loop that runs until the Irrlicht window is closed.
   - Renders the scene using Irrlicht.
   - Performs a single simulation step using `DoStepDynamics`.
