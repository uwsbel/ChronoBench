```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#

# Create the physical system
system = chrono.ChSystemNSC()

# Set the gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("ARTcar Simulation")
vis.Initialize()
vis.AddCamera(chrono.ChVectorD(0, 5, -10))
vis.AddTypicalLights()

# ---------------------------------------------------------------------
#
# Create the ground
#

# Create a rigid terrain
ground = chrono.ChBodyEasyBox(
    20, 20, 1, 1000, True, True, chrono.ChMaterialSurface.NSC
)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# Add a texture to the terrain
vis.AddGroundTexture("textures/grass.jpg")

# ---------------------------------------------------------------------
#
# Create the ARTcar vehicle
#

# Set vehicle parameters
vehicle_pos = chrono.ChVectorD(0, 0.5, 0)
vehicle_rot = chrono.ChQuaternionD(1, 0, 0, 0)
contact_method = chronovehicle.ChContactMethod.NSC
vis_type = chronovehicle.ChVehicleVisualType.POVRAY

# Create the ARTcar vehicle
vehicle = chronovehicle.ChVehicle("ARTcar", system, contact_method, vis_type)

# Set vehicle position and orientation
vehicle.SetChassisBodyInitialPosition(vehicle_pos)
vehicle.SetChassisBodyInitialRotation(vehicle_rot)

# ---------------------------------------------------------------------
#
# Add driver system
#

# Create an interactive driver system
driver = chronovehicle.ChInteractiveDriver(vehicle)

# ---------------------------------------------------------------------
#
# Simulation loop
#

# Set simulation parameters
timestep = 0.01
simulation_time = 10

# Run the simulation loop
while vis.Run() and system.GetChTime() < simulation_time:
    # Update the vehicle dynamics
    system.DoStepDynamics(timestep)

    # Update the visualization
    vis.Render()

# Cleanup
vis.Deinitialize()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono modules.
   - Creates a `chrono.ChSystemNSC` object to represent the physical system.
   - Sets gravitational acceleration.
   - Initializes Irrlicht visualization using `chronoirr.ChVisualSystemIrrlicht`.

2. **Ground Creation:**
   - Creates a `chrono.ChBodyEasyBox` as a rigid terrain.
   - Sets its position, fixes it in place, and adds it to the system.
   - Applies a grass texture to the terrain using `vis.AddGroundTexture`.

3. **ARTcar Vehicle Creation:**
   - Defines vehicle parameters like position, rotation, contact method, and visualization type.
   - Creates a `chronovehicle.ChVehicle` object, specifying the vehicle name, system, contact method, and visualization type.
   - Sets the initial position and rotation of the vehicle's chassis.

4. **Driver System:**
   - Creates an `chronovehicle.ChInteractiveDriver` object to allow user control of the vehicle.

5. **Simulation Loop:**
   - Sets the simulation timestep and total simulation time.
   - Enters a loop that continues until the Irrlicht window is closed or the simulation time is reached.
   - Inside the loop:
     - Updates the vehicle dynamics using `system.DoStepDynamics`.
     - Renders the scene using `vis.Render`.

6. **Cleanup:**
   - Deinitializes the Irrlicht visualization system.

**Key Points:**



* This script provides a basic framework for simulating an ARTcar on a rigid terrain with Irrlicht visualization.
* You can customize the vehicle parameters, terrain properties, and driver controls as needed.
* The `chronovehicle` module offers various vehicle components and functionalities for more complex simulations.
