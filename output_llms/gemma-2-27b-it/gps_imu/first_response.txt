```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# 1. Initialize PyChrono environment and core components

my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)

# 2. Add physical systems and objects

# a. Terrain
terrain = chrono.ChTerrainModel(chrono.ChTerrainModel.Type_HEIGHTMAP)
terrain.SetHeightMap("path/to/heightmap.png")
terrain_body = chrono.ChBodyEasyBox(100, 100, 1, 1000, True, True)
terrain_body.SetPos(chrono.ChVectorD(0, 0, 0))
terrain_body.SetBodyFixed(True)
terrain_body.AddAsset(terrain)
my_system.Add(terrain_body)

# b. HMMWV Vehicle
vehicle = chrono.ChVehicleModelHMMWV(my_system)
vehicle.SetChassisPosition(chrono.ChVectorD(0, 2, 0))
vehicle.SetChassisRotation(chrono.Q_from_AngAxis(0, chrono.ChVectorD(0, 0, 1)))

# c. Driver inputs (example: keyboard control)
driver = chrono.ChDriverSteering(vehicle)

# d. IMU and GPS sensors
imu = chrono.ChSensorIMU(vehicle.GetChassisBody())
gps = chrono.ChSensorGPS(vehicle.GetChassisBody())

# 3. Set default parameters

# Vehicle parameters (adjust as needed)
vehicle.SetMass(2500)
vehicle.SetInertia(chrono.ChVectorD(1000, 2000, 1000))

# Sensor parameters (adjust as needed)
imu.SetNoise(0.01)
gps.SetAccuracy(1)

# 4. Visual interface using Irrlicht

vis = chronoirr.ChIrrApp(my_system, "HMMWV Simulation", chronoirr.dimension2du(800, 600))
vis.AddTypicalSky()
vis.AddTypicalLights()
vis.AddCamera(chrono.ChVectorD(0, 5, -10))
vis.SetCameraVertical(chrono.ChVectorD(0, 0, 1))

# 5. Simulation loop

while vis.GetDevice()->run():
    vis.BeginScene()
    vis.Render()

    # Process driver inputs
    driver.Update(vis.GetDevice()->GetKeyboard()->GetState())

    # Update vehicle and terrain
    my_system.DoStepDynamics(0.01)

    # Process sensor data
    imu_data = imu.GetOutput()
    gps_data = gps.GetOutput()

    # Output vehicle mass
    print("Vehicle mass:", vehicle.GetMass())

    vis.EndScene()

    # Handle Irrlicht events
    vis.GetDevice()->PollEvents()

    # Exit if ESC key is pressed
    if vis.GetDevice()->IsKeyDown(chrono.irr::KEY_ESCAPE):
        break

```

**Explanation:**

1. **Initialization:**
   - Creates a `ChSystemNSC` object for the simulation.
   - Sets gravity and solver type.

2. **Adding Objects:**
   - **Terrain:** Loads a heightmap and creates a terrain body.
   - **HMMWV:** Instantiates a pre-built HMMWV vehicle model.
   - **Driver:** Sets up a driver module for controlling the vehicle (placeholder for more complex control logic).
   - **Sensors:** Creates IMU and GPS sensor objects attached to the vehicle's chassis.

3. **Default Parameters:**
   - Sets initial mass, inertia, and sensor parameters.

4. **Visual Interface:**
   - Uses Irrlicht for rendering.
   - Creates a window, adds sky, lights, and a camera.

5. **Simulation Loop:**
   - Runs until the user exits.
   - Renders the scene using Irrlicht.
   - Processes driver inputs.
   - Updates the vehicle and terrain physics.
   - Retrieves sensor data.
   - Prints the vehicle's mass.
   - Handles Irrlicht events and checks for exit condition.
