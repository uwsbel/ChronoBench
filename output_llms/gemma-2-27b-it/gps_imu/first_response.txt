```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# 1. Initialize the PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)

# 2. Add terrain
terrain = chrono.ChTerrainModel(chrono.ChTerrainModel.Type_HEIGHTMAP)
terrain.SetTexture(chrono.GetChronoDataPath() + 'terrain/textures/grass.png')
terrain.SetHeightmap(chrono.GetChronoDataPath() + 'terrain/heightmaps/heightmap.png')
terrain_shape = chrono.ChBodyEasyBox(
    chrono.ChVectorD(100, 1, 100), 1000, True, True
)
terrain_shape.SetPos(chrono.ChVectorD(0, 0, 0))
terrain_body = chrono.ChBody(terrain_shape)
terrain_body.SetBodyFixed(True)
my_system.Add(terrain_body)

# 3. Add HMMWV vehicle
vehicle = chrono.ChVehicleModelHMMWV(my_system)
vehicle.SetChassisPosition(chrono.ChVectorD(0, 2, 0))

# 4. Add driver inputs
driver = chrono.ChDriver(vehicle)

# 5. Add IMU and GPS sensors
imu = chrono.ChIMU(vehicle.GetChassisBody())
imu.SetPos(chrono.ChVectorD(0, 1, 0))
gps = chrono.ChGPS(vehicle.GetChassisBody())
gps.SetPos(chrono.ChVectorD(0, 1.5, 0))

# 6. Initialize Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("HMMWV Simulation")
vis.Initialize()

# 7. Simulation loop
while vis.Run():
    # Update driver inputs (example: steering and throttle)
    driver.SetSteering(math.sin(chrono.GetChTime()))
    driver.SetThrottle(0.5)

    # Update IMU and GPS data
    imu_data = imu.GetReadings()
    gps_data = gps.GetReadings()

    # Process sensor data (example: print vehicle mass)
    print("Vehicle Mass:", vehicle.GetChassisBody().GetMass())

    # Advance the simulation
    my_system.DoStepDynamics(0.01)

    # Render the scene
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - We create a `ChSystemNSC` object to represent the physical system.
   - Gravity is set, and the solver type is chosen.

2. **Terrain:**
   - A heightmap terrain is loaded using `ChTerrainModel`.
   - A simple box shape is used to represent the terrain body.

3. **HMMWV Vehicle:**
   - A pre-built HMMWV vehicle model (`ChVehicleModelHMMWV`) is added to the system.

4. **Driver Inputs:**
   - A `ChDriver` object is created to simulate driver actions.

5. **Sensors:**
   - An IMU (`ChIMU`) and a GPS (`ChGPS`) are attached to the vehicle's chassis.

6. **Visualization:**
   - `ChVisualSystemIrrlicht` is used for rendering the scene using Irrlicht.

7. **Simulation Loop:**
   - The loop runs until the Irrlicht window is closed.
   - Driver inputs are updated (steering and throttle in this example).
   - Sensor data is retrieved and processed.
   - The simulation is advanced using `DoStepDynamics`.
   - The scene is rendered using `vis.Render()`.
