```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files

# Create the physical system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add terrain
terrain = chrono.ChBodyEasyBox(
    100, 100, 1, 1000, True, True, chrono.ChMaterialSurfaceNSC()
)
terrain.SetPos(chrono.ChVectorD(0, -1, 0))
system.Add(terrain)

# 3. Add HMMWV vehicle
vehicle = chronovehicle.ChVehicleModelHMMWV(system)

# Set initial position and orientation
vehicle.SetChassisPosition(chrono.ChVectorD(0, 1, 0))
vehicle.SetChassisOrientation(chrono.Q_from_AngAxis(chrono.CH_C_PI / 4, chrono.ChVectorD(0, 0, 1)))

# 4. Add driver inputs
driver = chronovehicle.ChIrrGuiDriver(vehicle)

# 5. Add IMU and GPS sensors
imu = chronovehicle.ChSensorIMU(vehicle.GetChassisBody())
gps = chronovehicle.ChSensorGPS(vehicle.GetChassisBody())

# 6. Initialize Irrlicht visual system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("HMMWV Simulation")
vis.Initialize()

# 7. Simulation loop
while vis.Run():
    # Get driver inputs
    driver.Update(vis.GetTimeStep())

    # Update sensor data
    imu.Update()
    gps.Update()

    # Advance the simulation
    system.DoStepDynamics(vis.GetTimeStep())

    # Output vehicle mass
    print("Vehicle mass:", vehicle.GetVehicleMass())

    # Render the scene
    vis.Render()

# Cleanup
vis.Destroy()
```

**Explanation:**

1. **Initialization:**

   - Imports necessary PyChrono modules.
   - Sets the Chrono data path for loading assets.
   - Creates a Chrono system with standard gravity.

2. **Terrain:**

   - Creates a simple box terrain using `ChBodyEasyBox`.
   - Positions the terrain below the vehicle.

3. **Vehicle:**

   - Instantiates an HMMWV vehicle model using `ChVehicleModelHMMWV`.
   - Sets the initial position and orientation of the vehicle.

4. **Driver Inputs:**

   - Creates a driver object using `ChIrrGuiDriver` to handle user input through the Irrlicht interface.

5. **Sensors:**

   - Adds an IMU (`ChSensorIMU`) and GPS (`ChSensorGPS`) sensor attached to the vehicle's chassis.

6. **Visual System:**

   - Initializes the Irrlicht visual system (`ChVisualSystemIrrlicht`).
   - Attaches the Chrono system to the visualizer.
   - Sets window size and title.
   - Initializes the Irrlicht engine.

7. **Simulation Loop:**

   - Continuously runs until the Irrlicht window is closed.
   - Updates driver inputs based on user interaction.
   - Updates IMU and GPS sensor data.
   - Advances the Chrono system simulation by one time step.
   - Prints the vehicle's mass to the console.
   - Renders the current scene using Irrlicht.

8. **Cleanup:**

   - Destroys the Irrlicht visual system when the simulation loop exits.
