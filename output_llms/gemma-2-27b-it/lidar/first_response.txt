```python
import pychrono as chrono
import pychrono.postprocess as postprocess
import pychrono.irrlicht as chronoirr
import numpy as np

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("data/")
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)

# 2. Add the triangular mesh as a fixed body
mesh_file = "your_mesh.obj"  # Replace with your .obj file path
mesh = chrono.ChTriangleMeshConnected()
mesh.LoadWavefrontMesh(mesh_file)
body = chrono.ChBody()
body.SetBodyFixed(True)
body.SetCollide(True)
shape = chrono.ChTriangleMeshShape()
shape.SetMesh(mesh)
body.AddShape(shape)
my_system.Add(body)

# 3. Add lidar sensor to the body
sensor_manager = chrono.ChSensorManager(my_system)
lidar = chrono.ChLidarSensor()
lidar.SetCollisionEncapsulation(True)

# Set lidar parameters
lidar.SetVerticalFOV(chrono.CH_C_PI / 4)
lidar.SetHorizontalFOV(chrono.CH_C_PI / 2)
lidar.SetMaxRange(10)
lidar.SetSamplingDistance(0.1)
lidar.SetNumRays(100)

# Apply noise filters
lidar.AddNoise(chrono.ChNoiseGaussian(0.01))

# Visualization and saving options
lidar.SetVisualization(True)
lidar.SetSaveData(True)
lidar.SetOutputFile("lidar_data.txt")

# Attach lidar to the body
body.AddSensor(lidar)

# 4. Simulation loop
# Create Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Lidar Simulation")
vis.Initialize()

# Simulation parameters
time_step = 0.01
simulation_time = 10

# Orbital parameters
radius = 5
angular_speed = 1

while vis.Run():
    # Update lidar position in orbit
    angle = angular_speed * my_system.GetChTime()
    lidar.SetPos(chrono.ChVectorD(radius * np.cos(angle), 0, radius * np.sin(angle)))

    # Simulate one time step
    my_system.DoStepDynamics(time_step)

    # Print lidar buffer data
    print(lidar.GetBuffer())

vis.Deinitialize()
```

**Explanation:**

1. **Initialization:**
   - Sets up the Chrono environment and defines the gravity.
   - Creates a `ChSystemNSC` for the simulation.
2. **Mesh Loading:**
   - Loads the triangular mesh from the specified `.obj` file.
   - Creates a fixed body (`ChBody`) and attaches the mesh shape to it.
3. **Lidar Sensor:**
   - Creates a `ChLidarSensor` and configures its parameters:
     - Field of view (vertical and horizontal)
     - Maximum range
     - Sampling distance
     - Number of rays
   - Adds Gaussian noise to the lidar readings.
   - Enables visualization and data saving.
   - Attaches the lidar to the body.
4. **Simulation Loop:**
   - Initializes the Irrlicht visualization system.
   - Sets the simulation time step and duration.
   - Defines orbital parameters for the lidar.
   - In each iteration:
     - Updates the lidar's position in a circular orbit.
     - Performs a simulation step.
     - Prints the lidar buffer data (point cloud).

**Remember:**



* Replace `"your_mesh.obj"` with the actual path to your mesh file.
* Adjust simulation parameters (time step, duration, orbital parameters) as needed.
* Explore additional lidar settings and noise models in the PyChrono documentation.
