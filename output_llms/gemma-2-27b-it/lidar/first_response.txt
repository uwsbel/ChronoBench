```python
import pychrono as chrono
import pychrono.postprocess as postprocess
import pychrono.irrlicht as chronoirr
import numpy as np

# 1. Initialize PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add the triangular mesh as a fixed body
mesh_file = "your_mesh.obj"  # Replace with your .obj file path
mesh = chrono.ChTriangleMeshConnected()
mesh.LoadWavefrontMesh(mesh_file)
body = chrono.ChBody()
body.SetPos(chrono.ChVectorD(0, 0, 0))  # Set initial position
body.SetBodyFixed(True)
body.SetCollide(True)
body.AddAsset(chrono.ChTriangleMeshShape(mesh))
my_system.Add(body)

# 3. Add lidar sensor to the body
sensor_manager = chrono.ChSensorManager(my_system)
lidar = chrono.ChLidarSensor()
lidar.SetCollisionEnvelope(0.1)  # Adjust collision envelope as needed
lidar.SetFrequency(10)  # Set lidar scan frequency

# Apply noise filters
lidar.AddFilter(chrono.ChLidarNoiseFilterGaussian(0.01))  # Example Gaussian noise filter

# Set visualization options
lidar.SetVisualization(True)

# Set saving options
lidar.SetSaveData(True, "lidar_data.txt")  # Save lidar data to a text file

# Attach lidar to the body
sensor_manager.AddSensor(lidar)
lidar.AttachToBody(body)

# Simulation loop
timestep = 0.01
simulation_time = 10

# Initialize orbit parameters
radius = 5
angular_speed = 0.5

for i in range(int(simulation_time / timestep)):
    # Update lidar position in orbit
    angle = angular_speed * i * timestep
    lidar_pos = chrono.ChVectorD(radius * np.cos(angle), 0, radius * np.sin(angle))
    lidar.SetPos(lidar_pos)

    # Perform simulation step
    my_system.DoStepDynamics(timestep)

    # Print lidar buffer data
    print(lidar.GetBufferData())

# Save the simulation
postprocess.ChPostProcessVRML(my_system, "simulation.wrl")

# Visualize the simulation
chronoirr.ChIrrApp(my_system, "PyChrono Simulation", chronoirr.dimension2du(800, 600))
```

**Explanation:**

1. **Initialization:**

   - We create a `ChSystemNSC` object to represent the physical system.
   - We set the gravitational acceleration.

2. **Mesh Loading:**

   - We load the triangular mesh from the specified `.obj` file using `ChTriangleMeshConnected` and `LoadWavefrontMesh`.
   - We create a `ChBody` object to represent the mesh, set its position, fix it in place, and add the mesh shape as a collision asset.

3. **Lidar Sensor:**

   - We create a `ChSensorManager` to manage sensors.
   - We create a `ChLidarSensor` object and configure its properties:
     - `SetCollisionEnvelope`: Defines the range within which the lidar detects collisions.
     - `SetFrequency`: Sets how often the lidar takes scans.
   - We add noise filters (here, a Gaussian noise filter) to simulate real-world sensor imperfections.
   - We enable visualization of the lidar's scan rays.
   - We enable saving the lidar data to a text file.
   - We attach the lidar to the mesh body using `AttachToBody`.

4. **Simulation Loop:**

   - We set the simulation timestep and total simulation time.
   - We initialize parameters for the lidar's orbital motion.
   - In each iteration:
     - We update the lidar's position based on its orbital parameters.
     - We perform a simulation step using `DoStepDynamics`.
     - We print the lidar's buffer data (containing distance measurements).

5. **Post-Processing and Visualization:**

   - We save the simulation results in VRML format.
   - We use `ChIrrApp` to visualize the simulation interactively.

**Remember:**

- Replace `"your_mesh.obj"` with the actual path to your mesh file.
- Adjust parameters like `radius`, `angular_speed`, lidar settings, and noise filters to match your specific simulation requirements.
