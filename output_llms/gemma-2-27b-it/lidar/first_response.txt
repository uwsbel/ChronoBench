```python
import pychrono as chrono
import pychrono.postprocess as postprocess
import pychrono.irrlicht as irr
import numpy as np

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("data/")

# Create the physical system
system = chrono.ChSystemNSC()

# Create the Irrlicht visualization system
vis = irr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Lidar on Triangular Mesh")
vis.Initialize()
vis.AddCamera(chrono.ChCamera(chrono.ChVectorD(2, 2, 2)))

# 2. Add the required physical systems and objects

# Load the triangular mesh from .obj file
mesh = chrono.ChTriangleMeshConnected()
mesh.LoadWavefrontMesh("your_mesh.obj")

# Create a fixed body and attach the mesh
body = chrono.ChBody()
body.SetBodyFixed(True)
body.SetCollide(True)
body.AddAsset(chrono.ChTriangleMeshShape(mesh))
system.Add(body)

# 3. Set necessary default parameters

# Create a lidar sensor manager
lidar_manager = chrono.ChLidarSensorManager(system)

# Create a lidar sensor
lidar = chrono.ChLidarSensor()
lidar.SetCollisionEnforcer(chrono.ChCollisionEnforcer::Type_BOX)

# Set lidar parameters
lidar.SetVerticalAngle(chrono.ChRadians(np.pi / 4))
lidar.SetHorizontalAngle(chrono.ChRadians(np.pi / 2))
lidar.SetRange(10)
lidar.SetMaxDistance(5)
lidar.SetNumRays(128)

# Add noise filter to the lidar data
lidar.AddNoiseFilter(chrono.ChLidarNoiseFilterGaussian(0.01))

# Enable lidar visualization
lidar.SetVisualization(True)

# Set lidar data saving options
lidar.SetSaveData(True)
lidar.SetSaveFile("lidar_data.txt")

# Attach lidar to the body
lidar_manager.AddSensor(lidar)
lidar.AttachToBody(body)

# Simulation loop
while vis.Run():
    # Update lidar position in an orbit around the mesh
    angle = system.GetChTime() * 0.5
    lidar.SetPos(chrono.ChVectorD(2 * np.cos(angle), 2 * np.sin(angle), 2))

    # Simulate one timestep
    system.DoStepDynamics(0.01)

    # Print lidar buffer data
    print(lidar.GetBuffer())

    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**

- Sets up the Chrono environment and creates the physical system.
- Initializes the Irrlicht visualization system for rendering.

2. **Adding Objects:**

- Loads the triangular mesh from the specified .obj file.
- Creates a fixed body and attaches the mesh to it.

3. **Setting Parameters:**

- Creates a lidar sensor manager and a lidar sensor.
- Configures lidar parameters like vertical/horizontal angles, range, and number of rays.
- Adds a Gaussian noise filter to simulate real-world lidar imperfections.
- Enables lidar visualization and sets data saving options.
- Attaches the lidar sensor to the body and positions it initially.

4. **Simulation Loop:**

- Continuously updates the lidar's position in a circular orbit around the mesh.
- Performs a single simulation step.
- Prints the lidar buffer data, which contains distance measurements for each ray.
- Renders the scene using Irrlicht.

**Remember to:**

- Replace `"your_mesh.obj"` with the actual path to your .obj file.
- Adjust lidar parameters and noise filter settings as needed for your specific simulation.
