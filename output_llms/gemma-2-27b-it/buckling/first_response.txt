```python
import pychrono as chrono
import pychrono.fea as fea
import pychrono.irrlicht as chronoirr

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Create the beam using FEA
beam_material = fea.ChMaterialShellANCF(
    rho=7850, E=200e9, nu=0.3, G=76.9e9, thickness=0.01
)
beam_section = fea.ChSectionShellANCF()
beam_geometry = fea.ChGeometryShell()
beam_geometry.AddSegmentCircular(radius=0.05, arc_angle=2 * chrono.CH_C_PI)

beam = fea.ChBeamFEAelement(beam_material, beam_section, beam_geometry)
beam.SetNumStepsAlongX(10)  # Discretize the beam into 10 elements

# 3. Add the beam to the system
my_system.Add(beam)

# 4. Define custom motor functions (example: sinusoidal force)
class MyMotorFunction(chrono.ChFunction):
    def __init__(self, amplitude, frequency):
        chrono.ChFunction.__init__(self)
        self.amplitude = amplitude
        self.frequency = frequency

    def Get_y(self, x):
        return self.amplitude * chrono.Sin(self.frequency * x)

motor_function = MyMotorFunction(amplitude=100, frequency=2)

# 5. Define constraints (example: fixed support at one end)
fixed_point = chrono.ChLinkLockRevolute(
    beam.GetNode(0), chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0))
)
my_system.Add(fixed_point)

# 6. Apply force using the custom motor function
force_node = beam.GetNode(beam.GetNumNodes() - 1)
force_dir = chrono.ChVectorD(0, 1, 0)
force_application = chrono.ChForce(force_node, force_dir)
force_application.SetForceFunction(motor_function)
my_system.Add(force_application)

# 7. Set up solver and timestepper
solver = chrono.ChSolverMINRES()
my_system.SetSolver(solver)
timestepper = chrono.ChTimestepperHHT(my_system, 0.01, 0.9)

# 8. Visualization using Irrlicht
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Beam Buckling Simulation")
vis.Initialize()
vis.Run()

# 9. Simulation loop
while vis.Run():
    timestepper.Advance(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:** Sets up the PyChrono environment, system, and gravity.
2. **Beam Creation:** Defines the beam material, section, geometry, and FEA element. Discretizes the beam into elements.
3. **Adding Beam:** Adds the created beam to the PyChrono system.
4. **Custom Motor Function:** Defines a sinusoidal force function using `chrono.ChFunction`.

5. **Constraints:** Adds a fixed revolute joint constraint to fix one end of the beam.
6. **Force Application:** Applies a force to the other end of the beam using the custom motor function.
7. **Solver and Timestepper:** Sets up the MINRES solver and HHT timestepper for accurate dynamics simulation.
8. **Visualization:** Initializes the Irrlicht visualization module and connects it to the system.
9. **Simulation Loop:** Runs the simulation loop, advancing the timestepper and rendering the visualization.

**Remember:**

- This is a basic example and can be further customized with more complex geometries, loading conditions, and constraints.
- Adjust parameters like beam dimensions, material properties, force amplitude, and frequency to observe different buckling behaviors.
- Explore other PyChrono features like contact mechanics, collision detection, and advanced visualization options.
