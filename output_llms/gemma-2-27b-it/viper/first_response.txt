```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add ground body and terrain
ground = chrono.ChBodyEasyBox(100, 1, 100, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# 3. Initialize Viper rover and driver
# (This part requires you to have the Viper rover model and driver implementation)
rover = chrono.YourViperRoverClass(system)
rover.SetPos(chrono.ChVectorD(0, 0.5, 0))

driver = chrono.YourDriverClass(rover)

# 4. Create Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Viper Rover Simulation")
vis.Initialize()
camera = vis.GetCamera()
camera.SetLocation(chrono.ChVectorD(5, 5, 2))
camera.SetLookAt(chrono.ChVectorD(0, 0.5, 0))

# 5. Simulation loop
time_step = 0.01
simulation_time = 10.0
steering_change_time = 5.0

initial_steering = 0.0
final_steering = math.pi / 4  # 45 degrees

for t in range(int(simulation_time / time_step)):
    # Calculate steering angle based on time
    current_time = t * time_step
    if current_time <= steering_change_time:
        steering_angle = initial_steering + (final_steering - initial_steering) * (current_time / steering_change_time)
    else:
        steering_angle = final_steering

    # Apply steering to rover
    rover.SetSteeringAngle(steering_angle)

    # Update and render the simulation
    system.DoStepDynamics(time_step)
    vis.Render()

# 6. Clean up
vis.Deinitialize()
```

**Explanation:**

1. **Initialization:** Sets up the Chrono system, gravity, and a ground body.
2. **Rover and Driver:** This section requires you to have your own Viper rover and driver implementations. Replace `YourViperRoverClass` and `YourDriverClass` with your actual classes.
3. **Visualization:** Creates an Irrlicht visualizer, sets up the camera, and initializes the visualization system.
4. **Simulation Loop:**
   - Iterates over a specified simulation time.
   - Calculates the steering angle based on a linear change over a specified time period.
   - Applies the steering angle to the rover.
   - Updates the physics simulation and renders the scene.
5. **Cleanup:** Deinitializes the Irrlicht visualizer.
