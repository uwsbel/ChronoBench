```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#
# ---------------------------------------------------------------------

# Create a Chrono system
system = chrono.ChSystemNSC()

# Set the default gravity
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body
ground = chrono.ChBodyEasyBox(100, 1, 100, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# ---------------------------------------------------------------------
#
#  Create the Viper rover
#
# ---------------------------------------------------------------------

# Load the Viper rover model (replace with your actual file path)
rover = chrono.ChWheeledVehicle(system)
rover.SetChassisCollisionShape(chrono.ChCollisionShape())
rover.SetChassisBody(chrono.ChBodyEasyBox(2, 1, 3, 1000, True, True))
rover.SetChassisFixed(False)
rover.SetInitPosition(chrono.ChVectorD(0, 1, 0))

# Add wheels (replace with your actual wheel parameters)
wheel_radius = 0.3
wheel_width = 0.1
for i in range(4):
    wheel = chrono.ChWheel(system)
    wheel.SetRadius(wheel_radius)
    wheel.SetWidth(wheel_width)
    wheel.SetFriction(0.8)
    wheel.SetSuspensionStiffness(1000)
    wheel.SetSuspensionDamping(100)
    wheel.SetSteering(False)
    if i < 2:
        wheel.SetPos(chrono.ChVectorD(1, -wheel_radius, 1.5 - i * 1.5))
    else:
        wheel.SetPos(chrono.ChVectorD(-1, -wheel_radius, 1.5 - (i - 2) * 1.5))
    rover.AddWheel(wheel)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization
#
# ---------------------------------------------------------------------

# Create an Irrlicht application
vis = chronoirr.ChIrrApp(system, "Viper Rover Simulation", chrono.ChVectorD(0, 2, -5))
vis.AddTypicalCamera(chrono.ChVectorD(0, 1, -3))
vis.AddLight(chrono.ChVectorD(0, 5, 0), chrono.ChColor(1, 1, 1))
vis.SetCameraPosition(chrono.ChVectorD(0, 2, -5))
vis.SetCameraLookAt(chrono.ChVectorD(0, 1, 0))

# ---------------------------------------------------------------------
#
#  Simulation loop
#
# ---------------------------------------------------------------------

# Simulation parameters
time_step = 0.01
total_time = 10
steering_change_time = 5

# Steering angle
steering_angle = 0

while vis.GetDevice().run():
    # Update the rover's steering
    if system.GetChTime() < steering_change_time:
        steering_angle = math.sin(system.GetChTime() * 2 * math.pi / steering_change_time) * 0.5
    else:
        steering_angle = 0

    rover.SetSteeringAngle(steering_angle)

    # Advance the simulation
    system.DoStepDynamics(time_step)

    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.DoStep()
    vis.EndScene()

    # Check if the simulation is finished
    if system.GetChTime() >= total_time:
        break

# Quit the Irrlicht application
vis.GetDevice().close()
```

**Explanation:**

1. **Initialization:**
   - Creates a Chrono system with gravity.
   - Adds a ground body as a fixed obstacle.
   - Loads the Viper rover model (you'll need to replace the placeholder file path with your actual model).

2. **Rover Setup:**
   - Defines the rover's chassis and adds four wheels with specified parameters.
   - Sets the initial position of the rover.

3. **Visualization:**
   - Creates an Irrlicht application for real-time visualization.
   - Adds a camera and light source for better viewing.

4. **Simulation Loop:**
   - Sets the time step and total simulation time.
   - Defines a `steering_change_time` for gradual steering adjustment.
   - In each iteration:
     - Updates the rover's steering angle based on the current simulation time.
     - Advances the simulation using `DoStepDynamics`.
     - Renders the scene using Irrlicht.
     - Checks if the simulation time has reached the end.

5. **Cleanup:**
   - Closes the Irrlicht application.

**Remember:**



* Replace the placeholder file path for the Viper rover model with your actual file.
* Adjust the wheel parameters (radius, width, friction, suspension) according to your rover's specifications.
* Modify the steering logic and simulation parameters as needed for your specific scenario.
