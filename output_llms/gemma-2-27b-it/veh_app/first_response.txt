```python
import pychrono as chrono
import pychrono.postprocess as postprocess
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system
#
# ---------------------------------------------------------------------

mysystem = chrono.ChSystemNSC()
mysystem.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Set simulation parameters
mysystem.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
mysystem.SetSolverMaxIterations(100)
mysystem.SetTimestepperType(chrono.ChTimestepper.Type_EULER_IMPLICIT_LINEARIZED)

# ---------------------------------------------------------------------
#
# Create the terrain
#
# ---------------------------------------------------------------------

terrain = chrono.ChBodyEasyBox(
    200, 200, 1, 1000, True, True, chrono.ChMaterialSurface.NSC
)
terrain.SetPos(chrono.ChVectorD(0, -1, 0))
terrain.SetBodyFixed(True)
mysystem.Add(terrain)

# ---------------------------------------------------------------------
#
# Create the Gator vehicle
#
# ---------------------------------------------------------------------

gator = chrono.ChVehicle(mysystem)

# Chassis
chassis = chrono.ChBodyEasyBox(
    2.5, 1.2, 0.8, 1000, True, True, chrono.ChMaterialSurface.NSC
)
chassis.SetPos(chrono.ChVectorD(0, 1, 0))
gator.SetChassisBody(chassis)

# Wheels
wheel_radius = 0.3
wheel_width = 0.2
for i in range(4):
    wheel = chrono.ChWheel(
        chrono.ChBodyEasyCylinder(wheel_radius, wheel_width, 1000),
        chrono.ChContactMethod.NSC,
    )
    wheel.SetPos(
        chrono.ChVectorD(
            (-1.2 + i * 0.8, -0.6, 0),
        )
    )
    gator.AddWheel(wheel)

# Visualization
chassis.AddAsset(chrono.ChAssetLevel(chrono.ChTexture(chrono.GetChronoDataPath() + "blue.png")))
chassis.SetCollide(True)
chassis.SetBodyFixed(False)

for wheel in gator.GetWheels():
    wheel.GetBody().AddAsset(chrono.ChAssetLevel(chrono.ChTexture(chrono.GetChronoDataPath() + "black.png")))
    wheel.GetBody().SetCollide(True)
    wheel.GetBody().SetBodyFixed(False)

mysystem.Add(gator)

# ---------------------------------------------------------------------
#
# Create the driver system
#
# ---------------------------------------------------------------------

driver = chrono.ChDriverSteering(gator)
driver.SetSteeringAngle(0)
driver.SetTargetSpeed(5)

# ---------------------------------------------------------------------
#
# Create the sensor manager
#
# ---------------------------------------------------------------------

sensor_manager = postprocess.ChSensorManager(mysystem)

# Point light
light = postprocess.ChLightPoint(chrono.ChVectorD(5, 5, 5))
sensor_manager.AddSensor(light)

# Camera
camera = postprocess.ChCamera(chrono.ChVectorD(0, 2, 0))
camera.SetLookAt(chrono.ChVectorD(0, 0, 0))
camera.SetFOV(60)
sensor_manager.AddSensor(camera)

# Attach camera to chassis
camera.AttachToBody(chassis)

# ---------------------------------------------------------------------
#
# Create the Irrlicht visualization
#
# ---------------------------------------------------------------------

vis = chronoirr.ChIrrApp(mysystem, sensor_manager)
vis.SetWindowSize(1280, 720)
vis.SetStep(0.01)
vis.SetShowProfiler(True)
vis.AddTypicalLights()
vis.AddSkyBox()

# ---------------------------------------------------------------------
#
# Simulation loop
#
# ---------------------------------------------------------------------

while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()

    # Update driver
    driver.Update(vis.GetTime())

    # Update sensor manager
    sensor_manager.Update()

    # Advance the simulation
    mysystem.DoStepDynamics(vis.GetTimeStep())

    vis.EndScene()

```

**Explanation:**

1. **Initialization:**
   - Creates a Chrono system (`mysystem`) with gravity.
   - Sets solver type, max iterations, and timestepper type.

2. **Terrain:**
   - Creates a box-shaped terrain (`terrain`) with specified dimensions and material.
   - Sets its position and makes it fixed.
   - Adds it to the system.

3. **Gator Vehicle:**
   - Creates a `ChVehicle` object (`gator`).
   - Defines the chassis as a box (`chassis`).
   - Adds four wheels (`wheel`) with specified radius, width, and contact method.
   - Sets visualization properties for chassis and wheels, including textures and collision flags.
   - Adds the vehicle to the system.

4. **Driver System:**
   - Creates a `ChDriverSteering` object (`driver`) to control the vehicle.
   - Sets initial steering angle and target speed.

5. **Sensor Manager:**
   - Creates a `ChSensorManager` (`sensor_manager`) to handle sensors.
   - Adds a point light (`light`) and a camera (`camera`) to the manager.
   - Attaches the camera to the vehicle's chassis.

6. **Visualization:**
   - Creates an Irrlicht visualization (`vis`) linked to the system and sensor manager.
   - Sets window size, time step, profiler visibility, and adds lights and skybox.

7. **Simulation Loop:**
   - Runs the Irrlicht application loop.
   - In each iteration:
     - Renders the scene.
     - Updates the driver.
     - Updates the sensor manager.
     - Advances the simulation using `DoStepDynamics`.



**Notes:**

- This script provides a basic framework. You can customize vehicle parameters, sensor configurations, driver behavior, and visualization settings as needed.
- Make sure you have PyChrono installed and the necessary dependencies (Irrlicht, etc.) set up.
