```python
import pychrono as chrono
import pychrono.ros as chroro
import rospy
from std_msgs.msg import Int32

# Initialize PyChrono environment
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Set material properties
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.5)
material.SetRestitution(0.2)

# Create floor
floor = chrono.ChBodyEasyBox(10, 0.1, 10, 1000, True, True, material)
floor.SetPos(chrono.ChVectorD(0, -0.1, 0))
floor.SetBodyFixed(True)
my_system.Add(floor)

# Create movable box
box = chrono.ChBodyEasyBox(0.5, 0.5, 0.5, 10, True, True, material)
box.SetPos(chrono.ChVectorD(0, 1, 0))
my_system.Add(box)

# Initialize ROS
rospy.init_node('chrono_ros_node')

# Create custom ROS handler
class CustomRosHandler(chroro.ChROSMessageHandler):
    def __init__(self, topic_name):
        super().__init__()
        self.pub = rospy.Publisher(topic_name, Int32, queue_size=10)

    def OnUpdate(self, data):
        msg = Int32()
        msg.data = int(data)
        self.pub.publish(msg)

# Configure ROS manager
ros_manager = chroro.ChROSManager(my_system)
ros_manager.SetClockHandler(chroro.ChROSClockHandler())
ros_manager.SetBodyHandler(chroro.ChROSBodyHandler())
ros_manager.SetTransformHandler(chroro.ChROSTransformHandler())
ros_manager.AddHandler(CustomRosHandler('/custom_topic'))

# Simulation loop
dt = 0.001
while not rospy.is_shutdown():
    my_system.DoStepDynamics(dt)
    ros_manager.Update()
    rospy.rostime.wallsleep(dt)

```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules.
   - Creates a Chrono system (`my_system`) with gravitational acceleration.
   - Defines a material with friction and restitution properties.

2. **Object Creation:**
   - Creates a fixed floor using `ChBodyEasyBox` and sets its position and fixed status.
   - Creates a movable box, also using `ChBodyEasyBox`, and sets its initial position.

3. **ROS Integration:**
   - Initializes a ROS node named `chrono_ros_node`.
   - Defines a custom ROS handler (`CustomRosHandler`) that publishes integer messages to a specified topic (`/custom_topic`).
   - Creates a ROS manager (`ros_manager`) and configures it with clock, body, and transform handlers.
   - Registers the custom ROS handler with the manager.

4. **Simulation Loop:**
   - Sets the simulation timestep (`dt`).
   - Enters a loop that continues until ROS shuts down.
   - Advances the Chrono system by one timestep using `DoStepDynamics`.
   - Updates ROS communication using `ros_manager.Update()`.
   - Pauses for the duration of the timestep using `rospy.rostime.wallsleep(dt)` to maintain real-time execution.

**Notes:**

- This script provides a basic framework for integrating PyChrono with ROS. You can customize it further by adding more complex objects, interactions, and ROS communication logic.
- Remember to replace `/custom_topic` with the desired ROS topic name.
- The `CustomRosHandler` example simply publishes an integer value based on the input data. You can modify this to publish other message types or perform more complex processing.
