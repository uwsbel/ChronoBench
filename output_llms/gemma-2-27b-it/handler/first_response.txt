```python
import pychrono as chrono
import pychrono.ros as chroro
import rospy
from std_msgs.msg import Int32

# 1. Initialize PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravitational acceleration

# 2. Add physical systems and objects
# a. Fixed floor
floor_material = chrono.ChMaterialSurfaceNSC()
floor_material.SetFriction(0.5)
floor_material.SetRestitution(0.2)
floor = chrono.ChBodyEasyBox(10, 0.1, 10, 1000, True, True, floor_material)
floor.SetPos(chrono.ChVectorD(0, -0.1, 0))
floor.SetBodyFixed(True)
my_system.Add(floor)

# b. Movable box
box_material = chrono.ChMaterialSurfaceNSC()
box_material.SetFriction(0.8)
box_material.SetRestitution(0.3)
box = chrono.ChBodyEasyBox(1, 1, 1, 10, True, True, box_material)
box.SetPos(chrono.ChVectorD(0, 2, 0))
my_system.Add(box)

# 3. Set default parameters
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
my_system.SetTimestepperType(chrono.ChTimestepper.Type_EULER_IMPLICIT_LINEARIZED)
my_system.SetStep(0.01)

# 4. ROS Integration

# a. Create ROS node
rospy.init_node('chrono_ros_node', anonymous=True)

# b. Custom ROS handler
class CustomRosHandler(chroro.ChROSHandler):
    def __init__(self, topic_name):
        super().__init__()
        self.pub = rospy.Publisher(topic_name, Int32, queue_size=10)

    def Update(self, time):
        msg = Int32()
        msg.data = int(time * 1000)  # Publish time in milliseconds
        self.pub.publish(msg)

# c. ROS Manager configuration
ros_manager = chroro.ChROSManager(my_system)
ros_manager.SetClockHandler(chroro.ChROSClockHandler())
ros_manager.SetBodyHandler(chroro.ChROSBodyHandler())
ros_manager.SetTransformHandler(chroro.ChROSTransformHandler())
custom_handler = CustomRosHandler('/chrono_time')
ros_manager.AddHandler(custom_handler)

# 5. Simulation loop
while True:
    my_system.DoStepDynamics(0.01)
    ros_manager.Update()
    rospy.rostime.wallsleep(0.01)  # Maintain real-time execution

```

**Explanation:**

1. **Initialization:**
   - Creates a Chrono system (`my_system`) and sets gravitational acceleration.

2. **Objects:**
   - Defines a fixed floor and a movable box with specified dimensions, materials, and initial positions.

3. **Parameters:**
   - Sets solver type, timestepper type, and simulation step size.

4. **ROS Integration:**
   - Initializes a ROS node.
   - Creates a custom ROS handler (`CustomRosHandler`) that publishes the simulation time as an integer message to a specified topic.
   - Configures the ROS manager (`ros_manager`) with clock, body, and transform handlers.
   - Registers the custom handler with the ROS manager.

5. **Simulation Loop:**
   - Runs a continuous loop, advancing the Chrono system (`DoStepDynamics`) at each timestep.
   - Updates ROS communication (`ros_manager.Update()`).
   - Uses `rospy.rostime.wallsleep()` to maintain real-time execution.

**Remember:**

- Replace `/chrono_time` with the desired ROS topic name.
- Adjust simulation parameters (e.g., step size, object properties) as needed.
