```python
import pychrono.core as chrono
import pychrono.postprocess as postprocess
import pychrono.irrlicht as chronoirr
import rospy
from std_msgs.msg import Int32

# ROS integration setup
rospy.init_node('chrono_ros_node')
pub = rospy.Publisher('chrono_data', Int32, queue_size=10)

class CustomRosHandler(chrono.ChROSDataHandler):
    def __init__(self, ros_pub):
        chrono.ChROSDataHandler.__init__(self)
        self.ros_pub = ros_pub

    def OnUpdate(self, system, time):
        # Publish custom data to ROS topic
        data = Int32()
        data.data = int(system.GetChTime())  # Example: Publish simulation time as integer
        self.ros_pub.publish(data)

# PyChrono simulation setup
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravitational acceleration

# Material properties
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.5)
material.SetRestitution(0.2)

# Floor
floor = chrono.ChBodyEasyBox(10, 0.1, 10, 1000, True, True, material)
floor.SetPos(chrono.ChVectorD(0, -0.1, 0))
floor.SetBodyFixed(True)
system.Add(floor)

# Movable box
box = chrono.ChBodyEasyBox(1, 1, 1, 10, True, True, material)
box.SetPos(chrono.ChVectorD(0, 2, 0))
system.Add(box)

# ROS manager setup
ros_manager = chrono.ChROSManager(system)
ros_manager.SetClock(chrono.ChROSRealTimeClock())
ros_manager.SetBodyHandler(chrono.ChROSBodyHandler())
ros_manager.SetTransformHandler(chrono.ChROSTransformHandler())

# Register custom ROS handler
custom_handler = CustomRosHandler(pub)
ros_manager.AddHandler(custom_handler)

# Simulation loop
while True:
    system.DoStepDynamics(0.01)  # Adjust timestep as needed
    ros_manager.Update()  # Update ROS communication

    # Visualization (optional)
    # if visualization_enabled:
    #     vis.Render()

```

**Explanation:**

1. **Initialization:** Imports necessary PyChrono and ROS modules, initializes the ROS node, and creates a PyChrono system with gravity.

2. **Physical Objects:** Defines a floor and a box with specified dimensions, mass, and material properties. The floor is fixed, while the box is movable.

3. **ROS Integration:** Creates a `CustomRosHandler` class to publish custom data to a ROS topic.

4. **ROS Manager:** Sets up a `ChROSManager` to handle ROS communication, including clock synchronization, body updates, and transform publishing.

5. **Handler Registration:** Registers the custom ROS handler with the ROS manager.

6. **Simulation Loop:** Runs a continuous loop that advances the simulation using `DoStepDynamics` and updates ROS communication using `ros_manager.Update()`.

**Key Points:**

- **Real-Time Execution:** The use of `ChROSRealTimeClock` aims for real-time simulation execution.

- **Customization:** The `CustomRosHandler` allows you to publish any desired data from the simulation to ROS.

- **Visualization:** The commented-out section shows how to integrate visualization using Irrlicht if needed.

- **Parameter Tuning:** Adjust timestep, material properties, object dimensions, and ROS publishing frequency as required for your specific application.
