```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add vehicle and terrain
# 2.1 Vehicle
vehicle = chronovehicle.ChVehicle("HMMWV", system)
vehicle.SetChassisFixed(False)
vehicle.SetInitPosition(chrono.ChVectorD(0, 0.5, 0))
vehicle.SetInitRot(chrono.Q_from_AngAxis(0, chrono.ChVectorD(0, 1, 0)))

# Load vehicle model (replace with your HMMWV model file)
vehicle.SetVehicleModel("hmmwv_model.obj")

# 2.2 Terrain
terrain = chrono.ChTerrainSCM(system)
terrain.SetSize(200, 200)
terrain.SetTexture("terrain_texture.png")

# Custom soil parameters (adjust as needed)
terrain.SetYoungModulus(1e7)
terrain.SetPoissonRatio(0.3)
terrain.SetFriction(0.5)
terrain.SetRestitution(0.2)

# Enable moving patch feature
terrain.SetMovingPatch(True)
terrain.SetPatchSize(10)

# 2.3 Tire model
tire_model = chronovehicle.ChTireModelRigid()
vehicle.SetTireModel(tire_model)

# 3. Set default parameters and interactions
# 3.1 Visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle("HMMWV Simulation")
vis.Initialize()

# Enable mesh visualization for all vehicle components
vehicle.SetChassisVisualizationType(chrono.ChVisualizationType_MESH)
for wheel in vehicle.GetWheels():
    wheel.SetVisualizationType(chrono.ChVisualizationType_MESH)

# 3.2 Sinkage visualization
terrain.SetSinkageVisualization(True)

# 3.3 Driver system
driver = chronovehicle.ChDriverSystem(vehicle)
driver.SetSteeringControlType(chronovehicle.SteeringControlType_POSITION)
driver.SetThrottleControlType(chronovehicle.ThrottleControlType_POSITION)
driver.SetBrakingControlType(chronovehicle.BrakingControlType_POSITION)

# 4. Simulation loop
dt = 1.0 / 50.0  # 50 Hz update rate
while vis.Run():
    # Get input from the user (steering, throttle, braking)
    # ...

    # Apply driver inputs
    driver.Synchronize(dt)

    # Advance the simulation
    system.DoStepDynamics(dt)

    # Render the scene
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**
   - Sets up the Chrono environment, system, and gravity.

2. **Vehicle and Terrain:**
   - Creates a `ChVehicle` object for the HMMWV and sets its initial position, orientation, and chassis fixed state.
   - Loads the HMMWV model (replace `hmmwv_model.obj` with your actual file).
   - Creates a `ChTerrainSCM` object for the deformable terrain and sets its size, texture, and custom soil parameters.
   - Enables the moving patch feature to dynamically follow the vehicle chassis.

3. **Tire Model and Visualization:**
   - Sets a `ChTireModelRigid` for the vehicle's tires.
   - Initializes Irrlicht for visualization and attaches the Chrono system.
   - Enables mesh visualization for all vehicle components.
   - Enables sinkage visualization on the terrain using false colors.

4. **Driver System:**
   - Creates a `ChDriverSystem` to control steering, throttle, and braking.
   - Sets the control types for each input.

5. **Simulation Loop:**
   - Runs the simulation at 50 frames per second.
   - Retrieves user input for steering, throttle, and braking.
   - Applies the driver inputs to the vehicle.
   - Advances the simulation using `DoStepDynamics`.
   - Renders the scene using Irrlicht.
