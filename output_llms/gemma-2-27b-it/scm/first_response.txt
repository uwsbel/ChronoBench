```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add physical systems and objects
#   - Vehicle
vehicle = chronovehicle.ChVehicle(system)
vehicle.SetChassisFixed(False)
vehicle.SetChassisPosition(chrono.ChVectorD(0, 0.5, 0))
vehicle.SetChassisBody(chrono.ChBodyEasyBox(2.5, 1.0, 0.8, 1000))

#   - Tires (Rigid tire model for simplicity)
tire_radius = 0.4
tire_width = 0.2
for i in range(4):
    tire = chronovehicle.ChTire(chrono.ChMaterialSurfaceNSC())
    tire.SetRadius(tire_radius)
    tire.SetWidth(tire_width)
    tire.SetFriction(2.0)
    vehicle.AddTire(tire)

#   - SCM Terrain
terrain = chrono.ChTerrainSCM(system)
terrain.SetSize(20, 20)
terrain.SetBottomLevel(0)
terrain.SetTexture("textures/terrain.png")

# Customize soil parameters (example)
terrain.SetYoungModulus(1e6)
terrain.SetPoissonRatio(0.3)
terrain.SetFriction(0.5)

# Enable moving patch feature
terrain.SetMovingPatch(True)
terrain.SetPatchSize(5, 5)
terrain.SetPatchCenter(vehicle.GetChassis().GetPos())

# 3. Set default parameters and interactions

#   - Visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("HMMWV Simulation")
vis.Initialize()
vis.AddLogo(chrono.GetChronoDataPath() + 'logo_pychrono.png')

#   - Enable mesh visualization for vehicle components
vehicle.SetChassisVisualizationType(chrono.VisualizationType_MESH)
for tire in vehicle.GetTires():
    tire.SetVisualizationType(chrono.VisualizationType_MESH)

#   - Terrain sinkage visualization
terrain.SetSinkageVisualization(True)

#   - Interactive driver system (placeholder)
#   (Implement steering, throttle, and braking controls)

# 4. Simulation loop
while vis.Run():
    # Update vehicle dynamics
    system.DoStepDynamics(0.01)

    # Update terrain patch position
    terrain.SetPatchCenter(vehicle.GetChassis().GetPos())

    # Render the scene
    vis.Render()
```

**Explanation:**

1. **Initialization:**

   - Imports necessary PyChrono modules.
   - Sets up the Chrono system with gravity.

2. **Objects and Systems:**
   - Creates a `ChVehicle` object representing the HMMWV.
   - Adds a simple box-shaped chassis and four rigid tires.
   - Creates an `ChTerrainSCM` object for deformable terrain.
   - Customizes soil parameters for the terrain.
   - Enables the moving patch feature to dynamically follow the vehicle.

3. **Parameters and Interactions:**
   - Initializes the Irrlicht visualization system (`chronoirr`).
   - Sets up the window size and title.
   - Enables mesh visualization for the vehicle components.
   - Configures terrain sinkage visualization with false colors.
   - Placeholder for an interactive driver system (you'll need to implement steering, throttle, and braking controls).

4. **Simulation Loop:**
   - Runs the simulation in a loop until the user closes the window.
   - Updates vehicle dynamics using `system.DoStepDynamics()`.
   - Updates the terrain patch position to follow the vehicle.
   - Renders the scene using `vis.Render()`.



**Important Notes:**



- This script provides a basic framework. You'll need to:
    - Implement the interactive driver system for user control.

    - Adjust soil parameters and terrain settings for desired behavior.
- This script uses a rigid tire model for simplicity. For more accurate tire behavior, consider using Chrono's more advanced tire models.
