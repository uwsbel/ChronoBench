```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#

mysystem = chrono.ChSystemNSC()

# Set the default material properties
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.3)
material.SetRestitution(0.2)

# Create a body with a beam mesh
body = chrono.ChBody()
body.SetBodyFixed(False)
body.SetMass(10.0)
body.SetMaterialSurface(material)

# Define the beam mesh geometry
nodes = [chrono.ChNodeFEAxyz(chrono.ChVectorD(0, 0, 0)),
         chrono.ChNodeFEAxyz(chrono.ChVectorD(1, 0, 0)),
         chrono.ChNodeFEAxyz(chrono.ChVectorD(2, 0, 0))]

elements = [chrono.ChElementBeamEuler(nodes[0], nodes[1]),
            chrono.ChElementBeamEuler(nodes[1], nodes[2])]

mesh = chrono.ChMesh()
mesh.AddNodes(nodes)
mesh.AddElements(elements)

# Add the mesh to the body
body.AddMesh(mesh)

# Add the body to the system
mysystem.Add(body)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(mysystem)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Beam FEA Simulation')
vis.Initialize()
vis.AddTypicalSky()
vis.AddCamera(chrono.ChVectorD(0, 5, -10))

# ---------------------------------------------------------------------
#
#  Run the simulation
#

while vis.Run():
    mysystem.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono modules.
   - Creates a `ChSystemNSC` object to manage the simulation.
   - Defines a material with friction and restitution properties.

2. **Beam Mesh Creation:**
   - Creates a `ChBody` object to hold the beam mesh.
   - Defines nodes and elements for the beam mesh using `ChNodeFEAxyz` and `ChElementBeamEuler`.
   - Creates a `ChMesh` object and adds the nodes and elements.
   - Attaches the mesh to the body.

3. **Simulation Setup:**
   - Adds the body to the simulation system.
   - Initializes the Irrlicht visualization system (`chronoirr`).
   - Sets window size, title, and adds a camera.

4. **Simulation Loop:**
   - Runs the simulation loop using `vis.Run()`.
   - Performs a simulation step with `mysystem.DoStepDynamics(0.01)`.
   - Renders the scene using `vis.Render()`.



This script demonstrates the basic setup for a beam finite element simulation in PyChrono. You can expand upon this by adding more complex geometries, forces, constraints, and other features as needed for your specific application.
