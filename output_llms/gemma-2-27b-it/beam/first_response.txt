```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment and core components.
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Beam Finite Element Simulation')
vis.Initialize()
vis.AddCamera(chrono.ChVectorD(0, 5, -10))
vis.AddLight(chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1))

# 2. Add the required physical systems and objects.
# Create a beam mesh
beam_mesh = chrono.ChMesh()

# Define beam properties
beam_material = chrono.ChMaterialSurfaceNSC()
beam_material.SetFriction(0.3)
beam_material.SetRestitution(0.2)

# Add nodes and elements to the mesh
num_nodes = 10
for i in range(num_nodes):
    node = chrono.ChNodeFEAxyz(chrono.ChVectorD(i, 0, 0))
    beam_mesh.AddNode(node)

for i in range(num_nodes - 1):
    element = chrono.ChElementBeamEuler(
        beam_mesh.GetNode(i), beam_mesh.GetNode(i + 1)
    )
    element.SetMaterial(beam_material)
    element.SetSection(chrono.ChSectionBeamRect(0.1, 0.1))
    beam_mesh.AddElement(element)

# Create a body and attach the mesh
beam_body = chrono.ChBody()
beam_body.SetPos(chrono.ChVectorD(0, 0, 0))
beam_body.SetMass(10)
beam_body.SetInertiaXX(chrono.ChVectorD(1, 1, 1))
beam_body.AddMesh(beam_mesh)
my_system.Add(beam_body)

# 3. Set necessary default parameters.

# Apply a force to the last node
beam_mesh.GetNode(num_nodes - 1).SetForce(chrono.ChVectorD(0, 10, 0))

# Set simulation parameters
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
my_system.SetMaxItersSolverSpeed(100)

# 4. Run the simulation loop.
while vis.Run():
    my_system.DoStepDynamics(0.01)
    vis.Render()
```

**Explanation:**

1. **Initialization:**
   - We create a `ChSystemNSC` object to represent our physical system and set the gravity.
   - We initialize the Irrlicht visualization system (`chronoirr`) and attach it to the physics system.

2. **Beam Mesh Creation:**
   - We define a `ChMesh` object to represent the beam structure.
   - We create nodes (`ChNodeFEAxyz`) and elements (`ChElementBeamEuler`) to build the mesh.
   - We set material properties (`ChMaterialSurfaceNSC`) and cross-sectional properties (`ChSectionBeamRect`) for the beam elements.

3. **Body and Mesh Attachment:**
   - We create a `ChBody` object to represent the physical body of the beam.
   - We attach the `ChMesh` to the `ChBody`.

4. **Simulation Parameters:**
   - We apply a force to the last node of the beam to demonstrate its deformation.
   - We set solver parameters for the physics engine.

5. **Simulation Loop:**
   - The `while vis.Run():` loop runs the simulation until the Irrlicht window is closed.
   - Inside the loop, we perform a single time step (`DoStepDynamics`) and render the scene using Irrlicht (`vis.Render()`).

**To run this script:**

1. Make sure you have PyChrono and Irrlicht installed.
2. Save the script as a `.py` file (e.g., `beam_simulation.py`).
3. Run the script from your terminal using `python beam_simulation.py`.

This will open a window displaying the beam simulation in real-time. You'll see the beam deform under the applied force.
