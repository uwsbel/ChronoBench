```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize PyChrono environment and core components

# Create the physical system
system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add physical systems and objects

# Create a material for the beam
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.3)
material.SetRestitution(0.2)

# Create a beam mesh
beam_mesh = chrono.ChMesh()

# Add nodes to the mesh
node1 = chrono.ChNodeFEAxyz(chrono.ChVectorD(0, 0, 0))
node2 = chrono.ChNodeFEAxyz(chrono.ChVectorD(1, 0, 0))
beam_mesh.AddNode(node1)
beam_mesh.AddNode(node2)

# Add a beam element to the mesh
beam = chrono.ChElementBeamEuler(node1, node2, 0.05, material)  # 0.05 is the cross-section radius
beam_mesh.AddElement(beam)

# Create a body and attach the mesh
body = chrono.ChBody()
body.SetMesh(beam_mesh)
system.Add(body)

# 3. Set default parameters

# Set initial position and orientation of the body
body.SetPos(chrono.ChVectorD(0, 1, 0))

# Apply a force to the body
force = chrono.ChForce(chrono.ChVectorD(0, -10, 0))
body.AddForce(force)

# 4. Visualization and simulation loop

# Create an Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Beam Finite Element Simulation")
vis.Initialize()

# Simulation loop
while vis.Run():
    system.DoStepDynamics(0.01)  # Time step
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - We import the necessary PyChrono modules.
   - A `ChSystemNSC` is created to represent the physical system.
   - Gravitational acceleration is set.

2. **Physical Objects:**
   - A `ChMaterialSurfaceNSC` is defined with friction and restitution properties for the beam.
   - A `ChMesh` is created to hold the beam geometry.
   - Two `ChNodeFEAxyz` objects are added as nodes for the beam.
   - A `ChElementBeamEuler` is created, connecting the nodes and using the defined material and cross-section radius.
   - A `ChBody` is created and assigned the beam mesh. This body will represent the physical beam in the simulation.
   - The body is added to the system.

3. **Parameters:**
   - The initial position of the body is set.
   - A downward force is applied to the body.

4. **Visualization and Loop:**
   - An Irrlicht visualization system (`ChVisualSystemIrrlicht`) is created and attached to the simulation system.
   - The window size and title are set.
   - The Irrlicht system is initialized.
   - The main simulation loop runs:
     - `system.DoStepDynamics(0.01)` performs a dynamics step with a time step of 0.01 seconds.
     - `vis.Render()` renders the scene.

**To run this script:**

1. Make sure you have PyChrono and Irrlicht installed.
2. Save the code as a `.py` file (e.g., `beam_simulation.py`).
3. Run the script from the command line: `python beam_simulation.py`

This will open a window displaying the beam simulation in real-time. You can interact with the simulation using Irrlicht's controls (e.g., rotate the view, zoom).
