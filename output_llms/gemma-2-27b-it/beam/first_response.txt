```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#

# Create a physical system
my_system = chrono.ChSystemNSC()

# Set the gravitational acceleration
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create a material for the beam
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.3)
material.SetRestitution(0.2)

# Create a mesh for the beam
beam_mesh = chrono.ChMesh()

# Define nodes and add them to the mesh
nodes = [
    chrono.ChNodeFEAxyz(chrono.ChVectorD(0, 0, 0)),
    chrono.ChNodeFEAxyz(chrono.ChVectorD(1, 0, 0)),
    chrono.ChNodeFEAxyz(chrono.ChVectorD(2, 0, 0)),
]
for node in nodes:
    beam_mesh.AddNode(node)

# Define elements and add them to the mesh
elements = [
    chrono.ChElementBeamEuler(nodes[0], nodes[1], 0.1, material),
    chrono.ChElementBeamEuler(nodes[1], nodes[2], 0.1, material),
]
for element in elements:
    beam_mesh.AddElement(element)

# Create a body for the beam mesh
beam_body = chrono.ChBody()
beam_body.SetMesh(beam_mesh)
my_system.Add(beam_body)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#

# Create the visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Beam FEA Simulation')
vis.Initialize()

# Set the camera position
vis.GetCamera().SetLocation(chrono.ChVectorD(0, 2, 5))
vis.GetCamera().SetLookAt(chrono.ChVectorD(0, 0, 0))

# ---------------------------------------------------------------------
#
#  Simulation loop
#

while vis.Run():
    # Update the simulation
    my_system.DoStepDynamics(0.01)

    # Render the scene
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a `ChSystemNSC` object to represent the physical system.
   - Sets gravitational acceleration.

2. **Beam Definition:**
   - Defines a `ChMaterialSurfaceNSC` for the beam with friction and restitution properties.
   - Creates a `ChMesh` object to hold the beam's nodes and elements.
   - Defines nodes using `ChNodeFEAxyz` and adds them to the mesh.
   - Defines `ChElementBeamEuler` objects representing beam elements, connecting the nodes and using the defined material.
   - Adds the elements to the mesh.

3. **Body and System:**
   - Creates a `ChBody` object to represent the physical body of the beam.
   - Sets the mesh of the body to the created `beam_mesh`.
   - Adds the beam body to the physical system.

4. **Visualization:**
   - Creates a `ChVisualSystemIrrlicht` object for visualization using Irrlicht.
   - Attaches the visualization to the physical system.
   - Sets window size and title.
   - Initializes the visualization system.
   - Sets the camera position and target.

5. **Simulation Loop:**
   - Enters a loop that continues as long as the Irrlicht window is running.
   - Calls `DoStepDynamics` to advance the simulation by a small time step (0.01 seconds).
   - Calls `Render` to update the visualization.



**Running the Script:**

1. Ensure you have PyChrono and Irrlicht installed.
2. Save the script as a `.py` file (e.g., `beam_simulation.py`).
3. Run the script from the command line: `python beam_simulation.py`.

This will open a window displaying the beam simulation in real-time using Irrlicht.
