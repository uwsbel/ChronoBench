```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#
# ---------------------------------------------------------------------

my_system = chrono.ChSystemNSC()

# Set gravitational acceleration
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create a material for the beam
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.3)
material.SetRestitution(0.2)

# Create a mesh of beams
beam_length = 1.0
beam_width = 0.1
beam_height = 0.1

nodes = []
beams = []

# Define nodes
nodes.append(chrono.ChNodeFEAxyz(chrono.ChVectorD(0, 0, 0)))
nodes.append(chrono.ChNodeFEAxyz(chrono.ChVectorD(beam_length, 0, 0)))
nodes.append(chrono.ChNodeFEAxyz(chrono.ChVectorD(beam_length, 0, beam_height)))
nodes.append(chrono.ChNodeFEAxyz(chrono.ChVectorD(0, 0, beam_height)))

# Define beams
beams.append(chrono.ChElementBeamEuler(nodes[0], nodes[1], material))
beams.append(chrono.ChElementBeamEuler(nodes[1], nodes[2], material))
beams.append(chrono.ChElementBeamEuler(nodes[2], nodes[3], material))
beams.append(chrono.ChElementBeamEuler(nodes[3], nodes[0], material))

# Create a beam mesh
beam_mesh = chrono.ChMesh()
beam_mesh.AddNodes(nodes)
beam_mesh.AddElements(beams)

# Add the mesh to the system
my_system.Add(beam_mesh)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization
#
# ---------------------------------------------------------------------

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Beam FEA Simulation")
vis.Initialize()

# ---------------------------------------------------------------------
#
#  Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    vis.BeginScene()
    vis.Render()
    my_system.DoStepDynamics(0.01)
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**

   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a `ChSystemNSC` object to manage the simulation.
   - Sets gravitational acceleration.

2. **Beam Mesh Creation:**

   - Defines material properties for the beam (friction and restitution).
   - Creates nodes for the beam mesh using `ChNodeFEAxyz`.
   - Creates beam elements using `ChElementBeamEuler`, connecting the nodes and specifying the material.
   - Assembles the nodes and elements into a `ChMesh` object.

3. **Adding to the System:**

   - Adds the created beam mesh to the simulation system (`my_system`).

4. **Irrlicht Visualization:**

   - Creates a `ChVisualSystemIrrlicht` object for visualization.
   - Attaches the simulation system to the visualizer.
   - Sets window size and title.
   - Initializes the Irrlicht engine.

5. **Simulation Loop:**

   - Enters a loop that runs as long as the Irrlicht window is open.
   - In each iteration:
     - Begins the Irrlicht scene.
     - Renders the scene.
     - Performs one time step of the simulation using `DoStepDynamics`.
     - Ends the Irrlicht scene.
