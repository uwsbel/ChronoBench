```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# ---------------------------------------------------------------------
#
#  Simulation setup
#

# Initialize Chrono system
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Set simulation parameters
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
my_system.SetSolverMaxIterations(100)
my_system.SetTimestep(0.01)

# ---------------------------------------------------------------------
#
#  Terrain setup
#

# Define soil parameters
soil_params = chrono.ChSoilParams()
soil_params.SetYoungModulus(1e6)  # Pa
soil_params.SetPoissonRatio(0.3)
soil_params.SetFriction(0.5)
soil_params.SetRestitution(0.2)
soil_params.SetDensity(1500)  # kg/m^3

# Load height map (replace 'terrain.png' with your height map file)
height_map = np.loadtxt('terrain.png', delimiter=',')

# Create SCM terrain
terrain = chrono.ChTerrainSCM(my_system, soil_params, height_map)
terrain.SetTexture(chrono.GetChronoDataPath() + 'terrain/textures/grass.jpg')

# ---------------------------------------------------------------------
#
#  Vehicle setup
#

# Load HMMWV vehicle model (replace 'hmmwv.obj' with your vehicle model file)
vehicle = chrono.ChBodyEasyBox(
    'vehicle', 2.5, 1.5, 0.8, 1000, True, True
)
vehicle.SetPos(chrono.ChVectorD(0, 2, 0))

# Add vehicle to the system
my_system.Add(vehicle)

# ---------------------------------------------------------------------
#
#  Driver system setup
#

# Create a simple driver system (replace with a more sophisticated one if needed)
driver = chrono.ChDriver(vehicle)

# ---------------------------------------------------------------------
#
#  Visualization setup
#

# Create Irrlicht visualization system
vis = chronoirr.ChIrrApp(my_system, "HMMWV Simulation", chronoirr.dimension2du(1280, 720))

# Set camera position and orientation
vis.GetCamera().SetLocation(chrono.ChVectorD(10, 5, 5))
vis.GetCamera().SetLookAt(chrono.ChVectorD(0, 1.5, 0))

# Add lighting
vis.AddLightWithShadow(chrono.ChVectorD(5, 10, 5), chrono.ChVectorD(1, 1, 1), 50)

# ---------------------------------------------------------------------
#
#  Simulation loop
#

while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()

    # Update driver control (replace with your driver logic)
    driver.Update(0.1)

    # Advance simulation
    my_system.DoStepDynamics(vis.GetTimeStep())

    vis.EndScene()

```

**Explanation:**

1. **Initialization:**

   - Imports necessary Chrono and Irrlicht modules.
   - Creates a Chrono system (`my_system`) and sets gravity.
   - Defines simulation parameters like solver type, maximum iterations, and timestep.

2. **Terrain Setup:**

   - Defines soil parameters for the SCM terrain (Young's modulus, Poisson ratio, friction, restitution, density).
   - Loads a height map from a file (replace `'terrain.png'` with your file).
   - Creates an SCM terrain object (`terrain`) using the soil parameters and height map.
   - Sets a texture for the terrain.

3. **Vehicle Setup:**

   - Loads a vehicle model (replace `'hmmwv.obj'` with your file).
   - Creates a `ChBodyEasyBox` to represent the vehicle.
   - Sets the initial position of the vehicle.
   - Adds the vehicle to the Chrono system.

4. **Driver System Setup:**

   - Creates a simple `ChDriver` object for basic vehicle control. You can replace this with a more advanced driver model if needed.

5. **Visualization Setup:**

   - Creates an Irrlicht visualization system (`vis`) linked to the Chrono system.
   - Sets the window title and resolution.
   - Positions and orients the camera.
   - Adds a light source with shadows.

6. **Simulation Loop:**

   - Runs the Irrlicht event loop (`vis.GetDevice().run()`).
   - Inside the loop:
     - Renders the scene (`vis.BeginScene()`, `vis.Render()`, `vis.EndScene()`).
     - Updates the driver control logic (replace with your specific driver implementation).
     - Advances the Chrono simulation for one timestep (`my_system.DoStepDynamics()`).

**Important Notes:**

- Replace placeholder filenames (`terrain.png`, `hmmwv.obj`) with your actual files.
- This script provides a basic framework. You'll need to customize it further:
    - Implement a more sophisticated driver system.
    - Add sensors and actuators to the vehicle.
    - Define specific initial conditions and control inputs.
    - Adjust simulation parameters for desired performance.
