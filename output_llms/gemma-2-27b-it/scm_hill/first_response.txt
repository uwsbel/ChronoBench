```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np
from chrono_models import HMMWV

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")

# Create the simulation system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add physical systems and objects

# Create the HMMWV vehicle
vehicle = HMMWV.HMMWV_Vehicle(system)
vehicle.SetPos(chrono.ChVectorD(0, 0.5, 0))  # Initial position

# Create SCM deformable terrain
terrain = chrono.ChTerrainSCM(system)
terrain.SetSize(chrono.ChVectorD(50, 50, 1))  # Terrain size
terrain.SetTexture(chrono.GetChronoDataPath() + 'texture/terrain.jpg')

# Load height map for terrain
height_map = np.load("height_map.npy")  # Replace with your height map file
terrain.InitializeHeightMap(height_map)

# Define soil parameters (example values)
terrain.SetYoungModulus(1e7)
terrain.SetPoissonRatio(0.3)
terrain.SetFriction(0.5)
terrain.SetRestitution(0.1)

# 3. Set default parameters and interactions

# Add vehicle to terrain
system.Add(vehicle)
system.Add(terrain)

# Create driver system for vehicle control
driver = chrono.ChDriver(vehicle.GetChassis())

# 4. Initialize Irrlicht visualization

# Create Irrlicht application
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle("HMMWV Simulation")
vis.Initialize()

# Set camera position and lighting
camera = vis.GetCamera()
camera.SetPos(chrono.ChVectorD(10, 5, 5))
camera.SetLookAt(chrono.ChVectorD(0, 0.5, 0))

# 5. Simulation loop

# Set simulation timestep
dt = 0.01

while vis.Run():
    # Driver control (example: simple steering)
    driver.SetSteering(np.sin(chrono.GetChTime() * 2))

    # Advance simulation
    system.DoStepDynamics(dt)

    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**

   - Imports necessary PyChrono modules.
   - Sets the Chrono data path for loading assets.
   - Creates a Chrono system (`ChSystemNSC`) with gravity.

2. **Adding Objects:**

   - Creates an HMMWV vehicle using the `HMMWV_Vehicle` class (assuming you have a custom class or model for the HMMWV).
   - Creates an SCM deformable terrain (`ChTerrainSCM`) and sets its size, texture, and height map.
   - Defines soil parameters for the terrain (Young's modulus, Poisson ratio, friction, restitution).
   - Adds the vehicle and terrain to the Chrono system.
   - Creates a driver system (`ChDriver`) to control the vehicle.

3. **Visualization:**

   - Initializes Irrlicht visualization (`ChVisualSystemIrrlicht`).
   - Sets window size, title, and initializes the visualizer.
   - Sets camera position and look-at point for initial view.

4. **Simulation Loop:**

   - Sets the simulation timestep (`dt`).
   - Enters the main loop:
     - Applies driver control (in this case, simple steering based on time).
     - Advances the simulation by one timestep using `DoStepDynamics`.
     - Updates the visualization by rendering the scene.

**Notes:**

- This script assumes you have a custom `HMMWV_Vehicle` class or model defined elsewhere.
- Replace `"height_map.npy"` with the actual path to your height map file.
- Adjust soil parameters and driver control logic as needed for your specific simulation.
- The Irrlicht visualization settings (camera, lighting) can be further customized.
