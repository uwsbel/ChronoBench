```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np
from chrono_models.vehicle import HMMWV

# ---------------------------------------------------------------------
# 1. Initialize PyChrono environment and core components
# ---------------------------------------------------------------------
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# ---------------------------------------------------------------------
# 2. Add physical systems and objects
# ---------------------------------------------------------------------
# Create SCM deformable terrain
terrain = chrono.ChTerrainSCM(my_system)
terrain.SetSize(chrono.ChVectorD(50, 50, 0))  # Set terrain size
terrain.SetLevel(0)  # Set initial height level

# Load height map (replace with your height map file)
height_map = np.loadtxt("terrain_heightmap.txt")
terrain.InitializeHeightMap(height_map, 1.0)  # Set resolution

# Define soil parameters
terrain.SetFriction(0.5)
terrain.SetRestitution(0.1)
terrain.SetYoungModulus(1e7)
terrain.SetPoissonRatio(0.3)

# Create HMMWV vehicle
vehicle = HMMWV(my_system)
vehicle.SetPos(chrono.ChVectorD(0, 1, 0))  # Initial position

# ---------------------------------------------------------------------
# 3. Set default parameters and interactions
# ---------------------------------------------------------------------
# Connect vehicle to terrain
vehicle.SetContactMaterial(terrain.GetContactMaterial())

# Initialize driver system (replace with your driver model)
driver = chrono.ChDriver(vehicle)

# ---------------------------------------------------------------------
# 4. Visualization setup with Irrlicht
# ---------------------------------------------------------------------
vis = chronoirr.ChIrrApp(my_system, "HMMWV Simulation")
vis.SetWindowSize(1280, 720)
vis.SetSkyBox()
vis.AddTypicalLights()
vis.AddCamera(chrono.ChVectorD(0, 5, -10))
vis.SetCameraPosition(chrono.ChVectorD(0, 5, -10))

# ---------------------------------------------------------------------
# 5. Simulation loop
# ---------------------------------------------------------------------
while vis.GetDevice()->run():
    vis.BeginScene()
    vis.Render()

    # Update driver input (replace with your control logic)
    driver.Update(0.01)

    # Advance simulation
    my_system.DoStepDynamics(0.01)

    vis.EndScene()



```

**Explanation:**

1. **Initialization:**
   - We create a `ChSystemNSC` to manage the simulation.
   - Gravity is set to -9.81 m/s².

2. **Physical Systems:**
   - An SCM deformable terrain is created using `ChTerrainSCM`.
   - A height map is loaded to define the terrain shape.
   - Soil parameters like friction, restitution, Young's modulus, and Poisson ratio are set.
   - An HMMWV vehicle is instantiated from the `chrono_models.vehicle` module (you'll need to have this module installed or create your own HMMWV model).
   - The vehicle's initial position is set.

3. **Parameters and Interactions:**
   - The vehicle's contact material is set to match the terrain's material for proper interaction.
   - A driver system (placeholder) is initialized. You'll need to implement your own driver logic for controlling the vehicle.

4. **Visualization:**
   - An Irrlicht visualization system (`ChIrrApp`) is set up.
   - Window size, skybox, lights, and camera are configured.

5. **Simulation Loop:**
   - The loop runs as long as the Irrlicht window is open.
   - In each iteration:
     - The scene is rendered using Irrlicht.
     - The driver system is updated (replace with your control logic).
     - The simulation is advanced one timestep using `DoStepDynamics`.

**Remember:**

- Replace `"terrain_heightmap.txt"` with the path to your actual height map file.
- Implement your own driver system logic in the `driver.Update()` function.
- You'll need to install the necessary PyChrono and Irrlicht dependencies.

This script provides a basic framework for simulating an HMMWV on deformable terrain with visualization. You can customize it further by adding more complex terrain features, vehicle dynamics, driver behaviors, and visualization effects.
