```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import random

# ---------------------------------------------------------------------
#
#  Create the simulation
#
# ---------------------------------------------------------------------

# Create a Chrono system
my_system = chrono.ChSystemNSC()

# Set gravitational acceleration
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create a material for the particles
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.5)
material.SetRestitution(0.2)

# ---------------------------------------------------------------------
#
#  Create particle emitter
#
# ---------------------------------------------------------------------

class ParticleEmitter:
    def __init__(self, system, position, rate):
        self.system = system
        self.position = position
        self.rate = rate
        self.timer = 0

    def Update(self, step):
        self.timer += step
        if self.timer > 1.0 / self.rate:
            self.timer = 0
            # Create a random particle
            shape = random.choice(["SPHERE", "BOX", "CAPSULE"])
            if shape == "SPHERE":
                body = chrono.ChBodyEasySphere(0.1, 1000, material)
            elif shape == "BOX":
                body = chrono.ChBodyEasyBox(0.1, 0.1, 0.1, 1000, material)
            else:
                body = chrono.ChBodyEasyCapsule(0.1, 0.2, 1000, material)

            # Set random position, velocity, and orientation
            body.SetPos(self.position + chrono.ChVectorD(random.uniform(-0.5, 0.5), random.uniform(0, 1), random.uniform(-0.5, 0.5)))
            body.SetPos_dt(chrono.ChVectorD(random.uniform(-1, 1), random.uniform(0, 2), random.uniform(-1, 1)))
            body.SetRot(chrono.Q_from_AngAxis(random.uniform(0, 360), chrono.ChVectorD(random.uniform(0, 1), random.uniform(0, 1), random.uniform(0, 1))))

            # Add the particle to the system
            self.system.Add(body)

# Create a particle emitter
emitter = ParticleEmitter(my_system, chrono.ChVectorD(0, 5, 0), 10)

# ---------------------------------------------------------------------
#
#  Create Irrlicht visualization
#
# ---------------------------------------------------------------------

vis = chronoirr.ChIrrApp(my_system, "Particle Attraction", chrono.ChVectorD(0, 0, 0))
vis.AddTypicalSky()
vis.AddTypicalLights()
vis.SetCameraPosition(chrono.ChVectorD(5, 5, 5))
vis.SetCameraLookAt(chrono.ChVectorD(0, 0, 0))

# ---------------------------------------------------------------------
#
#  Simulation loop
#
# ---------------------------------------------------------------------

while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()
    emitter.Update(vis.GetTimeStep())
    my_system.DoStepDynamics(vis.GetTimeStep())
    vis.EndScene()

```

**Explanation:**

1. **Initialization:** The script starts by importing necessary Chrono and Irrlicht modules. It then creates a Chrono system (`my_system`) and sets the gravitational acceleration.

2. **Particle Emitter:** A `ParticleEmitter` class is defined to generate particles with random properties. It takes the system, position, and emission rate as input. The `Update` method creates particles at a specified rate, assigning random shapes, positions, velocities, and orientations.

3. **Visualization:** An Irrlicht visualization (`vis`) is created to render the simulation. It sets up a camera, lighting, and skybox.

4. **Simulation Loop:** The main loop runs until the Irrlicht window is closed. In each iteration:
   - The scene is rendered using Irrlicht.
   - The particle emitter updates, generating new particles.
   - The Chrono system performs a dynamics step, simulating particle interactions and movement.

**Key Points:**

- **Custom Gravitational Forces:** While the script sets a default gravitational acceleration, you can implement custom gravitational forces between particles using Chrono's force models.
- **Particle Shapes:** The script uses predefined shapes (sphere, box, capsule), but you can create custom geometries using Chrono's mesh loading capabilities.
- **Interaction Customization:** You can further customize particle interactions by adding forces, constraints, or collision detection.

Remember to install the required libraries (PyChrono, Irrlicht) before running the script.
