```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import random

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("data/")
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add the required physical systems and objects

# Create a particle emitter
emitter = chrono.ChParticleEmitter()
emitter.SetPos(chrono.ChVectorD(0, 5, 0))
emitter.SetFlowRate(10)  # Particles per second
emitter.SetSpeed(10)
emitter.SetMinSize(0.1)
emitter.SetMaxSize(0.5)

# Add emitter to the system
system.Add(emitter)

# 3. Set necessary default parameters

# Create a material for the particles
particle_material = chrono.ChMaterialSurfaceNSC()
particle_material.SetFriction(0.5)
particle_material.SetRestitution(0.2)

# Create a particle system
particle_system = chrono.ChParticles(1000)
particle_system.SetMaterial(particle_material)
system.Add(particle_system)

# Connect the emitter to the particle system
emitter.SetTarget(particle_system)

# Visualize the simulation using Irrlicht
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Particle Gravity Simulation")
vis.Initialize()

# Simulation loop
while vis.Run():
    # Apply custom gravitational forces
    for i in range(particle_system.GetNumParticles()):
        for j in range(i + 1, particle_system.GetNumParticles()):
            p1 = particle_system.GetParticle(i).GetPos()
            p2 = particle_system.GetParticle(j).GetPos()
            dist = (p1 - p2).Length()
            force = 10 / (dist ** 2) * (p2 - p1).Normalize()
            particle_system.GetParticle(i).AddForce(force)
            particle_system.GetParticle(j).AddForce(-force)

    system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Sets the data path for Chrono.
   - Creates a Chrono system with default gravity.

2. **Particle Emitter and System:**
   - Creates a `ChParticleEmitter` to generate particles.
   - Sets the emitter's position, flow rate, speed, and size range.
   - Creates a `ChParticles` system to hold the emitted particles.
   - Defines a material for the particles with friction and restitution.
   - Connects the emitter to the particle system.

3. **Visualization:**
   - Initializes Irrlicht visualization system (`chronoirr.ChVisualSystemIrrlicht`).
   - Attaches the Chrono system to the visualization.
   - Sets window size and title.
   - Initializes the Irrlicht window.

4. **Simulation Loop:**
   - Enters the main simulation loop, which continues as long as the Irrlicht window is open.
   - **Custom Gravity:**
     - Iterates through all particle pairs.
     - Calculates the distance between each pair.
     - Applies a gravitational force inversely proportional to the square of the distance.
   - Performs a single step of dynamics using `system.DoStepDynamics(0.01)`.
   - Renders the scene using `vis.Render()`.

**Key Points:**

- **Randomness:** The particle emitter generates particles with random shapes, positions, velocities, and orientations, creating a dynamic and visually interesting simulation.
- **Custom Forces:** The code implements a custom gravitational force calculation to simulate particle attraction. You can modify this calculation to experiment with different gravity models.
- **Irrlicht Visualization:** Irrlicht provides a real-time 3D visualization of the simulation, allowing you to observe the particle interactions.
