```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import random

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("data/")
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add the required physical systems and objects
# Create an Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Particle Gravity Simulation")
vis.Initialize()

# Create a particle emitter
emitter = chrono.ChParticleEmitter(my_system)
emitter.SetPos(chrono.ChVectorD(0, 5, 0))
emitter.SetDir(chrono.ChVectorD(0, -1, 0))
emitter.SetFlowRate(10)  # Particles per second
emitter.SetSpeed(2)

# 3. Set necessary default parameters

# Particle properties
particle_radius = 0.1
particle_mass = 0.1

# Gravitational constant
G = 6.67430e-11

# Function to create a random particle
def create_particle():
    shape = chrono.ChSphereShape()
    shape.GetSphereGeometry().rad = particle_radius
    body = chrono.ChBodyEasySphere(particle_mass, shape)
    body.SetPos(chrono.ChVectorD(random.uniform(-5, 5), random.uniform(0, 10), random.uniform(-5, 5)))
    body.SetRot(chrono.ChQuaternionD(random.uniform(0, 1), random.uniform(0, 1), random.uniform(0, 1), random.uniform(0, 1)))
    body.SetBodyFixed(False)
    my_system.AddBody(body)
    return body

# Create initial particles
for i in range(100):
    create_particle()

# Simulation loop
while vis.Run():
    # Emit new particles
    emitter.EmitParticles()

    # Apply gravitational forces between particles
    for i in range(my_system.Get_bodylist().size()):
        body1 = my_system.Get_bodylist()[i]
        for j in range(i + 1, my_system.Get_bodylist().size()):
            body2 = my_system.Get_bodylist()[j]
            r = body2.GetPos() - body1.GetPos()
            dist = r.Length()
            force = G * body1.GetMass() * body2.GetMass() / (dist * dist)
            force_dir = r.GetNormalized()
            body1.AddForce(force * force_dir)
            body2.AddForce(-force * force_dir)

    # Update the simulation
    my_system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Sets the Chrono data path.
   - Creates a Chrono system with standard gravity.
   - Initializes the Irrlicht visualization system and attaches it to the Chrono system.

2. **Particle Emitter:**
   - Creates a `ChParticleEmitter` to generate particles.
   - Sets its position, direction, flow rate, and speed.

3. **Particle Properties:**
   - Defines the radius and mass of each particle.
   - Sets the gravitational constant `G`.

4. **Particle Creation:**
   - `create_particle()` function creates a random particle with a sphere shape, random position, rotation, and adds it to the Chrono system.

5. **Simulation Loop:**
   - Continuously runs until the Irrlicht window is closed.
   - Emits new particles from the emitter.
   - Iterates through all particle pairs and calculates the gravitational force between them using Newton's law of universal gravitation.
   - Applies the calculated forces to the particles.
   - Performs a step of the Chrono simulation.
   - Renders the scene using Irrlicht.

**Key Points:**



* This script demonstrates the basic principles of particle-based simulations with gravitational attraction.
* You can adjust parameters like particle properties, emitter settings, and gravitational constant to explore different scenarios.
* For more complex interactions or visualizations, you can extend this script with additional Chrono features and Irrlicht functionalities.
