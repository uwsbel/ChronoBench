```python
import pychrono as chrono
import pychrono.sensor as sensor
import pychrono.postprocess as postprocess
import numpy as np

# 1. Initialize the PyChrono environment and core components.
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)

# 2. Add the triangular mesh as a fixed body.
mesh_file = "your_mesh.obj"  # Replace with your .obj file path
mesh = chrono.ChTriangleMeshConnected()
mesh.LoadWavefrontMesh(mesh_file)
body = chrono.ChBody()
body.SetMesh(mesh)
body.SetBodyFixed(True)
my_system.Add(body)

# 3. Add a camera sensor to the body.
camera = sensor.ChCameraSensor()
camera.SetCameraPosition(chrono.ChVectorD(2, 2, 2))
camera.SetCameraLookAt(chrono.ChVectorD(0, 0, 0))
camera.SetLens(sensor.ChLens.Type_PERSPECTIVE)
camera.SetVerticalFOV(60)
camera.SetAspect(16.0 / 9.0)

# Add noise filters and visualizations.
camera.AddFilter(sensor.ChFilterGaussianNoise(stddev=0.01))
camera.SetVisualizationType(sensor.ChVisualizationType.Type_COLOR)

# Create a sensor manager and add the camera.
sensor_manager = sensor.ChSensorManager(my_system)
sensor_manager.AddSensor(camera)

# Simulation loop
time_step = 0.01
simulation_time = 10

for i in range(int(simulation_time / time_step)):
    # Update camera position in an orbit around the mesh.
    angle = i * 0.1
    camera.SetCameraPosition(chrono.ChVectorD(2 * np.cos(angle), 2, 2 * np.sin(angle)))
    camera.SetCameraLookAt(chrono.ChVectorD(0, 0, 0))

    # Simulate the system.
    my_system.DoStepDynamics(time_step)

    # Print camera buffer data.
    buffer = camera.GetImageBuffer()
    print(buffer)

    # Optional: Save camera images to a file.
    # postprocess.ChPostProcessCamera(camera).SaveImage("image_" + str(i) + ".png")

```

**Explanation:**

1. **Initialization:**
   - We create a `ChSystemNSC` object, which represents the physics simulation world.
   - We set the gravity and solver type for the simulation.

2. **Mesh Loading:**
   - We load a triangular mesh from a Wavefront .obj file using `ChTriangleMeshConnected.LoadWavefrontMesh()`.
   - We create a `ChBody` object and assign the mesh to it.
   - We set the body as fixed so it doesn't move during the simulation.

3. **Camera Setup:**
   - We create a `ChCameraSensor` object and configure its position, look-at point, lens type, field of view, and aspect ratio.
   - We add a Gaussian noise filter to the camera to simulate real-world noise.
   - We set the visualization type to color for displaying the camera images.

4. **Sensor Manager:**
   - We create a `ChSensorManager` object to manage the camera sensor.
   - We add the camera to the sensor manager.

5. **Simulation Loop:**
   - We iterate through the simulation time, updating the camera position in an orbit around the mesh.
   - We call `my_system.DoStepDynamics()` to advance the simulation by one time step.
   - We print the camera buffer data, which contains the pixel values of the captured image.
   - You can optionally save the camera images to files using `ChPostProcessCamera`.

**Remember to:**

- Replace `"your_mesh.obj"` with the actual path to your .obj file.
- Adjust the simulation parameters (time step, simulation time, camera settings) as needed.
