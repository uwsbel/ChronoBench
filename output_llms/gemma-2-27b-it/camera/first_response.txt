```python
import pychrono as chrono
import pychrono.postprocess as postprocess
import pychrono.irrlicht as chronoirr

# 1. Initialize PyChrono environment and core components

# Create the physical system
my_system = chrono.ChSystemNSC()

# Set gravitational acceleration
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
viz = chronoirr.ChVisualSystemIrrlicht()
viz.AttachSystem(my_system)
viz.SetWindowSize(800, 600)
viz.SetWindowTitle('Triangular Mesh Visualization')
viz.Initialize()
viz.AddCamera(chronoirr.ChCamera(chrono.ChVectorD(1, 1, 1)))

# 2. Add the triangular mesh as a fixed body

# Load the mesh from the .obj file
mesh = chrono.ChTriangleMeshConnected()
mesh.LoadWavefrontMesh("your_mesh.obj")

# Create a body and attach the mesh
body = chrono.ChBody()
body.SetBodyFixed(True)
body.SetMesh(mesh)
my_system.AddBody(body)

# 3. Add camera sensor and sensor manager

# Create a sensor manager
sensor_manager = chrono.ChSensorManager()
my_system.AddSensorManager(sensor_manager)

# Create a camera sensor and attach it to the body
camera = chrono.ChCameraSensor()
camera.SetBody(body)
camera.SetSensorPosition(chrono.ChVectorD(0, 0, 1))
camera.SetSensorDirection(chrono.ChVectorD(0, 0, -1))
camera.SetWidth(640)
camera.SetHeight(480)
sensor_manager.AddSensor(camera)

# Add noise filters and visualizations
camera.AddNoiseFilter(chrono.ChNoiseFilterGaussian(0.01))
camera.AddVisualization(chrono.ChVisualizationRGB())

# Simulation loop

while viz.Run():
    # Update camera position in an orbit around the mesh
    angle = chrono.ChTime.GetTime() * 0.5
    camera.SetSensorPosition(chrono.ChVectorD(2 * chrono.ChCos(angle), 0, 2 * chrono.ChSin(angle)))

    # Simulate one time step
    my_system.DoStepDynamics(0.01)

    # Print camera buffer data
    print(camera.GetBuffer())

    # Render the scene
    viz.Render()
```

**Explanation:**

1. **Initialization:**
   - The code initializes the PyChrono system, sets gravity, and creates an Irrlicht visualization system.

2. **Mesh Loading and Body Creation:**
   - A triangular mesh is loaded from a Wavefront .obj file using `chrono.ChTriangleMeshConnected.LoadWavefrontMesh()`.
   - A fixed body is created, the mesh is attached to it, and the body is added to the system.

3. **Camera Sensor and Sensor Manager:**
   - A `chrono.ChSensorManager` is created and added to the system.
   - A `chrono.ChCameraSensor` is created, attached to the body, and configured with position, direction, width, and height.
   - Noise filters and visualizations are added to the camera sensor.

4. **Simulation Loop:**
   - The loop runs until the Irrlicht window is closed.
   - The camera's position is updated in an orbit around the mesh using trigonometric functions.
   - The system is simulated for one time step.
   - The camera buffer data is printed.
   - The scene is rendered using Irrlicht.

**Remember:**

- Replace `"your_mesh.obj"` with the actual path to your .obj file.
- You can adjust parameters like camera position, noise filter strength, and simulation time step as needed.

This script provides a basic framework for visualizing a triangular mesh with a camera sensor in PyChrono. You can expand upon it by adding more complex interactions, physics, and sensor types.
