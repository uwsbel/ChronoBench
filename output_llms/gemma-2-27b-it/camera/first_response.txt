```python
import pychrono as chrono
import pychrono.postprocess as postprocess
import pychrono.irrlicht as chronoirr

# 1. Initialize PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add the triangular mesh as a fixed body
mesh_file = "your_mesh.obj"  # Replace with your .obj file path
mesh = chrono.ChTriangleMeshConnected()
mesh.LoadWavefrontMesh(mesh_file)
body = chrono.ChBody()
body.SetBodyFixed(True)
body.SetPos(chrono.ChVectorD(0, 0, 0))  # Set initial position

# Create a collision model from the mesh
col_model = chrono.ChTriangleMeshShape()
col_model.SetMesh(mesh)
body.AddShape(col_model)

my_system.Add(body)

# 3. Add camera sensor, sensor manager, and visualizations
# Create a Irrlicht application
myapplication = chronoirr.ChIrrApp(my_system, "Camera Orbit Simulation", chronoirr.dimension2du(800, 600))
myapplication.AddTypicalCamera(chronoirr.vector3df(2, 2, 2))  # Initial camera position

# Create a sensor manager
sensor_manager = postprocess.ChSensorManager(my_system)

# Create a camera sensor and attach it to the body
camera = postprocess.ChCameraSensor(sensor_manager)
camera.AttachToBody(body)
camera.SetCameraPosition(chrono.ChVectorD(1, 1, 1))  # Initial camera position relative to the body

# Add noise filters and visualizations
camera.AddNoiseFilter(postprocess.ChGaussianNoiseFilter(0.01))
camera.SetVisualizationType(postprocess.ChVisualizationType_IMAGE)

# Simulate the system
myapplication.SetTimestep(0.01)
while myapplication.GetDevice().run():
    # Update camera position in an orbit around the mesh
    angle = myapplication.GetChTime() * 0.5  # Adjust speed as needed
    camera.SetCameraPosition(chrono.ChVectorD(2 * chrono.ChMath.Sin(angle), 1, 2 * chrono.ChMath.Cos(angle)))

    # Simulate one time step
    my_system.DoStepDynamics(myapplication.GetTimestep())

    # Print camera buffer data
    print(camera.GetImageBuffer())

    # Render the scene
    myapplication.DoStep()

```

**Explanation:**

1. **Initialization:**
   - Creates a Chrono system and sets gravity.
   - Loads the triangular mesh from the specified `.obj` file.
   - Creates a fixed body and attaches the mesh as its collision shape.

2. **Camera Setup:**
   - Initializes an Irrlicht application for visualization.
   - Creates a sensor manager to handle sensors.
   - Creates a camera sensor, attaches it to the body, and sets its initial position.
   - Adds a Gaussian noise filter to simulate real-world camera noise.
   - Sets the visualization type to display camera images.

3. **Simulation Loop:**
   - Sets the simulation timestep.
   - Enters the main loop, which continues until the Irrlicht window is closed.
   - Updates the camera's position in an orbit around the mesh using a sinusoidal function.
   - Performs one step of the Chrono simulation.
   - Prints the camera buffer data (pixel values) at each step.
   - Renders the scene using Irrlicht.

**Remember:**

- Replace `"your_mesh.obj"` with the actual path to your mesh file.
- Adjust the camera position, noise filter parameters, and orbit speed as needed.
- This script provides a basic framework; you can extend it by adding more objects, interactions, and sensor types.
