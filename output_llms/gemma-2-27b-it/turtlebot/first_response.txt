```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create the ground body
ground = chrono.ChBodyEasyBox(10, 10, 0.1, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.1, 0))
ground.SetBodyFixed(True)
my_system.Add(ground)

# 2. Add the Turtlebot robot
robot = chrono.ChRobotTurtlebot()
robot.SetPos(chrono.ChVectorD(0, 0.5, 0))
robot.SetRot(chrono.Q_from_AngAxis(chrono.CH_C_PI / 4, chrono.ChVectorD(0, 0, 1)))
my_system.Add(robot)

# 3. Set up Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Turtlebot Simulation")
vis.Initialize()
vis.AddCamera(chrono.ChCamera(chrono.ChVectorD(2, 2, 2)))
vis.GetCamera().SetLookAt(chrono.ChVectorD(0, 0.5, 0))
vis.SetAmbientLight(chrono.ChColor(0.5, 0.5, 0.5))
vis.SetDirectionalLight(chrono.ChVectorD(1, 1, 1), chrono.ChColor(1, 1, 1))

# Simulation loop
while vis.Run():
    # Control the Turtlebot's motors
    time = my_system.GetChTime()
    if time < 5:
        robot.SetWheelTorque(0.5, 0.5)  # Move forward
    elif time < 10:
        robot.SetWheelTorque(-0.5, 0.5)  # Turn left
    else:
        robot.SetWheelTorque(0, 0)  # Stop

    # Update and render the simulation
    my_system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Creates a `ChSystemNSC` object for the simulation.
   - Sets gravity using `Set_G_acc`.
   - Creates a ground body as a box using `ChBodyEasyBox` and fixes it in place.
   - Initializes a `ChRobotTurtlebot` object, sets its position and orientation, and adds it to the system.

2. **Visualization:**
   - Creates a `ChVisualSystemIrrlicht` object for real-time visualization using Irrlicht.
   - Attaches the system, sets window size and title, and initializes the visualization.
   - Adds a camera with a specific position and look-at target.
   - Sets ambient and directional lighting for better visualization.

3. **Simulation Loop:**
   - Enters a loop that runs as long as the Irrlicht window is open (`vis.Run()`).
   - Controls the Turtlebot's motors using `SetWheelTorque` at different time intervals to simulate forward movement and turning.
   - Updates the simulation using `DoStepDynamics` with a timestep of 0.01 seconds.
   - Renders the scene using `vis.Render()`.

**Remember:**

- This script provides a basic framework. You can customize it further by adding more objects, modifying robot parameters, implementing more complex control logic, and adding sensor data processing.
- Make sure you have PyChrono and Irrlicht installed in your environment.
