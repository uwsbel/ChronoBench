```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# ---------------------------------------------------------------------
#
#  Create the simulation system
#
# ---------------------------------------------------------------------

mysystem = chrono.ChSystemNSC()

# Set the gravitational acceleration
mysystem.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# ---------------------------------------------------------------------
#
# Create the ground body
#
# ---------------------------------------------------------------------

ground_material = chrono.ChMaterialSurfaceNSC()
ground_material.SetFriction(0.5)
ground_material.SetRestitution(0.2)

ground = chrono.ChBodyEasyBox(
    20, 20, 0.2, 1000, True, True, ground_material
)
ground.SetPos(chrono.ChVectorD(0, -0.2, 0))
ground.SetBodyFixed(True)
mysystem.Add(ground)

# ---------------------------------------------------------------------
#
# Create the Turtlebot robot
#
# ---------------------------------------------------------------------

# Load the Turtlebot URDF file
robot = chrono.ChRobot(chrono.GetChronoDataPath() + "turtlebot/turtlebot.urdf")

# Set the initial position and orientation of the robot
robot.SetPos(chrono.ChVectorD(0, 0.5, 0))
robot.SetRot(chrono.Q_from_AngAxis(chrono.CH_C_PI / 4, chrono.ChVectorD(0, 0, 1)))

# Add the robot to the simulation system
mysystem.Add(robot)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#
# ---------------------------------------------------------------------

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(mysystem)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Turtlebot Simulation")

# Set camera position and look at point
camera = vis.GetCamera()
camera.SetLocation(chrono.ChVectorD(2, 2, 2))
camera.SetLookAt(chrono.ChVectorD(0, 0, 0))

# Add some lighting
vis.AddLight(chrono.ChVectorD(1, 1, 1), chrono.ChColor(1, 1, 1))

# ---------------------------------------------------------------------
#
# Simulation loop
#
# ---------------------------------------------------------------------

# Simulation parameters
timestep = 0.01
time = 0

while vis.Run():
    # Control the robot's motors
    if time < 5:
        robot.SetMotorSpeed(0, 10)  # Left motor
        robot.SetMotorSpeed(1, -10) # Right motor
    else:
        robot.SetMotorSpeed(0, 0)
        robot.SetMotorSpeed(1, 0)

    # Advance the simulation
    mysystem.DoStepDynamics(timestep)

    # Update the visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    time += timestep



```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a Chrono system (`mysystem`) and sets gravity.
   - Defines a ground body with friction and restitution properties.

2. **Robot Setup:**
   - Loads the Turtlebot model from a URDF file.
   - Sets the robot's initial position and orientation.
   - Adds the robot to the simulation system.

3. **Visualization:**
   - Creates an Irrlicht visualization system (`vis`) and attaches it to the Chrono system.
   - Sets window size, title, camera position, and lighting.

4. **Simulation Loop:**
   - Sets the timestep and initializes the simulation time.
   - Enters a loop that runs until the Irrlicht window is closed.
   - Controls the robot's motors using `SetMotorSpeed()` to make it turn left for the first 5 seconds.
   - Advances the simulation using `DoStepDynamics()`.
   - Updates the visualization by rendering the scene.
   - Increments the simulation time.

**Key Points:**

- This script provides a basic framework for simulating a Turtlebot on a flat terrain.
- You can modify the URDF file, robot parameters, motor controls, and visualization settings to create more complex scenarios.
- The `SetMotorSpeed()` function controls the angular velocity of the robot's wheels.
- The Irrlicht visualization allows you to see the robot's motion in real-time.
