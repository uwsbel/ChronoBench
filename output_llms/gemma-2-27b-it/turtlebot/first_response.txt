```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add physical systems and objects
# a. Ground body
ground = chrono.ChBodyEasyBox(10, 10, 0.1, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.1, 0))
my_system.Add(ground)

# b. Turtlebot robot
robot = chrono.ChWheeledRobotSimple()
robot.SetSystem(my_system)
robot.SetChassisPosition(chrono.ChVectorD(0, 0.5, 0))
robot.SetChassisOrientation(chrono.Q_from_AngAxis(chrono.CH_C_PI / 4, chrono.ChVectorD(0, 0, 1)))

# 3. Set default parameters
# a. Motor parameters (adjust as needed)
left_motor_speed = 10
right_motor_speed = 10

# b. Simulation parameters
time_step = 0.01
simulation_time = 10

# 4. Real-time visualization with Irrlicht
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Turtlebot Simulation")
vis.Initialize()
camera = vis.GetCamera()
camera.SetLocation(chrono.ChVectorD(5, 3, 2))
camera.SetTarget(chrono.ChVectorD(0, 0.5, 0))
vis.SetAmbientLight(chrono.ChColor(0.5, 0.5, 0.5))
vis.SetDirectionalLight(chrono.ChVectorD(1, 1, 1), chrono.ChColor(1, 1, 1))

# 5. Simulation loop
while my_system.GetChTime() < simulation_time:
    # a. Control robot motors
    if my_system.GetChTime() < 5:
        robot.SetWheelTorque(left_motor_speed, right_motor_speed)
    else:
        robot.SetWheelTorque(-left_motor_speed, -right_motor_speed)

    # b. Update and render the simulation
    my_system.DoStepDynamics(time_step)
    vis.Render()

# 6. Clean up
vis.Shutdown()
```

**Explanation:**

1. **Initialization:**
   - Creates a Chrono system with gravity.
2. **Objects:**
   - Adds a ground plane as a rigid body.
   - Initializes a Turtlebot robot using `ChWheeledRobotSimple` and sets its position and orientation.
3. **Parameters:**
   - Sets initial motor speeds.
   - Defines simulation time step and total duration.
4. **Visualization:**
   - Sets up Irrlicht visualization with a camera and lighting.
5. **Simulation Loop:**
   - Controls the robot's motors based on time.
   - Updates the Chrono system and renders the scene using Irrlicht.
6. **Cleanup:**
   - Shuts down the Irrlicht visualization.

**Notes:**

- This script provides a basic framework. You can customize the robot's behavior, add more objects, and adjust simulation parameters as needed.
- The `ChWheeledRobotSimple` class is a basic implementation. For more complex robots, you might need to use other Chrono classes and define custom geometries and actuators.
- Remember to install the required PyChrono and Irrlicht libraries.
