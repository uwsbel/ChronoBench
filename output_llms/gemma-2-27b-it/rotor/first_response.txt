```python
import pychrono as chrono
import pychrono.fea as fea
import pychrono.irrlicht as irr
import numpy as np

# 1. Initialize the PyChrono environment and core components.
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Create the IGA beam
# Define beam geometry and material properties
beam_length = 1.0
beam_radius = 0.05
beam_material = fea.ChMaterialShellANCF(rho=7850, E=200e9, nu=0.3)

# Define NURBS control points for the beam (example - adjust for desired shape)
control_points = np.array([
    [0, 0, 0],
    [beam_length, 0, 0],
])

# Create the IGA beam object
beam = fea.ChBeamIGA(control_points, beam_material, 2)  # 2 indicates quadratic NURBS basis

# Add the beam to the system
my_system.Add(beam)

# 3. Attach the flywheel at the center of the beam
flywheel_radius = 0.2
flywheel_mass = 10.0
flywheel = chrono.ChBodyEasyBox(flywheel_radius * 2, flywheel_radius * 2, 0.1, flywheel_mass)
flywheel.SetPos(chrono.ChVectorD(beam_length / 2, 0, 0))
my_system.Add(flywheel)

# Create a constraint to attach the flywheel to the beam
constraint = chrono.ChLinkLockRevolute(flywheel, beam.GetNode(1))  # Attach to the center node
constraint.SetAxis(chrono.ChVectorD(0, 0, 1))  # Rotation axis
my_system.Add(constraint)

# 4. Add a rotational motor to drive the beam
motor_speed = 100  # RPM
motor = chrono.ChLinkMotorRotationSpeed(beam.GetNode(0))
motor.SetSpeedFunction(chrono.ChFunction_Const(motor_speed * np.pi / 30))
my_system.Add(motor)

# 5. Set up visualization
vis = irr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Jeffcott Rotor Simulation')
vis.Initialize()
vis.AddTypicalLights()
vis.AddCamera(chrono.ChVectorD(2, 2, 2))

# Enable FEM visualization
fea.ChVisualizationFEA(vis, beam)

# 6. Run the simulation
while vis.Run():
    my_system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:** Sets up the Chrono system, gravity, and other basic parameters.
2. **IGA Beam:** Defines the geometry, material properties, and control points for the IGA beam. The `ChBeamIGA` object is created using these parameters.
3. **Flywheel:** Creates a simple box-shaped flywheel and positions it at the center of the beam using `ChBodyEasyBox`. A `ChLinkLockRevolute` constraint connects the flywheel to the beam, allowing rotation around a specific axis.
4. **Motor:** A `ChLinkMotorRotationSpeed` is used to drive the beam at a constant speed. The `SetSpeedFunction` method defines the desired rotational speed.
5. **Visualization:** Initializes Irrlicht for visualization, adds lights and a camera, and enables FEM visualization for the beam.
6. **Simulation Loop:** Runs the simulation in a loop, performing dynamics calculations and rendering the scene.

**Remember:**


* This is a basic example and can be further customized. For instance, you can:

    * Add damping and other forces to the system.
    * Implement more sophisticated control strategies for the motor.
    * Explore different visualization options.
