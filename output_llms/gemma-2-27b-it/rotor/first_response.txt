```python
import pychrono as chrono
import pychrono.fea as fea
import pychrono.irrlicht as irr
import numpy as np

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")

# Create the system
system = chrono.ChSystemNSC()

# Create a material for the beam
material = fea.ChMaterialShellANCF(rho=7850, E=200e9, nu=0.3)

# Define beam geometry (example: rectangular cross-section)
width = 0.1
height = 0.2
length = 1.0
nodes = np.array([
    [0, 0, 0],
    [length, 0, 0],
])
elements = np.array([[0, 1]])

# 2. Create the IGA beam
beam = fea.ChBeamIGA(nodes, elements, material)
beam.SetKnotsDistribution([0, 1])  # Example knot distribution
beam.SetDegree(2)  # Example degree

# 3. Add the beam to the system
system.Add(beam)

# 4. Attach the flywheel at the center of the beam
flywheel_radius = 0.2
flywheel_mass = 10.0

flywheel = chrono.ChBodyEasyBox(flywheel_radius * 2, flywheel_radius * 2, 0.1, flywheel_mass)
flywheel.SetPos(chrono.ChVectorD(length / 2, 0, 0))
system.Add(flywheel)

# Create a constraint to connect the flywheel to the beam
constraint = chrono.ChLinkLockRevolute(beam.GetNode(1), flywheel)
system.Add(constraint)

# 5. Create a rotational motor to drive the beam
motor = chrono.ChLinkMotorRotationSpeed(beam.GetNode(0))
motor.SetSpeedFunction(chrono.ChFunction_Const(10))  # Set desired rotational speed
system.Add(motor)

# 6. Visual setup

# Create an Irrlicht visualization system
vis = irr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Jeffcott Rotor Simulation")
vis.Initialize()

# Add FEM visualization
fea_vis = fea.ChVisualizationFEA(vis)
fea_vis.SetMesh(beam.GetMesh())
fea_vis.SetFEMdataType(fea.ChVisualizationFEA.NODE_SPEED)
fea_vis.SetSymbolsScale(0.05)

# 7. Simulation loop
while vis.Run():
    system.DoStepDynamics(0.01)
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono modules.
   - Sets the Chrono data path.
   - Creates a `ChSystemNSC` to manage the simulation.

2. **Beam Creation:**
   - Defines material properties (density, Young's modulus, Poisson's ratio).
   - Sets up beam geometry (nodes, elements).
   - Creates an `ChBeamIGA` object using the defined geometry and material.

3. **Flywheel Attachment:**
   - Creates a `ChBodyEasyBox` for the flywheel.
   - Positions the flywheel at the center of the beam.
   - Uses a `ChLinkLockRevolute` constraint to rigidly connect the flywheel to the beam.

4. **Motor:**
   - Creates a `ChLinkMotorRotationSpeed` to drive the beam at a constant speed.
   - Sets the desired rotational speed using `SetSpeedFunction`.

5. **Visualization:**
   - Creates an Irrlicht visualization system (`ChVisualSystemIrrlicht`).
   - Attaches the system to the Irrlicht visualizer.
   - Sets window size and title.
   - Initializes the Irrlicht window.
   - Adds FEM visualization (`ChVisualizationFEA`) to display the beam's deformation and speed.

6. **Simulation Loop:**
   - Runs the simulation loop until the Irrlicht window is closed.
   - Performs a single simulation step using `DoStepDynamics`.
   - Renders the scene using Irrlicht.

**Notes:**



* This is a basic example and can be further customized. For instance, you can:
    * Change the beam geometry, material properties, and boundary conditions.
    * Add damping and other forces to the system.
    * Implement more complex motor control strategies.
    * Modify the visualization settings.

* You'll need to have PyChrono installed along with its dependencies (Irrlicht, NumPy).

* Remember to adjust parameters like beam length, flywheel mass, and motor speed to achieve the desired dynamic behavior.
