```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system
#

mysystem = chrono.ChSystemNSC()

# Set gravitational acceleration
mysystem.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(mysystem)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Mass-Spring-Damper System')
vis.Initialize()
vis.AddCamera(chrono.ChVectorD(0, 5, -10))  # Camera position
vis.AddLight(chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1))  # Light source

# ---------------------------------------------------------------------
#
#  Create the physical objects
#

# Create the ground body
ground = chrono.ChBodyEasyBox(10, 0.2, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
mysystem.AddBody(ground)

# Create the mass body
mass = chrono.ChBodyEasySphere(0.5, 1000)
mass.SetPos(chrono.ChVectorD(0, 2, 0))
mysystem.AddBody(mass)

# Create the spring-damper connection
spring = chrono.ChLinkTSDA()
spring.Initialize(ground, mass, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 0))
mysystem.AddLink(spring)

# ---------------------------------------------------------------------
#
#  Set visualization properties
#

# Create a sphere shape for the mass
mass_shape = chrono.ChSphereShape()
mass_shape.GetSphereGeometry().rad = 0.5
mass.AddVisualShape(mass_shape)

# Create a cylinder shape for the spring
spring_shape = chrono.ChCylinderShape()
spring_shape.GetCylinderGeometry().rad = 0.1
spring_shape.GetCylinderGeometry().p1 = chrono.ChVectorD(0, 0, 0)
spring_shape.GetCylinderGeometry().p2 = chrono.ChVectorD(0, -2, 0)
spring.AddVisualShape(spring_shape)

# ---------------------------------------------------------------------
#
#  Simulation loop
#

while vis.Run():
    mysystem.DoStepDynamics(0.01)
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a `ChSystemNSC` to manage the simulation.
   - Sets the gravitational acceleration.

2. **Visualization:**
   - Creates an `ChVisualSystemIrrlicht` for visualization.
   - Attaches it to the simulation system.
   - Sets window size, title, and camera position.
   - Adds a light source for better visibility.

3. **Physical Objects:**
   - Creates a ground body using `ChBodyEasyBox`.
   - Creates a mass body using `ChBodyEasySphere`.
   - Connects the mass to the ground with a `ChLinkTSDA` (mass-spring-damper).

4. **Visualization Properties:**
   - Adds a sphere shape to the mass body.
   - Adds a cylinder shape to the spring, visually representing its connection.

5. **Simulation Loop:**
   - Runs the simulation until the Irrlicht window is closed.
   - Performs a single simulation step using `DoStepDynamics`.
   - Renders the scene using Irrlicht.

This script demonstrates a basic mass-spring-damper system in PyChrono with Irrlicht visualization. You can modify parameters like mass, spring stiffness, damping coefficient, and initial conditions to explore different behaviors.
