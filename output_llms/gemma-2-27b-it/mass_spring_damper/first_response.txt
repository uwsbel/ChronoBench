```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the PyChrono simulation environment
#
# ---------------------------------------------------------------------

my_system = chrono.ChSystemNSC()

# Set the simulation step size
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))
my_system.SetTimestepperType(chrono.ChTimestepper.Type_EULER_IMPLICIT_LINEARIZED)
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
my_system.SetSolverMaxIterations(100)
my_system.SetStep(0.01)

# ---------------------------------------------------------------------
#
# Create the Irrlicht visualization system
#
# ---------------------------------------------------------------------
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Mass-Spring-Damper System')
vis.Initialize()
vis.AddCamera(chrono.ChVectorD(2, 2, 2))
vis.AddLight(chrono.ChVectorD(1, 1, 1), chrono.ChColor(1, 1, 1))

# ---------------------------------------------------------------------
#
# Create the physical objects
#
# ---------------------------------------------------------------------

# Ground
ground = chrono.ChBodyEasyBox(10, 0.2, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.1, 0))
ground.SetBodyFixed(True)
my_system.Add(ground)

# Mass
mass = chrono.ChBodyEasySphere(0.2, 1000, True, True)
mass.SetPos(chrono.ChVectorD(0, 1, 0))
my_system.Add(mass)

# Spring-damper connection
spring = chrono.ChLinkTSDA()
spring.Initialize(ground, mass, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)), chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
my_system.Add(spring)

# ---------------------------------------------------------------------
#
# Create visual shapes for the objects
#
# ---------------------------------------------------------------------

# Ground visualization
ground_shape = chrono.ChVisualShapeBox(10, 0.2, 10)
ground_shape.SetTexture(chronoirr.GetChronoDataPath() + 'blu.png')
ground.AddVisualShape(ground_shape)

# Mass visualization
mass_shape = chrono.ChVisualShapeSphere(0.2)
mass_shape.SetTexture(chronoirr.GetChronoDataPath() + 'red.png')
mass.AddVisualShape(mass_shape)

# Spring visualization
spring_shape = chrono.ChVisualShapeSpring(0.1, 10, 100, 10)
spring.AddVisualShape(spring_shape)

# ---------------------------------------------------------------------
#
# Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    my_system.DoStepDynamics(0.01)
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**

   - Imports necessary Chrono and Irrlicht modules.
   - Creates a Chrono system (`my_system`) and sets gravity.
   - Sets the timestepper and solver type for numerical integration.
   - Creates an Irrlicht visualization system (`vis`) and configures the window, camera, and lighting.

2. **Object Creation:**

   - Creates a ground body as a fixed box.
   - Creates a mass body as a sphere.
   - Creates a `ChLinkTSDA` object to connect the mass to the ground, representing the spring-damper.

3. **Visualization:**

   - Adds visual shapes (box, sphere, spring) to the ground, mass, and spring objects, respectively.

4. **Simulation Loop:**

   - Runs the Irrlicht visualization loop (`vis.Run()`).
   - In each iteration:
     - Performs a simulation step (`my_system.DoStepDynamics()`).
     - Renders the scene using Irrlicht (`vis.BeginScene()`, `vis.Render()`, `vis.EndScene()`).

**Key Points:**

- This script uses default parameters for the `ChLinkTSDA` spring-damper connection. You can adjust stiffness, damping, and other properties as needed.
- The Irrlicht visualization provides a real-time view of the simulation.
- The simulation loop continues until the Irrlicht window is closed.
