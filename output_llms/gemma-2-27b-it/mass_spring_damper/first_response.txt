```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------
#  1. Initialize the PyChrono environment and core components.
# ---------------------------------

# Create the physical system
system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Mass-Spring-Damper System")
vis.Initialize()

# Set camera position and lighting
vis.GetCamera().SetLocation(chrono.ChVectorD(2, 2, 2))
vis.GetCamera().SetLookAt(chrono.ChVectorD(0, 0, 0))
vis.AddLight(chrono.ChLightPoint(chrono.ChVectorD(2, 2, 2)))

# ---------------------------------
#  2. Add the required physical systems and objects.
# ---------------------------------

# Create the ground body
ground = chrono.ChBodyEasyBox(10, 0.1, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.1, 0))
system.Add(ground)

# Create the mass body
mass = chrono.ChBodyEasySphere(0.2, 10, True, True)
mass.SetPos(chrono.ChVectorD(0, 1, 0))
system.Add(mass)

# Create the spring-damper connection
spring = chrono.ChLinkTSDA()
spring.Initialize(mass, ground, chrono.ChCoordsysD(chrono.ChVectorD(0, 1, 0)))
system.AddLink(spring)

# ---------------------------------
#  3. Set necessary default parameters.
# ---------------------------------

# Visualize the mass as a sphere
mass_shape = chrono.ChVisualShapeSphere(0.2)
mass_shape.SetTexture(chronoirr.ChTexture(vis.GetSceneManager(), "textures/blue.png"))
mass.AddVisualShape(mass_shape)

# Visualize the spring as a cylinder
spring_shape = chrono.ChVisualShapeCylinder(0.05, 1)
spring_shape.SetTexture(chronoirr.ChTexture(vis.GetSceneManager(), "textures/green.png"))
spring.AddVisualShape(spring_shape)

# ---------------------------------
#  4. Run the simulation.
# ---------------------------------

# Simulation settings
time_step = 0.01
end_time = 5

while vis.Run() and system.GetChTime() < end_time:
    system.DoStepDynamics(time_step)
    vis.Render()

# Clean up
vis.Deinitialize()

```

**Explanation:**

1. **Initialization:**

   - Imports necessary PyChrono modules.
   - Creates a `ChSystemNSC` object for the physical system.
   - Sets gravitational acceleration.
   - Initializes the Irrlicht visualization system (`chronoirr.ChVisualSystemIrrlicht`).
   - Sets window size, title, and initializes the visualizer.
   - Configures camera position and lighting.

2. **Object Creation:**

   - Creates a ground body as a simple box using `ChBodyEasyBox`.
   - Creates a mass body as a sphere using `ChBodyEasySphere`.
   - Creates a spring-damper connection (`ChLinkTSDA`) between the mass and ground.

3. **Parameter Setting:**

   - Sets the initial position of the mass.
   - Adds visual shapes to the mass (sphere) and spring (cylinder) using `ChVisualShapeSphere` and `ChVisualShapeCylinder`, respectively. Textures are applied for visual appeal.

4. **Simulation Loop:**

   - Sets the simulation time step and end time.
   - Runs the simulation loop using `vis.Run()` and `system.GetChTime()`.
   - In each iteration:
     - Performs a dynamics step using `system.DoStepDynamics(time_step)`.
     - Renders the scene using `vis.Render()`.

5. **Cleanup:**

   - Deinitializes the Irrlicht visualizer.

**Key Points:**

- This script demonstrates a basic mass-spring-damper system with default spring-damper parameters. You can adjust these parameters in the `ChLinkTSDA` object for different behaviors.
- The Irrlicht visualization provides a real-time 3D view of the simulation, making it easier to understand the system's dynamics.
- You can modify this script to add more complex objects, forces, and interactions to create more elaborate simulations.
