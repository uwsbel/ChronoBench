```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and set parameters
#
# ---------------------------------------------------------------------

my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Set simulation time step
my_system.SetTimestep(0.01)

# ---------------------------------------------------------------------
#
# Create the Irrlicht visualization system
#
# ---------------------------------------------------------------------

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Mass-Spring-Damper System')
vis.Initialize()

# Set camera position and lighting
vis.GetSceneManager().addLightSceneNode(0, chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1))
vis.GetSceneManager().getActiveCamera().setPosition(chrono.ChVectorD(2, 2, 2))
vis.GetSceneManager().getActiveCamera().setTarget(chrono.ChVectorD(0, 0, 0))

# ---------------------------------------------------------------------
#
# Create the physical objects
#
# ---------------------------------------------------------------------

# Create the ground body
ground = chrono.ChBodyEasyBox(10, 0.2, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.1, 0))
my_system.AddBody(ground)

# Create the mass body
mass = chrono.ChBodyEasySphere(0.2, 10)
mass.SetPos(chrono.ChVectorD(0, 1, 0))
my_system.AddBody(mass)

# Create the spring-damper connection
spring = chrono.ChLinkTSDA()
spring.Initialize(mass, ground, chrono.ChVectorD(0, 0, 0))  # Connect to mass and ground at origin
my_system.AddLink(spring)

# ---------------------------------------------------------------------
#
# Add visualization shapes
#
# ---------------------------------------------------------------------

# Add a visual shape to the mass
mass_asset = vis.AddSphereAsset(0.2, chrono.ChColor(0.8, 0.2, 0.2))
mass.AddAsset(mass_asset)

# Add a visual shape to the spring (using a cylinder)
spring_asset = vis.AddCylinderAsset(0.05, 1, chrono.ChColor(0, 0, 1))
spring.AddAsset(spring_asset)

# ---------------------------------------------------------------------
#
# Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    my_system.DoStepDynamics(0.01)
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules: `chrono` for physics and `chronoirr` for visualization.
   - Creates a `ChSystemNSC` object to manage the simulation.
   - Sets gravity and time step.

2. **Visualization:**
   - Creates a `ChVisualSystemIrrlicht` object for Irrlicht visualization.
   - Attaches the system, sets window size and title, and initializes the visualization.
   - Configures camera position, target, and adds a light source.

3. **Physical Objects:**
   - Creates a ground body using `ChBodyEasyBox`.
   - Creates a mass body using `ChBodyEasySphere`.
   - Creates a `ChLinkTSDA` object to represent the spring-damper connection between the mass and ground.

4. **Visualization Shapes:**
   - Adds a sphere asset to visualize the mass.
   - Adds a cylinder asset to visualize the spring.

5. **Simulation Loop:**
   - Enters the main loop controlled by the Irrlicht visualization.
   - Performs a simulation step using `DoStepDynamics`.
   - Renders the scene using `BeginScene`, `Render`, and `EndScene` functions.



This script will create a visual simulation of a mass bouncing on a spring connected to the ground. The Irrlicht window will show the mass moving up and down, with the spring stretching and compressing accordingly.
