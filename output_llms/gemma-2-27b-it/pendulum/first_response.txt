```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#
# ---------------------------------------------------------------------

# Create a Chrono system
system = chrono.ChSystemNSC()

# Set the gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Simple Pendulum")
vis.Initialize()

# Create a ground body
ground = chrono.ChBodyEasyBox(1, 1, 0.1, 1000)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
ground.SetBodyFixed(True)
system.AddBody(ground)

# Create the pendulum bob
bob = chrono.ChBodyEasySphere(0.2, 10)
bob.SetPos(chrono.ChVectorD(0, 1, 0))

# Create a revolute joint to connect the bob to the ground
joint = chrono.ChLinkRevolute()
joint.Initialize(ground, bob, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
system.AddLink(joint)

# ---------------------------------------------------------------------
#
# Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    system.DoStepDynamics(0.01)

    # Log pendulum position and velocity every 10 steps
    if system.GetTimestepper().GetNumSteps() % 10 == 0:
        print(f"Time: {system.GetChTime()}")
        print(f"Position: {bob.GetPos()}")
        print(f"Velocity: {bob.GetPos_dt()}")

# Delete the Irrlicht visualization system
del vis
```

**Explanation:**

1. **Initialization:**

   - Imports necessary Chrono and Irrlicht modules.
   - Creates a Chrono system (`system`) and sets the gravitational acceleration.
   - Initializes the Irrlicht visualization system (`vis`) and connects it to the Chrono system.

2. **Physical Objects:**

   - Creates a ground body (`ground`) as an easy box with fixed position.
   - Creates a pendulum bob (`bob`) as an easy sphere with a specified mass.
   - Defines a revolute joint (`joint`) to connect the bob to the ground at the origin.

3. **Simulation Loop:**

   - Enters a loop that continues as long as the Irrlicht window is running.
   - Inside the loop:
     - Renders the scene using Irrlicht.
     - Performs a single time step of the simulation using `system.DoStepDynamics(0.01)`.
     - Logs the pendulum's position and velocity every 10 steps.

4. **Cleanup:**

   - Deletes the Irrlicht visualization system after the simulation loop ends.



**Key Points:**



- This script demonstrates the basic setup for a simple pendulum simulation using PyChrono and Irrlicht visualization.
- You can modify parameters like mass, length, initial conditions, and simulation time step to explore different pendulum behaviors.
- The logging code provides a starting point for data analysis; you can extend it to record other quantities or save data to a file.
