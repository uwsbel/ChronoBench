```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#

# Create the physical system
system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body
ground = chrono.ChBodyEasyBox(1, 1, 0.1, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
system.Add(ground)

# Create the pendulum bob
bob_radius = 0.2
bob_mass = 1
bob = chrono.ChBodyEasySphere(bob_radius, bob_mass, True, True)
bob.SetPos(chrono.ChVectorD(0, 1, 0))
system.Add(bob)

# Create a revolute joint to connect the pendulum to the ground
joint = chrono.ChLinkRevolute()
joint.Initialize(ground, bob, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
system.Add(joint)

# ---------------------------------------------------------------------
#
#  Set up visualization
#

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('Simple Pendulum Simulation')
vis.Initialize()
vis.AddTypicalLights()
vis.AddCamera(chrono.ChVectorD(2, 2, 2))

# ---------------------------------------------------------------------
#
#  Simulation loop
#

# Simulation parameters
time_step = 0.01
end_time = 10

# Logging variables
time_log = []
position_log = []
velocity_log = []

while vis.Run():
    # Update the simulation
    system.DoStepDynamics(time_step)

    # Log data
    time_log.append(system.GetChTime())
    position_log.append(bob.GetPos().x)
    velocity_log.append(bob.GetPos_dt().x)

    # Render the scene
    vis.Render()

# ---------------------------------------------------------------------
#
#  Save log data (optional)
#

np.savetxt('time.txt', time_log)
np.savetxt('position.txt', position_log)
np.savetxt('velocity.txt', velocity_log)
```

**Explanation:**

1. **Initialization:** The script imports necessary PyChrono and Irrlicht modules, creates a physical system, sets gravitational acceleration, and defines the simulation time step and duration.

2. **Ground and Pendulum:** It creates a ground body as a box and a pendulum bob as a sphere. Both bodies are added to the system.

3. **Revolute Joint:** A revolute joint is created to connect the pendulum bob to the ground, allowing for rotational movement.

4. **Visualization:** The Irrlicht visualization system is initialized, a camera is added, and typical lights are set up for rendering.

5. **Simulation Loop:** The main loop runs until the Irrlicht window is closed. In each iteration:
   - The simulation is advanced one time step using `system.DoStepDynamics()`.
   - The pendulum's position and velocity are logged for later analysis.
   - The scene is rendered using `vis.Render()`.

6. **Data Logging:** After the simulation, the logged data (time, position, and velocity) can be saved to text files for further processing and analysis.

**Running the Script:**

1. Make sure you have PyChrono and Irrlicht installed.
2. Save the script as a `.py` file (e.g., `pendulum_simulation.py`).
3. Run the script from your terminal using `python pendulum_simulation.py`.

This will open a window showing the pendulum swinging. The simulation will run until you close the window.

**Customization:**

You can customize the simulation by changing parameters like:

- `bob_radius`, `bob_mass`: Modify the pendulum bob's size and mass.
- `time_step`: Adjust the simulation time step for accuracy and stability.
- `end_time`: Change the simulation duration.
- Add forces, constraints, or other objects to the system.
