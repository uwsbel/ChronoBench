```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create the Irrlicht visualization system
viz = chronoirr.ChVisualSystemIrrlicht()
viz.AttachSystem(my_system)
viz.SetWindowSize(800, 600)
viz.SetWindowTitle('Simple Pendulum')
viz.Initialize()

# 2. Add physical systems and objects

# Create ground body
ground = chrono.ChBodyEasyBox(1, 1, 0.1, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
my_system.Add(ground)

# Create pendulum bob
bob = chrono.ChBodyEasySphere(0.2, 1000, True, True)
bob.SetPos(chrono.ChVectorD(0, 1, 0))
my_system.Add(bob)

# Create revolute joint
joint = chrono.ChLinkRevolute()
joint.Initialize(ground, bob, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
my_system.Add(joint)

# 3. Set default parameters

# Set initial velocity of the pendulum
bob.SetPos_dt(chrono.ChVectorD(0, 0, 0))

# Log pendulum position and velocity
log_file = open("pendulum_data.txt", "w")
log_file.write("Time\tPosition_X\tPosition_Y\tVelocity_X\tVelocity_Y\n")

# Simulation loop
while viz.Run():
    my_system.DoStepDynamics(0.01)

    # Log data
    time = my_system.GetChTime()
    pos = bob.GetPos()
    vel = bob.GetPos_dt()
    log_file.write(f"{time}\t{pos.x}\t{pos.y}\t{vel.x}\t{vel.y}\n")

    viz.BeginScene()
    viz.Render()
    viz.EndScene()

log_file.close()
```

**Explanation:**

1. **Initialization:**
   - We create a `ChSystemNSC` object, which represents the physics system.
   - We set the gravitational acceleration using `Set_G_acc`.
   - We initialize the Irrlicht visualization system using `chronoirr.ChVisualSystemIrrlicht` and attach it to the physics system.

2. **Adding Objects:**
   - We create a ground body using `ChBodyEasyBox` and set its position.
   - We create a pendulum bob using `ChBodyEasySphere` and set its position.
   - We create a revolute joint using `ChLinkRevolute` to connect the ground and the bob.

3. **Setting Parameters:**
   - We set the initial velocity of the pendulum bob.
   - We open a file to log the pendulum's position and velocity.

4. **Simulation Loop:**
   - The `while viz.Run()` loop runs the simulation until the Irrlicht window is closed.
   - In each iteration:
     - We advance the physics simulation using `DoStepDynamics`.
     - We log the current time, position, and velocity of the pendulum bob.
     - We render the scene using the Irrlicht visualization system.

**Running the Script:**

1. Make sure you have PyChrono and Irrlicht installed.
2. Save the script as a `.py` file (e.g., `pendulum.py`).
3. Run the script from the command line: `python pendulum.py`

This will open a window displaying the pendulum simulation. The pendulum's position and velocity data will be logged to the `pendulum_data.txt` file.
