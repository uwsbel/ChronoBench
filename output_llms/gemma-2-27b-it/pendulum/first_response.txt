```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# ---------------------------------------------------------------------
#
#  Create the simulation system and add items
#

mysystem = chrono.ChSystemNSC()
mysystem.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the ground body
ground = chrono.ChBodyEasyBox(1, 1, 0.2, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -0.5, 0))
mysystem.Add(ground)

# Create the pendulum bob
bob = chrono.ChBodyEasySphere(0.2, 1000, True, True)
bob.SetPos(chrono.ChVectorD(0, 1, 0))
mysystem.Add(bob)

# Create a revolute joint between the ground and the bob
joint = chrono.ChLinkRevolute()
joint.Initialize(ground, bob, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
mysystem.Add(joint)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization system
#

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(mysystem)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Simple Pendulum")
vis.Initialize()
vis.AddTypicalSky()
vis.AddTypicalCamera(chrono.ChVectorD(2, 2, 2))
vis.SetCameraPosition(chrono.ChVectorD(2, 2, 2))

# ---------------------------------------------------------------------
#
#  Simulation loop
#

while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    mysystem.DoStepDynamics(0.01)

    # Print the pendulum's position and velocity every 10 steps
    if mysystem.GetChTime() % 0.1 == 0:
        print("Time:", mysystem.GetChTime())
        print("Position:", bob.GetPos())
        print("Velocity:", bob.GetPos_dt())

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a `ChSystemNSC` object to manage the simulation.
   - Sets the gravitational acceleration.

2. **Physical Objects:**
   - Creates a ground body as a box using `ChBodyEasyBox`.
   - Creates the pendulum bob as a sphere using `ChBodyEasySphere`.
   - Connects the ground and bob with a revolute joint (`ChLinkRevolute`) allowing rotation around a fixed axis.

3. **Visualization:**
   - Initializes the Irrlicht visualization system (`ChVisualSystemIrrlicht`).
   - Attaches the simulation system to the visualizer.
   - Sets window size, title, and camera position.

4. **Simulation Loop:**
   - Enters the main simulation loop controlled by Irrlicht's `Run()` function.
   - Renders the scene using `vis.Render()`.
   - Performs a simulation step using `mysystem.DoStepDynamics(0.01)`.
   - Prints the pendulum's position and velocity every 0.1 seconds.

This script will create a window displaying the pendulum swinging under gravity. You can adjust parameters like mass, inertia, initial angle, and simulation step size to experiment with different pendulum behaviors.
