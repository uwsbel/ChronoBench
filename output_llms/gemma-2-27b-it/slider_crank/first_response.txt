```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import math

# ---------------------------------------------------------------------
#
#  Create the simulation system
#

# Create a physical system
my_system = chrono.ChSystemNSC()

# Set gravitational acceleration
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# ---------------------------------------------------------------------
#
# Create the ground (truss)
#

# Create a ground body
ground = chrono.ChBody()
ground.SetBodyFixed(True)

# Add a truss visualization to the ground
ground_vis = chronoirr.ChIrrNodeShapeBox(chrono.ChVectorD(10, 0.1, 10), 1)
ground_vis.SetMaterial(chronoirr.ChIrrMaterial(chrono.ChColor(0.5, 0.5, 0.5)))
ground.AddVisualShape(ground_vis)
my_system.AddBody(ground)

# ---------------------------------------------------------------------
#
# Create the crank-slider mechanism
#

# Crank parameters
crank_radius = 0.5
crank_length = 1.0

# Connecting rod parameters
rod_length = 2.0

# Piston parameters
piston_mass = 1.0

# Create the crankshaft
crank = chrono.ChBody()
crank.SetPos(chrono.ChVectorD(0, 0, 0))
crank_vis = chronoirr.ChIrrNodeShapeCylinder(crank_radius, crank_length, 1)
crank_vis.SetMaterial(chronoirr.ChIrrMaterial(chrono.ChColor(0.8, 0.2, 0.2)))
crank.AddVisualShape(crank_vis)
my_system.AddBody(crank)

# Create the connecting rod
rod = chrono.ChBody()
rod.SetPos(chrono.ChVectorD(crank_length, 0, 0))
rod_vis = chronoirr.ChIrrNodeShapeBox(chrono.ChVectorD(rod_length / 2, 0.1, 0.1), 1)
rod_vis.SetMaterial(chronoirr.ChIrrMaterial(chrono.ChColor(0.2, 0.8, 0.2)))
rod.AddVisualShape(rod_vis)
my_system.AddBody(rod)

# Create the piston
piston = chrono.ChBody()
piston.SetPos(chrono.ChVectorD(crank_length + rod_length, 0, 0))
piston_vis = chronoirr.ChIrrNodeShapeSphere(0.2)
piston_vis.SetMaterial(chronoirr.ChIrrMaterial(chrono.ChColor(0.2, 0.2, 0.8)))
piston.AddVisualShape(piston_vis)
my_system.AddBody(piston)

# Create revolute joints
crank_revolute = chrono.ChLinkRevolute()
crank_revolute.Initialize(ground, crank, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1))
my_system.AddLink(crank_revolute)

rod_revolute1 = chrono.ChLinkRevolute()
rod_revolute1.Initialize(crank, rod, chrono.ChVectorD(crank_length, 0, 0), chrono.ChVectorD(0, 0, 1))
my_system.AddLink(rod_revolute1)

rod_revolute2 = chrono.ChLinkRevolute()
rod_revolute2.Initialize(rod, piston, chrono.ChVectorD(crank_length + rod_length, 0, 0), chrono.ChVectorD(0, 0, 1))
my_system.AddLink(rod_revolute2)

# Add a motor to the crankshaft
motor = chrono.ChLinkMotorRotationSpeed()
motor.Initialize(ground, crank, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1))
motor.SetSpeedFunction(chrono.ChFunction_Const(math.pi))  # Constant angular speed
my_system.AddLink(motor)

# ---------------------------------------------------------------------
#
#  Visualization setup
#

# Create an Irrlicht application
application = chronoirr.ChIrrApp(my_system, "Crank-Slider Mechanism", chronoirr.dimension2du(800, 600))

# Set camera position and look-at point
application.AddTypicalCamera(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0))

# Add a directional light
application.AddLight(chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1))

# Set background color
application.SetBackgroundColor(chrono.ChColor(0.8, 0.8, 0.8))

# Set some additional visual elements
# (e.g., add textures, logos, etc.)

# ---------------------------------------------------------------------
#
# Simulation loop
#

application.SetTimestep(0.01)
while application.GetDevice().run():
    application.BeginScene()
    application.DrawAll()
    application.DoStep()
    application.EndScene()
```

**Explanation:**

1. **Initialization:**

   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a `ChSystemNSC` object to manage the physics simulation.
   - Sets gravitational acceleration.

2. **Ground:**

   - Creates a fixed body `ground` representing the floor.
   - Adds a box-shaped visualization to the ground with a gray color.

3. **Crank-Slider Mechanism:**

   - Defines parameters for the crank, connecting rod, and piston.
   - Creates `ChBody` objects for each component.
   - Adds cylinder, box, and sphere visualizations to the crank, rod, and piston respectively, with distinct colors.
   - Creates `ChLinkRevolute` joints to connect the bodies, allowing rotation at the joints.
   - Adds a `ChLinkMotorRotationSpeed` to the crankshaft to drive it at a constant angular speed.

4. **Visualization:**

   - Creates a `ChIrrApp` object for Irrlicht visualization.
   - Sets camera position, look-at point, and background color.
   - Adds a directional light for illumination.
   - You can add more visual elements here, like textures, logos, etc.

5. **Simulation Loop:**

   - Sets the simulation timestep.
   - Enters the main simulation loop, which:
     - Begins the Irrlicht scene.
     - Draws all objects in the scene.
     - Performs a simulation step.
     - Ends the Irrlicht scene.

**To run this script:**

1. Make sure you have PyChrono and Irrlicht installed.
2. Save the script as a `.py` file (e.g., `crank_slider.py`).
3. Run the script from your terminal using `python crank_slider.py`.

This will open a window displaying the crank-slider mechanism simulation. You can interact with the camera using mouse and keyboard controls.
