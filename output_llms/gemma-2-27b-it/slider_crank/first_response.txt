```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Crank-Slider Mechanism")
vis.Initialize()

# Set camera position and lighting
vis.GetCamera().SetLocation(chrono.ChVectorD(2, 2, 2))
vis.GetCamera().SetLookAt(chrono.ChVectorD(0, 0, 0))
vis.AddLight(chrono.ChLight(chrono.ChVectorD(0, 5, 0), chrono.ChColor(1, 1, 1)))

# 2. Add physical systems and objects
# Floor (truss)
floor_material = chrono.ChMaterialSurfaceNSC()
floor_material.SetFriction(0.5)
floor_material.SetRestitution(0.2)

floor = chrono.ChBodyEasyBox(10, 0.2, 10, 1000, True, True, floor_material)
floor.SetPos(chrono.ChVectorD(0, -0.1, 0))
my_system.Add(floor)

# Crankshaft
crankshaft_radius = 0.2
crankshaft_length = 0.5
crankshaft = chrono.ChBodyEasyCylinder(crankshaft_radius, crankshaft_length, 1000, True, True)
crankshaft.SetPos(chrono.ChVectorD(0, 0, 0))
my_system.Add(crankshaft)

# Motor
motor = chrono.ChLinkMotorRotationSpeed()
motor.SetTargetSpeed(10)  # radians/s
motor.Initialize(crankshaft)
my_system.Add(motor)

# Connecting rod
connecting_rod_length = 1
connecting_rod = chrono.ChBodyEasyBox(0.1, connecting_rod_length, 0.1, 500, True, True)
connecting_rod.SetPos(chrono.ChVectorD(crankshaft_radius, 0, 0))
my_system.Add(connecting_rod)

# Piston
piston_radius = 0.2
piston = chrono.ChBodyEasyCylinder(piston_radius, 0.2, 500, True, True)
piston.SetPos(chrono.ChVectorD(crankshaft_radius + connecting_rod_length, 0, 0))
my_system.Add(piston)

# 3. Set joints and interactions
# Revolute joint between crankshaft and connecting rod
revolute_joint = chrono.ChLinkRevolute()
revolute_joint.Initialize(crankshaft, connecting_rod, chrono.ChVectorD(crankshaft_radius, 0, 0))
my_system.Add(revolute_joint)

# Spherical joint between connecting rod and piston
spherical_joint = chrono.ChLinkSphere()
spherical_joint.Initialize(connecting_rod, piston, chrono.ChVectorD(connecting_rod_length, 0, 0))
my_system.Add(spherical_joint)

# Add collision detection
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
my_system.SetCollisionSystemType(chrono.ChCollisionSystem.Type_BULLET)

# 4. Visualization settings
# Add textures and logos (optional)

# Run the simulation
while vis.Run():
    my_system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - We create a `ChSystemNSC` object to represent the physical system.
   - We set the gravity using `Set_G_acc`.
   - We initialize the Irrlicht visualization system (`chronoirr`) and set up the window, camera, and lighting.

2. **Objects and Systems:**
   - We create the floor, crankshaft, connecting rod, and piston as `ChBody` objects.
   - We define materials for friction and restitution.
   - We add a motor to rotate the crankshaft at a constant speed.
   - We use `ChLinkRevolute` and `ChLinkSphere` to connect the objects with revolute and spherical joints, respectively.

3. **Interactions and Solver:**
   - We enable collision detection using a Bullet collision system.
   - We choose the BARZILAIBORWEIN solver for dynamics calculations.

4. **Visualization:**
   - We use the Irrlicht visualization system to render the simulation.
   - You can customize camera settings, lighting, and add textures and logos as needed.

5. **Simulation Loop:**
   - The `while vis.Run():` loop runs the simulation until the window is closed.
   - Inside the loop:
     - We advance the simulation using `DoStepDynamics`.
     - We render the scene using `vis.Render()`.
