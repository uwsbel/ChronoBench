```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Simulation Setup
#

# 1. Initialize the PyChrono environment
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files
my_system = chrono.ChSystemNSC()  # Create a Chrono system

# 2. Set simulation parameters
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity
my_system.SetTimestepperType(chrono.ChTimestepperType.EULER_IMPLICIT_LINEARIZED)
my_system.SetSolverType(chrono.ChSolver.Type_BARZILAIBORWEIN)
my_system.SetSolverMaxIterations(100)
my_system.SetSolverForceTolerance(1e-4)

# 3. Create the terrain
terrain = chrono.ChBodyEasyBox(
    100, 10, 100, 1000, True, True, chrono.ChMaterialSurfaceNSC.Default
)
terrain.SetPos(chrono.ChVectorD(0, -5, 0))
terrain.SetBodyFixed(True)
my_system.Add(terrain)

# 4. Define terrain properties
terrain_material = chrono.ChMaterialSurfaceNSC()
terrain_material.SetFriction(0.8)
terrain_material.SetRestitution(0.2)
terrain.AddMaterial(terrain_material)

# 5. Load the Kraz vehicle model
vehicle = chronovehicle.ChVehicle("kraz/kraz.json")
vehicle.Initialize(my_system)

# 6. Set initial conditions for the vehicle
vehicle.SetChassisPosition(chrono.ChVectorD(0, 1, 0))
vehicle.SetChassisVelocity(chrono.ChVectorD(0, 0, 0))

# 7. Initialize the driver system
driver = chronovehicle.ChDriver(vehicle)

# 8. Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(1200, 800)
vis.SetWindowTitle("Kraz Simulation")

# 9. Set camera and lighting
camera = vis.GetCamera()
camera.SetLocation(chrono.ChVectorD(10, 5, -10))
camera.SetLookAt(chrono.ChVectorD(0, 1, 0))
vis.AddLight(chrono.ChLight(chrono.ChVectorD(5, 10, 5), chrono.ChColor(1, 1, 1)))

# ---------------------------------------------------------------------
#
#  Simulation Loop
#

while vis.Run():
    # 1. Driver control
    driver.Synchronize(vehicle)

    # 2. Advance the simulation
    my_system.DoStepDynamics(0.01)

    # 3. Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**

- Imports necessary PyChrono modules.
- Sets up the Chrono system with gravity.
- Defines simulation parameters like timestepper and solver.
- Creates a rigid terrain with specified dimensions and material properties.

2. **Vehicle Setup:**

- Loads the Kraz vehicle model from a JSON file.
- Initializes the vehicle within the Chrono system.
- Sets initial position and velocity for the vehicle.
- Creates a driver system for controlling the vehicle.

3. **Visualization:**

- Initializes Irrlicht for real-time visualization.
- Sets window size and title.
- Configures camera position and lighting.

4. **Simulation Loop:**

- Runs continuously until the Irrlicht window is closed.
- Inside the loop:
    - The driver system synchronizes with the vehicle, controlling its behavior.
    - The Chrono system advances the simulation by one timestep.
    - Irrlicht renders the scene, updating the visualization.

**Important Notes:**

- You need to have the Kraz vehicle model (`kraz.json`) in the same directory as the script or provide the correct path.
- This script provides a basic framework. You can customize it further by adding more objects, modifying vehicle parameters, implementing different control strategies, and enhancing the visualization.
