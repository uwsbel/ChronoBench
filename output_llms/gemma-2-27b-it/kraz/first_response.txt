```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add physical systems and objects

# 2.1. Terrain
terrain = chrono.ChBodyEasyBox(100, 100, 1, 1000, True, True)
terrain.SetPos(chrono.ChVectorD(0, -1, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)
terrain.GetMaterialSurfaceNSC().SetFriction(0.8)  # Set friction
terrain.GetMaterialSurfaceNSC().SetRestitution(0.2)  # Set restitution

# 2.2. Kraz Vehicle
vehicle = chronovehicle.ChVehicle("kraz/kraz.json")
vehicle.SetChassisBody(chrono.ChBodyEasyBox(2, 1, 0.5, 1000, True, True))
vehicle.Initialize(system)
vehicle.SetPos(chrono.ChVectorD(0, 1, 0))

# 2.3. Driver System
driver = chronovehicle.ChDriver(vehicle)
driver.SetSteeringInput(0)
driver.SetThrottleInput(0)

# 3. Visualization settings
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Kraz Simulation")
vis.Initialize()
camera = vis.GetSceneManager().getActiveCamera()
camera.setPosition(chrono.ChVectorD(0, 5, -10))
camera.setTarget(chrono.ChVectorD(0, 1, 0))
vis.SetAmbientLight(chrono.ChColor(0.5, 0.5, 0.5))
vis.SetDirectionalLight(chrono.ChVectorD(1, 1, 1), chrono.ChColor(1, 1, 1))

# 4. Simulation loop
while vis.Run():
    # Update driver inputs (example: keyboard control)
    if vis.GetDevice()->IsKeyDown(chrono.irr::KEY_LEFT):
        driver.SetSteeringInput(-1)
    elif vis.GetDevice()->IsKeyDown(chrono.irr::KEY_RIGHT):
        driver.SetSteeringInput(1)
    else:
        driver.SetSteeringInput(0)

    if vis.GetDevice()->IsKeyDown(chrono.irr::KEY_UP):
        driver.SetThrottleInput(1)
    elif vis.GetDevice()->IsKeyDown(chrono.irr::KEY_DOWN):
        driver.SetThrottleInput(-1)
    else:
        driver.SetThrottleInput(0)

    # Advance simulation
    system.DoStepDynamics(0.01)

    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
```

**Explanation:**

1. **Initialization:**
   - Sets up the Chrono environment, defines gravity, and creates a system object.
2. **Physical Objects:**
   - **Terrain:** Creates a simple box-shaped terrain with specified dimensions, material properties (friction and restitution), and position.
   - **Kraz Vehicle:** Loads a Kraz vehicle model from a JSON file (assuming you have the model file "kraz/kraz.json"). Initializes the vehicle chassis and adds it to the system.
   - **Driver System:** Creates a driver object associated with the vehicle, allowing for control inputs.
3. **Visualization:**
   - Uses Irrlicht for real-time visualization.
   - Sets window size, title, camera position and target, and basic lighting.
4. **Simulation Loop:**
   - Runs continuously while the visualization window is open.
   - **Driver Input:** Handles keyboard input for steering and throttle control.
   - **Simulation Advance:** Steps the physics simulation forward by a small time step (0.01 seconds).
   - **Visualization Update:** Renders the scene using Irrlicht.

**Notes:**

- This script assumes you have the necessary Kraz vehicle model file ("kraz/kraz.json") and the PyChrono library installed.
- You can customize the terrain, vehicle, driver behavior, and visualization settings as needed.
- The provided driver control is basic and can be expanded to include more sophisticated control algorithms.
