- **Driver Inputs:**  
  The lane change steering input calculation is suspicious:  
  ```python

  ```  
  This expression produces a steering input that linearly interpolates from `-target_lane_offset` to `+target_lane_offset` over the lane change duration. However, steering inputs are typically normalized between -1 and 1, not in meters or world units. Using a lane offset value directly as steering input is logically incorrect.  
  **Deduct 10 points** for logical error in steering input calculation.

  **Deduct 10 points** for incorrect visualization synchronization call.
