```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("data/")

# Create the simulation system
system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add the required physical systems and objects

# Create the terrain
terrain = chrono.ChBodyEasyBox(
    200, 200, 1, 1000, True, True, chrono.ChMaterialSurfaceNSC()
)
terrain.SetPos(chrono.ChVectorD(0, -1, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)

# Create the vehicle model
vehicle = chronovehicle.ChVehicle("MAN 10t Truck", system)
vehicle.SetChassisVisualizationType(chronovehicle.VisualizationType_MESH)
vehicle.SetChassisCollisionType(chronovehicle.CollisionType_NONE)

# Load vehicle model
vehicle.SetVehiclePath("MAN_10t")
vehicle.Initialize()

# Set tire model
for wheel in vehicle.GetWheels():
    wheel.SetTireModel(chronovehicle.TMEasy())

# 3. Set necessary default parameters

# Initial position and orientation
vehicle.SetChassisPos(chrono.ChVectorD(0, 1, 0))
vehicle.SetChassisRot(chrono.Q_from_AngAxis(0, chrono.ChVectorD(0, 1, 0)))

# Driver controls
driver = chronovehicle.ChDriver(vehicle)
driver.SetSteeringGain(0.5)
driver.SetThrottleGain(0.5)
driver.SetBrakingGain(0.5)

# 4. Visualize the simulation

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle("MAN 10t Truck Simulation")

# Set camera
camera = vis.GetCamera()
camera.SetTarget(vehicle.GetChassis().GetPos())
camera.SetDistance(15)
camera.SetFollow(vehicle.GetChassis())

# Add directional lighting
vis.AddLight(chrono.ChLightPoint(chrono.ChVectorD(5, 5, 5), chrono.ChColor(1, 1, 1)))

# Add skybox
vis.AddSkyBox("data/skybox/blue")

# Set terrain texture and logo
terrain.GetVisualShape(0).SetTexture(chrono.ChTexture())
terrain.GetVisualShape(0).GetTexture().SetTextureFilename("data/terrain/grass.jpg")

# Simulation loop
while vis.Run():
    # Update driver controls
    driver.Update(vis.GetDeltaTime())

    # Advance the simulation
    system.DoStepDynamics(vis.GetDeltaTime())

    # Render the scene
    vis.Render()
```

**Explanation:**

1. **Initialization:** Sets up the PyChrono environment, creates the simulation system, and defines gravity.
2. **Terrain and Vehicle:** Creates a rigid terrain and a MAN 10t truck model using the `chronovehicle` module. Configures visualization and collision settings for the vehicle.
3. **Tire Model and Driver:** Assigns the TMEasy tire model to each wheel and creates a driver object to control steering, throttle, and braking.
4. **Visualization:** Uses Irrlicht for visualization, sets up a chase camera, adds lighting and a skybox, and applies textures to the terrain.
5. **Simulation Loop:** Continuously updates driver controls, advances the simulation, and renders the scene.

**Customization:**

* **Vehicle Model:** Replace "MAN_10t" with the path to your desired vehicle model.
* **Terrain:** Modify terrain dimensions, texture, and logo.
* **Driver Controls:** Adjust steering, throttle, and braking gains.
* **Visualization:** Customize camera settings, lighting, and skybox.
