```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# ---------------------------------------------------------------------
#
#  Simulation setup
#

# Create the system
system = chrono.ChSystemNSC()

# Set gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("MAN 10t Truck Simulation")
vis.Initialize()

# Create a chase camera
camera = chronoirr.ChCamera(vis.GetDevice())
camera.SetPosition(chrono.ChVectorD(0, 2, -5))
camera.SetLookAt(chrono.ChVectorD(0, 0, 0))
camera.SetFOV(45)
vis.AddCamera(camera)

# Add directional lighting
light = chronoirr.ChLight(vis.GetDevice())
light.SetPosition(chrono.ChVectorD(5, 5, 5))
light.SetDiffuseColor(chrono.ChColor(1, 1, 1))
vis.AddLight(light)

# Add a skybox
skybox = chronoirr.ChSkyBox(vis.GetDevice())
skybox.SetTexture("textures/skybox.jpg")
vis.AddSkyBox(skybox)

# ---------------------------------------------------------------------
#
#  Terrain
#

# Create a ground body
ground = chrono.ChBodyEasyBox(100, 100, 0.2, 1000)
ground.SetPos(chrono.ChVectorD(0, -0.1, 0))
ground.SetBodyFixed(True)
system.AddBody(ground)

# Set terrain texture
ground_texture = chronoirr.ChTexture(vis.GetDevice())
ground_texture.SetFile("textures/terrain.jpg")
ground.AddVisualShape(chrono.ChVisualShapeBox(100, 100, 0.2), chrono.ChColor(1, 1, 1))
ground.GetVisualShape(0).SetTexture(ground_texture)

# ---------------------------------------------------------------------
#
#  Vehicle
#

# Create a MAN 10t truck model
vehicle = chronovehicle.ChVehicleModelMAN()

# Set initial position and orientation
vehicle.SetPos(chrono.ChVectorD(0, 0.5, 0))
vehicle.SetRot(chrono.Q_from_AngAxis(0, chrono.ChVectorD(0, 1, 0)))

# Add the vehicle to the system
system.Add(vehicle)

# Set visualization settings
vehicle.SetChassisVisualizationType(chronovehicle.VisualizationType_MESH)
vehicle.SetSuspensionVisualizationType(chronovehicle.VisualizationType_PRIMITIVES)
vehicle.SetWheelVisualizationType(chronovehicle.VisualizationType_MESH)

# Configure tire model
vehicle.SetTireModelType(chronovehicle.TireModelType_TMEASY)

# ---------------------------------------------------------------------
#
#  Driver controls
#

# Create a driver input interface
driver = chronovehicle.ChDriver(vehicle)

# ---------------------------------------------------------------------
#
#  Simulation loop
#

while vis.Run():
    # Update driver inputs
    driver.SetSteeringAngle(chrono.ChDeg2Rad(10))  # Example steering input
    driver.SetThrottle(0.5)  # Example throttle input
    driver.SetBraking(0)  # Example braking input

    # Update the simulation
    system.DoStepDynamics(0.01)

    # Update the visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

# Cleanup
vis.DetachSystem()
vis.Destroy()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono modules.
   - Creates a `ChSystemNSC` for the simulation.
   - Sets gravitational acceleration.
   - Initializes the Irrlicht visualization system (`chronoirr`) and sets up a window, camera, lighting, and skybox.

2. **Terrain:**
   - Creates a ground body using `ChBodyEasyBox` and sets its position and fixed status.
   - Adds a visual shape to the ground with a texture.

3. **Vehicle:**
   - Creates a `ChVehicleModelMAN` instance for the MAN 10t truck.
   - Sets the initial position and orientation of the truck.
   - Adds the vehicle to the system.
   - Configures visualization settings for the chassis, suspension, and wheels.
   - Sets the tire model to TMEASY.

4. **Driver Controls:**
   - Creates a `ChDriver` instance to handle driver inputs.
   - Placeholder for implementing steering, throttle, and braking controls.

5. **Simulation Loop:**
   - Enters a loop that runs until the Irrlicht window is closed.
   - Updates driver inputs (example values are provided).
   - Performs a simulation step using `system.DoStepDynamics()`.
   - Updates the Irrlicht visualization.

**Remember:**

- This script provides a basic framework. You'll need to fill in the driver control logic, adjust parameters, and add more detailed vehicle and terrain models for a complete simulation.
- You can customize the Irrlicht visualization further by adding more objects, changing textures, and adjusting camera settings.
