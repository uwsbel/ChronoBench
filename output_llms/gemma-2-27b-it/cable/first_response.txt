```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr
import numpy as np

# ---------------------------------------------------------------------
#
#  Create the simulation system and add the Irrlicht visualizer
#
# ---------------------------------------------------------------------

my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(my_system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("ANCF Beam Simulation")
vis.Initialize()
vis.AddTypicalSky()
vis.AddTypicalLights()

# ---------------------------------------------------------------------
#
# Create the ground body
#
# ---------------------------------------------------------------------

ground = chrono.ChBodyEasyBox(10, 0.2, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
my_system.AddBody(ground)

# ---------------------------------------------------------------------
#
# Create the ANCF beam
#
# ---------------------------------------------------------------------

beam_length = 5
num_elements = 10
beam_radius = 0.1

beam = chrono.ChBody()
beam.SetBodyFixed(False)

# Create ANCF elements and add them to the beam
for i in range(num_elements):
    element = chrono.ChElementCableANCF()
    element.Set_L0(beam_length / num_elements)
    element.Set_radius(beam_radius)
    element.Set_young_modulus(2e7)
    element.Set_poisson_ratio(0.3)
    element.Set_density(7850)

    # Set initial position of the element nodes
    node1 = chrono.ChNodeANCF()
    node1.SetPos(chrono.ChVectorD(i * beam_length / num_elements, 0, 0))
    node2 = chrono.ChNodeANCF()
    node2.SetPos(chrono.ChVectorD((i + 1) * beam_length / num_elements, 0, 0))

    element.AddNode(node1)
    element.AddNode(node2)

    beam.AddElement(element)

my_system.AddBody(beam)

# ---------------------------------------------------------------------
#
# Hinge the beam to the ground
#
# ---------------------------------------------------------------------

hinge = chrono.ChLinkLockRevolute()
hinge.Initialize(ground, beam, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
my_system.AddLink(hinge)

# ---------------------------------------------------------------------
#
# Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    vis.BeginScene()
    vis.Render()
    vis.EndScene()

    my_system.DoStepDynamics(0.01)

    # Print nodal positions for debugging
    for i in range(beam.GetNnodes()):
        pos = beam.GetNode(i).GetPos()
        print(f"Node {i}: {pos}")

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a `ChSystemNSC` object for the simulation.
   - Sets gravitational acceleration.
   - Initializes the Irrlicht visualizer (`chronoirr`) and sets up the window.

2. **Ground Body:**
   - Creates a simple box body (`ChBodyEasyBox`) to represent the ground.
   - Positions the ground at y = -1.
   - Adds the ground body to the simulation system.

3. **ANCF Beam:**
   - Defines beam parameters (length, number of elements, radius).
   - Creates a `ChBody` object to hold the beam elements.
   - Loops through the number of elements:
     - Creates an `ChElementCableANCF` object for each element.
     - Sets element properties (length, radius, material properties).
     - Creates two `ChNodeANCF` objects for the element's nodes.
     - Sets initial positions of the nodes along the x-axis.
     - Adds the nodes to the element and the element to the beam body.
   - Adds the beam body to the simulation system.

4. **Hinge Constraint:**
   - Creates a `ChLinkLockRevolute` object to hinge the beam to the ground.
   - Initializes the hinge at the origin (0, 0, 0).
   - Adds the hinge constraint to the simulation system.

5. **Simulation Loop:**
   - Enters a loop that continues until the Irrlicht window is closed.
   - Inside the loop:
     - Renders the scene using Irrlicht.
     - Performs a dynamics step using `DoStepDynamics`.
     - Prints the positions of all beam nodes for debugging (optional).

**To Run:**

1. Make sure you have PyChrono and Irrlicht installed.
2. Save the script as a `.py` file (e.g., `beam_simulation.py`).
3. Run the script from the command line: `python beam_simulation.py`

This will open a window displaying the beam simulation. You should see the beam hanging downwards due to gravity and its deformation under its own weight.
