```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system
#

mysystem = chrono.ChSystemNSC()

# Set gravitational acceleration
mysystem.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# ---------------------------------------------------------------------
#
#  Create the ground body
#

ground = chrono.ChBodyEasyBox(10, 1, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
mysystem.Add(ground)

# ---------------------------------------------------------------------
#
#  Create the ANCF cable beam
#

beam = chrono.ChBeamSectionCable()
beam.SetDiameter(0.01)
beam.SetYoungModulus(2e7)
beam.SetDensity(7850)
beam.SetPoissonRatio(0.3)

beam_body = chrono.ChBody()
beam_body.SetPos(chrono.ChVectorD(0, 1, 0))
beam_body.SetBodyFixed(True)  # Fix the first node to the ground

n_nodes = 10
for i in range(n_nodes):
    node = chrono.ChNodeFEAxyzD(chrono.ChVectorD(i * 0.2, 0, 0))
    beam_body.AddNodeFEAxyzD(node)

beam_body.SetSection(beam)

mysystem.Add(beam_body)

# ---------------------------------------------------------------------
#
#  Create the Irrlicht visualization
#

vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(mysystem)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('ANCF Cable Beam Simulation')
vis.Initialize()
vis.AddTypicalSky()
vis.AddCamera(chrono.ChVectorD(2, 2, 2))

# ---------------------------------------------------------------------
#
#  Simulation loop
#

while vis.Run():
    mysystem.DoStepDynamics(0.01)

    vis.BeginScene()
    vis.Render()
    vis.EndScene()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Creates a `ChSystemNSC` object to manage the simulation.
   - Sets gravitational acceleration.

2. **Ground Body:**
   - Creates a simple box as the ground using `ChBodyEasyBox`.
   - Positions it below the beam.

3. **ANCF Cable Beam:**
   - Creates a `ChBeamSectionCable` object to define the cable's material properties (diameter, Young's modulus, density, Poisson ratio).
   - Creates a `ChBody` to hold the beam nodes.
   - Sets the first node fixed to the ground.
   - Adds nodes along the beam's length using `ChNodeFEAxyzD`.
   - Assigns the cable section to the beam body.

4. **Irrlicht Visualization:**
   - Creates a `ChVisualSystemIrrlicht` object for rendering.
   - Attaches the simulation system to the visualizer.
   - Sets window size and title.
   - Initializes the Irrlicht engine and adds a skybox.
   - Sets up a camera to view the scene.

5. **Simulation Loop:**
   - Runs the Irrlicht event loop.
   - Performs a simulation step using `DoStepDynamics`.
   - Renders the scene using Irrlicht's `BeginScene`, `Render`, and `EndScene` methods.

**To run this script:**

- Make sure you have PyChrono and Irrlicht installed.
- Save the code as a Python file (e.g., `beam_simulation.py`).
- Run the file from your terminal: `python beam_simulation.py`
