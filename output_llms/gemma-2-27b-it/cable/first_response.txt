```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# ---------------------------------------------------------------------
#
#  Create the simulation system
#
# ---------------------------------------------------------------------

# Create a physical system
system = chrono.ChSystemNSC()

# Set the gravitational acceleration
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Create a Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("ANCF Beam Simulation")
vis.Initialize()
vis.AddCameraLight()
vis.AddSkyBox()

# ---------------------------------------------------------------------
#
#  Create the beam
#
# ---------------------------------------------------------------------

# Define beam parameters
num_elements = 10
beam_length = 5.0
beam_radius = 0.1

# Create the ANCF cable material
material = chrono.ChMaterialSurfaceNSC()
material.SetFriction(0.3)
material.SetRestitution(0.2)

# Create the ANCF cable element
beam = chrono.ChBody()
beam.SetBodyFixed(False)
beam.SetMass(10.0)
beam.SetInertiaXX(chrono.ChVectorD(0.1, 0.1, 0.1))

# Add the ANCF cable elements to the beam
for i in range(num_elements):
    element = chrono.ChElementCableANCF()
    element.SetCableMaterial(material)
    element.SetNodes([beam.GetNode(i), beam.GetNode(i + 1)])
    element.SetLength(beam_length / num_elements)
    element.SetRadius(beam_radius)
    beam.AddElement(element)

# ---------------------------------------------------------------------
#
#  Set initial conditions and constraints
#
# ---------------------------------------------------------------------

# Fix one end of the beam to the ground
hinge = chrono.ChLinkLockRevolute()
hinge.Initialize(beam.GetNode(0), chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
system.AddLink(hinge)

# ---------------------------------------------------------------------
#
#  Simulation loop
#
# ---------------------------------------------------------------------

while vis.Run():
    # Advance the simulation
    system.DoStepDynamics(0.01)

    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()
```

**Explanation:**

1. **Initialization:**

   - Imports necessary PyChrono modules.
   - Creates a `ChSystemNSC` object for the physical system.
   - Sets gravitational acceleration.
   - Initializes the Irrlicht visualization system (`chronoirr`) and attaches it to the simulation system.

2. **Beam Creation:**

   - Defines parameters for the beam (number of elements, length, radius).
   - Creates an `ChMaterialSurfaceNSC` object to define the material properties of the cable.
   - Creates a `ChBody` object to represent the beam.
   - Iterates through the desired number of elements, creating `ChElementCableANCF` objects for each segment.
   - Sets the material, nodes, length, and radius for each element.
   - Adds the elements to the beam body.

3. **Constraints:**

   - Creates a `ChLinkLockRevolute` object to create a hinge constraint, fixing one end of the beam to the ground.

4. **Simulation Loop:**

   - Enters a loop that continues until the Irrlicht window is closed.
   - Advances the simulation using `system.DoStepDynamics(0.01)`, performing a time step of 0.01 seconds.
   - Updates the visualization using Irrlicht functions (`vis.BeginScene()`, `vis.Render()`, `vis.EndScene()`).

**To run this script:**

1. Make sure you have PyChrono and Irrlicht installed.
2. Save the script as a Python file (e.g., `beam_simulation.py`).
3. Run the script from your terminal: `python beam_simulation.py`.

This will launch a window showing the ANCF beam simulation, where you can observe its deformation under gravity.
