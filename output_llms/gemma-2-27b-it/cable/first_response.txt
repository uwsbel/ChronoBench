```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("data/")

# Create the physical system
system = chrono.ChSystemNSC()

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle('ANCF Beam Simulation')
vis.Initialize()

# 2. Add the required physical systems and objects
# Create the ground body
ground = chrono.ChBodyEasyBox(10, 0.2, 10, 1000, True, True)
ground.SetPos(chrono.ChVectorD(0, -1, 0))
system.AddBody(ground)

# Create the ANCF beam
beam = chrono.ChBody()
beam.SetBodyFixed(False)

# Define beam parameters
num_elements = 10
beam_length = 5
beam_radius = 0.1

# Create ANCF cable elements
for i in range(num_elements):
    element = chrono.ChElementCableANCF()
    element.SetCableRadius(beam_radius)
    element.SetNodes(beam, beam)
    element.SetLength(beam_length / num_elements)
    beam.AddElement(element)

# Hinge the beam to the ground
hinge = chrono.ChLinkLockRevolute()
hinge.Initialize(beam, ground, chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))
system.AddLink(hinge)

# 3. Set necessary default parameters
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# Simulation loop
while vis.Run():
    system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary Chrono and Irrlicht modules.
   - Sets the Chrono data path for loading assets.
   - Creates a Chrono system (`system`) to manage physics.
   - Initializes the Irrlicht visualization system (`vis`) and connects it to the Chrono system.

2. **Adding Objects:**
   - Creates a ground body (`ground`) as a fixed box.
   - Creates a beam body (`beam`) with no initial fixed state.
   - Defines beam parameters like the number of elements, length, and radius.
   - Loops to create ANCF cable elements and adds them to the beam.
   - Creates a revolute hinge (`hinge`) to connect the beam to the ground at the origin.

3. **Setting Parameters:**
   - Sets the gravitational acceleration (`system.Set_G_acc`).

4. **Simulation Loop:**
   - Enters a loop that runs until the Irrlicht window is closed.
   - Performs a single time step of dynamics simulation (`system.DoStepDynamics`).
   - Renders the scene using Irrlicht (`vis.Render`).

**Notes:**

- You'll need to have PyChrono and Irrlicht installed.
- Adjust the beam parameters (number of elements, length, radius) as needed.
- This script provides a basic framework. You can extend it by adding more complex geometries, forces, constraints, and visualization features.
