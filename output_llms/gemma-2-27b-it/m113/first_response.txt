```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import pychrono.vehicle as chronovehicle

# 1. Initialize PyChrono environment and core components
my_system = chrono.ChSystemNSC()
my_system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# 2. Add physical systems and objects
# a. Terrain
terrain = chrono.ChBodyEasyBox(
    100, 100, 1, 1000, True, True, chrono.ChMaterialSurfaceNSC.SMC_ADHESION
)
terrain.SetPos(chrono.ChVectorD(0, -1, 0))
terrain.SetBodyFixed(True)
my_system.Add(terrain)

# b. M113 Vehicle
vehicle = chronovehicle.ChVehicle("M113")
vehicle.SetSystem(my_system)
vehicle.Initialize(chrono.ChCoordsysD(chrono.ChVectorD(0, 0, 0)))

# Add M113 specific chassis, wheels, suspension, etc. (Refer to Chrono documentation for details)

# c. Driver System
driver = chronovehicle.ChDriver(vehicle)
driver.SetSteeringMode(chronovehicle.ChDriver.STEERING_TORQUE)
driver.SetThrottleMode(chronovehicle.ChDriver.THROTTLE_TORQUE)
driver.SetBrakeMode(chronovehicle.ChDriver.BRAKE_TORQUE)

# 3. Set default parameters
# Terrain properties
terrain.GetMaterialSurfaceNSC().SetFriction(0.8)
terrain.GetMaterialSurfaceNSC().SetRestitution(0.2)

# Vehicle initial conditions
vehicle.SetChassisPosition(chrono.ChVectorD(0, 1, 0))
vehicle.SetChassisVelocity(chrono.ChVectorD(5, 0, 0))

# 4. Real-time visualization using Irrlicht
vis = chronoirr.ChIrrApp(my_system, "M113 Simulation", chronoirr.dimension2du(800, 600))
vis.AddTypicalLights()
vis.AddSkyBox()
vis.SetCameraPosition(chrono.ChVectorD(10, 5, 0))
vis.SetCameraLookAt(chrono.ChVectorD(0, 1, 0))

# 5. Simulation loop
while vis.GetDevice().run():
    vis.BeginScene()
    vis.Render()
    
    # Update driver inputs (e.g., keyboard, joystick)
    driver.Synchronize(vehicle.GetTime())

    # Advance the simulation
    my_system.DoStepDynamics(vis.GetTimeStep())

    vis.EndScene()



```

**Explanation:**

1. **Initialization:** We create the core Chrono system, set gravity, and define the terrain as a fixed box with specified dimensions and material properties.

2. **Vehicle and Driver:**

   - We instantiate an `M113` vehicle object and initialize it within the Chrono system.
   - You'll need to add the specific components of the M113 (chassis, wheels, suspension, etc.) using Chrono's vehicle module functions. Refer to the Chrono documentation for details on how to create these components.
   - A `ChDriver` object is created to control the vehicle's steering, throttle, and brakes.

3. **Parameters:**

   - We set friction and restitution values for the terrain material.
   - Initial position and velocity are assigned to the vehicle.

4. **Visualization:**

   - `ChIrrApp` is used for real-time visualization with Irrlicht.
   - We set up the camera position and add basic lighting and a skybox.

5. **Simulation Loop:**

   - The loop runs until the Irrlicht window is closed.
   - In each iteration:
     - The scene is rendered.
     - Driver inputs are synchronized with the vehicle's state.
     - The Chrono system advances the simulation for one timestep.

**Important Notes:**

- This is a basic framework. You need to fill in the details for the M113 vehicle construction using Chrono's vehicle module.
- Adjust parameters like timestep, terrain size, vehicle properties, and driver controls according to your simulation requirements.
- Explore Chrono's documentation for more advanced features like collision detection, sensors, and advanced vehicle dynamics.
