```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("data/")
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))

# 2. Add physical systems and objects
# 2.1. Rigid Terrain
terrain = chrono.ChBodyEasyBox(
    200, 200, 1, 1000, True, True, chrono.ChMaterialSurfaceNSC.Default
)
terrain.SetPos(chrono.ChVectorD(0, -1, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)

# 2.2. M113 Vehicle (replace with your M113 model loading)
vehicle = chrono.ChBody()
vehicle.SetPos(chrono.ChVectorD(0, 1, 0))
# Load M113 model here (e.g., using ChBodyAuxRef)
system.Add(vehicle)

# 2.3. Driver System
driver = chrono.ChDriver(vehicle)
# Configure driver settings (steering, acceleration, etc.)

# 3. Set default parameters
terrain.GetMaterialSurfaceNSC().SetFriction(0.8)
terrain.GetMaterialSurfaceNSC().SetRestitution(0.2)

# 4. Initialize Irrlicht visualization
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("M113 Simulation")
vis.Initialize()
camera = vis.GetCamera()
camera.SetPos(chrono.ChVectorD(10, 5, 5))
camera.SetLookAt(chrono.ChVectorD(0, 1, 0))

# 5. Simulation loop
while vis.Run():
    # Get input from driver system
    driver_input = driver.GetInput()

    # Apply driver input to vehicle
    vehicle.SetPos_dt(driver_input.velocity)
    vehicle.SetRot_dt(driver_input.angular_velocity)

    # Advance the simulation
    system.DoStepDynamics(0.01)

    # Update visualization
    vis.BeginScene()
    vis.Render()
    vis.EndScene()



```

   - **Driver System:** Creates a `ChDriver` object to control the vehicle. You'll need to configure the driver's behavior (steering, acceleration, etc.) according to your simulation requirements.

3. **Default Parameters:** Sets friction and restitution values for the terrain material.

4. **Irrlicht Visualization:**
   - Initializes the Irrlicht visualization system (`chronoirr.ChVisualSystemIrrlicht`).
   - Attaches the Chrono system to the visualizer.
   - Sets window size and title.
   - Initializes the Irrlicht engine.
   - Configures the camera's position and look-at target.

5. **Simulation Loop:**
   - Enters the main simulation loop, which continues as long as the Irrlicht window is open.
   - **Driver Input:** Retrieves input from the `driver` system.
