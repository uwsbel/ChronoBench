```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize Chrono engine and visualization system
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
vis.InitVisualization()
vis.SetCamera(chrono.ChVectorD(2, 2, 2), chrono.ChVectorD(0, 0, 0))

# Create ground body
ground = chrono.ChBodyEasySphere(1e6, 1)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.SetBodyFixed(True)
vis.Add(ground)

# Create pendulum body
pendulum_mass = 1
pendulum_radius = 0.1
pendulum = chrono.ChBodyEasyCylinder(pendulum_mass, pendulum_radius, 0.2)
pendulum.SetPos(chrono.ChVectorD(0, 0, 1))
pendulum.SetInertiaXYZ(chrono.ChVectorD(pendulum_mass * pendulum_radius**2, pendulum_mass * pendulum_radius**2, pendulum_mass * pendulum_radius**2 / 2))
vis.Add(pendulum)

# Create revolute joint
joint = chrono.ChLinkLockRevolute(ground, pendulum, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1))
joint.SetPos(chrono.ChVectorD(0, 0, 0))
vis.Add(joint)

# Simulation parameters
chrono.ChSystemNSC.Instance().Set_G_acc(chrono.ChVectorD(0, 0, -9.81))
time_step = 0.01
total_time = 10

# Simulation loop
for t in chrono.ChTime.GetPhysicalTime():
    if t > total_time:
        break

    chrono.ChSystemNSC.Instance().DoStepDynamics(time_step)

    # Log pendulum position and velocity
    print(f"Time: {t:.2f}s, Angle: {pendulum.GetPos().y:.2f}rad, Angular Velocity: {pendulum.GetRotationalSpeed().z:.2f}rad/s")

    vis.Render()
    vis.Sleep(0.01)

# Cleanup
vis.Close()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Initialize Chrono engine and Irrlicht visualization system.
   - Set the camera position for visualization.

2. **Create Physical Systems:**
   - Create a ground body as a sphere with infinite mass to simulate a fixed surface.
   - Create a pendulum body as a cylinder with specified mass and radius.
   - Set the initial position of the pendulum body.

3. **Define Joint:**
   - Create a revolute joint connecting the ground and pendulum bodies.
   - Specify the joint's axis of rotation and position.

4. **Simulation Parameters:**
   - Set the gravitational acceleration.
   - Define the time step for the simulation.
   - Set the total simulation time.

5. **Simulation Loop:**
   - Iterate over time, updating the simulation step by step.
   - Perform dynamics calculations using `DoStepDynamics`.
   - Log the pendulum's position (angle) and velocity (angular velocity).
   - Render the visualization using `Render`.
   - Introduce a small sleep to control the simulation speed.

6. **Cleanup:**
   - Close the Irrlicht visualization window.

**Remember:**

- Replace `"path/to/chrono/data"` with the actual path to your Chrono data directory.
- Adjust the pendulum's mass, radius, and initial position as desired.
