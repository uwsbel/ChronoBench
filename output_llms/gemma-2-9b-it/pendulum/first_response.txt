```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize PyChrono environment
chrono.SetChronoDataPath("./")
system = chrono.ChSystemNSC()

# Create ground body
ground = chrono.ChBodyEasyBox(10, 10, 1, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(ground)

# Create pendulum body
pendulum_mass = 1.0
pendulum_length = 1.0
pendulum_body = chrono.ChBodyEasySphere(pendulum_mass, pendulum_length)
pendulum_body.SetPos(chrono.ChVectorD(0, pendulum_length, 0))
system.Add(pendulum_body)

# Create revolute joint
joint = chrono.ChLinkLockRevolute(ground, pendulum_body, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 1))
system.Add(joint)

# Set initial conditions
pendulum_body.SetBodyFixed(False)
pendulum_body.SetPos(chrono.ChVectorD(0, pendulum_length, 0))
pendulum_body.SetWvel(chrono.ChVectorD(0, 0, 0))

# Create Irrlicht visualization
vis.Init()
vis.Add(system)
vis.SetCamera(chrono.ChVectorD(2, 2, 2), chrono.ChVectorD(0, 0, 0))

# Simulation loop
dt = 0.01
while True:
    system.DoStepDynamics(dt)
    
    # Log pendulum position and velocity
    print(f"Time: {system.GetChTime()}, Pendulum Position: {pendulum_body.Pos().y}, Pendulum Velocity: {pendulum_body.GetWvel().y}")

    vis.Render()

    # Exit condition
    if vis.GetKeyPressed() == vis.KEY_ESCAPE:
        break

vis.Close()
```

**Explanation:**

1. **Initialization:**
   - Imports the necessary libraries `pychrono` and `pychrono.irrlicht`.
   - Initializes the PyChrono environment using `chrono.SetChronoDataPath()` and creates a new system with `chrono.ChSystemNSC()`.

2. **Ground Body:**
   - Creates a rectangular ground body using `chrono.ChBodyEasyBox()` with dimensions 10x10x1 and mass 1000.
   - Sets its position to the origin (0, 0, 0) and adds it to the system.

3. **Pendulum Body:**
   - Creates a spherical pendulum body using `chrono.ChBodyEasySphere()` with specified mass and radius.
   - Sets its initial position to (0, pendulum_length, 0), hanging from the ground.
   - Adds the pendulum body to the system.

4. **Revolute Joint:**
   - Creates a revolute joint using `chrono.ChLinkLockRevolute()` connecting the ground and pendulum bodies.
   - Specifies the anchor point on the ground and the axis of rotation.
   - Adds the joint to the system.

5. **Initial Conditions:**
   - Sets the pendulum body to be movable.
   - Sets its initial position and angular velocity.

6. **Visualization:**
   - Initializes the Irrlicht visualization system using `vis.Init()`.
   - Adds the system to the visualization.
   - Sets the camera position and orientation.

7. **Simulation Loop:**
   - Sets the time step `dt` to 0.01 seconds.
   - Enters a loop that runs until the user presses the escape key.
   - In each iteration:
     - Updates the system dynamics using `system.DoStepDynamics(dt)`.
     - Logs the pendulum's position and velocity.
     - Renders the visualization using `vis.Render()`.

8. **Cleanup:**
   - Closes the Irrlicht visualization window using `vis.Close()`.
