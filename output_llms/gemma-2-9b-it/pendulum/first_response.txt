```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize Chrono
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Create ground body
ground = chrono.ChBodyEasyBox(10, 10, 1, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.AddBody(ground)

# Create pendulum body
pendulum_mass = 1.0
pendulum_length = 1.0
pendulum_inertia = chrono.ChVectorD(0.1, 0.1, 0.1)  # Example inertia
pendulum = chrono.ChBodyEasySphere(pendulum_mass, pendulum_inertia)
pendulum.SetPos(chrono.ChVectorD(0, pendulum_length, 0))
system.AddBody(pendulum)

# Create revolute joint
joint = chrono.ChLinkRevolute(ground, pendulum, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
system.AddLink(joint)

# Visualization setup
vis.Add(system)
vis.SetCamera(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0))
vis.SetTimestep(0.01)

# Simulation loop
while True:
    system.DoStepDynamics(0.01)

    # Log pendulum position and velocity
    pendulum_pos = pendulum.GetPos()
    pendulum_vel = pendulum.GetRotSpeed()
    print(f"Position: {pendulum_pos}, Velocity: {pendulum_vel}")

    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries: `pychrono` for physics simulation and `pychrono.irrlicht` for visualization.
   - Initialize the Chrono system using `chrono.ChSystemNSC()`.
   - Set the path to your Chrono data files (replace `"path/to/chrono/data"` with the actual path).

2. **Ground Body:**
   - Create a rectangular ground body using `chrono.ChBodyEasyBox()`.
   - Set its dimensions (10x10x1) and mass (1000 for a heavy ground).
   - Position it at the origin (0, 0, 0).
   - Add it to the Chrono system using `system.AddBody(ground)`.

3. **Pendulum Body:**
   - Create a spherical pendulum body using `chrono.ChBodyEasySphere()`.
   - Set its mass (`pendulum_mass`), inertia (`pendulum_inertia`), and position (0, `pendulum_length`, 0).
   - Add it to the system.

4. **Revolute Joint:**
   - Create a revolute joint connecting the ground and pendulum using `chrono.ChLinkRevolute()`.
   - Specify the anchor points on both bodies (0, 0, 0 on ground, 0, 0, 0 on pendulum).
   - Set the joint axis (0, 1, 0) for rotation around the y-axis.
   - Add the joint to the system.

5. **Visualization:**
   - Initialize the Irrlicht visualization system using `vis.Add(system)`.
   - Set the camera position and orientation.
   - Set the simulation timestep to 0.01 seconds.

6. **Simulation Loop:**
   - Enter a loop that continuously updates the simulation.
   - Call `system.DoStepDynamics(0.01)` to advance the simulation by one timestep.
   - Log the pendulum's position and velocity using `pendulum.GetPos()` and `pendulum.GetRotSpeed()`.
   - Render the visualization using `vis.Render()`.



**Remember:**

- Replace `"path/to/chrono/data"` with the actual path to your Chrono data files.
- Adjust the pendulum's mass, length, and inertia as desired.
- You can customize the visualization further using Irrlicht's features.
