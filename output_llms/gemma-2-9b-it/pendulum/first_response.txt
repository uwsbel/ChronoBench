```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize Chrono
chrono.SetChronoDataPath("data/")  # Set path to Chrono data files

# Create the simulation world
world = chrono.ChSystemNSC()

# Create the ground body
ground = chrono.ChBodyEasySphere(1.0, 100.0)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
world.AddBody(ground)

# Create the pendulum body
pendulum_mass = 1.0
pendulum_radius = 0.1
pendulum_inertia = chrono.ChVectorD(pendulum_mass * pendulum_radius**2, 0, 0)
pendulum = chrono.ChBodyEasyCylinder(pendulum_mass, pendulum_radius, 0.5)
pendulum.SetPos(chrono.ChVectorD(0, 0.5, 0))
pendulum.SetInertiaXX(pendulum_inertia)
world.AddBody(pendulum)

# Create the revolute joint
joint = chrono.ChLinkRevolute(ground, pendulum,
                            chrono.ChVectorD(0, 0.5, 0),
                            chrono.ChVectorD(0, 0, 1))
world.AddLink(joint)

# Create the visualization system
vis.Initialize(chrono.GetChWorld(), "Simple Pendulum")

# Simulation loop
dt = 0.01
while True:
    world.DoStepDynamics(dt)
    
    # Log pendulum position and velocity
    pendulum_pos = pendulum.GetPos()
    pendulum_vel = pendulum.GetRotVel()
    print(f"Position: {pendulum_pos}, Velocity: {pendulum_vel}")
    
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries `pychrono` and `pychrono.irrlicht`.
   - Sets the path to Chrono data files using `chrono.SetChronoDataPath()`.
   - Creates a Chrono simulation world using `chrono.ChSystemNSC()`.

2. **Ground Body:**
   - Creates a spherical ground body using `chrono.ChBodyEasySphere()`.
   - Sets its position to the origin (0, 0, 0) and adds it to the world.

3. **Pendulum Body:**
   - Defines the pendulum's mass, radius, and inertia.
   - Creates a cylindrical pendulum body using `chrono.ChBodyEasyCylinder()`.
   - Sets its initial position slightly above the ground and adds it to the world.

4. **Revolute Joint:**
   - Creates a revolute joint connecting the ground and pendulum bodies using `chrono.ChLinkRevolute()`.
   - Specifies the joint's anchor point on the ground and the axis of rotation.
   - Adds the joint to the world.

5. **Visualization:**
   - Initializes the Irrlicht visualization system using `vis.Initialize()`.

6. **Simulation Loop:**
   - Sets the time step `dt` for the simulation.
   - Enters a loop that:
     - Advances the simulation by one time step using `world.DoStepDynamics(dt)`.
     - Retrieves the pendulum's position and velocity using `pendulum.GetPos()` and `pendulum.GetRotVel()`.
     - Prints the pendulum's position and velocity.
     - Renders the visualization using `vis.Render()`.
