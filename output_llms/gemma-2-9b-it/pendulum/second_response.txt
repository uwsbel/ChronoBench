```python
import pychrono.core as chrono
import pychrono.irrlicht as chronoirr
import math

# Initialize the Chrono simulation system
sys = chrono.ChSystemNSC()

# Set the gravitational acceleration for the system (in m/s^2)
sys.SetGravitationalAcceleration(chrono.ChVector3d(0, -1.62, 0))  

# Create the ground body and add it to the simulation
ground = chrono.ChBody()
sys.Add(ground)
ground.SetFixed(True)  
ground.EnableCollision(False) 

# Add a visualization cylinder to the ground
cyl_1 = chrono.ChVisualShapeCylinder(0.2, 0.4)  
ground.AddVisualShape(cyl_1, chrono.ChFramed(chrono.ChVector3d(0, 0, +1)))

# Create a pendulum body and add it to the simulation
pend_1 = chrono.ChBody()
sys.AddBody(pend_1)
pend_1.SetFixed(False) 
pend_1.EnableCollision(False) 
pend_1.SetMass(2)  
pend_1.SetInertiaXX(chrono.ChVector3d(0.4, 1.5, 1.5)) 

# Add a visualization cylinder to the pendulum
cyl_1 = chrono.ChVisualShapeCylinder(0.1, 1.5)  
cyl_1.SetColor(chrono.ChColor(0.6, 0, 0)) 
pend_1.AddVisualShape(cyl_1, chrono.ChFramed(chrono.VNULL, chrono.QuatFromAngleY(chrono.CH_PI_2)))

# Set the initial position of the pendulum (center of mass) in the absolute frame
pend_1.SetPos(chrono.ChVector3d(1, 0, 1)) 

# Set initial angular velocity
pend_1.SetRot(chrono.ChQuaterniond(0, 0, 0, 1)) 
pend_1.SetRotSpeed(chrono.ChVector3d(0, 0, 0.5))  # Initial angular velocity around Z-axis

# Create a spherical joint to connect the pendulum to the ground
sph_1 = chrono.ChLinkTSpherical()
sph_1.Initialize(ground, pend_1, chrono.ChFramed(chrono.ChVector3d(0, 0, 1), chrono.ChQuaterniond(1, 0, 0, 0)))
sys.AddLink(sph_1)

# Create the Irrlicht visualization system
vis = chronoirr.ChVisualSystemIrrlicht()
vis.AttachSystem(sys)  
vis.SetWindowSize(1024, 768)  
vis.SetWindowTitle('ChBodyAuxRef demo')  
vis.Initialize()  
vis.AddLogo(chrono.GetChronoDataFile('logo_pychrono_alpha.png'))  
vis.AddSkyBox()  
vis.AddCamera(chrono.ChVector3d(0, 3, 6))  
vis.AddTypicalLights()  

# Simulation loop
log_info = True  
while vis.Run():
    vis.BeginScene()  
    vis.Render()  
    vis.EndScene()
    sys.DoStepDynamics(1e-3)  

    # Log information after 1 second of simulation time
    if log_info and sys.GetChTime() > 1:
        pos_1 = pend_1.GetPos()  
        print("t = ", sys.GetChTime())
        print("     ", pos_1.x, "  ", pos_1.y)
        log_info = False  



```


**Explanation of Changes:**

1. **Gravitational Acceleration:**
   -  `sys.SetGravitationalAcceleration(chrono.ChVector3d(0, -1.62, 0))`  was set to simulate the moon's gravity.

2. **Pendulum Mass and Inertia:**
   - `pend_1.SetMass(2)` set the pendulum's mass to 2 kg.
   - `pend_1.SetInertiaXX(chrono.ChVector3d(0.4, 1.5, 1.5))` set the inertia tensor to the specified values.

3. **Pendulum Length:**
   - The visualization cylinder for the pendulum was changed to `cyl_1 = chrono.ChVisualShapeCylinder(0.1, 1.5)` to adjust the length.

4. **Initial Angular Velocity:**
   - `pend_1.SetRotSpeed(chrono.ChVector3d(0, 0, 0.5))` set the initial angular velocity around the Z-axis to 0.5 radians per second.

5. **Joint Type:**
   - The `rev_1` revolute joint was replaced with `sph_1 = chrono.ChLinkTSpherical()`, creating a spherical joint.

6. **Visualization Joint:**
   -  The visualization of the joint was not explicitly changed in this script. To visualize the joint as a sphere, you would need to add a separate visual shape to the joint and position it appropriately.
