```python
import pychrono as chrono
import pychrono.irrlicht as vis
import numpy as np

# 1. Initialize the PyChrono environment and core components
chrono.SetChronoDataPath("./")  # Set the path to Chrono data files
vis.InitVisualization()

# 2. Add the required physical systems and objects

# 2.1 Create the ARTcar vehicle
vehicle = chrono.ChBodyEasy(100, 100, 100, 1000, chrono.ChVectorD(0, 0, 0), chrono.ChQuaternionD(1, 0, 0, 0))
vehicle.SetPos(chrono.ChVectorD(0, 0, 0.5))
vehicle.SetRot(chrono.ChQuaternionD(1, 0, 0, 0))

# 2.2 Create the RigidTerrain
terrain = chrono.ChBodyEasy(1000, 1000, 10, 10000)
terrain.SetPos(chrono.ChVectorD(0, 0, 0))
terrain.SetRot(chrono.ChQuaternionD(1, 0, 0, 0))
terrain.SetBodyFixed(True)  # Fix the terrain

# 2.3 Add visualization to the vehicle
vehicle_vis = vis.ChVisualSystemIrrlicht(vehicle)
vehicle_vis.SetMaterial(vis.GetMaterial("Rubber"))  # Customize the visualization

# 2.4 Add a custom texture to the terrain
terrain_texture = vis.GetTexture("terrain.png")  # Replace "terrain.png" with your texture file
terrain_vis = vis.ChVisualSystemIrrlicht(terrain)
terrain_vis.SetTexture(terrain_texture)

# 3. Set necessary default parameters

# 3.1 Vehicle contact method
vehicle.SetCollide(True)  # Enable collision detection
vehicle.SetContactMethod(chrono.ChContactMethod.SMC)  # Set the contact method

# 3.2 Interactive driver system
# (This part requires implementation based on your specific control scheme)

# 4. Simulation loop
application = vis.ChIrrApp(chrono.GetSystem())
application.SetCamera(vehicle_vis.GetCamera())
application.SetTargetFPS(50)

while application.Run():
    application.BeginScene()
    application.DrawAll()
    application.EndScene()

    # Update vehicle dynamics and visualization
    chrono.ChSystem.DoStepDynamics(1/50)  # Update at 50Hz

vis.CloseVisualization()
```

**Explanation:**

1. **Initialization:** The script imports necessary libraries and initializes PyChrono and Irrlicht for visualization.
2. **Object Creation:**
   - **ARTcar:** A `ChBodyEasy` object represents the vehicle. Its mass, inertia, position, and orientation are set.
   - **RigidTerrain:** A `ChBodyEasy` object represents the terrain, fixed in place.
3. **Visualization:**
   - **Vehicle:** A `ChVisualSystemIrrlicht` object visualizes the vehicle, using a rubber material.
   - **Terrain:** A `ChVisualSystemIrrlicht` object visualizes the terrain, with a custom texture loaded.
4. **Parameters:**
   - **Vehicle Contact:** Collision detection is enabled for the vehicle, and the contact method is set to SMC (Sequential Moreau Contact).
   - **Driver System:** This part is left for you to implement based on your desired control scheme.
5. **Simulation Loop:**
   - **Irrlicht Application:** An `ChIrrApp` object manages the Irrlicht visualization and simulation.
   - **Camera:** The camera is set to follow the vehicle.
   - **Target FPS:** The simulation runs at 50 frames per second.
   - **Update Loop:**
     - The `BeginScene`, `DrawAll`, and `EndScene` methods handle rendering.
     - `chrono.ChSystem.DoStepDynamics(1/50)` updates the vehicle dynamics at 50Hz.

**Remember:**

- Replace `"terrain.png"` with the actual path to your terrain texture file.
- Implement the interactive driver system according to your requirements.
- Adjust parameters like vehicle mass, inertia, and terrain dimensions as needed.
