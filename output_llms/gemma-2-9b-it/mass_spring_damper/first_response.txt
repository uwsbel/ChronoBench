```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize Chrono
chrono.ChSystemNSC.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))  # Set gravity

# Create the system
system = chrono.ChSystemNSC()

# Create the ground
ground = chrono.ChBodyEasyBox(10, 10, 1, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.AddBody(ground)

# Create the mass
mass = chrono.ChBodyEasySphere(1, 10)
mass.SetPos(chrono.ChVectorD(0, 1, 0))
system.AddBody(mass)

# Create the spring-damper connection
link = chrono.ChLinkTSDA(mass, ground, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 0, 0))
system.AddLink(link)

# Set visualization
vis.ChVisualizationSystem.SetSystem(system)
vis.ChVisualizationSystem.SetCamera(chrono.ChVectorD(0, 2, 3), chrono.ChVectorD(0, 0, 0))
vis.ChVisualizationSystem.SetAmbientLight(chrono.ChColor(0.3, 0.3, 0.3))
vis.ChVisualizationSystem.SetDirectionalLight(chrono.ChVectorD(1, 1, -1), chrono.ChColor(1, 1, 1))

# Add visual shapes
mass_shape = chrono.ChShapeSphere(1)
mass.AddShape(mass_shape)

spring_shape = chrono.ChShapeCylinder(0.05, 1)
link.AddShape(spring_shape)

# Run the simulation
vis.Start()
while vis.GetTimer() < 10:
    system.DoStepDynamics(0.01)
    vis.Render()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries (`pychrono` and `pychrono.irrlicht`).
   - Set gravity using `ChSystemNSC.Set_G_acc`.
   - Create a `ChSystemNSC` object to represent the simulation environment.

2. **Physical Systems:**
   - Create a ground body using `ChBodyEasyBox` and set its position.
   - Create a mass body using `ChBodyEasySphere` and set its initial position.
   - Create a `ChLinkTSDA` object to connect the mass to the ground, using default spring-damper parameters.

3. **Visualization:**
   - Set up Irrlicht visualization using `ChVisualizationSystem`.
   - Define camera position and orientation.
   - Set ambient and directional lighting.

4. **Visual Shapes:**
   - Add a sphere shape to the mass body.
   - Add a cylinder shape to the spring-damper link.

5. **Simulation Loop:**
   - Use `vis.Start()` to initiate the visualization.
   - Loop until a specified time (`10` seconds in this case).
   - In each iteration:
     - Update the simulation dynamics using `system.DoStepDynamics(0.01)`.
     - Render the scene using `vis.Render()`.
