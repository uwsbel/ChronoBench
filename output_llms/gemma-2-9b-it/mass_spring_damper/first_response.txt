```python
import pychrono as chrono

# Initialize Chrono environment
system = chrono.ChSystemNSC()

# Create a ground body
ground = chrono.ChBodyEasyBox(10, 10, 1, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.AddBody(ground)

# Create a mass
mass = chrono.ChBodyEasySphere(1, 10)
mass.SetPos(chrono.ChVectorD(0, 1, 0))

# Create a spring-damper link
link = chrono.ChLinkTSDA()
link.Initialize(mass, ground, chrono.ChVectorD(0, 0, 0))
link.SetSpringStiffness(1000)  # Default spring stiffness
link.SetDampingRatio(0.7)  # Default damping ratio

# Add the mass and link to the system
system.AddBody(mass)
system.AddLink(link)

# Set up visualization
vis = chrono.ChVisualSystemIrrlicht(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Mass-Spring-Damper System")
vis.SetCamera(chrono.ChCamera(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0)))
vis.AddLight(chrono.ChLight(chrono.ChVectorD(1, 1, 1), chrono.ChColor(1, 1, 1)))
vis.AddLight(chrono.ChLight(chrono.ChVectorD(-1, -1, -1), chrono.ChColor(1, 1, 1)))

# Set up simulation
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))
system.Step(0.01)

# Run the simulation
while vis.Run():
    system.DoStepDynamics(0.01)
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - We import the `chrono` library.
   - A `ChSystemNSC` object is created to represent the simulation environment.

2. **Physical Systems:**
   - A ground body (`ChBodyEasyBox`) is created and positioned at the origin.
   - A mass (`ChBodyEasySphere`) is created and positioned 1 unit above the ground.

3. **Spring-Damper Link:**
   - A `ChLinkTSDA` object is created to represent the spring-damper connection between the mass and the ground.
   - `Initialize` method sets up the link with the specified bodies and position.
   - `SetSpringStiffness` and `SetDampingRatio` are used to set the default spring and damping parameters.

4. **Adding to System:**
   - The mass and link are added to the `ChSystem` using `AddBody` and `AddLink` methods.

5. **Visualization:**
   - A `ChVisualSystemIrrlicht` object is created to handle visualization using Irrlicht.
   - The window size, title, camera position, and lighting are set.

6. **Simulation Setup:**
   - `Set_G_acc` sets the gravitational acceleration.
   - `Step` advances the simulation by a small time step.

7. **Simulation Loop:**
   - The `while vis.Run()` loop keeps the simulation running until the user closes the window.
   - Inside the loop:
     - `DoStepDynamics` updates the simulation for one time step.
     - `Render` renders the scene.



This script creates a basic mass-spring-damper system with visualization. You can modify the parameters, add more objects, and explore different interactions within the PyChrono environment.
