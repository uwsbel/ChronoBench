```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize Chrono engine
chrono.ChSystemNSC.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))  # Set gravity
system = chrono.ChSystemNSC()

# Create ground
ground = chrono.ChBodyEasyBox(10, 10, 5, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(ground)

# Create mass
mass = chrono.ChBodyEasySphere(1, 10)
mass.SetPos(chrono.ChVectorD(0, 0, 5))
system.Add(mass)

# Create spring-damper connection
link = chrono.ChLinkTSDA(mass, ground)
link.SetSpringParams(stiffness=1000, damping=100)  # Default spring-damper parameters
system.Add(link)

# Visualization setup
vis_app = vis.ChVisualSystemIrrlicht(
    "Mass-Spring-Damper",
    chrono.ChVectorD(800, 600, 0),
    vis.VSYNC_DISABLED,
    vis.CAMERA_FIRSTPERSON,
)
vis_app.Add(ground)
vis_app.Add(mass)

# Set camera position and target
vis_app.GetActiveCamera().SetTarget(chrono.ChVectorD(0, 0, 0))
vis_app.GetActiveCamera().SetPos(chrono.ChVectorD(0, 0, 10))

# Set lighting
vis_app.SetAmbientLight(chrono.ChColor(0.1, 0.1, 0.1))
vis_app.SetDirectionalLight(chrono.ChColor(0.8, 0.8, 0.8), chrono.ChVectorD(0, -1, 0))

# Run simulation
while vis_app.Run():
    system.DoStepDynamics(chrono.ChTime(0.01))
    vis_app.Render()



```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries.
   - Sets the gravitational acceleration.
   - Creates a `ChSystemNSC` object to manage the simulation.

2. **Physical Systems:**
   - Creates a ground plane using `ChBodyEasyBox`.
   - Creates a sphere mass using `ChBodyEasySphere`.
   - Defines a `ChLinkTSDA` object to connect the mass to the ground, acting as a spring-damper system.
   - Sets default spring stiffness and damping parameters.

3. **Visualization:**
   - Initializes an Irrlicht visualization system (`ChVisualSystemIrrlicht`).
   - Adds the ground and mass to the visualization scene.
   - Sets the camera position and target for a clear view of the system.
   - Configures ambient and directional lighting.

4. **Simulation Loop:**
   - Enters a loop that runs until the user closes the visualization window.
   - Calls `DoStepDynamics` to update the system's physics for each time step (0.01 seconds).
   - Renders the visualization using `Render`.

**Key Points:**

- `ChLinkTSDA` provides the spring-damper behavior, connecting the mass to the ground.
- Default spring and damping parameters are used for simplicity. You can adjust these for different system behaviors.
- Irrlicht visualization offers a real-time view of the simulation with lighting and camera controls.
