```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Create the Chrono system
system = chrono.ChSystemNSC()

# Set up visualization
vis.ChVisualSystemIrrlicht.SetWindowSize(800, 600)
vis.ChVisualSystemIrrlicht.SetWindowTitle("Mass-Spring-Damper")
vis.ChVisualSystemIrrlicht.Initialize()
vis.ChVisualSystemIrrlicht.AddCamera(
    pos=chrono.ChVectorD(0, 0, 1),
    lookat=chrono.ChVectorD(0, 0, 0),
    up=chrono.ChVectorD(0, 1, 0),
)
vis.ChVisualSystemIrrlicht.SetAmbientLight(chrono.ChColor(0.1, 0.1, 0.1))
vis.ChVisualSystemIrrlicht.SetLight(
    chrono.ChVectorD(1, 1, 1), chrono.ChVectorD(0, 0, 0), chrono.ChColor(1, 1, 1)
)

# Create the ground
ground = chrono.ChBodyEasyBox(10, 10, 1, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.AddBody(ground)

# Create the mass
mass = chrono.ChBodyEasySphere(1, 10)
mass.SetPos(chrono.ChVectorD(0, 0, 1))
system.AddBody(mass)

# Create the spring and damper
link = chrono.ChLinkTSDA(mass, ground)
link.SetSpringParam(100, 10)  # Default spring stiffness and damping
system.AddLink(link)

# Create visual shapes
mass_shape = chrono.ChShapeSphere(1)
ground_shape = chrono.ChShapeBox(5, 5, 0.5)
link_shape = chrono.ChShapeCylinder(0.1, 1)

mass.GetAssets().push_back(chrono.ChVisualShapeData(mass_shape))
ground.GetAssets().push_back(chrono.ChVisualShapeData(ground_shape))
link.GetAssets().push_back(chrono.ChVisualShapeData(link_shape))

# Run the simulation
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))
for i in range(1000):
    system.DoStepDynamics(0.01)
    vis.ChVisualSystemIrrlicht.Render()

vis.ChVisualSystemIrrlicht.Close()
```

**Explanation:**

1. **Initialization:**
   - Imports `pychrono` and `pychrono.irrlicht`.
   - Creates a `ChSystemNSC` object for the simulation.
   - Initializes the Irrlicht visualization system with window size, title, camera position, ambient light, and a directional light.

2. **Physical Systems:**
   - Creates a ground body using `ChBodyEasyBox` with dimensions 10x10x1 and a large mass (1000).
   - Creates a mass body using `ChBodyEasySphere` with radius 1 and mass 10.
   - Creates a `ChLinkTSDA` object to connect the mass to the ground, defining it as a spring-damper system with default parameters.

3. **Visual Representation:**
   - Adds visual shapes to the bodies:
     - A sphere for the mass.
     - A box for the ground.
     - A cylinder for the spring.

4. **Simulation:**
   - Sets the gravitational acceleration to -9.81 m/s² using `system.Set_G_acc`.
   - Runs a loop for 1000 steps, updating the simulation with `system.DoStepDynamics(0.01)`.
   - Renders the visualization in each step using `vis.ChVisualSystemIrrlicht.Render()`.

5. **Cleanup:**
   - Closes the Irrlicht visualization window using `vis.ChVisualSystemIrrlicht.Close()`.
