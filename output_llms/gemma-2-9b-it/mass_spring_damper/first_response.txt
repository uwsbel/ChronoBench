```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize Chrono engine
chrono.SetChronoDataPath("..")  # Set path to Chrono data files
system = chrono.ChSystemNSC()

# Create ground
ground = chrono.ChBodyEasyBox(10, 10, 1, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(ground)

# Create mass
mass = chrono.ChBodyEasySphere(0.5, 100)
mass.SetPos(chrono.ChVectorD(0, 1, 0))
system.Add(mass)

# Create spring-damper connection
spring_damper = chrono.ChLinkTSDA()
spring_damper.Initialize(ground, mass, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
system.Add(spring_damper)

# Visualize with Irrlicht
vis = chronoirr.ChIrrApp(system, 'Mass-Spring-Damper')
vis.AddCamera(chrono.ChVectorD(5, 5, 5))
vis.AddLight(chrono.ChVectorD(10, 10, 10))

# Set up Irrlicht visualization
vis.SetWindowSize(1024, 768)
vis.SetRenderMode(chronoirr.CH_RENDERING_MODE_WIREFRAME)

# Run simulation
vis.Start()
while vis.GetDevice().run():
    system.DoStepDynamics(1e-3)
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules (`pychrono` and `pychrono.irrlicht`).
   - Initializes the Chrono engine using `chrono.ChSystemNSC()`.
   - Sets the path to Chrono data files using `chrono.SetChronoDataPath()`.

2. **Physical Systems:**
   - Creates a ground plane using `chrono.ChBodyEasyBox()`.
   - Creates a sphere mass using `chrono.ChBodyEasySphere()`.
   - Defines a `ChLinkTSDA` connection between the mass and the ground to simulate the spring-damper behavior.

3. **Visualization:**
   - Initializes Irrlicht visualization using `chronoirr.ChIrrApp()`.
   - Adds a camera to view the scene.
   - Adds a light source for illumination.
   - Sets the window size and rendering mode.

4. **Simulation Loop:**
   - Enters a loop that runs until the Irrlicht window is closed.
   - Performs a simulation step using `system.DoStepDynamics()`.
   - Renders the scene using `vis.Render()`.



**Key Points:**

- `ChLinkTSDA` is used to create the spring-damper connection, providing default parameters for linear spring and damper behavior.
- Irrlicht visualization is used to display the simulation, including lighting and camera settings.
- The simulation loop continuously updates the system dynamics and renders the scene.
