```python
from pychrono import ChSystem, ChBody, ChLinkLock, ChMaterialSurface, ChCoordsys, ChFunction
from pychrono.irrlicht import ChIrrApp

# Initialize Chrono environment
system = ChSystem()
app = ChIrrApp(system, 'Beam Simulation', 'data/media')

# Create beam material
beam_material = ChMaterialSurface(0.5, 0.5, 0.5)

# Define beam geometry and properties
beam_length = 1.0
beam_width = 0.1
beam_height = 0.1

# Create beam nodes
node1 = ChCoordsys(ChVectorD(0, 0, 0))
node2 = ChCoordsys(ChVectorD(beam_length, 0, 0))

# Create ANCF cable elements
cable_element = ChFunction.CreateANCF(beam_material, node1, node2)
cable_element.SetRestLength(beam_length)

# Create beam body
beam_body = ChBody(beam_material)
beam_body.SetPos(node1.pos)
beam_body.SetRot(node1.rot)
beam_body.SetMass(1.0)  # Adjust mass as needed

# Create hinge constraint
hinge_constraint = ChLinkLock(beam_body, system.GetGround(), ChCoordsys(ChVectorD(0, 0, 0)))
hinge_constraint.SetLockType(ChLinkLock.LOCK_XYZ)

# Add beam to the system
system.Add(beam_body)
system.Add(cable_element)
system.Add(hinge_constraint)

# Simulation loop
while app.GetTimer() < 10:
    app.DrawAll()
    system.DoStepDynamics(0.01)

# Terminate application
app.Close()
```

**Explanation:**

1. **Initialization:** The script imports necessary modules from PyChrono and initializes a Chrono system and an Irrlicht application for rendering.

2. **Beam Material:** A material object is created to define the properties of the beam.

3. **Geometry and Properties:** The beam's length, width, and height are defined.

4. **Nodes:** Two ChCoordsys objects represent the beam's nodes, defining their positions.

5. **ANCF Cable Element:** An ANCF cable element is created using `ChFunction.CreateANCF` and connected to the nodes. The rest length is set to the beam's length.

6. **Beam Body:** A ChBody object represents the beam itself, with its position, rotation, and mass set.

7. **Hinge Constraint:** A hinge constraint is added to fix one end of the beam to the ground.

8. **Simulation Loop:** The main loop iterates, drawing the scene using Irrlicht and advancing the simulation using `system.DoStepDynamics`.

9. **Termination:** The application is closed after the simulation time reaches 10 seconds.



**Note:** You may need to adjust parameters like mass, material properties, and rest length to achieve the desired beam behavior. Also, ensure you have the necessary PyChrono and Irrlicht libraries installed.
