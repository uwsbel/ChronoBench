```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht

# Initialize Chrono
chrono.SetChronoDataPath("..")  # Set path to Chrono data if needed
system = chrono.ChSystemNSC()

# Create ground
ground = chrono.ChBodyEasyBox(10, 10, 1, 1000)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(ground)

# Create beam using ANCF cable elements
beam_nodes = [
    chrono.ChBodyEasySphere(0.1, 100),
    chrono.ChBodyEasySphere(0.1, 100),
    chrono.ChBodyEasySphere(0.1, 100),
]

# Define ANCF cable properties
cable_material = chrono.ChMaterialSurfaceNSC()
cable_material.SetFriction(0.2, 0.2)
cable_material.SetDampingFric(0.1)
cable_material.SetYoungModulus(1e6)  # Adjust for desired stiffness

# Connect nodes with ANCF cables
for i in range(len(beam_nodes) - 1):
    cable = chrono.ChLinkCable(beam_nodes[i], beam_nodes[i + 1])
    cable.SetMaterial(cable_material)
    cable.SetRestLength(1)  # Adjust for desired beam length
    system.Add(cable)

# Set initial positions
beam_nodes[0].SetPos(chrono.ChVectorD(0, 0, 0))
beam_nodes[1].SetPos(chrono.ChVectorD(1, 0, 0))
beam_nodes[2].SetPos(chrono.ChVectorD(2, 0, 0))

# Apply gravity
system.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))

# Create Irrlicht visualization
vis = irrlicht.ChIrrApp(system, 'Beam Simulation')
vis.AddCamera(
    chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0)
)

# Simulation loop
vis.SetTimestep(1e-3)
while vis.Run():
    vis.BeginScene()
    vis.DrawAll()
    vis.EndScene()

    system.DoStepDynamics(vis.GetTimestep())

# Cleanup
vis.Close()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries: `pychrono` for physics and `pychrono.irrlicht` for visualization.
   - Initialize the Chrono system using `chrono.ChSystemNSC()`.
   - Set the Chrono data path if needed.

2. **Ground Creation:**
   - Create a ground body using `chrono.ChBodyEasyBox()` with dimensions 10x10x1 and a mass of 1000.
   - Set its position to the origin (0, 0, 0).
   - Add the ground body to the system.

3. **Beam Creation:**
   - Create a list of `beam_nodes` using `chrono.ChBodyEasySphere()` to represent the beam's nodes.
   - Define `cable_material` properties for the ANCF cables.
   - Connect the nodes using `chrono.ChLinkCable()` and set the material, rest length, and add it to the system.

4. **Initial Positions:**
   - Set the initial positions of the beam nodes.

5. **Gravity Application:**
   - Apply gravity to the system using `system.Set_G_acc()`.

6. **Visualization Setup:**
   - Create an Irrlicht visualization using `chrono.ChIrrApp()`.
   - Add a camera to view the simulation.

7. **Simulation Loop:**
   - Run the simulation loop using `vis.Run()`.
   - In each iteration:
     - Begin and end the scene rendering.
     - Draw all objects using `vis.DrawAll()`.
     - Update the physics simulation using `system.DoStepDynamics()`.

8. **Cleanup:**
   - Close the Irrlicht visualization.
