```python
import pychrono as chrono
import chrono.irrlicht as irrlicht

# 1. Initialize PyChrono environment and core components
chrono.ChSystemNSC.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))  # Set gravity
system = chrono.ChSystemNSC()

# 2. Add physical systems and objects
# - HMMWV vehicle
hmmwv = chrono.ChBodyEasy.Create(system, chrono.ChBodyType.Dynamic, 
                                  mass=5000,  # Adjust mass as needed
                                  shape=chrono.ChBoxShape(1.5, 2.5, 3.0))
hmmwv.SetPos(chrono.ChVectorD(0, 0, 0.5))  # Initial position
hmmwv.SetBodyFixed(False)  # Allow movement

# - SCM deformable terrain
terrain = chrono.ChBodyEasy.Create(system, chrono.ChBodyType.Static,
                                   shape=chrono.ChBoxShape(10, 10, 1))
terrain.SetPos(chrono.ChVectorD(0, 0, 0))
terrain.SetBodyFixed(True)  # Terrain is fixed

# Load height map for terrain
terrain_heightmap = chrono.ChFileLoader.LoadTerrainHeightmap("path/to/heightmap.txt")
terrain.SetTerrainHeightmap(terrain_heightmap)

# Set soil parameters for terrain
terrain.SetTerrainParameters(
    density=1500,  # Adjust density as needed
    cohesion=1000,
    friction=0.5,
    restitution=0.1
)

# - Driver system (placeholder)
driver = chrono.ChDriver(system)  # Initialize driver

# 3. Set default parameters and interactions
# - Define forces and interactions between objects
# ...

# 4. Real-time visualization using Irrlicht
vis = irrlicht.ChIrrApp(system, "HMMWV Simulation")
vis.AddCamera(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0))  # Camera position and target
vis.SetCamera(0)  # Set active camera
vis.SetAmbientLight(chrono.ChColor(0.1, 0.1, 0.1))  # Ambient light
vis.SetSunLight(chrono.ChColor(1, 1, 1), chrono.ChVectorD(1, 1, -1))  # Sunlight

# 5. Simulation loop
while not vis.GetQuitKey():
    system.DoStepDynamics(1.0/240.0)  # Timestep for real-time simulation
    vis.Render()
    driver.Update()  # Update driver system

vis.GetDevice().drop()
```

**Explanation:**

1. **Initialization:**
   - Sets gravity and creates a new Chrono system.
2. **Physical Systems:**
   - Creates a dynamic HMMWV body with initial position and mass.
   - Creates a static terrain body with a heightmap and soil parameters.
3. **Driver System:**
   - Initializes a placeholder driver system for vehicle control. You'll need to implement specific control logic based on your requirements.
4. **Visualization:**
   - Initializes Irrlicht for real-time visualization.
   - Sets up a camera, ambient light, and sunlight.
5. **Simulation Loop:**
   - Uses a `while` loop to continuously advance the simulation.
   - `system.DoStepDynamics()` updates the physics at a fixed timestep for real-time execution.
   - `vis.Render()` renders the scene.
   - `driver.Update()` updates the driver system, which will control the vehicle's movements.

**Important Notes:**

- **Replace placeholders:**
   - Replace `"path/to/heightmap.txt"` with the actual path to your heightmap file.
   - Implement the `driver` system with your desired vehicle control logic.
- **Adjust parameters:**
   - Modify mass, soil parameters, and other values to match your simulation requirements.
- **Irrlicht setup:**
   - Refer to the Irrlicht documentation for more detailed camera, lighting, and rendering options.
