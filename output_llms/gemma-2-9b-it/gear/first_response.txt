```python
import pychrono as chrono

# Initialize the PyChrono environment
chrono.SetChronoDataPath("..")  # Set the path to your Chrono data files
system = chrono.ChSystemNSC()

# Create a fixed truss
truss = chrono.ChBodyEasyBox(1.0, 0.5, 0.2, 1.0)
truss.SetPos(chrono.ChVectorD(0, 0, 0))
truss.SetBodyFixed(True)
system.Add(truss)

# Create a rotating bar
bar = chrono.ChBodyEasyCylinder(0.1, 0.5, 1.0)
bar.SetPos(chrono.ChVectorD(0, 0, 0.3))
bar.SetBodyFixed(False)
system.Add(bar)

# Create the gears
gear1 = chrono.ChBodyEasyCylinder(0.1, 0.1, 0.1)
gear1.SetPos(chrono.ChVectorD(0.2, 0, 0.5))
gear1.SetBodyFixed(False)
system.Add(gear1)

gear2 = chrono.ChBodyEasyCylinder(0.1, 0.1, 0.1)
gear2.SetPos(chrono.ChVectorD(0.4, 0, 0.5))
gear2.SetBodyFixed(False)
system.Add(gear2)

# Add gear mesh
gear1.AddAsset(chrono.ChMeshLoader.Load("gear.obj"))
gear2.AddAsset(chrono.ChMeshLoader.Load("gear.obj"))

# Create a gear motor
motor = chrono.ChMotorRotation(gear1.GetFrame(), gear1.GetPos(), chrono.ChVectorD(0, 0, 1), 10)
motor.SetMotorType(chrono.ChMotorRotation.Type_ConstantSpeed)
motor.SetSpeed(2 * chrono.CH_C_PI)
system.Add(motor)

# Connect the gears
gear1.AddContact(gear2)

# Set up visualization
vis = chrono.ChVisualSystemIrrlicht(system)
vis.SetWindowSize(800, 600)
vis.SetWindowTitle("Epicyclic Gears")
vis.EnableCamera(True)
vis.SetCamera(chrono.ChVectorD(0, 0, 1.5), chrono.ChVectorD(0, 0, 0))
vis.SetMaterialFlags(chrono.VIS_MATERIAL_COLORS)
vis.AddLight(chrono.ChLightPoint(chrono.ChVectorD(0, 0, 1.5), chrono.ChColor(1, 1, 1)))

# Run the simulation
while vis.Run():
    system.DoStepDynamics(chrono.ChTime(0.01))
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - `chrono.SetChronoDataPath(...)`: Sets the path to Chrono's data files containing meshes and other assets.
   - `system = chrono.ChSystemNSC()`: Creates a new Chrono simulation system.

2. **Physical Systems:**
   - **Truss:** A fixed box representing the base structure.
   - **Rotating Bar:** A cylinder attached to the truss, free to rotate.
   - **Gears:** Two cylinders representing the epicyclic gears.
   - **Gear Motor:** A motor attached to one gear to enforce constant rotation.

3. **Geometry and Materials:**
   - `AddAsset(...)`: Loads a 3D mesh file ("gear.obj") to represent the gear shape.
   - `SetMaterialFlags(...)`: Sets visualization properties for materials.

4. **Connections and Forces:**
   - `AddContact(...)`: Creates a contact constraint between the two gears, allowing them to mesh.
   - `SetMotorType(...)`: Configures the motor as a constant-speed motor.
   - `SetSpeed(...)`: Sets the desired rotation speed of the motor.

5. **Visualization:**
   - `vis = chrono.ChVisualSystemIrrlicht(...)`: Creates an Irrlicht visualization system to display the simulation.
   - `SetWindowSize(...)`, `SetWindowTitle(...)`, `EnableCamera(...)`: Configures the window size, title, and camera view.
   - `SetMaterialFlags(...)`: Sets material visualization properties.
   - `AddLight(...)`: Adds a point light source to illuminate the scene.

6. **Simulation Loop:**
   - `vis.Run()`: Starts the main simulation loop.
   - `system.DoStepDynamics(...)`: Updates the physics simulation for each time step.
   - `vis.Render()`: Renders the visualization frame.



**To use this script:**

- Make sure you have PyChrono and Irrlicht installed.
- Replace `"gear.obj"` with the path to your actual gear mesh file.
- Adjust the parameters (gear sizes, motor speed, etc.) as needed.
- Run the script, and you should see a 3D visualization of the epicyclic gears in action.
