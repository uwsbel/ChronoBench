```python
import pychrono as chrono
import chrono.irrlicht as irrlicht

# Initialize PyChrono environment
app = chrono.ChSystemNSC()
app.Set_G_acc(chrono.ChVectorD(0,0,-9.81)) # Set gravity

# Create Irrlicht visualization
vis = irrlicht.ChIrrApp(app, 'CityBus Simulation', 800, 600)
vis.AddTypicalSky()
vis.AddTypicalClouds()
vis.SetCamera(chrono.ChVectorD(10, 10, 10), chrono.ChVectorD(0, 0, 0)) # Initial camera position

# Create RigidTerrain with custom texture
terrain = chrono.ChBodyEasyBox(100, 100, 1, 1000) # Size and mass
terrain.SetPos(chrono.ChVectorD(0, 0, 0))
terrain.SetMaterialSurface(chrono.ChMaterialSurface(chrono.ChColor(0.5, 0.5, 0.5), 0.5)) # Set custom texture
app.Add(terrain)

# Create CityBus vehicle
bus = chrono.ChBodyEasyBox(5, 2, 1.5, 1000) # Size and mass
bus.SetPos(chrono.ChVectorD(0, 0, 1)) # Initial position
bus.SetRot(chrono.Q_from_Euler(chrono.CH_C_RAD, 0, 0)) # Initial orientation
app.Add(bus)

# Add wheels to the bus
wheel_radius = 0.3
for i in range(4):
    wheel = chrono.ChWheelEasy(wheel_radius, 100) # Size and mass
    wheel.SetPos(bus.GetPos() + chrono.ChVectorD(0, 0, 0.1)) # Position relative to bus
    wheel.SetRot(bus.GetRot()) # Orientation relative to bus
    bus.AddWheel(wheel)

# Define driver system (placeholder)
class Driver:
    def __init__(self):
        self.steering = 0
        self.throttle = 0
        self.brake = 0

    def update(self):
        # Implement logic for steering, throttle, and brake control
        pass

driver = Driver()

# Simulation loop
vis.SetTargetFPS(50)
while vis.Run():
    app.DoStepDynamics(1/50.0)
    vis.Render()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries (`pychrono` and `chrono.irrlicht`).
   - Creates a `ChSystemNSC` object to manage the simulation.
   - Sets gravity to -9.81 m/s².
   - Initializes an `irrlicht.ChIrrApp` object for visualization, setting the window title, size, and adding a sky and clouds.
   - Sets the initial camera position.

2. **RigidTerrain:**
   - Creates a `ChBodyEasyBox` object representing the terrain with specified dimensions and mass.
   - Sets the terrain's position and material surface with a custom color and roughness.
   - Adds the terrain to the simulation.

3. **CityBus:**
   - Creates a `ChBodyEasyBox` object for the bus body with dimensions and mass.
   - Sets the bus's initial position and orientation.
   - Adds the bus to the simulation.

4. **Wheels:**
   - Creates four `ChWheelEasy` objects representing the bus's wheels.
   - Sets the wheel's radius and mass.
   - Positions the wheels relative to the bus body and sets their initial orientation.
   - Adds the wheels to the bus.

5. **Driver System:**
   - Defines a `Driver` class with placeholder methods for steering, throttle, and brake control.
   - Creates an instance of the `Driver` class.

6. **Simulation Loop:**
   - Sets the target frame rate to 50 FPS using `vis.SetTargetFPS()`.
   - Enters a loop that runs until the user closes the window:
     - Updates the simulation dynamics using `app.DoStepDynamics()`.
     - Renders the scene using `vis.Render()`.
     - Calls the `update()` method of the `Driver` class to handle control inputs.
