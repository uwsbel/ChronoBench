```python
import pychrono as chrono
import pychrono_ros  # Import the ROS integration library

# Initialize Chrono and ROS
chrono.ChSystemNSC.Set_G_acc(chrono.ChVectorD(0, 0, -9.81))  # Set gravitational acceleration

# Create ROS manager
ros_manager = pychrono_ros.RosManager()

# Define custom ROS handler
class CustomRosHandler(pychrono_ros.RosHandler):
    def __init__(self, topic_name):
        super().__init__()
        self.topic_name = topic_name

    def update(self, system, step_size):
        # Access system data (e.g., box position)
        box_position = system.GetBody("box").GetPos()
        
        # Publish integer message to ROS topic
        msg = {"position_x": int(box_position.x), "position_y": int(box_position.y)}
        self.publisher.publish(self.topic_name, msg)

# Create Chrono system
system = chrono.ChSystemNSC()

# Add floor
floor = chrono.ChBodyEasyBox(10, 10, 0.1)
floor.SetPos(chrono.ChVectorD(0, 0, -0.05))  # Position floor slightly below origin
floor.SetBodyFixed(True)
system.Add(floor)

# Add movable box
box = chrono.ChBodyEasyBox(1, 1, 1)
box.SetPos(chrono.ChVectorD(0, 0, 0.5))  # Initial position of the box
system.Add(box)

# Configure ROS manager
ros_manager.SetClockHandler(pychrono_ros.RosClockHandler())
ros_manager.SetBodyHandler(pychrono_ros.RosBodyHandler())
ros_manager.SetTransformHandler(pychrono_ros.RosTransformHandler())

# Register custom ROS handler
ros_manager.RegisterHandler(CustomRosHandler("box_position"))

# Run simulation loop
while True:
    system.DoStepDynamics(0.01)  # Advance system by 0.01 seconds
    ros_manager.Update()  # Update ROS communication
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries: `pychrono` and `pychrono_ros`.
   - Set gravitational acceleration using `chrono.ChSystemNSC.Set_G_acc()`.
   - Create a `pychrono_ros.RosManager` instance to handle ROS communication.

2. **Custom ROS Handler:**
   - Define a class `CustomRosHandler` that inherits from `pychrono_ros.RosHandler`.
   - In the `update()` method:
     - Access Chrono system data (e.g., box position using `system.GetBody("box").GetPos()`).
     - Create a ROS message containing the desired data (e.g., box position).
     - Publish the message to the specified ROS topic using `self.publisher.publish()`.

3. **Chrono System Setup:**
   - Create a `chrono.ChSystemNSC` instance.
   - Add a fixed floor using `chrono.ChBodyEasyBox()` and set its position.
   - Add a movable box using `chrono.ChBodyEasyBox()` and set its initial position.

4. **ROS Manager Configuration:**
   - Configure the ROS manager with handlers for clock, body, and transform updates.
   - Register the custom `CustomRosHandler` with the ROS manager.

5. **Simulation Loop:**
   - Enter a loop that continuously advances the Chrono system using `system.DoStepDynamics(0.01)`.
   - Update ROS communication within the loop using `ros_manager.Update()`.
