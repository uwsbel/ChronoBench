```python
import pychrono as chrono
import pychrono_ros as chrono_ros
import rospy

# Initialize ROS node
rospy.init_node('pychrono_ros_example')

# Initialize Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravitational acceleration

# Create physical material properties
mat = chrono.ChMaterialSurfaceNSC()
mat.SetFriction(0.5)
mat.SetRestitution(0.2)

# Add fixed floor
floor = chrono.ChBodyEasyBox(10, 10, 0.1, mat)
floor.SetPos(chrono.ChVectorD(0, -0.5, 0))
floor.SetBodyFixed(True)
system.Add(floor)

# Add movable box
box = chrono.ChBodyEasyBox(1, 1, 1, mat)
box.SetPos(chrono.ChVectorD(0, 1, 0))
system.Add(box)

# Create ROS manager
ros_manager = chrono_ros.ChRosManager(system)

# Configure ROS handlers
ros_manager.SetClockHandler(chrono_ros.ChRosClockHandler(100))  # Set clock handler
ros_manager.SetBodyHandler(chrono_ros.ChRosBodyHandler())  # Set body handler
ros_manager.SetTransformHandler(chrono_ros.ChRosTransformHandler())  # Set transform handler

# Create custom ROS handler
class CustomRosHandler(chrono_ros.ChRosHandler):
    def __init__(self, topic_name):
        super().__init__()
        self.topic_name = topic_name

    def OnUpdate(self, time_step):
        # Publish integer message to specified topic
        msg = rospy.Message('std_msgs/Int32', data=1)
        self.publisher.publish(msg)

# Register custom ROS handler
custom_handler = CustomRosHandler('pychrono_ros_topic')
ros_manager.RegisterHandler(custom_handler)

# Run simulation loop
while not rospy.is_shutdown():
    system.DoStepDynamics(0.01)  # Advance system by 0.01 seconds
    ros_manager.Update()  # Update ROS communication

```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries: `pychrono`, `pychrono_ros`, and `rospy`.
   - Initialize the ROS node with `rospy.init_node('pychrono_ros_example')`.
   - Create a Chrono system using `chrono.ChSystemNSC()` and set gravitational acceleration.

2. **Physical Properties:**
   - Define a material surface with friction and restitution properties.

3. **System Components:**
   - Add a fixed floor using `chrono.ChBodyEasyBox()` and set its position.
   - Add a movable box using `chrono.ChBodyEasyBox()` and set its position.

4. **ROS Integration:**
   - Create a ROS manager using `chrono_ros.ChRosManager(system)`.
   - Configure ROS handlers for clock, body, and transform updates.
   - Define a custom ROS handler `CustomRosHandler` that publishes integer messages to a specified topic.

5. **Handler Registration:**
   - Create an instance of the custom handler and register it with the ROS manager.

6. **Simulation Loop:**
   - Enter a loop that continues until the ROS node is shut down.
   - Advance the Chrono system by one timestep using `system.DoStepDynamics(0.01)`.
   - Update ROS communication using `ros_manager.Update()`.

**Note:**

- This script assumes that you have ROS and PyChrono installed.
- Replace `'pychrono_ros_topic'` with the desired topic name for publishing messages.
- Adjust the simulation parameters (e.g., timestep, gravitational acceleration) as needed.
