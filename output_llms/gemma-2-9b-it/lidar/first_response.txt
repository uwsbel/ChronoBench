```python
import pychrono as chrono
import pychrono.postprocess as postprocess

# Initialize PyChrono
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Load the triangular mesh
mesh_file = "path/to/your/mesh.obj"  # Replace with your .obj file path
mesh = chrono.ChTriangleMeshConnected()
if not mesh.LoadWavefront(mesh_file):
    raise ValueError(f"Failed to load mesh from {mesh_file}")

# Create a fixed body from the mesh
body = chrono.ChBodyEasyBox(1.0, 1.0, 1.0)  # Replace dimensions with your mesh's
body.SetPos(chrono.ChVectorD(0, 0, 0))
body.SetBodyFixed(True)
body.AddAsset(chrono.ChTriangleMeshShape(mesh))
system.Add(body)

# Create a lidar sensor
lidar = chrono.ChLidarSensor()
lidar.SetSensorType(chrono.ChLidarSensor.TYPE_LASER)
lidar.SetRange(10.0)  # Set the lidar's maximum range
lidar.SetScanAngle(chrono.deg2rad(360))  # Set the lidar's scan angle

# Configure sensor manager
sensor_manager = chrono.ChSensorManager()
sensor_manager.AddSensor(lidar)

# Apply noise filters
lidar.SetNoiseStdDev(0.01)  # Set the standard deviation of noise

# Configure visualizations
lidar.SetVisualization(True)  # Enable lidar visualization
lidar.SetPointColor(chrono.ChColor(1.0, 0.0, 0.0))  # Set point color

# Configure saving options
lidar.SetSaveData(True)  # Enable saving lidar data
lidar.SetSaveFileName("lidar_data.txt")  # Set the filename for saving data

# Attach lidar to the body
lidar.SetParentBody(body)
lidar.SetPos(chrono.ChVectorD(0, 0, 1))  # Set initial lidar position

# Define orbit parameters
orbit_radius = 2.0
orbit_speed = 0.1

# Simulation loop
dt = 0.01
for i in range(1000):
    # Update lidar position in orbit
    angle = orbit_speed * i
    lidar.SetPos(chrono.ChVectorD(orbit_radius * chrono.cos(angle), orbit_radius * chrono.sin(angle), 1))

    # Run simulation step
    system.DoStepDynamics(dt)

    # Print lidar buffer data
    lidar_data = lidar.GetLidarBuffer()
    print(f"Step {i}: Lidar Data: {lidar_data}")

# Post-processing (optional)
postprocess.SaveVisualization("lidar_visualization.mp4")  # Save lidar visualization
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries.
   - Initializes the PyChrono environment.
   - Creates a new Chrono system.

2. **Mesh Loading and Body Creation:**
   - Loads the triangular mesh from the specified `.obj` file.
   - Creates a fixed body using `chrono.ChBodyEasyBox` (you can adjust dimensions).
   - Sets the body's position and makes it fixed.
   - Adds the loaded mesh as an asset to the body.
   - Adds the body to the Chrono system.

3. **Lidar Sensor Setup:**
   - Creates a `chrono.ChLidarSensor` object.
   - Configures sensor type, range, and scan angle.
   - Creates a `chrono.ChSensorManager` to manage the lidar sensor.
   - Adds the lidar sensor to the manager.

4. **Noise Filtering and Visualization:**
   - Applies noise to the lidar data using `SetNoiseStdDev`.
   - Enables lidar visualization and sets the point color.

5. **Saving Lidar Data:**
   - Enables saving lidar data to a file.
   - Sets the filename for the saved data.

6. **Lidar Attachment and Orbit:**
   - Attaches the lidar sensor to the fixed body.
   - Sets the initial lidar position.
   - Defines parameters for the lidar's orbit around the mesh (radius and speed).

7. **Simulation Loop:**
   - Sets the simulation time step (`dt`).
   - Iterates for a specified number of steps.
   - In each step:
     - Updates the lidar's position in its orbit.
     - Runs a simulation step using `system.DoStepDynamics(dt)`.
     - Prints the lidar buffer data.

8. **Post-Processing (Optional):**
   - Saves a visualization of the lidar data to a video file.



**Remember to:**

- Replace `"path/to/your/mesh.obj"` with the actual path to your Wavefront `.obj` file.
- Replace `"path/to/chrono/data"` with the path to your Chrono data directory if necessary.
- Adjust the mesh dimensions, lidar parameters, orbit parameters, and simulation duration as needed.
