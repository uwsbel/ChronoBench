```python
import pychrono as chrono
import chrono.postprocess as postprocess
import numpy as np

# 1. Initialize PyChrono environment
app = chrono.ChSystemNSC()  # Create a new Chrono system

# 2. Add the triangular mesh body
mesh_file = "path/to/your/triangle_mesh.obj"  # Replace with your .obj file path
mesh = chrono.ChTriangleMeshConnected()
mesh.LoadWavefront(mesh_file)
body = chrono.ChBodyEasyBox(1, 1, 1)  # Replace with desired dimensions
body.SetBodyFixed(True)  # Fix the body in place
body.AddAsset(mesh)
app.Add(body)

# 3. Add lidar sensor
sensor_manager = chrono.ChSensorManager()
lidar = chrono.ChLidarSensor()
lidar.SetSensorName("Lidar")
lidar.SetRange(10)  # Set lidar range
lidar.SetAngularResolution(np.pi / 180 * 5)  # Set angular resolution
lidar.SetScanAngle(np.pi)  # Set scan angle
lidar.SetNoise(0.1)  # Add noise to the lidar data
lidar.SetVisualization(True)  # Enable lidar visualization

sensor_manager.AddSensor(lidar)
body.AddSensor(sensor_manager)

# Define lidar orbit parameters
orbit_radius = 2
orbit_speed = 0.1

# Simulation loop
dt = 0.01
for i in range(1000):
    # Update lidar position in orbit
    angle = orbit_speed * i
    lidar.SetPos(body.GetPos() + chrono.ChVectorD(orbit_radius * np.cos(angle),
                                                orbit_radius * np.sin(angle), 0))

    # Advance simulation
    app.DoStepDynamics(dt)

    # Print lidar buffer data
    lidar_data = lidar.GetBuffer()
    print(f"Lidar data step {i}: {lidar_data}")

# Save lidar data
postprocess.SaveLidarData(lidar.GetBuffer(), "lidar_data.txt")

# Run the simulation
app.Run()
```

**Explanation:**

1. **Initialization:**
   - We create a new Chrono system using `chrono.ChSystemNSC()`.

2. **Adding the Mesh Body:**
   - Replace `"path/to/your/triangle_mesh.obj"` with the actual path to your .obj file.
   - We load the mesh using `chrono.ChTriangleMeshConnected()` and add it to a box-shaped body.
   - The `SetBodyFixed(True)` method ensures the mesh remains stationary.

3. **Adding the Lidar Sensor:**
   - We create a `chrono.ChLidarSensor()` object and configure its properties like range, angular resolution, scan angle, noise level, and visualization.
   - The sensor is added to the body's sensor manager.

4. **Lidar Orbit:**
   - We define parameters for the lidar's orbit around the mesh (radius and speed).
   - In the simulation loop, we update the lidar's position based on these parameters.

5. **Simulation Loop:**
   - We iterate for a specified number of steps (`1000` in this case).
   - Inside the loop:
     - We update the lidar's position in orbit.
     - We advance the simulation using `app.DoStepDynamics(dt)`.
     - We print the lidar buffer data using `lidar.GetBuffer()`.

6. **Saving Lidar Data:**
   - After the simulation, we save the lidar data to a text file using `postprocess.SaveLidarData()`.

7. **Running the Simulation:**
   - Finally, we run the simulation using `app.Run()`.



**Remember:**

- Replace `"path/to/your/triangle_mesh.obj"` with the actual path to your .obj file.
- Adjust the simulation parameters (e.g., `dt`, number of steps, orbit parameters) as needed.
- You might need to install additional packages like `pychrono` and `numpy`.
