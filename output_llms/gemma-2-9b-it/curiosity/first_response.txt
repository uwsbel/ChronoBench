```python
import pychrono as chrono

# Initialize PyChrono environment
chrono.SetChronoDataPath("path/to/your/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Define ground terrain
ground = chrono.ChBodyEasyBox(10, 10, 0.1)  # Size: 10x10 meters, height: 0.1 meters
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.SetBodyFixed(True)  # Fix the ground
ground.SetMaterialSurface(chrono.ChMaterialSurface())
ground.GetMaterialSurface().SetFriction(0.8)  # Adjust friction as needed
system.Add(ground)

# Define Curiosity rover model
rover = chrono.ChBodyEasySphere(0.5)  # Radius: 0.5 meters
rover.SetPos(chrono.ChVectorD(0, 0, 0.5))
rover.SetBodyFixed(False)

# Add motor control driver
motor_driver = chrono.ChMotorRotation(chrono.ChVectorD(0, 0, 1), rover)  # Motor axis: Z
motor_driver.SetSpeed(0)  # Initial speed

# Connect motor driver to rover
rover.AddAsset(motor_driver)

# Visualize the simulation
vis = chrono.ChVisualSystemIrrlicht(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle("Curiosity Rover Simulation")

# Customize camera settings
vis.AddCamera(
    chrono.ChVectorD(5, 5, 2),  # Camera position
    chrono.ChVectorD(0, 0, 0),  # Camera target
    chrono.ChVectorD(0, 1, 0),  # Camera up vector
)

# Lighting and shadows
vis.SetAmbientLight(chrono.ChColor(0.2, 0.2, 0.2))
vis.SetLight(chrono.ChVectorD(5, 5, 5), chrono.ChColor(0.8, 0.8, 0.8))
vis.EnableShadows(True)

# ...

# Run the simulation
while vis.Run():
    # Update motor speed based on real-time inputs
    # ...
    system.DoStepDynamics(0.01)  # Time step
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Import `pychrono` and set the data path.
   - Create a `ChSystemNSC` object to manage the simulation.

2. **Ground Terrain:**
   - Create a rectangular box (`ChBodyEasyBox`) representing the ground.
   - Set its position, fix it in place, and define its material properties (friction).

3. **Curiosity Rover:**
   - Create a spherical body (`ChBodyEasySphere`) for the rover.
   - Set its initial position and make it movable.

4. **Motor Control:**
   - Create a `ChMotorRotation` object to control the rover's rotation.
   - Set the motor axis and initial speed.

5. **Connection:**
   - Attach the motor driver to the rover body.

6. **Visualization:**
   - Initialize `ChVisualSystemIrrlicht` for Irrlicht rendering.
   - Set window size, title, and add a camera with desired position, target, and up vector.
   - Configure ambient light, a directional light, and enable shadows.

7. **Customization:**
   - Add comments for adding textures, logos, or other visual elements.

8. **Simulation Loop:**
   - Use `vis.Run()` to start the simulation.

     - Update the motor speed based on real-time inputs (not implemented here).
     - Advance the simulation with `system.DoStepDynamics()`.
     - Render the scene with `vis.Render()`.
