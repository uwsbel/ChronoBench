```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize PyChrono environment
chrono.SetChronoDataPath("path/to/your/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Create a physical system
physical_system = chrono.ChBodyEasyBox(1.0, 1.0, 1.0, 1000.0)  # Box shape with mass 1000 kg
physical_system.SetPos(chrono.ChVectorD(0, 0, 0))
system.AddBody(physical_system)

# Define beam properties
beam_material = chrono.ChMaterialSurfaceNSC()
beam_material.SetFriction(0.5, 0.5)  # Friction coefficient
beam_material.SetRestitution(0.0)  # Elasticity
beam_material.SetYoungModulus(2e11)  # Young's modulus
beam_material.SetDensity(7850)  # Density

# Create beam finite elements
beam_element = chrono.ChBeamElement(beam_material)
beam_element.SetCrossSection(chrono.ChBeamCrossSectionRectangle(0.1, 0.1))  # Rectangle cross-section
beam_element.SetLength(1.0)

# Define nodes for the beam
node1 = chrono.ChNodeData()
node2 = chrono.ChNodeData()

# Connect nodes with the beam element
beam_element.AddNode(node1)
beam_element.AddNode(node2)

# Add the beam element to the physical system
physical_system.AddElement(beam_element)

# Set node positions
node1.pos = chrono.ChVectorD(0, 0, 0)
node2.pos = chrono.ChVectorD(1, 0, 0)

# Initialize Irrlicht engine for visualization
app = chronoirr.ChIrrApp(system, 'Beam Finite Element Simulation')
app.SetWindowSize(1280, 720)
app.AddTypicalLights()
app.AddCamera(physical_system)
app.AssetBindAll()

# Run the simulation loop
app.Start()
```

**Explanation:**

1. **Initialization:**
   - Import necessary PyChrono and Irrlicht modules.
   - Set the Chrono data path.
   - Create a PyChrono system object.

2. **Physical System:**
   - Create a simple box body as the base physical system.
   - Set its initial position.
   - Add the body to the system.

3. **Beam Properties:**
   - Define a material for the beam with specified friction, restitution, Young's modulus, and density.

4. **Beam Element:**
   - Create a beam element object using the defined material.
   - Set the cross-section of the beam (here, a rectangle).
   - Define the length of the beam.

5. **Nodes:**
   - Create two node objects to represent the ends of the beam.

6. **Beam Connection:**
   - Connect the nodes to the beam element.

7. **Adding to System:**
   - Add the beam element to the physical system.

8. **Node Positioning:**
   - Set the initial positions of the nodes.

9. **Visualization:**
   - Initialize the Irrlicht engine for real-time rendering.
   - Set window size and add lights.
   - Add a camera to view the simulation.
   - Bind all assets.

10. **Simulation Loop:**
    - Start the Irrlicht application, which runs the simulation loop and displays the visualization.



Remember to replace `"path/to/your/chrono/data"` with the actual path to your Chrono data directory.
