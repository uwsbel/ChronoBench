```python
import pychrono as chrono

# Initialize Chrono environment
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Create a ground plane
ground = chrono.ChBodyEasyBox(10, 10, 0.1)
ground.SetPos(chrono.ChVectorD(0, 0, -0.5))
system.Add(ground)

# Create a beam finite element
beam_material = chrono.ChMaterialSurfaceNSC()
beam_material.SetYoungModulus(2e11)  # Example Young's modulus
beam_material.SetYieldStress(2e8)  # Example yield stress
beam_material.SetDensity(7850)  # Example density

beam_element = chrono.ChBeamElement()
beam_element.SetMaterial(beam_material)
beam_element.SetCrossSection(chrono.ChBeamCrossSectionRectangular(0.1, 0.01))  # Example rectangular cross-section

# Define nodes for the beam
node1 = chrono.ChNode()
node2 = chrono.ChNode()
node1.SetPos(chrono.ChVectorD(0, 0, 0))
node2.SetPos(chrono.ChVectorD(1, 0, 0))

# Connect nodes to the beam element
beam_element.AddNode(node1)
beam_element.AddNode(node2)

# Create a body to represent the beam
beam_body = chrono.ChBodyEasyBeam(beam_element)
beam_body.SetPos(chrono.ChVectorD(0.5, 0, 0))
system.Add(beam_body)

# Add visualization using Irrlicht engine
vis = chrono.ChVisualSystemIrrlicht(system)
vis.SetWindowSize(1280, 720)
vis.SetWindowTitle("Beam Finite Element Simulation")
vis.EnableCamera(True)
vis.SetAmbientLightColor(chrono.ChColor(0.1, 0.1, 0.1))

# Run the simulation loop
while vis.Run():
    system.DoStepDynamics(0.01)
    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Import the `pychrono` library.
   - Set the Chrono data path if necessary.
   - Create a `ChSystemNSC` object to represent the physical system.

2. **Ground Plane:**
   - Create a `ChBodyEasyBox` object representing a ground plane.
   - Set its position and add it to the system.

3. **Beam Finite Element:**
   - Define a `ChMaterialSurfaceNSC` object for the beam material with properties like Young's modulus, yield stress, and density.
   - Create a `ChBeamElement` object and set its material.
   - Define the cross-section of the beam (here, a rectangle).

4. **Nodes:**
   - Create two `ChNode` objects representing the nodes of the beam.
   - Set their positions.

5. **Beam Body:**
   - Connect the nodes to the beam element.
   - Create a `ChBodyEasyBeam` object using the beam element and set its position.
   - Add the beam body to the system.

6. **Visualization:**
   - Create a `ChVisualSystemIrrlicht` object to use the Irrlicht engine for rendering.
   - Set the window size, title, and enable camera control.
   - Set the ambient light color.

7. **Simulation Loop:**
   - Enter a loop that runs until the user closes the window.
   - Call `system.DoStepDynamics(0.01)` to perform a time step of 0.01 seconds.
   - Call `vis.Render()` to render the scene.



Remember to replace `"path/to/chrono/data"` with the actual path to your Chrono data directory.
