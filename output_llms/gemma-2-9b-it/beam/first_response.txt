```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize Chrono engine
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Create a ground plane
ground = chrono.ChBodyEasyBox(10, 10, 0.1)
ground.SetPos(chrono.ChVectorD(0, 0, -0.1))
ground.SetBodyFixed(True)
system.AddBody(ground)

# Define beam material properties
beam_material = chrono.ChMaterialSurfaceNSC()
beam_material.SetFriction(0.5)
beam_material.SetRestitution(0.1)

# Define beam cross-section properties
beam_cross_section = chrono.ChBeamCrossSectionSolid(0.1, 0.01)  # Adjust width and thickness

# Create beam finite elements
beam_elements = []
for i in range(5):
    # Create a beam node
    node = chrono.ChNodeBodyEasy(system)
    node.SetName(f"Node{i}")
    node.SetPos(chrono.ChVectorD(i * 2, 0, 0))

    # Create a beam element connecting nodes
    beam = chrono.ChBeamElement(beam_material, beam_cross_section)
    beam.SetNodes(node, node)  # Connect the same node for simplicity
    beam_elements.append(beam)

# Add beam elements to the system
for beam in beam_elements:
    system.Add(beam)

# Create visualization
vis_app = vis.ChIrrApp(system, 'Beam Simulation')
vis_app.AddTypicalSky()
vis_app.AddTypicalLights()
vis_app.AddCamera(
    chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0)
)

# Run simulation loop
vis_app.SetTimestep(1/240)  # Adjust timestep for desired simulation speed
vis_app.Start()

while vis_app.GetDevice().run():
    vis_app.Render()
    system.DoStepDynamics(vis_app.GetTimestep())



```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries `pychrono` and `pychrono.irrlicht`.
   - Initializes the Chrono engine with `chrono.ChSystemNSC()`.
   - Sets the data path for Chrono assets (replace with your actual path).

2. **Ground Plane:**
   - Creates a ground plane using `chrono.ChBodyEasyBox()` with dimensions 10x10x0.1.
   - Sets its position and makes it fixed (`SetBodyFixed(True)`).
   - Adds the ground to the system.

3. **Beam Properties:**
   - Defines a `beam_material` with friction and restitution properties.
   - Defines a `beam_cross_section` as a solid rectangle.

4. **Beam Elements:**
   - Creates a loop to generate 5 beam elements.
   - Inside the loop:
     - Creates a `chrono.ChNodeBodyEasy` representing a node.
     - Sets its position.
     - Creates a `chrono.ChBeamElement` using the defined material and cross-section.
     - Connects the beam to the same node for simplicity (you'd typically connect different nodes).
     - Appends the beam element to the `beam_elements` list.

5. **Adding to System:**
   - Adds all the created beam elements to the `system`.

6. **Visualization:**
   - Creates a `vis.ChIrrApp` object to visualize the simulation using Irrlicht.
   - Adds a sky, lights, and a camera to the scene.

7. **Simulation Loop:**
   - Sets the simulation timestep using `vis_app.SetTimestep()`.
   - Starts the Irrlicht application loop using `vis_app.Start()`.
   - Inside the loop:
     - Renders the scene using `vis_app.Render()`.
     - Advances the simulation one timestep using `system.DoStepDynamics()`.



**Remember:**

- Replace `"path/to/chrono/data"` with the actual path to your Chrono data directory.
- Adjust the beam properties (material, cross-section), node positions, and simulation parameters to suit your needs.
- To connect beam elements to different nodes, modify the `beam.SetNodes()` call accordingly.
