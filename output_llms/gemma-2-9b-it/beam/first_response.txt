```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize Chrono
chrono.SetChronoDataPath("..")  # Set path to Chrono data files

# Create a physical system
system = chrono.ChSystemNSC()

# Create a mesh composed of beams and nodes
# Define beam properties
beam_material = chrono.ChMaterialSurfaceNSC()
beam_material.SetFriction(0.5, 0.5)
beam_material.SetRestitution(0.0)

beam_cross_section = chrono.ChBeamSectionSolidCircle(0.05)  # Example: circular cross-section

# Create nodes
node1 = chrono.ChNodeBodyEasyMotion(system)
node1.SetPos(chrono.ChVectorD(0, 0, 0))

node2 = chrono.ChNodeBodyEasyMotion(system)
node2.SetPos(chrono.ChVectorD(1, 0, 0))

# Create beams connecting the nodes
beam1 = chrono.ChBeam(beam_material, beam_cross_section)
beam1.SetName("Beam1")
beam1.SetBody(node1)
beam1.SetOtherBody(node2)

# Add the beam to the system
system.Add(beam1)

# Create visualization using Irrlicht
vis = chronoirr.ChIrrApp(system, 'Beam Simulation')
vis.AddCamera(chrono.ChVectorD(2, 2, 2), chrono.ChVectorD(0, 0, 0))
vis.AddTypicalLights()

# Run the simulation loop
vis.Run()
```

**Explanation:**

1. **Initialization:**
   - Import necessary modules (`pychrono` and `pychrono.irrlicht`).
   - Set the path to Chrono data files.
   - Create a `ChSystemNSC` object to represent the physical system.

2. **Mesh Creation:**
   - Define properties for the beam material (friction, restitution).
   - Create a beam cross-section (example: circular).
   - Create two `ChNodeBodyEasyMotion` objects to represent nodes.
   - Set initial positions for the nodes.
   - Create a `ChBeam` object connecting the nodes.
   - Set the beam's material, cross-section, and bodies.
   - Add the beam to the physical system.

3. **Visualization:**
   - Create a `ChIrrApp` object to initialize the Irrlicht visualization engine.
   - Add a camera and lights to the scene.

4. **Simulation Loop:**
   - Call `vis.Run()` to start the simulation loop, which renders the scene in real-time and updates the physics simulation.



**Key Points:**

- **Beam Properties:** Adjust the `beam_material` and `beam_cross_section` properties to define the beam's behavior.
- **Node Positions:** Modify the `SetPos()` calls to change the initial positions of the nodes.
- **Visualization:** Explore different camera angles and lighting options using the Irrlicht API.
- **Advanced Features:** PyChrono offers more advanced features for defining complex beam meshes, applying loads, and analyzing the simulation results.
