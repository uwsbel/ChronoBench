```python
import pychrono as chrono
import pychrono.irrlicht as vis
import numpy as np

# Initialize Chrono environment
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Create Irrlicht visualization
vis_app = vis.ChIrrApp(system, 'HMMWV Simulation', 
                       width=1280, height=720, 
                       vsync=True, 
                       shadow=True, 
                       use_depth_buffer=True)
vis_app.AddCamera(vis.IrrlichtCamera(vis_app.GetSceneManager(), 
                                     pos=chrono.ChVectorD(0, 5, 10), 
                                     target=chrono.ChVectorD(0, 0, 0)))

# Create RigidTerrain
terrain = chrono.ChRigidBody(chrono.ChBodyEasyBox(100, 100, 1))
terrain.SetPos(chrono.ChVectorD(0, 0, 0))
terrain.SetBodyFixed(True)
system.Add(terrain)

# Load HMMWV model (replace with your model path)
vehicle = chrono.ChBodyEasyLoad("path/to/hmmwv/model.urdf")
vehicle.SetPos(chrono.ChVectorD(0, 0, 0))
system.Add(vehicle)

# Configure TMEASY tire model
for wheel in vehicle.GetComponents():
    if isinstance(wheel, chrono.ChWheel):
        wheel.SetContactMethod(chrono.ChContactMethod.C_TMEASY)

# Set up interactive driver system
driver = chrono.ChDriver()
driver.SetVehicle(vehicle)
driver.SetSteeringAxis(chrono.ChVectorD(0, 1, 0))
driver.SetThrottleAxis(chrono.ChVectorD(0, 0, 1))
driver.SetBrakeAxis(chrono.ChVectorD(0, 0, -1))
vis_app.AddDriver(driver)

# Simulation loop
vis_app.SetCamera(vis_app.GetCamera(0))
vis_app.SetTargetFPS(50)
while vis_app.Run():
    system.DoStepDynamics(1.0/50.0)
    vis_app.Render()

```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries (pychrono, pychrono.irrlicht, numpy).
   - Sets the Chrono data path.
   - Creates a Chrono system (`system`) and an Irrlicht visualization application (`vis_app`).

2. **Terrain Creation:**
   - Creates a `ChRigidBody` representing the terrain using a box shape (`ChBodyEasyBox`).
   - Sets the terrain's position and makes it fixed (`SetBodyFixed`).
   - Adds the terrain to the Chrono system.

3. **HMMWV Loading:**
   - Loads the HMMWV model using `ChBodyEasyLoad` (replace `"path/to/hmmwv/model.urdf"` with the actual path to your model).
   - Sets the vehicle's initial position.
   - Adds the vehicle to the Chrono system.

4. **Tire Model Configuration:**
   - Iterates through the vehicle's components to find wheels.
   - Sets the contact method for each wheel to `C_TMEASY` using the `SetContactMethod` function.

5. **Driver System Setup:**
   - Creates a `ChDriver` object to handle user input.
   - Sets the driver's vehicle, steering axis, throttle axis, and brake axis.
   - Adds the driver to the Irrlicht application.

6. **Simulation Loop:**
   - Sets the camera and target frame rate.
   - Enters a loop that runs until the user closes the application:
     - Updates the vehicle dynamics using `system.DoStepDynamics`.
     - Renders the scene using `vis_app.Render`.



**Remember:**

- Replace `"path/to/chrono/data"` with the actual path to your Chrono data directory.
- Replace `"path/to/hmmwv/model.urdf"` with the path to your HMMWV model file.
- You may need to adjust the camera position and other parameters to get a good view of the simulation.
