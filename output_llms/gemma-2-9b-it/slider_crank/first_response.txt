```python
import pychrono as chrono
import pychrono.irrlicht as vis

# Initialize Chrono and Irrlicht
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
app = vis.Application(
    vis.Application.Windowed,
    "Crank-Slider Mechanism",
    width=800,
    height=600,
    vsync=True,
)
vis.EnableShadows()
vis.EnableAmbientLight()

# Create the environment
floor = chrono.ChBodyEasy.CreateFromShape(chrono.ChBoxShape(10, 1, 10), 1000)
floor.SetPos(chrono.ChVectorD(0, -0.5, 0))
floor.SetBodyFixed(True)
app.Add(floor)

# Create the crankshaft
crankshaft = chrono.ChBodyEasy.CreateFromShape(chrono.ChCylinderShape(0.2, 1), 10)
crankshaft.SetPos(chrono.ChVectorD(0, 0, 0))
crankshaft.SetRot(chrono.Q_from_Euler(chrono.deg2rad(90), 0, 0))
app.Add(crankshaft)

# Create the connecting rod
connecting_rod = chrono.ChBodyEasy.CreateFromShape(chrono.ChBoxShape(0.1, 0.1, 1), 1)
connecting_rod.SetPos(chrono.ChVectorD(0.5, 0, 0))
app.Add(connecting_rod)

# Create the piston
piston = chrono.ChBodyEasy.CreateFromShape(chrono.ChCylinderShape(0.1, 0.2), 1)
piston.SetPos(chrono.ChVectorD(1, 0, 0))
app.Add(piston)

# Add joints
crankshaft_piston_joint = chrono.ChLinkTS()
crankshaft_piston_joint.Initialize(crankshaft, piston, chrono.ChVectorD(0.5, 0, 0))
crankshaft_piston_joint.SetPos(chrono.ChVectorD(0.5, 0, 0))
crankshaft_piston_joint.SetRot(chrono.Q_from_Euler(chrono.deg2rad(0), 0, 0))
crankshaft_piston_joint.SetMotionType(chrono.ChLinkTS.MOTION_ROT_X)

connecting_rod_piston_joint = chrono.ChLinkTS()
connecting_rod_piston_joint.Initialize(connecting_rod, piston, chrono.ChVectorD(0, 0, 0.2))
connecting_rod_piston_joint.SetPos(chrono.ChVectorD(0.5, 0, 0.2))
connecting_rod_piston_joint.SetRot(chrono.Q_from_Euler(chrono.deg2rad(0), 0, 0))
connecting_rod_piston_joint.SetMotionType(chrono.ChLinkTS.MOTION_ROT_X)

# Add motor to crankshaft
motor = chrono.ChMotorRotation(
    chrono.ChVectorD(0, 0, 1),
    crankshaft,
    chrono.ChVectorD(0, 0, 0),
    chrono.ChVectorD(0, 0, 1),
    100,  # Angular velocity
    chrono.ChVectorD(0, 0, 0),  # Torque
)
crankshaft.AddAsset(motor)

# Customize visualization
app.SetCamera(
    chrono.ChVectorD(3, 3, 3),
    chrono.ChVectorD(0, 0, 0),
    chrono.ChVectorD(0, 1, 0),
)

# Run the simulation
app.SetTimestep(0.01)
while app.Run():
    app.Render()
    chrono.Step(app.GetTimestep())



```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Set the Chrono data path.
   - Initialize the Irrlicht application with specified window dimensions and settings.
   - Enable shadows and ambient light for better visualization.

2. **Environment Setup:**
   - Create a floor using a box shape and set it as fixed.

3. **Mechanical Components:**
   - Create the crankshaft, connecting rod, and piston using appropriate shapes (cylinder and box).
   - Set their initial positions and rotations.

4. **Joints:**
   - Define two joints:
     - `crankshaft_piston_joint`: Connects the crankshaft and piston, allowing rotation around the x-axis.
     - `connecting_rod_piston_joint`: Connects the connecting rod and piston, also allowing rotation around the x-axis.

5. **Motor:**
   - Add a motor to the crankshaft to drive its rotation at a constant angular velocity.

6. **Visualization Customization:**
   - Set the camera position, target, and up vector for a specific view.

7. **Simulation Loop:**
   - Set the simulation timestep.
   - Run the simulation loop:
     - Render the scene using Irrlicht.
     - Advance the simulation by one timestep.



**Remember to:**

- Replace `"path/to/chrono/data"` with the actual path to your Chrono data directory.
- Adjust the shape parameters, positions, and motor properties to customize the mechanism.
- Explore Irrlicht's capabilities for adding textures, logos, and other visual enhancements.
