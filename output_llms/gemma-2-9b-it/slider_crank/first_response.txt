```python
from pychrono import ChSystem, ChBody, ChLink, ChMaterialSurface, ChMotor, ChContact
from pychrono.irrlicht import IrrlichtVisualizer
import numpy as np

# Initialize PyChrono system
system = ChSystem()

# Create ground plane
ground = ChBody(system)
ground.SetPos(ChVectorD(0, 0, 0))
ground.SetBodyFixed(True)

# Create crankshaft
crankshaft = ChBody(system)
crankshaft.SetPos(ChVectorD(0, 0, 0.5))
crankshaft.SetRot(ChQuaternionD.from_euler(0, 0, 0))
crankshaft.SetMass(1.0)
crankshaft.SetInertiaXX(ChVectorD(0.1, 0.1, 0.1))
crankshaft.SetCollide(True)

# Create connecting rod
connecting_rod = ChBody(system)
connecting_rod.SetPos(ChVectorD(0, 0, 1))
connecting_rod.SetRot(ChQuaternionD.from_euler(0, 0, 0))
connecting_rod.SetMass(0.5)
connecting_rod.SetInertiaXX(ChVectorD(0.01, 0.01, 0.01))
connecting_rod.SetCollide(True)

# Create piston
piston = ChBody(system)
piston.SetPos(ChVectorD(0, 0, 1.5))
piston.SetRot(ChQuaternionD.from_euler(0, 0, 0))
piston.SetMass(0.2)
piston.SetInertiaXX(ChVectorD(0.001, 0.001, 0.001))
piston.SetCollide(True)

# Create joints
crankshaft_joint = ChLinkLockUniversal(crankshaft, connecting_rod, ChVectorD(0, 0, 0), ChVectorD(0, 0, 0))
connecting_rod_joint = ChLinkSlider(connecting_rod, piston, ChVectorD(0, 0, 0), ChVectorD(0, 0, 1))

# Create motor
motor = ChMotor(system)
motor.SetPos(crankshaft.GetPos())
motor.SetRot(crankshaft.GetRot())
motor.SetBody(crankshaft)
motor.SetMode(ChMotor.Mode.TORQUE_CONTROL)
motor.SetTorque(10)  # Set desired torque

# Visualizer setup
vis = IrrlichtVisualizer(system)
vis.SetCamera(
    pos=ChVectorD(2, 2, 2),
    target=ChVectorD(0, 0, 0),
    up=ChVectorD(0, 1, 0),
)
vis.SetBackgroundColor(0.8, 0.8, 0.8)
vis.SetAmbientLight(0.5, 0.5, 0.5)
vis.SetDirectionalLight(0.8, 0.8, 0.8, ChVectorD(1, 1, 1))

# Add textures and logos
# ... (implementation depends on specific assets and desired appearance)

# Simulation loop
while vis.Run():
    system.DoStepDynamics(0.01)
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules from `pychrono` and `numpy`.
   - Creates a `ChSystem` object to represent the simulation environment.

2. **Physical Systems and Objects:**
   - Creates a `ChBody` for the ground plane, setting it as fixed.
   - Creates `ChBody` objects for the crankshaft, connecting rod, and piston, assigning them masses, inertias, and collision properties.

3. **Joints and Connections:**
   - Creates `ChLinkLockUniversal` for the crankshaft-connecting rod joint, restricting rotation around the Z-axis.
   - Creates `ChLinkSlider` for the connecting rod-piston joint, allowing linear motion along the Z-axis.

4. **Motor:**
   - Creates a `ChMotor` object to drive the crankshaft.
   - Sets the motor mode to torque control and applies a constant torque.

5. **Visualization:**
   - Creates an `IrrlichtVisualizer` object to render the simulation.
   - Sets the camera position, target, and up direction.
   - Configures background color, ambient light, and directional light.

6. **Simulation Loop:**
   - Enters a loop that runs until the visualization window is closed.
   - Calls `system.DoStepDynamics()` to update the simulation for each time step.
   - Calls `vis.Render()` to render the current state of the simulation.

**Notes:**

- This script provides a basic framework for the crank-slider mechanism.
- You'll need to adjust parameters like masses, inertias, joint limits, and motor torque to achieve the desired behavior.
- The `# ...` comments indicate where you can add code to customize the appearance with textures, logos, and other visual elements.
