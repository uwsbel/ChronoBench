```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize Chrono
chrono.SetChronoDataPath("path/to/your/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Set visualization options
vis = chronoirr.ChIrrApp(system)
vis.SetWindowSize(1280, 720)
vis.SetFullscreen(True)
vis.AddCamera(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))

# Create floor
floor = chrono.ChBodyEasyBox(10, 10, 0.1, 1000)
floor.SetPos(chrono.ChVectorD(0, 0, 0))
floor.SetBodyFixed(True)
system.Add(floor)

# Create crankshaft
crankshaft = chrono.ChBodyEasyCylinder(0.1, 0.5, 100)
crankshaft.SetPos(chrono.ChVectorD(0, 0, 0.5))
crankshaft.SetBodyFixed(False)
system.Add(crankshaft)

# Create connecting rod
connecting_rod = chrono.ChBodyEasyCylinder(0.05, 0.5, 100)
connecting_rod.SetPos(chrono.ChVectorD(0.5, 0, 0))
connecting_rod.SetBodyFixed(False)
system.Add(connecting_rod)

# Create piston
piston = chrono.ChBodyEasyBox(0.2, 0.2, 0.1, 100)
piston.SetPos(chrono.ChVectorD(1, 0, 0))
piston.SetBodyFixed(False)
system.Add(piston)

# Create joints
crankshaft_joint = chrono.ChLinkLockPrismatic(crankshaft, connecting_rod, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
connecting_rod_joint = chrono.ChLinkLockPrismatic(connecting_rod, piston, chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
system.Add(crankshaft_joint)
system.Add(connecting_rod_joint)

# Create motor
motor = chrono.ChMotorRotation(crankshaft, chrono.ChVectorD(0, 0, 1), chrono.ChVectorD(0, 0, 1), 100)
motor.SetMode(chrono.ChMotorMode.MODE_TORQUE_CONTROL)
motor.SetTorque(10)  # Set desired torque
system.Add(motor)

# Set visualization properties
vis.AddLight(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(1, 1, 1))
vis.AddLight(chrono.ChVectorD(-5, -5, 5), chrono.ChVectorD(1, 1, 1))

# Load textures and logos
# ... (add your texture and logo loading code here)

# Run simulation
vis.Start()
system.DoStepDynamics(0.01)
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries (`pychrono` and `pychrono.irrlicht`).
   - Initializes the Chrono environment with `chrono.ChSystemNSC()`.
   - Sets up the Irrlicht visualization system (`chronoirr.ChIrrApp`) with window size, fullscreen mode, and a default camera position.

2. **Physical Systems:**
   - Creates a floor using `chrono.ChBodyEasyBox`.
   - Creates a crankshaft, connecting rod, and piston using `chrono.ChBodyEasyCylinder` and `chrono.ChBodyEasyBox`.
   - Sets initial positions and properties for each body.

3. **Joints:**
   - Defines prismatic joints using `chrono.ChLinkLockPrismatic` to connect the crankshaft, connecting rod, and piston.

4. **Motor:**
   - Creates a rotational motor using `chrono.ChMotorRotation` to drive the crankshaft.
   - Sets the motor mode to torque control and applies a desired torque.

5. **Visualization:**
   - Adds lights to the scene using `vis.AddLight`.
   - You can add your own textures and logos here using the Irrlicht API.

6. **Simulation:**
   - Starts the Irrlicht visualization loop with `vis.Start()`.
   - Performs a single time step using `system.DoStepDynamics(0.01)`.

**Remember:**

- Replace `"path/to/your/chrono/data"` with the actual path to your Chrono data directory.
- Customize the parameters (sizes, positions, forces, etc.) to match your desired crank-slider mechanism.
- Add your own code for loading textures, logos, and other visual elements.
- Adjust the time step (`0.01`) for the simulation based on the desired speed and accuracy.
