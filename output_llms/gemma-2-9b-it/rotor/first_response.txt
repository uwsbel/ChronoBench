```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize Chrono
chrono.SetChronoData(chrono.ChSystemNSC)
system = chrono.ChSystemNSC()

# Create the beam using IGA
beam_material = chrono.ChMaterialSurfaceNSC()
beam_material.SetFriction(0.5, 0.5)
beam_material.SetRestitution(0.0)
beam_body = chrono.ChBodyEasyBox(1.0, 0.1, 0.01, beam_material)
beam_body.SetBodyFixed(True)

# Create the flywheel
flywheel_mass = 1.0
flywheel_radius = 0.05
flywheel_body = chrono.ChBodyEasyCylinder(flywheel_mass, flywheel_radius, beam_material)
flywheel_body.SetPos(chrono.ChVectorD(0.5, 0, 0))  # Position at center of beam

# Create the rotational motor
motor_body = chrono.ChBodyEasySphere(1.0, beam_material)
motor_body.SetPos(chrono.ChVectorD(0, 0, 0))  # Position at one end of beam
motor_joint = chrono.ChLinkLockFree(beam_body, motor_body)
motor_joint.SetMotor(chrono.ChMotorRotationSpeed(motor_body, 10.0))

# Add bodies to the system
system.Add(beam_body)
system.Add(flywheel_body)
system.Add(motor_body)

# Visualize the system
vis = chronoirr.ChVisualSystemIrrlicht(system, "Jeffcott Rotor Simulation", 1024, 768, true)
vis.AddCamera(chrono.ChVectorD(2, 2, 2), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
vis.AddLight(chrono.ChVectorD(1, 1, 1))
vis.AddFEMVisualization(beam_body)

# Run the simulation
while vis.Run():
    system.DoStepDynamics(0.01)



```

**Explanation:**

1. **Initialization:**
   - Imports necessary modules (`pychrono` and `pychrono.irrlicht`).
   - Initializes the Chrono environment with `chrono.SetChronoData(chrono.ChSystemNSC)`.
   - Creates a `ChSystemNSC` object to represent the simulation system.

2. **Beam Creation:**
   - Defines a material for the beam (`beam_material`).
   - Creates a box-shaped beam body (`beam_body`) using `chrono.ChBodyEasyBox`.
   - Sets the beam body as fixed (`beam_body.SetBodyFixed(True)`).

3. **Flywheel Creation:**
   - Defines the mass and radius of the flywheel.
   - Creates a cylindrical flywheel body (`flywheel_body`) using `chrono.ChBodyEasyCylinder`.
   - Positions the flywheel at the center of the beam.

4. **Motor Creation:**
   - Creates a spherical motor body (`motor_body`).
   - Positions the motor at one end of the beam.
   - Creates a `ChLinkLockFree` joint (`motor_joint`) to connect the motor and beam.
   - Sets a rotational motor (`chrono.ChMotorRotationSpeed`) on the joint to drive the beam.

5. **Adding Bodies to System:**
   - Adds the beam, flywheel, and motor bodies to the simulation system using `system.Add()`.

6. **Visualization:**
   - Creates an Irrlicht visualization system (`chronoirr.ChVisualSystemIrrlicht`) to display the simulation.
   - Adds a camera, light, and FEM visualization for the beam.

7. **Simulation Loop:**
   - Enters a loop that runs until the user closes the visualization window.
   - In each iteration, it updates the system dynamics using `system.DoStepDynamics(0.01)`.



**Remember:**

- You'll need to have PyChrono and PyChrono Irrlicht installed.
- Adjust the parameters (mass, radius, motor speed, etc.) to suit your specific simulation needs.
- This script provides a basic framework. You may need to modify it further to achieve your desired results.
