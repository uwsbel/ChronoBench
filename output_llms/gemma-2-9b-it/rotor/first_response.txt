```python
import pychrono as chrono
import chrono.irrlicht as irrlicht

# Initialize PyChrono
chrono.SetChronoDataPath("./")  # Set path to Chrono data files
system = chrono.ChSystemNSC()

# Create the IGA beam
beam_material = chrono.ChMaterialSurfaceNSC()
beam_material.SetFriction(0.5, 0.5)
beam_material.SetDampingF(0.1)

beam_iga = chrono.ChBeamIGA()
beam_iga.SetMaterial(beam_material)
beam_iga.SetLength(1.0)  # Adjust beam length as needed
beam_iga.SetCrossSectionType(chrono.ChBeamIGA.CROSS_SECTION_RECTANGLE)
beam_iga.SetCrossSectionParams(0.1, 0.05)  # Adjust cross-section dimensions as needed
beam_iga.SetNodes(5)  # Adjust number of nodes for finer mesh

# Attach the flywheel to the beam's center
flywheel_mass = 1.0
flywheel_radius = 0.05
flywheel = chrono.ChBodyEasyCylinder(flywheel_mass, flywheel_radius, 0.01)
flywheel.SetPos(chrono.ChVectorD(0.5, 0, 0))  # Center of the beam
beam_iga.AddBody(flywheel)

# Create the rotational motor
motor = chrono.ChMotorRotation()
motor.SetMode(chrono.ChMotorRotation.MODE_TORQUE_CONTROL)
motor.SetTorque(1.0)  # Adjust torque as needed
motor.SetDamping(0.1)
motor.AttachTo(beam_iga.GetNode(0), beam_iga.GetNode(1))

# Add visual components
beam_iga.SetCollide(True)
beam_iga.SetBodyFixed(False)
flywheel.SetCollide(True)
system.Add(beam_iga)
system.Add(flywheel)
system.Add(motor)

# Set up Irrlicht visualization
vis = irrlicht.ChIrrApp(system, 'Jeffcott Rotor Simulation')
vis.AddCamera(chrono.ChVectorD(2, 2, 2), chrono.ChVectorD(0, 0, 0))
vis.AddLight(chrono.ChVectorD(2, 2, 2))
vis.SetDrawMode(irrlicht.CH_DRAWMODE_WIREFRAME)
vis.SetCameraVertical(chrono.ChVectorD(0, 0, 1))
vis.Run()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries: `pychrono` and `chrono.irrlicht`.
   - Initialize the PyChrono environment with `chrono.ChSystemNSC()`.
   - Set the path to Chrono data files using `chrono.SetChronoDataPath()`.

2. **IGA Beam Creation:**
   - Define material properties for the beam using `chrono.ChMaterialSurfaceNSC()`.
   - Create an IGA beam object using `chrono.ChBeamIGA()`.
   - Set material, length, cross-section type, dimensions, and number of nodes for the beam.

3. **Flywheel Attachment:**
   - Create a cylindrical flywheel using `chrono.ChBodyEasyCylinder()`.
   - Set its mass and radius.
   - Attach the flywheel to the center of the beam using `beam_iga.AddBody(flywheel)`.

4. **Rotational Motor:**
   - Create a rotational motor using `chrono.ChMotorRotation()`.
   - Set its mode to torque control and provide a torque value.
   - Attach the motor to the first two nodes of the beam.

5. **Visual Components:**
   - Enable collision detection for the beam and flywheel using `SetCollide(True)`.
   - Add the beam, flywheel, and motor to the PyChrono system using `system.Add()`.

6. **Irrlicht Visualization:**
   - Create an Irrlicht visualization window using `chrono.ChIrrApp()`.
   - Add a camera and light source for better visualization.
   - Set the draw mode to wireframe for clarity.
   - Adjust camera position and orientation.
   - Start the simulation loop with `vis.Run()`.
