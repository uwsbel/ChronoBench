```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize Chrono environment
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Create the IGA beam
beam_material = chrono.ChMaterialSurfaceNSC()
beam_material.SetFriction(0.5, 0.5)
beam_material.SetRestitution(0.0)

beam_geometry = chrono.ChBeamIGA()
beam_geometry.SetMaterial(beam_material)
beam_geometry.SetNumDivisions(50)  # Adjust for desired mesh resolution
beam_geometry.SetCrossSection(chrono.ChBeamIGA.CrossSectionType.RECT, 0.1, 0.01)  # Adjust dimensions

# Create the beam body
beam_body = chrono.ChBodyEasyCylinder(beam_geometry, 1.0, 1.0)  # Adjust length and radius
beam_body.SetPos(chrono.ChVectorD(0, 0, 0))  # Set initial position

# Attach the flywheel
flywheel_geometry = chrono.ChBodyEasyCylinder(radius=0.05, mass=1.0)
flywheel_body = chrono.ChBodyEasyCylinder(flywheel_geometry, 0.1, 0.1)
flywheel_body.SetPos(chrono.ChVectorD(0, 0, 0.5))  # Adjust position relative to beam center

beam_body.AddChildBody(flywheel_body)

# Create the rotational motor
motor_body = chrono.ChBodyEasyCylinder(radius=0.02, mass=0.1)
motor_body.SetPos(chrono.ChVectorD(0, 0, 0))  # Set initial position

motor = chrono.ChMotorRotation(
    motor_body, beam_body, chrono.ChCoordsys<>(chrono.ChVectorD(0, 0, 0), chrono.ChQuaternionD(1, 0, 0, 0)),
    chrono.ChVectorD(0, 0, 1),
    chrono.ChVectorD(0, 0, 1),
    chrono.ChVectorD(0, 0, 1),
    100.0  # Adjust motor torque
)

# Add the bodies to the system
system.Add(beam_body)
system.Add(flywheel_body)
system.Add(motor_body)

# Visualize the system
app = chronoirr.ChIrrApp(system, 'Jeffcott Rotor Simulation')
app.AddCamera(chrono.ChVectorD(2, 2, 2), chrono.ChVectorD(0, 0, 0))
app.AddTypicalLights()
app.SetTimestep(0.01)
app.SetCameraVertical(chrono.ChVectorD(0, 1, 0))
app.Run()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Set the Chrono data path.
   - Create a Chrono system.

2. **IGA Beam Creation:**
   - Define the beam material properties (friction, restitution).
   - Create an IGA beam geometry object with desired divisions and cross-section.
   - Create a beam body using the IGA geometry and assign its mass and dimensions.

3. **Flywheel Attachment:**
   - Create a cylinder geometry for the flywheel.
   - Create a flywheel body and set its position relative to the beam center.
   - Attach the flywheel body to the beam body.

4. **Rotational Motor:**
   - Create a cylinder geometry for the motor.
   - Create a motor body and set its position.
   - Create a rotational motor object, connecting the motor body to the beam body.
   - Set the motor torque.

5. **System Assembly:**
   - Add the beam, flywheel, and motor bodies to the Chrono system.

6. **Visualization:**
   - Create an Irrlicht application for visualization.
   - Add a camera and lights to the scene.
   - Set the simulation timestep.
   - Run the simulation.



**Notes:**

- Adjust the parameters like beam dimensions, flywheel mass, motor torque, and mesh resolution to suit your specific needs.
- You may need to install additional libraries like PyChrono and Irrlicht.
- This script provides a basic framework for simulating a Jeffcott rotor with an IGA beam. You can further enhance it by adding features like damping, external forces, and more sophisticated control strategies.
