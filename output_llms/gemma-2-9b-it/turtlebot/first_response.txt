```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize Chrono system
system = chrono.ChSystemNSC()
system.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Create ground body
ground = chrono.ChBodyEasyBox(10, 10, 0.1)
ground.SetPos(chrono.ChVectorD(0, 0, 0))
ground.SetBodyFixed(True)
system.Add(ground)

# Initialize Turtlebot
turtlebot = chrono.ChBodyEasySphere(0.2)
turtlebot.SetPos(chrono.ChVectorD(0, 0.1, 0))
turtlebot.SetRot(chrono.Q_from_Euler(chrono.ChVectorD(0, 0, 0)))
system.Add(turtlebot)

# Add Turtlebot's wheels (replace with actual Turtlebot wheel model)
left_wheel = chrono.ChBodyEasySphere(0.05)
left_wheel.SetPos(chrono.ChVectorD(-0.1, 0, 0))
turtlebot.AddChild(left_wheel)

right_wheel = chrono.ChBodyEasySphere(0.05)
right_wheel.SetPos(chrono.ChVectorD(0.1, 0, 0))
turtlebot.AddChild(right_wheel)

# Set up Irrlicht visualization
app = chronoirr.ChIrrApp(system)
app.SetWindowSize(800, 600)
app.AddCamera(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0))
app.AddLight(chrono.ChVectorD(5, 5, 5))
app.AssetBindAll()

# Simulation loop
dt = 0.01
while app.Run():
    # Control Turtlebot's wheels
    if app.GetTime() > 1:
        left_wheel.SetPos(chrono.ChVectorD(-0.1, 0, 0.1))
    if app.GetTime() > 2:
        right_wheel.SetPos(chrono.ChVectorD(0.1, 0, 0.1))

    system.DoStepDynamics(dt)
    app.Render()


```

**Explanation:**

1. **Initialization:**
   - Imports `pychrono` and `pychrono.irrlicht` modules.
   - Creates a `ChSystemNSC` object to represent the physics simulation.
   - Sets gravity using `Set_G_acc`.
   - Creates a ground body using `ChBodyEasyBox` and sets it as fixed.
   - Initializes the Turtlebot as a sphere using `ChBodyEasySphere` and positions it.

2. **Turtlebot Components:**
   - Adds placeholder wheels (spheres) to the Turtlebot. In a real simulation, you'd replace these with accurate Turtlebot wheel models.

3. **Visualization:**
   - Creates an `ChIrrApp` object to interface with Irrlicht for rendering.
   - Sets window size and adds a camera with a specific position and target.
   - Adds a light source for illumination.
   - Binds all assets to the Irrlicht scene.

4. **Simulation Loop:**
   - Sets a timestep `dt`.
   - Runs the simulation using `app.Run()`, which handles rendering and user input.
   - **Control:**
     - Demonstrates basic control by moving the wheels at specific times using `SetPos`.
   - **Dynamics:**
     - Updates the simulation state using `system.DoStepDynamics(dt)`.
   - **Rendering:**
     - Renders the scene using `app.Render()`.

**Important Notes:**

- **Turtlebot Model:** You'll need to replace the placeholder wheels with a proper Turtlebot model from a library or create your own.
- **Motor Control:** The provided control is very basic. For realistic Turtlebot movement, you'd need to implement motor control algorithms that consider wheel speeds, odometry, and potentially sensor feedback.
- **Sensor Integration:** To make the simulation more interactive, you could add sensors (e.g., distance sensors, cameras) to the Turtlebot and use their data to adjust the robot's behavior.
- **Collision Detection:** Ensure that collision detection is enabled in the `ChSystemNSC` to prevent objects from passing through each other.
