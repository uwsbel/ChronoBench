```python
import pychrono as chrono
import pychrono.irrlicht as vis

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# 2. Add physical systems and objects
#   - UAZBUS vehicle
uazbus = chrono.ChBodyEasyCylinder(0.5, 1.5, 1.0, 1000.0)  # Replace with actual dimensions and mass
uazbus.SetPos(chrono.ChVectorD(0, 0, 0.5))  # Initial position
uazbus.SetBodyFixed(True)  # Fix the vehicle to the terrain

#   - Rigid terrain
terrain = chrono.ChBodyEasyBox(10, 10, 0.1, 1000.0)  # Replace with desired terrain dimensions and mass
terrain.SetPos(chrono.ChVectorD(0, 0, 0))
terrain.SetMaterialSurface(chrono.ChMaterialSurface(0.8, 0.2))  # Friction and restitution

system.Add(uazbus)
system.Add(terrain)

# 3. Set default parameters
#   - Driver system
driver = chrono.ChDriver()  # Initialize driver system

#   - Visualization settings
vis.Init()
vis.Add(uazbus)
vis.Add(terrain)
camera = vis.GetActiveCamera()
camera.SetPos(chrono.ChVectorD(5, 5, 2))  # Camera position
camera.SetTarget(chrono.ChVectorD(0, 0, 0))  # Camera target
vis.SetAmbientLight(chrono.ChColor(0.2, 0.2, 0.2))  # Ambient light
vis.SetDirectionalLight(chrono.ChColor(0.8, 0.8, 0.8), chrono.ChVectorD(1, 1, -1))  # Directional light

# Simulation loop
while True:
    # Update driver system
    driver.Update()

    # Advance simulation
    system.DoStepDynamics(0.01)  # Timestep

    # Update visualization
    vis.Render()
    vis.Sleep()  # Synchronize with real-time

# Cleanup
vis.Close()
```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries.
   - Set the Chrono data path.
   - Create a new Chrono system.

2. **Physical Systems:**
   - **UAZBUS:** Create a cylinder body representing the vehicle, set its initial position, and fix it to the terrain.
   - **Terrain:** Create a box body representing the terrain, set its position, and define its friction and restitution properties.
   - Add both objects to the Chrono system.

3. **Default Parameters:**
   - **Driver System:** Initialize a driver system for controlling the vehicle. You'll need to implement specific driver logic based on your control scheme.
   - **Visualization:**
     - Initialize Irrlicht for visualization.
     - Add the vehicle and terrain to the scene.
     - Set camera position and target.
     - Configure ambient and directional lighting.

4. **Simulation Loop:**
   - Continuously update the driver system.
   - Advance the simulation using `system.DoStepDynamics()` with a timestep of 0.01 seconds.
   - Update the visualization using `vis.Render()` and `vis.Sleep()` to synchronize with real-time.

5. **Cleanup:**
   - Close the Irrlicht visualization window.

**Remember:**

- Replace placeholder values with actual dimensions, masses, and control logic for your specific UAZBUS model and simulation requirements.
- Implement the driver system according to your desired control scheme (e.g., keyboard, joystick, etc.).
- Adjust camera settings and lighting to your preference.
- Experiment with different timesteps to achieve the desired simulation speed and stability.
