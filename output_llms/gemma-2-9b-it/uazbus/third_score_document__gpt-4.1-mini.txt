### 2. Correctness (30 points)

- **Incorrect Use of `chrono.ChBodyEasy`**:  
  The line:  
  ```python
  obstacle = chrono.ChBoxShape(chrono.ChVector3d(0.5, 5, 0.2))
  obstacle_body = chrono.ChBodyEasy(obstacle)
  ```  
  According to the docs, `ChBodyEasy` is not a constructor. Instead, there are `ChBodyEasyBox`, `ChBodyEasySphere`, etc. `ChBoxShape` is a visual shape, not a collision or body shape. This usage is incorrect and will cause an error or unexpected behavior.  
  **-15 points**

- **Setting `driver_inputs.throttle = 0.5` at the end of the loop**:  
  This line sets the throttle input after advancing the simulation and synchronizing. The driver inputs should be set before synchronization to affect the vehicle behavior in the current step. This is a logical error affecting simulation correctness.  
  **-10 points**

  This is correctly setting the collision system type to BULLET, which is appropriate.
