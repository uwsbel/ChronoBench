```python
import pychrono as chrono
import chrono.irrlicht as irrlicht

# Initialize Chrono environment
chrono.SetChronoDataPath("path/to/chrono/data")  # Replace with your Chrono data path
system = chrono.ChSystemNSC()

# Create visualization system
vis = irrlicht.ChIrrApp(system)
vis.AddCamera(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
vis.SetWindowSize(800, 600)
vis.SetRenderMode(irrlicht.CH_RENDERING_MODE_WIREFRAME)  # Optional: render in wireframe mode
vis.Start()

# --- Cloth Parameters ---
cloth_width = 2.0  # meters
cloth_length = 1.0  # meters
num_rows = 10
num_cols = 5
thickness = 0.001  # meters

# --- Material ---
material = chrono.ChMaterialShell()
material.SetYoungModulus(1e6)  # Adjust as needed
material.SetPoissonRatio(0.3)
material.SetDensity(1000)  # kg/m^3

# --- Create Cloth Mesh ---
cloth_mesh = chrono.ChMeshShell()
cloth_mesh.CreateMeshGrid(num_rows, num_cols, cloth_width, cloth_length, thickness)

# --- Create Cloth Body ---
cloth_body = chrono.ChBodyEasyShell(cloth_mesh, material)
cloth_body.SetPos(chrono.ChVectorD(0, 0, 0))
system.AddBody(cloth_body)

# --- Set Solver ---
system.SetSolverType(chrono.ChSolverType.PARSISO_MKL)

# --- Simulation Loop ---
while vis.Run():
    system.DoStepDynamics(chrono.ChTime(0.01))
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - Imports necessary PyChrono and Irrlicht modules.
   - Initializes the Chrono environment using `chrono.ChSystemNSC()`.
   - Creates an Irrlicht visualization system using `chrono.irrlicht.ChIrrApp()`.
   - Sets up a camera for viewing the simulation.
   - Configures the visualization window size and rendering mode.

2. **Cloth Parameters:**
   - Defines parameters like cloth dimensions, number of rows and columns for the mesh, and thickness.

3. **Material:**
   - Creates a `ChMaterialShell` object to define the cloth's material properties:
     - `SetYoungModulus`: Sets the Young's modulus (stiffness).
     - `SetPoissonRatio`: Sets the Poisson's ratio (how much the material deforms in one direction when stretched in another).
     - `SetDensity`: Sets the density of the cloth.

4. **Mesh Creation:**
   - Uses `chrono.ChMeshShell.CreateMeshGrid()` to generate a rectangular mesh grid representing the tablecloth.

5. **Cloth Body:**
   - Creates a `ChBodyEasyShell` object to represent the cloth.
   - Passes the cloth mesh and material to the body.
   - Sets the initial position of the cloth body using `SetPos()`.
   - Adds the cloth body to the Chrono system using `system.AddBody()`.

6. **Solver:**
   - Sets the solver type to `PARSISO_MKL` for efficient dynamics calculations.

7. **Simulation Loop:**
   - Runs a main loop using `vis.Run()`.
   - Inside the loop:
     - Updates the simulation dynamics using `system.DoStepDynamics(chrono.ChTime(0.01))`, with a time step of 0.01 seconds.
     - Renders the visualization using `vis.Render()`.



**To run this script:**

- Make sure you have PyChrono and Irrlicht installed.
- Replace `"path/to/chrono/data"` with the actual path to your Chrono data directory.
- Adjust cloth parameters and material properties as needed.
