### 2. Correctness (30 points)

- **Driver Usage:**  
  The script calls `driver.SetSteering()`, `driver.SetThrottle()`, `driver.GetInputs()`, `driver.Synchronize()`, and `driver.Advance()`, but **`driver` is never defined or initialized**. This will cause a runtime error.  
  **Deduct 15 points** for incorrect use of API leading to failure.

- **Body Creation:**  
  The box and cylinder bodies are created using `chrono.ChBodyEasy(1, box)` and `chrono.ChBodyEasy(1, cylinder)`. According to the API documentation, `ChBodyEasy` classes are named like `ChBodyEasyBox(lengthX, lengthY, lengthZ, density, visualize, collision, material)`. The constructor used here is incorrect: `ChBodyEasy` is not a class, but `ChBodyEasyBox` or `ChBodyEasySphere` etc. are.  
  The code uses `chrono.ChBoxShape(1,1,1)` and passes it to `ChBodyEasy(1, box)`, which is not a valid constructor. This is a **significant API misuse**.  
  The correct approach is to use `chrono.ChBodyEasyBox(1,1,1, density, visualize, collision, material)` or create a `chrono.ChBody()` and add a visual shape.  
  **Deduct 15 points** for incorrect body creation API usage.

- **Material Assignment:**  
  The script calls `box_body.SetMaterial(chrono.ChMaterialSurfaceNSC())` and then `box_body.GetMaterial().SetFriction(0.5)`. According to the API, `SetMaterial()` is not a method of `ChBody`. Instead, materials are assigned to collision models or contact materials. This is incorrect usage.  
  The correct approach is to create a material and assign it to the collision model or set it when creating the body.  
  **Deduct 10 points** for incorrect material assignment.

- **Collision Enabling:**  
  The script calls `box_body.SetCollide(True)`. According to the API, the method is `EnableCollision(True)`.
