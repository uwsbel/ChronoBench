```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht
import random

# 1. Initialize PyChrono environment and core components
chrono.SetChronoDataPath("..")  # Set the path to your Chrono data
app = irrlicht.Application(chrono.GetChronoDataPath())
world = chrono.ChSystemNSC()

# 2. Add physical systems and objects

# Particle emitter
emitter = chrono.ChParticleEmitter()
emitter.SetParticleCount(100)  # Number of particles to emit
emitter.SetParticleSize(0.01)  # Particle radius
emitter.SetEmissionRate(10)  # Particles emitted per second

# Define particle properties
emitter.SetParticleShape(chrono.ChParticleShape.SPHERE)  # Shape (can be SPHERE, BOX, or CUSTOM)
emitter.SetParticleMass(1e-3)  # Particle mass

# 3. Set default parameters

# Gravity
world.Set_G_acc(chrono.ChVectorD(0, -9.81, 0))  # Set gravity

# Visualize the simulation
vis = irrlicht.ChIrrApp(world, app.getVideoDriver(), app.getSceneManager(), app.getPhysScene())
vis.SetCustomDrawCallback(lambda: emitter.Draw())  # Draw particles using custom callback

# Apply custom gravitational forces
def apply_custom_gravity(data):
    for particle in emitter.GetParticles():
        # Calculate gravitational force between particles
        force = particle.GetPos() - data.pos
        force = force.Normalize() * 1e-3  # Adjust force strength

        # Apply force to particle
        particle.AddForce(force)

# Register callback function
world.SetCustomSimulationStepCallback(apply_custom_gravity)

# Run the simulation
app.run()
```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries.
   - Sets the Chrono data path.
   - Creates an Irrlicht application and a Chrono physics world.

2. **Particle Emitter:**
   - Creates a `ChParticleEmitter` object.
   - Sets parameters like particle count, size, emission rate, shape, and mass.

3. **Default Parameters:**
   - Sets the global gravitational acceleration.

4. **Visualization:**
   - Creates an Irrlicht visualization app connected to the Chrono world.
   - Uses a custom draw callback to visualize the particles emitted by the emitter.

5. **Custom Gravitational Forces:**
   - Defines a `apply_custom_gravity` function that iterates through particles and calculates gravitational forces between them.
   - Adjusts the force strength as needed.
   - Applies the calculated force to each particle.
   - Registers the `apply_custom_gravity` function as a custom simulation step callback, ensuring it's executed in each simulation step.

6. **Simulation Execution:**
   - Starts the Irrlicht application loop, running the simulation and rendering the particles.

**Remember:**

- Replace `".." ` with the actual path to your Chrono data folder.
- Adjust particle properties, emission rate, and force strength to achieve the desired simulation behavior.
- Explore different particle shapes and visualization options using Irrlicht.
