```python
import pychrono as chrono
import pychrono.irrlicht as irrlicht

# Initialize Chrono
chrono.SetChronoDataPath("..")  # Set the path to your Chrono data files
system = chrono.ChSystemNSC()

# Create a visualizer
vis = irrlicht.ChIrrApp(system)
vis.AddTypicalSky()
vis.AddTypicalLights()

# Set up the scene
vis.SetCamera(chrono.ChVectorD(5, 5, 5), chrono.ChVectorD(0, 0, 0))
vis.SetCameraDistance(10)

# Particle emitter
class ParticleEmitter(chrono.ChBody):
    def __init__(self, system, particle_count, emission_rate):
        super().__init__(system)
        self.particle_count = particle_count
        self.emission_rate = emission_rate
        self.particles = []
        self.create_particles()

    def create_particles(self):
        for i in range(self.particle_count):
            shape = chrono.ChTriangleMeshShape()
            shape.CreateFromBox(chrono.ChVectorD(0.1, 0.1, 0.1))  # Random shape example
            particle = chrono.ChBodyEasy(shape, 1.0)  # Mass 1.0
            particle.SetPos(chrono.ChVectorD(chrono.Random(), chrono.Random(), chrono.Random()))
            particle.SetRot(chrono.Q_from_Euler(chrono.Random(), chrono.Random(), chrono.Random()))
            particle.SetBodyFixed(False)
            particle.SetLinearVelocity(chrono.ChVectorD(chrono.Random(), chrono.Random(), chrono.Random()))
            self.particles.append(particle)

    def update(self, time_step):
        if time_step * self.emission_rate >= 1:
            for i in range(int(time_step * self.emission_rate)):
                self.create_particles()

# Initialize the emitter
emitter = ParticleEmitter(system, 100, 0.1)

# Custom gravitational force
def apply_gravitational_force(particle1, particle2):
    distance = particle1.GetPos() - particle2.GetPos()
    force_magnitude = -10 * (particle1.GetMass() * particle2.GetMass()) / (distance.LengthSquared())
    force_direction = distance.Normalize()
    particle1.AddForce(force_direction * force_magnitude)
    particle2.AddForce(-force_direction * force_magnitude)

# Simulation loop
while vis.Run():
    system.DoStepDynamics(0.01)

    # Apply gravitational forces between all particles
    for i in range(len(emitter.particles)):
        for j in range(i + 1, len(emitter.particles)):
            apply_gravitational_force(emitter.particles[i], emitter.particles[j])

    emitter.update(0.01)

    vis.Render()

```

**Explanation:**

1. **Initialization:**
   - Import necessary libraries: `pychrono` for physics and `pychrono.irrlicht` for visualization.
   - Initialize the Chrono system (`chrono.ChSystemNSC()`).
   - Create an Irrlicht visualizer (`chrono.ChIrrApp(system)`).
   - Set up the scene with a camera and lighting.

2. **Particle Emitter:**
   - Define a `ParticleEmitter` class that inherits from `chrono.ChBody`.
   - Constructor initializes the particle count, emission rate, and creates initial particles.
   - `create_particles()` method generates particles with random shapes, positions, velocities, and orientations.
   - `update()` method creates new particles at a specified rate.

3. **Custom Gravitational Force:**
   - Define `apply_gravitational_force()` function to calculate and apply gravitational forces between two particles.
   - The force magnitude is proportional to the product of the masses and inversely proportional to the square of the distance.
   - The force direction is along the line connecting the particles.

4. **Simulation Loop:**
   - Enter a loop that runs until the visualization window is closed.
   - Update the physics simulation with `system.DoStepDynamics(0.01)`.
   - Apply gravitational forces between all particles using nested loops and the `apply_gravitational_force()` function.
   - Update the particle emitter with `emitter.update(0.01)`.
   - Render the scene with `vis.Render()`.



**Note:**
