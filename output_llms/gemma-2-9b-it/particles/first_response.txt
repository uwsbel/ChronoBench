```python
import pychrono as chrono
import pychrono.irrlicht as chronoirr

# Initialize Chrono
chrono.SetChronoDataPath("data/")  
sys = chrono.ChSystemNSC()

# Create a scene with Irrlicht visualization
vis = chronoirr.ChIrrApp(sys)
vis.SetWindowSize(1280, 720)
vis.SetTerrain(chrono.ChColor(0.5, 0.5, 0.5))
vis.AddCamera(chrono.ChVectorD(0, 0, 5), chrono.ChVectorD(0, 0, 0), chrono.ChVectorD(0, 1, 0))
vis.AddLight(chrono.ChVectorD(1, 1, 1))

# Particle emitter settings
emitter_pos = chrono.ChVectorD(0, 0, 1)
particle_count = 100
particle_mass = 0.1
particle_radius = 0.05

# Create particle emitter
emitter = chrono.ChParticleEmitter(particle_count, particle_mass, particle_radius)
emitter.SetPos(emitter_pos)

# Define custom gravitational force function
def custom_gravity(particle, other_particle):
    distance = chrono.ChVectorD.Distance(particle.GetPos(), other_particle.GetPos())
    force = chrono.ChVectorD(0, 0, -1) * 10 / (distance**2)
    return force

# Initialize particle system
for i in range(particle_count):
    particle = chrono.ChParticle(particle_mass)
    particle.SetPos(chrono.ChVectorD(chrono.RandomDouble(-1, 1), chrono.RandomDouble(-1, 1), chrono.RandomDouble(0, 1)))
    particle.SetVel(chrono.ChVectorD(chrono.RandomDouble(-1, 1), chrono.RandomDouble(-1, 1), chrono.RandomDouble(-1, 1)))
    particle.SetRot(chrono.Q_from_Euler(chrono.RandomDouble(0, 360), chrono.RandomDouble(0, 360), chrono.RandomDouble(0, 360)))
    sys.Add(particle)
    
# Set up particle interactions
for particle in sys.GetBodyList():
    particle.SetBodyType(chrono.ChBody.Type.BodyFixed)
    particle.SetCollide(True)
    particle.SetMaterial(chrono.ChMaterialSurfaceNSC())
    particle.SetCustomGravityFunction(custom_gravity)

# Run the simulation
vis.Start()
while vis.Run():
    sys.DoStepDynamics(0.01)
    vis.Render()



```

**Explanation:**

1. **Initialization:**
   - Imports necessary libraries (`pychrono` and `pychrono.irrlicht`).
   - Initializes the Chrono system (`chrono.ChSystemNSC()`).
   - Creates an Irrlicht visualization interface (`chronoirr.ChIrrApp`) with a specified window size, terrain, camera, and light.

2. **Particle Emitter:**
   - Defines variables for emitter position, particle count, mass, and radius.
   - Creates a `chrono.ChParticleEmitter` object with the specified parameters.
   - Sets the emitter's position using `SetPos`.

3. **Custom Gravity Function:**
   - Defines a function `custom_gravity` that calculates a gravitational force between two particles based on their distance.
   - This function returns a force vector proportional to the inverse square of the distance.

4. **Particle System Initialization:**
   - Loops `particle_count` times to create individual particles.
   - For each particle:
     - Creates a `chrono.ChParticle` object with the specified mass.
     - Randomly assigns position, velocity, and orientation to the particle.
     - Adds the particle to the Chrono system (`sys.Add`).

5. **Particle Interactions:**
   - Iterates through the particles in the system.
   - Sets each particle's body type to `BodyFixed` (preventing rigid body motion).
   - Enables collision detection (`SetCollide(True)`).
   - Assigns a material to the particles.
   - Sets the custom gravity function (`SetCustomGravityFunction`) for each particle.

6. **Simulation Loop:**
   - Starts the Irrlicht visualization loop (`vis.Start()`).
   - Enters a `while` loop that runs until the user quits the visualization.
   - Inside the loop:
     - Advances the simulation by one time step (`sys.DoStepDynamics(0.01)`).
     - Renders the visualization (`vis.Render()`).
